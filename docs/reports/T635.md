## Claim card and exact conditional target

The audited conditional route keeps one fixed band/sample, one energy, and one moving window:

```text
B, X : one Band/Sample pair
E : Real
s t : Nat -> Real
u : TimeIcc s t N
v : a closed target endpoint with s_N <= v <= t_N
q : LoopData (B.L N) 2, with arbitrary charge word q.charge
```

The intended pointwise QV profile is exactly

```text
R_{u,v}^4 * A_u^(-4) * eta_u^(-1) * flowR^5,
R_{u,v} = (1-u)/(1-v),
A_u = B.scale E N u,
flowR = ell_t/ell_s.
```

All factors are evaluated on the same sample and the same window.  The endpoint sets are
closed.  In particular, `v = s_N` is retained and must be handled as the zero-length integral
branch; it does not permit a separately chosen sample or witness.  The prospective Lean QV
statement is uniform over every two-charge word, not only `(+,-)`.

The source inputs remain conditional:

```text
LocalLawFlow X E s t
AprioriDecayFlow X E s t
the floored LDE/high-probability inputs
the endpoint polynomial bounds
```

No compiled theorem supplies these simultaneously for one nondegenerate Gaussian sample and
one target interval.  Separate existential witnesses cannot be combined, and this report does
not manufacture or strengthen a witness.

  absorption it has the fourth-power expansion `(eta_u/eta_t)^4`, the source order

  second term; it must not be dropped from the pointwise QV ledger.

The arbitrary-charge Lean target is deliberately stronger in charge coverage than the literal
`sigma=(+,-)` statement of (2.76).  It is still only a conditional target here.
