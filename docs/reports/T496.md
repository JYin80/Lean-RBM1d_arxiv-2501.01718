## Result

For `d = Gauss.Dims.exampleGrow`, define

```text
F_b(u) = trace ((green(Hflow d N u omega, zt E u) - mE E) Eblk_b).
```

`eventually_centeredTrace_sub_le` proves under exactly

```text
|E| < 2,
forall N, 0 <= s_N <= t_N < 1,
c > 0,
Cond272Reg (band d) E s t c,
```

that eventually, for every `omega` in the fixed actual event

```text
Good_N = {omega | ||Xmat d N omega|| <= N},
```

every `u,u' in [s_N,t_N]` and every block `b` satisfy

```text
||F_b(u)-F_b(u')|| <= 2 N^5 sqrt(|u-u'|).
```

The proof applies `Gauss.norm_green_flow_sub_le_sqrt`, then
`RBM.norm_trace_mul_Eblk_le`; the normalized block trace introduces no
`W` factor. T488's `eventually_eta_window` gives
`eta_t >= N^(-2)`, hence `eta_t^(-2) <= N^4`. On `Good_N`,
`||Xmat||+1 <= 2N` for `N>=1`.

The statement directly includes collapsed windows `s_N=t_N`, windows
with `s_N=0`, both closed endpoints, and `u=u'=0`. No division by the
window length or by either time occurs.
