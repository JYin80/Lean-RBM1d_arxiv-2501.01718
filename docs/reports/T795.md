# T795 — uniform next image on an actual permutation prefix cell

## Deliverables and verdict

**Proved, standalone.** Added only `RBM1D/Gauss/PermutationNextImageUniformCell.lean` and this report. The public theorem `RBM.Gauss.uniformPerm_nextImage_given_actualPrefix` has the exact T766/T780 signature: for every `W`, `k : Fin W`, actual `π : PermΩ W`, and `v : Fin W` unused by every `i < k`,

```lean

  uniformPerm W {ρ | ρ ∈ prefixCell W k.val π} =
    (1 : ENNReal) / ((W - k.val : ℕ) : ENNReal)
```

## Proof and nonvacuity

The explicit equivalence `prefixCellNextImageSigmaEquiv` partitions the actual cell by the value of `ρ k`. `prefixCell_card_eq_sum_nextFibers` identifies its cardinal with the sum of fiber cardinals. T776's used-image zero theorem removes values already seen before `k`, giving `prefixCell_card_eq_sum_unused_nextFibers`. T785 counts the remaining values as `W-k.val`. T703's swap equivalence, transported through T749's bridge, makes all unused fibers equal. The actual permutation `π` inhabits the fiber at `π k`; equality transfers this **positive** cardinal to every unused `v`. Thus `prefixCell_card_eq_unused_mul_fiber` gives `#C = (W-k.val)·#fiber`. T776's event/card quotient and cancellation of this finite nonzero fiber cardinal finish the ENNReal identity. The proof never assumes the desired uniform law or an inconsistent prescribed prefix.

The companion `uniformPerm_nextImage_actualPrefix_nonzero` records positive actual-cell mass, positive `W-k.val`, and positive unused-fiber cardinal. The first is T776's finite, nonzero actual-cell denominator; `k.isLt` supplies the second. T776 separately proves quotient zero for a used image. No new probabilistic or analytic hypothesis was introduced.

Boundary declarations compile:

- `W=0`: `uniformPerm_nextImage_no_index_zero` proves no `k : Fin 0` exists.
- `W=1, k=0`: the unique event quotient is one.
- `W=2, k=0, π=id`: `v=0` and `v=1` are distinct and each quotient is `1/2`. T749/T776 also exhibit their separate nonempty one-point fibers, so the law is nondegenerate.
- `k.val+1=W`: every unused `v` has quotient one. A terminal `k=W` cannot have type `Fin W`.
