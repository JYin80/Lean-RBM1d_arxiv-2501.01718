## Proof route and power ledger

### 1. Raw two-loop coordinate derivative

For a stored time `u`, let `eta := etaT E u` and

```text
Bres := 2 * (1 + eta^(-1))^3.
```

The scale condition gives, eventually,

```text
N^(-1) <= etaT E (t N) <= etaT E u,
```

so `eta^(-1) <= N`.  For `N >= 1`,

```text
Bres <= 16 * N^3.
```

Apply `Gauss.quadVar_loopObs_sub_le` to the length-two `coordFun`.  With
`card(Idx N) <= N` and `APrimeQVGlobalPoly.coordWt2_le`, the derivative
coefficient is bounded by

```text
card(Idx N) * 2 * Bres^2 <= 512 * N^7,
sqrt(coordWeight) <= 3N.
```

Hence the safe reusable row is

```text
sqrt(quadVar(coordFun)) <= 2^15 * N^8.
```

This is independent of the matrix argument and therefore holds at the
identical matrix `(sqrt u : Complex) • Xmat d N omega` for every sample.

### 2. Tail and moving normalization

The literal tail floor is

```text
W^(-D) <= tT.
```

Since `D >= 0` and `W <= N`, division by `tT` costs at most `N^D`.  Thus the
raw normalized coordinate rate is at most

```text
2^15 * N^(D+8).
```

For every stored `j < k`, net membership gives

```text
s_N <= u_j <= t_N < 1.
```

Consequently

```text
sqrt(u_j) <= 1,
1 <= ratR E s N u_j,
ratR(E,s,N,u_j)^(-4) <= 1.
```

There is no residual time-ratio power in the global envelope.

### 3. Smooth prefix and threshold

Apply `sqrt_quadVar_prefixMatrix_le_exp` with the canonical calibration.  The
smooth maximum costs exactly `exp(1)` and no power of the target-mesh
cardinality.  Since `deltaWeight >= 0` and `N >= 1`,

```text
exp(1) <= threshold deltaWeight N
       = 8 * exp(1)^2 * N^(2*deltaWeight).
```

The threshold therefore absorbs the `exp(1)` factor without changing the
polynomial exponent.  This yields

```text
prefixGradient <= 2^15 * N^(D+8).
```

This is a deliberately coarse all-sample bound.  It neither uses nor
duplicates T607's sharp transition-local rate.

### 4. Current evolved QV

Use `APrimeQVGlobalPoly.eventually_qvAt_le_poly` with `Keta = 1`.  On the
same closed window and sample it gives

```text
qvAt <= 2^21 * N^(2D+16).
```

Therefore

```text
sqrt(qvAt) <= 2^11 * N^(D+8).
```

The constant is safe because `(2^11)^2 = 2^22 >= 2^21`.

### 5. Product

Multiplication gives exactly

```text
(2^15 * N^(D+8)) * (2^11 * N^(D+8))
  = 2^26 * N^(2D+16).
```

No `W` factor, mesh-cardinality factor, endpoint factor, or `ratR` factor is
hidden.  The only one-power widening is the separate payment bound
`jointEnvelope <= N^(2D+17)`.
