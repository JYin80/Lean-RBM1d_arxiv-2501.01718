## Literal definitions and identity

`APrimeGeneralMovingTwoChargeModulus.centeredTrace E N u ω σ b` is

```text
Tr[(Gsig(Hflow, zt E u, σ) − mSigma E σ · I) Eblk(b)].
```

`APrimeGeneralMovingCommonSources.centeredEvent` requires its norm bound for
**both** `σ : Bool`, every `u : TimeIcc s t N`, and every physical block `b`.
`Gsig true` is `green H z = (H−zI)⁻¹`; `Gsig false` uses `conj z`. At `E=0`,
`mSigma 0 true = i`, `mSigma 0 false = −i`, and `zt 0 u = i(1−u)`.

The scratch theorem `trace_Eblk_exact` uses the actual `Eblk`: for any full
matrix `A`, `Tr(A Eblk(b)) = W⁻¹ ∑_{α : Fin W} A_(b,α),(b,α)`.
`centered_true_diagonal` therefore gives exactly

```text
centered trace(+) = W⁻¹ ∑_α [G(+)_((b,α),(b,α)) − i].
```

There is no second `W⁻¹`: T953's `permutationFourierSum` already contains the
one-block `W⁻¹` average. If all `W` full-resolvent diagonal entries in block
`b` equal that same zero-mode average `q_b(u)`, the outer `Eblk` average leaves
`q_b(u)−i`. This cancellation, with `W>0`, is compiled as
`centered_true_of_constant_diagonal`.

The scratch `centered_false_conj_true` is the full-matrix Hermitian
conjugation identity. It uses the existing
`APrimeTwoChargeOneLoop.centered_block_trace_false_eq_conj_true`; hence
`centered trace(−) = conj(centered trace(+))`, with **the same** physical
sample and block. Its norm is identical. In particular the false charge is
`conj(q_b(u)−i) = conj(q_b(u))+i`, not `q_b(u)+i` in general.
