# T437 — full-root QV monotonicity in block J and fixed-two adapter

## Verdict

Implemented in `RBM1D/Gauss/APrimeFirstCellQVFixedTwo.lean`.

The deterministic `APrimeFullQV.rootProfile` is monotone in its block
parameter `J` under the actual positive width, scale, and spectral-height
premises.  Applying this with T436's

```text
1 ≤ APrimeSupportRunning.jG N r ω ≤ 2
```

replaces the actual block parameter by the literal constant `2` while
retaining the complete moving-endpoint profile.  The near row, repaired
`W⁻¹` term, quadratic and cubic far rows, and propagated `W⁻⁶⁰` leakage all
remain inside the unchanged `rootProfile` definition.

The resulting running theorem and positive `k=2` witness use T434's literal
`sharpCommonEvent`; no T395 event or separate resident is introduced.

## Deterministic sign and monotonicity lemmas

The endpoint kernel multiplying the far square root is proved nonnegative:

```lean
theorem endpointKernel_nonneg {Ω : Type*} [MeasurableSpace Ω]
    (B : Band Ω) (E : ℝ) (N : ℕ) (u v D : ℝ)
    (a : LoopArg (B.L N) 2) (hW : 0 ≤ (B.W N : ℝ)) :
    0 ≤ ((1 - u) / (1 - v)) ^ 2 *
      Step2.xiK (B.L N) (B.W N : ℝ) (mE E).im *
      Step2.tT B E N D v (zdist (B.L N) (a 0 - a 1))
```

Its three factors are nonnegative: the time ratio is squared,
`Step2.xiK_nonneg` supplies the middle factor, and `tailT_nonneg` supplies
the last factor.  No division-sign assumption on `1-v` is needed for this
kernel fact; the application still has the stronger `v≤1/2`.

The entire root profile is also nonnegative:

```lean
theorem rootProfile_nonneg {Ω : Type*} [MeasurableSpace Ω]
    (B : Band Ω) (E : ℝ) (N : ℕ)
    (u v D ellSource J Smax ε : ℝ) (a : LoopArg (B.L N) 2)
    (hW : 0 ≤ (B.W N : ℝ)) :
    0 ≤ APrimeFullQV.rootProfile B E N u v D ellSource J Smax ε a
```

This includes the supported near kernel, its `W⁻ᴰ` leakage, and the far
kernel.  It is used when squaring the normalized root-profile inequality.

The main deterministic theorem is:

```lean
theorem rootProfile_mono_J {Ω : Type*} [MeasurableSpace Ω]
    (B : Band Ω) (E : ℝ) (N : ℕ)
    (u v D ellSource Smax ε : ℝ) (a : LoopArg (B.L N) 2)
    {J J' : ℝ}
    (hW : 1 ≤ (B.W N : ℝ)) (hℓu : 0 < B.ell N u)
    (hηu : 0 < etaT E u) (hJ0 : 0 ≤ J) (hJJ' : J ≤ J') :
    APrimeFullQV.rootProfile B E N u v D ellSource J Smax ε a ≤
      APrimeFullQV.rootProfile B E N u v D ellSource J' Smax ε a
```

The proof reuses the existing generic
`APrimeJGWidened.diagFarRate_mono`.  Literally,

```text
diagFarRate(J)
 = 2 η⁻¹ [cFar2 (2J)² A (2√Smax) + 72 (2J)³ A⁻¹]
   + 4 W L W⁻ᴰ (2J)³.
```

All coefficients multiplying the quadratic and cubic powers are
nonnegative when `W≥1`, `ell>0`, and `eta>0`.  The near square-root term is
independent of `J`.  `Real.sqrt_le_sqrt` transports far-rate monotonicity,
and `endpointKernel_nonneg` transports it through the endpoint kernel.

The theorem is slightly stronger than the application: it works for every
`D,v,Smax`.  No premise `Smax≥0` is logically required because `Smax`
occurs as `√Smax`, which is nonnegative for every real input.  In the T437
application `D=60`, `v≤1/2`, and the actual source amplitude is used.

## Fixed-two full profile

The exported profile is:

```lean
def fixedTwoMovingProfileAt (ν : ℝ) (N : ℕ) (ω : Ω d) (v r : ℝ)
    (a : LoopArg (d.L N) 2) : Prop :=
  APrimeDriftTimeFamily.qvAt d 0 60 N Step2.sigPM a 0 v r ω ≤
    ((APrimeDriftTimeFamily.driftScale d 0 60 N a 0 v)⁻¹ *
      APrimeFullQV.rootProfile B 0 N r v 60
        (APrimeFirstCellSourceAllTime.ellSource (sourceLoss ν) N)
        2
        (APrimeFirstCellSourceAllTime.sourceC4 (sourceLoss ν) N r)
        ((d.W N : ℝ)⁻¹) a) ^ 2
```

The moving endpoint `v` and time `r` are unchanged.  The source loss is
exactly T418's `sourceLoss ν`.  Since the whole `rootProfile` is reused,
this statement retains:

- `diagNearRate + 2W⁻¹`;
- the supported near endpoint kernel;
- its separate propagated `W⁻⁶⁰` leakage;
- the far `J²` and `J³` rows, now evaluated at `J=2`;
- the far `WL W⁻⁶⁰ J³` row;
- the literal `driftScale ... 0 v` normalization.

The local adapter has the exact signature:

```lean
theorem fixedTwoMovingProfileAt_of_sharp {ν : ℝ} {N : ℕ} {ω : Ω d}
    {v r : ℝ} {a : LoopArg (d.L N) 2}
    (hW : 1 ≤ (d.W N : ℝ)) (hℓ : 0 < B.ell N r)
    (hη : 0 < etaT 0 r) (hr0 : 0 ≤ r) (hrv : r ≤ v) (hv1 : v < 1)
    (hJ1 : 1 ≤ APrimeSupportRunning.jG N r ω)
    (hJ2 : APrimeSupportRunning.jG N r ω ≤ 2)
    (hraw : APrimeFirstCellQVSharpMoving.sharpMovingProfileAt
      ν N ω v r a) :
    fixedTwoMovingProfileAt ν N ω v r a
```

The proof applies `rootProfile_mono_J`, multiplies by the nonnegative inverse
`driftScale`, and squares.  Positivity of `driftScale` follows from
`0≤r≤v<1`.  `rootProfile_nonneg` supplies the sign needed for
`pow_le_pow_left₀`.  Thus the passage to `J=2` changes only the block slot;
it performs no rate absorption.

## Same-event running theorem

`fixedTwoRunningMovingProfile τ' δ ν` states that eventually, for every
`ω` in the literal T434 `sharpCommonEvent`, every actual positive-`δ`
active prefix `k≥1`, and

```text
v = cutNetPt 0 transitionMesh N k,
```

one has `0<v≤firstCellT≤1/2`, the all-real-time sharp cap, and for every
`r∈[0,v]`:

```text
1 ≤ jG(r) ∧ jG(r) ≤ 2 ∧
∀ a, fixedTwoMovingProfileAt ν N ω v r a.
```

Its producer is:

```lean
theorem eventually_fixedTwo_running_moving_profile {τ' δ ν : ℝ}
    (hτ' : 0 < τ') : fixedTwoRunningMovingProfile τ' δ ν
```

It uses T436's
`eventually_sharp_running_moving_profile` on exactly the same event and
sample.  `APrimeJG.one_le_jG` supplies the lower bound, while T436 supplies
the upper bound and the actual-J full profile.  For `r≤v≤1/2`, the existing
`ellHat` and `etaT` lemmas give the positive scale premises for the local
adapter.

The interval is closed, so both `r=0` and `r=v` are present.  No fixed
endpoint replaces `v=u_k`, and `k=0` remains outside this positive-prefix
statement.
