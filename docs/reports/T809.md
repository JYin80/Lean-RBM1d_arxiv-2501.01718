# T809 — finite-set next-image quotient preflight

## Verdict and frozen target

**PASS (mathematical preflight, not a Lean proof).** The following exact finite-set statement is true with the current definitions, has no additional assumptions, and is a suitable frozen target for T810:

```lean
theorem uniformPerm_nextImage_finset_given_actualPrefix
    (W : ℕ) (k : Fin W) (π : PermΩ W) (A : Finset (Fin W)) :
    uniformPerm W {ρ | ρ ∈ prefixCell W k.val π ∧ ρ k ∈ A} /
      uniformPerm W {ρ | ρ ∈ prefixCell W k.val π} =
        ((A.filter (fun v => v ∈ unusedImages W k π)).card : ENNReal) /
          ((W - k.val : ℕ) : ENNReal)
```

The code block is a **statement template**, not code submitted to Lean. The actual `π` fixes a nonempty cell; arbitrary inconsistent prescribed prefixes do not enter the claim. The quotient is an event-on-cell ratio, not conditional expectation with respect to `prefixSigma`.

The proposed T810 module can import `PermutationNextImageUniformCell`, which already imports the T776 and T785 modules. None of those modules imports the proposed finite-set theorem, a conditional law, or T810, so this route has no circular dependency.

For each `v ∈ A`, let `E_v={ρ | ρ∈prefixCell W k.val π ∧ ρ k=v}`. The target event is the finite union of the `E_v`; distinct `v` give disjoint fibers because `ρ k` is a single value. Thus its `uniformPerm` mass is `∑ v∈A, uniformPerm W E_v`. Dividing by the **same positive finite cell mass** distributes across that finite sum in `ENNReal`. For `v` used by the prefix, `mem_unusedImages_iff` supplies `i<k` with `π i=v`, and T776 makes its summand zero. For each unused `v`, T795 makes its summand `1/(W-k.val)`. Hence the sum is the number of unused members of `A` divided by `W-k.val`. Equivalently, use T776's finite-cardinality quotient, partition the event cardinal into disjoint next-image fibers, and cancel the common positive fiber cardinal using T795's established equality. Either path involves only finite sums and actual positive cells.

The denominator `W-k.val` is a positive natural number for every `k : Fin W`; its `ENNReal` cast is neither zero nor `⊤`. The cell denominator is positive and finite by T776. All singleton fibers at unused values are positive by T795, so no hidden zero-division convention is needed. `A=∅` yields zero, and inclusion of used values changes neither side.

## Boundary and nondegeneracy checks

| Case | Direct value |
| --- | --- |
| `W=0` | There is no `k : Fin 0`; T785's `no_next_index_zero` records this. The sole width-zero permutation is irrelevant to a next-image statement. |
| `W=1, k=0` | The only image is unused and the cell has mass one. `A=∅` gives zero; `A={0}` gives one. |
| `W=2, k=0, π=id` | The prefix cell is all two permutations and both images are unused. `A={0}` has quotient `1/2`; `A={1}` also has `1/2`; `A=univ` has one. Identity and swap occupy the two distinct positive fibers, giving a genuine nondegenerate witness. |
| `k.val+1=W` | Exactly one image is unused, necessarily `π k`. The quotient is one if `π k∈A` and zero otherwise. In particular `W=2,k=1` has this behavior for either actual permutation. |

These checks test the statement's edge cases but are not being used as a universal proof; the finite disjoint-partition argument above covers every `W`, `k`, `π`, and `A`.
