## Per-import audit

### `APrimeQVEndpoint`

- **Owner and acceptance:** T277; report `docs/reports/T277.md`.  The module
  is accepted as a partial endpoint-QV bridge and was included in the
  T302/T304 committed dependency closure.  Current STATUS still explicitly
  describes T277's evolved endpoint work as partial.
- **Actual versus conditional:** `weightedKernel_tail_le` and the exact QV
  identity are deterministic actual statements.  The principal
  `sqrt_evolvedQV_le_endpoint` is pointwise for the actual evolved two-loop
  quadratic variation, but it requires the displayed `Gm/Gsq`, four-loop,
  (2.73), far-tail, scale, and logarithmic hypotheses.  It is not a complete
  Gaussian Good-event producer and does not itself give the normalized
  integrated `QBd` budget.
- **Witness/event:** `endpoint_scale_witness` gives a positive-duration,
  large-`W` deterministic witness.  It does not certify simultaneous
  satisfaction of the model fields on one Good event.
- **Signature effect:** this was a new module.  It does not modify an old
  declaration.  Its explicit large-`W` assumptions and leakage term are
  recorded by paper delta T277a.
- **Root decision:** no direct line is needed; both committed root branches
  above already import it transitively.
