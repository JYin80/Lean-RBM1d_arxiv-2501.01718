## Delivered declaration

The new module fixes the model privately to
`d = Gauss.Dims.exampleGrow` and exports exactly one theorem:

```lean
theorem flowY_left_eq_initialEvolvedNormAt
    {E D : Real} {s t : Nat -> Real} (N : Nat)
    (v : TimeIcc s t N) (hE : |E| < 2) (ht1 : t N < 1)
    (a : LoopArg (d.L N) 2) :
    APrimeDuhamelModel.flowY d N
        (APrimeDriftTimeFamily.coordAt d E D N Step2.sigPM a
          (s N) v) (s N) =
      APrimeAssembly.initialEvolvedNormAt (sample d) E D s N v a
```

This is equality of random functions, not merely pointwise equality at a
chosen sample and not an inequality.  It is uniform in every bulk `E`, every
real `D`, every `N`, every moving endpoint `v : TimeIcc s t N`, and every
two-loop coordinate `a`, subject only to the already needed bulk condition
`|E| < 2` and upper-window condition `t N < 1`.

## Rewrite route

The proof first applies function extensionality at `omega`, then uses exactly
one semantic rewrite:

```lean
rw [APrimeDriftTimeFamily.flowY_coordAt d E D N Step2.sigPM a
  hE v.2.1 (v.2.2.trans_lt ht1)]
```

The remaining goal closes by `rfl`.  Thus the only non-definitional step is
the existing `Gauss.ukerObsT_flow` reduction encapsulated by
`flowY_coordAt`; the following identifications remain definitional:

- `Step2.lk` is `SumZeroDyn.lkT ... Step2.sigPM`;
- the charge on both sides is exactly
  `xiOf (mSigma E) Step2.sigPM`;
- `APrimeDriftTimeFamily.driftScale` is exactly the denominator in
  `APrimeAssembly.initialEvolvedNormAt`.

No charge conversion lemma or normalization rewrite was used.

## Endpoint audit

The same subtype-coerced real endpoint `v` occurs in `coordAt`, `Uker`,
`driftScale`, and `initialEvolvedNormAt`.  The lower endpoint condition passed
to `flowY_coordAt` is literally `v.2.1 : s N <= v`.  Its strict upper bound is
obtained without changing the endpoint:

```text
v <= t N < 1,
```

namely `v.2.2.trans_lt ht1`.  Therefore the result includes both `v=s N`
(the `k=0` consumer branch) and every other closed-interval target-net point;
no endpoint is replaced by `t N`, and no positive-time assumption is added.
