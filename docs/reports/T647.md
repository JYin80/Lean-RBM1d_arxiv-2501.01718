## Why T627 could not succeed

T627 tested an import-only substitution between the `SampleFlowBridge` and
`Step2Bootstrap` surfaces.  Both choices still reached `Hierarchy.Step45`, so its edits were
correctly reverted.  The deeper reason is that the prefix code needs declarations presently
*stored* in polluted files, not either polluted file as a mathematical unit:

1. the eight elementary soft-maximum declarations are inside `Step2Bootstrap`;
2. `jStar`, `sigPM`, `lk`, `tT`, and `jS` are inside `Hierarchy.Step2`;
3. `ratR`, `ratR_pos`, `jSnorm`, and `one_le_ratR` are inside `Step2Moment`;
4. `cutNetPt` and `cutNetTop` are inside `CutHypTheta`;
5. fixed-time differentiability and the flow identity were proved using later bridge modules.

Thus no permutation of the old imports can be clean.  The declarations must be extracted,
and the three small bridge uses must be reproved at the lower level.  This is the missing
upstream extraction recorded by T627.

### Lower-level proof replacements

Only proof plumbing changes:

1. `contDiff_coordFun` is proved at fixed time directly from
   `Gauss.bddC2_loopObs` in `Gauss.LoopC2`; the joint-time
   `contDiffAt_loopObs_zt_pair` theorem is unnecessary.
2. `smoothJSMatrix_flow` unfolds the same equality locally using
   `Gauss.loopObs_Hflow`; no `SampleFlowBridge` theorem is imported.
3. `prefixSample_le_of_jSnorm_bound` proves the needed
   `cutNetPt ∈ Set.Icc (s N) (t N)` arithmetic locally from
   `j < k ≤ cutNetTop`; it does not import the later net theorem stack.

`Step2.lk` is written with the unfolded body `X.Lval ... - B.Kval ...`, which is
definitionally equal to its current `SumZeroDyn.lkT` body.  This removes the otherwise
spurious `SumZeroDyn -> Step3` route without changing its type or value.

### Cardinal calibration: local, not extracted

Keep the public `APrimeWeight.card_calib_top` where it is for existing consumers, but do not
make the new core import `APrimeWeight`.  Instead, reproduce its elementary argument as a
private local lemma and use it only in `canonicalM_calibration`.

This is smaller than moving the public theorem: it avoids an additional `APrimeWeight`
facade edit and an extra public core declaration, while preserving the frozen calibration
statement, exact `+1`, exact denominator `2 * canonicalM`, and exact `exp 1` constant.  The
prototype proves the local version with no new hypothesis and the same allowed axioms.

### SampleFlowBridge and Step2Bootstrap subsets

- `SampleFlowBridge`: extract **zero** declarations.  Its sole lower-prefix contribution,
  `lk_eq_loopObs_sub`, is a one-line consequence of `loopObs_Hflow` and is reproved locally.
- `Step2Bootstrap`: extract exactly the eight soft-maximum declarations listed above.
  None of its cut-event, moment, Step-6, or stochastic-domination surface belongs in the
  core.
