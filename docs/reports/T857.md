## Theorem and proof

`uniformPerm_nextImage_hasCondSubgaussianMGF` proves the installed Mathlib interface

```lean
HasCondSubgaussianMGF (prefixSigma W k.val) le_top
  (fun π : PermΩ W => f (π k) - unusedImageAverage W k f π)
  ⟨4 * C ^ 2, ...⟩ (uniformPerm W)
```

for every `k : Fin W`, `0 ≤ C`, and `∀ v, |f v| ≤ C`. There is no added probabilistic hypothesis. T842 gives the pointwise interval `[-2C, 2C]`. T840 gives zero conditional expectation. `StronglyMeasurable.ae_eq_trim_of_stronglyMeasurable` transfers the latter to the trimmed prefix measure, and `condExp_ae_eq_trim_integral_condExpKernel` identifies that expectation with the conditional-kernel integral. On this **one** full-measure set of prefixes, Hoeffding's lemma under each probability kernel gives an MGF bound for **every real** `t`. `condExpKernel_comp_trim` and finiteness of the permutation space provide exponential integrability under the composite measure. The interval width is `4C`; Mathlib's parameter `((b-a)/2)²` simplifies to `4C²`.

## Boundaries and nondegeneracy

- `W=0`: there is no `k : Fin 0`, so no conditional reveal statement is requested.
- `W=1` and the last reveal at any width: T840 proves the centered increment is pointwise zero; the general parameter remains valid.
- `W=2`, `k=0`, `f(0)=0`, `f(1)=1`, `C=1`: `uniformPerm_nextImage_condMGF_two_witness` proves the exact conditional MGF and positive mass of both identity and transposition atoms. T840's `uniformPerm_nextImage_centered_two_witness` gives the distinct centered values `-1/2` and `1/2`. Thus the theorem is not vacuous.
