## Claim, verdict, and dispatch decision

**Primary implementation verdict: incomplete, with the smallest missing implication identified below. Mathematical/source preflight: PASS.** The accepted actual first-cell event and the compiled scalar minor calculus suffice mathematically for every fixed finite deletion budget. No new local law, event intersection, random-scale axiom, all-time input, or arbitrary-`Dims` statement is required. However, the requested all-order squared-loop theorem is **not already compiled** in the prescribed sources. T1452 proves only order one, including arbitrary admissible base minors. The pivot reciprocal identity and its scalar higher differences already compile. The minimal independently provable first subtarget is the one-fresh-deletion endpoint estimate in Section 5. ## 1. Exact normalized target and quantifiers

Fix `d = Dims.exampleGrow`, `E = 0`, and the single positive first-cell parameter `τ'` supplied by the accepted T1412/T1444 source. Put `s = firstCellS τ'` and `t = firstCellT τ'`. Write

\[
 E_b(N)=\texttt{flowNetEvent}\ d\ 0\ s\ t\ \delta_b\ N,
 \qquad
 \beta=\min(b/8,1/16),\qquad
 \delta_b=N^\beta\,\texttt{firstCellPsi}(N).
\]

For one `ω ∈ E_b(N)` and one `u ∈ [firstCellS τ' N, firstCellT τ' N]`, set

\[
 W=d.W(N),\quad z=\texttt{zt}\ 0\ u,\quad
 G^S_{xy}=\texttt{gEnt}\ d\ N\ u\ z\ \omega\ x\ y\ S,
 \quad
 \Gamma=\texttt{Lmax}(\texttt{Hflow}\ d\ N\ u\ \omega,z).
\]

The minor is zero-embedded in the original index set. For the **ordered** original blocks `a,c`,

\[
 \Gamma^S_{ac}=W^{-2}\sum_{x\in I_a,y\in I_c}|G^S_{xy}|^2
   =\texttt{embeddedMinorLoop}\ d\ N\ u\ z\ S\ \omega\ a\ c.
\]

Use `Δ_k F(S) = F(S) - F(S ∪ {k})`. For a list `l` of distinct fresh deletion labels, let `r = l.length` and `T = l.toFinset`. The target is

\[
 |\Delta_T\Gamma^S_{ac}|
 \le C_M N^{C_M b}\Gamma^{1+r/2},
 \qquad 1\le r,\quad |S|+r\le M,\quad S\cap T=\varnothing. \tag{L}
\]

If a deletion label is already in `S`, that entire iterated difference is zero; thus allowing such bases adds only a trivial case. No block coordinates are removed from the summation domain.

The intended order is

```text
one τ' > 0 with the actual LocalLawUnifIcc source;
for every M, a finite constant C_M >= 1 independent of b, N, ω, u and blocks;
for every b > 0, eventually N >= 1;
for every ω ∈ E_b(N), every u in the first cell,

```

Equivalently one may choose `b,M` in the opposite order; both precede eventual `N`. The threshold for `N` may depend on the fixed budget and loss. There is no single eventual threshold asserted for all budgets simultaneously. The event remains **exactly** T1444's `E_b(N)`, with the same `b`; the constant in (L) is paid in the conclusion, not by changing the sample or replacing `Γ` by a minor maximum or smooth proxy.

The manuscript's (4.9) is the principal-minor rank-one identity. Its (4.12) is fixed-time stochastic domination of a weighted actual row fluctuation by the full same-sample random `Lmax`, for deterministic weights with `max |t_k| ≤ W⁻¹` and `sum |t_k| ≤ 1`. ## 3. Same-event scales and the missing vector induction

Fix the parameters and an eventual `N` such that

\[
 N\ge1,\qquad 0\le\delta_b\le1/4,\qquad 8M\delta_b\le1.
\]

T1444 proves these smallness conditions eventually after fixing `b,M`: `δ_b ≤ N^(-3/16)`. At every first-cell time of every sample in `E_b`, let

\[
 \psi=2\delta_b,\qquad Q=\sqrt{20}\,N^{b/2}\sqrt\Gamma.
\]

The compiled sources give

\[
 0\le\psi\le1/2,\qquad W^{-1}\le4\Gamma,\qquad \Gamma>0,
 \qquad
 \psi^2=N^{2\beta}W^{-1}\le4N^{2\beta}\Gamma. \tag{1}
\]

The exact identity in (1) uses `firstCellPsi_sq_eq_invW_div_four`; it is the arithmetic used inside T1444, not a new REL hypothesis. In particular,

\[
 \psi\le2N^\beta\sqrt\Gamma,\qquad \beta\le b/8. \tag{2}
\]

Keep `ψ = 2δ_b`, rather than substituting a random real into a stochastic theorem. `diffBd_atom` is pointwise at the fixed sample, so it applies directly to the actual `hg` above. Its protected-label conditions give, at every permitted shifted base,

\[
 |\Delta_A G_{ij}|\le c_n\psi^{1+|A|}\quad(i\ne j),\qquad
 |\Delta_A (G_{ii}^{-1})|\le c_n\psi^{|A|},\quad |A|\le n, \tag{3}
\]

provided the difference labels avoid the displayed scalar endpoints. Here `c_n = atomC n`. Those conditions will always hold for the **internal** scalar factors below.

Define the normalized endpoint vectors and normalized block matrix on the original offset sets:

\[
 V^S_{a,k}=W^{-1/2}(G^S_{xk})_{x\in I_a},\qquad
 R^S_{k,c}=W^{-1/2}(G^S_{ky})_{y\in I_c},\qquad
 A^S_{ac}=W^{-1}(G^S_{xy})_{x\in I_a,y\in I_c}.
\]

Use their ordinary finite Euclidean and Hilbert–Schmidt norms. T1444 says `‖V‖, ‖R‖ ≤ Q` for every surviving terminal and `|S| ≤ M`. A deleted terminal gives the zero vector. Summing the squared column-endpoint estimate over the `W` original columns yields

\[
 \|A^S_{ac}\|_{HS}^2
 =W^{-1}\sum_{y\in I_c}\|V^S_{a,y}\|_2^2\le Q^2. \tag{4}
\]

Thus the zero-order block bound needs neither a minor-to-full telescoping argument nor a new Ward proof.

### Endpoint invariant, including boundary coordinates

For distinct difference labels avoiding terminal `k`, prove simultaneously for all shifted bases within the budget

\[
 \|\Delta_T V^S_{a,k}\|_2,
 \|\Delta_T R^S_{k,c}\|_2
 \le A_r Q\psi^r,\qquad r=|T|. \tag{5}
\]

Only the **fixed terminal** is excluded from `T`. The freely summed coordinate `x` or `y` is not excluded; it can equal any deletion pivot. This is the crucial difference from applying `diffBd_atom` pointwise to every component. Such an application would demand false endpoint-avoidance hypotheses on these boundary coordinates.

For `j ≠ k`, the already compiled identity gives, componentwise including `x = j` and `x = k`,

\[
 \Delta_j V^S_{a,k}
 =V^S_{a,j}\,G^S_{jk}\,(G^S_{jj})^{-1},\qquad
 \Delta_j R^S_{k,c}
 =G^S_{kj}\,(G^S_{jj})^{-1}\,R^S_{j,c}. \tag{6}
\]

Start with `A_0 = 1`. For `r ≥ 1`, select the first label `j` and distribute the other `r-1` distinct differences over the three factors of (6). The identity

\[
 \Delta_h(fg)=(\Delta_h f)g+f^{+h}(\Delta_h g)
\]

holds componentwise, and for scalar multiplication of vectors. Repetition creates at most `3^(r-1)` terms, each with shifted factors and orders `s,t,v` satisfying `s+t+v=r-1`. Its norm is bounded by

\[
 (A_sQ\psi^s)(c_{r-1}\psi^{1+t})
 (c_{r-1}\psi^v)
 =A_s c_{r-1}^2 Q\psi^r.
\]

The vector factor's new terminal is `j`; the remaining labels avoid `j` by distinctness. The internal off-diagonal factor's endpoints are `j,k`, both avoided by those remaining labels. Every shifted base uses only labels from the original finite difference, so the bound `|S|+r ≤ M` covers all evaluations. No extra deletion budget for a surviving terminal is needed.

For example, finite constants are obtained recursively by

\[
 A_r=3^{r-1}\Big(\max_{0\le s<r}A_s\Big)c_{r-1}^2,
 \qquad r\ge1.
\]

This proves (5) by induction. It uses no global inverse-diagonal bound: all reciprocal factors are at the same sample and finite minor levels already covered by `hg`.

The inverse pivot is not a missing mathematical input. The exact rule already compiled is

\[
 \Delta_j(G^S_{kk})^{-1}
 =-G^S_{kj}G^S_{jk}(G^S_{jj})^{-1}
   (G^S_{kk})^{-1}(G^{S+j}_{kk})^{-1}. \tag{7}
\]

It costs at most `8 ψ²` when `j ≠ k`; `ψ ≤ 1` permits weakening this to one gain. `diffBd_atom` already iterates that bookkeeping. Reproving (7) or asserting it for coinciding protected labels would be the wrong next ticket.

## 4. Block differences and all squared-loop faces

At the first deletion `k`, the same rank-one identity becomes

\[
 \Delta_k A^S_{ac}
 =V^S_{a,k}\otimes R^S_{k,c}\,(G^S_{kk})^{-1}. \tag{8}
\]

The outer product in (8) is ordinary multiplication of its two coordinates. Its Hilbert–Schmidt norm is the product of the two vector norms, independently of `W` and `L`.

Distribute the remaining `r-1` differences over these three factors, use (5) twice and the inverse part of (3), and sum the finitely many terms. This gives

\[
 \|\Delta_T A^S_{ac}\|_{HS}
 \le B_r Q^2\psi^{r-1},\qquad r\ge1, \tag{9}
\]

with, for example,

\[
 B_r=3^{r-1}\Big(\max_{0\le s<r}A_s\Big)^2 c_{r-1}.
\]

For order zero use (4), `‖A^S_ac‖ ≤ Q`, not an invented `Q² ψ⁻¹` bound. Equations (8)–(9) preserve the row block `a` and column block `c`. They do not invoke `Lre` or its reversed block convention.

Now `Γ^S_ac = ‖A^S_ac‖²`. The discrete sesquilinear product rule, followed by Cauchy–Schwarz, expands its `r`-fold difference into at most `2^r` terms. Each term pairs shifted block differences of orders `p,q` with `p+q=r`. If one order is zero, (4) and (9) give a multiple of `Q³ ψ^(r-1)`. If both are positive, (9) gives a multiple of `Q⁴ ψ^(r-2)`. Conjugation commutes with differences, so this argument applies to the actual squared complex norm.

Consequently, for finite constants `D_r` depending only on `r`,

\[
 |\Delta_T\Gamma^S_{ac}|
 \le D_1 Q^3\quad(r=1),
\]

and

\[
 |\Delta_T\Gamma^S_{ac}|
 \le D_r\big(Q^3\psi^{r-1}+Q^4\psi^{r-2}\big),\quad r\ge2. \tag{10}
\]

For `r=1`, retain the stronger accepted `320 N^b Γ^(3/2)` theorem; there is no need to implement a replacement with a worse loss. For `r ≥ 2`, substitute (2) into (10):

\[
 Q^3\psi^{r-1}
 \le20^{3/2}2^{r-1}
 N^{3b/2+(r-1)\beta}\Gamma^{1+r/2},
\]

\[
 Q^4\psi^{r-2}
 \le400\,2^{r-2}
 N^{2b+(r-2)\beta}\Gamma^{1+r/2}. \tag{11}
\]

Since `β ≤ b/8` and `r ≤ M`, both losses are at most `N^((2+M/8)b)`. Choose a single `C_M ≥ max(320, 2+M/8)` also satisfying

\[
 C_M\ge D_r\big(20^{3/2}2^{r-1}+400\,2^{r-2}\big)
 \quad\text{for every }2\le r\le M.
\]

There are only finitely many such requirements. This proves exactly (L).

There is **no residual bandwidth factor**: each endpoint carries `W⁻¹/²`, each block carries `W⁻¹`, the squared loop carries `W⁻²`, and the outer-product identity multiplies the two endpoint norms exactly. The only remaining use of bandwidth is the accepted same-event comparison `W⁻¹ ≤ 4Γ` in (1). Nor does (10)–(11) require `Γ ≤ 1` or absorb an extra power of `Γ` without justification. The smallness used for the scalar inverse induction is the available `ψ ≤ 1`, not a new random-scale assumption.

For a later prescribed loss `ε`, choose the source parameter `b` sufficiently small as a function of the already fixed `M,ε`, before eventual `N`. That is the ordinary fixed-moment order and does not require an event depending on a subsequently chosen failure exponent.

## 5. Minimal concrete first subtarget and Lean interface

The smallest new endpoint estimate can be stated with T1452's existing `hω`, `hδquarter`, `hMδ`, `hN`, and `hu`, taking `loss = b` and naming its positive-loss hypothesis `hb`, plus

```text
|S| + 1 ≤ M; j ∉ S; k ∉ S; j ≠ k;
a is an original block;
```

and should conclude **both**

\[
 W^{-1}\sum_{x\in I_a}
 |G^S_{xk}-G^{S+j}_{xk}|^2
 \le320N^{b+2\beta}\Gamma^2,
\]

\[
 W^{-1}\sum_{x\in I_a}
 |G^S_{kx}-G^{S+j}_{kx}|^2
 \le320N^{b+2\beta}\Gamma^2. \tag{12}
\]

The proof is fully determined by accepted inputs: (6), T1444's normalized endpoint squared norm `≤ 20 N^b Γ`, `|G_jk| ≤ ψ`, and `|G_jj⁻¹| ≤ 2` give `80 N^b Γ ψ²`; (1) gives (12). It includes `x=j`, `x=k`, and `x∈S`. It produces a new actual-model endpoint derivative on the unchanged event. The right side can also be weakened to `320 N^(5b/4) Γ²` using `2β ≤ b/4`.

For an efficient all-order successor, formalize (5) directly, using (12) as the low-order check and T1444 as the order-zero case. A concrete coordinate form avoids changing frozen `DiffBd`:

```text
iterDeltaFam l (fun U => gEnt ... x k U) S
```

inside the finite square sum, and the analogous row family. The current `iterDeltaFam`/`DiffBd` declarations are complex-scalar, so a vector/outer-product Leibniz estimate requires a new finite-sum lemma or a primed generalization. Merely writing `DiffBd` for this vector is a type mismatch. The real squared-loop family can similarly be handled by a real finite-difference lemma or its complex embedding with an explicit norm/absolute-value bridge.

Every endpoint theorem must quantify over base `S`, not only `S=∅`. Carry actual shifted bases, or use `diffBd_atom` with its existing base parameter and remaining budget. Do not replace `|S|+r≤M` by an all-minor hypothesis, or quietly strengthen it to a larger fixed budget because a proof failed to account for shifts.

An endpoint-only ticket should not claim full (L). The subsequent new arrow is (9) followed by (10). Conversely, a complete all-face ticket is mathematically dispatchable only with this explicit vector invariant and proof scope; it is not a one-line application of T1452.
