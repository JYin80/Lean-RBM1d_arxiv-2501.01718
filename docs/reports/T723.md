# T723 — Semicircle density measure

**Owned files:** `RBM1D/Defs/SemicircleDensityMeasure.lean` and this report. The root import file, task table, and unrelated in-flight files were not edited.

## Result

The new module defines `semicircleDensity x = sqrt (4 - x²) / (2π)` and `semicircleMeasure = volume.withDensity (ENNReal.ofReal ∘ semicircleDensity)`. Because `Real.sqrt` vanishes on nonpositive arguments, this is the paper's `ρ_sc(x) = (2π)⁻¹ sqrt((4-x²)₊)` immediately before (2.1).

The normalization is proved by an actual integral: `integral_sqrt_four_sub_sq` scales Mathlib's `integral_sqrt_one_sub_sq` to obtain `∫_{-2}^{2} sqrt(4-x²) dx = 2π`; `semicircleDensity_integral_Icc` then yields `1`. `semicircleMeasure_univ` transfers that real integral to the density measure, giving an `IsProbabilityMeasure` instance.

Further proved declarations: pointwise nonnegativity, evenness, continuity, positive density at `0`, vanishing outside `[-2,2]`, strict positivity inside `(-2,2)`, integrability, zero measure of the complement of `[-2,2]`, topological support contained in `[-2,2]`, zero mass at every singleton, positive mass on every interval `(a,b)` with `-2 ≤ a < b ≤ 2`, and invariance under `x ↦ -x`. The explicit nondegeneracy witness is `semicircleMeasure_nontrivial : 0 < semicircleMeasure (Ioo (-1) 1)`.
