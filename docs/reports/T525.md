## Fixed-size proof

`endpointLowMomentAt_of_family` combines the two accepted inputs directly.

1. T522's `jSnorm_endpoint_eq_familyMax` gives, for every sample,

   ```text
   jSnorm(endpoint N k) = R_v^(-4) + familyMax N k.
   ```

2. T521's `sameWeight_integrability` supplies

   ```text
   Integrable (fun omega =>
     weight tauPrime P N k omega * |familyMax N k omega|^(2*p)) (P d)
   ```

   for the actual low order `p` and the unchanged high-order weight.

3. The canonical weight satisfies `0 <= weight_P <= 1`, and `familyMax`
   is nonnegative because it is a nonempty finite supremum of absolute
   values.

4. T522's `momNormW_const_add_le` therefore gives the coefficient-one
   weighted Minkowski bound.  Composing with T521's
   `familyLowMomentAt` gives the displayed target without a measure switch,
   another family-cardinality factor, or an additional power of `N`, `W`,
   or time.
