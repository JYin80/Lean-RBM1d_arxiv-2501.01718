## Exponent check

The requested endpoint arithmetic itself is valid under the native `Dims`
bandwidth. From `R^30 ≤ S ≤ N`, one gets `R^(5/2) ≤ N^(1/12)`, and
`W ≥ N^(1/2+d.c)` then gives

```text
R^(5/2)/W ≤ N^(1/12)/N^(1/2+d.c) = N^(-(5/12+d.c)).
```

The separate `Cond272Reg` flow gain `N^(-c/12)` is unchanged. This matches
the dimension calculation in §6 of
`docs/reports/V6-T230A-original-target-audit.md`. The algebra is not the
obstruction.
