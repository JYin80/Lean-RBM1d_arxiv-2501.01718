## 2. The two distinct dynamic `J` caps

T405 distinguishes the loop maximum from the block Green-function maximum.
That distinction remains necessary here.


supplies the norm event through

```text

```

The cap includes the right endpoint `r=u_k`; the strict-prefix cutoff reaches
that endpoint through the compiled time-modulus theorem.

### Block maximum exported by T413

`APrimeSupportRunning.jG`.  On the same common event it gives



This block cap is available and same-event correct, but T422's quadratic term
uses `J_loop`, so substituting the block cap there would be a type-level and

## 4. Exact rows and powers

The first-cell scale identities and monotonicities used below are

```text
ell_0 = 1,
1 ≤ ell_r/ell_0 ≤ sqrt(x_r),
1 ≤ x_r ≤ R,
A ≤ A_r,
eta_r ≤ 1.
```

### Linear `eGpm` row

The T418 coefficient transforms as

```text
N^(nu/2) eta_r^(-1) (ell_r/ell_0)^3
  * N^(nu/2) R^(-2) x_r^(-2)

≤ N^nu eta_r^(-1) R^(-2) x_r^(-1/2).
```

This is precisely the leading T405 drift row.  T418 already bounds the whole
actual `eGpm` for all output distances, so no near/far indicator or additional
block-`J` row is needed in this first-cell specialization.

### Quadratic gluing row

The same-event loop cap gives

```text
J_loop(r)^2 ≤ C_loop^2 N^(4 delta) x_r^8.
```

Therefore the main quadratic coefficient becomes

```text
36 exp(1) J_loop(r)^2 eta_r^(-1) A_r^(-1)
  * Xi_N R^(-2) x_r^(-2)

≤ C N^nu eta_r^(-1) R^(-2)
      N^(4 delta) A^(-1) x_r^6.
```

This is exactly the T405 quadratic row

```text
N^(4 delta) A^(-1) x_r^6.
```

No power of `L`, `W`, `ell_r`, `eta_r`, `x_r`, or `R` is lost in this
conversion.

### The literal `W⁻⁶⁰` floor

Before transport, the retained floor is

```text
exp(1) J_loop(r)^2 W L W^(-60).
```

It transforms to

```text
C Xi_N R^(-2) N^(4 delta) x_r^6 W L W^(-60).
```

It is absorbed into the preceding quadratic row because

```text
(W L W^(-60)) * (eta_r A)
  ≤ (W L) A W^(-60)
  ≤ N^2 W^(-60)
  ≤ W^(-56)
  ≤ 1
```

eventually, using `W L≤N`, `A≤N`, `N≤W²`, `eta_r≤1`, and `W≥1`.  Hence

```text
W L W^(-60) ≤ eta_r^(-1) A^(-1).
```

The floor is retained until this comparison; it is not discarded by the
kernel convolution.

Combining all terms gives the proof-grade target

```text

  ≤ C N^nu eta_r^(-1) R^(-2)
      [x_r^(-1/2) + N^(4 delta) A^(-1) x_r^6]
```

on the literal T422 event and positive actual support, uniformly in active
`k≥1`, real `r∈[0,u_k]`, and the output coordinate `a`.

## 6. Boundary cases and nonvacuity

- **`r=0`, `k≥1`:** T422 and the loop-support theorem both use closed
  intervals.  `norm_Uker_flow` permits `r=0`, so the transported bound is
  valid directly.  Independently, `Gauss.driftF_zero_at_initial` shows that
  the actual raw drift is identically zero there.
- **`r=v`, `k≥1`:** all inputs use `r≤v`; equality is allowed.  The kernel
  reduces to its self action, and the same normalized bound remains valid.
- **`k=0`:** here `v=s=0`, while T422 intentionally assumes `k≥1`.  The
  correct branch uses `driftF_zero_at_initial`; hence `driftAt=0`, every time
  integral is over `[0,0]`, and T421 supplies the exact initial endpoint
  coordinate identity.  No positive-support premise is required.
- **`s=v`:** the drift integral vanishes.  For the first cell this is the
  preceding `k=0` branch.
- **Positive resident:** T422's `positiveRawDriftPlateau` supplies, on the
  same literal common event, an actual `k=2` sample with `u_2>0`, both the
  `delta` and `1/100` weights equal to one for every moment order, and the raw
  full-drift bound for every output.  Applying the deterministic transport
  above gives a nondegenerate resident of the moving-endpoint conclusion.

## 7. Noncircularity

The loop cap uses only the strict-prefix cutoff values, the fixed Gaussian
norm event, and the compiled time modulus.  Its extension to the current
right endpoint does not use a drift, QV, endpoint moment, or a sharp bound at
that endpoint.  T413's block cap uses the independent source/comparison
event.  T422 combines those sources with deterministic identities for the
actual drift.  Kernel transport is deterministic.

Consequently this implication does not invoke the desired `hfamily`, an
intermediate-cell `BoundsCore`, or the output of later Steps 3--5.  The
dependency direction is

```text
strict-prefix support + common source event
  -> running loop/block caps and raw actual drift
  -> deterministic U transport
  -> moving-endpoint driftAt bound.
```
