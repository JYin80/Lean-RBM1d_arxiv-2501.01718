# T1349 — Actual first-half all-charge loop decay

## Result

Added `RBM.Gauss.Lemma514FirstCellLKDecay` in
`RBM1D/Gauss/Lemma514FirstCellLKDecay.lean`. For the actual Gaussian model
`Gauss.Dims.exampleGrow`, energy `E = 0`, and the full interval `[0, 1/2]`, it proves the
raw-loop and `gloop − Kval` `Decay.LoopDecay` bounds at radius `ell_u N^τ` and error `N⁻ᴰ`.
For each fixed `m ≥ 1`, `τ > 0`, and `D > 0`, the one eventual size threshold works for every
sample in the existing event `APrimeFirstCellJGAllTime.good N` and every `u ∈ [0, 1/2]`.

The file also proves the literal consumer

```lean
SumZeroDyn.LKDecay (Gauss.sample Gauss.Dims.exampleGrow) 0
  (fun _ => 0) (fun _ => (1 / 2 : ℝ))
```

and gives measurability and eventual positive probability for that same event.

## Proof route

The raw loop uses `APrimeFirstCellCTDecay.Gsig_entry_decay_on_good`, which bounds both Bool
charges on the same actual event. With entry radius
`R = ell_u N^τ / (2m)`, `Decay.loopDecay_gloop` gives radius `2mR = ell_u N^τ`. On this time
interval, `Im (zt 0 u) = 1-u ≥ 1/2`, while `ell_u ≥ 1`, so the loop error is at most
`4 · 2^m · exp(-α N^τ/(2m))`.

The primitive loop uses `Decay.loopDecay_Kgen` with the fixed gap `δ = 1/2`; the gap hypothesis
follows from `u ≤ 1/2` and `Decay.one_sub_le_norm_one_sub`. Its error is bounded by
`cKdecay(m,1/2) · exp(-cor35Rate(1/2) N^τ)`. Both exponential errors are absorbed into
`N^-(D+1)` with constants fixed in `m,τ,D`. `Decay.LoopDecay.sub` adds the bounds, and
`SumZeroDyn.eventually_two_mul_rpow_le` absorbs their sum into `N^-D`. All event, Hermitian,
charge, spectral-parameter, and gap hypotheses are discharged in the proof; none is added as an
input.

`DecayBridge.lkDecay_of_highProb` converts the pointwise pair into the literal `LKDecay`
consumer using `APrimeFirstCellJGActual.highProb_good`. Event measurability comes from
`APrimeFirstCellJGAllTime.measurableSet_good`. For eventual positivity, the `D=1` high-probability
bound makes the complement measure strictly less than one for all sufficiently large `N`; the
probability-measure identity for a measurable event and its complement then rules out zero event
measure.

## Joint nondegenerate witness

`eventually_joint_nonzero_far_witness` retains
`APrimeFirstCellCTDecay.diagonalWitness`, its membership in the same good event, and its nonzero
`Xmat`. At `u = 1/4`, `m = 2`, `τ = 1/16`, and `D = 1`, choose the blocks
`[⌊L/2⌋, 0]`. Their cyclic distance is exactly `⌊L/2⌋`. For sufficiently large `L`, the
fourth-root bound `N ≤ (L+1)^4` gives `N^(1/16) ≤ L/8`; also `ell_(1/4) ≤ 2`. Hence the required
radius is at most `L/4 ≤ ⌊L/2⌋`. The theorem includes distinctness of the blocks and strict
positivity of both radius and error, together with both loop-decay conclusions. This verifies that
the spatial-decay instance has a nonempty far region on an actual nonzero sample.

## Paper scope

The paper anchor is Lemma 5.9, especially (5.75), which states the loop-decay pair. This Lean
result formalizes an actual Gaussian specialization with `E = 0` and the bounded interval
`[0, 1/2]`. It does not formalize the full generality of Lemma 5.9, a window whose right endpoint
approaches `1`, or the T230A-prime closure. The resulting first-half decay is available for
T1347's `hdec` input and the `FastDecayFlow` Psum estimate.
