## Statements proved

For arbitrary `d : Dims`, size `N`, and arbitrary family `C` of `Fin (d.W N)` complex matrices indexed by physical blocks `ZMod (d.L N)`, `blockDiagonal d N C` places `C a` in block `a` and zeros between blocks. The module proves:

1. If each `C a` is Hermitian, the full matrix is Hermitian.
2. The full matrix satisfies `HermitianBandSupported` with no Hermiticity assumption.
3. Under block Hermiticity, `Xmat d N (omegaOfHermitian d N (blockDiagonal d N C)) = blockDiagonal d N C` exactly at every entry.
4. The encoded full-product sample is zero at every coordinate whose actual `gvar` is zero, including unused and other-size coordinates.

The proofs use the existing `Generator.lean` encoder and its exact readback and zero-variance lemmas. No variance rescaling occurs.
