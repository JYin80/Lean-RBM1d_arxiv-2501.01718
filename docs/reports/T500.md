## Exact statement and quantifiers

Set `d = Gauss.Dims.exampleGrow`, `delta = 1/2000`, and let

\[
v_{N,k}=\texttt{APrimeFirstCellMinkowskiExact.endpoint}\ N\ k,
\qquad R_{N,k}=\frac{\eta^{(0)}_0}{\eta^{(0)}_{v_{N,k}}}.
\]

The weight and random initial quantity are literally the definitions from
T494:


The latter is

```lean

  N (APrimeFirstCellMinkowskiExact.endpoint N k) a
```

`eventually_initialBoundAt` proves, for every `τ' > 0` and each fixed
`p : ℕ` with `1 ≤ p`,

\[
\forall^{\mathrm{ev}}N\;\forall k\leq
 \operatorname{cutNetTop}(0,\operatorname{firstCellT}(\tau'),\mathrm{mesh},N)
 \;\forall a,
\quad
\operatorname{momNormW}(P_d,w_{\tau',p,N,k},p,I_{N,k,a})
\leq
\frac{\operatorname{initTerm}(N^{\delta/8},R_{N,k},
 \operatorname{slotXi}'(N^{\delta/8}))}{R_{N,k}^{4}}.
\]

There is no lower restriction `1 ≤ k`: the same statement includes `k = 0`.
The threshold in `N` is chosen after `τ'` and `p`, and before `k` and `a`.
It can depend on the fixed moment order. It does not depend on the moving
mesh index or output coordinate.

`initialBudget_eq` proves, for `N ≥ 1` and an active index,

\[
\frac{\operatorname{initTerm}(N^{\delta/8},R_{N,k},
 \operatorname{slotXi}'(N^{\delta/8}))}{R_{N,k}^{4}}
=N^{5\delta/32}R_{N,k}^{-2}.
\]

`eventually_initial_simplified` combines these two facts with the same
quantifier order. For the fixed value of `delta`, `5 delta / 32 = 1/12800`.

`N^(1/2 + 1/8) ≤ W_N`, and eventually `2 ≤ N^(1/8)`, hence

\[
N^{1/2}\leq W_N/2\leq
(\mathrm{band}\ d).\mathrm{scale}(0,N,\operatorname{firstCellT}(\tau',N)).
\]

Eventually `2^30 ≤ N^(1/2)`. Since `1-firstCellT ≥ 1/2`, inversion yields
the literal `Cond272` inequality. The separate `N^(1/2)` lower bound gives
the second field of `Cond272Reg`. This applies to every positive `τ'`, so
it can be instantiated at the parameter already selected by T494.

The decisive order of operations is:

1. Fix `τ' > 0` and `p ≥ 1`.
2. Apply T488 with the single function `W N va ω = 1`.

for each `k` and then attempt to interchange `∀ k` with `∀ᶠ N`.
