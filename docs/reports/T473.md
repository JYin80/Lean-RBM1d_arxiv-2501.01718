# T473 — general moving-window endpoint floor

## Result

Implemented in `RBM1D/Gauss/APrimeGeneralMovingWindowFloor.lean` for
`d = Gauss.Dims.exampleGrow` and the original `Cond272Reg`.

For fixed bulk energy `|E| < 2`, fixed `c > 0`, and deterministic sequences
`0 ≤ s_N ≤ t_N < 1`, the theorem `eventually_endpoint_floor` proves

```lean
(N : ℝ)⁻¹ ≤ 1 - t N ∧ 1 - t N ≤ 1 - s N
```

eventually in `N`.  No fixed terminal bound `t₀ < 1` is used.

The corollary `eventually_abs_rhoS_sub_le` proves, on every moving interval,

```lean
∀ v ∈ Icc (s N) (t N), ∀ w ∈ Icc (s N) (t N),
  |rhoS s N v - rhoS s N w| ≤ 4 * N * |v - w|.
```

Thus the intended exact polynomial constant `4N` is supported by the public
API; no weakening was needed.

## Proof

`Cond272Reg` supplies `N^c ≤ B.scale E N (t N)`.  The existing deterministic
scale theorem `Gauss.rpow_neg_one_le_one_sub_of_scale_ge` uses
`W_N L_N ≤ N`, `ell_{t_N} ≤ L_N`, and `Im m(E) ≤ 1` to give
`N⁻¹ ≤ 1-t_N`.  Monotonicity of the window gives the second endpoint
inequality.

The existing fourth-power estimate
`APrimeSlotFields.abs_rhoS_sub_le`, instantiated with terminal time `t_N`,
gives Lipschitz factor `4(1-t_N)⁻¹`.  Inverting the positive endpoint floor
gives `(1-t_N)⁻¹ ≤ N`.

## Nondegenerate witness

`positive_length_grid_window_witness` uses a single application of
`cond272Reg_grid_step_domain` at `E=0`, `κ=1`, `τ=1/2`, and terminal sequence
`t_N=1/2`.  Its first grid cell supplies all deterministic window conditions
and `Cond272Reg`.  `eventually_gridT_zero_lt_gridT_one` proves that this same
cell has positive length eventually.  No separately chosen witnesses are
identified.

## Scope

The module does not claim the full loop modulus, `WeightedMoment`, `hfamily`,
`APrimeSlot'`, next-cell `BoundsCore`, or any random-profile estimate.
