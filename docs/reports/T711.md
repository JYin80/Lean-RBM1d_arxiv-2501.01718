# T711 — basic uniform-permutation prefix filtration

## Files and scope

Added only `RBM1D/Gauss/PermutationPrefixFiltrationCore.lean` and this report. The module defines `PermΩ W = Equiv.Perm (Fin W)` with the full measurable space, the uniform probability measure on all permutations, coordinate cylinders and their generated prefix sigma-algebras, the natural-number prefix filtration, and the finite cell of permutations agreeing with an actual permutation on the first `k` coordinates.

No conditional distribution, conditional expectation, Doob increment, Azuma/P2 estimate, first-cell event, shared Gaussian event, `hfamily`, A-prime, or paper closure is claimed. No root import was added, per the assigned file scope.

## Statements established

* `prefixSigma_mono`: if `k ≤ l`, then `prefixSigma W k ≤ prefixSigma W l`, proved with `MeasurableSpace.generateFrom_mono`.
* `prefixFiltration`: the sigma-algebras form a filtration indexed by `ℕ`, with each bounded by the full measurable space.
* `uniformPerm` has an `IsProbabilityMeasure` instance.
* `mem_prefixCell` and `prefixCell_card_pos`: every actual prefix cell contains its source permutation, and hence has positive finite cardinality, for all `W`, `k`, and `π`.
* `prefixCell_eq_univ_of_zero`: at `k=0`, the cell is the full permutation space.
* `prefixCell_eq_singleton_of_width_le`: for `W ≤ k`, the cell is `{π}`. This includes `W=0`, whose permutation type is a singleton, and all `k ≥ W`.
* `prefixCell_two_support_witness`: for `W=2,k=0`, the identity and swap are distinct members of the same cell. Thus this finite support witness is nonconstant.

No arbitrary prescribed, potentially inconsistent prefix is asserted to have a nonempty cell.
