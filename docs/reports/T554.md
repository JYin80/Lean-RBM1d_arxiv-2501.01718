# T554 — Variable-δ coordinate-budget exponent absorption

Implemented the pure real-power arithmetic in
`RBM1D/Gauss/APrimeFirstCellDeltaCoordinateBudgetArithmetic.lean`.

The exact deterministic Minkowski sum uses

* the T547 initial term `N^(5δ/32) R⁻²`;
* the T546 drift term `absorbedRate + N⁻ᵝ`;
* `2 * budgetConstant P * N^(α-2δ) R⁻²`, namely the outer Minkowski factor
  applied once to T544's `literalBfull` integral budget;
* the T545 QV square-root term
  `√(2P-1) (384√3 N^(α/2) R⁻² + √v N^(-β/2))`.

Thus `literalBfull` is not confused with `BcrossActual`, and no additional
factor `2P` is introduced.  The theorem `literalCrossIntegralBudget_eq_two_literal`
records this normalization against T544's public `crossScale` and
`budgetConstant`.

With `α=δ/16` and `β=δ`, the exported gaps are

* `δ/5 - 5δ/32 = 7δ/160`;
* `δ/5 - 2α = 3δ/40`;
* `δ/5 - (α-2δ) = 171δ/80`;
* `δ/5 - α/2 = 27δ/160`;
* `δ/5 - (-β) = 6δ/5`;
* `δ/5 - (-β/2) = 7δ/10`.

The proof first bounds every contribution by a fixed `P`-dependent multiple
of `N^(5δ/32) R⁻²`.  The assumptions `1≤R≤2` give `1≤4R⁻²`, which absorbs the
two terms without an `R⁻²` factor.  The strict initial gap then absorbs the
fixed constant and proves, uniformly for `1≤R≤2` and `0≤v≤1/2`,

`totalBudget δ P N R v ≤ N^(δ/5) R⁻²`

eventually in `N`.

For the later stochastic assembly, `qvRate` must be changed to the evolved
(endpoint-time) version before this numerical endpoint can be applied; the
static initial-time `qvRate` is not the required QV input.
