## Mathematical and satisfiability checks

The existing signature is polymorphic in `Ω`, `Band Ω`, every `E : ℝ`, `N : ℕ`, `u : ℝ`,
and every `m : ℕ`, **including `m = 0`**. It accepts one
`M : Matrix (B.Idx N) (B.Idx N) ℂ`, one `σ : Fin m -> Bool`, and
`c : LoopArg (B.L N) (m+m)`. The body passes exactly that `M`, `σ`, and `c` to `eeArg`;
`eeArg` splits `c` by `Fin.castAdd m` and `Fin.natAdd m`, applies the *same* `σ` on both
halves, and calls the original `Gauss.eeTens`. The `Fin.append` laws and zero case were
already checked in T675/T679. No proposed move changes the `2m+2` glued-loop convention,
the matrix, the charges, `N`, `W N`, `L N`, or the factor `1-u` in `zt`.

The project PDF's Definition 5.4, (5.22)–(5.23), defines the sum over glued
`(2m+2)`-loops and its two label strings. Equation (5.42) is a **later** normalized,
propagated estimate for the two-charge term; neither formula supplies a QV theorem by
merely relocating `eeFun`.

There is no new hypothesis in either definition move, so there is no new consistency
obligation. Domain feasibility is concrete: take `B = Gauss.band
Gauss.Dims.exampleGrow` (`Gauss/DimsExample.lean:222`), `E = 0`, and `u = 0` or
`u = 1/2`. The model has positive `W N` and `L N >= 3` for every `N`, with both growing;
`|E| < 2`, `0 <= u < 1`, and `zt 0 u = (1-u)i`, so the spectral imaginary part is positive
at both times. These two times form a nontrivial window; no sample point, event,
shared-event condition, first-cell restriction, or additional `N/W/time` power is
introduced by the extraction.
