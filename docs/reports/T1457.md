## Formal statement and assumptions

The matrix is Hermitian on the actual block/offset index `ZMod L × Fin W`, with `3 ≤ L`,
`[NeZero L]`, and `[NeZero W]`, so `N=L W>0`. For fixed `κ>0`, `|E|≤2-κ`, and
`|Re z-E|≤κ/4`, the proof establishes, for every site `y` and either resolvent sign,

```text
Q_y ≤ (D/N) P₁ + δ⁻¹,
P₁ = ∑β ‖(λβ-z)⁻¹‖,   δ=κ/4,
```

assuming only `|uβ(y)|²≤D/N` for eigenvalues `λβ∈J`. Completeness of the eigenbasis controls the
tail mass; no all-spectrum eigenvector estimate is assumed. The proof handles both `G` and `G*`
with `Im z>0` by verifying that both pole moduli equal `|λβ-z|⁻¹`.

The relative form defines
`R_z²=N⁻¹∑β|λβ-z|²` from this same matrix and proves
`P₁/N≥1/R_z`, hence

```text
Q_y ≤ (D + R_z/δ) P₁/N.
```

It derives the reciprocal bound from finite-sum Titu/Cauchy–Schwarz inequalities. Since `Im z>0`
and `N>0`, the proof establishes `R_z>0` before division; the `R_z=0` case cannot occur.

Each composition theorem allows independent Boolean signs `σ₁,σ₂`, so all four combinations of
`G` and `G*` are covered. It retains the full T1397 alpha factor and inserts the new beta bound;
it does not replace that factor by an unrestricted maximum or claim the paper's stochastic
domination.

The T1456 reconciliation records a same-sample band-supported path with an isolated site. On that
finite matrix, the bulk eigenvectors have site masses at most `2/N`, a nonempty bulk and a
nonempty outside-`J` tail coexist, and the second spectral moment is bounded at positive `Im z`.
Thus the premises used here are nonvacuous on one actual block/offset matrix (with `D=2`), while
the tail remains present. T1456 also records that positive-variance Gaussian coordinates contain
neighborhoods of this witness. This checks support-level satisfiability only; it is not a
probability or OU-event result.

The bulk-mass bound and the second-moment bound remain explicit conditional inputs on a common
matrix/sample. A later stochastic lift must prove them on the same event with the paper's fixed
parameter-before-eventually-`N` order and verify the loss against the (2.29)/(2.30) budget. The
weak OU estimate currently recorded in the reconciliation does not establish loss-free (2.31),
and this module does not prove (2.29), (2.30), or (2.32)–(2.33).
