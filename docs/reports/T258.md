## 乙：否定结论落到真实模型——**不是一行**

T252 的 `hsep_exampleGrow` 活在 `Gauss.band d : Band (Gauss.Ω d)` 上，而反驳要的是 `Band ℝ`。桥：`bandR (d : Gauss.Dims) : Band ℝ`（同样的 `W`、`L`、`c`、`dim`、`bandwidth`，律取 `gaussianReal 0 1`），于是 `hsep_bandGrow := hsep_exampleGrow_quarter` **`rfl` 通过**。

结果：`not_entryModulusEv_bandGrow`、`not_cutHypEv_bandGrow`、`not_entryModulusEvKOn_one_half_bandGrow` —— **只剩 `2 ≤ D` 一个前提，没有 `hgap`、没有 `hsep`、没有自由常数。T249 的判决现在在一个具体模型上无条件成立。**

## ⭐⭐ 精确回答：反驳对哪一组 `(Kmod, γ)` 成立

* **不加事件、窗口 `[0, t_N]`：对每个 `Kmod : ℝ` 与每个 `γ > 0` 都成立**（`not_entryModulusEvK_swapSample_of_far`）。
  机制：`not_modulusEv_zero_start` **先定 `N`**，然后才挑 `v = min(t_N, (c/(N^{Kmod}+1))^{1/γ})`；而 `gap_lower` 的跳跃 `c` **不随 `v` 缩小**，所以加大 `Kmod` 只是**把反驳时刻挪走**。
  ⭐ **参数化本身救不了这个字段。**（`γ ≤ 0` 被构造排除——右端会变成绝对界 `N^{Kmod}`。）
* **限制到 `{|ω| ≤ N}` 后：反驳范围恰好是 `Kmod ≤ 2γ`**（`not_entryModulusEvKOn_swapSample_of_far`，要 `W_N` 发散）。
  机制（正是协调者转的第 3 条）：`exists_jSfarSm_ge_swapSample'` 改成 `∃ ω, |ω| ≤ 1/√v ∧ …` 之后，`v = N^{−2}` 处的见证 `ω = N` **落在事件里**；而 `gap_lower_mul_W`（**把 T249 丢掉的因子 `W` 捡回来**）使跳跃 `≍ W_N → ∞`，那里模的预算只有 `N^{Kmod−2γ} ≤ 1`。
* **结论**：**D17 的 `(Kmod ≥ D−1, γ = 1/2)` 落在 `Kmod ≤ 2γ` 之外，未被反驳**（`d17_pair_outside_event_refutation`）；**而硬编码的 `(1, 1/2)` 恰好取等号，加不加事件都被反驳**。
  ⭐ **所以事件限制本身不是修法——指数也必须跟着长。两者缺一不可。**
* 结构形式：`not_cutHypEvOn_of_jump` —— **任何自身字段满足 `H.Kmod ≤ 2·H.γ` 的 `CutHypEvOn` 都不可满足。**
