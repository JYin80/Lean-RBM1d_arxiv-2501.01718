## 1. Exact finite statement and proof route

Let `W≥2`, `T≥1`, `x : Fin T → Fin W → ℂ`, `‖x t j‖≤2`, and `r>0`. For each `q : Fin W` other than zero use the existing normalized convention

```text
χ_q(j) = permutationFourierCharacter W q j
F_(t,q)(π) = permutationFourierSum W (x t) (χ_q) π
           = (∑ j, χ_q(j) * x t (π j)) / W.
q0 : Fin W := ⟨0, by omega⟩,
I = (Finset.univ : Finset (Fin T)) ×ˢ
    ((Finset.univ : Finset (Fin W)).erase q0),
K = I.card = T * (W - 1).
```

Assume `4 * (K:ℝ) * Real.exp (-(W:ℝ)*r^2/256) < 1`. The proposed conclusion is

```text
∃ π : PermΩ W, ∀ t : Fin T, ∀ q : Fin W,
  q ≠ q0 → ‖F_(t,q)(π)‖ < r.
```

The one-block route is:

1. For `q≠q0`, `permutationFourierCharacter_sum_zero` gives `∑χ_q=0`; `permutationFourierCharacter_mean_zero` (or the generic `permutationFourierSum_mean_zero`) confirms exact finite counting mean zero. The character norm bound `‖χ_q(j)‖=1` must be supplied as a small helper from the purely imaginary exponential. Do not silently assume it is already exported by `PermutationFourierCharacter.lean`. The explicit `q0` term matches that theorem's actual `⟨0, by omega⟩` signature and avoids relying on a `Zero (Fin W)` instance under a merely propositional width hypothesis.
2. After T901/T902 acceptance, invoke `uniformPerm_permutationFourierSum_zeroCharacter_complex_tail` with `x t`, `χ_q`, and `r`. Its bad event is **weak**, `B_(t,q)={π | r≤‖F_(t,q)(π)‖}`, and its measure is `(uniformPerm W).real B_(t,q) ≤ 4 exp(-Wr²/256)`. This is the precise complement of the desired **strict** inequality `‖F‖<r`; using a theorem for `{r<‖F‖}` would leave the equality boundary uncovered.
3. Let `B=⋃ i∈I, B_i`. The installed `measureReal_biUnion_finset_le` gives `μ.real B≤∑i∈I μ.real B_i≤4 K exp(-Wr²/256)<1`. `Finset.card_product`, `Finset.card_erase_of_mem`, and `Fintype.card_fin` give `K=T(W-1)`; `W≥2,T≥1` give `K>0`. Every event is measurable because `PermΩ W` has the top, discrete `MeasurableSpace`.
4. `uniformPerm_isProbabilityMeasure` and Mathlib's `probReal_univ` give `μ.real univ=1`. If no good permutation existed, each permutation would belong to at least one `B_i`, so `univ⊆B` and `1≤μ.real B<1`, contradiction. Equivalently, the complement has positive real measure, and `nonempty_of_measureReal_ne_zero` supplies a point. **Positive singleton mass is an alternative, not a missing hypothesis**: `uniformPerm_singleton_pos` exists privately in `PermutationPrefixCellCondExp.lean`, and its proof unfolds `uniformPerm`, `uniformOn_univ`, and `Measure.count_singleton`. The contradiction with probability one avoids exposing that private lemma.

The finite family may instead be an arbitrary `Finset I` with `K=card`; then the theorem should explicitly demand a nonempty family for a meaningful witness. An empty family has a tautological existence conclusion, while `W≥2,T≥1` makes the concrete time/mode product nonempty. Keep the real cast `(K:ℝ)` explicit in the threshold.

## 3. Nondegenerate finite satisfiability witness

Take `W=8192`, `T=1`, `r=1`, and, with `χ=χ_1`, set `x 0 j=2·conj(χ(j))`. Every `x 0 j` has norm `2`; the table is nonconstant because `χ_1` is a nontrivial character. There are `K=8191` constraints and

```text
4K exp(-Wr²/256) = 4·8191·exp(-32) < 1.
```

The displayed strict inequality follows, for example, from the first five nonnegative terms of the exponential series:
`exp(32) ≥ 1+32+32²/2+32³/6+32⁴/24 > 4·8191`.
At the identity permutation, `F_(0,1)=2`, so the bad event is **nonempty** at `r=1`; this witness is stronger than choosing an enormous `r` for which every permutation is automatically good. It is an explicit nonconstant `W≥3,T≥1` model of all finite assumptions. A Lean witness can prove unit character modulus and `χ·conj χ=1` using the complex exponential facts, and use a finite exponential-series lower bound. It need not enumerate 8192! permutations.
