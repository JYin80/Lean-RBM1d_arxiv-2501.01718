## Literal `Cond272` and the corrected envelope

For eventual `N`, (2.72) gives

```text
A_t^(-1) <= ((1-t_N)/(1-s_N))^30 <= 1,
```

because `s_N <= t_N < 1`.  Since `A_t>0`, this implies `A_t>=1`.  Also

```text
A_t = W_N ell_t eta_t <= W_N L_N eta_t <= N eta_t.
```

Thus `eta_t>=N^(-1)`.  Since `eta_u=(1-u) Im(m_E)` decreases in `u`, every
`u<=t_N` satisfies `eta_u>=eta_t>=N^(-1)`.  This is the clean scratch theorem above.  The
existing downstream theorem `Gauss.eventually_rpow_neg_two_le_etaT_window` is correct but
strictly weaker.

At two charges, `Gauss.norm_eeFun_herm_le` simplifies to

```text
‖eeFun‖ <= 2 L_N W_N^(-4) eta_u^(-6).
```

Using `L_N<=N`, `W_N>=1`, and `eta_u^(-1)<=N` gives

```text

```

Hence `Env_N=N^8`, `Kenv=8` is the clean integer choice.  If one deliberately uses only the
currently packaged `eta_u^(-1)<=N^2`, one instead obtains `2N^13<=N^14`, explaining T662's
safe but non-sharp `14`.
