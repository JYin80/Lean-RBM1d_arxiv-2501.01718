# T1131 — actual widened low-p moment at k = 1

## Verdict: PASS

The mathematical preflight found an exact one-index specialization.  For each
fixed `δ > 0` and positive target order `p`, T1119 supplies an order `q ≥ p`,
then a positive constant, then an eventual bound at the same active `k = 1`.
At each sufficiently large `N`, T999's `low_integral_of_high_integral` applies
on the same probability space with the same observable and cutoff base:

```text
χ_N(ω) = baseCutoff(canonicalR, 1, jSnorm, δ, N, 1)(ω)
Y_N(ω) = cutTrunc(N^(2δ), jSnorm(... cutNetPt(..., 1) ...))
```

By `widenedW_eq_baseCutoff_pow`, the literal order-`m` integrand is
`χ_N^(2m) |Y_N|^(2m)` for both `m=p` and `m=q`.  The base cutoff is
nonnegative, and the required integrability follows from the same deterministic
truncation envelope used by T999.  Thus Lyapunov gives

```text
∫ widenedW(p) |Y_N|^(2p)
≤ (∫ widenedW(q) |Y_N|^(2q))^(p/q)
≤ Cq^(p/q) N^(δp/2).
```

The last exponent is exactly `δp/2`; the constant `Cq^(p/q)` is chosen before
the eventual threshold in `N`.  The additional T1119 threshold condition
`32 ≤ 3δq` is retained by that producer and is not needed again in the
one-index Lyapunov step.

For `p = 0`, the actual piecewise widened weight at order zero is identically
one, the truncated observable to power zero is one, and the Gaussian band is
a probability measure.  The integral is exactly one, with constant `C=1` and
the exponent `δp/2=0`.
