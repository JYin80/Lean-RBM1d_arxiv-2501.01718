## Pointwise endpoint identity

For every `N`, index `k`, output
`a : LoopArg (Dims.exampleGrow.L N) 2`, and sample `omega`, the theorem
`Y_endpoint_eq_coordAt_norm` proves

```text
Y N k a (endpoint N k) omega
  = ‖APrimeDriftTimeFamily.coordAt d 0 60 N Step2.sigPM a 0
      (endpoint N k) (endpoint N k)
      (Hflow d N (endpoint N k) omega)‖.
```

This is definitional: T509's `Y` is `APrimeDuhamelModel.flowY` applied to
exactly this `coordAt`, and `flowY` evaluates its coordinate at
`Hflow d N r omega`.

## Finite maximum and normalized bootstrap identity

`endpointCoordMax_eq_sup_Y` proves, without an activity assumption,

```text
APrimeFirstCellEndpointCoord.endpointCoordMax d N (endpoint N k) omega
  = Finset.univ.sup' Finset.univ_nonempty
      (fun a => Y N k a (endpoint N k) omega).
```

For `tauPrime > 0` and every active index

```text
k ≤ cutNetTop (fun _ => 0) (firstCellT tauPrime)
      APrimeSmoothTransition.transitionMesh N,
```

including `k = 0`, `jSnorm_endpoint_eq_sup_Y` composes this equality with
T425's accepted `firstCell_endpoint_identity` and proves

```text
Step2Moment.jSnorm (sample d) 0 60 (fun _ => 0) N v omega
  = 1 / Step2Moment.ratR 0 (fun _ => 0) N v ^ 4
      + Finset.univ.sup' Finset.univ_nonempty
          (fun a => Y N k a v omega),
```

where `v = endpoint N k`.  The first term is the literal Lean form of
`R_v^{-4}` already used by T425.  The imported endpoint theorem establishes
`0 ≤ v ≤ firstCellT tauPrime N ≤ 1/2 < 1`; no new size, bandwidth, time, or
stochastic hypothesis is introduced.

`active_endpoint_observable` packages all three identities under the same
active-index quantifier and keeps the zero boundary index in scope.
