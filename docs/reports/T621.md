# T621 — same-window producer and nondegeneracy preflight for T616's `hEE`

## Verdict

### Independent-audit correction (supersedes the dispatch recommendation below)

The conditional mathematical chain and exponent ledger pass, but the current Lean module graph
is not pre-Step-3 clean.  In particular, `LKDecayQuant`, `Step2PP`, `GoodSetFlow`,
`LDENetClose`, and `EEBridge` transitively reach Step45, Step3, or later packages; the suggested
`Thm221Bare` import is also downstream.  Thus §7 is only a theorem-level pre-(2.77) DAG, and
§8's flexible adapter is **not dispatchable** from the listed modules.  T626 must first extract
the floored flow inputs, good-flow/LDE/decay interfaces, basic scale tools, the necessary
`EEBridge` core, and the pure Step-1 `xiL_6` producer into genuinely upstream modules.

T621 also found no simultaneous same-window `LocalLawFlow ∧ AprioriDecayFlow` witness.  Until
both that witness and the upstream extraction exist, no `hEE` adapter or `XiLKTwoCutQV` theorem
may be dispatched.

The conditional producer chain is type-correct and preserves exactly the source profile required
by T616:

```text
highProb_xiLowEvent (n = 0, C = 18)
  + highProb_eeDecay_of_inputs' (n = 0)
      [same-window FlowGoodEv + LDEFlowDom' + (2.76)]
  -> EEBridge.stochDom_norm_eeField (n = 0)
  -> ||eeField|| \prec A_u^(-4) eta_u^(-1) xiL_6.
```

The primary verdict is nevertheless **incomplete, with the smallest missing implication at the
floored good-flow adapter**.  The repository does not currently contain a compiled simultaneous
nondegenerate Gaussian witness for every premise of this chain on T608's target moving window.
The deterministic window, `Cond272Reg`, `BoundsCore`, eventual positive duration, and a genuine
`(+,+)` coordinate are compiled together.  The Gaussian floored large-deviation input and the
`xiL_6` lower event are also producible on that same window.  What is not compiled is the literal
good-flow premise of `highProb_eeDecay_of_inputs'`:

```text
forall a : Real, 0 < a ->
  HighProb P (FlowGoodEv X E s t (fun N => N^(-a))).
```

The existing constructor immediately specializes this premise at `a = 1`; its numerical bundle
hard-codes `gdel_N = N^-1` and `Phi_N = N`.  `highProb_goodSetFlow_of_localLaw` only produces a
threshold `delta_N` after a margin `N^tau Psi_N <= delta_N`; no existing theorem obtains the
above arbitrary-threshold statement, or even its hard-coded `N^-1` specialization, from the
same-window Step-2 local law on the target grid.  The target-grid witness also does not contain a
same-parameter compiled `LocalLawFlow`/`AprioriDecayFlow`; outside the excluded first-cell/A-prime
packages, the latter remains only the named pre-Step-3 input (2.76).

Therefore no `XiLKTwoCutQV` theorem, and not even a self-contained `hEE` adapter satisfying the
project's nondegeneracy rule, should be implemented next.  The selected smaller ticket is the
flexible floored `FlowInputs'` producer described in §8.  It must replace the hard-coded
`(gdel,Phi) = (N^-1,N)` by compatible positive exponents and connect one same-window Step-2 local
law event to one same-window (2.76) event.  It must stop before `hEE` and before any QV moment row.

## 1. Claim card

At `n = 0`, with

```text
B = band d, X = sample d, P = B.P,
A_u = B.scale E N u = W_N ell_u eta_u,
U_N = TimeIcc s t N x ((Fin 2 -> Bool) x LoopArg (d.L N) 4),
```

the audited target is

```lean
StochDom B.P
  (fun N (p : U_N) omega =>
    ‖EEBridge.eeField X E 0 N (p.1 : Real) omega p.2.1 p.2.2‖)
  (fun N p omega =>
    (B.scale E N (p.1 : Real))⁻¹ ^ 4 *
    (etaT E (p.1 : Real))⁻¹ *
    X.xiL E N (p.1 : Real) omega 6)
```

`StochDom` literally means

```text
forall tau > 0, forall D > 0, eventually N,
  P {omega | exists p : U_N,
      N^tau * control(N,p,omega) < observable(N,p,omega)}
    <= N^(-D).
```

The statement is uniform over the closed time subtype `TimeIcc s t N`, both charge bits, and
all four tensor labels.  In particular it contains the constant-true charge `(+,+)` and both
time endpoints.  It is under one Gaussian measure and one sample; there is no independent copy.

## 3. Exact producer chain at `n = 0`

```lean
(hst : forall N, s N <= t N)
```

and conclusion

```text
HighProb (band d).P
  (EEBridge.xiLowEvent (sample d) E s t n (6*(n+3))).
```

At `n = 0`, the exponent is `C = 18` and the event is

```text
forall u : TimeIcc s t N,
```

This theorem already works at `s_N = 0`; its code assumes `0 <= s_N`, not `0 < s_N`.

### 3.2 The floored loop-decay event

The only admissible decay producer is
`RBM.LKDecayQuant.highProb_eeDecay_of_inputs'`.  Its literal inputs are

```lean
(hE : |E| < 2)
(hs0 : forall N, 0 <= s N)
(ht1 : forall N, t N < 1)
(hOmega : forall a : Real, 0 < a ->
  HighProb B.P
    (FlowGoodEv X E s t (fun N => (N : Real)^(-a))))
(hlde : LDEFlowDom' X E s t)
(hdecay : forall D : Real, 0 < D ->
  StochDom B.P
    (fun N (p : TimeIcc s t N x (ZMod (B.L N) x ZMod (B.L N))) omega =>
      X.lkErr E N p.1 omega (pmLoop p.2.1 p.2.2))
    (fun N p _ =>
      (etaT E (s N) / etaT E p.1)^4 *
      (B.scale E N p.1)⁻¹^2 *
      B.decayProf N p.1 D p.2.1 p.2.2))
(n : Nat).
```

Its conclusion is

```text
forall tau > 0, forall D > 0,
  HighProb B.P
    (GLoopDecayEvent X E s t (2*(n+2)+2) tau D).
```

At `n = 0`, the loop length is exactly `6`.  `GLoopDecayEvent ... 6 tau D` is definitionally
the `EEBridge.eeDecayEvent ... 0 tau D` required by `stochDom_norm_eeField`.

The internal quantifier and exponent order is important.  For each requested `tau > 0` and
`D > 0`, `highProb_loopDecay_pair'` uses `FlowInputs'` at

```text
m = 6, D' = D + 2*m + 1 = D + 13.
```

The current `flowInputs'_of_highProb` then fixes

```text
gdel_N = N^-1,
Phi_N  = N,
eps_N  = N^(-2*(D'+2)) = N^(-2*(D+15)).
```

Thus it calls:

```text
hOmega at a = 1,
LDEFlowDom' at b = 1 and Bex = 2*(D+15),
FlowDec at radius ell_u*N^(tau/2) and error exponent c = 2*(D+15).
```

`highProb_flowDec_of_aprioriDecay` in turn specializes the literal (2.76) input at

```text
D_276 = 30 + 2*c = 4*D + 90.
```

All choices occur after the requested decay exponent.  There is no illegal interchange of
`D`, `tau`, or `N`, and no event parameter survives in the final stochastic domination.

### 3.3 The floored LDE input

`LDEFlowDom' X E s t` literally means

```text
forall Bex : Real, 0 <= Bex ->
  StochDom P ldeRowLHS (ldeRowRHS + N^-Bex) and
  StochDom P ldeColLHS (ldeColRHS + N^-Bex),
```

with the time inside the index set and every off-diagonal band pair included.  For the Gaussian
sample, `RBM.Gauss.ldeFlowDom_floor` proves each pair from

```lean
hE, hs0, hst, ht1,
(hK : 0 <= K),
(heta : eventually N, N^-K <= etaT E (t N)),
(hBex : 0 <= Bex).
```

On a `Cond272Reg ... c` window with `c > 0`, the existing
`rpow_neg_one_le_etaT_of_scale_ge` supplies the needed lower bound with `K = 1`.  Hence
`LDEFlowDom'` is not the missing analytic leaf on T608's target grid.

The unprimed `LDEFlowDom` route is rejected.  Its time-uniform net closure would require a
polynomial lower bound on `ldeRowRHS`/`ldeColRHS`; those controls may be exponentially small
and need not dominate any `N^-B`.  The compiled Gaussian theorem is the primed form with the
additive floor, and all consumers used here already absorb that floor.

### 3.4 Final bridge

`RBM.EEBridge.stochDom_norm_eeField` takes

```lean
hE, hs0, hst, ht1, Cond272 B E s t,
hxi : HighProb B.P (xiLowEvent X E s t n C),
hdec : forall tau > 0, forall D > 0,
  HighProb B.P (eeDecayEvent X E s t n tau D).
```

At `n = 0`, its output is exactly

```text
||eeField|| \prec
  (scale E N u)⁻¹^4 * (etaT E u)⁻¹ * xiL(E,N,u,omega,6).
```

The scale powers are literal: `2*(n+2)=4` and `2*(n+2)+2=6`.  No extra `N`, `W`, `L`,
`ell`, `eta`, or time-ratio factor is introduced.  The bridge asks its decay event at
`tau/2` and `D+2`; this pays the prefactor and additive decay remainder without changing the
displayed control.

## 4. Same sample, event intersections, and endpoints

Every probabilistic object above is evaluated under the one measure `(band d).P` and the one
sample `sample d`, with the identical `E`, `s`, and `t` threaded through every theorem.

`highProb_flowGoodSet'` intersects the good-flow, floored row/column LDE, and (2.76) decay
events before Lemma 5.9 is applied.  `stochDom_norm_eeField` combines the resulting loop-decay
event with `xiLowEvent` through a stochastic-domination union argument.  This is a legitimate
same-sample intersection of high-probability events; it is not a reuse of a `(+,-)` event as a
`(+,+)` coordinate and not an independence argument.

All event statements quantify over `u : TimeIcc s t N`, so both closed endpoints are present.
The intended QV consumer must still split its integrated endpoint:

* if `v = s_N`, the interval integral is zero by `intervalIntegral.integral_same`;
* if `s_N < v`, the pointwise profile may be used for every `u in [s_N,v]`.

The pointwise `hEE` itself does not vanish at `v=s_N`, and no positive-time T596 theorem should
be invoked in that branch.

## 6. Why the current good-flow interface is the first local blocker

`flowInputs'_of_inputs` does not use the full strength of its `hOmega` argument: it passes it to
`flowInputs'_of_highProb`, which immediately calls only `hOmega 1`.  The hard-coded numerical
choice then checks

```text
36 * N * (N^-1)^2 <= 1.
```

This choice is sufficient but not necessary.  A Step-2 local law with a positive scale gain
only gives `HighProb goodSetFlow` after choosing a threshold compatible with that gain.  On a
`Cond272Reg ... c` window, the natural safe form is to choose positive exponents `alpha,beta`
with

```text
0 < beta < 2*alpha,
gdel_N = N^-alpha,
Phi_N  = N^beta.
```

Then `36*Phi_N*gdel_N^2 = 36*N^(beta-2*alpha) <= 1` eventually.  The decay error can be chosen,
after `D'`, as

```text
eps_N = N^(-2*(D' + beta + 1)),
```

so `Phi_N*sqrt(2*eps_N) <= N^-D'` eventually.  `LDEFlowDom'` supports every `beta>0` and every
floor exponent, and (2.76) supports every positive decay exponent.  This is precisely the
freedom the present hard-coded constructor discards.

For example, once a same-window `LocalLawFlow` is supplied, `Cond272Reg ... c` with `c>0`
allows choices such as `alpha=c/4`, `beta=c/4`; the local-law high-probability exponent may be
chosen smaller than the remaining scale margin.  These numbers are only the proposed adapter's
safe bookkeeping; this report does not claim the missing `LocalLawFlow` or (2.76) witness.

## 8. Conditional adapter design, blocked pending T626

Do not dispatch `XiLKTwoCutQV.lean` or the adapter below yet.  At theorem level, the smallest
local repair would be a new primed constructor
with one good-event exponent and one LDE exponent, followed by a Gaussian wrapper that derives
the good event from the same-window Step-2 local law.  A suitable core signature is:

```lean
theorem flowInputs'_of_exponents
    {alpha beta : Real}
    (halpha : 0 < alpha) (hbeta : 0 < beta) (hgap : beta < 2 * alpha)
    (hOmega : HighProb B.P
      (FlowGoodEv X E s t (fun N => (N : Real) ^ (-alpha))))
    (hlde : LDEFlowDom' X E s t)
    (hdecay : AprioriDecayFlow X E s t) :
    FlowInputs' X E s t
```

The proof must choose `eps` only after `D'`, as above; it must not reintroduce the unavailable
unprimed `LDEFlowDom`.  The Gaussian wrapper should take

```lean
d, hE, hs0, hst, ht1, hc : 0 < c,
hreg : Cond272Reg (band d) E s t c,
hlocal : LocalLawFlow (sample d) E s t,
hdecay : AprioriDecayFlow (sample d) E s t,
```

derive `LDEFlowDom'` with `K=1`, choose compatible `alpha,beta`, and return
`FlowInputs' (sample d) E s t`.  It must include a target-grid parameter/endpoint witness and
must state plainly that a full Gaussian satisfiability witness still waits for the upstream
same-parameter `(2.75),(2.76)` producer.  It must not manufacture that witness from a
first-cell, T589, A-prime, or Step-3 theorem.

The following historical import sketch is forbidden pending T626 because its transitive closure
reaches downstream modules:

```lean

import RBM1D.Gauss.LDENetClose
import RBM1D.Hierarchy.LKDecayQuant
import RBM1D.Flow.Thm221Bare
```

Only after that producer and its genuine same-window Step-2 witness exist should a second ticket
compose `highProb_xiLowEvent`, the primed decay event, and
`EEBridge.stochDom_norm_eeField` into `hEE`.
