## The smallest deterministic absorption lemma

The correct scalar helper should assume the ordinary positive-scale facts and the one
quadratic-source comparison

```text
cFar2(W,ell_u) * N^(zetaSrc/2) * r_u^(3/2)
  <= A_u^(1/6) * Jbar.                                      (QA)
```

Together with

```text

W*L*W^(-D) <= eta_u^(-1)*A_u^(-1),
```

it gives, row by row,

```text

Q3  <= 1152 * eta_u^(-1) * A_u^(-1/3) * Jbar^3,
```

```text
diagFarRate(...,Jbar,sourceC4(...))
  <= 1200 * eta_u^(-1) * A_u^(-1/3) * Jbar^3.              (FA)
```

The constant is exact for this route: `16 + 1152 + 32 = 1200`, and
`sqrt(1200) = 20*sqrt(3)`.  The spatial row uses the already compiled
`APrimeFullQV.ExponentRows.leak_paid_by_dims`; its hypotheses follow from
`D >= 60`, `W*L <= N <= W^2`, `A_u <= N`, and `eta_u <= 1`.  No product inequality
`N^c R_u^30 <= A_u` is used.

The root-profile corollary should consequently have exactly the form

```text
qvAt <=
  (R_u^(-2) * R_v^(-2) *
    (sqrt(Near + 2*W^(-1)) * (Xi*chi_v(a) + K_D)
      + sqrt(1200 * eta_u^(-1) * A_u^(-1/3) * Jbar^3) * Xi))^2.   (RP)
```

This is the smallest honest paper-(5.42)-shape theorem.  It weakens only the complete far
coefficient.  It deliberately keeps the repaired residual and propagated leakage, and it
does not expand a square of a sum termwise.

## Why the quadratic comparison holds

Use the standard flow inequality

```text
r_u^2 <= R_u
```

and the uniform subpolynomial estimate

```text
cFar2(W,ell_u) <= N^(tauG/2).                              (CF)
```

The latter is a small deterministic helper, uniform in the moving time because
`ell_u >= 1`; from the definition,

```text
cFar2(W,ell_u)
 <= (4*(log W)^(3/2)+4) * exp((log W)^(3/4)),
```

and `W <= N`.  Existing stretched-exponential estimates used for `xiK` prove (CF) for every
fixed positive `tauG`.

Assume the closed parameter room

```text
0 < delta <= c/20,
0 < tauG <= delta/16,
0 < zetaSrc <= tauG.                                      (ROOM)
```

Apply `Cond272Reg.margin` with

```text
e = tauG/2 + zetaSrc/2,   b = 3/4,   a = 1/6.
```

Indeed `e <= tauG <= c/320`, and

```text
e/c + b/30 <= 1/320 + 1/40 = 9/320 < 1/6.
```

Thus, uniformly for every `u in [s_N,t_N]`,

```text
N^(tauG/2+zetaSrc/2) * R_u^(3/4) <= A_u^(1/6).
```

Combining this with `r_u^(3/2) <= R_u^(3/4)` and `Jbar >= 1` proves (QA).
The strict unused interpolation room is at least `133c/960`; constants can therefore be
absorbed eventually without touching a boundary equality.

The centered loss `zetaCtr` does not enter this argument.  It stays an independent positive
parameter of the same common event and must not be identified with `zetaSrc` or `tauG`.

then the main near pure square costs `zetaSrc+3*tauG/2`, and the absorbed far pure square

remains in the kernel bracket.  If a later rate-form consumer separates that bracket, it

## Endpoint factor and boundary cases

The endpoint identity is exact.  The propagated kernel supplies

```text
((1-u)/(1-v))^2 = (eta_u/eta_v)^2 = (R_v/R_u)^2,
```

and division by `R_v^4` gives

```text
R_u^(-2) * R_v^(-2).
```

Both factors are required.  The closed running interval causes no singularity:

- at `u=s_N`, `R_u=1`, so the factor is `R_v^(-2)`;
- at `u=v`, it is `R_v^(-4)`;
- `v<=t_N<1` makes every `eta` and denominator positive.

The pointwise actual-model theorem must retain `1 <= k`.  T579's support cap has precisely
that hypothesis.  At `k=0`, `v=s_N`; the instantaneous QV rate is not forced to vanish, and
there is no positive-support `Jbar` conclusion to apply.  The `k=0` contribution is zero only
after integration over the degenerate interval `[s_N,s_N]`.
