# 真路径试点 P4/P5 的纸面论证（总调度，2026-09-25；Opus 5.5）

状态：初稿，待独立复核（见 §8）。依据：`paper/250520-YinJun-v2.pdf` §5.2 的 Lemma 5.3、5.5 与 §5.3 的 (5.43)–(5.48)（下称「论文」）；锁定的 Mathlib（`lake-manifest.json`，inputRev v4.34.0）；现有 Lean 接口 `RBM.Step1.step1`（`RBM1D/Hierarchy/Step1.lean:845`）、`StochDom`（`RBM1D/Defs/StochDom.lean:86`）。

**结论先行**：P4、P5 都不需要事先没有预见的新数学。
- P4（停止过程的矩／尾界）不需要 BDG，也不需要 Burkholder。停时的指示函数是可预测的，所以停止后的鞅差条件次高斯常数仍是确定性的。于是可以直接用 Mathlib 已有的 Azuma–Hoeffding（`ProbabilityTheory.measure_sum_ge_le_of_hasCondSubgaussianMGF`，`Mathlib/Probability/Moments/SubGaussian.lean:921`）。
- P5（停时越过阈值）在离散论证里不需要单独控制，Lipschitz 界也用不上。停时那一格的值由停止后的积分层级方程直接给出，最后一步的增量本来就包含在停止鞅里。
- 顺带发现论文 (5.43) 的阈值字面上少一个 N^δ 因子（§6）。这是证明内部的细节，不改动任何定理陈述；按 DECISIONS §2 记为 paper-delta 候选。

## 1. 论文的论证骨架（§5.3，σ = (+,−)）

1. 积分层级 (5.20)，以及它的停止版本 (5.21)：由 Itô 公式 (2.45) 和确定性传播子 U（Lemma 5.3）得到。
2. 鞅项的矩界 Lemma 5.5，即 (5.24)：用 BDG，二次变差由 (E⊗E) 控制，见 (5.25)。
3. 停时 (5.43)：T := min{u : J*_{u,D} ≥ (η_s/η_t)^4}，τ = T∧t。在 τ 之前 J* 低于阈值，所以 Lemma 5.7 的 (5.34)–(5.36) 给出漂移项 (5.40)(5.41) 和二次变差 (5.44) 的界。
4. BDG 给出停止鞅 ≺ (η_s/η_t)^2·1(|a₁−a₂| ≤ 6ℓ*_t) + 1。再在 N^{−C} 网格 t(k) 上取最大值 (5.46)，把随机时刻 τ 处的 U_{t,τ} 换成近似恒等 (5.46 之后)。
5. 合起来得到 J*_τ ≺ (η_s/η_t)^2 (5.47)，所以 P(T ≤ t) 可以忽略，(2.76) 和 (5.48) 成立。

论文用到路径的只有三处：Itô 公式、BDG、停时。Lemma 5.7 与 (5.39)–(5.42) 都是在固定时刻、固定样本上的确定性推导，其输入是 Step 1 的界。

## 2. 离散模型与记号

取 Δ = (t−s)/K，其中 K = ⌈N^C⌉；网格时刻 u_k = s + kΔ，k = 0,…,K，所以 u_K = t 恰好落在网格上。H_{u_{k+1}} = H_{u_k} + ΔH_k，各增量 ΔH_k 相互独立，协方差为 Δ·S，并且与 F_k := σ(H_{u_0},…,H_{u_k}) 独立。每个网格时刻 H_{u_k} 与现模型的 √u_k·X 同分布（这是 P1 的转移引理）。

对 loop 泛函 f_u(H) := L_{u,σ,a}(H)（z = z_u，Im z_u = η_u ≥ N^{−1+τ}），有以下**确定性**事实，对一切 Hermitian H 成立，不需要概率：‖G‖ ≤ η_u^{−1}，所以 f_u 对 H 的各阶导数、对 u 的导数都 ≤ C_k·N^{C_k}。

## 3. 离散积分层级（代替 Itô 与 (5.20)(5.21)）

令 A_k := (L−K)_{u_k}，把一步的变化拆成三部分：
- 鞅差 ξ_{k+1} := A_{k+1} − E[A_{k+1} | F_k]。
- 漂移 E[A_{k+1}|F_k] − A_k = (P_Δ f_{u_{k+1}})(H_{u_k}) − f_{u_k}(H_{u_k}) − (K 的增量)，其中 P_Δ 是与增量分布作卷积。
- 对 ΔH 做四阶 Taylor 展开：奇数阶矩为零；二阶矩给出生成元，与 ∂_u 合起来正好是 (2.45) 的漂移乘以 Δ（生成元恒等式：A′ 代码里已有 `MomentDuhamel` 一族，可复用）；余项 ≤ N^C·E‖ΔH‖^4 = O(Δ²N^C)，是确定性的。

离散 Duhamel：U 满足半群性 U_{v,t}U_{u,v} = U_{u,t}（(5.24) 后的显式乘积式，是 S^{(B)} 多项式之比，彼此可交换）。于是有纯代数的伸缩恒等式

A_k − U_{u_0,u_k}A_0 = Σ_{j<k} U_{u_{j+1},u_k}(A_{j+1} − U_{u_j,u_{j+1}}A_j)，

再用 U_{u_j,u_{j+1}} = 1 + ΔΘ_{u_j} + O(Δ²N^C)，就得到 (5.20) 的离散版本：漂移项是 Riemann 和 Δ·Σ_{j<k}（与积分只差 O(ΔN^C)），鞅项是 Σ_{j<k} U_{u_{j+1},u_k}ξ_{j+1}，余项 O(ΔN^C)。停止版本 (5.21) 只需把 k 换成 k∧τ。因为 τ 取网格值，这一步不需要任何近似。

## 4. P4：停止鞅的尾界，不用 BDG

固定目标格 k 和指标 a，考虑 M^{(k)}_m := Σ_{j<m∧τ∧σ} U_{u_{j+1},u_k}ξ_{j+1}，分实部和虚部处理，其中：
- τ := min{j : J*_{u_j,D} ≥ 阈值}（阈值见 §6）。它是 F-停时，而且 1(j < τ) 是 F_j-可测的。
- σ := min{j : Lemma 5.7 或 Step 1 的某个界在 u_j 处不成立}，这里的界都是 H_{u_j} 的确定性函数。所以 σ 也是停时，1(j < σ) 是 F_j-可测的；由 §5，P(σ ≤ K) 可忽略。

**关键观察**：在 F_j 条件下，ξ_{j+1} = ∇f(H_{u_j})·ΔH_j + r_{j+1}，其中
- 线性部分在条件下**恰好是高斯的**，方差 v_j = Δ·Σ_α S_α|∂_α f|² + O(Δ²N^C) = Δ·[(U⊗U)∘(E⊗E)]（(5.22)(5.25) 的同一恒等式，只是差一个 U 因子）。在 {j < τ∧σ} 上，v_j ≤ Δ·λ(u_j)·N^δ，其中 λ(u) 就是 (5.42)/(5.44) 被积函数的**确定性**上界。
- 所以停止后的增量 1(j<τ∧σ)·(线性部分) 满足 `HasCondSubgaussianMGF (ℱ j) … (c_j := Δ·λ(u_j)·N^δ)`：指示函数为 0 时增量为 0，为 1 时是方差 ≤ c_j 的高斯变量（Mathlib 有 `mgf_gaussianReal`）。**c_j 是确定性的**，这正是 Mathlib 的 Azuma–Hoeffding 所要求的。
- 令 Λ := Σ_j c_j。由 (5.44) 的离散 Riemann 和，Λ ≤ N^{2δ}·T_{t,D}(|a₁−a₂|)²·[(η_s/η_t)^4·1(|a₁−a₂| ≤ 6ℓ*_t) + 1]。对实部、虚部各用一次双侧 Azuma–Hoeffding：P(|M_lin| ≥ N^δ·Λ^{1/2}) ≤ 4·exp(−N^{2δ}/2)。于是 |M_lin|/T_{t,D} ≺ (η_s/η_t)^2·1(|a₁−a₂| ≤ 6ℓ*_t) + 1，这就是 (5.45) 的离散版本。
- 余项 r 满足 |r_{j+1}| ≤ N^C‖ΔH_j‖²（确定性）。Σ(r − E[r|F]) 的二阶矩 ≤ K·N^C·Δ² = N^C·Δ，由 Chebyshev，对给定的 D 取 C 足够大，这部分可以忽略。**网格随 D 选取是允许的**：结论只关于固定时刻 t 的分布，而这个分布与网格无关。
- 对 k（至多 K+1 ≤ 2N^C 个）、a、ℓ（多项式个）取并集界，得到 (5.46) 的离散版本。论文的「t(k) 网格加 U_{t(k),τ} ≈ 1」一步在这里变成平凡：在 {τ = k} 上直接用目标格 k。

所以 P4 的 Lean 陈述是一条纯概率的引理，与 RBM 无关：「停时截断后的、条件方差有确定性上界的条件高斯鞅差之和，满足 Azuma 型尾界」，再加上余项的 Chebyshev 估计。用到的 Mathlib 部件都已在锁定版本里：`HasCondSubgaussianMGF`、`measure_sum_ge_le_of_hasCondSubgaussianMGF`、`mgf_gaussianReal`、`condExp_indep_eq`、`IsStoppingTime`/`hitting`。不需要 BDG、Burkholder、Freedman、Doob 的 L^p 极大不等式，也不需要连续时间随机积分。

## 5. 输入界在所有网格时刻同时成立

- Step 1：`RBM.Step1.step1` 的结论是对 `TimeIcc s t N × LoopData` 一致的 `StochDom`，而 `StochDom` 的 badSet 是对指标的并（`Defs/StochDom.lean:86`）。在现模型里它蕴含每个固定 u 的单时刻界，由单时刻同分布转移到网格模型，再对 K+1 个网格时刻取并集界：N^C·N^{−D'} 仍可忽略。这里**只用单时刻律**，没有用现模型的联合律，是合法的。
- Lemma 5.7（(5.34)–(5.36)）：在固定时刻，从 Step 1 的界和 J* 出发确定性地推出，逐格照搬即可。Lean 里要核对的是现有部件是否已经写成「逐时刻、逐样本」的形式（见 §7，核对项 3）。
- 初值 J*_s ≺ 1 来自 (2.68)(2.69)，是 s 时刻的单时刻界，可直接转移。

## 6. P5：越过阈值，以及阈值本身的一个小缺口

**越过阈值不需要单独控制。** §3 的停止方程在 k = τ 处成立：A_τ 的鞅部分是 Σ_{j<τ}，其中已经包含把路径带到 τ 的最后一个增量 ξ_τ；漂移部分只用到 j < τ，而在这些时刻 J* 低于阈值。所以 §4 直接给出 J*_{u_τ} ≺ (η_s/η_t)^2，与 J*_{u_τ} 越过阈值多少无关。最后一步增量的大小只进入 §4 的尾界（线性部分是精确的高斯，余项 O(ΔN^C)），用不上任何 Lipschitz 界。论文在连续情形也没有用到 J*_T 恰好等于阈值。

**阈值缺口（paper-delta 候选）。** (5.43) 的阈值是 (η_s/η_t)^4，而初值只有 J*_s ≺ 1，结论只有 J*_τ ≺ (η_s/η_t)^2，两者都带 N^ε 损失。当 η_s/η_t 接近 1（s、t 很近，(2.72) 允许）时：
- 可能 J*_s > 阈值，于是 T = s；
- 由「J*_τ ≺ (η_s/η_t)^2」推不出「J*_τ < (η_s/η_t)^4」，所以论证无法闭合。

修补：T := min{u : J*_{u,D} ≥ N^δ·(η_s/η_t)^4}，δ > 0 任意小。之后
- (5.44) 中 J*³ 项多出 N^{3δ}。它被 (Wℓ_uη_u)^{−1/3} 吸收，因为 Wℓ_tη_t ≥ W^{30τ'}（Lemmas 2.18–2.20 证明中的选取），取 δ ≪ τ' 即可；
- 结论 P(T ≤ t) ≤ P(J*_τ ≥ N^δ(η_s/η_t)^2) 可以忽略。

这不改变 (2.76)(5.48) 的陈述（≺ 本来就吸收 N^δ），属于 DECISIONS §2 的「必要条件」类微小改动。**需要独立复核后再记入 `docs/paper-deltas.md`**。

## 9. 独立复核结果（Fable 论证子代理，2026-09-25；原文英文，此处为摘要）

总评：**不需要预料之外的新数学**，前提是做下面两处修补。

逐项结论：
- §3 离散积分层级：**OK**。U 的半群性由 (5.17) 的乘积式与 Lemma 2.14(3) 的可交换性得到，U_{t,t} = 1；U_{u_j,u_{j+1}} = 1 − Δ·ξS·Θ_{u_{j+1}ξ}（Lemma 7.1 之后的恒等式）给出 O(Δ²N^C) 误差。K 是确定性的，经 (2.48)/(2.57)/(5.19) 处理，l_K = 2 的部分正是 Θ∘(L−K)。
- §4 线性部分用确定性 c_j 的 Azuma：**OK**；τ、σ 都是停时，指示函数属于 F_j。
- §4 余项：**有缺口**。原文写的是「先 Chebyshev、再对目标格 k 取并集」，但并集会吃掉 K = Δ^{−1} 倍，最后剩 N^C/x²，并不小。**修补 (A)**：写 U_{u_{j+1},u_k} = U_{u_k,t}^{−1}·U_{u_{j+1},t}，其中 U_{u_k,t}^{−1} = ⊗(1 + (u_k−t)ξSΘ_{u_kξ}) 的 max→max 范数对 k 一致地 ≤ C^n（由 (2.52)）。于是 M̃_k = Σ_{j<k∧τ∧σ} U_{u_{j+1},t}ζ_{j+1} 是关于 k 的真鞅，用 Doob 极大不等式（Mathlib `maximal_ineq`，作用于 |M̃|² 这个非负下鞅）即可一次控制所有 k。线性部分也可以这样处理，从而省掉对 k 的并集。
- σ 必须显式列出 (5.36) 证明用到的全部单时刻输入：长度不超过 6 的 loop 的 (2.73)（(5.64)），(2.74)/(4.2) 的 resolvent 元素界（(5.57)(5.61)(5.69)–(5.70)），以及确定性的 Lemma 5.6 (5.31)。
- §5 转移：**OK**。`TimeIcc s t N` 是实区间 `Set.Icc (s N) (t N)`（`Flow/Hypotheses.lean:337`），所以随 D 选取的网格时刻都在 Step 1 的覆盖范围内。
- §6(a) 越过阈值不需单独控制：**OK**；论文 (5.46) 之后的 U_{t(k),τ} ≈ 1 一步在离散版中消失。
- §6(b) 阈值缺口：**确认是字面缺口**。论文只在应用处（p. 24，η_s/η_t = W^{τ′}）隐含地吸收了它，别处没有。N^δ·(η_s/η_t)^4 的修补正确。**但记账不完整，需要修补 (B)**：按 (5.35)(5.36) *陈述的* 指数，(5.41)(5.44) 里的 J*³ 项在 (2.72) 的极端情形下闭合不了：(J*)³ ≤ (η_s/η_t)^{12} ≤ (Wℓ_tη_t)^{2/5}，而对面只有 (Wℓ_uη_u)^{−1/3}，差一个 (Wℓη)^{1/15}·log N。好在这两个引理的**证明**给出的比陈述强得多：(5.55)(5.63) 给 (Wℓη)^{−1/2}(J*)² + (Wℓη)^{−3/2}(J*)³，(5.71)(5.72) 给 ℓ(Wℓη)^{−3/2}(J*)²、ℓ(Wℓη)^{−2}(J*)³，还富余一个 W^{−1}。用证明里的指数，一切都能闭合，并且留得出 N^{3δ} 的空间。另外 (5.44) 丢掉了因子 (ℓ_u/ℓ_s)^5 ≤ (η_s/η_t)^{5/2}，它无害也正是因为 (5.64)/T² 带有那个额外的 W^{−1}。**结论：Lean 里 Lemma 5.7 的陈述必须采用证明给出的指数，不能照抄 (5.35)(5.36) 显示的指数。**
- 其余：路径连续性只在 Step 1 的 (5.1) 网格论证里用到（已有接口），另外就是「对 u ∈ [s,t] 一致」这种连续时间陈述，这是陈述上的限制，不是证明缺口。Hermitian 增量的复/实结构（B_ii 为实，B_ji = conj B_ij，Wirtinger 导数）只改变 v_j ≤ C·Δ(E⊗E)_{a,a} 里的常数。条件高斯 MGF 的「冻结引理」（F_j-可测系数 × 独立的 ΔH_j）在 `Measure.pi` 下可能要自己证，属于工程量，不是数学问题。
