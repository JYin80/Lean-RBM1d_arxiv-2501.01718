## Result

The module fixes the T453 event mismatch without an event inclusion.  Its
master event is the literal T434 event

```text
G_alpha(N) = sharpCommonEvent tauPrime delta alpha N.
```

The theorem

```lean
egEvent_two_mul
```

proves the exact identity

```text
EGAllOutputRunning.good tauPrime delta ((2 alpha)/2) N
  = EGAllOutputRunning.good tauPrime delta alpha N.
```

Thus T442 is instantiated at loss `2 alpha`, while its required event is
exactly the second component of `G_alpha`.  No monotonicity between events is
assumed.

The main property

```lean
weightedDriftGood tauPrime delta alpha
```

is eventual in `N` and uniform in every sample in `G_alpha`, every active
prefix `k>=1`, the literal moving endpoint `v=u_k`, every real
`r in [0,v]`, and every two-loop output.  It states

```text
w * driftAt <= w * endpointCoefficient delta (2 alpha) N v r,
```

for the actual smooth prefix weight.  The producer

```lean
weightedDriftGood_of_absorbed
```

splits on the actual value of `w`:

* if `w=0`, both sides vanish;
* if `w>0`, the EG projection of `G_alpha` is rewritten with
  `egEvent_two_mul` and fed to T442.

The nonnegativity needed to multiply T442's inequality is supplied by
`APrimeSmoothWeightActual.weight_nonneg`.

## Exact rate

`endpointCoefficient_two_mul` exposes the retained T442 coefficient:

```text
C * N^(2 alpha) * eta_r^(-1) * R_v^(-2) *
  [x_r^(-1/2) + N^(4 delta) A_v^(-1) x_r^6].
```

In particular, the outer factor is `N^(2 alpha)`.  It is not weakened or
rewritten as `N^alpha`, and neither the near nor the far row is removed.

## Empty prefix

`weightedDrift_zero_prefix` treats `k=0` separately.  It proves on every
sample and for every moment label that

```text
w = 1,
v = u_0 = 0,
w * driftAt(...,v,0) <=
  w * endpointCoefficient delta (2 alpha) N v 0.
```

The weight equality is the accepted
`APrimeSmoothWeightActual.weight_zero_prefix`; the drift inequality is
`APrimeFirstCellDriftAbsorbed.driftAt_cutNet_zero_le_endpointCoefficient`.
No favorable event is needed in this zero-window branch.

## Same-sample positive resident

`positiveWeightedDriftPlateau` records a single sample in the same literal
`G_alpha` at `k=2`.  It retains:

* `2 <= cutNetTop`;
* the positive moving endpoint `0 < u_2 <= firstCellT <= 1/2`;
* actual weight equal to one for every moment order;
* the weighted drift bound for every real `r in [0,u_2]` and every output;
* explicit instances at `r=0` and `r=u_2`.

`positiveWeightedDriftPlateau_of_sharp` uses T434's resident and T442's
universal favorable bound on that same sample.  It applies T442 once with
moment label `1`, where T434 gives weight one, and then uses T434's
all-moment weight equality to export the weighted estimate for every moment
label.  No separately selected resident is introduced.

The closed producer

```lean

```

chooses `tauPrime` from T434 before `delta` and `alpha`, and returns the
measurability, `HighProb`, favorable weighted bound, and nondegenerate
resident on the same event.  It introduces no new hypothesis.

## Scope

The module makes no assertion about:

* a weighted `L^(2p)` norm;
* the complement of `G_alpha` or its probability payment;
* T450's global polynomial envelope;
* `hcross`, weighted moments, `hfamily`, or an A-prime slot;
* event monotonicity or next-cell `BoundsCore`.

T450 is therefore intentionally not imported.  Its all-sample envelope is
needed only by the later bad-event moment split, which is outside T456.
