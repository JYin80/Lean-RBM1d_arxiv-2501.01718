## ⭐ 一个结构性发现：**瓶颈换人了**

重标之后，原先的绑定条件 `β* = 5.5` 不再是瓶颈；**唯一的绑定条件变成远场阈值 `A ≥ cWt²x^{33}R^{10}`**，而 `sideBundle''_of_A` **由它一条推出两条远场条件**（`β` 只需 `cWt²x^{32}R^{5.5}`，`γ` 只需 `cWt^{3/2}x^{24}R^{4.5}`）。**于是这个 bundle 只有一条主不等式，而不是三条。**

## 代价：`δ` 预算

`4δ ≤ 2c` 实际变成 `5δ < c`，打包成 `N`-充分大的 `cWt² ≤ N^{c−5δ}`。两条配套引理**把这件事两头都说实话**：
* `eventually_cWt_sq_le` —— 只要 `5δ < c` 它就 `∀ᶠ N in atTop` 成立（项目要求的量词形状）；
* `five_delta_lt` —— 对 `N > 1`，那个假设**反过来逼出** `5δ < c`，**所以它不是白搭的前件**。

**(2.72) 的指数 30 没有动**——重标后的阈值只要 `R^{10}`，**还剩 20 次幂的余量**。

## 可满足性见证：`R > 1`、**处处留余量**

`sat_StepSide''_half`（任意 `x ≥ 1`、`R ≥ 1`），具体实例 `sat_StepSide''_two`（`x = 1, R = 2`）：
`Ξ = x/2`、`A = 2(cWt²x^{33}R^{10})`、`ε = (2cWt²x^{33}R^{10})⁻¹`、`q = R²/2`、`β = (2cWt x^{16}R²)⁻¹`、`γ = (2cWt^{3/2}x^{24}R^4)⁻¹`、`κ = x/2`、`Jv = cWt x^{16}R^4/2`。

**没有一条取等号。** `sat_StepSide''_half_strict` 证明八条有向约束**全部带因子 2 的严格余量**，`sat_StepSide''_half_pos` 证明七个非负槽也严格。
对比：`Step2Bootstrap.sat_StepSide_gt_one` 的 docstring 写明八条**全部取等号**——**那正是本单要消掉的零余量。**

**两个失效方向都回答了**：
* *不可满足（空真）？* 否。上面的见证是联合的、严格的、在 `R = 2 > 1` 上；而且在真实的流上 `side_conditions_of_reg''` **由 (2.72) 把整个 bundle 交割出来**，所以加强后的假设是**被真实对象满足的**，不只是被人造见证满足。
* *松到无内容？* 否。`phi_lt_threshold''` 说明放大后的输出 `(cStep' m + 1)x²R^4` **仍低于**放大后的水平 `cWt x^{16}R^4`（条件 `cStep' m + 1 ≤ cWt x^{14}`，比 `phi_lt_threshold` 的 `cStep' m ≤ x^6` **更宽松**），自举照样闭合；`prior_lt_level` 说明真实的先验界 `4e·x^{16}R^4` **严格**落在新水平内、余量 `2x^{16}R^4`；`old_level_lt` 说明旧水平 `x^8R^4` 也严格落在内——**什么都没有被换掉**。
