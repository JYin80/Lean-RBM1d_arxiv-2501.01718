# T703 — exact sum transport between finite prefix fibers

## Files and scope

Added `RBM1D/Gauss/PermutationFiberCount.lean`, importing only

No existing source, root import, or task/status row was changed.

## Results

For every `W ≥ 2`, `k : Fin W`, prefix map `p : Fin W → Fin W`, distinct
`a,b : Fin W` absent from the prescribed prefix, and arbitrary
`F : Equiv.Perm (Fin W) → ℂ`,

```lean
(∑ π : permutationPrefixFiber W k p a,
    F (permutationCodomainSwap W a b π.1)) =
  ∑ ρ : permutationPrefixFiber W k p b, F ρ.1
```

The same hypotheses give

```lean
Fintype.card (permutationPrefixFiber W k p a) =
  Fintype.card (permutationPrefixFiber W k p b)
```

Both follow directly from T694's `permutationPrefixFiberSwap` equivalence via
`Fintype.sum_equiv` and `Fintype.card_congr`. The module supplies a finite-type
instance for the fibers, obtained by embedding finite permutations into the
function type `Fin W → Fin W` and then taking a subtype.

The explicit W=2 witness is `permutationPrefixFiber_two_card_pos`: for `k=0`,
`p i=i`, `a=0`, and `b=1`, both fiber cardinalities are positive. T694's
`permutationPrefixFiberSwap_two_nonempty` supplies identity and transposition
inhabitants, so all unused-value hypotheses hold vacuously at the empty prefix.

## Limitations

An arbitrary prefix map can make both fibers empty (for example, it can repeat
an earlier value). Thus the general equivalence proves equality of sums and
cardinalities, not unconditional positivity. This is deterministic finite
counting transport toward conditional exposure. It adds no N/time scale, first
cell or boundary claim, shared event, conditional expectation, Azuma estimate,
P2 result, `hfamily`/A-prime result, or theorem-level claim of paper formulas
(2.3)–(2.4).
