# T628 — target/canonical joint-support cylinder feasibility audit

## Verdict

carrier.**  The literal target-mesh/canonical-order scalar ray does have an eventual
strict `k = 2` transition point, with

```text
1 < prefixSample / threshold < 2.
```

However, every such scalar-ray transition point lies strictly outside

```lean

```

This norm event is the first conjunct of `sourceGood`, hence the first conjunct of

subset of `rawCarrier ∩ transition`, regardless of Gaussian support.  The later
`rawEvent` rows, `goodSetFlow`, centered two-charge row, and block `jG` row are not
used to hide this failure and were not declared to have strict margins.

No Lean source, root import, scheduling document, git index, commit, branch, or


## 3. First exact raw-carrier failure

The raw carrier expands, in its literal order, as

```text
rawCarrier
  = sourceGood
      ∩ goodSetFlow
      ∩ centeredEvent
      ∩ blockEvent,

sourceGood
  = {‖Xmat‖ ≤ N}
      ∩ rawEvent(n=3)
      ∩ rawEvent(n=4)
      ∩ rawEvent(n=6).
```

The first conjunct already excludes the scalar transition.

Indeed, let `0 ≤ x ≤ N` and put `r = sqrt(h_N)*x`.  At `u=h_N`, the explicit
scalar formula is

```text
lk(a,b)
  = (if a=b then [W_N*(r^2+(1-h_N)^2)]^(-1) else 0)
      - W_N^(-1) * Theta(h_N)(a,b).
```

For large `N`, `h_N ≤ 1/2`, `r^2 ≤ h_N*N^2`, and
`r^2+(1-h_N)^2 ≥ 1/4`.  Combining this with
`‖Theta(h_N)-I‖_entry ≤ 4h_N` gives, uniformly in `(a,b)`,

```text
‖lk(a,b)‖ ≤ W_N^(-1) * (16h_N + 4r^2).
```

Since `tailT ≥ W_N^(-60)` and eventually `W_N ≤ N`,

```text
jS(h_N) ≤ 1 + (16h_N + 4r^2) W_N^59
         ≤ 1 + 16N^(-199) + 4N^(-197)
         ≤ 2.
```

Also `ratR ≥ 1`, so `jSnorm(h_N) ≤ 2`; at `u_0=0` the same bound is immediate.
The public two-level smooth-prefix bound and canonical calibration now imply

```text
prefixSample(scalarSample x) ≤ exp(1)*(2+N^(-10)) ≤ 3*exp(1),
prefixSample(scalarSample x) / threshold deltaWeight N < 1.
```

Therefore no scalar sample with `0 ≤ x ≤ N` belongs to the strict transition.
The crossing from Section 2 satisfies the strict opposite margin

```text
x_N > N.
```

But

```text
Xmat d N (scalarSample d x_N) = x_N I,
‖Xmat d N (scalarSample d x_N)‖ = x_N > N.
```

Hence `omega_N` fails `APrimeGeneralMovingGoodMesh.good N` strictly.  By
continuity of the matrix norm, a whole neighborhood of the crossing still has
`‖Xmat‖ > N`.  Thus no open cylinder around this scalar crossing can lie in
`sourceGood`, and therefore none can lie in `rawCarrier`.

For completeness, the later carrier components and their exact thresholds are:

- `rawEvent(n=3,4,6)`: for every closed-window time and loop index,
  `‖Lval‖ ≤ N^zetaSrc * Step1.aprioriRhs`;
- `goodSetFlow`: for every `u ∈ [0,t_N]` and matrix indices,
  `‖G_u(x,y) - 1(x=y)m(0)‖ ≤ flowDelta d 0 t N`, including both endpoints;
- `centeredEvent`: for both Boolean charges, every closed-window time and block,
  `‖centeredTrace‖ ≤ N^zetaCtr * (2*qExt)`;
- `blockEvent`: for every closed-window time,
  `jG ≤ 1 + N^tauG*(9*exp(sqrt 3)*Step2.jS + 2)`.

Following the ticket's stopping rule, no strict-margin claim is made for these
later rows after the first literal failure in `{‖Xmat‖ ≤ N}`.  In particular,
high probability of any row is not substituted for same-sample membership.

## 4. Finite positive-variance projection

For fixed `N`, the prefix reads the sample only through `Xmat d N`.  The finite
coordinate set actually read is

```text
I_N = { Gauss.crd d N p | p ∈ Gauss.usedCoord d N },
```

where `usedCoord` contains:

- one real coordinate `(i,i,true)` for each diagonal entry;
- both real/imaginary coordinates `(i,j,true/false)` for each ordered pair
  with `idxKey i < idxKey j`.

Some off-diagonal coordinates have variance zero because the band profile
vanishes there.  The effective projection must therefore be

```text
I_N^+ = {c ∈ I_N | Gauss.gvar d c ≠ 0}.
```

It is incorrect to assert full support on all of `I_N`.  Every diagonal
coordinate belongs to `I_N^+` by `Sblk_diag_pos`; the scalar point sets these
coordinates to `x_N` and all effective off-diagonal coordinates to zero.
The omitted zero-variance coordinates must be fixed at their almost-sure
Dirac value `0` when the cylinder is pulled back to `Omega d`; they are not
given artificial open support.

`Gauss.P_map_restrict` identifies the law on `I_N^+` with the finite product
of its one-dimensional centered Gaussian laws.  On every coordinate in
`I_N^+`, Mathlib's
`gaussianReal_absolutelyContinuous` and
`gaussianReal_absolutelyContinuous'` give mutual absolute continuity with
Lebesgue measure.  These are the correct ingredients for positive mass of a
nonempty open box in the effective projection.

The repository does not currently package the finite-product consequence
`nonempty open box -> positive product-Gaussian mass`; a small finite-product
full-support lemma would still be needed to turn these APIs into the desired
cylinder statement.  More importantly, such a positive-mass cylinder around
the scalar crossing remains disjoint from the first raw-carrier norm event, so
adding that support lemma cannot repair the T628 route.

## 5. Measurable core: the stored identity is weaker than the requested null difference

Let `P = Gauss.P d`, `R = rawCarrier ... N`, and `C = measCore P R`.  The current
API proves

```text
C is measurable,
C ⊆ R,
P(C^c) = P(R^c).
```

It does **not**, by itself, justify the stronger assertion

```text
P(R \ C) = 0.
```

The reason is that the repository has not proved `R` measurable (or even
`NullMeasurableSet R P`), and equality of the outer measures of a set and its
measurable hull does not generally make the hull difference null.  The precise
missing implication for the phrase "null raw-carrier difference" is therefore
one of

```text
MeasurableSet R,
NullMeasurableSet R P,
or directly P(R \ C) = 0.
```

For an independently known measurable cylinder `U ⊆ R`, Mathlib's
`Measure.measure_toMeasurable_inter` and `P(R^c) < infinity` would give

```text
P(toMeasurable P R^c ∩ U) = P(R^c ∩ U) = 0.
```

and hence, by `C = (toMeasurable P R^c)^c`,

```text
P(U ∩ C) = P(U).
```

This direct measurable-`U` argument is mathematically sufficient for retention,
but it is not the requested global proof that `R \ C` is null.  Under the
independent-audit gate, T628 therefore does **not** record the null-difference
or positive-intersection transfer as an available producer.  Before a future
implementation uses that route, it must first compile either
`MeasurableSet rawCarrier`, `NullMeasurableSet rawCarrier P`, or the exact lemma

```text
P(rawCarrier \ commonEvent) = 0.
```

Complement-measure equality and probability finiteness alone do not prove
that statement for a potentially nonmeasurable carrier.  This is a secondary
API gap; the scalar construction has already failed earlier at the norm row.

## 7. Exact theorem needed next

The next mathematical input cannot be a scalar-ray full-support lemma.  It must
be one of the following genuinely joint statements.

1. A **non-scalar strict-margin construction**: eventually produce a matrix
   `M_N` with

   ```text
   ‖M_N‖ < N,
   1 < prefixMatrix(M_N)/threshold < 2,
   ```

   and strict inequalities for every `rawEvent(3,4,6)`, every
   `goodSetFlow` constraint, both centered charges, and every block `jG`
   constraint.  Continuity plus a finite positive-variance product-support
   lemma would then yield the required positive-measure cylinder.

2. A direct conditional anti-concentration/support theorem

   ```text
   0 < P(rawCarrier_N ∩ transition_N),
   ```

   or equivalently a sufficiently sharp mass comparison that implies it.

The first statement must use a genuinely non-scalar supported direction or a
different finite-dimensional deformation inside the norm ball.  A theorem
giving only `0 < P(transition_N)` is still insufficient.

No implementation ticket is selected until such a construction survives all
four carrier components on the same sample.
