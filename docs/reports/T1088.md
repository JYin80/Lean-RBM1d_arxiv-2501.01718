# T1088 — independent final audit of T1087

## Normalized claim and verdict

**Verdict: incomplete, with the selected-high-order Gaussian endpoint moment as the smallest missing implication.** This is a mathematical preflight FAIL, not a counterexample to the estimate. T1087 correctly stopped before claiming a producer. The accepted T999 theorem is a conditional transfer and remains sound at the audited source revision.

For admissible moving-window data, `mesh = APrimeGeneralMovingMesh.targetMesh D` with `D ≥ 60`, the producer required by T999 must show, for every fixed `δ` with `0 < δ ≤ δ₀` and every `p ≥ 1`, that there exist an integer `q ≥ p` and `C > 0` such that, for all sufficiently large `N` and **every** `k ≤ cutNetTop s t mesh N`, including `k = 0`,

```text
∫ widenedW (canonicalR s t mesh) 1 jSnorm s t mesh δ q N k ω
    · |cutTrunc (N^(2δ)) (jSnorm N (cutNetPt s mesh N k) ω)|^(2q)
  d(Gauss.band Dims.exampleGrow).P
≤ C · N^(δq/2).
```

This is the literal `hHigh` in `APrimeGeneralMovingLowMomentTransfer.lean:281–292`. The order is `δ, p, q, C, ∀ᶠ N, ∀ k`; `q` and `C` cannot vary with `N` or `k`. T999 then obtains the low-order constant `C^(p/q)` and exponent `δp/2` by probability-space Lyapunov monotonicity (`:246–276`, `:340–356`). The `p = 0` branch is separately exact (`:358–377`). Its specialization uses `Dims.exampleGrow`; it does not directly cover arbitrary dimensions in `APrimeAssembly.aprimeSlot_of_widened_family` (`APrimeAssembly.lean:1191–1211`).

## Paper scope

I independently extracted and visually checked printed pages 54 and 58 of the sole authorized source, `paper/250520-YinJun-v2.pdf`. Formula (5.21) is the **stopped** integrated loop hierarchy and includes an Itô martingale. Formula (5.44) bounds the time-integrated quadratic variation of that stopped martingale, using stopping time (5.43); (5.45)–(5.46) continue the stopped martingale and net argument. These formulas do not state a static Gaussian expectation with a smooth order-dependent prefix weight and a separately truncated endpoint. They therefore do not discharge `hHigh` without an additional derivation. This is a bounded source-scope finding, not a claim that the desired estimate is false.
