## Exact statement and calculation

Set `d = RBM.Gauss.Dims.exampleGrow` and, for `N : ℕ`,

```text
h_N = log(N)/W_N,
T_N = Nat.ceil((1/2)/h_N) + 1,
K_N = L_N (W_N - 1) T_N,
r_N = 64 sqrt(log(N)/W_N).
```

Here `T_N` is the *number* of nodes, including both endpoints. It equals the count proposed in T668 §4, `ceil(W_N/(2 log N))+1`, once `W_N>0` and `log N>0`; this equality of real arguments is elementary division algebra. The scratch proof defines the count directly and does not import the in-flight T919 closed-grid file or assert its coverage theorem.

For `N≥2`, `W_N>0`, and `log N>0`, put `q=log N/(W_N:ℝ)>0`. `Real.sq_sqrt q.le` gives

```text
-(W_N:ℝ) * (64 sqrt q)^2 / 256
  = -(W_N:ℝ) * 4096 q / 256
  = -16 log N.
```

Since `(N:ℝ)>0`, `Real.rpow_def_of_pos` identifies `exp(-16 log N)` with `(N:ℝ)^(-16:ℝ)` (equivalently `1/(N:ℝ)^16`). The equality is exact, including the coefficient 16; it is not an asymptotic estimate.

The compiled generic numerical lemma takes `N≥2` and the **natural-number** premise `K≤2*N^2`. Casting that inequality to `ℝ`, using positivity of the real power and `Real.rpow_add` with `-14=2+(-16)`, it proves

```text
4 * (K:ℝ) * (N:ℝ)^(-16:ℝ)
  ≤ 8 * (N:ℝ)^(-14:ℝ)
  < 1.
```

For the strict final step, `N≥2` implies `(N:ℝ)^14≥2^14>8`; `Real.rpow_neg` turns the target into `8/(N:ℝ)^14<1`. No limit convention at `N=0` or `N=1` is used. The real exponent `-16` must be written as `(-16:ℝ)`; `K` and `T*(W-1)` are natural products before their single outer cast. `Real.rpow_add` needs strictly positive real base in this Mathlib version.
