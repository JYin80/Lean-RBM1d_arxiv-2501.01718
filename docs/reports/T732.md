# T732 — measurability of an actual permutation-prefix cell

## Files and scope

Added `RBM1D/Gauss/PermutationPrefixCellMeasurable.lean` and this report. The new module imports only T711's `PermutationPrefixFiltrationCore`. It proves that the event of an actual prefix cell is measurable in the sigma algebra generated by its coordinate cylinders. No root import was added.

The paper's equations (2.3) and (2.4) are high-probability Green-function entry and partial-trace local laws. This finite measurability result is only supporting infrastructure; it proves neither local law, nor a conditional distribution or any concentration estimate.

## Statements established

* `measurableSet_prefixCell`: for every `W`, `k`, and `π`, the event `{ρ | ρ ∈ prefixCell W k π}` is the finite intersection of the generating cylinders `{ρ | ρ i = π i}` over positions `i.val < k`, hence belongs to `prefixSigma W k`.
* `prefixCell_event_eq_univ_of_zero`: at `k=0`, the event is the whole permutation space.
* `prefixCell_event_eq_singleton_of_width_le`: if `W ≤ k`, the event is `{π}`.
* `prefixCell_event_zero_width`: for `W=0`, `PermΩ 0` has one element and every prefix-cell event is the singleton containing that unique empty permutation.
* `prefixCell_event_two_support_witness`: for `W=2,k=0`, identity and swap lie in the same event and are distinct, so the full cell has nontrivial support.

No claim is made that an arbitrary prescribed prefix is realized; the cell is always the prefix of an actual `π`.
