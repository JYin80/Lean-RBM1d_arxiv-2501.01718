## Exact claim and dependencies

`RBM.Gauss.permutationFourierSum W x χ π` in `RBM1D/Gauss/PermutationFourierSwap.lean:18–20` is `(∑ i : Fin W, χ i * x (π i)) / (W : ℂ)`. `RBM1D/Gauss/PermutationFourierMaxNorm.lean` imports only this accepted T676 module; T676 imports only `Mathlib`. This is an acyclic import chain.

`norm_permutationFourierSum_le_two` quantifies over every natural `W` with `1 ≤ W`, every `x χ : Fin W → ℂ`, every permutation `π`, and the pointwise hypotheses `∀ i, ‖x i‖ ≤ 2` and `∀ i, ‖χ i‖ ≤ 1`. Its conclusion is exactly `‖permutationFourierSum W x χ π‖ ≤ 2`. The theorem requires `W > 0` before multiplying by or dividing by `W`; it excludes `W=0` and includes `W=1`. The underlying total Lean definition is still defined at `W=0`, but the theorem makes no claim there.

The proof unfolds the exact normalized sum, applies `norm_sum_le`, bounds each summand by `1·2=2`, sums `W` copies of `2`, and cancels the positive real denominator `W`. The bound does not use a permutation property beyond `π i` being a valid index. For `W=1`, it reduces to `‖χ 0 * x (π 0)‖ ≤ 2`.

`permutationFourierSum_sharp_two` has no premises and constructs `W=2`, `π=id`, `x=(2,-2)`, `χ=(1,-1)`. The theorem explicitly checks both pointwise bounds, `x 0 ≠ x 1`, `χ 0 ≠ χ 1`, and equality of the normalized norm to `2`. Directly, the numerator is `1·2+(-1)·(-2)=4`, so `F=4/2=2`. This is a nonvacuous, nonconstant witness.
