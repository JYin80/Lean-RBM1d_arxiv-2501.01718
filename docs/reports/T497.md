# T497 — general moving centered one-loop time-net interface audit

## Scope and verdict

This was a read-only audit. No all-time centered one-loop theorem is claimed here.

The intended continuum argument is mathematically compatible with the existing generic
time-net engine. The smallest existing consumer is

```text
RBM.Gauss.stochDom_timeIcc_of_unifDom
```

from `RBM1D/Gauss/Eq45FlowInputs.lean`, preceded by

```text
RBM.Gauss.unifDomIcc_of_forall_stochDom
```

from `RBM1D/Gauss/Lemma514Moment.lean`. The `DominationHolder.lean` consumers are not the
right first interface for the pending T495 output: they require unconditional integrability
and moment estimates, whereas T495 is specified to export a fixed-selector local law or
singleton `StochDom` statement.

The net arithmetic passes with spacing `N^(-16)`. T496 and T501 now provide the required
same-norm-event pathwise modulus for both charges. T495 remains the missing stochastic leaf.
There are two additional interface obligations for the eventual assembler:

1. extend the raw control `q_N(u)` to a nonnegative function on every real `u`, because the
   generic consumer requires global nonnegativity, not only positivity on the moving window;
2. prove the consumer's symmetric slow-variation premise for that control on pairs of nearby
   times in the window.

Neither obligation is a mathematical obstruction. The first exposes a literally false premise
if one tries to pass the raw formula globally. The second is true by the endpoint floor, but no
q-specific public producer was found.

## 1. Exact fixed-time-to-continuum interface

For the plus charge, let

```text
xi(N,u,b,omega) =
  ||trace ((G_+(u)-m_E) E_b)||,

q_N(u) = (ell_u/ell_s)/A_u
       = 1/(W ell_s eta_u).
```

T495 is specified to give, for every deterministic selector `v : N -> R` satisfying
`v_N in [s_N,t_N]`, the sharp singleton local law at

```text
Psi_N = sqrt(q_N(v_N) + W^(-1)).
```

The exact fixed-time averaging theorem is

```text
Gauss.detAvgIBP_stochDom_of_localLaw_complete
```

with hypotheses

```text
0 < kappa <= 1,
|E| <= 2-kappa,
0 <= v_N < 1,
0 < a,
0 <= K,
N^(-K) <= eta(v_N) eventually,
W^(-1/2) <= Psi_N eventually,
Psi_N <= N^(-a) eventually,
LocalLawUnifIcc d E v v Psi,
```

and conclusion

```text
xi(N,v_N,b,omega) \prec Psi_N^2.
```

T492 gives `Psi_N^2 = q_N(v_N)+W^(-1) <= 2q_N(v_N)`, and T488's
`APrimeGeneralMovingInitialHinit.eventually_eta_window` permits `K=2`.

The selector quantifier has the correct order in the existing theorem

```text
RBM.Gauss.unifDomIcc_of_forall_stochDom
```

whose hypothesis is, exactly,

```text
forall v : N -> R,
  (forall N, v_N in [s_N,t_N]) ->
  StochDom P (xi at v_N) (control at v_N).
```

Thus the selector is fixed before the eventual-`N` quantifier inside `StochDom`. Its conclusion
is `UnifDomIcc P s t xi control`, the fixed-time tail estimate uniform in all real
`u in [s_N,t_N]`. No uncountable probability union is taken in this exchange.

After the harmless fixed factor two is absorbed, this is the `hfix` input of
`stochDom_timeIcc_of_unifDom`.

## 2. The smallest exact existing consumer

The relevant signature of `RBM.Gauss.stochDom_timeIcc_of_unifDom` is:

```text
hcard : eventually card(V_N) <= N^Cv
hst   : forall N, s_N <= t_N
hT    : 0 < T
hlen  : forall N, t_N-s_N <= T
hK    : 0 <= K
hB    : 0 <= B
hgamma: 0 < gamma
hzeta0: forall N u a omega, 0 <= zeta(N,u,a,omega)
hdelta: eventually T/N^((K+B+1)/gamma) <= delta_N
hXi   : HighProb P Xi
hHol  : eventually on Xi,
        |xi(N,u,a)-xi(N,v,a)| <= N^K |u-v|^gamma
hzetaLow:
        eventually on Xi and in the window, N^(-B) <= zeta
hslow : for every epsilon>0, eventually on Xi,
        |u-v| <= delta_N -> zeta(N,v,a) <= N^epsilon zeta(N,u,a)
hfix  : UnifDomIcc P s t xi zeta
```

Its conclusion is the required `StochDom` over
`TimeIcc s t N x V_N`. Use `V_N = ZMod(L_N)` and transfer the minus charge only after the
plus-charge event has been obtained. This is smaller than inserting `Bool` into the net index,
and it makes the common-event property immediate.

The parameter choice is

```text
T = 1,
gamma = 1/2,
B = 1,
K = 6,
delta_N = N^(-16).
```

T496 gives coefficient `2N^5`. For eventual `N >= 2`, enlarge it to `N^6`, so the exact
consumer exponent is `K=6`. Then

```text
(K+B+1)/gamma = (6+1+1)/(1/2) = 16,
```

and `hdelta` holds at equality for `T=1`. Since `0 <= s_N <= t_N < 1`, one has
`t_N-s_N <= 1`.

The index cardinality input is already

```text
Gauss.card_ZMod_L_le d : eventually card(ZMod(L_N)) <= N.
```

The actual time net has `ceil(N^16)+1`, hence at most `N^16+2`, points. The generic theorem's
coarse public estimate `card_net_le` pays `N^17`; together with the block index it pays at most
`N^18`. Both counts are polynomial and are harmless in a `StochDom` union bound.

## 3. Modulus error versus the target

T496's theorem

```text
APrimeGeneralMovingTraceModulus.eventually_centeredTrace_sub_le
```

proves on

```text
APrimeGeneralMovingGoodMesh.good N
  = {omega | ||Xmat d N omega|| <= N}
```

that, uniformly in the full moving window and every block,

```text
|F_b(u)-F_b(v)| <= 2 N^5 sqrt(|u-v|).
```

The consumer is applied to the real-valued quantity `xi=||F_b||`. The reverse triangle
inequality gives

```text
|xi(N,u,b,omega)-xi(N,v,b,omega)|
  <= ||F_b(u)-F_b(v)||,
```

so T496 supplies `hHol` with no further scale loss.

At `Delta=N^(-16)` this is

```text
2 N^5 sqrt(Delta) = 2 N^(-3).
```

T492 gives

```text
q_N(u) >= W^(-1) >= N^(-1).
```

Consequently, for every fixed `zeta>0`, eventually

```text
2N^(-3) <= N^zeta q_N(u),
```

with two powers of `N` to spare. This is also reflected by the generic consumer: its net error
is forced below `N^(-B)=N^(-1)` before the final stochastic-domination exponent is allocated.

The norm event is already measurable and HighProb by

```text
APrimeGeneralMovingGoodMesh.measurableSet_good,
APrimeGeneralMovingGoodMesh.highProb_good.
```

## 4. The two exact control mismatches

### 4.1 Global nonnegativity of the control

The raw formula

```text
q_N(u) = 1/(W ell_s etaT(E,u))
```

is positive on the target window because `u <= t_N < 1`. It is not a globally nonnegative
function of `u : R`; for example `etaT(E,u)` changes sign after `u=1`. Therefore the literal
attempt

```text
zeta(N,u,b,omega) := q_N(u)
```

does not satisfy the consumer's premise

```text
forall N u b omega, 0 <= zeta(N,u,b,omega).
```

This is the false premise found by the audit.

The assembler should use a deterministic safe extension, for example

```text
qSafe_N(u) = max 0 q_N(u),
zeta = 2 qSafe,
```

prove `qSafe_N(u)=q_N(u)` on `[s_N,t_N]`, and simplify the conclusion there. The factor two
matches `Psi^2 <= 2q` and is absorbed in `StochDom`.

### 4.2 Symmetric slow variation

The generic theorem's `hslow` is symmetric in the sense that it quantifies arbitrary ordered
pairs `u,v` in the window. T492's informal choice of a left neighbour, giving only
`q(v) <= q(u)`, does not by itself discharge this signature.

The required statement is nevertheless true. Since `etaT(E,u)` is proportional to `1-u`,

```text
q_N(v)/q_N(u) = (1-u)/(1-v).
```

T473's

```text
APrimeGeneralMovingWindowFloor.eventually_endpoint_floor
```

gives `1-t_N >= N^(-1)`. If `|u-v| <= N^(-16)` and `u<v`, then

```text
1-u <= (1-v)+N^(-16) <= (1+N^(-15))(1-v),
```

so

```text
q_N(v) <= (1+N^(-15)) q_N(u) <= N^epsilon q_N(u)
```

eventually for every fixed `epsilon>0`. For `v<=u`, monotonicity gives the bound with factor
one. The same statement holds for `qSafe` because it equals `q` on the window.

No public q-specific theorem with exactly this `hslow` signature was found. It is the smallest
deterministic producer still required by the chosen consumer; it may be proved locally in the
future assembler.

## 5. Why the `DominationHolder` routes are not minimal

The closest theorem in `RBM1D/Gauss/DominationHolder.lean` is

```text
RBM.Gauss.stochDom_timeIcc_of_holder_slow_hp.
```

It has analogous window, Hölder, polynomial lower-bound and slow-variation inputs, but it also
requires, at every time, unconditional integrability and a uniform moment estimate

```text
integral |Y_N(u)|^(2p) dP
  <= C N^(epsilon p) Phi_N(u)^(2p).
```

The `_dom` variants replace the fixed Good-event modulus by a `StochDom`-controlled random
Hölder constant, but retain those moment inputs. T495 does not supply these moments. Rebuilding
them would duplicate the fixed-time probability estimate and is strictly more work than using
`UnifDomIcc`.

The specialized `Eq45FlowInputs.stochDom_timeIcc_Lmax_of_unifDom'` is also the wrong interface:
its control is the random `Lmax` field and its event is `flowNetEvent`. The centered one-loop
route has deterministic control `q_N(u)` and needs only the norm Good for interpolation. Using
the specialized wrapper would introduce unrelated and currently unproved premises.

## 6. Both charges and one measurable event

T501 has now compiled the general-energy consequence that was only algebraically identified in
T492:

```text
APrimeGeneralMovingTwoChargeModulus.centeredTrace_false_eq_conj_true,
APrimeGeneralMovingTwoChargeModulus.centeredTrace_false_norm_eq_true.
```

They instantiate

```text
APrimeTwoChargeOneLoop.centered_block_trace_false_eq_conj_true
```

at the actual Hermitian flow. Thus the minus centered trace is the conjugate of the plus trace,
pointwise for the identical sample, time and block. There is no second probability event and no
loss in `N`, `W`, or time.

After the plus-charge continuum `StochDom` is eventually proved, use its `StochDom.highProb`
event at a slightly smaller exponent, absorb the fixed factor two, and transfer the bound to the
minus charge pointwise. If a measurable event is required, use

```text
Gauss.measCore,
Gauss.measurableSet_measCore,
Gauss.measCore_subset,
Gauss.highProb_measCore.
```

The same event is eventually nonempty by

```text
Gauss.nonempty_measCore
```

or `FastDecayFlow.nonempty_of_highProb`. This gives one measurable HighProb event for every
time, charge and block.

## 7. Collapsed and positive-length windows

The generic consumer accepts `s_N=t_N`. `netTime` clips the shifted net to `t_N`, and
`exists_netTime_close` assumes only `s_N<=t_N` and `t_N-s_N<=T`; it never divides by the window
length. The selector exchange also uses only `s_N<=t_N`, taking `s_N` as a default point.
Therefore the collapsed-window case is valid.

For nondegeneracy, T496 and T501 export respectively

```text
positive_length_same_good_trace_modulus_witness,
positive_length_same_good_twoCharge_modulus_witness.
```

These give one admissible positive-length moving window together with the same measurable,
HighProb, nonempty norm event and the modulus. T495's task specification separately requires a
same-parameter first-cell witness for `BoundsCore`, `Step1.Hyp`, `Cond272Reg`, and positive
length. The final assembler must instantiate the modulus theorem on that exact T495 tuple; two
unrelated existential witnesses would not establish simultaneous satisfiability. This exact
same-parameter check remains pending until T495 lands.

## 8. Paper placement and absence of a dependency cycle

In the paper, (5.39), (5.40), (5.41), and (5.42) are the propagated terms in the proof of the
first-pass estimate. The centered one-loop input occurs through (4.5), used in the proof of
(5.35), which is then fed into the `E(\widetilde G)` contribution (5.41). This route uses the
current window's Step-1 local law and current `BoundsCore` at `s_N`.

It does not use `APrimeSlot`, the first-pass output, or a `BoundsCore` for the next cell. Hence
the audited route does not create a circular dependency.

## 9. Exact missing Lean producers

The first missing stochastic leaf is the T495 selector theorem:

```text
forall v : N -> R,
  (forall N, v_N in [s_N,t_N]) ->
  LocalLawUnifIcc d E v v
    (fun N => sqrt(q_N(v_N)+W_N^(-1)))
```

or the exact equivalent singleton local-law interface allowed by the T495 specification.
Applying `detAvgIBP_stochDom_of_localLaw_complete` and `Psi^2 <= 2q` must then produce, for
every such selector,

```text
StochDom (P d)
  (fun N b omega => plusCenteredTrace(N,v_N,b,omega))
  (fun N b omega => 2*q_N(v_N)).
```

The smallest exact package directly consumed by the existing time-net theorem is currently
absent:

```text
UnifDomIcc (P d) s t
  (fun N u b omega => plusCenteredTrace(N,u,b,omega))
  (fun N u b omega => 2*qSafe_N(u)).
```

It should be produced by `unifDomIcc_of_forall_stochDom`, not by a new selection argument.
Alongside it, the assembler must provide the qSafe global-nonnegativity/equality lemmas and the
`N^(-16)` slow-variation lemma described above. T496/T501 already supply `hHol`, its HighProb
event, both-charge conjugation, collapsed-window coverage, and a positive-length modulus
witness.

After those inputs exist, `stochDom_timeIcc_of_unifDom` is sufficient. No new time-net engine,
moment theorem, or strengthened `Cond272Reg` premise is needed.
