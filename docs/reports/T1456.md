# T1456 — bulk restriction in (2.31)–(2.32)

**Primary verdict: incomplete, with a small explicit missing implication.** The accepted spectral identity is correct. Bulk delocalization plus a fixed-distance tail split suffices for the beta factor; all-spectrum delocalization is unnecessary. However, the manuscript does not display this split, its unrestricted maximum in the first part of (2.32) does not follow from the cited bulk estimate, and the proved weak OU local-law scale produces a fixed `N^{C tau_U}` loss in (2.31). The exact loss-free (2.31) throughout the OU interval remains conditional on a sharper bulk OU input. These are distinct issues, not a counterexample to the actual Gaussian model's stochastic claim.

This is a focused mathematical review, not a proof ticket, independent Lean acceptance, or closure of (2.29), (2.30), or StepTwoClaim. Only this report was written.

## 1. Exact claim and evidence

Use the paper's matrix dimension `N = L W > 0`, `L >= 3`. Fix `kappa > 0`, `C0 > 0`, a sufficiently small **fixed** `tau_U > 0`, `0 <= t <= N^{-1+tau_U}`, and

`|E| <= 2-kappa`, `|e-E| <= C0/N`, `z=e+i eta`, `N^{-1-tau_U} <= eta <= N^{-1+tau_U}`.

These are (2.19), (2.22), and the regime of (2.29). The signs of the two resolvents do not affect the pole moduli. Write

`w_beta(y)=|u_beta(y)|^2`, `P_j(z)=sum_beta |lambda_beta-z|^{-j}`,

`Q_y(z)=sum_beta |lambda_beta-z|^{-1} w_beta(y)`,

`A_y(z)=sum_alpha |lambda_alpha-z|^{-2}|M_{y,alpha}|`.

The accepted `RBM1D/Flow/GreenSpectralL1.lean:186,204` proves the exact expansion and

`|I_y(z)| <= N^{-1} A_y(z) Q_y(z)`.

Both sums are over the **whole spectrum**. Acceptance `docs/reports/V6-T1397-acceptance.md` explicitly preserves `Q_y`; it does not claim (2.31). The disputed replacement is `Q_y prec N^{-1} P_1`.

Theorem 2.2 has the indicator `1(lambda_k in [-2+kappa,2-kappa])`. Formula (2.10) itself is an unrestricted deterministic identity/inequality, but its useful local-law bound is available only at bulk real energies. `EnergyUniform.lean:1162–1170` retains exactly this indicator and takes `Transfer` and `Thm221NoELN'` for the original band model. It is not an OU delocalization theorem. Its proof already supplies the energy-net mechanism; no replacement theorem should be invented for that existing edge.

The manuscript proceeds directly from (2.31) to (2.32), without separating edge/outside-bulk eigenvalues. The split after (2.32) is the different, shrinking window `|lambda_alpha-E| <= N^{-1+c/6}`; its complement still contains the uncontrolled edge eigenvectors. Section 7.2, (7.27)–(7.30), proves the weak OU input only in `N^{-1+2 tau_U} <= eta <= N^{-1+c/3}`. The sentence after (2.26) permits restricting that proof to `eta=N^{-1+4 tau_U}`. Neither supplies sharp OU bulk delocalization at every `N^{-1+epsilon}` for the *same fixed* time interval. The remark about removing the eta restriction is a statement of a stronger result, not a proof of this additional input in the inspected argument.

T1407 is unrelated to this gap: `GreenComparisonSpectralProduct.lean:65` partitions eigenvalue **tuples into injective/colliding tuples**, not eigenvalues into bulk/tail sets.

## 2. Small deterministic repair of the beta factor

Set `J=[-2+kappa/2,2-kappa/2]`. Eventually `C0/N <= kappa/4`, so

`lambda notin J  ==>  |lambda-e| >= delta := kappa/4`.

On one sample suppose only

`w_beta(y) <= D_N/N` for every site `y` and every `lambda_beta in J`.

Completeness gives `sum_beta w_beta(y)=1`, hence **on that same sample**

`Q_y(z) <= (D_N/N) P_1(z) + delta^{-1}`.                         (A)

There is no tail eigenvector hypothesis. To absorb the additive constant, set

`R_z^2 = N^{-1} sum_beta |lambda_beta-z|^2`.

Cauchy–Schwarz, first for reciprocals and then for the distances, gives

`P_1(z)/N >= 1/R_z`,

so (A) implies

`Q_y(z) <= (D_N + R_z/delta) P_1(z)/N`,

`|I_y(z)| <= (D_N + R_z/delta) N^{-2} A_y(z) P_1(z)`.          (B)

This is the smallest deterministic replacement for the disputed arrow. The additive version (A) needs no norm or spectral-mass lower-bound premise. The relative version (B) needs only a subpolynomial second spectral moment to make its prefactor subpolynomial; a nonzero loop integrand is irrelevant.

For the Gaussian marginal, that moment is elementary internal work, not a new external theorem: put `F_N=N^{-1} Tr H_t^2`. With entry variances `v_xy`, `sum_xy v_xy=N` by (7.25), Jensen and scalar Gaussian moments give `E F_N^p <= C_p` for each fixed integer `p>=1`, uniformly in deterministic `t`. Indeed apply Jensen with weights `v_xy/N` to `|H_xy|^2/v_xy`, omitting zero-variance entries. Consequently `F_N prec 1`, and `R_z^2 <= 2F_N+2e^2+eta^2` gives `R_z prec 1`. This argument is not asserted to be a newly compiled Lean theorem.

Thus **sharp bulk** `D_N prec 1` recovers precisely (2.31), including its full-spectrum sums, without all-spectrum delocalization. At `t=0` the paper's Theorem 2.2 supplies this bulk input. Throughout the OU interval, the currently cited weak input only gives the following weaker conclusion.

## 3. OU loss and quantifier order

Let `eta_0=N^{-1+a tau_U}`, with `a=2` for the stated (2.26), or `a=4` if using the manuscript's explicitly restricted version. A simultaneous bulk local-law event

`max_{x, r in J} |G_t(r+i eta_0)_{xx}| <= q_N`

and (2.10) give `D_N=N eta_0 q_N=N^{a tau_U} q_N`. For `q_N prec 1`, (B) yields

`|I_y(z)| prec N^{-2+a tau_U} A_y(z) P_1(z)`.                 (C)

The fixed factor `N^{a tau_U}` cannot be hidden in `prec`: Definition 2.1 requires **every** arbitrarily small domination tolerance with `tau_U` held fixed. Choosing a smaller `tau_U` also shrinks the time interval and therefore does not prove the missing estimate on the original interval. The loss in (C) is compatible with the existing `C tau_U` allowance downstream; it does not demand a new analytic research program.

Fix `kappa,C0,tau_U` and deterministic time/energy sequences first. For every domination tolerance `epsilon>0` and failure exponent `D>0`, construct a common event at sufficiently large dimension. A polynomial energy net, a union bound with a larger failure exponent, and resolvent continuity give the needed simultaneous bulk-energy/site event from a uniform local-law producer. Intersect that event with the moment event for (B). Both estimates must hold at one `omega`; separate witnesses do not suffice. Uniform-in-deterministic-time probability estimates suffice for `sup_t E|I_t|`; a probability of a supremum over all times additionally needs a path/time-net argument. The accepted fixed-time/common-carrier OU sources do not by themselves produce a Brownian OU path or such a maximal event.

Lean's sequence index and matrix dimension must remain distinct: in `Gauss.Dims`, the latter is `B.size n=L(n)W(n)>0`, including at sequence index `n=0`. The spectral identities use the positive dimension; asymptotic powers/windows are imposed eventually with the chosen convention. No division by the sequence index at zero is justified.

## 4. What changes in (2.32)

The safe maximum is **restricted**:

`max_{alpha: lambda_alpha in J, y} |M_{y,alpha}| <= D_N+1`,

because `M_{y,alpha}=N sum_x S_xy w_alpha(x)-1` and `sum_x S_xy=1`. Therefore it is `prec N^{a tau_U}` under the weak OU input. The unrestricted maximum in (2.32) is **missing from these premises**; the elementary all-spectrum bound is of order `L`, not subpolynomial in general.

The exact consumer does not need that unrestricted maximum. Nonnegativity of `S` and completeness give the sharper aggregate bound

`sum_alpha |M_{y,alpha}| <= N sum_x S_xy sum_alpha w_alpha(x)+N = 2N`.

Consequently

`sum_{lambda_alpha notin J} |p_alpha(z)|^2 |M_{y,alpha}| <= 2N/delta^2`.   (D)

This is the appropriate far-spectrum tail for (2.29), independent of any edge delocalization. On the remaining bulk spectrum, use the restricted maximum and then the paper's shrinking QUE window. Thus a three-part split (QUE window / remaining bulk / outside fixed bulk) repairs the spectral bookkeeping; the last part is only `O_kappa(N)` before multiplication by `N^{-1}Q_y`. This report does not re-audit the separate QUE event/threshold conversion or claim the final expectation bound.

The two scalar pole sums in (2.32) are **not invalidated** by edge eigenvectors. On the same uniform coarse bulk local-law event, interval counting and a dyadic sum give, for `eta<=eta_0`,

`P_1 <= C_kappa N [q_N(eta_0/eta + 1+log N)+1]`,

`P_2 <= C_kappa N [q_N eta_0/eta^2+1]`.

To see the counting input, each eta_0-sized interval has at most `C N eta_0 q_N` eigenvalues by positivity of `Im Tr G`; cover larger bulk intervals by such intervals. Each dyadic shell contributes `O(N q_N)` to `P_1` and `O(N q_N/r)` to `P_2`; outside the fixed bulk use distance `delta` and at most `N` eigenvalues. Hence the stated forms `P_1 prec N^{1+C tau_U}` and `P_2 prec N^{2+C tau_U}` follow, with explicit admissible exponents `1+(a+1)tau_U` and `2+(a+2)tau_U`. For `r=N^{-1+c/6} >> eta_0`, the bulk portion with `|lambda-E|>r` similarly has pole-square sum `prec N/r`; require `a tau_U<c/6` and absorb the `C0/N` displacement. The fixed-bulk outside contribution is handled by (D), not by the unrestricted maximum.

## 5. Nondegenerate same-sample witness and nonimplication

There is a concrete band-supported matrix satisfying the repaired deterministic hypotheses while having a large tail `M`. Enumerate sites by their actual block/offset order. Isolate site `0` with diagonal value `3`, and on sites `1,...,N-1` put the adjacency matrix of the path (nearest-neighbor entries `1`, all other entries `0`). These entries respect the three-block variance support. Its eigenvalues are `3` and `2 cos(k pi/N)`, `1<=k<=N-1`. The path eigenvectors are

`u_k(j)=sqrt(2/N) sin(k j pi/N)`, `u_k(0)=0`.

Every bulk eigenvector has squared coordinates at most `2/N`, there are many bulk eigenvalues, the spectrum is simple, and the spectral norm is `3`. Thus `D_N=2` and bounded `R_z` hold simultaneously. At every fixed bulk margin and `eta_0>=1/N`, elementary spacing of the path eigenvalues gives `max_{x,r in J}|G(r+i eta_0)_{xx}|=O_kappa(1+log N)`, so the weak local-law-sized event is simultaneously satisfiable as well. Both `P_1` and `Q_y` are positive.

For the isolated eigenvector, at `y=0`,

`M_{0,tail}=N S_00-1=L/3-1`.

For the allowed growing-block geometry this is polynomially large despite sharp bulk delocalization. This refutes the proposed **deterministic implication** to the unrestricted maximum. It does not refute a stochastic estimate for the Gaussian distribution: these specially chosen matrices can be very rare.

The example is an actual Gaussian coordinate sample: assign the displayed real entries to the used positive-variance band coordinates of `Gauss.Xentry`, their imaginary coordinates zero, and zero to unsupported entries. On `ouProductMeasure`, for a fixed nonnegative time choose both band and GUE matrices to be this matrix divided by `exp(-t/2)+sqrt(1-exp(-t))`; their interpolation is the same nonzero matrix. Lift that pair by `ouCommonProjection` to the accepted common carrier. The fixed-size positive-variance coordinates admit neighborhoods of this sample, and the strict relaxed finite-dimensional bounds persist in a sufficiently small neighborhood; this is a support/satisfiability witness, not a high-probability producer. It uses one matrix and one event, including nonempty bulk and an active tail. No all-spectrum delocalization premise is introduced.
