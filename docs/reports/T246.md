## ⭐ 它查出的空真陷阱（本单最重要的发现）

**把 `Kd ζ δ δ' Msz Pb esz` 从常数改成了 `ℕ → ℝ`**。理由：常数版**不可满足**——`commErr` 带一个显式因子 `L`，当 `B.L N → ∞` 时没有固定的 `δ'` 能压住它，除非 `Pb = 0`（即把被估的量取成 0）。这是换线过程中唯一的真陷阱。

另外三处被迫的形状变化：
1. 衰减现在是**张量 `A` 自己**的，而不是 `Q_u ∘ A` 的——因为 `fastDecay_lkT_of_mem_lkGood` 供给的正是前者；
2. 新增 `hAMI/hAMF/hPsC/hAME`（**事件上**的先验 size）、`hZI…hZEint`（核值的确定性包络 `Env N` + 可积性）、`hPr/hEnvPr/hEnvPrE`。

## 工单预判的两个难点**都不存在**

- 区间可积性：`intervalIntegral_le_of_le_const`（`Gauss/MomentDuhamelRhs.lean:291`）**根本不要可积性假设**，而且 `Env`/`pr` 不依赖 `u`，所以不需要 `u ↦ Env·pr^{1/(2p)}` 的区间可积性。
- 量词次序：`hEnvPr : ∀ p, 1 ≤ p → ∀ᶠ N in atTop, Env N * pr N ^ (1/(2p)) ≤ cE N` 在 `p` 固定之后于 `filter_upwards` 里消费，`cE N` 再被吸进 `hnum` 的 `errKer716` 槽，算术行保持原形状。
