`Cond272Reg`, `BoundsCore`, and `0 < δ ≤ min 1 (c/100)`. Fix `p ≥ 1`, and
set `deltaWeight = δ/100` as in T995. Eventually in `N`, whenever the first
positive cell is active, for every `a : LoopArg ... 2`, with
`v = cutNetPt s (targetMesh D) N 1`, the literal integral satisfies

```text
∫_(s N)^v positiveTimeCrossBudget E D (deltaWeight δ) s t N 1 p a u du
  ≤ (15*p/2) K N^(13δ/640 − 2D − 8) ratR(E,s N,N,v)^(-2)
    + (15*p/2) N^(-2D − 10),
```

where `K = crossProfilePointwiseConst`. The `N` cutoff is common to all
outputs `a`.

`v - s_N = N^(-(4D+18))` eventually. Hence

`N^(13δ/640 − 2D − 8)` and `N^(-2D − 10)` in the statement. The proof
handles `u=0` through the totalized budget definitions and uses the exact
integral `∫_(s_N)^v u^(-1/2) du = 2(√v−√s_N)`, whose interval integrability
also holds when `s_N=0` or the interval is degenerate.
