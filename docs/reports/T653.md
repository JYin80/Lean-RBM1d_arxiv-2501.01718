## Proof and condition audit

### Finite effective support

For each `c : I`, the condition `gvar d c.1 ≠ 0` gives
`volume ≪ gaussianReal 0 (gvar d c.1)` by
`gaussianReal_absolutelyContinuous'`.  This transports `IsOpenPosMeasure` from Lebesgue measure to
each factor; `Measure.pi.isOpenPosMeasure` supplies the finite product instance.  Finally,
`P_map_restrict`, `Finset.measurable_restrict`, and `Measure.map_apply` pull positive mass back to
the cylinder in `Ω d`.

Finiteness is encoded by `I : Finset (Coord d)`.  Nonemptiness is the explicit hypothesis
`U.Nonempty`.  Nondegeneracy is the exact subtype hypothesis
`∀ c : I, gvar d c.1 ≠ 0`.  For `I = effectiveCoords d J`, that hypothesis follows definitionally
from subtype membership in the filter, so `support_cylinder_pos` requires no extra variance
assumption.  Taking `U = Set.univ` witnesses the open/nonempty hypotheses for every finite `J`;
for any nonempty effective subtype, ordinary open boxes give the intended genuinely restrictive
cylinders.

### Zero-variance coordinates and the hybrid cylinder

`zero_variance_coord_ae_zero` pushes the coordinate evaluation through `P_map_eval`; after
rewriting `gvar = 0`, `gaussianReal_zero_var` identifies its law with `dirac 0`.
`Filter.eventually_all_finset` combines these statements over finite `J`.

`zeroFix_measurable` expresses `zeroFix` as a finite intersection.  Each zero-variance branch is
the measurable equality event `{ ω | ω c = 0 }`; each nonzero-variance branch is `univ`.
Therefore

~~~text
supportCylinder d J U
  = ((effectiveCoords d J).restrict ⁻¹' U) ∩ zeroFix d J
~~~

is measurable whenever `U` is measurable.  Since `zeroFix d J` holds almost surely,
`Measure.measure_inter_eq_of_ae` proves that this intersection has exactly the mass of the
effective cylinder.  Combining that equality with `effective_open_cylinder_pos` proves strict
positivity.  This explicitly fixes zero-variance coordinates at `0` in the full event instead of
silently discarding them.

### Local retention and the rejected global statement

From `C ⊆ R` one gets `Rᶜ ⊆ Cᶜ`.  Equality `P Cᶜ = P Rᶜ`, finiteness, and
`Measure.measure_inter_eq_of_measure_eq` give

~~~text
P (Rᶜ ∩ U) = P (Cᶜ ∩ U).
~~~

The left side is zero because `U ⊆ R`; removing the null part `U ∩ Cᶜ` leaves
`P (U ∩ C) = P U`.  The direct specialization independently uses
`Measure.measure_toMeasurable_inter` for `C = (toMeasurable P Rᶜ)ᶜ`.

This does **not** imply `P (R \ C) = 0`: the theorem cannot be specialized with `U = R` unless
`R` is measurable.  Concretely, take a two-point type with the trivial measurable space and its
probability measure (outer measure `1` on every nonempty set).  For a proper nonempty,
nonmeasurable `R`, `toMeasurable P Rᶜ` is the whole space, hence
`C = (toMeasurable P Rᶜ)ᶜ = ∅`.  Then `C ⊆ R` and `P Cᶜ = P Rᶜ = 1`, while
`P (R \ C) = P R = 1`.  Local retention remains true because the only measurable subset of that
proper `R` is `∅`.  Thus the local theorem is consistent with, and cannot prove, the rejected
global null-difference claim.
