## Same-resident proof

For fixed admissible `δ,ν`, T418 supplies `HighProb` for its literal
`good τ' δ ν`.  T428 supplies `HighProb` for
`APrimeFirstCellJGAllTime.good` without an additional parameter.  Applying
`HighProb.inter` gives `HighProb` for `sharpCommonEvent`, and
`HighProb.nonempty (by simp)` selects

```lean
ω ∈ APrimeFirstCellJGAllTime.good N ∩
    APrimeFirstCellEGAllOutputRunning.good τ' δ ν N.
```

The proof never selects another sample after this point.

From `ω`'s T418 projection, the code unfolds the common event, applies
`commonEvent_to_dynamic_support`, and then
`APrimeSupportRunning.good_subset`.  The first raw-good field is the
same-sample bound

```lean
‖Xmat d N ω‖ ≤ N.
```

This is fed to the universal theorem
`APrimeFirstCellCommon.eventually_active_weight_two_one`, whose conclusion
is quantified over every `ω` satisfying that norm bound and every `p`.
After rewriting `firstCellS τ' = 0`, it gives the actual weight-one field in
`positiveSharpPlateau` for every `p`.

The T418 projection also gives T413's source common event.  With
`0 < u₂ ≤ firstCellT τ' N`, it defines the actual `TimeIcc` point and applies
`APrimeFirstCellSourceAllTime.sourceEvent_of_common` to the same `ω`.

From `ω`'s T428 projection,
`APrimeFirstCellCTDecay.eventually_all_time_jG_le_two_on_good` gives
the block cap for every real `r ∈ [0,1/2]`.  The package retains this full
statement and also records its instances at `r = 0` and `r = u₂`; the latter
uses `u₂ ≤ firstCellT τ' N ≤ 1/2`.

T418's old `positiveAllOutputPlateau` is used only for the three
sample-independent endpoint facts `2 ≤ cutNetTop`, `0 < u₂`, and
`u₂ ≤ firstCellT`.  Its resident, weights, and all-output field are discarded.

## Nondegeneracy and exponent compatibility

The witness is nonempty because it is selected by `HighProb.nonempty` from
the literal intersection.  It is nondegenerate for this package because
`u₂ > 0`, the actual `k = 2` prefix exists, and its actual weight is exactly
one for every `p`.  Consequently the source and sharp bounds are evaluated
at a positive endpoint on an active prefix, rather than being vacuous facts
on an empty event or inactive cutoff.

T428's failure estimate remains
`4 L_N exp(-15 W_N) ≤ N^(-D)`, using only
`W_N ≥ N^(5/8)` and `W_N L_N ≤ N`.  `HighProb.inter` asks both factors for
a stronger polynomial exponent before its two-event union bound; it creates
no relation between `W`, `δ`, and `ν`.  The source loss is exactly
`APrimeFirstCellEGAllOutputRunning.sourceLoss ν` throughout.

The `jG` field is definitionally the block observable
`APrimeJG.jG (sample d) 0 N r ω (ell N r) (etaT 0 r) 60`.  No inference about
the distinct loop observable `Step2.jS` is made.
