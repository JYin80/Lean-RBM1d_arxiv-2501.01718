# T1163 — all low moments on the early general-moving mesh

## Verdict: mathematical preflight PASS; exact all-`p` early-range theorem proved

Added `RBM.APrimeGeneralMovingLowMomentAllEarly.eventually_low_all_early` in
`RBM1D/Gauss/APrimeGeneralMovingLowMomentAllEarly.lean`. For fixed admissible
`δ` and each `p : ℕ`, there is one `C > 0` and one eventual-in-`N` set such
that the literal order-`p` actual widened Gaussian moment is bounded by
`C N^(δp/2)` at every active target-mesh index `k ≤ N^4`. This includes `p=0`
and indices `k=0,1,2` as well as `2 ≤ k ≤ N^4`. It is an early-range static
moment result only.

## Mathematical preflight and exact producer match

I checked the public statements and proof inputs of accepted T1155/T1156 and
T1151/T1152 directly in their source files. Their common fixed context is
`E,D,c,s,t,δ₀`, the assumptions `|E|<2`, `60≤D`, `0≤s≤t<1`, `c>0`,
`Cond272Reg (band Dims.exampleGrow) E s t c`, and
`BoundsCore (sample Dims.exampleGrow) E s`. Both use the same
`Dims.exampleGrow` sample, Gaussian law `(band Dims.exampleGrow).P`, target
mesh `APrimeGeneralMovingMesh.targetMesh D`, `canonicalR`, order-`p`
`widenedW` with `N₀=1`, observable `Step2Moment.jSnorm`, truncation
`cutTrunc (N^(2δ))`, endpoint `cutNetPt`, and rate `N^(δp/2)`. The T1151
producer takes the same `δ₀` explicitly; no parameter conversion or change
of event, law, weight, cutoff, sample, mesh, or endpoint is used.

T1155 gives `k=0` unconditionally and `k=1` under exactly
`1 ≤ cutNetTop ... N`, with one common constant and eventual set for all
`p`, including zero. T1151 gives every active `2 ≤ k ≤ N^4` for `p≥1`,
with its selected high order and constant fixed before eventual `N`. For
positive `p`, the new theorem takes the sum of the two producer constants,
intersects their eventual sets, and splits the active indices into `k=0`,
`k=1`, and `k≥2`. For `p=0`, it uses
`actual_zero_order_widened_integral`, which gives exactly one for every
`N,k`; the resulting bound holds for every `N` with `C=1`. Thus each fixed
`δ,p` has one constant and one eventual set uniformly over the whole active
early range.
