## Loss schedule and preflight

For `0 < λ ≤ min (1/10000) (c/10000)`, the module sets

```text
δweight = λ,  xi = λ,  δcap = 2λ,
zetaSrc = zetaCtr = tauG = h = λ/1000.
```

`freeLoss_schedule_room` proves the source and center losses are at most
`tauG`, `tauG ≤ δweight/16` and `tauG ≤ δcap/16`, both weight and cap losses
are at most `c/20`, and the stronger route room
`h + 2 δcap + 2/15 < 1`. It also proves the far-term exponent inequality

```text
3 (tauG + 2 δweight) - c/30 ≤ 2h.
```

This is the required margin for the literal T613 transition cap, whose
polynomial factor is `N^(tauG + 2 δweight) ratR^4`. The cap-room condition
used by T613 follows from the stronger `h + 2 δcap + 2/15 < 1` statement.

The scalar preflight follows the actual definitions in
`APrimeGeneralMovingTransitionPrefixGradient` and
`APrimeGeneralMovingQVAbsorption`. Write
`r = etaT(E,s_N)/etaT(E,u)`, `A = B.scale E N u`, and `J` for the T613
transition block cap. On the existing regularity assumptions,

```text
A ≥ N^(c/10) r^27,
J ≤ K N^(tauG + 2 δweight) r^4,
K = 3 + 9 exp(sqrt 3) (16 exp(1)^2 + 1).
```

Thus `A^(-1/3) J^3 ≤ K^3 N^(3(tauG+2δweight)-c/30) r^3`, which is at most
`K^3 N^(2h) r^3`. The near source is bounded using
`cNear2 ≤ N^h` and `(ell_u/ell_s)^5 ≤ r^3`; the `2/W` residual is absorbed
because `N^(2h) eta_u^(-1) r^3 ≥ 1`. Consequently the actual raw rate obeys

```text
transitionRawCoordRate ≤ C0 N^(2h) eta_u^(-1) r^3,
C0 = 6 + 1200 K^3.
```

In the stored normalization, `ratR = r ≥ 1`, the threshold is at least one,
and `ratR^(-2) sqrt(transitionRawCoordRate)` cancels the `eta_u` and ratio
factors to `sqrt(C0) N^h eta_s^(-1/2)`. The two remaining inverse powers of
`ratR`, the threshold, and each `sqrt(u_j) ≤ 1` only decrease the bound.
Taking the finite supremum and its `exp(1)` factor gives the public constant
`freeLossRateConst = exp(1) sqrt(C0)`.

This intermediate estimate matches the scale suggested by paper
(5.40)–(5.42). It is a deterministic scalar bound on the already defined
T613 raw-QV producer; it does not assert the stopped paper conclusions from
(5.43)–(5.44).
