# T302 — integration audit for accepted A′ modules T292/T293/T297/T298

## Verdict and scope

The four accepted modules compile together and contain the intended bounded
results: T292 pins the actual fixed-endpoint coordinate, drift, moment and
evolved QV; T297 proves its `TestFunT₁` bridge; T298 proves the pointwise
generator comparison for that same coordinate/QV; T293 proves the widened
block-level `J` exponent margins and conditional QBd comparisons. None
proves the near cross comparison, an integrated evolved-QV budget on a
common Good/soft-support event, `hfamily`, or `APrimeSlot'`. T294's
`APrimeQVRateTime.lean` and T300's `APrimeQVBridge.lean` are downstream,
in-flight modules and are **not** needed in this import closure.

The four files cannot be pushed alone on a clean checkout: their imports
reach eleven currently untracked A′ modules. The complete source closure
can be staged without touching T294 or T300, provided the scheduler includes
the dependency set below, applies the root imports, and reruns the root
build on that staged snapshot. The existing root build by itself does not
validate that staged snapshot.
