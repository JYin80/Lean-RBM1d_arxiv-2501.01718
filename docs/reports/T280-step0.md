# T280 step 0 — read-only audit of the first `APrimeSlot'` witness

Scope: `J = Step2Moment.jSnorm X E D s`, `lev ≡ 1`, `Θ ≡ 1`. No Lean file was edited, no probe or build was claimed, and no commit was made. `docs/CODEX-TICKETS.md` §3 describes T280, but the current active `docs/TASKS.md` has **no T280 row**; hence there is no same-number full specification to read.

## Exact target and quantifiers

`APrimeSlotFields.APrimeSlot'` has three fields: one fixed family `Good : ℕ → Set Ω`, an `APrimeHypOn … Good`, and `HighProb B.P Good`. The target in `thm221NoEL_of_inputs_mergedOnAll_aprime'` is uniform in every admissible `E,s,t,c,D`; `D ≥ 60` is chosen before the slot. At a fixed window and `D`, the **same** `APrimeHypOn` must work for

```
∀ δ, 0 < δ → δ ≤ δ₀ → ∀ p : ℕ, 1 ≤ p →
  ∀ᶠ N in atTop, ∀ k ≤ cutNetTop s t mesh N, Hstep δ p N k.
```

This is the premise of `APrimeModel.aprimeHypOn_of_stepBound''` (`APrimeModel.lean:611`); `weightedMoment_of_stepBoundPos''` handles `p = 0`. The final producer would be `⟨Good, aprimeHypOn_of_stepBound'' hm (fun _ => rfl) H Hstep, hGood⟩`, where `H` is `APrimeSlotFields.aprimeHypOn_jSnorm_event` (`APrimeSlotFields.lean:442`). **No declaration currently constructs this tuple for `jSnorm`.** The existing `APrimeSlotFields.aprimeHypOn_jSnorm_exampleGrow` is conditional on the weight's four fields and `WeightedMoment`; it is not the desired completed witness.

The `init` deleted from `APrimeSlot'` is the *stochastic initial bound* (2.69), produced in the assembly from `BoundsCore` by `APrimeSlotFields.stochDom_jSnorm_init_of_boundsCore` and `jsNormDom_of_aprimeSlot'`. It is distinct from the numerical `hinit` required by `oneStep_of_slots` below.

## One `Good`, one `(δ,p,N)` order?

* **High probability of a fixed intersection:** T274 gives `APrimeSlotFields.goodEv`, `measurableSet_goodEv`, `highProb_goodEv`, and `highProb_goodEv_of_stochDom`. `Gauss.traceMomentBound_gauss` + `Gauss.highProb_normX_le` give the norm event. T267/T273 give `EarlyQVRateEv.stochDom_quadVar_grid` / `_det` from `BoundsCore`, `Step1.Hyp`, and regularity; `StochDom.highProb` gives an S3 event **after a positive exponent `τ` is chosen**. `Step1Producer.step1Hyp_slot`/`step1Hyp_gauss_grid_first` supply the Step 1 hypothesis in the corresponding model settings. Finitely many **fixed** measurable high-probability events can be intersected; T274's `goodEv_subset` preserves the modulus. A measurable-set proof for the *specific* S3 level event is not named in T267–T276, though `APrimeHypOn.good_meas` requires one.
* **Quantifier mismatch:** `APrimeSlot'.Good` is chosen once for the whole `∀ δ ∀ p ∀ᶠ N` moment assertion. The S3 event obtained by `StochDom.highProb` is `{qvGrid ≤ N^τ s3Grid}` and depends on `τ`; the slot budgets need a loss small relative to the current `δ` (T276 takes `δ/32`). Since `δ` can approach zero after `Good` has been fixed, T274's intersection lemma does **not** furnish a single `Good` with all these `δ`-dependent S3 bounds. It only furnishes `Good_τ` for each fixed `τ`. This is an unclosed quantifier issue, not a proof of impossibility: a bad-event split, a stronger common event theorem, or an interface change could resolve it.
* **The complement of `Good`:** `WeightedMoment` and `Hstep` integrate over the whole probability space. T275's `crossPart_le_of_S5` requires `hwDoff : ∀ ω ∉ Good, wD(ω)=0`. The cited `quadVar_softW_pow_eq_zero_of_outside_band` proves derivative zero **outside the cutoff transition band**. It does not prove zero outside an unrelated norm/S3/Step 1 intersection: a point may leave `Good` while its soft maximum lies inside the transition band. Restricting the actual differentiable weight by `1_Good` also needs a new regularity argument. Thus the proposed same-event use of the current T275 lemma has no provider. A complement estimate with a polynomial envelope and `HighProb` is another possible route, but is not assembled here.
* **Uniformity in `k`:** T267's probability statement is indexed over all grid points; `Hstep` likewise puts `∀ k` **inside** `∀ᶠ N`. T276 accepts envelope families `G p N`, `fitLhs p N` without `k`; to use it, the evolved QV, drift and initial-moment estimates must be uniform over every `k` at the same `N`. The existing per-cell analytic declarations do not yet establish that uniform statement.

**Verdict:** the T274 deterministic part and the finite-event high-probability calculus are compatible on the first cell, and T276 has the correct `p` before `∀ᶠ N` order. The full `APrimeSlot'` witness for `jSnorm` is **not yet derivable** from T267–T277. In addition to T277's sharp evolved-QV gap, the concrete prefix weight, `hdom`, the numerical `hinit`, the `p`-independent `W` interface, the `hwDoff`/Good relation, and the fixed-Good versus `δ`-dependent S3 event must be resolved. No joint satisfiability certificate for all of these inputs on one nondegenerate first cell is currently present; the separate witnesses in T270/T271/T274/T275/T276 use different observables, weights, or events.
