# T498 — actual first-cell canonical-weight drift integral budget

## Result

Added `RBM1D/Gauss/APrimeFirstCellDriftIntegralBudget.lean`.

For fixed `p`, `alpha`, and `beta` before the eventual `N`, the module
integrates T470's pointwise absorbed drift bound for every active moving
cell `k >= 1` and every output `a`.  With

```text
v = cutNetPt 0 transitionMesh N k
A(r) = momNormW(P, canonicalWeight, p, driftAt(r)),
```

the resulting `actualDriftIntegralBudget` is

```text
integral_0^v A(r) dr
  <= v * (absorbedRate alpha N v + N^(-beta)),

2 * integral_0^v A(r) dr
  <= absorbedRate alpha N v + N^(-beta).
```

The second estimate uses the first-cell bound `v <= 1/2`; it introduces no
additional factor in `p`, `W`, or time.

## Inputs and deterministic integration

The pointwise estimate is exactly T470's
`actualDriftNormAbsorbed`.  The bridge to T494's `A` only unfolds the two
accepted canonical-weight definitions and uses
`minkowski_delta_eq_fixedDelta` to identify their literal deltas.

`intervalIntegrable_A` reconstructs the accepted canonical `WeightC1`
package and applies
`APrimeDriftTimeFamily.intervalIntegrable_momNormW_driftAt`.  Then
`intervalIntegral.integral_mono_on` integrates the constant upper bound.
Nonnegativity of the absorbed rate follows directly from its factorization;
positivity of `xRate v` uses `Step2.etaT_pos'` and `v < 1`.

No integrated-family moment, `hfamily`, `APrimeSlot`, cross/QV term,
next-cell `BoundsCore`, or new stochastic assumption is introduced.
