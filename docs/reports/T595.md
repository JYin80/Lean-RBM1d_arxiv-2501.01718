# T595 — General-moving initial-term compatibility audit

## Exact verdict

**Verdict: T488 already proves the required mathematical initial branch, but the
repository still lacks one public net-indexed adapter at the literal current
differentiable-weight signature.**  No new estimate is needed.  The smallest
dispatch-ready addition is a theorem which invokes T488 once with the constant
weight `1`, uniformly in all moving endpoints and output coordinates, and then
uses `0 <= w_{N,k} <= 1` to pass to the actual smooth prefix weight.  This is a
pure indexing/weight-monotonicity adapter; it must not import or use a
first-cell theorem as its general producer.

Thus the initial branch is not a blocker in the mathematical sense, but a
future general-moving generator should not claim the literal all-`k` `hinit`
until this adapter (or the identical argument inline) is present.

## Claim card and paper check

The source PDF `paper/250520-YinJun-v2.pdf`, formula (5.39) (printed p. 57), is

```text
(U_{s,t,sigma} o (L-K)_{s,sigma})_a / T_{t,D}(|a_1-a_2|)
  \prec (ell_t/ell_s)^2 1(|a_1-a_2| <= ell_t^*) + 1.
```

The paper explicitly says that the final order-one term comes from the tail
estimate (7.2).  In the current A-prime normalization the coordinate is divided
once more by `R_v^4`, where

```text
R_v = Step2Moment.ratR E s N v
    = etaT E (s N) / etaT E v.
```

The exact Lean object is
`APrimeAssembly.initialEvolvedNormAt` (`APrimeAssembly.lean:211`):

```text
norm (Uker(s_N,v) (Step2.lk ... s_N) a)
  / (Step2.tT ... v (zdist ...) * R_v^4).
```

This is the normalized initial value of the current Duhamel coordinate for
`sigma = Step2.sigPM`.  Indeed
`APrimeDriftTimeFamily.driftScale` (`APrimeDriftTimeFamily.lean:65`) is
definitionally

```text
Step2.tT ... v (zdist ...) * (etaT E s_N / etaT E v)^4,
```

and `APrimeDriftTimeFamily.flowY_coordAt` (`:111`) identifies the evolving
coordinate with the same `Uker` row divided by that scale.  At `r=s_N` and
`sigma=Step2.sigPM`, the remaining identification with
`initialEvolvedNormAt` is the same definitional reduction used by the
first-cell files, but no first-cell theorem is needed or authorized here.

T488's accepted theorem
`APrimeGeneralMovingInitialHinit.eventually_initial_hinit`
(`APrimeGeneralMovingInitialHinit.lean:179`) proves, for fixed `delta>0` and
fixed `p>=1` before `eventually N`, uniformly in every
`v : TimeIcc s t N` and every two-loop output `a`,

```text
momNormW P W p (initialEvolvedNormAt ... v a)
  <= initTerm (N^(delta/8)) R_v (slotXi' (N^(delta/8))) / R_v^4.
```

By `APrimeAssembly.initial_slot_scale_eq`, this is exactly

```text
N^(5 delta / 32) * R_v^(-2).
```

There is no extra `W`, `N`, spatial-tail, or time-ratio loss.

## Why a thin adapter is still needed

T488 indexes its arbitrary measurable weight by

```text
TimeIcc s t N x LoopArg (d.L N) 2.
```

The actual differentiable weight is instead

```text
APrimeSmoothWeightActual.weight d E D delta s t mesh
  2 p N k (APrimeSmoothWeightActual.canonicalM d s t mesh N),
```

so it is indexed by `N,k` and the desired consumer quantifies

```text
eventually N, forall k <= cutNetTop ..., forall a, ... .
```

One cannot apply T488 separately after choosing `k`, because that would allow
the eventual threshold to depend on a selector.  Nor is there a current public
inverse which recovers `k` from an arbitrary `TimeIcc` endpoint for the weight
parameter.

The uniform solution is already validated by the accepted first-cell pattern,
but the general theorem must reproduce the two-line argument rather than use a
first-cell declaration:

1. apply T488 once with `W = 1`, obtaining one eventual threshold uniform in
   every `(v,a)`;
2. after that threshold, choose any active `k`, set
   `v_k = cutNetPt s (targetMesh D) N k`, and use integral/rpow monotonicity
   with `APrimeSmoothWeightActual.weight_nonneg` and
   `APrimeSmoothWeightActual.weight_le_one`.

The required unweighted integrability is already
`APrimeAssembly.integrable_initialEvolvedNormAt_pow_gauss`.  No stochastic
event and no union over `k` are introduced.

## Smallest dispatch-ready adapter

Suggested new file:
`RBM1D/Gauss/APrimeGeneralMovingInitialBudget.lean`, importing only
`APrimeGeneralMovingInitialHinit`, `APrimeGeneralMovingMesh`, and
`APrimeSmoothWeightActual` (plus whatever those imports already expose).

The literal target should include the following endpoint constructor because
T488's endpoint-uniform theorem is indexed by the subtype `TimeIcc s t N`.
The underlying `initialEvolvedNormAt` itself accepts a real endpoint.

```lean
noncomputable def targetCutNetPt {s t : ℕ → ℝ} (D : ℝ)
    (hst : ∀ N, s N ≤ t N) (N k : ℕ)
    (hk : k ≤ cutNetTop s t (APrimeGeneralMovingMesh.targetMesh D) N) :
    TimeIcc s t N :=
  ⟨cutNetPt s (APrimeGeneralMovingMesh.targetMesh D) N k,
    MomentDuhamelCut.netFinset_subset_Icc (hst N)
      (APrimeGeneralMovingMesh.targetMesh_pos D N) _
      (CutHypTheta.cutNetPt_mem_netFinset hk)⟩

theorem eventually_initial_hinit_smooth_target
    {E D c delta : ℝ} {s t : ℕ → ℝ}
    (hE : |E| < 2) (hD : 60 <= D)
    (hs0 : ∀ N, 0 <= s N)
    (hst : ∀ N, s N <= t N)
    (ht1 : ∀ N, t N < 1)
    (hc : 0 < c)
    (hreg : Cond272Reg B E s t c)
    (hB : BoundsCore (sample d) E s)
    (hdelta : 0 < delta) (p : ℕ) (hp : 1 <= p) :
    ∀ᶠ N : ℕ in atTop, ∀ k,
      ∀ hk : k <= cutNetTop s t
        (APrimeGeneralMovingMesh.targetMesh D) N,
      ∀ a : LoopArg (d.L N) 2,
        MomentDuhamel.momNormW B.P
          (APrimeSmoothWeightActual.weight d E D delta s t
            (APrimeGeneralMovingMesh.targetMesh D) 2 p N k
            (APrimeSmoothWeightActual.canonicalM d s t
              (APrimeGeneralMovingMesh.targetMesh D) N))
          p
          (APrimeAssembly.initialEvolvedNormAt (sample d) E D s N
            (targetCutNetPt D hst N k hk) a)
        <=
          APrimeOneStep.initTerm ((N : ℝ) ^ (delta / 8))
            (etaT E (s N) /
              etaT E (targetCutNetPt D hst N k hk))
            (APrimeInit.slotXi' ((N : ℝ) ^ (delta / 8))) /
          (etaT E (s N) /
            etaT E (targetCutNetPt D hst N k hk)) ^ 4
```

The intended quantifier order is exactly

```text
E,D,c,s,t,delta,p fixed; eventually N; forall active k; forall a.
```

An optional generic helper may replace the hard-coded smooth weight by
`w : forall N k, Omega d -> Real` with hypotheses `AEStronglyMeasurable`,
`0 <= w`, and `w <= 1`.  It is not mathematically stronger.  The literal
smooth theorem above is preferable for the generator because it prevents an
accidental endpoint/index mismatch.  In the recommended constant-one route,
only pointwise nonnegativity and the upper bound by one are used for the final
weight monotonicity step.

## Weight and endpoint audit

The active endpoint is

```text
v_k = cutNetPt s (targetMesh D) N k.
```

`targetMesh D` is positive for every `N`
(`APrimeGeneralMovingMesh.targetMesh_pos`), and
`cutNetPt_mem_netFinset` plus `netFinset_subset_Icc` gives
`v_k in [s_N,t_N]`.  Thus T488 applies at the same endpoint used by
`coordAt`, `driftScale`, the evolved QV, and the drift/cross consumers.

The smooth prefix weight at index `k` uses `Finset.range k`, hence the previous
net points `j<k`, while the Duhamel coordinate terminates at `v_k`.  This is the
intended fixed-in-time prefix weight for the `s_N -> v_k` Duhamel computation;
it is not an evaluation at `v_{k-1}` or at the ambient `t_N`.

The order-dependent widened weight uses the same `N,k`, sample, and net times.
`APrimeSmoothWeightActual.widenedW_le_weight_canonical` proves it is bounded
by the actual smooth weight.  The different cutoff thresholds/supports are
irrelevant to the initial term: the initial estimate uses only nonnegativity
and the upper bound by `1`; it never uses `W_dom`, a plateau event, or a support
identity.  Support alignment matters later for the derivative/cross and final
family transfer, not for `hinit`.

## Exact declarations for the future generator

The future generator package should use these declarations, with no
first-cell producer:

- `APrimeGeneralMovingInitialHinit.eventually_initial_hinit` — one uniform
  unweighted (`W=1`) initial bound;
- `APrimeAssembly.integrable_initialEvolvedNormAt_pow_gauss` — integrability
  needed for weight monotonicity;
- `APrimeSmoothWeightActual.weight_nonneg`, `weight_le_one`,
  `canonicalM_pos`, and, where the generator needs regularity,
  `continuous_weight` / `weightC1`;
- `APrimeGeneralMovingMesh.targetMesh_pos`, `cutNetPt_mem_netFinset`, and
  `MomentDuhamelCut.netFinset_subset_Icc` — construction of `v_k`;
- `APrimeDriftTimeFamily.flowY_coordAt` and the definitions of
  `driftScale` and `initialEvolvedNormAt` — identification of the left
  Duhamel endpoint with the T488 object;
- `APrimeSmoothWeightActual.widenedW_le_weight_canonical` only for the later
  widened-family transfer, not to justify the initial estimate itself;
- `APrimeAssembly.initial_slot_scale_eq` if the consumer wants the simplified
  `N^(5 delta/32) R_v^(-2)` form.

## Conditions which remain external

The adapter still assumes exactly T488's external conditions:

1. the concrete model `d = Gauss.Dims.exampleGrow`;
2. `|E|<2`, `60<=D`, `0<=s_N<=t_N<1`, `c>0`;
3. `Cond272Reg B E s t c` and the current-left-endpoint
   `BoundsCore (sample d) E s`;
4. `delta>0` and fixed `p>=1`.

For a direct application of T488 with an arbitrary caller-supplied weight,
measurability and pointwise `0<=w<=1` remain caller conditions.  The
recommended adapter instead applies T488 only to the measurable constant-one
weight; its later comparison with the literal smooth target weight uses only
`weight_nonneg`, `weight_le_one`, and unweighted integrability.

Everything else in the general-moving moment route remains outside this
ticket: the drift and cross budgets, the integrated evolved-QV budget, the
pointwise derivative package, Minkowski assembly, coordinate-family sum,
Lyapunov/order transfer, widened-family estimate, `WeightedMoment`/`hfamily`,
`APrimeSlot'`, A-prime, the six-step chain, and paper closure.
