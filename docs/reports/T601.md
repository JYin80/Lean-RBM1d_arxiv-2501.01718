# T601 — post-T597 general-moving cross-seam preflight

## Verdict

T603 appeared concurrently during this audit and now composes T599 with T590
on positive actual smooth support.  Conditional on acceptance of the exact
T603 source hash audited below, the single smallest remaining dispatchable
theorem is therefore a **thin transition-to-current-QV adapter**.  It should
replace T603's positive actual-weight premise by the literal smooth-transition
premise and conclude only the pointwise `qvAt` bound needed for
`crossPart_active_le_jointEvent.hQgood`.  Replaying T599 and T590 in another
module would now be duplication, not the smallest next step.

It must **not** be advertised as a cross-term theorem.  T597 supplies a
same-sample running `jSnorm` cap, but it does not bound the literal
`prefixGradient`.  Therefore no honest specialization of
`crossPart_active_le_jointEvent` is dispatchable yet.  The first missing
analytic premise for that specialization is a general-moving favorable
prefix-gradient producer on the same `commonEvent ∩ transition`, uniform over
all stored indices `j < k`, including `j = 0`.  In addition, the general-moving
five-field measurability/integrability package and a polynomial all-sample
joint envelope are not yet public producers.

This audit proves no paper formula, cross budget, `hfamily`, `APrimeSlot'`,
A-prime estimate, six-step chain, or paper closure.

## Exact power and endpoint ledger

Keep `deltaWeight` in the actual differentiable weight and transition.  Keep
`deltaCap = deltaWeight + xi` in the T603/T599 widened support and every
underlying T590 occurrence.  These parameters must never be identified.

T599's direct support loss is exactly

```text
N^(2 * xi).
```

Downstream, T590 uses

```text
Jbar = 1 + N^tauG *
  (9 * exp(sqrt 3) *
    ((4 * exp 1 + 2) * N^(2 * (deltaWeight + xi)) * ratR_u^4) + 2).
```

Thus the exponent in the cap's leading `N`-monomial changes exactly from
`2*deltaWeight` to `2*deltaWeight + 2*xi`.  Since the far rate contains
`Jbar^3`, its pure leading monomial acquires exponent increment `6*xi` after
squaring the root profile; equivalently the corresponding square-root
monomial in the later cross rate acquires increment `3*xi`.
The near source does not acquire this buffer:

```text
4 * N^zetaSrc * eta_u^(-1) * cNear2(W,ell_u)
  * (ell_u/ell_s)^5 + 2 * W^(-1).
```

The exact T590 root remains

```text
ratR_u^(-2) * ratR_v^(-2) *
  (sqrt(nearSourceRate + 2*W^(-1)) *
      (xiK * 1(dist <= 6*ellStar_v) + 256*exp(3)*W^(-D))
   + sqrt(1200 * eta_u^(-1) * A_u^(-1/3) * Jbar^3) * xiK).
```

The theorem keeps the square of this **whole sum**.  It does not expand or
drop cross terms.  The two `W^(-D)` mechanisms remain distinct, and the
repaired `2*W^(-1)` is retained.  Both running endpoints
`u = s_N` and `u = v_k` are included.  At the root level their endpoint
normalization is `ratR_u^(-2) ratR_v^(-2)`; the `qvAt` conclusion squares it.

T597's sharper transition-local cap


has no `W` or time-ratio loss, but it is not an input accepted by T590's

## Quantifiers, satisfiability, and acyclicity

The parameter order is fixed losses and window first, then eventual `N`, then
`k`, the identical `omega`, transition membership, running `u`, and `a`.
The buffer `xi` is fixed before `N`; it may be arbitrarily small but may not
depend on `N`.  The future cross order `p` is also fixed before all
probability/complement thresholds.

The deterministic room assumptions are jointly nondegenerate.  T603 already
contains a witness obtained from T590's explicit positive-cell witness for
`deltaCap`, setting

```text
deltaWeight = deltaCap / 2,
xi          = deltaCap / 2.
```

Then `xi>0`, `deltaWeight+xi=deltaCap>0`, and all T590 room inequalities are
unchanged.  The proposed adapter adds only eventual `2 <= N` and a conditional
transition premise.  T599 itself adds no event hypothesis.

What is **not** presently witnessed is a resident of the exact intersection

```text
commonEvent E D s t zetaSrc zetaCtr tauG N
  ∩ transition d E D deltaWeight s targetMesh N k canonicalM.
```

T597 records the same limitation: the common event is genuinely inhabited
and the smooth transition is genuinely nonconstant, but no declaration puts
one sample in both.  The proposed result is therefore an honest conditional
localization theorem, useful in the event split even if the favorable
intersection happens to be empty.  It must not claim an intersection
witness.  If scheduling interprets the nonvacuity rule as requiring a literal
joint resident for every conditional localization theorem, then no such
transition-QV theorem may be accepted yet; the smallest missing premise is
exactly a positive-cell `commonEvent ∩ transition` inhabitance theorem.  Under
the already accepted T592/T597 convention, this is a recorded non-claim, not
an implementation blocker.

The proposed module is a leaf over T603 and `APrimeCrossJointSplit`.  T603 is
already a leaf over T590/T599; `APrimeCrossJointSplit` is an upstream producer
and does not import T603.  The new module imports no drift, moment-family,
slot, six-step, or paper-closure consumer, so it introduces no dependency
cycle.
