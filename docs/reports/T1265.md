The exact Lean calculation is:

1. At `p = 1`, public T615 gives `∫ g ≤ ∫ profile + (v-s_N)N⁻¹` and the
   required interval integrability. T1251 bounds that exact profile by
   `(12/Im(m_E)+1) N^(δ/8) ratR(v)^(-2)` on all active cells.
2. For the complement, `v-s_N ≤ 1`. Cond272 and the band dimension bound give
   `ratR(v)^30 ≤ scale(v) ≤ N`; since `ratR(v) ≥ 1`, `ratR(v)^2 ≤ N`, so
   `N⁻¹ ≤ ratR(v)^(-2) ≤ N^(δ/8)ratR(v)^(-2)` for eventual `N ≥ 1`.
   Therefore the actual-drift coefficient is `12/Im(m_E)+2`.
3. T1253's full positive-time cross proof gives coefficient
   `(15/4)(|crossProfileBudgetConst E|+2)`. T1253's exported theorem packages
   its coefficient existentially, although its proof constructs this exact
   value. This module repeats that proof with the constructed coefficient
   exposed in the theorem type, so the combined public coefficient is fixed
   and depends only on `E`.
4. The exact closed-cell integrability inputs are T615's `g` integrability
   and T1123's positive-time cross-budget integrability, as used by T1219.
   `intervalIntegral.integral_add` combines the literal integrands on
   `[s_N,v]`; the proof preserves the same `N,k,a`, schedule, and endpoint.
   The zero-length cell remains included.
