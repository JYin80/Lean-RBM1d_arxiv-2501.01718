## Exact claim and proof audit

```lean
∀ (W k : ℕ) (π : PermΩ W),
  @measurableAtom (PermΩ W) (prefixSigma W k) π =
    {ρ | ρ ∈ prefixCell W k π}
```

The explicit measurable-space argument is essential. T711 defines `prefixSigma W k` as `generateFrom (prefixCylinders W k)`, with generators `{π | π i = v}` for `i.val < k`; its ambient measurable space on `PermΩ W` is `⊤`. The theorem uses the generated prefix sigma algebra, not that ambient `⊤`.

The atom-to-cell inclusion applies `measurableAtom_subset` to T732's `measurableSet_prefixCell` and T711's `mem_prefixCell`. For the reverse inclusion, membership in the actual cell means coordinate agreement at every `i.val < k`; hence `π` and `ρ` have identical membership in every generating cylinder. `MeasurableSpace.forall_generateFrom_mem_iff_mem_iff` extends this to every set measurable in `prefixSigma W k`. Unfolding `measurableAtom` then puts `ρ` into every prefix-measurable set containing `π`. This closes the universal inclusion without using a conditional expectation, conditional law, or the desired atom identity as an input.
