## Result

The module defines the actual centered trace for either charge:

```text
F_sigma,b(u) =
  trace ((Gsig(Hflow d N u omega, zt E u, sigma)
    - mSigma E sigma) Eblk_b).
```

`centeredTrace_true_eq` identifies the true-charge definition with
T496's plus trace. The energy-generic theorem
`APrimeTwoChargeOneLoop.centered_block_trace_false_eq_conj_true`,
instantiated with the actual Hermitian `Hflow`, proves

```text
F_false,b(u) = conj(F_true,b(u)).
```

`centeredTrace_false_norm_eq_true` records the resulting pointwise norm
equality at every energy, size, time, block and sample.

`eventually_centeredTrace_sub_le` transfers T496's modulus to both
charges. Under exactly

```text
|E| < 2,
forall N, 0 <= s_N <= t_N < 1,
c > 0,
Cond272Reg (band d) E s t c,
```

it proves eventually, on the identical fixed event

```text
Good_N = {omega | ||Xmat d N omega|| <= N},
```

simultaneously for every `u,u' in [s_N,t_N]`, charge `sigma`, and
block `b`,

```text
||F_sigma,b(u)-F_sigma,b(u')||
  <= 2 N^5 sqrt(|u-u'|).
```

Conjugation commutes with subtraction and preserves the complex norm.
Consequently the transfer introduces no event, probability, `N`, `W`,
or time factor. The theorem includes collapsed windows `s_N=t_N` and
`u=u'`; in the latter case both sides are zero.
