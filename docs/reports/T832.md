## Mathematical and Lean audit

`RBM.eventually_forall_of_forall_sequences` has exactly these data: arbitrary
`α` and `A0 A1 P : ℕ → α → Prop`; a base `b` with `A0 n (b n)` at every `n`
and `A1 n (b n)` eventually; and the premise that **every** sequence `f`
with all-index `A0` and eventual `A1` has eventual `P`. Its conclusion is
eventual `∀ z, A0 n z → A1 n z → P n z`, including all values admissible at
the *current* index. No nonempty-type instance is silently assumed: the base
supplies an inhabitant.

I independently reconstructed the contradiction argument. If the conclusion
fails, the bad-index set where some `z` satisfies `A0 ∧ A1 ∧ ¬ P` is
frequently true. Choice selects such a `z` at each bad index; at every other
index the constructed sequence uses `b n`. Thus `A0` holds at **all** indices,
including `n = 0` and any finite prefix. `A1` holds at bad indices and holds
eventually at the other indices because it holds eventually for `b`. The
sequence premise gives eventual `P`, which intersects the frequently bad set;
at an index in that intersection, the chosen value both satisfies and fails
`P`. This checks the exact quantifier order and shows no circular appeal to
the desired uniform conclusion.

`RBM.eventually_uniform_bool_satisfiable` uses `A0 = A1 = True`, base
`b n = false`, and `P n z := n ≠ 0 ∨ z = false`. At `n = 0`, both Boolean
values are admissible and `P 0 true` is false. For every `n ≥ 1`, `P n z`
holds for both values. Hence every admissible sequence satisfies the premise,
while the conclusion is genuinely eventual and not an all-index assertion.
