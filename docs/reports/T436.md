## Running statement

The public running predicate has the exact form:

```lean
def sharpRunningMovingProfile (τ' δ ν : ℝ) : Prop :=
  ∀ᶠ N : ℕ in atTop,
    ∀ ω ∈ APrimeFirstCellSharpCommonEvent.sharpCommonEvent τ' δ ν N,
    ∀ N0 p k m : ℕ, N0 ≤ N → 1 ≤ p → 1 ≤ m →
      1 ≤ k → k ≤ cutNetTop (fun _ => 0) (firstCellT τ')
        APrimeSmoothTransition.transitionMesh N →
      0 < APrimeSupportRunning.weight δ (firstCellT τ')
        N0 p N k m ω →
      let v := cutNetPt (fun _ => 0)
        APrimeSmoothTransition.transitionMesh N k
      0 < v ∧ v ≤ firstCellT τ' N ∧ v ≤ 1 / 2 ∧
        (∀ q ∈ Set.Icc (0 : ℝ) (1 / 2),
          APrimeSupportRunning.jG N q ω ≤ 2) ∧
        ∀ r ∈ Set.Icc (0 : ℝ) v,
          APrimeSupportRunning.jG N r ω ≤ 2 ∧
            ∀ a : LoopArg (d.L N) 2,
              sharpMovingProfileAt ν N ω v r a
```

Its producer is premise-free apart from positivity of the already chosen
first-cell parameter:

```lean
theorem eventually_sharp_running_moving_profile {τ' δ ν : ℝ}
    (hτ' : 0 < τ') : sharpRunningMovingProfile τ' δ ν
```

The proof combines three eventual statements: T415's
`eventually_running_scales`, T428/T414's
`eventually_all_time_jG_le_two_on_good`, and `N ≥ 2`.  For each real
`r ∈ [0,v]`, the endpoint lemma gives `r ∈ [0,1/2]`; T418's common-event
projection gives the actual `SourceEvent` at this `r`; the scale ledger and
`jG(r) ≤ 2 ≤ N` then feed `qvAt_full_absorbed`.

The closed interval includes both `r = 0` and `r = v`.  No fixed endpoint is
substituted.  The hypothesis is the actual positive-`δ` weight of the
prefix, and `k=0` is deliberately outside this statement.
