## Proof

For the T416 quarter-net `V`, the strict inequality `8 < ‖M‖` and
`‖M‖ ≤ 2 * blockBilinearMax M V` imply the strict inequality
`4 < blockBilinearMax M V`.  Unfolding the finite supremum therefore supplies a pair
`v,w ∈ V` with `4 < ‖v* M w‖`.  Thus the strict block event is contained in the finite union of
the strict scalar events at threshold `r = 4`.

T420 bounds every such scalar event by
`4 * exp (-(3/2) * W * 4^2) = 4 * exp (-24W)`.  The finite union bound and
`(V × V).card = V.card^2 ≤ 9^(4W)` give the stated result.  No independence among pair events is
used.

The file also proves measurability of the strict block-norm event from
`APrimeFirstCellJGAllTime.measurable_xBlock`, and records both a general `W = 1` specialization and
the concrete endpoint `N = 0`, using T420's `exampleGrow_width_zero`.
