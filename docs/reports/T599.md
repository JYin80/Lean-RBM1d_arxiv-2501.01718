# T599 — buffered actual-smooth support to canonical widened support

## Files

- Added `RBM1D/Gauss/APrimeSmoothToWidenedSupport.lean`.
- Added this report.
- No other source, scheduling, root-import, git, or remote state was changed.

The new module has one direct import only:

```lean
import RBM1D.Gauss.APrimeSmoothWeightActual
```

It imports no first-cell QV result, T584 module, common-event module, or moment assembly.

## Public declaration

```lean
RBM.APrimeSmoothToWidenedSupport.
  eventually_actualWeight_pos_implies_widenedW_pos
```

For arbitrary `d : Gauss.Dims`, fixed `E,D,delta,xi`, moving `s,t,mesh`, and fixed
`p >= 1`, under

```text
|E| < 2,
s_N <= t_N < 1,
0 < mesh_N,
0 < xi,
```

the theorem proves, eventually in `N`, uniformly for every
`k <= cutNetTop s t mesh N` and every `omega : Gauss.Ω d`, that positivity of

```text
APrimeSmoothWeightActual.weight d E D delta s t mesh
  2 p N k (APrimeSmoothWeightActual.canonicalM d s t mesh N) omega
```

implies positivity of the literal canonical widened weight at `delta + xi`, with the
same `N`, `k`, `omega`, net, sample `Gauss.sample d`, and `jSnorm` observable.

There is no assumption `0 <= delta`; the argument only requires `N >= 2`, so every
real `delta` is allowed.

## Proof ledger and exact loss

Write `S` for the literal actual `prefixSample` and `H` for the literal hard
canonical prefix soft maximum.

1. Since `p >= 1`, positivity of the actual `2p`-th power forces its base cutoff to
   be nonzero. The identity `cutChi x = 0` for `x >= 2` then gives

   ```text
   S < 2 * threshold(delta,N)
     = 16 * exp(1)^2 * N^(2*delta).
   ```

2. For each stored `j < k`, net membership gives
   `s_N <= cutNetPt_j <= t_N < 1`. On the identical sample and matrix,

   ```text
   jSnorm(cutNetPt_j) <= smoothJS(cutNetPt_j) <= S.
   ```

   The first inequality is `APrimeSmoothPrefix.jSnorm_le_smoothJS`; the second is
   `Step2Bootstrap.le_softMax` for the actual outer prefix. No event or sample change
   occurs.

3. `Step2Bootstrap.softMax_le` and
   `APrimeWeight.card_calib_top` for `canonicalR` give

   ```text
   H <= exp(1) * S
     < 16 * exp(1)^3 * N^(2*delta).
   ```

4. The sole eventual absorption is exactly

   ```text
   4 * exp(1)^2 < N^(2*xi).
   ```

   Using `N^(2*(delta+xi)) = N^(2*delta) * N^(2*xi)`, this yields

   ```text
   H < 4 * exp(1) * N^(2*(delta+xi)).
   ```

   Therefore the widened cutoff argument

   ```text
   H / (2 * exp(1) * N^(2*(delta+xi)))
   ```

   is strictly below `2`; elementary cutoff algebra makes its cutoff positive, and
   so does its `2p`-th power.

Thus the exact new loss is `N^(2*xi)`. There is no `W` loss, time-ratio loss, event
loss, or alteration of the prefix/sample.

## Boundary cases

- `k = 0` is included in the theorem and covered by the same proof. Both finite soft
  maxima are empty; the actual and widened weights simplify to `1` on their
  one-plateaux. No pointwise QV statement is made.
- `k = cutNetTop` is retained. Every stored index is `j < k`, and its net point lies in
  `[s_N,t_N]`.
- `p = 0` is deliberately absent. The proof reads positivity back through a nonzero
  power, so `p >= 1` is essential. This module makes no claim about invoking T584 or a
  QV profile in the `p = 0` branch. (The isolated support implication at `p=0`
  would be trivial because both zeroth powers equal `1`.)
- Only `N >= 2` is imposed eventually. Small `N` is irrelevant to the asymptotic
  conclusion.

## Dependency acyclicity

The proof uses only definitions and deterministic lemmas already below this module:

- cutoff values and positivity below `2`;
- `jSnorm_le_smoothJS`;
- `le_softMax` and `softMax_le`;
- `card_calib_top` for `canonicalM`/`canonicalR`;
- the elementary limit `N^(2*xi) -> infinity`.

It does not import or use `Cond272Reg`, `BoundsCore`, `commonEvent`, T584, T591,
`hfamily`, `WeightedMoment`, `APrimeSlot'`, or any stochastic conclusion. Hence the
bridge is acyclic with respect to every intended consumer.

## Satisfiability

The hypotheses are simultaneously and non-vacuously satisfiable: for example take

```text
E = 0, D = 0, delta = 0, xi = 1,
s_N = 0, t_N = 1/2, mesh_N = 1, p = 1.
```

This has a positive-duration moving-window instance, positive mesh, `|E| < 2`, and
`xi > 0`. For every `N >= 2`, every sample `omega`, and the exact boundary prefix
`k = 0`, `APrimeSmoothWeightActual.weight_zero_prefix` gives actual weight `1`; the
literal empty-prefix definition gives widened weight `1`. This witnesses the support
premise and conclusion on the exact objects without importing a first-cell or QV
resident. No additional pointwise size hypothesis was introduced, so there is no
empty-truth risk of the kind caused by all-sample stochastic bounds.

## Non-claims

This ticket does **not** prove or assert:

- the false same-`delta` implication from positive actual smooth weight to positive
  widened weight;
- any reverse numerical comparison at `delta + xi`;
- a QV, drift, cross, or actual-weight norm budget;
- a common-event, moment, stochastic-domination, or probability conclusion;
- `hfamily`, `APrimeSlot'`, A-prime, the six-step chain, or paper closure.

Any later consumer must keep `deltaWeight = delta` in the differentiable weight and
`deltaCap = delta + xi` in the support/QV cap; identifying them would recreate the
same-support error found in T594.
