## Smallest single-block mathematics

Fix `W≥1`, `π : Equiv.Perm (Fin W)`, and real
`λ_j=semicircleLambda W hW j.val j.isLt`. Define the matrix with **positive**
phase and row `j`, column `a` by

```text
F(j,a) = W^{-1/2} χ_a(j),   D(j,j)=λ_(π j),   A=Fᴴ D F.
```

For this orientation, orthogonality gives `FᴴF=FFᴴ=I`. Independently of
orthogonality, real `λ` and `isHermitian_conjTranspose_mul_mul` give
`A.IsHermitian`. The exact entry is

```text
A(a,b) = (1/W) Σ_j conj(χ_a(j)) χ_b(j) λ_(π j)
       = (1/W) Σ_j χ_(b-a mod W)(j) λ_(π j).
```

The second equality needs a separately proved modular-character identity
bridging `Fin W` representatives and exponent periodicity. `b-a` is the
**positive-phase** mode. With Mathlib's negative-phase `ZMod.dft`, it becomes
`a-b`. For `a=b` the mode is zero; for `a≠b` it is nonzero. No sign reversal
may be hidden in a conjugation or permutation reindexing.

For `0≤u≤1/2`, set

```text
d_j(u) = √u λ_(π j) - i(1-u),
g_j(u) = d_j(u)^{-1} = semicircleFlowKernel u λ_(π j).
```

The imaginary part of `d_j` is `-(1-u)≤-1/2`, so every `d_j≠0` including
`u=0`. Finite matrix algebra then gives

```text
√u A - i(1-u)I = Fᴴ diag(d_j) F,
(√u A - i(1-u)I)^{-1} = Fᴴ diag(g_j) F,
[(√u A - i(1-u)I)^{-1}](a,b)
  = (1/W) Σ_j χ_(b-a mod W)(j) g_u(λ_(π j)).
```

This is the **exact** `permutationFourierSum` for the mode `b-a`, after the
character bridge. The inverse identity can be proved with ordinary matrix
inverse laws; a general continuous functional calculus (continuous functional
calculus，连续函数演算) theorem is not required for this rational function. The
actual `√u A-i(1-u)I=Fᴴdiag(d)F` rewrite, normalized Fourier matrix
orthogonality, and character bridge remain **uncompiled**. Hence the exact
resolvent-entry theorem for the literal `A` is still open.

At `W=2`, the scratch theorem proves the actual quantile table is nonconstant:
`λ_0<λ_1`. With `π=id` and the normalized two-point Fourier matrix
`2^{-1/2}[[1,1],[1,-1]]`, elementary multiplication gives
`A(0,1)=(λ_0-λ_1)/2≠0`; this is a concrete nonconstant block. The
quantile inequality compiled; this displayed **matrix** evaluation has not
been compiled. The witness does not depend on T914's synthetic W8192 table.
