# T294 — time integrability of the actual evolved QV rate

## Model audit

The rate in this ticket is exactly `APrimeDriftTimeFamily.qvAt d E D N σ a s v r ω = Gauss.quadVar d N (coordAt … r) (Gauss.Hflow d N r ω)`. T292 proved it definitionally equal to T275's `qvRateEvolved` for this normalized coordinate; T298 uses the same quantity in its pointwise generator comparison. No Good indicator or freely chosen quadratic-variation field occurs in the new theorems.

For fixed finite `N`, endpoint `v`, and coordinate `a`, `Gauss.bddC2C_ukerObsT` bounds the raw first matrix derivative by its finite kernel-row norm. `Gauss.continuous_ukerRow` and compactness of `[s,v]` give a uniform row constant. The actual `K` window bound is `Gauss.exists_bdd_Kval_Kprim`, and `Gauss.window_le_abs_im` supplies the common resolvent distance. Since `driftScale>0` is independent of running time and matrix, `exists_bdd_fderiv_coordAt` obtains a deterministic first-derivative envelope for the normalized coordinate. `exists_bdd_qvAt` applies `Gauss.norm_coordD1_le` to the finite `usedCoord` sum and returns `0≤qvAt(r,ω)≤C` for all `r∈[s,v]` and all samples, with finite `C` depending on the fixed model data. This is a coarse regularity envelope, not the sharp (5.42) bound.

## Measurability and integrability

`continuous_coordAt_on_window` proves joint continuity of the actual coordinate in time and matrix on the window subtype, using `Gauss.differentiableAt_ukerObsT_pair` and the genuine Gaussian `K` derivative. `measurable_qvAt_on_window` then applies Mathlib's `measurable_fderiv_with_param` to that jointly continuous family. The jointly continuous Gaussian map `(r,ω)↦Hflow_r(ω)` supplies the evaluation point; applying the resulting derivative to each fixed `Bmat` direction and summing proves joint Borel measurability of the actual QV in `(r,ω)`.

For a fixed measurable sample weight `0≤w≤1`, `measurable_rateNormW_qvAt_window` integrates the jointly measurable function `w(ω)|qvAt(r,ω)|^p` in the sample variable and applies the continuous nonnegative `p`th-root map. `intervalIntegrable_rateNormW_qvAt` combines this time measurability with the deterministic QV envelope and `APrimeModel.rateNormW_le_of_le_on`; the compact time subtype has finite induced Lebesgue measure. The theorem holds for `|E|<2`, `0≤s≤v<1`, and `1≤p` at each fixed finite `N`.

`intervalIntegrable_rateNormW_prefixSoftW` instantiates the weight with the actual `APrimeWeight.prefixSoftW` driven by `Step2Moment.jSnorm`. Its measurability is supplied by `APrimeWeight.measurable_prefixSoftW` and `APrimeSlotFields.measurable_jSnorm`; `softW_nonneg` and `softW_le_one` give the required range. `first_cell_empty_prefix_witness` compiles the strict window `E=D=0`, `s=0`, `v=1/2`, `p=1`, `k=0`: the empty-prefix weight is identically one, and the actual rate is interval integrable there.

## Scope and verification

This proves only regularity and finite-size time integrability. It does not give the quantitative Good-event (5.42) rate, a common Good/soft-weight support event, or the near cross comparison; those remain separate inputs for the A′ closure.
