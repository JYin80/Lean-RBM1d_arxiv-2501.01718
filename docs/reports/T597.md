## Proof and exact constants

The proof uses exactly the upstream route requested in T592.

1. A private arbitrary-`E`, arbitrary-`s` version of the stored-net
   comparison applies `APrimeSmoothPrefix.jSnorm_le_smoothJS`, rewrites the
   matrix flow with `smoothJSMatrix_flow`, and inserts the selected entry into
   the outer finite `softMax`.  Thus every stored index `j < k` is at most the
   actual `prefixSample`.
2. Strict-transition membership supplies

   ```text
   prefixSample / threshold(delta,N) < 2,
   threshold(delta,N) = 8 * (exp 1)^2 * N^(2*delta),
   ```

   hence every stored net value is strictly below

   ```text
   16 * (exp 1)^2 * N^(2*delta).
   ```

3. The same `omega` is projected through
   `commonEvent_subset_rawCarrier` and then
   `sourceGood_subset_good`, giving membership in
   `APrimeGeneralMovingGoodMesh.good N`.  The general-moving deterministic
   field package supplies the modulus and target-mesh fineness

   ```text
   Kmod = 2*D + 7,
   gamma = 1/2,
   N^Kmod * (1 / targetMesh(D,N))^gamma <= 1.
   ```

   `CutHypTheta.prefix_of_modulus` therefore adds at most exactly `1` on the
   whole closed prefix.
4. Eventually `N >= 1`; because `delta > 0`,
   `1 <= N^(2*delta)`.  Absorbing the additive mesh error gives exactly

   ```text
   (16 * (exp 1)^2 + 1) * N^(2*delta).
   ```

There is no `W` power, no `ratR` factor, and no additional time power in the
conclusion.  The only `N` power is `N^(2*delta)`; the intermediate modulus
power `N^(2*D+7)` is canceled by the target-mesh fineness bound.

- The assumptions are exactly arbitrary `E,D,c,s,t`, `|E|<2`, `60<=D`,

  membership, transition membership, `u`, and closed-prefix membership.

  `u=cutNetPt ... k` are covered.
- `k=0` is excluded exactly by `1<=k`.  The theorem makes no pointwise claim
  for the empty prefix.
