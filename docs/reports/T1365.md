# T1365 — arbitrary-Dims free-loss cross split preflight

## Verdict: FAIL (scope/API obstruction)

The requested result cannot be stated and proved with the current exported
event-split chain while retaining the literal common event and actual
positive-time budget. This is an API-level scope failure, not a counterexample
to the dimension-uniform inequality one might prove after generalizing that
chain. I did not create a Lean module, weaken the result to
`Dims.exampleGrow`, or add assumptions standing in for the target bound.

The first non-generic dependency is the common-event interface. The imported
`APrimeGeneralMovingCommonSources.commonEvent` has type
`Set (Gauss.Ω APrimeGeneralMovingCommonSources.d✝)`, where that private `d✝`

this type. Thus the existing literal event cannot be used as an event on
`Gauss.Ω d` for arbitrary `d`.

The remaining chain has the same specialization. The accepted pointwise split

`APrimeFreeLossCrossAssembly.eventually_integral_positiveTimeCrossBudget_le_of_uniform_absorbed_root`;

## Same-event nondegeneracy check

The accepted example-dimension witness in T1305 realizes `E = 0`, `D = 60`,
`s ≡ 0`, a positive-length window, `Cond272Reg`, `BoundsCore`, `Step1.Hyp`, an
eventually nonempty common event, an active first positive cell, and a strictly
positive actual smooth weight on the same sample. It does not establish
membership in the actual transition event or a nonzero value of the actual
cross observable. High probability of the common event is not high
probability of its intersection with the transition.

The separate result
`APrimeGeneralMovingTargetTransitionExists.eventually_exampleGrow_target_transition`
supplies a strict-transition scalar sample at `k = 2`, but its statement makes
no common-event claim. These two witnesses cannot be combined into a
same-sample certificate. Moreover,
`APrimeGeneralMovingEarlyPrefixTransitionExclusion.eventually_early_prefix_transition_exclusion`
shows that on its stated `E = 0`, `D = 60`, first-cell window, the strict
transition is excluded for every sample in the norm event whenever `k ≤ N^10`.
The literal common event is a subset of that norm event. For the target's
weight loss `lambda`, instantiate the exclusion with its schedule parameter
`delta = 100 * lambda`; the target small-loss bounds imply
`delta ≤ min(1, c/100)`. Thus at the witness's early positive cell `k = 1`
(and `k = 2` when active), the exact common-event/transition intersection is
empty eventually. The actual `jointRate`, which is an indicator of the strict
transition, vanishes there. This rules out the requested nonzero observable
certificate on those early cells; it does not claim exclusion at later
prefixes `k > N^10`.

Accordingly, the required same-sample positive-window certificate carrying a
nonzero actual observable and positive probability for the common-event /
transition intersection remains unavailable; the existing statements either
give common-event membership with positive weight or transition membership
separately, and the early-cell instance is contradicted by the exclusion.
These example-dimension facts are independent of the arbitrary-Dims API
obstruction above.
