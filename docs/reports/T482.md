# T482 — first-cell derivative-to-integrated-moment preflight

## Verdict

The derivative-to-moment consumer is exactly
`MomentDuhamel.weightedMinkowski_of_deriv_le`
(`Gauss/APrimeGronwall.lean:404`).  With T480's current working-tree
pointwise theorem, T469's literal `Bfull`, and T470's drift estimate, every
analytic premise of this consumer is either already public or is elementary
glue.  The one genuine missing quantitative premise is a **weighted rate
bound for the actual uncut `qvAt`**.  The repository has all of its inputs,
but no theorem currently composes them into

```text
rateNormW(P,w,p,qvAt(r))
  <= currentRate(delta,delta/16,alpha,N,v,r) + N^(-beta).
```

Consequently this audit does not claim an integrated moment estimate or
`hfamily`.  The bounded next Lean ticket should prove only that QV rate split,
its time integral, and the resulting square-root budget.  After that ticket,
the remaining Minkowski assembly is routine glue.

T480 is still a separate live ticket.  At the time of this audit its module
and report are present but untracked.  The module now exports the eventual
uniform positive-time derivative bound, the `r=0` and `k=0` branches, and the
positive `k=2` resident (`Gauss/APrimeFirstCellMomFlowDerivExact.lean:190-347`).
This report audits that current artifact but does not accept it or make its
status part of T482.

`bd6f7e32bee30a28202e147742b28e88e85bdd6a691ae8fa89e3aedae22bbb43`.

These displays contain no smooth prefix weight, moment order `p`, `Bfull`,
`momFlowDeriv`, or Minkowski estimate.  They therefore do not justify the
first-cell integrated-moment calculation.  The coefficient calculation below
comes from the checked Lean interfaces.  In particular, the sentence in the
T472 report relating the `Bfull` factorization to paper (5.37)-(5.42) is only
an analogy; the algebraic T472 conclusion remains correct independently of
that citation.

`weightedMinkowski_of_deriv_le` gives

```text
momNormW(P,w,p,Y(v))
  <= momNormW(P,w,p,Y(0))

     + sqrt((2p-1) * integral_0^v g(r) dr).
```

Its exact premises and their present status are:

## Recalculated coefficient and time budgets

Write

```text
delta = 1/2000,
tau   = delta/16,
R     = xRate(v) = eta_0/eta_v,       1 <= R <= 2.
```

All statements below fix `p >= 1` and the small event exponent before the
eventual threshold in `N`.

### Cross term

T476 supplies the exact consumer form

```text
crossPart(r) <= 2p * phi(r)^((2p-1)/(2p)) * Bfull(r).
```

The raw T361 coefficient is

```text
(1/(2 sqrt r)) * (2p)^2 * (15/8) = 15 p^2/(4 sqrt r),
```

whereas

```text
Bfull(r) = 15p/(8 sqrt r) * [b sqrt(q(r)) + Eall rho^(1/(2p))].
```

Hence the outer `2p` in `momFlowDeriv_le` gives the raw coefficient exactly;
`BcrossActual = 2p*Bfull` must not be used as `Bc`.  T469 proves
(`APrimeFirstCellFullCrossBudget.lean:316`)

```text
integral_0^v Bfull(r) dr
  <= C_p N^(alpha-2delta) R^(-2),

C_p = (15p/4) * (18432 sqrt(2)/exp(1) + 1).
```

Therefore the Minkowski cross contribution is exactly bounded by

```text
2 C_p N^(alpha-2delta) R^(-2).
```

No extra factor `2p` occurs after this integration.

### Drift term

T470's actual norm estimate (`APrimeFirstCellDriftCoefficientAbsorbed.lean:334`)
and deterministic integral theorem (`:303`) give, for any paid exponent
`beta>0`,

```text
A(r) <= endpointCoefficient(delta,2alpha,N,v,r) + N^(-beta),

integral_0^v endpointCoefficient dr
  <= v * C_d N^(2alpha) R^(-2),

C_d = coefficientConstant * (sqrt 2 + 1).
```

Using `v <= 1/2`, the full Minkowski drift contribution satisfies

```text
2 integral_0^v A(r) dr
  <= C_d N^(2alpha) R^(-2) + N^(-beta).
```

The missing Lean item is only the monotone interval-integral composition
with the already available integrability of the actual `A`.

### Quadratic variation

T448 gives only the favorable-event pointwise weighted inequality
(`APrimeFirstCellQVWeightedGood.lean:26-63`):

```text
w(omega) qvAt(r,omega) <= w(omega) currentRate(r)
```

on the one literal `sharpCommonEvent`.  T451 supplies integrability of
`w |qvAt|^p`.  The reusable support-aware split is
`weighted_norm_le_of_weighted_event`
(`APrimeFirstCellDriftNormSplit.lean:30`).  The all-sample complement input is
`eventually_qvAt_le_poly` (`APrimeQVGlobalPoly.lean:436`), which at
`E=0,D=60,Keta=1` gives

```text
0 <= qvAt <= 2^21 N^136.
```

After absorbing the fixed coefficient into `N^137`, the `HighProb` property
of the same sharp event pays, for fixed `p` and arbitrary `beta>0`,

```text
2^21 N^136 rho^(1/p) <= N^(-beta)
```

eventually.  This yields the mathematically valid but currently uncompiled
rate estimate

```text
g(r) <= currentRate(delta,tau,alpha,N,v,r) + N^(-beta).       (QV-rate)
```

The exact current-rate identity
(`APrimeFirstCellFarRowAbsorb.lean:102`) and the bracket bound by three
(`:392`) give

```text
currentRate(r)
  <= 3 * 147456 * N^alpha * eta_r^(-1) * R^(-4)
   = 442368 * N^alpha * eta_r^(-1) * R^(-4).
```

Since `0 <= r <= v <= 1/2`, one may avoid any logarithmic endpoint issue and
use `eta_r^(-1) <= 2` and `v <= 1/2`:

```text
integral_0^v eta_r^(-1) dr <= 1.
```

Therefore (QV-rate) would imply

```text
integral_0^v g(r) dr
  <= 442368 N^alpha R^(-4) + (1/2) N^(-beta),
```

and hence, using `sqrt(442368) = 384 sqrt 3`,

```text
sqrt((2p-1) * integral_0^v g(r) dr)
  <= sqrt(2p-1) *
       (384 sqrt 3 N^(alpha/2) R^(-2)
        + 2^(-1/2) N^(-beta/2)).
```

The fixed-`N` integrability needed to justify interval monotonicity is
already `intervalIntegrable_rateNormW_qvAt`.  The missing content is precisely
the quantitative weighted split (QV-rate), not measurability or time
integrability.

## Exponent check with one event

Choose the common event parameter

```text
alpha = tau = delta/16.
```

The four moment-norm contributions then have exponents

| contribution | exponent of `N` |
|---|---:|
| initial term | `5delta/32` |
| drift | `2alpha = delta/8` |
| cross | `alpha-2delta = -31delta/16` |
| QV after square root | `alpha/2 = delta/32` |

All carry `R^(-2)`, apart from negligible complement terms; since
`1 <= R <= 2`, those terms can be put on the same scale at a fixed factor
four.  The largest exponent is `5delta/32`, strictly below `delta/4`.
Thus fixed constants depending on `p` can be absorbed eventually, and the
numerical ledger has enough room for the first-cell weighted-moment target.
No threshold uniform in `p` is asserted or needed.

Every favorable input above uses the same
`sharpCommonEvent(tauPrime,delta,alpha,N)`: T476 for `hcross`, T470 for the
drift norm, and T448 for QV.  The global QV envelope is all-sample and does
not introduce another event.

## Boundary, witness, and dependency checks

* At `r=0`, the Minkowski derivative premise is required only on `Ioo 0 v`.
  `Bfull(0)=0` is totalized, while `A` and `g` are integrable on the closed
  interval.  T480's extra zero-time derivative theorem is consistent but is
  not needed by the consumer.
* At `k=0`, `v=0`; every interval integral is zero and the endpoint quantity
  equals its initial value.  This branch should remain separate from the
  positive-time assembly.
* T480/T476 retain a positive `k=2` resident in the same sharp event, with
  `0=u_0<u_1<u_2<=firstCellT`.  It supplies nonvacuous positive-cell geometry.
  No theorem asserts that the strict transition set itself is inhabited,
  and none of the calculations above requires that assertion.
* The only `BoundsCore` used here is `BoundsCore_zero` for the initial
  first-cell datum.  No next-cell `BoundsCore`, transition bootstrap, or
  reverse dependency is used.
