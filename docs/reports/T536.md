# T536 — First-cell delta-uniformization producer audit

## Verdict

The accepted fixed-delta theorem T535 does not imply the first-cell field
required by `Step2Bootstrap.WeightedMoment`.  The consumer asks for

```text
forall delta, 0 < delta -> delta <= delta0 -> forall p, ... eventually N ...,
```

whereas T535 proves only `delta = 1/2000`.  In particular, taking a smaller
delta makes the required power `N^((delta/2)p)` smaller, changes both the
widened weight and the truncation height `N^(2delta)`, and cannot be obtained
by monotonicity from the literal T535 statement.

There is no mathematical exponent obstruction to a first-cell uniform
producer.  The smallest quantitative route is the T533/T535 route, with a
delta-dependent high order

```text
P(delta,p) = max p ceil(20 / delta).
```

For `p >= 1`, this is exactly the least integer condition supplied by the
accepted coarse T512 route `card(LoopArg(L_N,2)) <= N^2`: the family root is
then `N^(1/P)`, and

```text
1 / P <= delta / 20
```

is needed to add it to the coordinate exponent `delta/5` and reach
`delta/4`.  This is minimal only along that accepted coarse cardinality
bound, not globally optimal in the repository: a sharper estimate using the
actual growth of `growL` could reduce the family-root cost and change the
required high order.  A single finite `P` cannot work uniformly for all
positive delta tending to zero.  This is harmless because both the literal
consumer and the paper order the quantifiers as `delta`, then `p`, then
eventual `N`.

The work needed is formal but substantial: the accepted first-cell Duhamel
chain contains two early literal freezes of delta, and the later convenience
definitions inherit them.  Primed delta-parametric wrappers are required
only for the frozen specializations enumerated below.  In particular, T460,
T463, T467, T512's generic finite-family machinery, T520's generic
cross-order comparison, T522's endpoint identity, and the general initial
`hinit` theorem are already reusable.  The generic analytic, Lyapunov,
weight-monotonicity, truncation, and final consumer theorems are reusable as
well.

The largest currently justified uniform range is

```text
0 < delta <= 1/100,
tau = delta/16,
alpha = delta/16,
beta = 1.
```

This is exactly the range of the existing common-event and source packages.
It also leaves strict margins in every frozen arithmetic step.

## Literal consumer

The exact definition in
`RBM1D/Gauss/Step2Bootstrap.lean` is
`Step2Bootstrap.WeightedMoment`:

```text
forall delta, 0 < delta -> delta <= delta0 -> forall p : Nat,
  exists C > 0, eventually N, forall k <= cutNetTop s t mesh N,
    integral W(delta,N,k) *
      |cutTrunc (N^(2delta) * lev(N,u_k)) J(N,u_k)|^(2p)
      <= C * (N^((delta/2)p) * Theta(N)^(2p)).
```

The first-cell specialization has

```text
s = 0,
t = firstCellT tauPrime,
mesh = APrimeSmoothTransition.transitionMesh,
lev = 1,
Theta = 1,
J = Step2Moment.jSnorm (sample exampleGrow) 0 60 0.
```

The exact bridge in `RBM1D/Gauss/APrimeAssembly.lean` is
`APrimeAssembly.weightedMoment_of_widened_family`.  Its hypothesis is

```text
forall delta, 0 < delta -> delta <= delta0 -> forall p,
  exists C > 0, eventually N, forall k <= cutNetTop s t mesh N,
    integral Wp(p,delta,N,k) *
      |cutTrunc (N^(2delta)) J(N,u_k)|^(2p)
      <= C * N^((delta/2)p).
```

It then transfers this estimate to the order-independent prefix weight
`W`, using only `0 <= W <= Wp <= 1`, measurability, and integrability of the
bounded truncation.  This bridge is directly reusable without a primed
version.

The more general `APrimeAssembly.aprimeSlot_of_widened_family` is not a
first-cell conclusion: it takes arbitrary `E,D,s,t`.  A first-cell producer
can instantiate its moment bridge at the displayed first-cell data, but it
does not prove the general moving-window `hfamily` or an `APrimeSlot'`.

## Where delta first becomes literal

The first literal definition on the dependency route is in
`RBM1D/Gauss/APrimeFirstCellFarRowAbsorb.lean`:

```text

```

This is T461, before T480.  It is inherited by T464, T465, T468, T469,
T476, T480, T487, T494, T499, and the later combined coordinate chain.
Thus T480 does not first choose the literal value; its declaration
`APrimeFirstCellMomFlowDerivExact.delta` merely aliases the already frozen
T461 value.

There is a second independent freeze in
`RBM1D/Gauss/APrimeFirstCellDriftBadPayment.lean`:

```text
APrimeFirstCellDriftBadPayment.fixedDelta := 1/2000.
```

Its immediate source,
`APrimeFirstCellDriftNormSplit.exists_actualDriftNormSplit_with_resident`,
is already quantified over every `0 < delta <= 1/100`.  T466 specializes
that source once and propagates the literal value through T470, T498, T502,
T506, T509, T526, and T527.

There are later re-specializations, rather than new analytic freezes:

- `APrimeFirstCellCrossOrderWeight.targetWeight` inserts `1/2000` directly;
- T512, T521, T522, T524, T528, T529, T533, T534, and T535 alias the fixed
  coordinate-chain delta;
- T535 inserts the same value in its measurable/nonnegative target-weight
  wrappers and in `cutTrunc`.

The parametric repair therefore has to begin before T480, at T461 and T466.
Changing only T527, T533, or T535 would leave the canonical weight, common
event, derivative, drift, cross, and QV inputs at the wrong delta.

## Exponent ledger

Fix `0 < delta <= 1/100`, set `alpha = delta/16`, `beta = 1`, and write

```text
R = etaT 0 0 / etaT 0 (endpoint N k),  1 <= R <= 2.
```

Before the final coordinate absorption, the exact accepted ledger becomes:

| source | power of `N` | ratio/time factor |
|---|---:|---|
| initial, T500 | `5delta/32` | `R^(-2)` |
| drift favorable, T498 | `2alpha = delta/8` | `R^(-2)` |
| drift complement | `-beta = -1` | none; converted using `R^(-2) >= 1/4` |
| full cross, T469/T499 | `alpha-2delta = -31delta/16` | `R^(-2)` |
| QV favorable after square root | `alpha/2 = delta/32` | `R^(-2)` |
| QV complement after square root | `-beta/2 = -1/2` | `sqrt(v)`, with `v <= 1/2` |

Every displayed exponent is strictly below `delta/5` for positive delta.
The constants may depend on the fixed moment order, and the corresponding
eventual threshold may depend on delta and that order.  The coordinate
output is therefore

```text
momNormW(P_gauss, canonicalWeight_delta_P, P, Y_a(endpoint))
  <= N^(delta/5) R^(-2).
```

The family has `card(LoopArg(L_N,2)) = L_N^2 <= N^2`.  Its exact root cost
at order `P` is `N^(1/P)`.  With `P >= ceil(20/delta)`,

```text
delta/5 + 1/P <= delta/5 + delta/20 = delta/4.
```

Lyapunov under the unchanged high-order canonical weight and target-weight
monotonicity add no exponent or coefficient.  Hence

```text
momNormW(P_gauss, widenedWeight_delta_p, p, familyMax)
  <= N^(delta/4) R^(-2).
```

At the endpoint, T522 gives the deterministic baseline `R^(-4)`.  Since
`1 <= R <= 2` and `N >= 1`,

```text
momNormW(..., jSnorm(endpoint))
  <= R^(-4) + N^(delta/4) R^(-2)
  <= 1 + N^(delta/4)
  <= 2 N^(delta/4).
```

Raising to `2p` and using the honest target-weight integrability gives

```text
integral widenedWeight_delta_p *
  |cutTrunc (N^(2delta)) jSnorm(endpoint)|^(2p)
  <= 2^(2p) N^((delta/2)p),       p >= 1.
```

For `p=0`, the constant is `1`, directly from `0 <= widenedWeight <= 1`
on the probability space.

### No hidden scale losses

- **W power:** after the accepted source estimates, this chain introduces
  no explicit positive power of `W`.  The paper's additive `W^(-D)` error
  is upstream of the accepted high-probability source packages.  The Lean
  family, Lyapunov, target-weight, endpoint, and truncation passages have
  W exponent zero.
- **Time:** the only surviving raw time factors are `v <= 1/2` in the drift
  integral and `sqrt(v) <= sqrt(1/2)` in the QV complement.  There is no
  time-net cardinality factor in the downstream moment chain.
- **Ratio:** all coordinate stochastic terms retain `R^(-2)`.  The exact
  endpoint baseline is `R^(-4)`.  The first-cell bounds `1 <= R <= 2`
  remove them only at the final unnormalized integral step; no positive
  power of `R` is paid.
- **Family cardinality:** it is paid once, as `N^(1/P)`.  Lyapunov and
  target-weight transfer must occur after this single high-order payment.

## Quantifier order and boundary branches

The producer must have the following order:

```text
exists tauPrime > 0,
forall delta, 0 < delta -> delta <= 1/100 ->
forall p : Nat,
  let P = max p ceil(20/delta);
  exists C > 0,
  eventually N,
  forall k <= cutNetTop 0 (firstCellT tauPrime) mesh N, ...
```

For `p>=1`, take `C=2^(2p)`.  For `p=0`, take `C=1`.  The auxiliary `P`
is chosen after delta and p but before the eventual threshold.  The
threshold is then uniform in active `k` and all output coordinates.

The final `forall k <= cutNetTop` includes `k=0`.  The proof must merge the
positive branch and the independent exact zero branch before invoking
`weightedMoment_of_widened_family`.  At zero it should retain

```text
endpoint N 0 = 0,
R = 1,
```

and prove the same integral bound directly.  A theorem quantified only over
`1 <= k` is not a valid input to the literal consumer.

## Common event and nondegeneracy

One `tauPrime` must be selected from
`exists_sharpCommonEvent_with_positive_plateau` before delta.  For each
fixed delta, all drift, cross, QV, canonical-weight, and resident arguments
must use the single event

```text
sharpCommonEvent tauPrime delta (delta/16) N.
```

The event may depend on delta; `WeightedMoment` does not ask for an
intersection over all real delta.  It must be independent of the moment
orders `p` and `P` at fixed delta.  Combining separately closed existential
producers is unsafe because they may expose unrelated witnesses for
`tauPrime`; the new closed chain should choose `tauPrime` once and pass the
explicit event hypotheses through the non-closed lemmas.

The resident should state, eventually in `N`, that some sample in this same
event satisfies

```text
2 <= cutNetTop ... N,
0 < endpoint N 2 <= firstCellT tauPrime N,
canonicalWeight_delta_P N 2 omega = 1,
widenedWeight_delta_p N 2 omega = 1,
the final integral inequality at k=2.
```

The canonical plateau theorem already gives all positive moment orders on
one sample.  The target plateau must be reproved with variable delta from
the same prefix values.  This rules out a vacuous theorem caused by a zero
cutoff weight.

## Paper check

Formula (2.76) states, for the two-loop tail,

```text
|L_u - K_u| prec
  (eta_s/eta_u)^4 (W ell_u eta_u)^(-2)
    exp(-|a1-a2|^(1/2)/ell_u^(1/2)) + W^(-D).
```

The paper uses stochastic domination, so the loss exponent is arbitrarily
small after all fixed parameters have been chosen.  This is compatible with
choosing delta first and a delta-dependent high moment later.  It does not
justify replacing the required continuum of delta values by one literal
value.

Formulas (5.28) and (5.29) define

```text
J_{u,D}(ell) = T_u^(L-K)(ell) / T_{u,D}(ell) + 1,
J*_{u,D} = max_ell J_{u,D}(ell) <= (eta_s/eta_u)^4.
```

They explain the ratio-four normalization and the finite spatial maximum;
they do not introduce the Lean high moment `P`.  The condition
`P >= ceil(20/delta)` comes solely from the Lean passage from all coordinate
moments to the `L_N^2` family maximum.

Formula (5.43) stops when `J*` reaches the ratio-four barrier.  Formula
(5.44) bounds the stopped quadratic variation.  Formulas (5.45) and (5.46)
make the martingale estimate uniform on a fine time net, and (5.47) gives
`J*_{tau,D} prec (eta_s/eta_t)^2`, so the stopping time is not reached with
high probability.  This supports one common high-probability event with no
extra downstream time factor.  The accepted Lean first-cell source chain
encodes these inputs, but its T461/T466 wrappers specialized delta too early.

The paper therefore supports the parametric repair.  It does not supply a
shortcut from fixed-delta T535, and it does not turn the first-cell result
into a general moving-window theorem.
