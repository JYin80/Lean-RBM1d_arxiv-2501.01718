# T1137 — fresh far-index good-event preflight

## Verdict: mathematical preflight FAIL; no Lean source

The literal target is the T999 selected-order Gaussian integral, restricted to
`good N = {ω | ‖Xmat Dims.exampleGrow N ω‖ ≤ N}`. For every fixed `δ₀`,
`0 < δ ≤ δ₀`, and `p ≥ 1`, it must choose `q ≥ p` and `C > 0` **before**
the eventual threshold in `N`, and then bound, uniformly for every active
`k > N^4`,

```text
∫ ω in good N,
  widenedW(canonicalR s t targetMesh, 1, jSnorm, s,t,targetMesh, δ,q,N,k,ω)
    * |cutTrunc(N^(2δ), jSnorm(cutNetPt(s,targetMesh,N,k),ω))|^(2q) dP
  ≤ C N^(δq/2).
```

This is neither established nor refuted by the inspected sources. I found no
mathematically justified new producer or paper-to-Lean bridge with this exact
observable, event, weight, cutoff, endpoint, range, and rate. Per the ticket's
preflight gate I created no Lean file and did not weaken the statement.

## Independent route checks

1. **Endpoint transfer from the initial law.** T1097 gives the initial
   `jSnorm` moment, T1103 handles `k=1`, and T1117 handles active
   `2 ≤ k ≤ N^4`. T475 bounds the same-sample change on `good N` by
   `N^(2D+7)|v-s_N|^(1/2)`. Since `targetMesh=N^(4D+18)` eventually,
   at the actual endpoint this is `N^-2√k`. The cutoff is `19/4`-Lipschitz,
   so the resulting power error is bounded by a constant (depending on `q`)
   times `N^-4q k^q`. Its absorption at `N^(δq/2)` requires approximately
   `k ≲ N^(4+δ/2)`, which does not cover the active far range. This is only a
   limitation of that upper bound; it supplies no lower bound or
   counterexample to the desired integral.

2. **Prefix support and event splitting.** The active `widenedW` is the
   `2q` power of a cutoff of the soft maximum over exactly `j < k`, at the
   widened level `2e N^(2δ)`. Its support and T475's final-mesh-step bound
   give only an endpoint cap of order `N^(2δ)`. The resulting `2q` power is
   order `N^(4δq)`, not `N^(δq/2)`; a tail estimate is missing. T1115 pays
   the complementary `goodᶜ` integral for all active later indices, but
   supplies no gain on `good N`.

3. **Existing all-time source event.** `APrimeGeneralMovingCommonSources`
   constructs a high-probability common event containing the norm condition,
   raw Step-1 bounds for loops of lengths 3, 4 and 6, flow and centered
   events, and a block bound. Those statements provide coefficients for a
   stopped or weighted two-loop argument. They do not bound the normalized
   two-loop `jSnorm` itself at far endpoints. Step 1's general length-two
   a priori bound is a spatially unweighted scale bound; identifying it with
   the sharp spatial-tail `jS` estimate would discard the tail denominator.
   Restricting the integral to the common event and using high probability
   for its complement therefore still lacks the needed on-event endpoint
   estimate.

4. **Actual smooth-weight route.** The same-sample comparison
   `APrimeSmoothWeightActual.widenedW_le_weight_canonical` does dominate the
   literal widened weight by an actual differentiable smooth weight at the
   same `δ`. The general-moving files also prove pieces of the weighted
   generator and an integrated QV slot. The missing arrow is a uniform
   high-order smooth-weighted **endpoint coordinate family moment** for
   every active `k`, strong enough to reach `C N^(δq/2)` after
   `APrimeGeneralMovingEndpointFamily.cutTrunc_jSnorm_pow_le_endpoint_family`.
   The checked general-moving modules supply integrability, pointwise
   comparisons, and budgets, not that family moment. The first-cell family
   result is for its specified first-cell model and cannot be inserted as a
   general-moving far-index producer. Adding the endpoint moment as a premise
   would merely restate the gap.

5. **Paper stopping route.** In the authorized PDF, printed p. 58,
   (5.43) stops when `J*` reaches `(η_s/η_t)^4`; (5.44) bounds the
   time-integrated QV only up to that stopping time. Equations (5.45)–(5.46)
   propagate the stopped martingale bound to a time net. The continuation on
   p. 59 first combines those inputs with the drift and initial bounds, then
   obtains (5.47) and removes stopping. The checked Lean sources do not
   provide a same-sample identification of that stopped process and its
   exit event with the static order-`q` prefix-weighted integral above, nor
   the requisite far-index stopped martingale estimate. `Step2.jS_stochDom`
   has a `Step2.Hyp` input containing such a martingale estimate; using it
   without a Gaussian producer would be circular for this task.

These routes leave one precise implication: obtain a far-index
distributional or high-moment estimate for the **actual normalized two-loop
endpoint on the norm-good event**, jointly with its literal order-`q`
prefix cutoff. A completed smooth-weighted coordinate bootstrap or a fully
proved stopped-process translation could supply it, but neither is available
as an established input here.
