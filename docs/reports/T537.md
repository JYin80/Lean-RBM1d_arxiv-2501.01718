## Exact rate identities and gaps

The source powers are retained literally:

```lean
storedQuad   = N ^ (4 * delta + 2 * tau delta) * endpointScale ^ (-1/2)
               * xRate ^ (7/4)
storedCubic  = N ^ (6 * delta + 3 * tau delta) * endpointScale ^ (-1)
               * xRate ^ 5
currentQuad  = N ^ (4 * delta + 2 * tau delta) * endpointScale ^ (-1/2)
               * xRate ^ (19/4)
currentCubic = N ^ (6 * delta + 3 * tau delta) * endpointScale ^ (-1)
               * xRate ^ 8
```

The public identities `storedRowsRate_eq` and `currentRate_eq` identify these
brackets definitionally with the producer rates.

After `tau = delta/16`, the exact decay margins are exported as

```lean
quadGap delta  = 1 / 4 - (4 * delta + 2 * tau delta)
               = 1 / 4 - 33 * delta / 8
cubicGap delta = 1 / 2 - (6 * delta + 3 * tau delta)
               = 1 / 2 - 99 * delta / 16.
```

For `0 < delta <= 1/100`, both are strictly positive.  The endpoint
`delta = 1/100` is included and gives the explicit positive margins
`167/800` and `701/1600`.  Thus no stronger product condition is used.

## Quantifiers and boundary cases

The two main exports have the following quantifier order:

```lean
{tau' delta : Real} -> 0 < tau' -> 0 < delta -> delta <= 1/100 ->
  eventually N atTop,
    forall k, k <= cutNetTop ... (firstCellT tau') ... N ->
      let v := cutNetPt ... N k
      forall u in Set.Icc 0 v, stored row bounds and stored bracket <= 3
```

and identically with every real current time `r in Set.Icc 0 v`.  Each of
the three rows is separately proved to lie in `[0,1]`; consequently each
bracket is at most `3`.  This includes every active first-cell index and both
closed time boundaries `0` and `v`.

`eventually_zero_rows_absorbed` records the exact `k=0` endpoint `v=0` and
the stored/current bounds at its sole prefix time.  Hence the degenerate
boundary is handled explicitly rather than hidden by an empty interval.

`eventually_positive_two_rows_absorbed` records the actual `k=2` resident,
proves its endpoint satisfies `0 < v`, and instantiates all stored/current
row and bracket bounds at time `0`.  This supplies a nonempty positive-cell
instance.

`admissible_parameters_witness` gives the simultaneous witness
`tau' = 1`, `delta = 1/2000` for all parameter hypotheses and both strict
gaps.
