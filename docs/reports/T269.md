## (a) 传播 —— 签名与它选的那条模

```lean
eventually_le_cWt_mul_priorLevel (H : CutHypEvOn P J s t Θ Good) (hr : 1 ≤ r) (hδ : 0 ≤ δ) :
  ∀ᶠ N in atTop, ∀ ω ∈ Good N,
    softW r (netFinset s t H.mesh N) (fun ws => J N ws ω) (priorThr δ Θ N) ≠ 0 →
    ∀ v ∈ Set.Icc (s N) (t N), J N v ω ≤ cWt * priorLevel δ Θ N
```
`cWt = 4e + 2` **直接复用 T263 的 `RBM.StepSideAPrime.cWt`，没有重新推导**。
链条：`abs_le_two_mul_of_softW_ne_zero`（**每个网点、无基数损失**）→ `MomentDuhamelCut.hclose_of_modulus`（`H.modulus` + `H.mesh_fine`）→ 窗口里**所有** `v`。
逐点形式 `le_cWt_mul_priorLevel` 把 `Kmod`/`γ` **取成抽象参数**，所以**两条模都原样装得进去**。

⭐ **见证里用的是 T257/T266 的事件路线**（`γ = 1/2`、`Kmod = 2+2D`，经 `RBM.modulus_event_exampleGrow_zero`）。**理由**：p.24 网格第一格是 `[0, 1/2]`、左端点 `0`，而 T257 那条 `‖X‖`-free 的 `γ = 1` 路线**在那里用不了**（它要 `0 < s`，D17/T249）。`0 < s` 的格子上，下游调用者把 `γ = 1` 的模传进**同一条引理**即可。

## 验收第 2 条：**没有残留的 `∀ω` size 假设**

每条 size 陈述要么是**单个 `ω` 处逐点的**（Step-1 输入就在那里供给：`quadVar_lkFun_le_qvShape/qvBd`、`le_qvBd_of_le_qvShape`、`div_le_QBd_of_le_qvShape`），要么被 **`ω ∈ Good N` 且 `softW ≠ 0`** 双重守卫（`eventually_le_cWt_mul_priorLevel`）。
`Good` **只作为事件假设进来**，本单**不声称**它的 `HighProb`（那是 T267 的事）。

## 见证

* `softW_ne_zero_at` —— 权重在一个显式正阈值处 `= 1`，**对任意 `ω`**：`supp W` 不会因平凡理由退化；
* `softW_priorThr_ne_zero` —— **校准过的**阈值 `2Θ′ = 2e·Λ_N` 只要网点值服从 `Λ_N` 就够得到（经 `one_le_softW` + `card_calib_two_exp`，即 `rpow_card_le_exp_one` 留 `2e` 余量）：**`softW ≠ 0` 这个假设不空**；
* ⭐ `sat_supp_inter_good_nonempty_exampleGrow` —— **`supp W ∩ Good ≠ ∅`**：在 `exampleGrow` 上 `ω = 0` 落在 `Good N = {∣‖X_N‖ ≤ N}`（T266 那个 bundle 的 `Good`）里，且权重在那里非零；
* `sat_propagation_exampleGrow` —— (a) 在 `exampleGrow`、`E = 0`、`D = 1`、格 `[0, 1/2]`（**左端点 `0`**）、`Θ ≡ 1`、`Kmod = 4`、`γ = 1/2`、`mesh = (N+1)^8` 上**无条件**端到端跑通，结论 `jSfarSm … v ω ≤ (4e+2)·N^{2δ}` 对**所有** `v ∈ [0, 1/2]`；显式有限（`cWt_priorLevel_one`），且**严格高于支撑水平**，余量由 `StepSideAPrime.prior_lt_level` 给。

## 没做的

1. ⚠ **(5.42) 的 `U`-传播没做**：它**没有**从 `E⊗E` 的界重建 `‖Uker (xi2bar) (eeFun)‖` 的界（即把 (5.36)@`u` 变成端点 `t` 处 (5.42) 的那一步）。因此 `Q^{bd}` 交付的形式是「**(5.42) 形状的逐点界 @ 运行水平 `J*` ⟹ 显式的、不含 `J*` 的包络**」（`div_le_QBd_of_le_qvShape`），而那个形状的**可居性**由 T262 在 `U = id` 处交割（`quadVar_lkFun_le_qvShape`）。缺的那一环是**带非平凡核的 `EEUker → Lemma57` 复合**，归 Lemma 5.7 / `Uker` 桥的持有者（与 T262 的文件相邻），**不归算术单**。
2. **时间相关的水平**（`T269b`）：`CutHypEvOn` 每个 `N` 只带一个 `Θ`，所以 (a) 传播到常数 `Λ_N = N^{2δ}Θ_N`（报告里 `Λ_v` 在**右端点**的取值，即**最弱**的那一点），与 `StepSideAPrime.StepSide''` 自己的约定 `Jv ≤ cWt·x^{16}R^4` 一致。**接口不需要改。**
3. `T269a`：审稿的 `W^{−1}` 是笔误，本文件跟 T262（`(J*)²` 取代 `(J*)³`、无 `W^{−1}`）。
