# T913 — closed-time clipped grid API preflight

## Verdict and boundary

**PASS for the deterministic finite-grid lemma.** With `0 < h` (the requested `h ≤ 1/2` is not needed for coverage), the `Fin` index type of size `Nat.ceil ((1/2 : ℝ)/h)+1` gives an exact grid containing both endpoints. Every `u ∈ [0,1/2]` is at distance **strictly less than** `h` from the grid point indexed by `Nat.floor (u/h)`, hence at distance at most `h`. The same proof works at `h=1/2`, at `u=0,1/2`, and when `u/h` is an integer. This is an auxiliary arithmetic result, with no probabilistic, Fourier, or Gaussian conclusion.

T668 §4's eventual cardinality bound has a clean separate specialization, but this ticket does not prove any eventual statement for `Dims.exampleGrow` or use the in-flight T905 time modulus.

## Exact finite interface and compiled APIs

The scratch file `/tmp/T913Grid.lean` imported `Mathlib` and set `autoImplicit false`. The following definitions and theorem shapes compiled with `lake env lean /tmp/T913Grid.lean` (exit 0):

```lean
private noncomputable def gridCount (h : ℝ) : ℕ :=
  Nat.ceil ((1 / 2 : ℝ) / h) + 1

private noncomputable def grid (h : ℝ) (j : Fin (gridCount h)) : ℝ :=
  min ((j.val : ℝ) * h) (1 / 2 : ℝ)

private theorem grid_zero (h : ℝ) :
    grid h ⟨0, Nat.zero_lt_succ _⟩ = 0

private theorem grid_range (h : ℝ) (hh : 0 < h)
    (j : Fin (gridCount h)) :
    0 ≤ grid h j ∧ grid h j ≤ 1 / 2

private theorem grid_last (h : ℝ) (hh : 0 < h) :
    grid h ⟨Nat.ceil ((1 / 2 : ℝ) / h), Nat.lt_succ_self _⟩ = 1 / 2

private theorem grid_coverage (h u : ℝ) (hh : 0 < h)
    (hu0 : 0 ≤ u) (hu1 : u ≤ 1 / 2) :
    ∃ j : Fin (gridCount h), |u - grid h j| ≤ h

private theorem grid_card (h : ℝ) :
    (Finset.univ : Finset (Fin (gridCount h))).card = gridCount h
```

`noncomputable` is required because the real `Nat.ceil`, division, and real minimum use noncomputable order/field instances. The exact number of indices is `gridCount h`; the final index is legal by `Nat.lt_succ_self`. For the last endpoint, `Nat.le_ceil` and `div_le_iff₀ hh` show `1/2 ≤ (Nat.ceil ((1/2)/h) : ℝ)*h`, so `min_eq_right` applies. `grid_range` uses `le_min`, `mul_nonneg`, and `min_le_right`.

The compiled coverage proof uses the **floor for selection, ceiling for indexing**:

```lean
let k : ℕ := Nat.floor (u / h)
have huv : u / h ≤ (1 / 2 : ℝ) / h :=
  (div_le_div_iff_of_pos_right hh).2 hu1
have hk : k ≤ Nat.ceil ((1 / 2 : ℝ) / h) :=
  (Nat.floor_mono huv).trans (Nat.floor_le_ceil _)
let j : Fin (gridCount h) := ⟨k, Nat.lt_succ_of_le hk⟩
```

`Nat.floor_le (div_nonneg hu0 hh.le)` gives `k*h ≤ u`; `Nat.lt_floor_add_one (u/h)` gives `u < k*h+h` after multiplication by `h>0`. Since `k*h ≤ u ≤ 1/2`, clipping is inactive at this selected index: `grid h j = k*h`. Thus `0 ≤ u-grid h j < h`, and `abs_of_nonneg` finishes the claimed `≤ h`. This handles a grid boundary without subtracting one from an integer index; when `u/h=k`, the selected grid point is exactly `u`.

Concrete boundary checks also compiled:

* `gridCount (1/2 : ℝ)=2`, with node values `0` and `1/2`.
* `gridCount (1/3 : ℝ)=3`, with last node `min (2/3) (1/2)=1/2`; the last gap is genuinely clipped.

There is no `Nat.ceil`/`Nat.floor` API gap. `#print axioms` for `grid_coverage`, `grid_last`, and the count bound below returned only `propext`, `Classical.choice`, `Quot.sound`. These are scratch typechecks, **not** a repository module or root build.

## T907 §4 / T668 §4 cardinality specialization

For any natural `W≥1` and real `a≥1`, the following also compiled:

```lean
private theorem gridCount_div_identity (W : ℕ) (a : ℝ)
    (hW : 1 ≤ W) (ha : 0 < a) :
    gridCount (a / (W : ℝ)) =
      Nat.ceil ((W : ℝ) / (2 * a)) + 1

private theorem gridCount_le_two_width (W : ℕ) (a : ℝ)
    (hW : 1 ≤ W) (ha : 1 ≤ a) :
    gridCount (a / (W : ℝ)) ≤ 2 * W
```

The identity is `field_simp` under `W>0`, `a>0`. For the bound, `(1/2)/(a/W) ≤ W` follows from `a≥1`, so `Nat.ceil_le` gives `Nat.ceil ((1/2)/(a/W)) ≤ W`, and `omega` gives `T≤W+1≤2W`. This avoids a delicate integer interpretation of `W/2+2` in T907's informal estimate; it is slightly weaker at the intermediate step and exactly sufficient for `T≤2W`.

Specialize `a=Real.log N`, `W=d.W N`, `h_N=a/W` only after establishing `Real.log N≥1` and `1≤W`. The requested `0<h_N≤1/2` needs a **separate** eventual bandwidth-versus-log estimate; it does not follow merely from `log N≥1` and `W≥2`. The generic coverage lemma itself only needs `h_N>0`. With the already cited eventual `d.dim : L_N W_N≤N` and `L_N≥1`, one gets `W_N≤N`, then

```text
K_N = L_N (W_N-1) T_N
    ≤ L_N W_N · 2 W_N
    ≤ 2 N².
```

These last inequalities identify the consumer interface; they were **not** scratch-compiled as an eventual theorem. They do not imply the T907 finite-union probability premise or the T668 interpolation estimate. In particular the latter still needs the T905 time modulus, its finite-Fourier-sum lift, and the quantitative `h_N` estimate.
