## Literal comparison

`widenedW_le_minkowskiWeight` proves, for every positive first-cell
parameter tau', all N, k, samples omega, and integers `1 <= p <= P`,

```text
APrimeWeight.widenedW
  (canonicalR (fun _ => 0) (firstCellT tau') transitionMesh) 1
  (fun N u omega =>
    jSnorm (sample exampleGrow) 0 60 (fun _ => 0) N u omega)
  (fun _ => 0) (firstCellT tau') transitionMesh

<=
APrimeFirstCellMinkowskiExact.weight tau' P N k omega.
```

The right side is T494's literal actual weight, with its public canonical
smoothing order. `minkowski_delta_eq` verifies exactly that its delta
is 1/2000. The public `targetWeight` is simply the left-hand formula,
used to keep the witness readable.

The theorem is pointwise and valid at every N and k. It has no probability
premise, active-index restriction, or asymptotic loss.
