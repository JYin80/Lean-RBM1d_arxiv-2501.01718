## Exact source-to-consumer comparison

Write `N=L*W`, `J=[-2+κ/2,2-κ/2]`, and `δ=κ/4`. T1459's `spectral_alpha_outside_bulk_tail_le` assumes one Hermitian matrix on `ZMod L × Fin W`, `[NeZero L]`, `[NeZero W]`, `3 ≤ L`, `κ>0`, `|E|≤2-κ`, `|Re z-E|≤C0/N≤κ/4`, and `Im z>0`. Its conclusion uses `spectralPole hH z α`.

T1397's `norm_green_spectral_identity_blockM_le` instead retains

\[
A_{\sigma_1}(y)=\sum_\alpha
 |\operatorname{spectralGsigPole}(hH,z,\sigma_1,\alpha)|^2
 |\operatorname{blockM}(hH,y.1,\alpha)|,
\]

with `σ₁ σ₂ : Bool` quantified independently. By `GreenSpectralL1.lean:31–37`, the false sign replaces only `z` by `conj z`; it does not replace the matrix, eigenbasis, eigenvalues, or profile coefficient. Applying the existing tail theorem at `conj z` would require the false premise `0 < -z.im`.

For every real eigenvalue λ, however,

\[
(\lambda-\overline z)^{-1}
 =\overline{(\lambda-z)^{-1}},\qquad
 |(\lambda-\overline z)^{-1}|=|(\lambda-z)^{-1}|.
\]

Thus the alpha factors are termwise equal for both signs, including on exactly the same outside-J index set. There is no change in `N`, `δ`, exponent, event, time window, or order of quantifiers. This equality alone does not assert equality of the original mixed-sign complex loop expressions.

T1457 already proves this argument in `spectralGsigPole_norm_eq_inv_distance` at `GreenSpectralBulkFactor.lean:69–84`, but the theorem is **private**. An importing file cannot use the proposed public name `RBM.spectralGsigPole_norm_eq_inv_distance`; a direct `#check` reports an unknown identifier. Its conjugation proof is a valid template for the missing public interface, not an already exported theorem.

## Minimal repair specification

Keep the existing positive-imaginary-part theorem intact. Add a public norm interface with the following type, which needs no sign-of-imaginary-part hypothesis at all:

```lean
theorem spectralGsigPole_norm_eq_spectralPole
    {n : Type*} [Fintype n] [DecidableEq n]
    {H : Matrix n n ℂ} (hH : H.IsHermitian)
    (z : ℂ) (σ : Bool) (α : n) :
    ‖spectralGsigPole hH z σ α‖ = ‖spectralPole hH z α‖
```

The true case is definitional. For the false case, unfold the pole definitions, apply `norm_inv`, rewrite the denominator as `star ((hH.eigenvalues α : ℂ) - z)`, and apply `norm_star`. The unrestricted statement is also valid at a pole under Lean's totalized inverse; the actual resolvent consumer continues to require `Im z>0`.

With the existing AlphaTail variable context and its current set-valued interval, the exact required successor is:

```lean
theorem spectral_alpha_outside_bulk_tail_le_gsig
    {κ E C0 : ℝ} {z : ℂ} (hL : 3 ≤ L) (a0 : ZMod L) (β : Fin W)
    (hκ : 0 < κ) (hE : |E| ≤ 2 - κ)
    (hzE : |z.re - E| ≤ C0 / (L * W : ℝ))
    (hsmall : C0 / (L * W : ℝ) ≤ κ / 4) (hη : 0 < z.im)
    (σ : Bool) :
    (∑ α : Idx, if hH.eigenvalues α ∉ spectralBulkInterval κ then
      ‖spectralGsigPole hH z σ α‖ ^ 2 * ‖blockM hH a0 α‖ else 0) ≤
      2 * (L * W : ℝ) * (κ / 4)⁻¹ ^ 2 := by
  simpa only [spectralGsigPole_norm_eq_spectralPole] using
    spectral_alpha_outside_bulk_tail_le hH hL a0 β hκ hE hzE hsmall hη
```

An analogous one-line wrapper for `spectral_pole_sq_le_outside_bulk` can expose its pointwise conclusion with `spectralGsigPole`; it is optional for the aggregate consumer. No bulk mass or second moment assumption is needed for either tail wrapper. Do not strengthen the input to a lower-half-plane positive-imaginary-part assumption, an all-spectrum eigenvector maximum, or a nonzero loop integrand.

For the downstream consumer define `A_J(σ₁,y)` by restricting the displayed alpha sum to `λα∈J`. The exact deterministic composition, under T1457's existing bulk-mass hypotheses at y, is

\[
\|\text{T1397 loop}_{\sigma_1,\sigma_2}(y)\|
\le N^{-1}\bigl(A_J(\sigma_1,y)+2N\delta^{-2}\bigr)

The relative version replaces the last factor by `(D+R_z/δ)P₁/N`. This is a specified future composition, not a compiled new project theorem. It follows by the exact finite bulk/complement partition and multiplication by nonnegative factors. The `σ₂` theorem already exists in T1457; no relation between the signs is needed.

## Same-matrix simultaneous witness

Use the witness already recorded in T1459/T1460: `W=1`, `L=N≥100`, the path adjacency matrix on the first `N−1` sites, and an isolated final site with diagonal value `10`. Fix `κ=1`, `E=0`, `C0=1`, and `z=i`; then `J=[-3/2,3/2]` and `δ=1/4`. The path eigenvalues are `2 cos(πk/N)`, with normalized eigenvector masses at most `2/N`, and there are eigenvalues in J. \[
M_{y,\mathrm{iso}}=N/3-1>0,\qquad
|p_{\mathrm{iso}}(i)|^2=|p_{\mathrm{iso}}(-i)|^2=1/101.
\]

Consequently the same alpha-tail term is `(N/3−1)/101>0` for both signs on the very same matrix. Moreover

\[
R_i^2=N^{-1}(\operatorname{Tr}H^2+N)=3+96/N<6.

All path and diagonal coordinates are permitted positive-variance coordinates of the actual W=1 block profile, and zero values in other active coordinates are allowed. The cited reports provide the support identification; this ticket does not inspect or certify a new Gaussian carrier/event implementation. Simple spectrum and strict separation of eigenvalues from the J endpoints then preserve the finite-dimensional conditions on a sufficiently small neighborhood. Both signs hold there by the same deterministic identity, with no new event intersection. This is a satisfiability/support witness, not a high-probability or OU-path result.
