# T467 — same-event canonical-weight positive `k = 2` plateau

## Result

Implemented in `RBM1D/Gauss/APrimeFirstCellCanonicalPlateau.lean`.

For the pinned first-cell parameters `d = exampleGrow`, `E = 0`, `D = 60`,
`s = 0`, and the actual transition mesh, the module proves that for every
`τ' > 0` and `δ > 0`, eventually every sample satisfying the literal norm cap
has

```lean
canonicalWeight τ' δ p N 2 ω = 1
```

for every moment order `p`.  Therefore every resident of T434's literal
`sharpCommonEvent τ' δ α N` has the same assertion.  The closed producer keeps
T434's parameter order `∃ τ' > 0, ∀ 0 < δ ≤ 1/100, ∀ α > 0` and retains one
resident carrying the positive endpoint, source event, all-time `jG ≤ 2`
bound, endpoint bounds, and canonical weight one.

The zero-prefix boundary is also explicit in `canonicalWeight_k_zero`.

## Direct canonical-order proof

The proof uses the public modulus theorem at the actual first mesh point to
obtain

```lean
jSnorm ... (cutNetPt ... N 1) ω ≤ 1 + N⁻².
```

Together with the public `J_zero`, this bounds the two entries used by
`prefixSample_le_of_jSnorm_bound`.  The smoothing order is
`APrimeSmoothWeightActual.canonicalM ... N` throughout.  Its calibration gives

```lean
prefixSample ≤ exp 1 * (1 + N⁻² + N⁻¹⁰) ≤ 3 * exp 1,
```

while the cutoff threshold is at least `8 * (exp 1)^2`; hence the cutoff and
the canonical weight are one.  No result for smoothing order `m = N` is used
or transferred.

The event projection uses the actual resident from T434.  Its common-event
component yields the norm cap through `commonEvent_to_dynamic_support` and
`good_subset`, so no sample is replaced and no extra event intersection is
introduced.
