## Modes, orientation, and nondegeneracy

The interface above is intentionally stated for arbitrary `χ` with `‖χ j‖ ≤ 1`, so it covers every canonical character, including every nonzero mode supplied by the finite-existence producer. For that application use `W ≥ 2`, `q : Fin W`, `q ≠ ⟨0, _⟩`, and `χ := permutationFourierCharacter W q`; `permutationFourierCharacter_norm_eq_one` supplies the coefficient bound. The nonzero condition comes from the finite-existence layer, not from interpolation. The source defines the character with the **positive** exponent `exp(2π I q.val j.val / W)`, and `permutationFourierSum` is `(∑ i, χ i * x (π i))/(W : ℂ)`. This agrees with T668 §4's displayed positive phase. The proof does not conjugate `χ`, reverse the phase, or replace `π` by its inverse.

The generic coefficient interface also admits a nonconstant `W=1` witness, where there is no nonzero mode. Take `lam=0`, `χ=1`, `π=id`, `h=1/2`, and `r=3`. The grid consists of `0` and `1/2`; the sums have norms `1` and `2`, so every node premise is strict, while the endpoint values are respectively `i` and `2i` and differ. This combines the checked grid values with T917's `permutationFourierSum_W1_flow_endpoint_witness`; the scratch file also typechecked the all-node `<3` witness. Thus the strict premise is not empty, and the time observable is not constant.
