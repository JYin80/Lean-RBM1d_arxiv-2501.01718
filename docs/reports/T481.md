# T481 — general-window `WeightedMoment` mathematical audit

## Verdict

The mathematical preflight **passes**, but the concrete Lean producer is still
missing.  T475 and T479 close the moving-window modulus, fixed event, mesh, and
cardinality fields.  `APrimeWeight.jSnorm_piecewiseW_fields` closes the four
structural weight fields.  Neither result proves a moment estimate.

The first missing actual general-window producer is therefore the complete
post-family widened-weight estimate `hfamily` consumed by
`APrimeAssembly.weightedMoment_of_widened_family`:

```text
forall delta, 0 < delta -> delta <= delta0 -> forall p : Nat,
  exists C > 0, eventually N, forall k <= cutNetTop s t mesh N,
    integral [ widenedW p delta N k
      * |cutTrunc (N^(2 delta)) (jSnorm_N(u_k))|^(2p) ]
      <= C * N^((delta/2) p).
```

Here `u_k = cutNetPt s mesh N k`.  The order is exactly

```text
delta, p, C, eventually N, forall k.
```

Thus the high moment used to prove a requested order may depend on the fixed
`delta,p`, but it must be selected before `N`; the eventual threshold must be
uniform in every active net index `k`.  No theorem currently produces this
statement for an arbitrary admissible moving window.  In particular,
`aprimeSlot_of_widened_family` is only a conditional consumer, and its separate
fixed-`t0` hypotheses do not implement the T479 moving-window package.

This report does not claim `WeightedMoment`, `APrimeHypOn`, or `APrimeSlot'` is
closed.

## Paper comparison

Paper (2.76) is the two-loop tail conclusion, not a moment premise.  In the
stopping argument, (5.43) stops when the normalized quantity reaches
`(eta_s/eta_t)^4`.  Equations (5.44)--(5.46) bound the stopped QV and martingale
uniformly over a polynomial time net.  Equation (5.47) yields only
`(eta_s/eta_t)^2`, leaving the square of the scale ratio as the stopping gap.
The printed condition (2.72), together with the separate regime lower bound in
`Cond272Reg`, pays for that gap.  It is not a direct proof of the Lean
`WeightedMoment` field.

The route audited in T405 is the correct weighted replacement of this stopping
argument.  It freezes one prefix weight for a coordinate estimate, proves the
weighted differential inequality up to every moving endpoint `u_k`, sums the
coordinate family, and only then transfers the widened weight to the fixed
interface weight.  This preserves the paper's causal order: initial data at
`s_N`, running estimates on `[s_N,u_k]`, and a conclusion at `u_k`.

## Exact available interfaces

For `d = Dims.exampleGrow`, fixed `|E| < 2`, `D >= 60`,
`0 <= s_N <= t_N < 1`, `c > 0`, and the original
`Cond272Reg (band d) E s t c`, T479 packages

```text
Good_N = {omega | ||Xmat_N(omega)|| <= N},
Kmod = 2D+7,
gamma = 1/2,
mesh_N = targetMesh D N,
Ccard = 4D+19.
```

It proves, eventually in `N`, uniformly for all `omega in Good_N` and all
`v,w in [s_N,t_N]`,

```text
|jSnorm_N(v,omega)-jSnorm_N(w,omega)|
  <= N^(2D+7) |v-w|^(1/2),
N^(2D+7) (1/mesh_N)^(1/2) <= 1,
(t_N-s_N) mesh_N + 2 <= N^(4D+19).
```

The event is measurable, high probability, and nonempty for every `N`, with
the explicit member `omega = 0`.  T479 also contains a witness satisfying the
same original `Cond272Reg` for which `s_N < t_N` eventually, so the window is
not made vacuous by equality of its endpoints.

For the same `jSnorm`, `APrimeWeight.jSnorm_piecewiseW_fields` supplies the
measurability, nonnegativity, upper bound by one, and prefix domination of the
order-independent `piecewiseW`.  Its comparison theorem gives, pointwise and
at each requested order,

```text
piecewiseW delta N k <= widenedW p delta N k.
```

Consequently `weightedMoment_of_widened_family` loses no power of `N`, no
bandwidth power, and no time factor when it turns `hfamily` into the literal
`WeightedMoment` with `lev = Theta = 1`.

## Exponent ledger for the missing producer

Write `A_u = W_N ell_u eta_u` and
`x_u = eta_s/eta_u`.  Positive support of the active widened prefix weight at
order `p >= 1`, together with the T479 modulus and mesh estimate, gives the
safe running cap

```text
jSnorm_N(u) <= (4 exp(1)+2) N^(2 delta),
u in [s_N,u_k], omega in Good_N.
```

The exact raw interpolation gives `4 exp(1) N^(2 delta)+1`; the displayed
constant uses `N^(2 delta) >= 1`.  This is a prefix statement: it reaches the
moving endpoint `u_k`, but does not assert control after `u_k`.

Substitution into the actual drift/QV shapes has the same powers recorded in
T405.  With the small block-comparison loss `tau` and a reserved source loss
`nu`, the positive-power rows are

```text
drift:
  N^(4 delta) A_u^(-1) x_u^6,
  N^(2 delta+tau) A_u^(-1/2) x_u^(11/4),
  N^(3 delta+3 tau/2) A_u^(-1) x_u^(9/2),

current QV:
  N^(4 delta+2 tau) A_u^(-1/2) x_u^(19/4),
  N^(6 delta+3 tau) A_u^(-1) x_u^8.
```

Thus the quadratic and cubic powers in paper (5.42) cost respectively
`N^(4 delta)` and `N^(6 delta)` after the `N^(2 delta)` support cap.  The
bandwidth tail floor remains `W_N^(-D)` inside the source estimates; it is not
discarded or replaced by a first-cell rate.  The two separate facts
`N^c <= A_t` and `x_t^30 <= A_t` from `Cond272Reg` absorb these rows.  No
strengthened product hypothesis `N^c x_t^30 <= A_t` is needed.

At the family step, the endpoint identity is

```text
jSnorm_N(u_k) = R_k^(-4) + max_a |Y_(k,a)|
              <= 1 + max_a |Y_(k,a)|.
```

The required coordinate norm is `C_p N^(5 delta/32)`.  Its `2p` moment has
power `N^(5 delta p/16)`.  Summing at most `L_N^2 <= N^2` coordinates gives

```text
N^2 * N^(5 delta p/16) <= N^(delta p/2)
```

exactly when

```text
32 <= 3 delta p.
```

The unused exponent margin is `3 delta p/16 - 2`.  For a small requested
order `p`, choose a higher integer `P >= p` with
`32 <= 3 delta P` (and, in the T405 budget, `1/P <= delta/8`) before `N`,
prove the coordinate estimate under one fixed target-order weight, and apply
weighted Lyapunov under that same subprobability measure.  Switching from
`widenedW P` to `widenedW p` inside Lyapunov is invalid because those are
different measures.  The final cutoff can only decrease the integrand.

The later first-failure argument has per-index probability
`C_p N^(-3 delta p/2)`.  Since the mesh has at most polynomial size
`N^(4D+19)`, the moment order is chosen after `delta` and the desired failure
power, but still before `N`.  This union bound is downstream of
`WeightedMoment`; it is not an input to `hfamily`.

## Quantifier and boundary audit

- `p = 0`: handle separately.  The widened power and the observable power are
  both zeroth powers, so the probability integral is at most one.  No support
  implication, division by `p`, or Lyapunov argument is used.
- `p >= 1`: positive widened weight implies positive base prefix cutoff on the
  active branch.  This is the premise needed for the running cap above.
- `k = 0`: the prefix derivative and all time integrals vanish; use the
  left-endpoint initial moment.  No nonexistent predecessor `k-1` is used.
- `s_N = u_k`: all time integrals vanish.  The argument remains valid at
  `s_N = 0`; the `u^(-1/2)` term is integrable and must not be replaced by an
  invalid `log(1/s_N)` estimate.
- A final partial mesh interval is covered by the T479 modulus.  It does not
  require an extra active prefix index.
- The same fixed `Good_N = {||Xmat_N|| <= N}` is used for the modulus and mesh
  propagation.  Auxiliary source events may be paid for inside the
  unconditional moment estimate, but they may not silently replace `Good` in
  `APrimeHypOn`.
- The favorable estimates are conditional on `Good_N` and positive cutoff
  support.  That intersection is not assumed high probability.  `Good_N`
  itself is nonempty for every `N`; the admissible window has eventual positive
  length.  `APrimeHypOn` does not require a separate nonemptiness field for the
  cutoff support, so a toy nonconstant weight witness cannot substitute for
  the missing model moment proof.

## First-cell exclusion and dependency graph

`APrimeSupportRunning`, the first-cell drift/QV files, and the first-cell
higher-moment cutoff files specialize to data such as `E=0`, `D=60`, `s=0`,
`t<=1/2`, and their own transition mesh.  They are valid examples and local
producers, but none can be used as a theorem for the arbitrary moving window
of T479.  In particular, first-cell powers `N^122`, `N^248`, or special
bandwidth gains are not premises of the general-window argument.

The acyclic dependency order is

```text
current BoundsCore at s_N + pre-A-prime Step 1 + Cond272Reg
  -> general-window source, drift, full-QV, and integrability estimates

T475 modulus + T478 fixed Good/mesh
  -> T479 moving event/modulus/mesh package
  -> running prefix support cap through each u_k

the two branches above
  -> uniform coordinate weighted moments at each moving u_k
  -> L_N^2 family reduction and same-measure Lyapunov
  -> widened-weight hfamily
  -> weightedMoment_of_widened_family
  -> moving-window APrimeHypOn / APrimeSlot'
  -> paper (2.76) first-pass conclusion
  -> Steps 3--5
  -> next-cell BoundsCore.
```

Only the current window's `BoundsCore` at `s_N` is an input.  Feeding the
next-cell `BoundsCore`, paper (2.76), or the A-prime conclusion back into the
coordinate moment proof would create a cycle and is not allowed.

## Bounded Lean follow-up

The next bounded implementation ticket should prove the **general moving
prefix-support adapter**, not a conditional slot constructor and not
`hfamily` itself.  Under the exact T479 hypotheses, for each fixed
`0 < delta <= delta0` and `p >= 1`, it should show eventually in `N`, uniformly
in every `k <= cutNetTop`, that

```text
omega in Good_N ->
0 < widenedW p delta N k omega ->
forall u in [s_N,u_k],
  jSnorm_N(u,omega) <= (4 exp(1)+2) N^(2 delta).
```

The proof uses only `APrimeWeight.le_of_prefixSoftW_ne_zero_of_modulus`, the
T479 modulus/fineness fields, and the active-branch facts `N >= 1` and
`k <= cutNetTop`.  It has no new stochastic hypothesis, no bandwidth or time
loss, and no first-cell specialization.  A separate trivial lemma should
record `p=0` for the later moment producer.

After that adapter, the first genuinely stochastic ticket is the uniform
general-window coordinate estimate with the actual drift, full QV,
prefix-gradient cross term, interval integrability, and the fixed-p-before-N
quantifiers above.  Only its completion, followed by the existing family
reduction, can produce `hfamily`.
