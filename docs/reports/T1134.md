# T1134 — independent final audit of the T1133 actual cross-budget integral bound

## Verdict: PASS — proved as written, within its polynomial-envelope scope

The audited theorem is
`RBM.APrimeGeneralMovingCrossBudgetIntegralBound.eventually_integral_positive_time_cross_budget_le`.
For fixed `p ≥ 1`, `|E| < 2`, `D ≥ 60`, nonnegative loss `deltaWeight`, and the stated moving-window/`Cond272Reg` hypotheses, it proves eventually in `N`, uniformly for every active `k` and output `a`,

```text
∫_[s N, v] positiveTimeCrossBudget E D deltaWeight s t N k p a r dr
  ≤ 2 · envelopeConstant p N D · (√v − √(s N)),
v = cutNetPt s (targetMesh D) N k,
envelopeConstant p N D = crossMomentCoeff p / (4p) · N^(2D+17).
```

The integral is of the *actual* T1089 budget, whose `momNorm` uses the canonical smooth weight through `jointRate`, `Gauss.P Dims.exampleGrow`, and `Step2.sigPM`. It is not a new deterministic budget definition.
