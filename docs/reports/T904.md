## Exact claim and constant

Write

```text
z_u(x) = (√u · x : ℂ) - i(1-u),     g_u(x) = z_u(x)⁻¹.
```

For `0≤u,v≤1/2`, put `δ=|u-v|`. Then `δ≤1/2≤1`, and the square-root estimate gives
`|√u-√v|≤√δ`; also `δ≤√δ`. For `|x|≤2`,

```text
‖z_u(x)-z_v(x)‖
  ≤ |x| |√u-√v| + |u-v|
  ≤ 2√δ + δ
  ≤ 3√δ.
```

The imaginary-part gap is `‖z_w(x)‖≥1-w≥1/2` for either `w=u` or `w=v`; hence both inverse norms are at most `2`. The inverse-subtraction identity therefore gives

```text
‖g_u(x)-g_v(x)‖
  = ‖z_v(x)-z_u(x)‖ ‖z_u(x)⁻¹‖ ‖z_v(x)⁻¹‖
  ≤ (3√δ)·2·2 = 12√δ.
```

All inequalities are non-strict, so endpoints are included. In particular at `(u,v)=(0,1/2)` and `x=±2`, `δ=1/2`; the same denominator lower bounds and `|x|=2` estimates apply with no limiting argument or division by `√u`. The bound is conservative rather than sharp; the requested constant is exactly accounted for as `3 × 2 × 2`.

## Repository producer/API check

Inspected `RBM1D/Defs/SemicircleFlowResolvent.lean` and `RBM1D/Defs/SemicircleQuadrature.lean`.

* Accepted public gap theorem:

  ```lean
  RBM.semicircleFlowResolvent_denominator_gap
    (u x : ℝ) (hu : u ≤ 1 / 2) :
    1 - u ≤ ‖((Real.sqrt u * x : ℝ) : ℂ) - Complex.I * ((1-u : ℝ) : ℂ)‖
  ```

  It does not require `x` bounds or `u≥0`. Its proof uses `Complex.abs_im_le_norm`; the new result separately needs `hu0`/`hv0` for square roots.

Importing `SemicircleQuadrature` just for them is unnecessary and pulls in quantile-cell dependencies.

  ```lean
  {x y : ℝ} → 0 ≤ x → 0 ≤ y →
    |Real.sqrt x - Real.sqrt y| ≤ Real.sqrt |x-y|
  ```

  Its statement is exactly the needed Hölder bound, but importing a `Gauss` module into `Defs` would reverse the project layering. Its short proof only uses `le_total`, `Real.sqrt_le_sqrt`, `Real.sq_sqrt`, `Real.sqrt_nonneg`, `mul_le_mul_of_nonneg_right`, and `nlinarith`; copy the proof locally as a private helper, or locate a suitable lower-layer Mathlib theorem during implementation.

This avoids relying on an unverified named `inv_sub` lemma. A time-difference helper should first unfold/restatement of the public kernel, establish both denominators nonzero from the gap, then use the same field simplification pattern.

The full proposed time-modulus theorem was not implemented or compiled in this preflight.

Suggested public interface, in a new module importing only `RBM1D.Defs.SemicircleFlowResolvent`:

```lean
def semicircleFlowKernel (u x : ℝ) : ℂ :=
  (((Real.sqrt u * x : ℝ) : ℂ) - Complex.I * ((1-u : ℝ) : ℂ))⁻¹

theorem semicircleFlowKernel_time_modulus
    (u v x : ℝ) (hu0 : 0 ≤ u) (hv0 : 0 ≤ v)
    (hu : u ≤ 1 / 2) (hv : v ≤ 1 / 2) (hx : |x| ≤ 2) :
    ‖semicircleFlowKernel u x - semicircleFlowKernel v x‖
      ≤ 12 * Real.sqrt |u-v| := ...
```

This is P3 verbatim with the parameter domain made explicit. The `hx` hypothesis is precisely where the semicircle support enters. Public kernel syntax makes the modulus usable by a later Fourier interpolation module without exposing the quadrature implementation.

## Nonconstant endpoint witness

Take `u=0`, `v=1/2`, `x=1`. Then `g_0(1)=Complex.I`, while `Re(g_{1/2}(1))>0`, so the two time-endpoint values are distinct. The positivity follows from `kern_inv_re` in `SemicircleFlowResolvent.lean` and positivity of `sqrt(1/2)`. This is a nonconstant witness for the closed time interval, not merely a spatial nonconstancy witness. Existing `semicircleFlowResolvent_half_nonconstant` separately certifies spatial nonconstancy at `u=1/2`, comparing `x=0` and `x=1`.
