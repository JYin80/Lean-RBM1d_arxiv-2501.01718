## Mathematical preflight

I checked `T1097`, `T1103`, the accepted general-moving T475 producer, and
their literal model and event definitions. On `good N`, T475 gives

```text
|jSnorm(v) - jSnorm(w)| ≤ N^(2D+7) |v-w|^(1/2).
```

The target mesh is eventually `N^(4D+18)`. For an active `k ≤ N^4`,
`cutNetPt(k)` lies in `[s_N,t_N]` and its displacement from `s_N` is
`k/mesh ≤ N^4/N^(4D+18) = N^(-4D-14)`. Thus the T475 modulus changes
`jSnorm` by at most `1` on the same sample in `good N`. The Lean proof uses
the equivalent accepted mesh inequality
`N^(2D+7) * mesh^(-1/2) ≤ N^(-2)` and multiplies by `N²`.

The T1103 cutoff argument applies unchanged at every such `k`: `cutTrunc`
is globally `19/4`-Lipschitz, the actual order-`q` widened weight is
measurable and lies in `[0,1]`, and the endpoint and left-endpoint values
are evaluated at the same Gaussian sample. Pointwise on `good N`,

```text
widenedW(k) * |cutTrunc(jSnorm(k))|^(2q)
  ≤ 2^(2q) (|cutTrunc(jSnorm(s_N))|^(2q) + (19/4)^(2q)).
```

The first term is exactly the T1097 empty-prefix integral, bounded by
`C₀ N^(δq/2)`. Since `δq/2 > 0`, the fixed cutoff-error term is absorbed
eventually into the same `N^(δq/2)` rate. Integrability follows from the
literal cutoff envelope and the probability measure; no moment assumption
was added.

The formulas in the authorized paper were checked visually in
`paper/250520-YinJun-v2.pdf`: (2.69) is an initial loop bound, (5.21) is the
integrated loop-hierarchy identity, and (5.44) is a stopped quadratic-
variation bound. None directly states this static widened-prefix moment.
This theorem supplies only its good-event model contribution using the
existing `BoundsCore` initial law and T475 modulus.
