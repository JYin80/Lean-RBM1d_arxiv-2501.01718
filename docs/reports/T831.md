# T831 — eventual uniformity from every admissible sequence

## Scope and result

`RBM1D/Flow/EventuallyUniformBySequences.lean` proves the pure logical theorem
`RBM.eventually_forall_of_forall_sequences`. For arbitrary `α` and predicates
`A0 A1 P : ℕ → α → Prop`, it assumes a base `b` satisfying `A0 n (b n)` for every
`n` and `A1 n (b n)` eventually. If every sequence satisfying those two
conditions has `P n (f n)` eventually, then eventually every `z` satisfying
both current-index conditions has `P n z`. The proof chooses a counterexample
at each bad index and uses `b` elsewhere. Cofinally many bad indices would
contradict the sequence premise. No uniform-in-`z` premise is inserted.

The same file proves `RBM.eventually_uniform_bool_satisfiable`. At `n = 0`,
both Boolean values satisfy `A0` and `A1`, while `P 0 true` fails. From `n = 1`
onward, `P n z` holds for both values. The base is constantly `false`. Thus
the premise is satisfiable and the eventual quantifier cannot be replaced by
an all-index assertion. This also tests the finite prefix and `n = 0` boundary.
