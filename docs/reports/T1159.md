# T1159 — public fixed-order high moment at the moving left endpoint

## Verdict: mathematical preflight PASS; exact fixed-order theorem proved

The new public theorem
`RBM.APrimeGeneralMovingHighQK0FixedOrder.eventually_fixed_order_high_k0`
proves the requested order-`q` estimate for every fixed `q ≥ 1` and every
`δ > 0`, under the same `E,D,s,t,c`, `Cond272Reg`, and `BoundsCore` inputs as
T1097. It keeps the actual target mesh, `Dims.exampleGrow` Gaussian sample,
`widenedW`, `cutTrunc (N^(2δ))`, `jSnorm`, and empty-prefix `k=0` observable.
For each fixed pair `(δ,q)`, its type chooses `C > 0` before the eventual
`N` bound, and the right side is exactly `C N^(δq/2)`. There is no existential
order in the public result.

This is an auxiliary fixed-order Gaussian moment producer, not a formalization
of (5.43) or (5.44). The authorized paper PDF’s formulas (5.43)–(5.44), as
recorded in the direct inspections for T1097 and T1135, concern the stopping
threshold and the stopped time-integrated quadratic-variation estimate.
Neither formula directly asserts this static initial-endpoint expectation.

## Mathematical preflight

- **Actual T1097 producer.** Its public `eventually_selected_high_k0` takes
  `δ₀`, `δ`, and input order `p`, and returns some `q₀ ≥ p` with a high-order
  moment bound. The implementation uses the initial `BoundsCore` law,
  `stochDom_jSnorm_init_of_boundsCore`, and the literal truncated observable;
  it does not assume a later-cell estimate. Setting `δ₀=δ` removes the
  otherwise irrelevant upper restriction on `δ`.
- **Why arbitrary fixed `q` is valid.** The existential output order is not
  exposed as equal to its input in T1097's theorem type. The new proof
  therefore follows T1135's accepted private fixed-order pattern: retain
  `q₀ ≥ q`, identify the empty-prefix weight as exactly one for every order,
  and apply the probability-space low-moment transfer to the same cutoff
  random variable. It gives constant `C₀^(q/q₀)` and exponent
  `(δq₀/2)(q/q₀)=δq/2`. Truncated powers are integrable at every `N`; the
  transfer is applied eventually where `N≥1`.
- **Empty prefix.** `cutNetPt ... N 0 = s N`, and `Finset.range 0` is empty.
  Thus `softMax=0`, the prefix cutoff equals one, and T1097's `widenedW`
  equals one for every order and sample. The helper proves this in the new
  module for both `q₀` and `q` rather than treating the selector's weight as
  order-independent without checking its definition.
- **Satisfiability.** T995's `scheduled_positive_cell_witness` supplies one
  nondegenerate model with `E=0`, `D=60`, `c>0`, `s_N=0`, `Cond272Reg`, and
  `BoundsCore`, together with an eventually active first positive cell and a
  sample in the same common event with positive actual smooth weight. T1097's
  `positive_length_k0_witness` instantiates the k0 bound on that model. This
  confirms the shared hypotheses are jointly satisfiable; it is not used as a
  substitute for the general theorem.
