## Mathematical audit

* `unusedImages W k π` means `∀ i < k, π i ≠ v`; the local proof correctly converts this to `k.val ≤ (π.symm v).val`. This uses injectivity and both inverse identities, not a distributional assumption.
* The explicit equivalence in `PermutationUnusedImageMarginal.lean:36–84` sends an event permutation `π` to its inverse position `j = π.symm v` and the permutation `ρ = (swap 0 j).trans π`, for which `ρ 0 = v`. Its inverse swaps the positions back. The left and right inverse proofs establish an actual bijection, including `j=0` and the last position.
* The remaining-position subtype has cardinality `W-k.val`, so the event has cardinality `(W-k.val) × card {ρ | ρ 0=v}`. Both event masses are computed as finite cardinality divided by `card (PermΩ W)`. `uniformPerm_firstImage` supplies the independently proved first-image mass `1/W`. It is upstream through `PermutationFiberFirstPartition`/`PermutationFiberCount`/`PermutationFiberSwap`; it neither imports nor assumes the T816 target. No conditional law is used.
* `W=0` has no `k : Fin W`. At `W=1,k=0` and `W=2,k=0`, the mass is one; at `W=2,k=1` it is one half. The source proves that for `v=1`, identity belongs to the `W=2,k=1` event and the transposition does not. The last valid `k` gives `1/W`. For every valid `k`, `W>0`, the ENNReal denominator is finite and nonzero, and the event mass is positive. These are explicit Lean theorems, not only numerical examples.
