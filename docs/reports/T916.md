# T916 — normalized finite Fourier flow-time modulus preflight

## Verdict

**PASS — deterministic adapter is valid as stated for `W ≥ 1`, and the current Lean
APIs typecheck with the proposed new-module interface.** No Lean source was added.

The claim is: for `W ≥ 1`, `λ : Fin W → ℝ`, `χ : Fin W → ℂ`,
`|λ j| ≤ 2`, `‖χ j‖ ≤ 1`, `π : Equiv.Perm (Fin W)`, and
`0 ≤ u,v ≤ 1/2`,

```text
‖permutationFourierSum W (fun j => semicircleFlowKernel u (λ j)) χ π
 - permutationFourierSum W (fun j => semicircleFlowKernel v (λ j)) χ π‖
≤ 12 √|u-v|.
```

This is the deterministic normalized finite-Fourier adapter for the T668 §4 (P3)
interpolation step. It assumes no concentration or random-matrix event.

## Proof/API audit

The inspected definitions are `RBM.Gauss.permutationFourierSum` in
`RBM1D/Gauss/PermutationFourierSwap.lean` and
`RBM.semicircleFlowKernel` in `RBM1D/Defs/SemicircleFlowKernelTimeModulus.lean`.
The latter's pointwise theorem already gives the exact closed-interval bound
`12 √|u-v|` whenever `|x| ≤ 2`; T905/T906 establish its endpoint handling and
nonconstant witness. The prescribed PDF uses the `(x-z)⁻¹` Stieltjes convention
(immediately before (2.1)); the inspected flow kernel follows the same sign.

For each `j`, apply the pointwise kernel modulus at `x = λ (π j)` and multiply by
`‖χ j‖ ≤ 1`. Then rewrite the difference of the two normalized sums as the sum
of their termwise differences divided by `(W : ℂ)`. `norm_sum_le` bounds the
numerator by the sum of `W` copies of `12 √|u-v|`, while `norm_div` and
`Complex.norm_natCast` identify the denominator norm with `(W : ℝ)`. The explicit
`1 ≤ W` hypothesis gives `0 < (W : ℝ)` for `div_le_iff₀`, so the numerator bound
`W · (12 √|u-v|)` cancels the actual normalization exactly. No extra factor of
`W`, `π`, or `χ` remains.

The W1 endpoint witness is nondegenerate: take `λ := fun _ : Fin 1 => 0`,
`χ := fun _ : Fin 1 => (1 : ℂ)`, and `π := Equiv.refl _`. The normalized sums
are `i` at `u=0` and `2i` at `u=1/2`, respectively. Their hypotheses hold
(`|0| ≤ 2`, `‖1‖ ≤ 1`), so this directly witnesses time variation for the
finite normalized observable. W0 is excluded by the theorem's `1 ≤ W` premise;
the proof never divides by a zero real normalization.

## Proposed file-disjoint module

Add `RBM1D/Gauss/PermutationFourierFlowTimeModulus.lean`, importing the two modules
above, under `namespace RBM.Gauss`. The main public declaration can be named
`norm_permutationFourierSum_flow_time_modulus` with arguments
`(W) (hW : 1 ≤ W) (lam : Fin W → ℝ) (χ : Fin W → ℂ)`, pointwise bounds on `lam`
and `χ`, `π`, `u`, `v`, and the four closed-time inequalities. Its conclusion is
the displayed norm bound. A second declaration can expose the W1 equalities
`i` and `2 * i` as the endpoint witness. The following is the scratch-compiled public type (Lean uses `lam`, since `λ` is
a syntax token):

```lean
theorem norm_permutationFourierSum_flow_time_modulus
    (W : ℕ) (hW : 1 ≤ W) (lam : Fin W → ℝ) (χ : Fin W → ℂ)
    (hlam : ∀ j, |lam j| ≤ 2) (hχ : ∀ j, ‖χ j‖ ≤ 1)
    (π : Equiv.Perm (Fin W)) (u v : ℝ)
    (hu0 : 0 ≤ u) (hv0 : 0 ≤ v) (hu : u ≤ 1/2) (hv : v ≤ 1/2) :
    ‖permutationFourierSum W (fun j => semicircleFlowKernel u (lam j)) χ π -
      permutationFourierSum W (fun j => semicircleFlowKernel v (lam j)) χ π‖
        ≤ 12 * Real.sqrt |u-v|
```

The compiled proof rewrites both `permutationFourierSum` definitions, combines the
quotients with `← sub_div`, moves subtraction under the finite sum with
`← Finset.sum_sub_distrib`, applies `norm_div` and
`Complex.norm_natCast`, and uses `div_le_iff₀` with `exact_mod_cast hW` to cancel
the denominator. The summand proof rewrites `a*b-a*c` with `← mul_sub`, applies
`norm_mul_le`, and invokes `semicircleFlowKernel_time_modulus`.
