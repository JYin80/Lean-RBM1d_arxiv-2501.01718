## 4. Quantifiers, boundaries, and exact powers

Specializing `Band.eventually_flow_grid'` at `kappa=1` and `tau=1/2` makes its internal
choices explicit:

```text

tauPrime  = tau0/120     = 1/480,
c         = tau0/16      = 1/64,
n0        = ceil(2/tauPrime) = 960.
```

The witness uses only the first step, not `n0`:

```text
s_N = gridT W_N (1/480) (1/2) 0 = 0,
t_N = gridT W_N (1/480) (1/2) 1
    = min(1 - W_N^(-1/480), 1/2).
```

The cap hypothesis is exactly `N^(-1/2)≤1/2` eventually.  Since `W_N→∞`,
`W_N^(-1/480)→0`; hence

```text
∀ᶠ N, W_N^(-1/480) < 1/2,
∀ᶠ N, t_N = 1/2,
∀ᶠ N, s_N < t_N.
```

The gained grid inequality at `k=0` is the source of `c=1/64`; converting it to
`Cond272Reg` discards only the factor `((1-s_N)/(1-t_N))^30≥1` in the regime component.
There is no altered `N`, `W`, or time exponent.

All boundary cases pass:

- `k=0` is handled by `gridT_zero`, not by an asymptotic rewrite;
- both domain inequalities `0≤s_N≤t_N<1` hold for every `N`;
- positive duration is eventual and becomes exactly `1/2`, so the witness is not a
  collapsed-window construction;
- `BoundsCore` is at the identical function `s`, transported from exact zero only through
  the proved equality `s_N=0`;
- the same `tauPrime`, `c`, `s`, and `t` are used for regularity and duration.
