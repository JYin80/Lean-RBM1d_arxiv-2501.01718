# T914 — simultaneous finite Fourier bounds for one permutation

## Result

**Standalone proof PASS.** In
RBM1D/Gauss/PermutationFourierFiniteExistence.lean,
exists_permutationFourierSum_norm_lt_of_union_bound proves that for W ≥ 2,
T ≥ 1, a table x : Fin T → Fin W → ℂ with ‖x t j‖ ≤ 2, r > 0, and

    4 * (T * (W - 1) : ℝ) * exp(-W r² / 256) < 1,

there is one permutation π for which every nonzero canonical Fourier mode
at every time has norm strictly below r.

For each time/mode pair, the bad event is the weak event r ≤ ‖F‖. The
accepted T901 zero-character tail bounds its uniform measure by
4 exp(-W r²/256). The exact index set is
Fin T × (Fin W).erase q₀, whose cardinality is T * (W - 1). Mathlib's
finite union measure bound makes the union's measure strictly smaller than
one. Since the uniform permutation measure has total mass one, some permutation
lies outside that union. This complement gives the desired strict inequality,
including the equality boundary ‖F‖ = r.

The public helper permutationFourierCharacter_norm_eq_one verifies the
canonical character's norm-one bound directly from its complex exponential.
The zero-character cancellation is supplied by the canonical
permutationFourierCharacter_sum_zero theorem.

## Nondegenerate witness

permutationFourierFiniteExistence_nonempty_bad_witness uses W = 8192,
T = 1, r = 1, q = 1, and x j = 2 * conj(χ₁(j)). Every entry has norm
two, and the table is nonconstant. At the identity permutation the mode-one
Fourier sum equals 2, so the weak bad event is nonempty. The numeric premise
is 32764 * exp(-32) < 1; the proof uses exp(1) ≥ 2, hence
exp(32) ≥ 2^32 > 32764.
