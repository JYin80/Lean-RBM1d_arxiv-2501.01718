`[1 + (Σ_a (√(‖(L−K)_{u,a}‖²+ε²)/T_{u,D}(a))^(2m))^(1/(2m))] / R_u⁴`, `R_u=η_s/η_u`.

`smoothJS ≤ [1 + card(LoopArg)^(1/(2m)) (max_a ‖(L−K)_{u,a}‖/T_{u,D}(a) + ε/Tmin)] / R_u⁴`.

The max here is the finite `Finset.univ.sup'`, exactly the hard maximum inside `Step2.jS−1`; the denominator floor is `rpow_neg_le_tailT`. The generic lemmas `sqrt_sq_add_sq_bounds`, `hard_le_smooth`, `smooth_le_hard_add`, and `hardJ_sandwich` establish the inequalities without a random event or first-pass input. The formulation allows `ε=0` for the sandwich but requires `ε>0` for smoothness.
