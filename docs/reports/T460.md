## 1. Generic support-aware split

The theorem

```text
weighted_norm_le_of_weighted_event
```

is the probability-space variant of
`APrimeBadSplit.weighted_norm_le_of_event`.  Its favorable premise is the
strictly weaker support-aware statement

```text
W omega * |Z omega| <= W omega * good,   omega in E,
```

together with `0 <= W <= 1`, integrability of `W * |Z|^q`, the global bound
`|Z| <= Env`, measurability of `E`, and the exact complement bound
`(P E^c).toReal <= pr`.  It proves

```text
(integral W * |Z|^q)^(1/q)
  <= good + Env * pr^(1/q).
```

The proof uses the same root-scaled variable

```text
Zr omega = W omega ^ (1/q) * Z omega
```

as the accepted split.  On `W omega = 0`, `Zr omega` is proved literally
zero.  On `0 < W omega`, the weighted favorable inequality is cancelled by
the positive weight, after which `W^(1/q) <= 1` gives `|Zr| <= good`.  The
existing `Gauss.momNorm_le_affine_on_event` then applies.  There is no
division in the zero-weight branch.

`drift_norm_le_of_weighted_event` specializes `q = 2p` and exports the
result in `momNormW` notation:

```text
momNormW P W p G
  <= A + Env * pr^(1/(2p)).
```

## 2. Actual first-cell specialization

cutoff.  Eventually in `N`, uniformly for every active `k >= 1`, with the
literal moving endpoint

```text

```

every `r in [0,v]` and every two-loop output `a`, it states the exact bound

```text
momNormW (P d) (weight tauPrime delta p N k) p (G N k a r)
  <= endpointCoefficient delta (2*alpha) N v r
     + driftConstant * N^61 *
         ((P d) (sharpCommonEvent tauPrime delta alpha N)^c).toReal

```

Here `weight` is T451's canonical actual smooth weight and `G` is the actual
normalized `driftAt`.  `actualDriftNormSplit_of_inputs` uses the following

`r in [0,u_2]` and every output.

plateau.  The norm bound itself uses the canonical smoothing order from
T451.  No claim equating these two smoothing orders is made.
