## Scope and result

The two public theorems are:

```lean
RBM.CarrierCutoffTime.continuousOn_ell
  (B : Band Ω) (N : ℕ) {a b : ℝ} (hb : b < 1) :
  ContinuousOn (fun u : ℝ => B.ell N u) (Set.Icc a b)

RBM.CarrierCutoffTime.continuousOn_ellStar_half
  (B : Band Ω) (N : ℕ) {a b : ℝ} (hb : b < 1) :
  ContinuousOn (fun u : ℝ => ellStar (B.W N : ℝ) (B.ell N u) / 2)
    (Set.Icc a b)
```

The first proof expands the actual `Band.ell` and `ellHat`; for every `u∈[a,b]`, `u≤b<1` makes the square-root denominator nonzero. It proves continuity on the closed interval itself, including `a` and `b`. The second proof composes that result with the actual `ellStar W ℓ = (log W)^(3/2) ℓ` and divides by the constant `2`. No exponent, bandwidth, or time condition is weakened. `Band.W_pos N` also gives `(0:ℝ) < B.W N`; the continuity argument only needs the fixed real coefficient because `Real.log` is a total function.

The paper's (5.27)–(5.29) supply the far-cutoff context. This result is a lower-level deterministic continuity fact, rather than a claim about the random ratio or a carrier. It introduces no new hypothesis or paper-delta.
