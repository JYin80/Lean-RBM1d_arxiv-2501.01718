## Indicator and quantifier audit

Fix the Step 1 `Hyp` above. `Step1.apriori` at `n=2` gives, uniformly in **time and every loop label**,

```text
|L_{u,(+,-),(a,b)}| ≺ Φ_u,
Φ_u := (ell_u/ell_s) A_u^{-1}.
```

Precompose the length-two loop index by `Step45.pmData` and insert the `goodEv` indicator (which only decreases a nonnegative norm). This is exactly the conversion used inside `Step1.weakLaw_highProb` (`Hierarchy/Step1.lean:706–724`). Applying the same `Hyp.lemma41` yields

```text
1_{goodEv(u)} llMax_u² ≺ Φ_u + W^{-1}
```

with `TimeIcc s t N` **inside the `StochDom` index set**. Independently, `Step1.weakLaw_highProb` from the same `Hyp` and domain data produces one `HighProb` event on which, simultaneously for every `u` in this first cell, `llMax_u < A_u^{-1/4}`. The scale facts give `A_u≥N^c≥1` eventually, hence `A_u^{-1/4}≤A_u^{-1/6}` and every such `u` lies in `goodEv(u)`. `Step1.stochDom_of_indicator` removes the indicator by intersecting this uniform good event with the domination event, choosing the tail exponent `D+1` to pay for the two exceptional probabilities. It does **not** choose a different sample point for each time. The use of `weakLaw_highProb` is not circular: its proof starts from the independent indicator estimate (5.8), applies Lemma 4.1, then performs the continuity bootstrap; it does not use the desired sharp `W^{-1/2}` law.

For `E=0`, `s=0`, and every `u≤1/2`, `ell_0=1`, `A_u=W ell_u eta_u`, and `eta_u=1-u≥1/2`. Thus the cancellation is exact:

```text
Φ_u = (ell_u/ell_0)/A_u = 1/(W eta_u) ≤ 2/W,
Φ_u + W^{-1} ≤ 3/W.
```

Consequently `llMax² ≺ 3/W` on the common time-indexed family. `StochDom.sqrt_of`, `llErr≤llMax`, and `sample.llErr_eq` give every Green-entry error at control `sqrt(3/W) = 2 sqrt(3)·firstCellPsi`. This absorbs the fixed constant without altering the probability exponent. `GoodSetFlow.unifDomIcc_of_stochDom_timeIcc` then gives `LocalLawUnifIcc` directly; its event quantifier is weaker (each fixed time, uniformly in time) than the already obtained time-indexed `StochDom` event.
