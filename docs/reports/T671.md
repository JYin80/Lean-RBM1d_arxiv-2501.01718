## Zero mode and Stieltjes identity

Let `rho_sc(dlambda) = sqrt(4-lambda^2)/(2 pi) dlambda` on `[-2,2]`. For `u>0`, put `y=(1-u)/sqrt(u)` and `z=iy`. With the repository's resolvent convention `m_sc(z)=int (lambda-z)^(-1) rho_sc(dlambda)`, the upper-half-plane root is

```text
m_sc(iy) = i (sqrt(y^2+4)-y)/2 = i sqrt(u),
```

because `sqrt(y^2+4)=(1+u)/sqrt(u)`. Therefore `int g_u drho_sc = m_sc(iy)/sqrt(u)=i`. At `u=0`, `g_0(lambda)=(-i)^(-1)=i` identically, so the identity holds on the **closed** interval; there is no division by `sqrt(0)` in this branch.

```text
|partial_lambda g_u(lambda)| <= sqrt(u)/(1-u)^2 <= 2 sqrt(2).
```

## Finite permutation concentration: constants checked

For any finite complex table `x_j` with `|x_j|<=2`, any `W>=2`, and `q in {1,...,W-1}`, define

```text
F_q(pi) = W^(-1) sum_{j=0}^{W-1} x_(pi(j)) exp(2 pi i qj/W).
```

Under the uniform law on `Equiv.Perm (Fin W)`, each `pi(j)` is uniform, and the nonzero character sums to zero; hence `E F_q=0`. Swapping two images changes only two summands and gives

```text
|F_q(pi)-F_q(pi')|
 = W^(-1)|x_a-x_b| |chi_q(j)-chi_q(k)| <= 8/W.    (P1)
```

Here is the missing conditional step behind T668's Azuma invocation. Reveal `pi(0),...,pi(W-1)` in order. Given the first `k-1` images, couple completions with two possible values `a,b` for `pi(k)` by swapping **codomain values** `a,b` throughout the remaining permutation. Every coupled pair differs by exactly the transposition in (P1). Consequently, the conditional expectations for any two possible next images differ by at most `8/W`, separately for real and imaginary parts. The Doob difference from their conditional average is therefore bounded in absolute value by `8/W`. The last reveal is deterministic, but counting all `W` steps is conservative.

The ordinary two-sided real Azuma bound with `W` increments bounded by `8/W` is

```text
P(|Re F_q| >= a) <= 2 exp[-a^2/(2 W(8/W)^2)]
                   = 2 exp[-W a^2/128],
```

and likewise for the imaginary part. Since `|F_q|>=r` implies one coordinate has absolute value at least `r/sqrt(2)`, the union gives exactly the **valid, conservative** bound

```text
P(|F_q| >= r) <= 4 exp(-W r^2/256).                (P2)
```

There is no missing factor of two in the denominator. A range-width Hoeffding argument could improve the exponent, but is unnecessary. What is missing is a repository theorem implementing the finite coupling/martingale/counting implication; invoking Azuma in prose is not internal evidence.
