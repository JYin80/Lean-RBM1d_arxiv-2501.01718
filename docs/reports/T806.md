## Actual producers and noncircular route

- T711's `PermutationPrefixFiltrationCore.lean` defines `PermΩ W := Equiv.Perm (Fin W)` and `prefixSigma W n := MeasurableSpace.generateFrom (prefixCylinders W n)`, where a generator is exactly `{π | π i = a}` for `i.val < n`.
- T785's `PermutationUnusedImageCount.lean` gives `mem_unusedImages_iff`: `v ∈ unusedImages W k π ↔ ∀ i : Fin W, i < k → π i ≠ v`. Here `i < k` is equivalent to `i.val < k.val`.
- Thus the target event is exactly
  `⋂ i : {i : Fin W // i.val < k.val}, ({π : PermΩ W | π i.1 = v})ᶜ`.
  For each finite-indexed factor, its cylinder belongs to `prefixCylinders W k.val` by the witness `⟨i.1, v, i.2, rfl⟩`, hence is measurable by `MeasurableSpace.measurableSet_generateFrom`. Complements and the finite-indexed intersection preserve measurability. The existing `measurableSet_prefixCell` proof in `PermutationPrefixCellMeasurable.lean` demonstrates the same generated-cylinder intersection API without the complements.
- T804's `unusedImages_eq_of_mem_prefixCell` independently confirms that unused images are constant on an actual prefix cell. Constancy alone is not being substituted for the requested measurability theorem. The direct proof needs only T711 and T785; importing T804 is optional and does not create a cycle. No ambient `⊤` measurability or conditional distribution is used.
