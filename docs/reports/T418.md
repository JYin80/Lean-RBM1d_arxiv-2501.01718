## Result

The new predicate `allOutputBound τ' δ ν` states, on one literal T413 event

`commonEvent τ' (sourceLoss ν) (sourceLoss ν) (δ / 16)`,

that positive actual cutoff weight at exponent `δ` implies, eventually in `N`, uniformly for every real
`r ∈ [0,u_k]` and every output pair `a₁,a₂`,

`‖eGpm_r(a₁,a₂)‖ ≤ N^ν η_r⁻¹ (ell_r / ell_0)^3 T_{r,60}(d(a₂,a₁))`.

Here the module's `sourceLoss ν` is exactly
`APrimeFirstCellEGFarSmallRunning.sourceLoss (ν / 2)`.  Thus the far theorem is T412 requested at
`ν/2` on the event without any conversion.

The accepted T409 and T412 source-loss functions are not definitionally the same: T409 uses
`min (x/8) (1/2)`, whereas T412 uses `min (x/64) (1/64)`.  To keep one event, the near theorem is
requested at

`nearExponent ν = 8 * sourceLoss ν`.

The compiled identity `near_sourceLoss_eq` proves that T409's internal source loss is then exactly the
same `sourceLoss ν`.  Also `nearExponent ν ≤ ν/2`, so this is a stronger near estimate than the requested
`N^(ν/2)` loss and is absorbed into `N^ν` for `N≥1`.  No event inclusion or intersection of separately
inhabited events is used.

The cutoff premise is transferred from the actual `δ` weight to the fixed `1/100` weight by T413's
`weight_pos_transfer`.  For `d≤ellStar`, T409 gives the near bound.  For its complement, linear order gives
`ellStar≤d` and T412 gives the far bound.  The far profile is enlarged by
`1≤(ell_r/ell_0)^3`, using `ell_0=1` and `ell_r≥1` throughout the first half-cell.  Equality belongs to the
near branch.  T412's exact zero-time branch handles `r=0` in the far case, while T409 is uniform on the
closed interval in the near case.
