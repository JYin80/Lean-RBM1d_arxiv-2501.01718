# T445 — all-sample polynomial complement envelope audit

## Verdict

The required deterministic envelopes are mathematically valid at
`d = Gauss.Dims.exampleGrow`, `E = 0`, `D = 60`, on the actual moving first
cell

```text
s_N = 0,  v = u_k = cutNetPt 0 transitionMesh N k,
0 ≤ r ≤ v ≤ firstCellT τ' N ≤ 1/2.
```

They hold for every Gaussian sample `ω`, uniformly in every actual first-cell
index `k≤cutNetTop`, the two-loop label `a`, the charge label, and `r`.  No
bound on `‖Xmat ω‖`, no `Good` event, and no next-cell `BoundsCore` input is
needed.  A conservative power ledger is

```text
driftAt                                      ≤ C_F N^61,
prefixGradient = B_k                        ≤ C_B N^62,
qvAt                                         ≤ 2^21 N^136,
sqrt(qvAt)                                  ≤ C_Q N^68,
prefixGradient * sqrt(qvAt)                 ≤ C_all N^130.
```

The `B_k` and product exponents assume the actual regime `0 ≤ δ`.  For an
arbitrary fixed negative `δ`, the same all-sample statement remains true with
the additional factor `N^(-2δ)`, hence with real exponent
`62 + max 0 (-2δ)` for `B_k` and `130 + max 0 (-2δ)` for the product (or any
larger integer exponent).  Thus there is no mathematical obstruction; the
missing item is an exported Lean theorem with these quantitative constants.

The exponents are deliberately coarse.  They use T378 exactly as compiled.
A direct first-cell specialization of its derivative proof would replace the
`qvAt` exponent `136` by `124`, and the product exponent `130` by `124`, but
that sharpening is unnecessary for T361.

## Exact objects and consumer

The audited definitions are the literal repository objects.

* `APrimeDriftTimeFamily.driftAt` is

  ```text
  ‖Uker ... r v (DriftDef.driftF ... r (Hflow r ω) σ) a‖ /
    driftScale d E D N a s v,
  ```

  where `driftScale = T_{v,D}(dist(a₀,a₁)) (η_s/η_v)^4`.

* `APrimeCrossJointSplit.prefixGradient` is

  ```text
  sqrt (Gauss.quadVar d N
    (fun M => (prefixMatrix d E D s mesh N k m M : ℂ))
    (Gauss.Xmat d N ω)) / threshold δ N,
  ```

  with `threshold δ N = 8 exp(1)^2 N^(2δ)`.

* `APrimeDriftTimeFamily.qvAt` is the actual uncut QV of the normalized
  `coordAt`; T378's theorem applies directly to it.

* `APrimeCrossJointSplit.jointRate` is the transition indicator times
  `prefixGradient * sqrt(qvAt)`.

The exact complement premise in both
`APrimeCrossJointSplit.jointRate_norm_le_event` and
`APrimeCrossJointSplit.crossPart_active_le_jointEvent` is

```text
hAll : ∀ ω,
  prefixGradient d E D δ s mesh N k m ω *
    sqrt (APrimeDriftTimeFamily.qvAt d E D N σ a (s N) v r ω)
      ≤ Eall.
```

It is pointwise over the same `Gauss.Ω d` and has no event hypothesis.  Taking
`Eall = C_all N^130` therefore discharges the intended T361 slot in the
first-cell regime.

## Geometry and uniform parameter bounds

`APrimeSupportRunning.firstT_bounds` gives
`0 ≤ firstCellT τ' N ≤ 1/2`.  Together with
`MomentDuhamelCut.netFinset_subset_Icc`, every actual net time `u_j`, including
`v = u_k`, lies in `[0,1/2]`.  Since `E=0`,

```text
etaT 0 u = 1-u,       1/2 ≤ etaT 0 u ≤ 1,
(etaT 0 u)^(-1) ≤ 2.
```

`Gauss.Dims.dim` gives `W_N L_N ≤ N` eventually.  Positivity of `W_N,L_N`
also gives each of `W_N ≤ N`, `L_N ≤ N`, and
`card (d.Idx N) = W_N L_N ≤ N`.  The label distance satisfies
`zdist L (a₀-a₁) ≤ L`; in the estimates below even this upper bound is unused,
because `rpow_neg_le_tailT` supplies a tail floor uniformly in the distance.

## Drift envelope

Fix `r ∈ [0,v]`.  The exact deterministic inputs are:

1. `Gauss.exists_norm_Kval_le_win (m := 2)` supplies a constant `C_K`
   independent of `N,r,ω,σ,a` with
   `‖Kval_r(J)‖ ≤ C_K eta_v^(-2)` for lengths up to two.
2. `Gauss.norm_gloop_le_win`, applied to
   `Gauss.Hflow_isHermitian`, gives `‖gloop(J)‖ ≤ eta_v^(-3)` for the lengths
   up to three needed when the drift input length is two.
3. `Gauss.norm_driftF_le_crude` with its parameter `n=0` counts all three
   drift blocks.  Every summand in its displayed bound contains exactly one
   factor `W_N L_N`; all remaining factors depend only on the fixed loop
   length and on

   ```text
   MG = eta_v^(-3) ≤ 8,
   MK = C_K eta_v^(-2) ≤ 4 C_K.
   ```

   Consequently, for a fixed constant `C₀`,
   `‖driftF ...‖ ≤ C₀ W_N L_N ≤ C₀ N` at every sample.
4. `Gauss.norm_Uker_apply_le_ukerRow` bounds the propagated value by
   `ukerRow` times that supremum.
5. `APrimeQVGlobalPoly.inv_driftScale_mul_ukerRow_le` gives, with `D=60`,

   ```text
   driftScale^(-1) * ukerRow ≤ N^60.
   ```

   Internally this is the exact cancellation
   `ukerRow ≤ (η_s/η_v)^2` against the fourth power in `driftScale`, followed
   by the uniform tail floor
   `T_{v,60}(distance) ≥ W_N^(-60)` and `W_N≤N`.

Thus

```text
driftAt ≤ N^60 * C₀ N = C_F N^61.
```

For a Lean implementation, `exists_driftF_envelope` alone is not sufficiently
quantitative because its returned witness is existential at fixed `N`.
The polynomial theorem should unfold the explicit witness used in its proof,
or invoke `norm_driftF_le_crude` directly with the fixed `C_K` from
`exists_norm_Kval_le_win`.

## Prefix-gradient envelope

Assume first `k>0`; `k=0` is treated separately below.  For each `j<k` and
each two-loop label `a`, `APrimeSmoothPrefix.coordFun` is `loopObs-Kval`.
The `Kval` term is matrix-constant and contributes no matrix derivative.

At `u_j≤1/2`, use

```text
B = 2 (1 + eta_u_j^(-1))^3 ≤ 54.
```

For a two-loop index, `Gauss.bddC2C_loopObs_sub` gives first-derivative
coefficient

```text
b₁ = card(Idx) * 2 * B^2
   ≤ N * 2 * 54^2
   = 5832 N.
```

`Gauss.quadVar_le_of_bddC2C` then yields
`quadVar(coordFun) ≤ b₁² coordWeight`.  After the definitional rewrite
`‖Bmat‖^2 = ‖Bmat‖*‖Bmat‖`, this is the same coordinate sum bounded by the
exact dimension estimate `APrimeQVGlobalPoly.coordWt2_le`:

```text
coordWeight ≤ 8 N^2.
```

Therefore, uniformly at every matrix argument, including
`sqrt(u_j) • Xmat ω` for an arbitrarily large sample,

```text
sqrt(quadVar(coordFun)) ≤ 5832 sqrt(8) N^2.
```

The raw rate divides by `T_{u_j,60}(distance)`.  The tail floor gives

```text
T_{u_j,60}(distance)^(-1) ≤ W_N^60 ≤ N^60,
Kraw(j,a) ≤ C_raw N^62.
```

Now apply
`APrimeSmoothWeightActual.sqrt_quadVar_prefixMatrix_le_exp_max`.  With
`m = APrimeSmoothWeightActual.canonicalM ...`, the hypothesis needed to remove
the finite maximum is exactly
`APrimeSmoothWeightActual.canonicalM_calibration`; it costs only `exp(1)`,
not a power of the number of net points or labels.  Its remaining factors are

```text
sqrt(u_j) ≤ 1,
((Step2Moment.ratR 0 s N u_j)^4)^(-1) ≤ 1,
Kraw(j,a) ≤ C_raw N^62.
```

Hence the numerator of `prefixGradient` is at most
`exp(1) C_raw N^62`.  Division by
`threshold δ N = 8 exp(1)^2 N^(2δ)` gives

```text
prefixGradient ≤ (C_raw/(8 exp(1))) N^(62-2δ).
```

For `δ≥0` and `N≥1`, this is at most `C_B N^62`.  No factor depending
positively on `k`, the number of labels, `L`, or `ell_u` remains.

## Uncut QV and the product

`APrimeQVGlobalPoly.eventually_qvAt_le_poly` states, uniformly in all windows,
two-loop charges, endpoint labels, times, and samples,

```text
N^(-Keta) ≤ etaT E v  ->
qvAt ≤ 2^21 N^(2D+4+12Keta).
```

On the first cell, `N^-1≤etaT 0 v` for `N≥2`; this is also the bound used by
`APrimeSupportRunning.first_eta_lower`.  Substituting `D=60`, `Keta=1` gives

```text
qvAt ≤ 2^21 N^136,
sqrt(qvAt) ≤ 2^(21/2) N^68.
```

Multiplication with the preceding prefix estimate gives, for `δ≥0`,

```text
prefixGradient * sqrt(qvAt) ≤ C_all N^(62+68)
                                      = C_all N^130.
```

This is the required all-sample `hAll`.  It uses the same sample `ω` and the
same probability space `Gauss.P d` as T361; there is no measure conversion.

## Required corner checks

### Arbitrarily large `ω`

The bounds are global.  `Gauss.Xmat_isHermitian` and
`Gauss.Hflow_isHermitian` hold for every sample.  Resolvent bounds depend on
the spectral imaginary part `etaT`, not on `‖Xmat ω‖`.  The prefix derivative
bound is a global `BddC2C` estimate at every matrix.  Thus samples of
arbitrarily large norm cause no loss.

### `r=0`

The general deterministic estimate remains valid.  In the initial endpoint
case it is sharper: `Gauss.driftF_zero_at_initial` and
`APrimeFirstCellDriftTransportRaw.driftAt_zero_window` make `driftAt` exactly
zero.  T361's positive-time cross estimate asks for `r>0`, so no hidden
singularity at zero is being used.

### `k=0`

`APrimeSmoothWeightActual.prefixSample_zero` reflects that `prefixMatrix` is
the soft maximum over the empty range and is constant zero.  Its QV, hence
`prefixGradient`, is zero.  The theorem
`sqrt_quadVar_prefixMatrix_le_exp_max` requires `0<k`, so a Lean producer must
split this branch before applying it.

### `j=0`

`cutNetPt_zero` gives `u_0=0`.  In the pullback derivative of `prefixMatrix`
the exact factor `sqrt(u_0)` is zero.  The `j=0` contribution is therefore
zero, independently of the sample.

### First positive prefix `k=2`

The range contains `j=0,1`; only `j=1` can contribute.  It still satisfies
`0<u_1≤v≤1/2`, so every eta, tail, dimension, and calibration bound above is
unchanged.  Although the transition representation can evaluate a rescaled
sample of size proportional to `u_1^-1/2`, the global Hermitian-resolvent
derivative bound is independent of that norm.

### Event independence

All three estimates quantify over every `ω`.  Neither `Good` nor `transition`
appears in their hypotheses.  In `jointRate`, the transition indicator only
decreases the nonnegative rate.  Hence the complement estimate is not
obtained by smuggling an event assumption into `hAll`.
