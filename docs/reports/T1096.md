## Claim and dependency check

Fix `τ,c,δ > 0` with `δ ≤ min 1 (c/100)`, set
`s = firstCellS τ`, `t = firstCellT τ`, `ζ = zetaSrc δ = δ/3200`,
`δw = deltaWeight δ = δ/100`, `d = Dims.exampleGrow`, and use the *same*
`N`, sample `ω`, mesh `M_N = targetMesh 60 N`, and order
`m_N = canonicalM d s t (targetMesh 60) N` in both events.
The parameter range is nonempty: `τ=c=1`, `δ=1/200` is explicit in T1051.

The definitions in `APrimeGeneralMovingCarrierCore.lean:27–50` say

```
sourceGood 0 s t ζ N
  = {ω | ‖Xmat d N ω‖ ≤ N}
      ∩ rawEvent 0 s t ζ 3 N
      ∩ rawEvent 0 s t ζ 4 N
      ∩ rawEvent 0 s t ζ 6 N.
```

Each of the three raw rows quantifies over **every** `TimeIcc s t N` time
and every length-`n` loop index. The proof below uses only the first norm
component, uniformly for every `ω` in that component. The three additional
all-time rows are retained in the literal target and can only shrink it.

For all sufficiently large `N`, `firstCellS τ N = 0`,
`firstCellT τ N = 1/2`, and `M_N = N^(4·60+18) = N^258`.
Moreover `2 ≤ cutNetTop s t (targetMesh 60) N`; T1051 checks this with the
same target mesh. Since `prefixSample` uses `Finset.range k`, the *only*
times in the `k=2` prefix are `cutNetPt s M N 0 = 0` and
`cutNetPt s M N 1 = h_N := N^-258`. For `N ≥ 2`, both belong to `[0,1/2]`.

Let `J_N(u,ω) = Step2Moment.jSnorm (sample d) 0 60 s N u ω`.
`APrimeFirstCellCommon.J_zero` proves `J_N(0,ω)=1` for every sample,
using `lk_zero`, `jS=1`, and `ratR=1`; `firstCellS τ = fun _ => 0` follows
from `gridT_zero`. The compiled
`APrimeSlotFields.eventually_modulus_jSnorm_event` has hypotheses
`|E|<2`, `1≤D`, `0≤t₀<1`, `0≤s_N`, `t_N≤t₀`, and containment of its event in
`{‖Xmat‖≤N}`. They hold here with `E=0`, `D=60`, `t₀=1/2` and the norm
event itself. One eventual bound applies **uniformly to every sample** in
that event and both times:

```
|J_N(h_N,ω) - J_N(0,ω)|
  ≤ N^(2+2·60) |h_N|^(1/2)
  = N^122 · N^-129 = N^-7.
```

Thus both stored `J_N` values are at most `2` for `N ≥ 2`. The literal
`APrimeSmoothWeightActual.prefixSample_le_of_jSnorm_bound` applies with
`B=2`, and `canonicalM_calibration` bounds its cardinality factor by `e`:

```
prefixSample d 0 60 s M N 2 m_N ω
  ≤ e · (2 + N^-10) ≤ 3e.
```

The exact threshold in `APrimeSmoothPrefixCanonicalCore.lean:441` is
`8e² N^(2δw)`, which is at least `8e²` since `δw>0` and `N≥1`.
Consequently, for every such `ω` and all sufficiently large `N`,

```
prefixSample_N(ω) / threshold_N ≤ 3/(8e) < 1.
```

But `APrimeCrossJointSplit.transition` in
`APrimeGeneralMovingCarrierCore.lean:213` requires this very ratio to be
strictly **greater** than `1` for the same `N,k,m_N,ω`. Therefore

```
∀ᶠ N, sourceGood 0 s t (zetaSrc δ) N ∩
  transition d 0 60 (deltaWeight δ) s (targetMesh 60)
    N 2 (canonicalM d s t (targetMesh 60) N) = ∅.
```

The strict upper transition inequality `<2` is immaterial once its lower
inequality fails. The T1051 scalar-ray transition resident must eventually
lie outside `sourceGood`'s norm component. Since
`commonEvent ⊆ rawCarrier ⊆ sourceGood`, the corresponding literal
`commonEvent ∩ transition` is empty on this schedule as well. This does
not claim emptiness for other prefixes, meshes, or time locations.
