## Mathematical preflight

The exact T995 schedule was retained:

```text
deltaWeight = xi = δ/100,  deltaCap = δ/50,
tauG = δ/1600,              zetaSrc = zetaCtr = δ/3200.
```

The imported public T1245 producer bounds the literal T1029 `crossProfile`,
for positive `u ∈ [s_N,v]`, by

```text
K N^(13δ/640) etaT(E,s_N)^(-1) ratR(E,s_N,v)^(-2) / sqrt(u).
```

The exponent is exactly the product of the transition-prefix and absorbed
profile losses:
`zetaSrc + 2(δ/100) = δ/3200 + δ/50 = 13δ/640`.
`Cond272Reg` gives `N^c ≤ W ell_t eta_t`; the bandwidth dimension bound and
`ell_t ≤ L` yield `etaT(E,t_N) ≥ N^(-1)`. Since `etaT` is nonincreasing and
`s_N ≤ t_N`, this gives `etaT(E,s_N)^(-1) ≤ N` eventually.

The target mesh producer gives `targetMesh(D,N) = N^(4D+18)` eventually.
Because `cutNetPt(s,mesh,N,1) = s_N + 1/mesh_N`, the first-cell length is
exactly `v - s_N = N^(-(4D+18))`. The inverse-square-root integral is
`2(sqrt(v)-sqrt(s_N))`, and
`sqrt(v)-sqrt(s_N) ≤ sqrt(v-s_N) = N^(-(2D+9))`. Combining these factors
gives the exponent

```text
13δ/640 + 1 − (2D+9) = 13δ/640 − 2D − 8.
```

The final estimate keeps `ratR(E,s_N,v)^(-2)` intact. The pointwise producer,
the regime bound, and the mesh event are intersected before introducing the
output, so the cutoff is independent of `a`.
