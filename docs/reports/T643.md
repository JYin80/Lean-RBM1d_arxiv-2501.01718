# T643 - impossibility/redistribution audit after T638

## Verdict

**The proposed universal impossibility estimate is refuted.**  Literal
`goodSetFlow ∩ centeredEvent` controls only the **signed row sum** of `L-K`.
Positivity of the two-loop matrix controls its total mass, but it does not turn that
signed row-sum estimate into entrywise control.  The missing factor is of order `W`:

```text
sum_b (L-K)_(a,b) = O(N^zetaCtr/W^2),
sum_b |(L-K)_(a,b)| can still be O(1/W).
```

Since the transition needs only one entry of size

```text
N^deltaCap / W^2,
```

and `N^deltaCap << W`, positivity leaves ample room for spatial redistribution.
`goodSetFlow` does not remove this room.

More decisively, the early-time restriction in T638 is not forced by the literal
prefix.  T638 chose `v <= 6/N^2`, making every off-diagonal propagator error
`O(vW)=o(1)` after normalization.  At the later, still vanishing scale

```text
v_N asymp threshold(deltaWeight,N) / W
    asymp N^deltaCap / W,
```

the off-diagonal propagator entry itself has normalized size `asymp v_N W`, hence
`asymp N^deltaCap`.  The large stored row can therefore be off-diagonal, where the
Ward row-sum cancellation is spatial; it need not be the diagonal row used in
T638 (4.4)-(4.5).  This invalidates the step from T638 (4.3) to (4.4) for a general
prefix and, in fact, already for a well-chosen block-diagonal semicircle sample.

A genuinely nearest-neighbour coupled version is also quantitatively viable.  Use
semicircle-quantile circulant blocks with equal spectra but different permutations,
then conjugate disjoint adjacent block pairs by a fixed two-block rotation.  It has
norm `< N`, uses only positive-variance coordinates, passes all three raw rows,
`goodSetFlow`, both centered charges, and `blockEvent`; its literal target/canonical
prefix has ratio tending to `3/2` after choosing the first hitting mesh point at the
scale above.  Thus **all deterministic carrier rows survive** on the identical
sample.  The first remaining obstructions are downstream: packaging the finite
effective Gaussian support cylinder, proving the exact `measCore` null-difference
transfer, and extracting admissible clean prefix/carrier producer surfaces.

This is a mathematical feasibility audit, not a compiled support theorem.  In
accordance with T639 and the file ownership of this ticket, no Lean source, root
import, scheduler/status file, paper-delta file, git index, commit, branch, or remote
state was changed.  This report is the only repository file written.

## 2. What Ward plus centeredEvent actually implies

Fix a time `0 <= v < 1`, put `eta = 1-v`, and write

```text
L_ab = L_(+,-),(a,b),
K_ab = W^(-1) * Theta_v(a,b),
c_a  = W^(-1) Tr_block_a(G_v) - i.
```

The clean low-level identities give

```text
L_ab = W^(-2) * ||(G_v)_(b,a)||_F^2 >= 0,
sum_b L_ab = (1 + Im c_a)/(W*eta),
sum_b K_ab = 1/(W*eta).
```

Consequently the exact signed Ward row sum is

```text
sum_b (L_ab-K_ab) = Im c_a/(W*eta).                 (2.1)
```

On the literal centered row,

```text
|c_a| <= 2*N^zetaCtr/(W*eta),
```

and therefore

```text
|sum_b (L_ab-K_ab)| <= 2*N^zetaCtr/(W^2*eta^2).     (2.2)
```

This is the strongest cancellation estimate supplied by centeredEvent.  Positivity
only gives

```text
sum_b |L_ab-K_ab|
  <= sum_b L_ab + sum_b K_ab
  <= 2/(W*eta) + 2*N^zetaCtr/(W^2*eta^2).           (2.3)
```

Thus (2.2) cannot be upgraded to an entrywise `O(N^zetaCtr/W^2)` bound.  The
ratio between (2.3) and the desired transition scale is

```text
(1/W) / (N^deltaCap/W^2) = W/N^deltaCap -> infinity.
```

The literal `goodSetFlow` bound does not close this gap.  With

```text
Delta_N = flowDelta d 0 t N asymp W^(-1/6),
```

it gives `|(G_v)_(b,b')| <= Delta_N` off the matrix diagonal, hence the crude
block estimate `L_ab <= Delta_N^2`; (2.3) is already stronger at the row level.
Neither estimate controls the **variation distance** between the two nonnegative
rows `L_a*` and `K_a*` by their signed mass difference.

This is the exact inequality gap in the attempted impossibility proof.

## 3. Why the T638 diagonal reduction is not uniform in the prefix

T638 fixed

```text
5/N^2 <= v <= 6/N^2.
```

At this scale the distance-one propagator contribution satisfies

```text
|K_(a,a+1)| / tailT(...,1) asymp vW = o(1),
```

so an `N^deltaCap` normalized maximum had to occur on the diagonal for that
particular block-diagonal spiked construction.  Only after that reduction does the
diagonal Ward identity force a centered-trace violation.

For the literal target prefix, however, `k` is chosen after `N`; it is not restricted
to this scale.  Take instead

```text
v_N asymp T_N/W asymp N^deltaCap/W.
```

Then `v_N -> 0`, `v_N < 1/2`, and

```text
Theta_v(a,a+1) = v/3 + O(v^2),
tailT(W,ell_v,eta_v,60,1) = exp(-1)*W^(-2)*(1+o(1)),
|K_(a,a+1)|/tailT(...,1) = (exp(1)/3+o(1))*vW.       (3.1)
```

At `v=v_N`, (3.1) is of order `T_N`.  A block-diagonal sample has
`L_(a,a+1)=0`, so the large stored row is already off-diagonal.  Its negative
mass is compensated by the diagonal `L-K` row, exactly as (2.1) permits.  There
is no lower bound on `|c_a|` analogous to T638 (4.5).

This refutes the universal claim that every identical-block block-diagonal strict
transition violates centeredEvent.  The statement is valid only for the early spiked
prefix class actually analyzed in T638.

## 4. The deterministic semicircle base

Let `rho_sc` be the semicircle law.  Choose one quantile point
`lambda_j in [-2,2]` in each of its `W` equal-mass intervals.  For

```text
g_v(lambda) = (sqrt(v)*lambda - i*(1-v))^(-1),
0 <= v <= 1/2,
```

the semicircle equation gives

```text
integral g_v d rho_sc = i.
```

The equal-mass quantile rule and uniform Lipschitz bounds give

```text
|W^(-1) sum_j g_v(lambda_j) - i| <= C/W             (4.1)
```

uniformly on the closed interval `0 <= v <= 1/2`.

Choose permutations `pi_b` so that, simultaneously for all physical blocks,
nonzero internal Fourier modes, and `v in [0,1/2]`,

```text
|W^(-1) sum_j g_v(lambda_(pi_b j))*exp(2*pi*i*q*j/W)|
  <= C*sqrt(log N/W),  q != 0.                       (4.2)
```

The same bounded-difference/net argument as in T638 works after a union bound over
the additional `L=O(N^(1/4))` blocks.  This proves existence of a finite deterministic
family; it is not a substitute probability event for the Gaussian model.

Put

```text
A_b = F_W^* diag(lambda_(pi_b j)) F_W.
```

Each `A_b` is Hermitian, has norm at most `2`, has the same spectrum, and has the
uniform resolvent bounds (4.1)-(4.2).

Already `diag_b(A_b)` is a block-diagonal survival sample.  The next section adds
genuine nearest-neighbour coupling without changing the favorable trace estimates.

## 5. Nearest-neighbour isospectral redistribution ansatz

Pair disjoint adjacent physical blocks, leaving at most one block unpaired.  On every
pair `(b,b+1)`, use the fixed rotation

```text
U_theta = [[cos theta, sin theta],[-sin theta, cos theta]] tensor I_W,
theta = pi/4,
```

and define

```text
X_pair = U_theta * diag(A_b,A_(b+1)) * U_theta^*,
X_N    = direct sum of the paired X_pair and any unpaired A_b.
```

Then:

1. `X_N` is Hermitian and `||X_N|| <= 2 < N` eventually.
2. Its only nonzero physical-block entries are within one block or an adjacent
   paired block.  For every such coordinate, `Sblk=1/(3W)>0`; hence every used real
   or imaginary coordinate has positive Gaussian variance.
3. At every flow time,

   ```text
   G_pair(v) = U_theta * diag(g_v(A_b),g_v(A_(b+1))) * U_theta^*.
   ```

   The two diagonal block traces remain identical because `A_b,A_(b+1)` have the
   same eigenvalue multiset.  Off-diagonal Green blocks are proportional to
   `g_v(A_b)-g_v(A_(b+1))`.
4. Equations (4.1)-(4.2) therefore remain uniform after coupling.  In particular,

   ```text
   max_ij |G_v(i,j)-i*1(i=j)| <= C*sqrt(log N/W).     (5.1)
   ```

5. For a paired block `b`, choose its other neighbour `b-1`.  Since the resolvent
   has support only inside the matched pair,

   ```text
   L_(b,b-1)(v) = 0,
   (L-K)_(b,b-1)(v) = -W^(-1)*Theta_v(b,b-1).         (5.2)
   ```

Thus the coupled ansatz retains the exact distance-one lower bound (3.1).  The
two-block rotation adds genuine positive two-loop mass on the paired edge while the
Ward row sum is preserved by an opposite change on the diagonal.  The transition
does not depend on a high-eigenvalue spike or a centered-trace violation.

## 6. Literal target/canonical prefix

Let

```text
J_N(v) = Step2Moment.jSnorm(sample d,0,60,s,N,v,omega_N).
```

For the sample in Section 5, the resolvent expansion and the exact propagator
Neumann series give, uniformly while `vW = O(T_N)`,

```text
c1*(1+vW) <= J_N(v) <= c2*(1+vW)                   (6.1)
```

for fixed positive numerical constants; (5.2) gives the lower constant.  Hence
`J_N(0)=1`, while for a fixed sufficiently large `C`,

```text
J_N(C*T_N/W) > 3*T_N.
```

Let `v_N^*` be the first time the running maximum reaches `(3/2)T_N`.  Then

```text
v_N^* asymp T_N/W,
0 < v_N^* < 1/2.
```

Round `v_N^*` to the target mesh and set

```text
j_N = nearest integer to mesh(N)*v_N^*,
k_N = j_N+1.
```

Because `mesh N=N^258`, the induced error in `vW` is

```text
O(W/mesh N) = O(N^(-257)),
```

negligible compared with `T_N`.  In particular, eventually

```text
2 <= k_N <= cutNetTop s t mesh N.
```

The literal inner and outer smooth maxima use

```text
m N = cutNetTop(s,t,mesh,N)*card(LoopArg(L,2)) + 1.
```

Thus their cardinal factors are

```text
exp(O(log(mesh*L^2)/m N)) = 1+o(1),
```

not merely the coarse public upper bound `exp(1)`.  The regularization contributes
`N^(-10)`.  Therefore

```text
prefixSample(...,k_N,m N,omega_N)
  = (1+o(1))*max_(j<k_N) J_N(cutNetPt j) + o(1)
  = (3/2+o(1))*T_N.                                  (6.2)
```

Equation (6.2) gives the strict literal transition

```text
1 < prefixSample/T_N < 2
```

eventually.

Boundary cases remain explicit:

- `k=0`: the prefix is zero, so transition is impossible.
- `k=1`: only time zero is stored; `J_N(0)=1` and the canonical smoothed prefix is
  `1+o(1)`, hence it lies below `T_N`.
- the construction uses a later active prefix `k_N`, chosen after `N`, while all
  deterministic exponents and functions were fixed before `N`.

## 12. Strongest safe conclusion

1. `goodSetFlow ∩ centeredEvent` does not force the stored normalized `L-K` rows

   a distance-one propagator mismatch of the required size.
4. An isospectral nearest-neighbour coupled semicircle-quantile sample has strict
   margins for every deterministic carrier row, including `blockEvent`.
