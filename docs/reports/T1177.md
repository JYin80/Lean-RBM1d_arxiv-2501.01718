# T1177 — fixed-order conditional moment on the extended norm-good mesh

## Verdict: mathematical preflight PASS; exact conditional claim proved

Added `RBM.APrimeGeneralMovingHighQExtendedGoodFixedOrder.eventually_extended_good_of_exact_k0` in
`RBM1D/Gauss/APrimeGeneralMovingHighQExtendedGoodFixedOrder.lean`.

For fixed `δ > 0`, `q ≥ 1`, and `C₀ > 0`, assume the literal full order-`q`
T999 integral at `k = 0` is eventually bounded by
`C₀ N^(δq/2)`. The theorem returns one `C₁ > 0` and an eventual threshold in
`N`, uniform over every active index satisfying

```text
N^4 < k,    (k : ℝ) ≤ N^(4+δ/2),    k ≤ cutNetTop.
```

Its conclusion is the same order-`q` T999 integral restricted to the actual
norm-good event, with the same Gaussian sample and law, moving window, target
mesh, canonical `widenedW`, `cutTrunc (N^(2δ))`, and `jSnorm` observable. No
order is selected or changed by this theorem. The exact constant is
`C₁ = 2^(2q) (C₀ + (19/4)^(2q))`.

## Mathematical preflight and exact producer match

I inspected the actual declarations and source files for T1145, T1157, and
T1097, along with the accepted T475 modulus and target-mesh bound.

* T1157's `eventually_early_good_of_exact_k0` has the exact same fixed-order
  `k=0` premise: same sample, `B.P`, canonical `widenedW`, cutoff, target mesh,
  `jSnorm`, and exponent `C₀ N^(δq/2)`. Its conclusion covers the early
  interval `2 ≤ k ≤ N^4`; it does not cover this ticket's later interval.
* T1145's `eventually_selected_high_extended_good` has the exact extended
  later-index domain and conclusion, but selects its order through T1097.
  Its pointwise transfer uses the accepted general-moving T475 modulus, not
  the early-index estimate from T1117. T1177 keeps that later-index argument
  while replacing order selection with T1157's fixed-order conditional
  interface.
* T1097's `eventually_selected_high_k0` is the actual full `k=0` producer
  used to witness satisfiability. The public interface returns an order at
  least its input order; its proof instantiates the input order itself. The
  witness below uses its output order and the associated exact `k=0` integral.

The numerical preflight is the endpoint modulus itself. On
`{ω | ‖Xmat N ω‖ ≤ N}`, T475 gives
`|jSnorm(v,ω)-jSnorm(w,ω)| ≤ N^(2D+7)|v-w|^(1/2)`. At the target mesh,
`N^(2D+7) mesh(N)^(-1/2) ≤ N^-2`. For the real-power range,
`√k ≤ N^(2+δ/4)`, so the displacement from `s_N` costs at most
`N^-2√k ≤ N^(δ/4)`. The globally `19/4`-Lipschitz cutoff therefore changes
by at most `(19/4)N^(δ/4)`. Raising this additive error to power `2q` gives
exactly `(19/4)^(2q)N^(δq/2)`, the same rate as the premise. Since
`0 ≤ widenedW ≤ 1`, pointwise comparison on the same good event reduces the
integral to the full `k=0` premise plus this error term; at `k=0`, the empty
prefix makes `widenedW = 1`. No mesh-cardinality factor appears.

I checked the authorized `paper/250520-YinJun-v2.pdf` at (5.43)–(5.46),
printed page 58. Those formulas concern the stopping time, stopped quadratic
variation, stopped martingale, and net extension. T1177 proves only this
conditional static Gaussian moment transfer; it does not claim those stopped
process conclusions or a literal paper theorem.

## Nondegenerate premise and active-index witness

`nondegenerate_extended_fixed_order_witness` combines T1145's positive-length
`E=0`, `D=60` Gaussian model, `Cond272Reg`, `BoundsCore`, and a sample in the
literal norm-good event with T1097's full `k=0` producer on that same model
and law. It provides a chosen `q ≥ 1`, a positive `C₀`, and the exact premise
used by the theorem. It also explicitly witnesses the same sample as good
with `k=N^4+1`, eventually satisfying both the real-power upper bound and
`k ≤ cutNetTop`. T1145's construction obtains this resident; the new witness
projects it from T1145's existential range statement, since any integer
`k > N^4` is at least `N^4+1`.

The theorem's hypotheses are exactly the existing model conditions
`|E|<2`, `D≥60`, the ordered nonnegative moving window below one, `c>0`,
`Cond272Reg`, `δ>0`, `q≥1`, `C₀>0`, and the named full `k=0` integral bound.
No new size bound on every sample or added event hypothesis was introduced.
