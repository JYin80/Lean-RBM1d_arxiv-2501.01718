# T453 — common-event reconciliation and weighted drift moment audit

## Verdict

The event mismatch has a valid repair, but the two occurrences of the old
parameter `nu` must not be identified.  Fix a master loss `alpha > 0` and use

```text
G_alpha(N) = APrimeFirstCellSharpCommonEvent.sharpCommonEvent
  tauPrime delta alpha N
```

for every favorable estimate.  Instantiate T442 at loss `2 * alpha`, while
T438 and T447 remain at loss `alpha`.  T442 then asks for

```text
APrimeFirstCellEGAllOutputRunning.good
  tauPrime delta ((2 * alpha) / 2) N,
```

which is the `EGgood(alpha)` component of `G_alpha(N)` after arithmetic
simplification.  The price is exactly the replacement of T442's factor
`N^alpha` by `N^(2 * alpha)`.  No event monotonicity and no second sample are
used.

The resulting common-event and weighted-moment argument is mathematically
valid.  A Lean follow-on needs one support-aware weighted split lemma, because
the existing `APrimeBadSplit.drift_norm_le_of_event` requires the favorable
drift bound even where the weight is zero.  T442 only supplies that bound on
positive weight support.  This is a Lean interface gap, not a mathematical or
probabilistic obstruction.

This ticket is read-only with respect to Lean.  No Lean, shared, root, index,
commit, or remote state was changed.

## 1. Exact source signatures and the mismatch

T442 defines

```lean
def absorbedDriftBound (tauPrime delta nu : Real) : Prop :=
  eventually N,
    forall omega in EGAllOutputRunning.good tauPrime delta (nu / 2) N,
    forall N0 p k m,
      N0 <= N -> 1 <= p -> 1 <= m -> 1 <= k -> k <= cutNetTop ... ->
      0 < weight delta ... N0 p N k m omega ->
      let v := cutNetPt ... N k
      forall r in Set.Icc 0 v, forall a,
        driftAt ... v r omega <= endpointCoefficient delta nu N v r
```

and exports it through

```lean
APrimeFirstCellDriftAbsorbed.eventually_absorbed_drift_on_active_support.
```

T434 instead defines

```text
sharpCommonEvent tauPrime delta nu N
  = APrimeFirstCellJGAllTime.good N
      intersect
    APrimeFirstCellEGAllOutputRunning.good tauPrime delta nu N.
```

T438 `currentRowsBound` and T447 `rowsOnStoredPrefixes` both use this literal
`sharpCommonEvent tauPrime delta nu`.  Therefore T442 at `nu = alpha` would
need `EGgood(alpha/2)`, whereas T434/T438/T447 at `alpha` use
`EGgood(alpha)`.  No declaration proving monotonicity between these events was
found, and the audit does not assume one.  In particular, the source-loss
definitions contain minima and should not be treated as a set inclusion by
informal comparison of their scalar parameters.

The exact reparameterization is

```text
T442 loss       = 2 * alpha,
T442 event loss = (2 * alpha) / 2 = alpha,
T438 loss       = alpha,
T447 loss       = alpha.
```

Thus membership `omega in G_alpha(N)` projects to the one EG event needed by
all three estimates.  The sharp `jG` component remains available to T438 and
T447.  T442 does not require it.

An unnecessary alternative would be the literal finite intersection

```text
JGgood(N) intersect EGgood(alpha,N) intersect EGgood(alpha/2,N).
```

`HighProb.inter` would make it high probability, using exponent `D+1` at each
binary intersection and the compiled two-event union bound.  Its resident
would have to be selected once from the full intersection.  The
reparameterized scheme above is strictly simpler: it uses the already
accepted `G_alpha` and loses only one additional `N^alpha` in the drift.

## 3. Exact `N` exponents after reparameterization

```text
A = endpointScale N v,     tau = delta/16.
```

On the first cell, `eta_0 = 1`, `1 <= x_r <= R`, and `v` is the literal

```text

  [x_r^(-1/2) + N^(4 delta) * A^(-1) * x_r^6].
```

Hence the exact `N` exponents are

| row | exact `N` exponent |
|---|---:|
| near | `2 alpha` |
| far | `2 alpha + 4 delta` |

The full near spatial factor is

```text
eta_r^(-1) R^(-2) x_r^(-1/2)
  = R^(-2) x_r^(1/2) <= 1.
```

For the far row,

```text
eta_r^(-1) R^(-2) x_r^6 A^(-1)
  = R^(-2) x_r^7 A^(-1) <= R^5 A^(-1).
```

Thus its `Cond272Reg.margin` tuple can be taken as



## 4. High probability and quantifier order

By `HighProb (P d) G_alpha`, for every real `K > 0`, eventually in `N`,

```text
(P d) (G_alpha(N))^c
  <= ENNReal.ofReal (N^(-K)).
```

For `N >= 1`, this gives the real-valued bound

```text
((P d) (G_alpha(N))^c).toReal <= N^(-K).
```

The event itself is independent of the moment order `p`.  The exponent `K`
used to pay for its complement is allowed to depend on a fixed `p`.  The
valid order for the weighted conclusion is therefore

```text
forall p, 1 <= p -> forall beta > 0, eventually N, ... .
```

It is not

```text
eventually N, forall p, ... .
```

T442's favorable pointwise bound is stronger in this respect: its eventual
`N` tail precedes and is uniform in `p`.  T434's positive `k=2` resident also
has weight one for every `p` on the same `N`.  Only the complement payment
forces `p` to be chosen before the final eventual threshold.

## 5. Weighted `L^(2p)` split with the T450 envelope

Fix `p >= 1`, an active prefix, a loop output, and `r in [0,v]`.  Put

```text
q       = 2p,
w(omega)= APrimeSupportRunning.weight delta (firstCellT tauPrime)
            N0 p N k m omega,
Z(omega)= APrimeDriftTimeFamily.driftAt ... v r omega,
F       = endpointCoefficient delta (2 alpha) N v r,
Env     = driftConstant * N^61.
```

The actual smooth weight satisfies

```text
0 <= w(omega) <= 1.
```

T450 gives `0 <= Z(omega) <= Env` for every sample, with no event premise.
On `G_alpha(N)` there are two support branches:

* if `w(omega)=0`, then `w(omega) * Z(omega)^q = 0`;
* if `0 < w(omega)`, T442 at `2 * alpha` applies and gives
  `Z(omega) <= F`, whence `w(omega) * Z(omega)^q <= F^q`.

Consequently

```text
integral w Z^q
  <= F^q + Env^q * ((P d) (G_alpha(N))^c).toReal,
```

and the `q`-th root satisfies

```text
MomentDuhamel.momNormW (P d) w p Z
  <= F + Env * (((P d) (G_alpha(N))^c).toReal)^(1/q).
```

If the complement estimate is requested at exponent `K`, this becomes the
exact power calculation

```text
momNormW <= F + driftConstant * N^(61 - K/(2p)).
```

Thus, for a desired bad-event loss `N^(-beta)`, one may choose any
`gamma > 0` and request

```text
K = 2p * (61 + beta + gamma).
```

The fixed factor `driftConstant` is eventually at most `N^gamma`, so the bad
term is eventually at most `N^(-beta)`.  A convenient compiled route is to
first absorb the fixed constant into

```text
Env <= N^62
```

and invoke

```lean
RBM.Gauss.eventually_env_mul_prob_rpow_le_moment
```

with `Cenv = 62`.  That route requests the explicit HighProb exponent

```text
K = 2p * (beta + 62)
```

and returns the bad-event payment `<= N^(-beta)`.

The fixed-time integrability needed for the split is nonproblematic.  The
actual weight is continuous by
`APrimeSmoothWeightActual.continuous_weight`; the drift is continuous in the
Gaussian sample through `Gauss.continuous_uker_driftF_omega`; and T450 gives
the deterministic bounded envelope.  Hence
`w * |Z|^(2p)` is integrable on the probability space.

### Existing split interface

`APrimeBadSplit.drift_norm_le_of_event` has the premise

```text
forall omega in E, |Z omega| <= A,
```

without conditioning it on positive weight.  It therefore cannot be applied
directly to T442 at samples where `w=0`.  The minimal correct local lemma has
either of the equivalent favorable premises

```text
forall omega in E,
  w omega = 0 or |Z omega| <= A
```

or

```text
forall omega in E,
  (w omega)^(1/q) * |Z omega| <= A.
```

Its proof is the same root-scaled argument as
`APrimeBadSplit.weighted_norm_le_of_event`, with the zero/positive support
case split made before applying the favorable bound.

## 6. Same-sample nondegeneracy and boundary checks

Intersect the finitely many eventual tails from T434, T442 at `2 * alpha`,
T438 at `alpha`, T447 at `alpha`, and T450.  T434 then supplies one

```text
omega in G_alpha(N)
```

with all the following properties on that same sample:

* `2 <= cutNetTop`;
* the literal moving endpoint `v=u_2` is positive and at most
  `firstCellT tauPrime N <= 1/2`;
* `weight delta ... 2 p N 2 N omega = 1` for every `p`;
* the T434 source event and sharp `jG` cap;
* T442's reparameterized drift bound for every real `r in [0,v]` and every
  two-loop output;
* T438's current QV rows and T447's stored rows, including stored `j=0` and
  positive stored `j=1`;
* T450's global drift envelope.

No conclusion is obtained by separately choosing residents of two
high-probability events.

The corner cases are consistent:

* `r=0` and `r=v` are included in T442's closed interval and are exported by
  `absorbed_drift_endpoints_of_bound`; T450 exports both endpoints as well.
* For `k=0`, the net endpoint is `v=0`, hence the only time is `r=0` and the
  actual drift is zero.  T442's separate
  `driftAt_cutNet_zero_le_endpointCoefficient` handles this branch.  The
  actual empty-prefix weight is `1` by
  `APrimeSmoothWeightActual.weight_zero_prefix`; it is not a zero-weight
  case.
* At a positive prefix with `w=0`, the favorable integrand vanishes and no
  T442 estimate is needed.
* At a positive prefix with `w>0`, all hypotheses of the reparameterized
  T442 estimate are present.
* The first nondegenerate resident is `k=2`, where the weight is exactly one
  for all moment orders.
