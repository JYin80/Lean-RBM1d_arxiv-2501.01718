# T492 — general moving all-time centered one-loop gate

## Verdict

**The mathematical gate passes.** Under the stated current-window hypotheses

```text
BoundsCore (sample d) E s,
Step1.Hyp (sample d) E s t,
Cond272Reg (band d) E s t c,   c > 0,
0 <= s_N <= t_N < 1,
|E| <= 2-kappa,                0 < kappa <= 1,
```

the following bound follows without a `FlucGain` or `FlucGainUpTo` premise: for every fixed
`zeta > 0` there is one measurable `HighProb` event on which, eventually in `N`, simultaneously
for every `u in [s_N,t_N]`, every block `b`, and both charges `sigma`,

```text
|trace ((G_sigma(u)-m_sigma) E_b)|
  <= N^zeta (ell_u/ell_s) (W ell_u eta_u)^(-1).
```

The proof uses the deterministic-scale version of (4.5), a fixed polynomial time net, and the
pathwise resolvent modulus. It does not use the first-cell `DetAvgIBPTimeNet` theorem on a later
window. The current repository does not yet expose this arbitrary-window result as one compiled
theorem; the bounded next ticket is specified in §9.

This conclusion is only the centered one-loop source needed between paper (5.35) and (5.41). It
does not construct an `APrimeSlot`, a drift family, or next-window initial data.

## 1. Scales and the exact remaining margin

For `u in [s_N,t_N]`, put

```text
A_u = W ell_u eta_u,
r_u = ell_u/ell_s,
R_u = eta_s/eta_u,
q_u = r_u/A_u.
```

The identities and monotonicities of the flow give

```text
q_u = 1/(W ell_s eta_u),
1 <= r_u <= R_u^(1/2),
A_t <= A_u,
R_u^30 <= A_u.
```

The last inequality is exactly `Cond272.pow_thirty_le`, hence uses the printed (2.72), not the
stronger product condition rejected in T280d. Therefore

```text
r_u <= A_u^(1/60),
q_u <= A_u^(-59/60) <= N^(-59c/60).
```

Also `ell_s eta_u <= 1`, so

```text
W^(-1) <= q_u,
q_u + W^(-1) <= 2 q_u.
```

For deterministic fluctuation averaging take

```text
Psi_u = sqrt(q_u + W^(-1)).
```

Then

```text
W^(-1/2) <= Psi_u
Psi_u <= sqrt(2) N^(-59c/120).
```

After absorbing the fixed `sqrt(2)`, the compiled fixed-time theorem may use any

```text
0 < a < 59c/120,
```

for example `a=59c/240`. Thus the exact positive exponent margin available to the `Psi` input is
`59c/120`; the squared averaged output has margin `59c/60`. No factor involving `R_u` remains.
The endpoint spectral floor is polynomial: T488's
`APrimeGeneralMovingInitialHinit.eventually_eta_window` gives `eta_u >= N^(-2)` throughout the
window, so the fixed-time theorem can take `K=2`.

## 2. Sharp entry law from the stated hypotheses

The required entry scale is internal to Step 1.

1. `Step1.apriori` at loop length two gives the all-time two-loop control `q_u`.
2. `Step1.Hyp.lemma41`, equivalently the public generic producer
   `Gauss.stochDom_indicator_llMax_sq_flow_of`, converts the two-loop input to
   `1_goodEv llMax^2 prec q_u+W^(-1)`.
3. `Step1.weakLaw` makes `goodEv` hold simultaneously in time with high probability, since its
   `A_u^(-1/4)` error is eventually below the `A_u^(-1/6)` cutoff.
4. Removing the indicator and taking square roots gives the sharp deterministic-time local law
   at `Psi_u`.

All labels and the full closed time interval already occur in the Step-1 stochastic domination.
The private first-cell bridge in `FirstCellStep1LocalLaw.lean` is a useful implementation model,
but is not a mathematical premise and must not be invoked as an arbitrary-window theorem.

## 4. Uniformity in a moving continuum of times

Applying the singleton theorem independently at every real time would not by itself control an
uncountable union. The required upgrade has two distinct finite steps.

First, for fixed tail parameters, the singleton estimate is uniform over all deterministic
choices `u_N in [s_N,t_N]`. Otherwise, at infinitely many `N` choose a time at which the
fixed-time probability estimate fails; the resulting deterministic sequence contradicts
`detAvgIBP_stochDom_of_localLaw_complete`. This selection argument concerns the probability of
one fixed-time bad event, not the union over times.

Second, use a deterministic left time net with spacing at most `N^(-16)`, including both
endpoints. It has at most `N^16+2` points. On

```text
{omega : ||X_N(omega)|| <= N},
```

which is `HighProb` by `Gauss.highProb_norm_Xmat_le`, the public pathwise estimate
`Gauss.norm_green_flow_sub_le_sqrt` and `RBM.norm_trace_mul_Eblk_le` give

```text
|F_b(u)-F_b(v)|
 <= eta_t^(-2) (N+1) |u-v|^(1/2)
 <= 2 N^5 |u-v|^(1/2)
 <= 2 N^(-3),
```

where `F_b(u)=trace((G_+(u)-m)E_b)` and `eta_t>=N^(-2)`. Since
`q_u>=W^(-1)>=N^(-1)`, this interpolation error is smaller than `N^zeta q_u` with room. Choosing
the left neighbour also gives `q_v<=q_u`, because `q` is increasing. Allocate, for example,
`zeta/4` to the fixed-time source and constants, and request the fixed-time failure exponent
larger than the desired exponent by `18`; the union over at most `(N^16+2)L_N` net/block pairs
then remains rapidly decaying (`L_N<=N`).

This argument is uniform in the moving endpoint. It uses only the polynomial eta floor, so no
fixed `t_0<1` is needed. A collapsed window `s_N=t_N` is a one-point net. Both endpoints are
included. At `u=0`, `Gauss.detAvgIBP_at_zero` gives the plus trace exactly zero.

## 5. Both charges and one common event

The minus charge needs no new probability estimate. The public algebraic theorem
`APrimeTwoChargeOneLoop.centered_block_trace_false_eq_conj_true`, together with
`Gsig_conjTranspose`, `Eblk_conjTranspose`, `mSigma_false`, and
`Matrix.trace_conjTranspose`, gives pointwise on the same sample

```text
|trace ((G_-(u)-m_-)E_b)| = |trace ((G_+(u)-m_+)E_b)|.
```

The existing Gaussian convenience wrapper is specialized to `E=0`, but the underlying public
theorem is already energy-generic and directly yields the required general-energy corollary.

For fixed `zeta`, define one event by intersecting the norm event with the finitely many net-time
and block good events, transfer both charges pointwise, and take
`Gauss.measCore (P d)` if a measurable representative is wanted. Public lemmas
`highProb_measCore` and `FastDecayFlow.nonempty_of_highProb` show respectively that this costs no
probability and that the resulting event is eventually nonempty. Thus the quantifier order is

```text
for every fixed zeta>0:
  there is one measurable event family Good_zeta;
  HighProb Good_zeta;
  eventually for every omega in Good_zeta,
    every u, sigma, b satisfies the bound.
```

The failure exponent in `HighProb` is chosen after `zeta`; the mesh and label union are paid
before the eventual threshold. There is no separate event for the two charges.

## 6. First-cell and anti-vacuity checks

The proof above also covers `s_N=0`; it does not divide by `s_N`, the window length, or the
number of mesh cells. The identity at zero handles the left endpoint, while every positive net
point uses the same fixed-time theorem.

The assumptions have a nondegenerate actual Gaussian instance. In particular,
`FirstCellStep1LocalLaw.firstCell_step1_localLaw_witness` supplies a positive first cell, and
`DetAvgIBPTimeNet.exampleGrow_simultaneous` supplies a single measurable high-probability event
with the centered one-loop conclusion and eventual nonemptiness on that cell. These theorems are
used only as satisfiability witnesses, not as sources for a general moving window.
