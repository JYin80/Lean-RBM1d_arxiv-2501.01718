# T813 — finite next-image conditional expectation

## Result

`RBM1D/Gauss/PermutationNextImageCondExp.lean` proves the exact T797 singleton target, with no additional hypotheses:

```lean
theorem uniformPerm_nextImage_condExp (W : ℕ) (k v : Fin W) :
  (uniformPerm W)[(fun ρ : PermΩ W =>
    if ρ k = v then (1 : ℝ) else 0) | prefixSigma W k.val]
    =ᵐ[uniformPerm W]
  (fun π : PermΩ W =>
    if v ∈ unusedImages W k π
    then (1 : ℝ) / ((W - k.val : ℕ) : ℝ) else 0)
```

The equality is almost everywhere, not a pointwise assertion about Mathlib's chosen `condExp` representative. The proof introduces no `axiom`, `sorry`, `opaque`, new assumption, or frozen-signature change.

## Proof route

The `nextImageMean` function is measurable for `prefixSigma` by T807's `measurableSet_unusedImage_prefixSigma`. Both the indicator and mean are integrable because the permutation sample space is finite and `uniformPerm W` is a finite probability measure. On each actual prefix cell, T804's `unusedImages_eq_of_mem_prefixCell` makes the mean constant. T795's `prefixCell_card_eq_unused_mul_fiber`, T776's event/cardinality mass identities, and the used-value zero fiber theorem give equal real set integrals of the mean and indicator on that cell. The real conversion uses the positive integer denominators `W-k.val` and `Fintype.card (PermΩ W)`; every actual cell has positive finite mass by T776's `uniformPerm_actualPrefix_event_pos_ne_top`.

For an arbitrary `prefixSigma`-measurable set, T792's atom identity makes each actual cell either fully inside or outside the set. The proof forms a finite set of **distinct** actual cells, avoiding duplicate labels, and uses T733's equal-or-disjoint partition to sum the cell integral identities. Mathlib's `ae_eq_condExp_of_forall_setIntegral_eq` then gives the stated almost-everywhere equality. This route does not assume a conditional law or conditional expectation as an input.

## Boundary and nondegeneracy

The module proves that `Fin 0` has no next-image index; at `W=1,k=0` the conditional expectation equals one; and at `W=2,k=0` both distinct values have conditional expectation one half. The last-valid-reveal theorem gives probability one for the sole unused value and zero for every used value, including `W=2,k=1`. T795's positive two half-mass fibers supply a nondegenerate witness; the width-two conditional-expectation theorem directly reflects it. No new hypothesis requires a separate satisfiability witness.
