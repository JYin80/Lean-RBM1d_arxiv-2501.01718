## Definitions

- `targetWeight tauPrime delta p N k` is definitionally T542's literal
  explicit-delta widened target weight.
- `endpointJ N k` is the actual endpoint observable
  `jSnorm ... N (endpoint N k)`.
- `endpointBaseline N k` is
  `1 / ratR 0 0 N (endpoint N k)^4`, namely `R_v^(-4)`.
- `targetFamilyBoundAt ... C` is the supplied premise

  ```text
  momNormW (P d) targetWeight p familyMax <= C.
  ```

- `endpointBoundAt ... C` is the corresponding conclusion

  ```text
  momNormW (P d) targetWeight p endpointJ
    <= endpointBaseline + C.
  ```

The measure, weight, and moment order are literally identical in the two
predicates.

## Weight and integrability facts

Theorems `targetWeight_aestronglyMeasurable`, `targetWeight_nonneg`, and
`targetWeight_le_one` unfold T542's weight and apply the generic `widenedW`
facts with the same explicit `delta`.

`integrable_targetWeight_familyMax_pow` starts with the honest unweighted
integrability of `|familyMax|^(2p)`.  Multiplication by the measurable weight
preserves integrability because the weight lies pointwise in `[0,1]`.

`integrable_targetWeight_endpoint_pow` proves

```text
Integrable (fun omega =>
  targetWeight omega * |endpointJ omega|^(2p)) (P d).
```

It does not use the total-integral convention.  The proof uses the exact
identity

```text
endpointJ = endpointBaseline + familyMax
```

and dominates the endpoint power by

```text
2^(q-1) *
  (targetWeight * |endpointBaseline|^q
    + targetWeight * |familyMax|^q),
q = 2p.
```

The first summand is integrable because the target weight is measurable and
bounded by one on the Gaussian probability space.  The second summand is
the preceding weighted-family integrability theorem.  This proof also covers
`p = 0`; the Minkowski estimate itself correctly retains the required
assumption `p >= 1`.

## Coefficient-one endpoint adapter

`endpointJ_eq_baseline_add_familyMax` is T515/T522's exact pointwise
identity in T552's vocabulary.

`momNormW_endpointJ_le` applies
`APrimeFirstCellEndpointHighMoment.momNormW_const_add_le` and proves

```text
momNormW (P d) targetWeight p endpointJ
  <= endpointBaseline
       + momNormW (P d) targetWeight p familyMax.
```

There is no multiplicative constant, exponent loss, measure change, weight
change, or event restriction.

`endpointBoundAt_of_familyBound` is the exported numerical adapter.  Its
premise is a caller-supplied `targetFamilyBoundAt ... C`; its conclusion is
exactly `endpointBoundAt ... C`.  T552 supplies no theorem producing that
family premise.

## Exact zero-prefix branch

`kZero_exact` proves simultaneously, for every size and every explicit
`delta`:

1. `endpoint N 0 = 0`;
2. `ratR ... (endpoint N 0) = 1`;
3. `endpointBaseline N 0 = 1`;
4. T542's target weight is identically one at `k = 0`.

`kZero_endpointJ_eq` gives the exact pointwise identity

```text
endpointJ N 0 = 1 + familyMax N 0.
```

`kZero_endpointBoundAt_of_familyBound` keeps all four exact boundary facts
and derives

```text
momNormW (P d) targetWeight p (endpointJ N 0) <= 1 + C
```

only from the supplied zero-prefix family bound.

## Event and positive resident

`exists_deltaWeightEventResident` is a projection of T542's accepted closed
producer.  It fixes one `tauPrime > 0` before every
`0 < delta <= 1/100` and retains only:

- measurability of the literal

- its `HighProb (P d)` property;

No family or endpoint numerical estimate is inserted into the resident.
