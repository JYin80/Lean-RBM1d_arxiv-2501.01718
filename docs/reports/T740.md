Key signatures (the probe printed these under the installed names):

* `ProbabilityTheory.uniformOn_inter (hs : s.Finite) : uniformOn s (t ∩ u) = uniformOn (s ∩ t) u * uniformOn s t`. This is the finite conditional-probability multiplication rule. `uniformOn_inter'` swaps the conditioning role to `u`.
* `ProbabilityTheory.uniformOn_apply_finset` is also available: for finite sets `s t`, `uniformOn s t = #(s ∩ t) / #s`, requiring measurable singletons and decidable equality. `uniformOn_univ` gives `Measure.count s / Fintype.card Ω`.
* `MeasureTheory.condExp` is the conditional expectation function, written `μ[f | m]`. The useful characterization is `MeasureTheory.ae_eq_condExp_of_forall_setIntegral_eq`: if `m ≤ m₀`, `f` is integrable, and a strongly measurable `g` has the same integral as `f` on every finite-measure `m`-measurable set (with the stated local integrability), then `g =ᵐ[μ] μ[f | m]`.
* `ProbabilityTheory.condExp_generateFrom_singleton` handles conditioning on the two-cell σ-algebra generated by one measurable event `s`; it identifies the conditional expectation with the conditional integral on `s`, almost everywhere under `μ.restrict s`. It is not a prefix-filtration theorem.
* `ProbabilityTheory.condExp_set_generateFrom_singleton` is the corresponding conditional probability of an event for that one-generator σ-algebra.
* `ProbabilityTheory.condDistrib Y X μ` is available for a regular conditional distribution, but requires the output space to be standard Borel and nonempty, and `μ` finite. `ProbabilityTheory.condExp_ae_eq_integral_condDistrib` converts conditional expectations of `f ∘ Y` into integration against this kernel, with measurability, strong measurability, and integrability hypotheses. This is not directly adapted to `prefixSigma W k`, which is an abstract sub-σ-algebra rather than yet a chosen prefix-valued conditioning map.
* `measurableAtom x`, `mem_measurableAtom_self`, `mem_of_mem_measurableAtom`, and `measurableAtom_subset` describe the measurable atom containing a point. `measurableAtom_of_measurableSingletonClass` simplifies atoms to singletons when all singletons are measurable; `measurableSet_measurableAtom` is available under `CountablyGenerated`. These generic names do not identify a `prefixSigma` atom with the T711 `prefixCell` without a separate proof.
* `MeasurableSpace.generateFrom_mono` and `MeasurableSpace.measurableSet_generateFrom` support the existing generator-based filtration and cell-measurability arguments.

The declarations are in `.lake/packages/mathlib/Mathlib/Probability/UniformOn.lean`, `Probability/Kernel/Condexp.lean`, `Probability/Kernel/CondDistrib.lean`, and `MeasureTheory/MeasurableSpace/{Constructions,CountablyGenerated}.lean`.

## Smallest next interface and boundary checks

Recommended next theorem seam: on the existing finite type `PermΩ W` with `uniformPerm W` and `prefixSigma W k`, identify the conditional expectation of a bounded real-valued function `f : PermΩ W → ℝ` with its explicit average over the actual prefix cell containing the sample, almost everywhere. State and prove this using the `ae_eq_condExp_of_forall_setIntegral_eq` characterization and the finite partition into actual-prefix cells (using `prefixCell` and its measurability). This keeps the interface on T711's existing space and σ-algebra and avoids introducing a second conditioning model. Only after that identity is established should the test function be a next-image observable `f ρ = g (ρ ⟨k,hk⟩)` and T694/T703 be used to rewrite the cell average as a sum over next-image fibers. For the conditional law itself, the resulting minimal law is uniform on the unused values after a realized prefix; T694/T703 alone only establish finite fiber coupling/counting and do not yet prove that statement.

Boundary cases for any such next-image theorem:

* `k = 0`, `W > 0`: `prefixSigma W 0 = ⊥`; the conditioning cell is all permutations. For `W=2`, identity and swap are both in the same cell, while their first images differ; each next-image fiber has one point, giving the nondegenerate half/half witness.
* `0 < k < W`: the actual prefix cell is nonempty by T711; the next value must lie outside the already-used prefix images. The theorem must be stated only at a valid coordinate `k : Fin W` and use this realized-prefix support.
* `k ≥ W`: there is no next coordinate `Fin W` to expose. T711's natural-indexed filtration is already at full information (`prefixCell W k π = {π}`), so treat this as terminal information, not as a next-image distribution.
* `W = 0`: there is one empty permutation and no `k : Fin W`; no next-image theorem instance exists. The natural-indexed filtration and full prefix cell still exist, so this is not an empty-support case.
* `W = 1`: the unique valid next-image law is a point mass; retain it as the smallest-width boundary even though T740's requested concrete nonconstant support witness is `W=2`.

No conditional distribution was asserted or proved here. No Doob/Azuma/P2 result, shared event, `N`/`W`/time power, first-cell carrier, or paper closure is claimed.
