## Exact claim and dependency graph

For arbitrary `d : Dims`, `N : Nat`, and finite complex matrix `M` indexed by
`d.Idx N`, `omegaOfHermitian d N M : Omega d` sums coordinate singletons over
`usedCoord d N`. It stores `Re M_ij` and `Im M_ij` at the two tags of each
`idxKey`-upper pair, and `Re M_ii` at the diagonal real tag. The key is exactly
`W * block.val + offset`; `crd d N p` is the size-tagged coordinate. The definition
contains no variance factor.

The proof chain is:

```text
idxKey injectivity + crd injectivity + usedCoord membership
  -> used/unused/other-size coordinate evaluations
  -> three Xentry branches + Hermitian diagonal and conjugate symmetry
  -> Xmat d N (omegaOfHermitian d N M) = M

sbSupport = {0, 1, -1} + sbKre/Sblk definitions + W > 0
  -> Sblk = 1/(3W) on support, 0 off support
  -> gvar = 1/(3W) on the diagonal, 1/(6W) off diagonal on support
  -> positive variance iff support
  -> band-supported entry vanishes whenever its coordinate variance is zero
  -> omegaOfHermitian d N M c = 0 for every zero-variance c : Coord d
```

The `Xmat` conclusion assumes exactly `M.IsHermitian`. The zero-variance conclusion
assumes exactly `HermitianBandSupported M`; the latter is a condition on all matrix
entries, not an implicit probability or carrier hypothesis.
