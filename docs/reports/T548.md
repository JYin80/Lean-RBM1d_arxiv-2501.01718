## Reciprocal high-order bound

For `0 < delta` and `1 <= p`, `one_div_highOrder_le` proves

```lean
(1 : Real) / highOrder delta p <= delta / 20.
```

The ceiling and cast steps are explicit:

1. `Nat.le_ceil` gives `20 / delta <= (⌈20 / delta⌉₊ : Real)`.
2. T542's `ceil_le_highOrder` gives the cast inequality
   `20 / delta <= (highOrder delta p : Real)`.
3. T542's `highOrder_bounds` and `p >= 1` give a strictly positive natural
   and real denominator.
4. Multiplication by the positive `delta` gives
   `20 <= highOrder delta p * delta`, which is divided by the positive
   constants to obtain the claimed reciprocal inequality.

Thus there is no zero-denominator, natural-ceiling, or natural-to-real cast
gap.

## Family root and exponent ledger

For `0 < delta`, `1 <= p`, and `81 <= N`, `family_card_root_le` proves the
coefficient-one estimate

```lean
(Fintype.card (LoopArg (d.L N) 2) : Real) ^
    (1 / (2 * highOrder delta p)) <=
  (N : Real) ^ (delta / 20).
```

The intermediate exponent is definitionally reduced as

```text
(N^2)^(1/(2P)) = N^(1/P),
```

and monotonicity in the exponent uses `N >= 1` and the preceding reciprocal
bound.

For every `N >= 1`, `exponent_product_eq` proves the exact identity

```lean
N^(delta/20) * N^(delta/5) = N^(delta/4).
```

The inequality form is exported separately as `exponent_product_le`.
