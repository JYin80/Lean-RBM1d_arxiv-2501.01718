## Result

The new module proves, for every real `x`,

```lean
RBM.semicircleMeasure_cdf_reflection (x : ℝ) :
  ProbabilityTheory.cdf semicircleMeasure (-x) =
    1 - ProbabilityTheory.cdf semicircleMeasure x
```

It also proves the concrete center identity
`RBM.semicircleMeasure_cdf_zero : ProbabilityTheory.cdf semicircleMeasure 0 = 1 / 2`.
This checks the symmetry at a nontrivial point of the CDF.

The endpoint correction is explicit. Reflection maps `Iic (-x)` back to `Ici x`; the finite-measure complement formula then uses `(Iio x)ᶜ = Ici x`. The proof replaces `μ.real (Iio x)` by `μ.real (Iic x)` using the decomposition `Iic x = Iio x ∪ {x}` and the proved zero singleton mass. Thus no atomlessness endpoint step is omitted.

I checked `paper/250520-YinJun-v2.pdf`: on printed page 7 the density immediately preceding the discussion of (2.1) is `ρ_sc(x) = (2π)⁻¹√((4−x²)₊)`, matching the accepted density definition. The proof uses only the resulting probability measure and its proved reflection invariance. It makes no claim about quantiles, `Q0`, a Stieltjes integral, or a local law.
