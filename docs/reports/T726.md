# T726 — independent final acceptance audit of T720

## Verdict

**PASS** for T720's stated deterministic component-swap ticket. The new module proves the real and imaginary absolute swap differences are each at most `8 / W`, with the exact normalization and hypotheses of the accepted T676 complex theorem. Both component bounds have separate nonconstant sharp witnesses at `W = 2`.

## Source and mathematical check

- Read `paper/250520-YinJun-v2.pdf`, formulas (2.3)–(2.4). They are later high-probability local laws for matrix entries and partial traces; neither is claimed by T720.
- Read the accepted `RBM1D/Gauss/PermutationFourierSwap.lean` (T676) and `RBM1D/Gauss/PermutationFourierComponentSwap.lean` (T720). T676 defines `F(π) = (∑ i, χ i * x (π i)) / W` and proves, for every `W ≥ 2`, bounded `x, χ`, permutation `π`, and `j,k : Fin W`,
  `‖F((swap j k).trans π) - F(π)‖ ≤ 8 / W`.
- T720 applies `Complex.abs_re_le_norm` and `Complex.abs_im_le_norm` directly to that **same difference** and composes each with the T676 bound. It neither changes the order/sign of the swap nor adds a factor or changes a power of `W`. It retains the pointwise assumptions `‖x i‖ ≤ 2` and `‖χ i‖ ≤ 1`, with no additional hypothesis.
- For the real witness, `W=2`, `π=id`, `j=0`, `k=1`, `x=(2,-2)`, and `χ=(1,-1)`. Directly, `F(id)=2` and `F(swap)=-2`, so the real absolute difference is `4=8/2`. The formal witness proves the pointwise bounds and both `x 0 ≠ x 1` and `χ 0 ≠ χ 1`.
- For the imaginary witness, the same data use `x=(2I,-2I)`. Directly, `F(id)=2I` and `F(swap)=-2I`, so the imaginary absolute difference is `4=8/2`. Its formal witness again proves the pointwise bounds and both nonconstancy conditions. These examples make the ticket nonvacuous.
- Both bound theorems require `2 ≤ W`; neither witness asserts a distinct pair at `W=1`. `W=0` is excluded. The quantified bound allows `j=k`, where its left side is zero, without relying on that degenerate case for sharpness.
