## Coefficient-one weighted Minkowski

The generic theorem `momNormW_const_add_le` proves

```text
momNormW P w p (fun omega => b + Z omega)
  <= b + momNormW P w p Z
```

for `p >= 1`, `b >= 0`, `Z >= 0`, `0 <= w <= 1`, and the required
weighted-power integrability.  Its proof puts

\[
w^{1/(2p)}(b+Z)
\]

in the ordinary probability-space `L^{2p}` norm and invokes the existing
coefficient-one affine Minkowski theorem.  Since
`w^{1/(2p)} <= 1`, the deterministic baseline costs at most `b`.  The
two root-scaled ordinary norms are converted back to `momNormW` by
`APrimeBadSplit.momNorm_root_eq`.

Thus the implementation realizes the same subprobability argument as the
preflight without replacing the baseline by a larger explicit constant.
