# T395 — one-parameter first-cell source/support event

## Result

Added `RBM1D/Gauss/APrimeFirstCellSourceSupport.lean`. The exported theorem
`RBM.APrimeFirstCellSourceSupport.exists_jointEvent_with_plateau` chooses one
`τ' > 0` from T358 **before** quantifying over `ζ > 0`. For each `ζ`, it gives
the measurable, high-probability, eventually nonempty event

```text
jointEvent τ' ζ N =
  APrimeFirstCellSourceAllTime.commonEvent τ' ζ N ∩
  APrimeSupportRunning.good τ' (1/100) N.
```

On every sample in this event, `jointConsequences` gives T384's actual
`SourceEvent` for every real running time in the first cell. It gives T388's
`jG_r ≤ N^(1/8)` only if a literal active prefix has positive weight, for
`N0 ≤ N`, `p,m ≥ 1`, `1 ≤ k ≤ cutNetTop`, and `0 ≤ r ≤ u_k`. It does not move
the positive-weight condition outside that implication.

The same theorem includes `positivePlateau`: eventually one sample in the
joint event has the `k=2`, `N0=2`, `m=N` plateau weight equal to one for every
`p`. The two actual grid points are `u₁=N⁻²⁴⁸` and `u₂=2N⁻²⁴⁸`, both in the
first cell, with `u₁>0`. The source event holds at each point, and the support
bound holds for every `r∈[0,u₂]` on that same sample. The cutoff at `k=2`
tests earlier grid points `u₀` and `u₁`; the resulting positive weight covers
the interval through `u₂`.

## Dependencies and event thresholds

The proof rebuilds the T384 source event's HighProb estimate at T358's chosen
`τ'` from the raw length-four and length-six `StochDom` laws, the Gaussian
norm event, and the first-cell local-law Good event. It obtains T388's good
event from the **same** T358 local law, then intersects the two HighProb
events before choosing a sample. `firstCellDelta` in the source event and
`flowDelta` in the support event remain distinct components. The positive
plateau is applied to the chosen joint-event sample using its norm bound;
T388's auxiliary positive-plateau theorem is used only for deterministic
grid facts.

There is no WeightedMoment dependency, global Good-only `jG` cap, T334
profile, integrated QV estimate, or A′ conclusion in this module. The theorem
is a formal joint-event interface for paper (5.42), not a claim that (5.42)
itself has already been integrated.
