## 验收 2 —— ⚠⚠ **按现有编码被反驳，已按指示停下报回**

**D17 的算术只在「`Kmod` 允许随 `D` 增长」时成立，而仓库不允许**：`EntryModulusEv`（`Flow/Eq548Producer.lean:430`）与 `EntryModulusEvOn`（`Flow/Thm221Assembly.lean:1074`）**都把右端 `(N:ℝ)^(1:ℝ) * |v−w|^(1/2)` 硬编码**。对着这个固定指数，事件**救不了**第一格：

* 取 `v = N^{−2}`、`w = 0`。T249 的见证是 `ω = 1/√v = N`，即 `‖X(ω)‖ = N`——**落在** `{‖X‖ ≤ N}` **里面**（`exists_jSfarSm_ge_swapSample` 的两个候选 `{1/√v, 0}` 都在）。
* `jump_le_one_of_kmod_one`（编译）：`Kmod = 1, γ = 1/2` 的模在那一点只允许跳跃 **≤ 1**。
* ⚠ **`gap_lower_W`（编译）：T249 的跳跃不是常数——`gap_lower` 丢掉了一个因子 `W`**（它有 `num ≥ 1/(100W)` 与 `T_{v,D} ≤ W^{−2}((η_{t₀})^{−2}+1)`，然后用 `W ≥ 1` 把 `W` 丢了）。留着的话跳跃是 `≥ W/(200((η_{t₀})^{−2}+1))`，**发散**。
* 于是 `W > 200((η_{t₀})^{−2}+1)` 一成立就矛盾。

`kmod_ge_of_jump` 给一般形式：`v = N^{−2}` 处的跳跃 `g` 逼出 `g ≤ N^{Kmod−1}`。`g ≍ W ≥ N^{1/2}` 已经打掉 `Kmod = 1`；改用 `tailT` 的 `W^{−D}` 项而不是粗界，则**要 `Kmod` 随 `D` 线性增长**（`Kmod ≳ D`），正好对上 D17 的「取 `Kmod ≥ D−1`」。
