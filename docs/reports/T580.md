**Scope:** read-only mathematical/Lean preflight after T579.  This report changes no Lean

## Verdict

The earliest honest actual-model theorem after T579 is a **positive-cell, same-event,
general-moving evolved-QV profile** obtained by specializing
`APrimeFullQV.qvAt_full_absorbed` with T491's `sourceEll/sourceC4` and T579's support-local
block cap.  It is ready for a bounded implementation ticket.

This is the exact pre-simplification profile underlying paper formula (5.42), not yet the
paper's final `A_u^(-1/3) (J^*_{u,D})^3` row.  The latter still needs a deterministic
absorption lemma for the quadratic source term and the spatial leakage.  Drift (5.35) is a
separate branch and is not a prerequisite for this QV specialization; the cross term is
downstream of the drift and QV branches.  Nothing inspected justifies time integration,
stopping, coordinate moments, `hfamily`, `APrimeSlot'`, A-prime, six-step assembly, or paper
closure.

The current T579 implementation and report are present in the working tree.  Its report
records a successful build and an allowed axiom audit.  Scheduler acceptance/merge remains
outside this ticket, so the dispatch below is conditional only on making that current T579
surface available to the next module.

## Paper boundary

The relevant formulas in `paper/250520-YinJun-v2.pdf` have distinct logical roles:

- (5.35) is the pointwise `E^{(G)}` drift estimate.
- (5.42) is the evolved `E \otimes E` endpoint/QV estimate.  Its near row carries
  `(eta_u/eta_t)^4 (ell_u/ell_s)^5`; its far row is weakened to
  `A_u^(-1/3) (J^*_{u,D})^3`.
- (5.43) defines the stopping time at the threshold `(eta_s/eta_t)^4`.
- (5.44) is an **integrated stopped** QV estimate.
- (5.45) is a deterministic-time stopped-martingale estimate.
- (5.46) takes a maximum over a separate `N^(-C)` stopped-martingale time net.
- (5.47) is the resulting bootstrap conclusion for `J^*`.

Consequently, T523's all-time centered-trace construction is a source for the drift branch;
it is not the stopped-martingale net of (5.46).  The proposed theorem below stops at the
pointwise actual QV profile and does not imply (5.43)--(5.47).

## Exact quantities for the next theorem

For readability set, at a current time `u` and endpoint `v`,

```text
A_u = W * ell_u * eta_u,
r_u = ell_u / ell_s,
R_u = eta_s / eta_u = Step2Moment.ratR E s N u,
R_v = eta_s / eta_v = Step2Moment.ratR E s N v.
```

The support-local cap must remain literally

```text
Jbar(N,u) =
  1 + N^tauG *
    (9 * exp(sqrt 3) *
      ((4 * exp 1 + 2) * N^(2*delta) * R_u^4) + 2).
```

In particular, `R_u^4` must not be replaced by `16`, by an endpoint ratio, or by an
unrecorded `N`-power.

The source parameters are exactly T491's

```text
ellSource = ell_s * (2 * N^zetaSrc)^(-1/5),
Smax      = N^zetaSrc * r_u^3 * A_u^(-3).
```

A minimal implementation may define `Jbar` and retain
`APrimeFullQV.rootProfile` literally.  A useful companion definition for the normalized
square-root ledger is obtained by expanding the already present definitions:

```text
nearRate = 4 * N^zetaSrc * eta_u^(-1)
             * Lemma57.cNear2 W ell_u * r_u^5,

farRate(J) =
    16 * eta_u^(-1) * Lemma57.cFar2 W ell_u * J^2
       * N^(zetaSrc/2) * r_u^(3/2) * A_u^(-1/2)
  + 1152 * eta_u^(-1) * J^3 * A_u^(-1)
  + 32 * W * L * W^(-D) * J^3,

qvRootLedger(Jbar,a) =
  (R_u^2 * R_v^2)^(-1) *
    (sqrt(nearRate + 2 * W^(-1)) *
       (xiK * nearIndicator(v,a) + 256 * exp 3 * W^(-D))
     + sqrt(farRate(Jbar)) * xiK).
```

Here `xiK = Step2.xiK L W (mE E).im` and

```text
nearIndicator(v,a) =
  if zdist(a_0-a_1) <= 6 * ellStar W ell_v then 1 else 0.
```

The displayed `farRate` is an exact positive-scale rewrite of
`APrimeQVEndpoint.diagFarRate ... Jbar (sourceC4 ...)`; an implementation may first state the
theorem with `diagFarRate` and prove this equality separately.  This avoids making a long
square-root/rpow normalization part of the main proof.

The endpoint factor is exact.  In `rootProfile`, every endpoint kernel contains

```text
((1-u)/(1-v))^2 * T_{v,D}(a),
```

while `driftScale = T_{v,D}(a) * R_v^4`.  Since
`(1-u)/(1-v) = eta_u/eta_v = R_v/R_u`, division by `driftScale` gives

```text
R_u^(-2) * R_v^(-2).
```

Both time ratios are essential; replacing them by a single terminal power is not an exact
rewrite.

## Exponent audit

All identities below are before any stochastic-loss choice or absorption.

T491 contributes

```text
C3 = N^zetaSrc * r_u^2 * A_u^(-2),
C4 = N^zetaSrc * r_u^3 * A_u^(-3),
C6 = N^zetaSrc * r_u^5 * A_u^(-5),
ellSource = ell_s * (2*N^zetaSrc)^(-1/5).
```

Thus

```text
(ell_u/ellSource)^5 = 2*N^zetaSrc*r_u^5,
```

and `diagNearRate` is exactly the `nearRate` displayed above.  The factor `2` in
`ellSource` and the outer factor `2` in `diagNearRate` produce the coefficient `4`.

Substituting `C4` into `diagFarRate` gives exactly three rows:

| row | exact rate before square root |
| --- | --- |
| quadratic source | `16*eta_u^(-1)*cFar2*J^2*N^(zetaSrc/2)*r_u^(3/2)*A_u^(-1/2)` |
| cubic inverse scale | `1152*eta_u^(-1)*J^3*A_u^(-1)` |
| spatial leakage | `32*W*L*W^(-D)*J^3` |

The repaired near residual is exactly `2*W^(-1)` under the square root.  The endpoint
kernel also retains the separate `256*exp(3)*W^(-D)` near leakage.  Neither term may be
deleted when stating the first theorem.

For power bookkeeping only, write `lambda = tauG + 2*delta`.  Since `R_u >= 1`, the exact
cap has the eventual comparison

```text
Jbar <= C * N^lambda * R_u^4
```

for a fixed deterministic constant `C`; this is a comparison, not the definition of
`Jbar`.  After taking the square root and multiplying by the exact endpoint normalization
`R_u^(-2)R_v^(-2)`, the dominant rows are:

| row in normalized square-root budget | `N` power | remaining time power |
| --- | --- | --- |
| near source | `zetaSrc/2` | `R_u^(-2) R_v^(-2)` |
| quadratic far source | `lambda + zetaSrc/4` | `R_u^2 R_v^(-2)` |
| cubic inverse scale | `3*lambda/2` | `R_u^4 R_v^(-2)` |
| spatial leakage | `3*lambda/2` | `R_u^4 R_v^(-2)` |

The non-time factors in these four rows are respectively

```text
eta_u^(-1/2) * sqrt(cNear2) * r_u^(5/2),
eta_u^(-1/2) * sqrt(cFar2) * r_u^(3/4) * A_u^(-1/4),
eta_u^(-1/2) * A_u^(-1/2),
sqrt(W*L) * W^(-D/2).
```

The final QV bound is the square of the sum of these normalized root rows; expanding the
square would double pure monomial exponents and introduce cross terms, so it should not be
silently presented as a termwise equality.  In particular, the retained support cost
`R_u^4` becomes `R_u^4` in the normalized cubic **root** row after the
`R_u^(-2)R_v^(-2)` endpoint factor.  This is the main moving-window cost absent from the
first-cell files.

The centered loss `zetaCtr` and `flowDelta` do not enter this QV theorem.  They remain in the
same literal common event because they are needed by the independent drift branch.  The
losses must not be identified merely because one branch does not use all of them.

## Endpoint and `k = 0` audit

The universal QV theorem must require `1 <= k`.  T579's support propagation has exactly this
hypothesis.  It is invalid to apply its cap at `k = 0` or to substitute the first-cell bound
`R <= 2` into a general moving cell.

At `k = 0`, `v = s_N`.  The quantity `qvAt ... s v u` is an instantaneous QV rate, not a time
integral, and therefore is not automatically zero when `u = v = s_N`.  T579 does supply the
raw source at `s_N`, but it does not supply the positive-support `Jbar` cap there.  The clean
handling is:

- keep this pointwise theorem on positive cells only;
- discharge `k = 0` later, after time integration, by the zero length of `[s_N,s_N]`;
- do not invent a universal pointwise `k=0` cap.

One could separately state `qvAt_full` at `u=v=s_N` with the actual `jG` and unabsorbed
`nearEpsilon`, but that statement is not needed for the mesh induction and does not improve
the first dispatch.

- The event is literally one
  `APrimeGeneralMovingCommonSources.commonEvent E D s t zetaSrc zetaCtr tauG N`.
  The proof must take every source and cap from the same `omega`; it must not select new
  residents from T491, T523, or T575 separately.

  is required for the pathwise QV theorem.
- Parameters `E,D,c,s,t`, their geometry assumptions, and `BoundsCore` occur before the
  losses.  Event membership occurs before `k,u,a` conclusions.  `delta,p,k` belong only to
  support localization and are not event parameters.
- `u` ranges over the closed interval `[s_N,v_k]`, and `v_k` lies in `[s_N,t_N]`; hence T579's
  `TimeIcc` sources apply at `u=s_N` and `u=v_k` as well as in the interior.
- The three losses remain independent.  The QV branch uses `zetaSrc`; the event still carries
  positive `zetaCtr` and `tauG` unchanged.
- T579's `positive_length_common_support_witness` is a genuine same-event, positive-duration
  witness at `D=60`, `E=0`, `k=1`, with `widenedW=1`.  Choosing, for example,
  `zetaSrc=zetaCtr=tauG=delta=1/100` and `p=1` also satisfies
  `tauG+2*delta+2/15<1`.  Therefore the proposed hypotheses are nondegenerate and jointly
  satisfiable.  This first-cell tuple is used only as a witness, never as the universal proof.

## Drift and cross: the first remaining obligations

The general-moving drift branch is plausible but is not yet a one-line specialization of
`Step2FarInputs.eGpm_le_rhs535_of_jS`.  The literal common-event sources give

```text
centered coefficient kappa1 = 4*N^zetaCtr*r_u,
raw three-loop coefficient  = N^zetaSrc*r_u^2*A_u^(-2),
block-average coefficient   = flowDelta(N) + W^(-1).
```

The extra factor `2` relative to the first-cell `kappa1` is forced by T523's literal
`2*qExt`: `EGDef.norm_eGpm_le` contributes its own factor `2*W`, so on the window
`2*W*(2*N^zetaCtr*qExt) = (4*N^zetaCtr*r_u)*(ell_u*eta_u)^(-1)`.
The first two stochastic losses must remain visible.  The first-cell proof
`APrimeFirstCellEGFar.norm_eGpm_far_source_bound` shows the correct deterministic route
through `Lemma57.eG_far_le`, but its first-cell `J <= 2` and time restrictions cannot be
reused.  A general-moving drift assembly must instead use actual `jG <= Jbar`, the literal
`flowDelta+W^(-1)`, and T523's two-charge bound in the far subtheorem; T491's `C3` enters the
near subtheorem.  Its exact far target is

```text
||eGpm_u(a1,a2)|| <=
  eta_u^(-1) * (4*N^zetaCtr*r_u) *
    (cFar(W,ell_u) * Jbar * (flowDelta(N)+W^(-1))
      + Jbar*sqrt(Jbar) *
          (168*A_u^(-1) + L*sqrt(W^(-D))/ell_u))
    * T_{u,D}(a1-a2),
```

with the corresponding near branch retaining the combined loss
`N^(zetaCtr+zetaSrc)` and `r_u^3`.  Proving and then absorbing these rows is the first real
drift obligation.  It is not an assumption of the QV theorem above.

The cross term should be dispatched only after the general-moving drift and QV root budgets
are both available on the same sample, using the appropriate deterministic/Cauchy--Schwarz
bridge.  No inspected theorem currently licenses stating the integrated cross estimate or a
coordinate-moment conclusion directly from T579.

## Dependency and non-claims

The proposed QV module should depend only on the general-moving source/support stack and
neutral deterministic QV modules.  It must not import a moment conclusion, `hfamily`,
`APrimeSlot'`, A-prime closure, six-step assembly, or a first-cell endpoint theorem.  This
keeps the graph acyclic.

This report does **not** claim:

- the simplified paper (5.42) exponent `A_u^(-1/3) Jbar^3`;
- (5.35) in either its near or far final form;
- the stopping-time construction (5.43);
- the integrated estimates (5.44)--(5.45);
- the stopped-martingale net estimate (5.46);
- the bootstrap conclusion (5.47);
- any coordinate moment, `hfamily`, `APrimeSlot'`, A-prime, six-step, or theorem-2.21
  closure statement.

The first dispatch should therefore be the exact positive-cell QV profile above, followed by
a separate deterministic exponent-absorption ticket and, independently, a general-moving
drift assembly ticket.
