## Positive moment orders

For an arbitrary probability space, fixed `p >= 1`, `N >= 1`, and real
`delta`, `integral_cutTrunc_le_of_momNormW` assumes:

- `0 <= W` and `W <= 1` pointwise;
- `W` is `AEStronglyMeasurable` for the same probability measure `P`;
- `0 <= J` pointwise, the exact condition used by
  `cutTrunc_le_self`;
- honest integrability of `W * |J|^(2p)` under the same `P`;
- the conditional estimate

  ```lean
  momNormW P W p J <= 2 * N^(delta/4).
  ```

It proves, with the identical `P`, `W`, and `J`,

```lean
integral (W * |cutTrunc (N^(2*delta)) J|^(2p)) P <=
  2^(2p) * N^((delta/2) * p).
```

The proof uses
`APrimeOneStep.integral_cutTrunc_le_of_momNormW_le`; the pointwise majorant is
obtained from nonnegativity of `J` and `cutTrunc_le_self`.  No event or
deterministic all-sample bound is introduced.

## Exact exponent identity

`normBound_pow_eq` proves for `N >= 1`

```lean
(2 * N^(delta/4))^(2p) = 2^(2p) * N^((delta/2) * p).
```

The proof expands the natural power, converts it to a real power using the
positive base `N`, and checks exactly

```text
(delta/4) * (2p) = (delta/2) * p.
```

There is no additional constant or exponent slack.

## Zero order

`integral_cutTrunc_zero_le` treats `p = 0` directly with
`Gauss.integral_weight_pow_zero_le`.  It does not invoke `momNormW`, whose
definition degenerates at zero order.  The displayed right side simplifies
to

```text
2^0 * N^0 = 1.
```

## Satisfiability witness

`conditional_interface_satisfiable` uses the one-point space `Unit`, the
Dirac probability measure `Measure.dirac ()`, weight `W = 1`, and observable
`J = 0`, at `delta = 1/100`, `p = 1`, and `N = 1`.

The theorem explicitly records that the measure of the whole space is one,
so the witness is not the zero measure.  It simultaneously verifies weight
nonnegativity, the upper bound by one, strong measurability, observable
nonnegativity, weighted-power integrability, the conditional moment-norm
premise, and the cutoff-integral conclusion.
