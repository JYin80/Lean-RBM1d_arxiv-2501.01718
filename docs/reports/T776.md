# T776 — exact next-image event quotient on an actual prefix cell

## Files and result

Added only `RBM1D/Gauss/PermutationNextImageCellRatio.lean` and this report. The module imports T749's `PermutationPrefixCellFiberBridge` and T736's `PermutationPrefixCellMass`; their common lower dependency is T711's actual-prefix cell. No root, shared documentation, `.mathbox`, or existing Lean file was edited. In particular, the new module is **not yet imported by `RBM1D.lean`**; the root build below checks the existing root tree while the separate module build checks this source.

`uniformPerm_nextImage_cell_ratio` proves, for every `W : ℕ`, `k : Fin W`, actual `π : PermΩ W`, and `v : Fin W`, exactly

```lean
uniformPerm W {ρ | ρ ∈ prefixCell W k.val π ∧ ρ k = v} /
  uniformPerm W {ρ | ρ ∈ prefixCell W k.val π} =
    (Fintype.card (prefixCellNextFiber W k π v) : ENNReal) /
      (prefixCell W k.val π).card
```

There is no unused-image hypothesis. The proof first counts the intersection event as the subtype fiber, allowing for T749's custom `Fintype` instance by a `Fintype.card_congr` step. It then uses `uniformOn_univ` and `Measure.count_apply_finset` to express the numerator as fiber card divided by the total permutation card, and T736 to express the denominator as cell card divided by the same total. The local cancellation lemma explicitly assumes that common total card is neither zero nor `⊤`. `uniformPerm_actualPrefix_event_pos_ne_top` independently records that the actual conditioning cell has strictly positive finite mass, so the quotient is not `0/0`.

## Boundary and nondegeneracy checks

- `W=0`: no `k : Fin 0` exists, so the universal theorem has no zero-width reveal instance.
- `W=1`, `k=0`, `v=0`: `uniformPerm_nextImage_cell_ratio_one` gives quotient `1`.
- `W=2`, `k=0`, `π=id`: `uniformPerm_nextImage_cell_ratio_two` gives `1/2` for each of the distinct values `v=0,1`. Its proof computes each fiber card as `1` and the cell card as `2`; both fibers have positive mass. This is a nondegenerate witness, not an empty assertion.
- For `i<k` and `v=π i`, injectivity of any permutation makes the next-image fiber empty. `prefixCellNextFiber_card_zero_of_used` and `uniformPerm_nextImage_cell_ratio_zero_of_used` prove card and quotient zero. Thus the all-`v` statement does not tacitly assume that `v` is unused.

## Scope relative to the paper and T766

The paper's (2.3) and (2.4) are high-probability Green-function and partial-trace local laws with `N`, `W`, `ℓ`, and `η` scales. This theorem is a finite event probability ratio only. It establishes neither `1/(W-k.val)` for unused images nor a `condExp` or `condDistrib` identity given `prefixSigma`; it supplies no first-cell/shared event, P2 concentration, time estimate, or chain closure. No new hypotheses were introduced, and this is an auxiliary result rather than a restatement of (2.3) or (2.4).

T766's attribution of `prefixCell_card_eq_factorial` to T741 is a typo: the actual producer is T738 `PermutationPrefixCellCard`. T741 proves positive support for a realized prefix fiber. The present proof does not import or use either theorem.
