# T1113 — integral of the deterministic general-moving cross envelope

## Verdict: mathematical preflight PASS; exact envelope integral proved

The deterministic envelope in T1107 is interval integrable on every
`[s,v]` with `0 ≤ s ≤ v`, and its interval integral is exactly

```text
C / √r,  C = crossMomentCoeff p / (4p) · N^(2D+17)
∫_s^v C / √r dr = 2C(√v − √s).
```

The new moving-endpoint theorem specializes this result to
`v = cutNetPt s (targetMesh D) N k` for every active `k` and retains T1107's
pointwise positive-time budget bound with the same coefficient and exponent.
The integral in the theorem is only the integral of the deterministic
envelope.

## Mathematical and API preflight

I checked the supplied `paper/250520-YinJun-v2.pdf` directly, including a
visual review of the pages containing the formulas. Formula (5.21) is the
stopped integrated loop hierarchy and includes a terminal stochastic-integral
term. Formula (5.24) is its BDG moment estimate in terms of the integrated
quadratic variation. This ticket proves neither paper formula; it integrates
the polynomial cap already obtained for the T1089 cross budget in T1107.

For the calculus step, the exponent is `-1/2`, so the checked Mathlib producer
`intervalIntegral.intervalIntegrable_rpow'` applies because `-1 < -1/2`.
The checked `integral_rpow` formula gives
`(v^(1/2) − s^(1/2))/(1/2)`, which is `2(√v − √s)` for nonnegative endpoints.
In Lean, both `C / √0` and `C * 0^(-1/2)` are formally zero. The proof records
that endpoint equality explicitly; the interval-integrability and integral
congruences use equality on the open interval, where `r > 0`. Thus `s = 0`
needs no logarithmic or limiting case, and the degenerate endpoint `s = v`
also evaluates to zero.

The coefficient check is exact: T1089 defines
`crossMomentCoeff p = (2p)^2 · 15/8`, hence
`crossMomentCoeff p/(4p) = 15p/8` for `p ≥ 1`. At `p = 1`, this is `15/8`;
the T1107 pointwise cap is therefore `15/(8√r) · N^(2D+17)`. The source
proves the `p = 1` specialization as `envelopeConstant_one`.

For the endpoint specialization, T1107's accepted producer bounds its actual
positive-time budget by
`crossMomentCoeff p/(4p√r) · N^(2D+17)` on each active cell and each `r > 0`.
The new theorem algebraically rewrites that expression to the integrand
`C/√r`, then supplies the exact interval integral at the same target endpoint.
It makes no measurability or integrability claim about the actual budget or
the random joint-rate norm.

The included T995 witness is the accepted `E = 0`, `D = 60` schedule witness.
It supplies `s_N = 0`, a positive-length window, an eventually active first
positive cell, and a same-sample common-event point with positive actual
smooth weight at `p = 1`. This confirms the moving-window context is
nonempty; it does not assert that the point is in the strict transition event.
