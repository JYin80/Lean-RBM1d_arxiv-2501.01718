# T339 — old-prefix weight versus the new smooth cutoff

## Verdict

**Yes for the pointwise domination of the literal old `piecewiseW`, with a branch correction; no for treating that result alone as a completed old-weight integration or a verified nonconstant Gaussian witness.** The T329 §11 numerical margin is sufficient and independent of the moment order. The exact live old weight in `APrimeAssembly.lean:1216` starts at `N₀=1`, while the proposed new weight can start at `N₀=2`. The comparison must therefore allow `N₀_old≤N₀_new`, rather than assert that both inactive branches always coincide. Also, `APrimeAssembly`'s existing `hfamily` is for `widenedW`, which is not dominated by the same plateau calculation at `Θ=4e²N^(2δ)`.

No Lean theorem stating this new comparison has yet been compiled in `APrimeSmoothWeightActual.lean`; that file is T333's ongoing work. The present result is a read-only preflight and supplies a precise statement for its next milestone.

## Pointwise proof and constants

The live old `prefixSoftW` (`Gauss/APrimeWeight.lean:27`) is `softW` of the *hard* `J` values at `cutNetPt s mesh N j` for `j<k`. Its active threshold is exactly `exp 1 · priorLevel δ (fun _=>1) N = e N^(2δ)` (`Gauss/APrimeWeight.lean:93`; `Gauss/APrimePrior.lean:80`). The new `prefixSample` (`Gauss/APrimeSmoothWeightActual.lean:343–352`) uses `smoothJSMatrix` at precisely those same net times, evaluated on `(sqrt u_j)•Xmat N ω = Hflow N u_j ω`. `APrimeSmoothPrefix.smoothJSMatrix_flow` identifies each inner term with `smoothJS`. This common sample/time identity is essential; no independence between net times is used.

If the old weight is positive on the common active branch, `Step2Bootstrap.abs_le_two_mul_of_softW_ne_zero` (`:1122`) gives the **weak** but sufficient bound `|J_j|≤2eN^(2δ)` for every `j<k`. One need not prove the strict `<` written in T329 §11. For `k≥1`, the inner `APrimeSmoothPrefix.smoothJS_le_hard` (`:293`) and `Step2Moment.one_le_ratR` (`Hierarchy/Step2Moment.lean:414`) give, with `ε=W^(-D)N^(-10)`, a bound by the loop-label cardinality factor times `J_j+N^(-10)`. Applying `Step2Bootstrap.softMax_le` (`:970`) to the outer prefix multiplies that factor by `k^(1/(2m))`; the product is `(kM)^(1/(2m))≤e`, where `M=card (LoopArg (d.L N) 2)`. Hence

`S_k≤e(2eN^(2δ)+N^(-10))≤(2e²+e)N^(2δ)<4e²N^(2δ)=Θ_N`

for active `N≥2`, since `N^(-10)≤N^(2δ)` and `e>1/2`. Thus `cutChi(S_k/Θ_N)=1` by `Cutoff.cutChi_eq_one` (`Gauss/CutoffChi.lean:201`), and the new weight is one for **every** moment order `p`. The old weight is at most one by `APrimeWeight.piecewiseW_le_one` (`:125`), proving domination. If the old weight is zero, domination follows from nonnegativity of the new cutoff (`Cutoff.cutChi_nonneg`). The orientation of `cutChi` is correct: it is one at arguments ≤1 and zero at arguments ≥2 (`Cutoff.cutChi_eq_zero`, `:207`).

At `p=0`, `cutoff^(2p)=cutoff^0=1` even if the cutoff itself is zero, so the result follows from `piecewiseW_le_one`. At active `k=0`, both soft maxima run over the empty prefix and equal zero for orders at least one; the old cutoff is one and `APrimeSmoothWeightActual.weight_zero_prefix` (`:403`) gives the new weight one. If `k>cutNetTop` both are inactive. If `N<N₀_new`, the new weight is one; this covers the live old-active/new-inactive case `N=1`. If the new weight is active, `N₀_old≤N₀_new` ensures the old weight is active as well. At `N=0` both actual piecewise weights are inactive, so no inverse-scale expression is evaluated. These branches are the correction to T329 §11's sentence that all inactive branches coincide.

## Consumer distinction and witness status

`APrimeAssembly.lean:1203–1220` currently asks `hfamily` for `APrimeWeight.widenedW`, whose old cutoff threshold is `2eN^(2δ)` (`Gauss/APrimeWeight.lean:100`). Positive `widenedW` only yields `J_j≤4eN^(2δ)`, so the same soft bound is at most `(4e²+e)N^(2δ)`, **above** `Θ_N=4e²N^(2δ)`. The plateau proof therefore does not establish `widenedW≤weight_new`. To use the proved old-weight comparison at this Θ, produce the literal `Step2Bootstrap.WeightedMoment` field for `piecewiseW` (`Gauss/Step2Bootstrap.lean:1166`) and feed `APrimeSlotFields.aprimeHypOn_jSnorm_event` (`Gauss/APrimeSlotFields.lean:441`) or another direct consumer. Alternatively a separate widened-weight comparison would need a larger new threshold and a fresh downstream constant audit.

The T329 §12 high-order transfer is arithmetically consistent for the **old** weight: a uniform `2P` coordinate estimate for `c_kY_a`, together with `W_old≤c_k^(2P)`, costs `N^(C_label/(2P))` from label counting and no endpoint count. Choose `P` after the target moment order, with `C_label/(2P)≤δ/8`, and `ν≤δ/16`; then the resulting exponent `2p(ν+C_label/(2P))≤3δp/8≤δp/2` fits `WeightedMoment`. At `p=0`, `E W_old≤1`. This arithmetic does not itself provide the still-required smooth coordinate moment producer.

The existing `APrimeWeight.sat_piecewiseW_nonconstant` (`:334`) is a toy sample-space witness, and the current T333 file has no declaration showing the new cutoff is nonconstant on an **active Gaussian** branch. `weight_zero_prefix` only proves the constant `k=0` branch. A suitable witness must exhibit some `N≥N₀_new`, `2≤k≤cutNetTop`, a positive preceding net time, and two samples `ω₁,ω₂:Gauss.Ω d` with different values of `cutChi(S_k/Θ_N)` (for instance `S_k(ω₁)≤Θ_N<S_k(ω₂)`). Nonconstancy of `jSnorm` alone is insufficient because `cutChi` has a plateau. This actual-model anti-vacuity item remains **unverified**, so the full T333 acceptance gate is not yet met.

## Widened-weight reroute requested after the preflight

**Yes: replacing the new threshold by `Θ'_N = 8e² N^(2δ)` closes the specific `widenedW` comparison.** Keep the same calibrated smoothing order, sample, net, and loop labels. On the common active branch with `p≥1`, positivity of the old `widenedW` implies positivity of its base cutoff and therefore, for every `j<k`,

`J_j ≤ 4e N^(2δ)`.

The inner and outer soft-maximum estimates above then give

`S_k ≤ e(4e N^(2δ)+N^(-10)) ≤ (4e²+e)N^(2δ) ≤ 5e²N^(2δ) < 8e²N^(2δ)=Θ'_N`.

The last inequality uses `e≥1` and `N≥2`. Thus the new cutoff equals one wherever the old widened weight is positive, proving `widenedW_old(p,δ,N,k,ω) ≤ weight_new,Θ'(p,δ,N,k,ω)`. The coefficient `4e²+e` is the smallest threshold justified by this coarse estimate; `5e²` is a convenient simple safe coefficient, and the proposed `8e²` has ample fixed slack. For `p=0`, both power weights equal one on active branches. At `k=0`, both prefixes vanish and both weights equal one. At `N=1` the live old cutoff (`N₀_old=1`) may be active while the new one (`N₀_new=2`) is inactive and equals one; at `N=0`, both are inactive. More generally use the exact hypothesis `N₀_old≤N₀_new`. For `k>cutNetTop`, both are inactive.

Conversely, on the new cutoff's positive active support, `S_k<2Θ'_N=16e²N^(2δ)`. By `APrimeSmoothPrefix.jSnorm_le_smoothJS` and `Step2Bootstrap.le_softMax`, this gives `J_j≤16e²N^(2δ)` for every **preceding** net point `j<k`. It does not assert this bound at the current endpoint `j=k`; extending to running times needs the separate net-modulus lemma already used in T329. The threshold change doubles the old support constant `8e²` to `16e²` and halves the explicit reciprocal-threshold factor in the covariance-gradient estimate. Every factor of `N` in the drift, QV, and cross estimates is unchanged. Their fixed constants and eventual starting index may change, but the strict exponent margins of T329/T330 are unaffected.
