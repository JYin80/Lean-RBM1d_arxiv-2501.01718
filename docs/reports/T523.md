## Proof

The `true` branch is exactly T518's
`centeredTrace_stochDom_timeIcc`.  For the `false` branch, the plus theorem
is rewritten to T511's public `traceNorm` interface and passed to
`stochDom_timeIcc_false_of_true`.  Unfolding `traceNorm` gives the requested
minus centered-trace norm.

T511 uses the pointwise all-sample norm equality, so the two bad sets are
identical.  There is no event union and no loss in `N`, `W`, time, or the
control.


The two-charge theorem is applied once to that tuple.  No separate
existential windows are combined.
