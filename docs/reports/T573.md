## Result

The actual first-cell observable and p-independent weight are packaged as

```lean
noncomputable abbrev actualJ :
    ℕ → ℝ → Gauss.Ω Gauss.Dims.exampleGrow → ℝ

noncomputable def weight (tauPrime delta : ℝ) (N k : ℕ) :
    Gauss.Ω Gauss.Dims.exampleGrow → ℝ
```

with the definitional alignment

```lean
theorem weight_eq_piecewiseW (tauPrime delta : ℝ) (N k : ℕ) :
  weight tauPrime delta N k =
    APrimeWeight.piecewiseW
      (APrimeWeight.canonicalR (fun _ => 0) (Gauss.firstCellT tauPrime)
        APrimeSmoothTransition.transitionMesh) 1
      (fun N u omega => Step2Moment.jSnorm
        (Gauss.sample Gauss.Dims.exampleGrow) 0 60 (fun _ => 0) N u omega)
      (fun _ => 0) (Gauss.firstCellT tauPrime)
      APrimeSmoothTransition.transitionMesh delta N k
```

The proof is `rfl`. Thus this is literally the
`piecewiseW(canonicalR, 1, jSnorm, ...)` specified by T571, with
`d = exampleGrow`, `E = 0`, `D = 60`, `s = 0`,
`t = firstCellT tauPrime`, and `mesh = transitionMesh`. There is no moment
order parameter in `weight`.

After T571's module became available in the shared worktree, an independent
scratch check importing both modules also compiled the stronger literal test


The production T573 module deliberately does not import T571, so the field

## Boundary and witnesses

The empty-prefix boundary is exact and unconditional:

```lean
theorem weight_k_zero (tauPrime delta : ℝ) (N : ℕ)
    (omega : Gauss.Ω Gauss.Dims.exampleGrow) :
  weight tauPrime delta N 0 omega = 1
```

This is obtained from the exact prefix-domination field applied to the empty
`prefNet`, together with `weight ≤ 1`; it does not require `N ≥ 1`, an active
index, positivity of `delta`, a moment assumption, or an event.

The actual-weight satisfiability and nonconstancy declarations are

```lean
theorem eventually_weight_zeroSample_eq_one :
  ∀ᶠ N : ℕ in atTop,
    weight 1 (1 / 8) N 2
      (APrimeSmoothTransition.scalarSample exampleGrow 0) = 1

theorem eventually_weight_transitionSample_eq_zero :
  ∀ᶠ N : ℕ in atTop,
    weight 1 (1 / 8) N 2
      (APrimeSmoothTransition.scalarSample exampleGrow
        (2 / Real.sqrt ((APrimeSmoothTransition.transitionMesh N)⁻¹))) = 0

theorem eventually_weight_nonconstant_witness :
  ∀ᶠ N : ℕ in atTop,
    weight 1 (1 / 8) N 2
      (APrimeSmoothTransition.scalarSample exampleGrow 0) = 1 ∧
    weight 1 (1 / 8) N 2
      (APrimeSmoothTransition.scalarSample exampleGrow
        (2 / Real.sqrt ((APrimeSmoothTransition.transitionMesh N)⁻¹))) = 0
```

This is a genuine witness for the actual first-cell `jSnorm`, not the generic
toy witness `APrimeWeight.sat_piecewiseW_nonconstant`. Both values occur at
the same fixed positive prefix `k = 2`, with the same `tauPrime = 1` and
`delta = 1/8`. The weight-one side reuses the public actual zero-sample
plateau. The weight-zero side uses the public transition-sample lower bound
`APrimeSmoothTransition.jSnorm_transition_lower`, the public
`Step2Bootstrap.softW_eq_zero`, and the growing-bandwidth bound. No stochastic
moment, good-event, or slot hypothesis appears.

## Noncircularity

- The four fields are a direct specialization of the already accepted
  `APrimeWeight.jSnorm_piecewiseW_fields`.
- `weight_k_zero` uses only those structural fields.
- The weight-one witness comes from
  `APrimeFirstCellTargetWeightWitness.eventually_exampleGrow_target_weights_one`,
  which was proved before and independently of this module.
- The weight-zero witness uses explicit scalar-sample resolvent estimates and
  deterministic bandwidth growth. It does not use T571, `WeightedMoment`,
  `APrimeHypOn`, `APrimeSlot'`, an `hfamily`, or a closure theorem.
