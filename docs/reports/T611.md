## Delivered theorem and exact quantifiers

The public producer is

```lean
theorem eventually_abs_driftAt_le_rpow
    {E D c : Real} {s t : Nat -> Real}
    (hE : |E| < 2) (hD : 60 <= D)
    (hs0 : forall N, 0 <= s N)
    (hst : forall N, s N <= t N)
    (ht1 : forall N, t N < 1)
    (hc : 0 < c)
    (hreg : Cond272Reg B E s t c) :
    ∀ᶠ N : Nat in Filter.atTop, forall k : Nat,
      k <= cutNetTop s t (APrimeGeneralMovingMesh.targetMesh D) N ->
      let v := cutNetPt s (APrimeGeneralMovingMesh.targetMesh D) N k
      forall u, u ∈ Set.Icc (s N) v ->
      forall a : LoopArg (d.L N) 2, forall omega : Gauss.Ω d,
        |APrimeDriftTimeFamily.driftAt
            d E D N Step2.sigPM a (s N) v u omega|
          <= (N : Real) ^ (D + 8)
```

Thus `d` is definitionally `Gauss.Dims.exampleGrow`, the charge is literally
`Step2.sigPM`, `D` is a real parameter with `60 <= D`, and the eventual
cutoff is chosen only after all deterministic window parameters.  After
that cutoff, `k`, closed running time `u`, the two-loop output label `a`, and
the sample `omega` are universally quantified.

The statement contains no `BoundsCore`, event, support, `delta`, `zeta`,
`tauG`, or moment-order hypothesis.

## `D + 8` ledger

1. `Cond272Reg` is used only through its scale component
   `hreg.2`.  `Gauss.rpow_neg_one_le_etaT_of_scale_ge` yields
   `N^-1 <= etaT E (t N)` eventually.
2. Every active endpoint belongs to `[s_N,t_N]`; monotonicity of `etaT`
   gives `N^-1 <= etaT E v`, hence `etaT(E,v)^-1 <= N`.  The closed
   running-time restriction is used by the window envelopes, so the same
   endpoint inverse controls all source loops at `u`.
3. `Gauss.exists_norm_Kval_le_win B hE 2` supplies one fixed `CK >= 0`,
   independent of `N`, `u`, `v`, charge, output, and sample.
4. For `n = 0`, all Gaussian loops needed by
   `Gauss.norm_driftF_le_crude` are bounded by
   `M := (1 + CK) N^3`; the length-two `Kval` terms are also bounded by
   this `M` (their sharper cost is `CK N^2`).
5. Since `W_N L_N <= N`, the three counted drift blocks are respectively
   bounded by `4`, `32`, and `16` times `W_N L_N M^2`.  Therefore
   `|driftF| <= 52 (1 + CK)^2 N^7` for every sample.
6. `Gauss.norm_Uker_apply_le_ukerRow` propagates the crude source, while
   `APrimeQVGlobalPoly.inv_driftScale_mul_ukerRow_le` bounds the normalized
   row factor by `N^D`.  This gives
   `driftAt <= 52 (1 + CK)^2 N^(D+7)`.
7. `eventually_le_rpow (52 (1 + CK)^2) 1` absorbs the sole fixed constant
   into one final power, giving exactly `N^(D+8)`.

No stochastic profile or favorable-event estimate is used in this ledger.

## Endpoints, `k = 0`, and all-sample scope

The proof uses only `k <= cutNetTop` and
`cutNetPt_mem_netFinset`; it never assumes `1 <= k`.  Consequently the
result includes `k = 0` without a separate branch.  The running-time set is
the literal closed interval `Set.Icc (s N) v`, so both `u = s N` and `u = v`
are included.  The sample quantifier is `forall omega : Gauss.Ω d` after all
geometry and output quantifiers.  No assertion that `driftAt = 0` at `k = 0`
is made or used.

## Nondegenerate witness

T598 witness to exactly the deterministic hypotheses of the T611 theorem:

- `E = 0`, `D = 60`;
- `|E| < 2`, `60 <= D`;
- `0 <= s_N <= t_N < 1` for every `N`;
