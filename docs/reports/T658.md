# T658 — exact Gaussian-coordinate encoding of the T643 center

## Verdict

correction to keep explicit: off-diagonal real and imaginary coordinates have variance
`1/(6W)`, not `1/(3W)`.  No square-root variance normalization is used when encoding the
target matrix.**

For every finite Hermitian matrix

```text
M : Matrix (Gauss.Dims.exampleGrow.Idx N)
           (Gauss.Dims.exampleGrow.Idx N) C,
```

there is one literal sample `omega_M : Gauss.Omega Dims.exampleGrow` whose size-`N`

whose other coordinates are zero.  The actual definitions of `Gauss.Xentry`, `Gauss.crd`,
and `Gauss.usedCoord` then give

```text
Gauss.Xmat Dims.exampleGrow N omega_M = M
```

exactly.  Hermitian symmetry supplies the lower triangle and the diagonal imaginary
coordinate is not read.  A scratch implementation of this generic encoding, including the
exact `Xmat` identity and the zero-variance compatibility theorem, compiled against the
current `Gauss.Generator` and used only `propext`, `Classical.choice`, and `Quot.sound`.

For T643's paired-block ansatz, every nonzero matrix entry is in a same or adjacent physical

imaginary.  Every used coordinate of variance zero has target value zero.  Redundant reverse

## 1. Exact coordinate convention

Fix `d : Gauss.Dims` and `N : Nat`.  A matrix index is

```text
i = (a, alpha) : d.Idx N = ZMod (d.L N) x Fin (d.W N).
```

The actual total order used to choose independent entries is not the product order.  It is

```text
Gauss.idxKey d N (a, alpha) = d.W N * a.val + alpha.
```

Write `i prec j` for strict inequality of these keys.  The full coordinate space is

```text
Gauss.Coord d = Sigma N, d.Idx N x d.Idx N x Bool,
Gauss.Omega d = Gauss.Coord d -> Real,
Gauss.crd d N (i,j,b) = <N,(i,j,b)>.
```

The Bool convention is literal:

```text
true  = real part,
false = imaginary part.
```

At size `N`, `Gauss.usedCoord d N` consists exactly of

```text
(i,j,true), (i,j,false)  when i prec j,
(i,i,true)               on the diagonal.
```

The coordinates `(j,i,b)` with `i prec j` and `(i,i,false)` exist in the infinite product,
but `Xentry` never reads them.

For a Hermitian target `M`, define one full sample by

```text
omega_M <N,(i,j,true)>  = Re M_ij   if i prec j,
omega_M <N,(i,j,false)> = Im M_ij   if i prec j,
omega_M <N,(i,i,true)>  = Re M_ii,
omega_M c               = 0         for every other coordinate c.
```

The last line includes every coordinate at sizes other than `N`, every reverse-ordered pair,
and every diagonal imaginary tag.  Equivalently, and more conveniently in Lean, this is the
finite sum over `usedCoord d N` of coordinate singletons.

The actual `Xentry` table then reads

```text
X_ij = Re M_ij + I Im M_ij = M_ij                         if i prec j,
X_ji = Re M_ij - I Im M_ij = conj(M_ij) = M_ji,
X_ii = Re M_ii = M_ii.
```

The final equality on the diagonal is
`Matrix.IsHermitian.coe_re_apply_self`.  There is no factor `sqrt(2)`, `1/sqrt(2)`,
`sqrt(gvar)`, or `1/sqrt(gvar)` in this map.  The Gaussian variances describe the law of the
coordinate values; `Xentry` inserts the coordinate values directly.

This also agrees with `Gauss.Xmat_eq_sum`: the real coordinate multiplies
`E_ij+E_ji`, the imaginary coordinate multiplies `I E_ij-I E_ji`, and the diagonal real
coordinate multiplies `E_ii`.

## 2. The paired-block target in these coordinates

Let the physical blocks be paired by consecutive representatives, for example
`(0,1),(2,3),...`, leaving the final block unpaired when `L` is odd.  This choice must be made
on representatives before coercing to `ZMod L`; it avoids accidentally using two different
partners for a cyclic endpoint.

For a pair `(b,c)` with `c=b+1`, T643 takes

```text
U = [[cos theta, sin theta],[-sin theta, cos theta]] tensor I_W,
theta = pi/4,
M_pair = U * diag(A_b,A_c) * U^*.
```

Since `cos theta = sin theta = 1/sqrt(2)`, the exact four blocks are

```text
M_bb = (A_b + A_c)/2,
M_cc = (A_b + A_c)/2,
M_bc = (A_c - A_b)/2,
M_cb = (A_c - A_b)/2.
```

The last two displayed block matrices are equal as arrays because `A_c-A_b` is Hermitian;
entrywise the reverse full-matrix entry is still the complex conjugate, as required.  An
unpaired block has `M_bb=A_b`.  Every other physical-block matrix is zero.

Thus, for internal indices `alpha,beta`, the center coordinates are literally

```text
Re ((A_b+A_c)_{alpha,beta}/2),
Im ((A_b+A_c)_{alpha,beta}/2),
Re ((A_c-A_b)_{alpha,beta}/2),
Im ((A_c-A_b)_{alpha,beta}/2),
```

placed only on the `idxKey`-ordered representative of each full matrix entry.  The order may
put either physical block first only in the lower-triangular readback; it does not change the
target matrix because the lower entry is reconstructed by conjugation.

## 3. Exact variance support and scaling

For `i=(a,alpha)` and `j=(b,beta)`, the repository definitions give

```text
Sblk i j = sbKre(a-b)/W,
sbKre(u) = 1/3 if u is in {0,1,-1}, and 0 otherwise.
```

Since `d.W N>0`, this is the exact dichotomy

```text
Sblk i j = 1/(3W)  iff a-b is in {0,1,-1},
Sblk i j = 0       otherwise.
```

The coordinate variance is then

| matrix position | used tag(s) | `Gauss.gvar` |
|---|---|---:|
| `i=j` | real only | `1/(3W)` |
| `i!=j`, same/adjacent physical blocks | real and imaginary | `1/(6W)` |
| physical block difference outside `{0,1,-1}` | any tag | `0` |

The `1/2` in the off-diagonal variance is essential: the two independent real coordinates
then satisfy

```text
E |X_ij|^2 = 1/(6W) + 1/(6W) = 1/(3W) = Sblk i j.
```

T643's statement that each nonzero target entry has `Sblk=1/(3W)>0` is correct, but the
coordinate-level statement needed by a support cylinder is the table above.

The paired target is supported only when `a-b` belongs to `{0,1,-1}`.  Therefore:

1. every nonzero target coordinate has positive variance;
2. if a used coordinate has zero variance, the corresponding matrix entry is zero, so both
   its real and imaginary target values are zero;
3. an unused reverse coordinate or diagonal imaginary coordinate is set to zero regardless
   of its variance;
4. every coordinate at a size other than `N` is set to zero.

Consequently `omega_M c=0` for **every** zero-variance coordinate `c` in the full infinite
sample space, not only for the finite current-size subtype.  This is the exact compatibility
needed before intersecting an effective open box with finite zero-coordinate fixing.

## 6. Continuity and a literal finite cylinder

There is no continuity obstruction once a center with strict margins is actually supplied.
For a fixed `N`, `Xmat d N` reads only the finite set `usedCoord d N` and is continuous in
those real coordinates (`Gauss.continuous_Xmat`).  On the closed time interval `[0,1/2]`, the
spectral parameter has imaginary part at least `1/2`.  Hence the resolvent, every fixed loop,
every centered block trace, and both resolvent charges are jointly continuous in the finite
matrix coordinates and time.

The remaining operations are finite maxima/suprema and positive-denominator divisions:

- loop words and block labels are finite for `n=3,4,6`;
- `GoodEvent` has finitely many matrix-entry labels;
- `jG`, `jS`, the inner smooth maximum, and the target prefix use finite index types;
- `tailT` is strictly positive because of its positive floor;
- the running interval is compact and contains both endpoints.

The distance cutoff inside `jG` is an `if` whose condition depends on time, so one should not
claim that `jG` is jointly continuous in time across a cutoff crossing.  This causes no
cylinder obstruction: the cutoff is independent of `omega`, there are only finitely many
block pairs, and the Green entries have a uniform coordinate modulus on the compact time
interval.  At the center every term selected by the far branch is zero; a sufficiently small
coordinate box makes all such selected terms uniformly small, including at both endpoints.

Therefore a strict inequality holding uniformly at the center has a positive coordinate
radius that preserves it uniformly on the entire closed time interval.  Taking the minimum
over the finitely many rows gives one finite cylinder, on the same sample, preserving norm,
all raw rows, `goodSetFlow`, both centered charges, every block row, and the canonical prefix.
The radius may depend on `N`; no uniform-in-`N` lower bound is needed for positivity.

The precise full-space cylinder must be hybrid:

```text
open inequalities around omega_N on positive-variance used coordinates
intersected with
exact equality omega(c)=0 on zero-variance used coordinates.
```

The second factor is not open, but it is finite, measurable, and has full Gaussian mass in
the Dirac coordinates.  Omitting it would destroy the deterministic inclusion for arbitrary
points of the cylinder, even though the omitted coordinates vanish almost surely.

Continuity alone does not create the missing strict center.  In particular, it cannot replace
the absent proofs of (4.1)–(4.2) or (6.1)–(6.2).
