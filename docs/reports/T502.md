## Result

Added `RBM1D/Gauss/APrimeFirstCellMinkowskiDriftPaid.lean`.

size, every active moving cell `k >= 1` and output `a` satisfies

```text

  <= momNormW(P,w,p,initial)
```

objects, and `v = cutNetPt 0 transitionMesh N k`.
