# T427 — independent proof-grade gate for moving current and early QV rows

## Verdict

**Mathematical gate: pass.**  At the literal endpoint

```text
v = u_k = cutNetPt 0 transitionMesh N k
```

the current rows 4–5 and stored-prefix rows 6–7 have strictly positive
`Cond272Reg.margin` room.  The derivation uses only the two separate scale
facts supplied by `(2.72)/Cond272Reg`,

```text
N^c <= A_v,                    R_v^30 <= A_v,
R_v = eta_0/eta_v,             A_v = W ell_v eta_v,
```

and never replaces them by the false product lower bound rejected in T280d.
The same source/support event can carry T415's moving profile, the dynamic
block cap, the stored-prefix source estimates, and an eventual positive
`k=2` witness.  No dependency cycle is needed.

**Lean gate: the rows are not yet exported.**  There is one precise interface
trap.  The existing `APrimeFullQV.early_T331_profile` cannot be applied to the
actual first-cell `ellSource` with the intended substitution `t^4=x_j`:
its simultaneous premise

```text
ell_j / ellSource <= t^2
```

already fails at `u_j=0`, where `t^2=1` but
`ell_0/ellSource=(2 N^zeta)^(1/5)>1`.  This is not a mathematical obstruction.
The source factor is an `N^zeta` loss and must be retained separately by
starting from `early_normalized_full` (or by proving a slack-aware replacement
for `early_T331_profile`).  Directly invoking the existing packaged theorem
would be invalid.

## 2. Exact current-row calculation at `v=u_k`

Write

```text
x_r = eta_0/eta_r,       R = eta_0/eta_v,
A_r = W ell_r eta_r,     A = A_v.
```

For `0<=r<=v<1`, monotonicity gives

```text
1 <= x_r <= R,     ell_r/ell_0 <= x_r^(1/2),     A <= A_r.
```

On positive support of the actual weight at loss `delta`, T413 gives the
slightly sharper bound

```text
J_r <= C_J N^(2 delta + tau),             tau=delta/16.
```

Since `x_r>=1`, this implies the row form
`J_r<=C_J N^(2 delta+tau)x_r^4`.  The latter is the form substituted below;
it is not the coarse `N^(1/8)` cap internal to T415's standalone theorem.

For the actual T415 source,

```text
ellSource = (2 N^zeta)^(-1/5),
S_r = N^zeta ell_r^3 A_r^(-3),
sqrt(S_r) = N^(zeta/2) ell_r^(3/2) A_r^(-3/2).
```

Before endpoint normalization the four relevant coefficients are, up to
fixed constants and subpolynomial `cNear2/cFar2` losses,

```text
near:   eta_r^(-1) (ell_r/ellSource)^5,
J^2:    eta_r^(-1) J_r^2 ell_r^(3/2) A_r^(-1/2),
J^3:    eta_r^(-1) J_r^3 A_r^(-1),
leak:   W L W^(-60) J_r^3.
```

The exact transport and `driftScale` quotient contribute

```text
((eta_r/eta_v)^2 / R^4)^2 = R^(-4) x_r^(-4)
```

to the squared QV.  Hence the three principal powers are

```text
near: x_r^(-4) * x_r^(5/2)                         = x_r^(-3/2),
J^2:  x_r^(-4) * x_r^8 * x_r^(3/4)               = x_r^(19/4),
J^3:  x_r^(-4) * x_r^12                           = x_r^8.
```

After assigning the source, logarithmic, kernel `xiK^2`, and fixed-constant
losses to an arbitrarily small reserved `N^nu`, the current profile is

```text
C N^nu eta_r^(-1) R^(-4) [
    x_r^(-3/2)
  + N^(4 delta + 2 tau) A^(-1/2) x_r^(19/4)
  + N^(6 delta + 3 tau) A^(-1)   x_r^8 ].
```

The loss assignment is available in the actual files: the common event may
use the T418 source loss `sourceLoss nu <= nu/128`, while
`eventually_coefficients_uniform` and `eventually_xiK_le` accept every
positive exponent.  Thus these losses can be chosen before intersecting the
event and their sum kept below `nu`.

### Leakage accounting

No leakage is deleted.

* `W^(-1)` is absorbed into the near coefficient by
  `W^(-1) <= eta_r^(-1)(ell_r/ellSource)^5`; this remains valid at `r=0`.
* The raw `WL W^(-60) J_r^3` term is paid by the cubic row using the compiled
  dimension inequality `WL W^(-60) <= eta_r^(-1) A_r^(-1)`; T415 supplies
  `WL<=N<=W^2`, and `D=60` is much stronger than the required `D>=4`.
* The propagated `256 exp(3) W^(-60)` term remains additive in `rootProfile`.
  Squaring is handled with `(a+b)^2<=2a^2+2b^2`; `N<=W^2` makes its
  `W^(-120)` square dominate every finite and subpolynomial factor.  It can
  therefore be absorbed eventually without changing either displayed row.

## 3. Exact stored-prefix calculation

For `j<k`, put `x_j=eta_0/eta_{u_j}` and `A_j=W ell_j eta_j`.  Scale
monotonicity gives `A<=A_j`, and `x_j<=R`.  Divide the raw T334 diagonal QV by

```text
T_{u_j,60}^2 * x_j^8 * Theta_N^2,
Theta_N=N^(2 delta).
```

Using `eta_j^(-1)=eta_0^(-1)x_j`, the same three coefficients give

```text
C N^(nu-4 delta) eta_0^(-1) [
    x_j^(-9/2)
  + N^(4 delta + 2 tau) A^(-1/2) x_j^(7/4)
  + N^(6 delta + 3 tau) A^(-1)   x_j^5 ].
```

The powers are exact:

```text
near:  1 + 5/2 - 8       = -9/2,
J^2:   1 + 8 + 3/4 - 8   =  7/4,
J^3:   1 + 12 - 8        =  5.
```

The prefix theorem then takes the square root, multiplies by
`sqrt(u_j)<=1`, and takes the finite maximum.  It introduces no additional
power of `x_j`, `A`, `N`, `W`, `ell`, or `eta`.  The outer cutoff threshold is
exactly the `N^(2 delta)` already used above.

The displayed estimate is mathematically valid with the actual `ellSource`.
Its Lean proof must expose the factor
`(ell_j/ellSource)^5 = 2 N^zeta ell_j^5` directly.  As noted in the verdict,
the current `early_T331_profile` packages this factor into an incompatible
exact `t` parameter and cannot be used verbatim at `u_j=0`.

## 4. `Cond272Reg` margins

For a monomial `N^e R^b A^(-a)`, `Cond272Reg.margin` uses the two lower bounds
separately and requires

```text
(e+nu)/c + b/30 < a.
```

At the largest allowed choices

```text
delta=c/1000,       tau=delta/16,       nu=delta/100,
```

the exact consumed powers and remaining margins are:

| Row | `(e,b,a)` | Consumed | Strict remaining margin |
|---|---|---:|---:|
| Current quadratic | `(4delta+2tau, 19/4, 1/2)` | `97481/600000` | `202519/600000` |
| Current cubic | `(6delta+3tau, 8, 1)` | `327437/1200000` | `872563/1200000` |
| Early quadratic | `(4delta+2tau, 7/4, 1/2)` | `37481/600000` | `262519/600000` |
| Early cubic | `(6delta+3tau, 5, 1)` | `207437/1200000` | `992563/1200000` |

All four margins are strictly positive.  The early calculation deliberately
keeps the conservative reserved `nu` used by T405; no cancellation of that
reserve is needed.  Since `x_r,x_j<=R`, the same endpoint scale `A_v` pays all
current and stored rows.  No assertion of
`N^c R^30<=A_v` occurs.

## 5. Quantifiers, boundary cases, and nonvacuity

### Same event

T418's event is literally T413's

```text
commonEvent tau' (sourceLoss nu) (sourceLoss nu) (delta/16) N.
```

Membership supplies the all-time source event, fixed support
`good tau' (1/100)`, and dynamic support `good tau' (delta/16)` on the same
sample.  It therefore maps to T415's T395 event

```text
jointEvent tau' (sourceLoss nu) N
```

by `commonEvent_to_source` and `commonEvent_to_fixed_support`.  Positivity of
the actual `weight delta` transfers to positivity of `weight (1/100)`, while
the dynamic component gives the sharp `J_r` cap.  T415 is uniform in every
positive `tau'`, so the `tau'` selected once by T413 is reused; no second
existential parameter is introduced.

The resulting order is

```text
exists tau'>0,
  forall 0<delta<=1/100, forall nu>0,
    eventually N,
      forall omega in G_N,
      forall N0 p k m,
      forall r in [0,u_k], forall a,
      ... .
```

The event and eventual `N` tail are chosen before `omega`, the support
indices, the real running time, and the output pair.  Stored rows add
`forall j<k`.  The prefix maximum theorem has the separate deterministic
cardinality premise `hcal` for the chosen smoothing order `m`; it contributes
only the fixed factor `exp(1)` and does not change a row exponent.

### Boundaries

* `r=0`: T415 quantifies over the closed interval `[0,v]`; all scale and
  source terms are positive and finite there, with `x_0=ell_0=1`.  The current
  near row is finite.  The later generator cross term also has the separate
  theorem `crossPart_zero_r0`.
* `u_j=0`: for `j=0`, the prefix pullback contains `sqrt(u_0)=0`, so this
  coordinate contributes exactly zero.  The raw QV divided by its positive
  tail remains finite; no division by `u_j` is used.
* `k=1`: the only stored index is `j=0`, hence the prefix gradient is zero;
  the current moving endpoint is positive and T415 applies.
* `k=0`: T415 and `sqrt_quadVar_prefixMatrix_le_exp_max` correctly exclude
  this case.  It must use the existing empty-prefix branch:
  `prefixMatrix=0`, `weightD_zero_k0`, and `crossPart_zero_k0`; the time
  interval also has `v=s=0`.  One must not assert that the pointwise `qvAt`
  itself vanishes.
* `r=v`: the exact kernel ratio is one and all denominators remain positive
  because `v<=firstCellT<=1/2`.

### Positive witness

`APrimeFirstCellMovingSupport.positivePlateau` supplies eventually a sample

`weight (1/100)=1`, positive endpoint
