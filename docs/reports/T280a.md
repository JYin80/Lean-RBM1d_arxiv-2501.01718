## Results

1. `weightedMoment_of_stepBound_mono` takes a separate `Wp p δ N k` for each moment order and transfers its one-step integral bound to one fixed `W δ N k`. It then invokes `APrimeOneStep.weightedMoment_of_stepBoundPos''`, which handles `p = 0`. The older `Step2Bootstrap.weightedMoment_mono` cannot perform this transfer because its larger weight is itself independent of `p`.
2. `softW_le_widened_pow` proves the pointwise cutoff decision in §9(1): `χ(J̃/θ) ≤ χ(J̃/(2θ))^(2p)` for every `p`, with `θ > 0`. `piecewiseW_le_widenedW` includes the inactive branch where both weights equal one.
3. `le_of_prefixSoftW_ne_zero_of_modulus` propagates from the soft cutoff over `Finset.range k` to every `v ∈ [s_N,u_k]`, using `CutHypTheta.prefix_of_modulus`. Its necessary condition is `1 ≤ k`; at `k = 0` the prefix is empty, and the left-endpoint estimate is an initial-cell obligation. The theorem also requires `k ≤ cutNetTop`, a positive mesh, a modulus bound, a fineness bound, and nonzero weight.
4. `piecewiseW` uses the narrow cutoff when `k ≤ cutNetTop` and `N₀ ≤ N`, and equals one otherwise. `piecewiseW_meas`, `_nonneg`, `_le_one`, and `_dom` give all four `APrimeHypOn` weight fields for all `δ,N,k`, including out-of-range `k` and small `N`.
5. `card_calib_top` and `piecewiseW_dom_canonical` discharge the cardinal premise concretely for `r N = cutNetTop s t mesh N + 1`, `N₀ = 1`, for every `N,k`. This choice works with the actual mesh and first cell, so the four-field witness does not rely on an abstract possibly empty calibration hypothesis. The intended `r ≍ log N` is an available future optimization from an eventual polynomial net-cardinality estimate; the current `r` can be much larger and its effect on downstream derivative budgets has not been checked.
6. `jSnorm_piecewiseW_fields` instantiates all four fields for the actual `jSnorm` functional, using T274's `measurable_jSnorm` and the existing `jS ≥ 1` proof. It needs no extra assumptions on the model parameters.
7. `sat_piecewiseW_on_good` exhibits two points in the same event `{ω : ℝ | 0 ≤ ω}` where the toy prefix weight is respectively one and zero. The toy functional `J_N(u,ω)=max(ω,0)` is measurable and nonnegative; this proves the weight is genuine, not `W ≡ 1`, and that its support is nonempty on a nontrivial event. The witness does not claim to be the Gaussian `jSnorm` model.
