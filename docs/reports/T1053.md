# T1053 — general-moving cross-product integrability

## Verdict: mathematical preflight PASS; exact `hProdInt` proved

For fixed `p : ℕ` with `1 ≤ p`, the actual full-space `2p`-power
integrability producers for `Y` and `jointRate` imply the literal product
integrability required by
`APrimeCrossJointSplit.crossPart_active_le_jointEvent`. The proof uses Hölder
with conjugate exponents

```text
qY = 2p/(2p - 1),   qZ = 2p,
1/qY + 1/qZ = (2p - 1)/(2p) + 1/(2p) = 1.
```

Thus `|Y|^(2p - 1)` is in `L^qY` because its `qY`-power is exactly
`|Y|^(2p)`, and `|jointRate|` is in `L^qZ` by its `2p`-power producer.
The denominator `2p - 1` is positive for every `p ≥ 1`; at `p = 1`, the
exponents are simply `qY = qZ = 2`. The proof uses `AEStronglyMeasurable Y`
from T1043 and the exact joint-rate measurability producer from T618, together
with both integrability fields. This is on the same full Gaussian probability
measure `Gauss.P d`; no event restriction or event intersection is involved.
