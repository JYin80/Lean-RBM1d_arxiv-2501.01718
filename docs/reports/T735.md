## Exact claim and proof check

For every `W k : ℕ` and `π ρ : PermΩ W`, `prefixCell W k π` is the finite set of
permutations `σ` satisfying `σ i = π i` for every `i : Fin W` with `i.val < k`.
T733 proves that two such cells are equal **iff** the defining permutations
agree at every revealed coordinate. The forward implication uses the actual
occupant `ρ ∈ prefixCell W k ρ`; the reverse implication checks membership in
both directions. Thus no arbitrary prescribed prefix, potentially
inconsistent with a permutation, is assumed to have support.

If `π i ≠ ρ i` for one `i.val < k`, membership in both cells would force
`σ i = π i = ρ i`, so `prefixCell_disjoint_of_disagree` is valid. The
`prefixCell_partition` case split covers every pair of cells, while
`prefixCell_iUnion_eq_univ` covers every permutation using its own cell.
T711's `prefixCell_card_pos` ensures every actual cell is nonempty. Repeated
names at the same prefix are correctly treated as one cell.
