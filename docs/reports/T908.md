## Proof and dependency audit

The sole density identity used is accepted `semicircleMeasure_stieltjes_flow` from `SemicircleStieltjesBridge.lean`: for `0<u≤1/2`, the density integral at `q(u)=i(1-u)/√u` equals algebraic `msc(q(u))`. Its proof scales the independently evaluated flow resolvent integral; it does not assume the all-upper-half-plane conclusion. The new module imports the bridge, Mathlib's resolvent transform and identity theorem, and complex convexity. It does not import T898 or any Gaussian/local-law/A-prime/Q0 module.

For `S(z)=∫(x-z)⁻¹ dμ(x)`, the module establishes `S = MeasureTheory.resolventTransform μ` and applies `analyticOn_resolventTransform` off the image of the real support. Every upper-half-plane point is off that image; the set is open. Thus `P(z)=S(z)(S(z)+z)+1` is `AnalyticOnNhd` there. The bridge and accepted `msc_mul` make `P(q(u))=0` for `0<u<1/2`. The curve accumulates at `q(1/2)=i/√2` in the *interior* of the upper half-plane. Nonisolation is proved using accepted `msc_flow_value`: equality `q(u)=q(1/2)` would force `√u=√(1/2)` and then `u=1/2`. The upper half-plane is preconnected by `convex_halfSpace_im_gt`; `AnalyticOnNhd.eqOn_of_preconnected_of_mem_closure` therefore gives `P=0` throughout it. This yields the quadratic identity for the actual integral, rather than assuming it as an input.

For every real `x` and upper-half-plane `z`, `Im (x-z)⁻¹ = z.im / normSq(x-z)>0`. The module proves integrability using `MeasureTheory.integrable_resolvent`, takes imaginary parts under the integral, and uses `semicircleMeasure_univ=1` to show `Im S(z)>0`. Accepted `eq_msc_of_mul_im_pos` then selects the algebraic `msc` root. No analytic regularity of the arbitrary square-root choice used inside `msc` is assumed.
