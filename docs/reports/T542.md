## Result

The new module keeps `delta` explicit and defines

```text
highOrder(delta,p) = max p ceil(20/delta),

targetWeight(tauPrime,delta,p,N,k)
  = the widened first-cell target weight at order p,

canonicalWeight(tauPrime,delta,P,N,k)
  = T467's actual canonical smooth weight at order P.
```

For every `p >= 1`, `highOrder_bounds` proves

```text
1 <= p,
p <= highOrder(delta,p),
1 <= highOrder(delta,p),
```

and `ceil_le_highOrder` records

```text
ceil(20/delta) <= highOrder(delta,p).
```

The pointwise comparison

```text
targetWeight tauPrime delta p N k omega
  <= canonicalWeight tauPrime delta (highOrder delta p) N k omega
```

has coefficient one. Its proof is a direct application of the already
delta-parametric public T520 theorem

```text
APrimeFirstCellCrossOrderWeight.exampleGrow_firstCell_cross_order.
```

No monotonicity in `delta`, truncation, or moment estimate is used.
