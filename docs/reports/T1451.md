## Statement and proof check

`abs_iteratedFDeriv_smoothNormPower_le` quantifies over an arbitrary finite
coordinate type, even `q` with `max 2 (4 * M) ≤ q`, `1 ≤ k ≤ M`, every nonzero
`x : ι → ℝ`, and arbitrary directions `v : Fin k → ι → ℝ`. It covers both
`s = 1` and `s = -1` and proves

```text
|D^k smoothNormPower(q,s)(x)[v]| ≤
  C_k q^(k-1) qNorm(q,x)^(s-k) ∏ j, qNorm(q,v_j),
C_k = ∑ c : OrderedFinpartition k, (c.length)!,
smoothNormPower(q,s)(x) = powerSum(q,x)^(s/q).
```

`C_k` is explicit and depends only on `k`; neither the theorem nor its
constant uses coordinate cardinality, a nonzero individual coordinate
condition, or positive direction norms. Evenness identifies `powerSum q x`
with `qNorm q x ^ q`; nonzero `x` makes this power sum strictly positive.
`smoothNormPower_contDiffAt` proves smoothness of every finite order there,
including at vectors with zero coordinates.

I checked the ordered-partition chain-rule expansion against the source:
each block uses the accepted T1434 inner bound, block sizes sum to `k`, and
the block direction products reindex to the product over `Fin k`. The scalar
coefficient satisfies `|(s/q)_p| ≤ p!/q` for both signs; multiplying the
inner bounds gives `q^k`, hence `q^(k-1)`. The powers of `qNorm q x` combine
as `(p q - k) + (s - p q) = s - k`. The finite sum yields exactly `C_k`.
The source imports accepted T1434 and Mathlib calculus, with no T1430 import,
conditional derivative premise, frozen-signature edit, `sorry`, `admit`, or
declared axiom.

`fin2_smoothNormPower_first_derivative_witness` uses the same `Fin 2` vector
`x = v = (1,0)` for each sign. Its proof computes the derivative as `s`, so
it is nonzero for `s = ±1` while the second coordinate is zero. This is a
nondegenerate deterministic witness, not a stochastic same-event claim.
