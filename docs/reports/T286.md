## Minimum honest continuation

The existing estimates support a widened block level `J≤1+N^τ(A·cWt·Λ+2)` on the joint (4.2)/good event and soft-weight support, with `A=9 exp(√3)`. To use T280g's `eeL6_near_remainder` and `sqrt_evolvedQV_le_endpoint'`, one may retain the exact block fields from `APrimeJG` and prove a polynomial cap `J≤N^k` from this widened level, then recompute the far-rate budget with that loss. An unchanged `cWt·Λ` cap would require an independently proved smaller prior level for `jS` (roughly `N^{-τ}Λ` with the constant gap), which the current weight support does not provide. The common calibrated-support nonemptiness also needs proof; it cannot be inferred from the two existing separate witnesses.

I did not replace `jG` by `EarlyQVRateEv.jStar`, and did not relabel the missing level as a new hypothesis. The block fields and endpoint theorem were audited but intentionally not composed across the false level implication.
