## Public result and proof structure

`RBM.Gauss.multiaffineInterpolation` is the standard product-weight interpolation over the canonical finite coordinate order. Its recursive step is

```lean
(1 - t i) • A_lower + t i • A_upper
```

The private `multiaffineInterpOn_perm` proof shows that changing the order of a nodup enumeration does not change the interpolant. This lets the proof put an arbitrary selected set `J` first and its complement second, while keeping one fixed interpolation in the public theorem.

For every finite coordinate type, every vertex family `a : (ι → Bool) → V`, every `J : Finset ι` (including empty and full), and every `t`, the main statement is:

```lean
cubeMixedPartial_shiftedFaces
  (J : Finset ι) (a : (ι → Bool) → V) (t : ι → ℝ) :
  cubeMixedPartial J.toList (fun x => multiaffineInterpolation a x) t =
    weightedTermsValue
      (multiaffineTerms (Finset.univ \ J).toList
        (shiftedDifferenceList J.toList a) (fun _ => false) t)
```

The right side is a finite list sum that retains repeated terms. At each complementary coordinate the list branches into its zero and one choices, multiplying the previous coefficient by `1 - t i` or `t i`. `multiaffineTerms_length` proves there are `2 ^ |(Finset.univ \ J).toList|` branches. Thus the list enumerates all complementary bit assignments; each value is the corresponding iterated `J`-face difference, based at false on `J`.

The weights have total mass one by `cubeMixedPartial_shiftedFaces_weights_sum`. Under `t i ∈ [0,1]` on the complement, every weight is nonnegative by `cubeMixedPartial_shiftedFaces_weights_nonneg_on_unitCube`. The norm conclusion `cubeMixedPartial_shiftedFaces_norm_le_on_unitCube` assumes a bound on every base with the selected bits false and derives the mixed-derivative bound from that same uniform face bound. This ranges exactly over all complementary shifts.

The theorem is generic in a finite coordinate type, so specializing `ι := Fin r` proves the requested statement for every finite dimension. The main theorem also covers the empty subset. Separate statements make the zero-order identity, the full-coordinate single-face case, the singleton case, and the absence of a nonempty subset in `Fin 0` explicit.
