`APrimeNormalizedGenerator.normalizedGeneratorBridge` for the actual Gaussian
flow under `|E| < 2`, `0 ≤ s ≤ r ≤ v < 1`, and `1 ≤ p`. This discharges the

The proof applies `Gauss.timeD1_add_genMomentPt_le_driftF_flow` to the raw

moment function is `k^(2p)` times the raw moment function. The new
`timeD1_const_smul` and `genPt_const_smul` lemmas make the left-hand side
exactly `k^(2p)` times the raw generator. The drift coordinate is `k` times
the raw `Uker∘driftF` norm; `flowY_coordAt` gives the same factor for the
evolved coordinate. The new `qvAt_eq_const_smul` proves that **the actual
evolved** `qvAt` is `k²` times the raw `Gauss.quadVar` of the same
`ukerObsT`. Thus each right-hand term has the same `k^(2p)` factor, with
no additional power of `N`. The `genPt` conversion is for the actual
moment function (`genPt_momentFun` definition), not a separately chosen
generator or quadratic-variation field.
