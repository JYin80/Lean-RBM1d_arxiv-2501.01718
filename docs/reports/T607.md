## 4. Literal proposed API

The following is a theorem schema, not compiled code.  Names are chosen to
make the raw/evolved distinction explicit.  All displayed normalizations are
part of the claim and should not be weakened during implementation.

### 4.1 Deterministic rates

```lean
noncomputable def transitionBlockCap
    (E : Real) (s : Nat -> Real) (tauG delta : Real)
    (N : Nat) (u : Real) : Real :=
  1 + (N : Real)^tauG *
    (9 * Real.exp (Real.sqrt 3) *
      (((16 * (Real.exp 1)^2 + 1) * (N : Real)^(2 * delta)) *
        Step2Moment.ratR E s N u ^ 4) + 2)

noncomputable def transitionRawCoordRate
    (E : Real) (s : Nat -> Real)
    (zetaSrc tauG delta : Real) (N : Nat) (u : Real) : Real :=
  APrimeGeneralMovingQVAbsorption.nearSourceRate E s zetaSrc N u +
    2 * (B.W N : Real)⁻¹ +
    APrimeGeneralMovingQVAbsorption.absorbedFarRate E N u
      (transitionBlockCap E s tauG delta N u)

noncomputable def storedRootRate
    (E : Real) (s : Nat -> Real)
    (zetaSrc tauG delta : Real) (N : Nat) (u : Real) : Real :=
  (Step2Moment.ratR E s N u ^ 4)⁻¹ *
    Real.sqrt (transitionRawCoordRate E s zetaSrc tauG delta N u) /
    APrimeSmoothWeightActual.threshold delta N

noncomputable def transitionPrefixGradientRate
    (E D : Real) (s t : Nat -> Real)
    (zetaSrc tauG delta : Real) (N k : Nat) : Real :=
  if hk : 0 < k then
    Real.exp 1 *
      (Finset.range k).sup' ⟨0, Finset.mem_range.mpr hk⟩ (fun j =>
        Real.sqrt
            (cutNetPt s (APrimeGeneralMovingMesh.targetMesh D) N j) *
          storedRootRate E s zetaSrc tauG delta N
            (cutNetPt s (APrimeGeneralMovingMesh.targetMesh D) N j))
  else 0
```

Keeping `threshold delta N` literal is preferable to expanding it.  It
guarantees exact agreement with `prefixGradient` and avoids a gratuitous
power-normalization proof.

## 6. Proof obligations and exact route

### 6.1 Transition cap and source conversion

For `u ∈ [s_N,u_k]`, T597 gives

```text
jSnorm(u) ≤ (16 e² + 1) N^(2 delta).
```

The common event gives

```text
jG(u) ≤ 1 + N^tauG (9 exp(sqrt 3) jS(u) + 2).
```

Using the literal identity

```text
jS(u) = jSnorm(u) * ratR(E,s,N,u)^4
```

yields `jG(u) ≤ transitionBlockCap(...)`.  No enlarged support or later
endpoint is introduced.

A new analogue of T584's block-cap lemma proves the transition cap is at most
`N` eventually.  The exponent room is exactly

```text
tauG + 2 * delta + 2/15 < 1.
```

Changing the numerical coefficient from `4e+2` to `16e²+1` affects only the
eventual constant and does not change the exponent condition.

### 6.2 Far absorption

T590's `eventually_quadratic_source_comparison` has
`generalMovingBlockCap` on its right side.  It may be reused because the
deterministic comparison

```text
generalMovingBlockCap E s tauG delta N u
  ≤ transitionBlockCap E s tauG delta N u
```

follows from `4e+2 ≤ 16e²+1`.  Multiplication by the nonnegative scale factor
then gives the `hquad` expected by
`diagFarRate_source_le_absorbed`, now with `J = transitionBlockCap ...`.
Before that absorption, use
`APrimeJGWidened.diagFarRate_mono` with
`actual jG(u) ≤ transitionBlockCap(u)` to replace the literal far rate in
`early_normalized_full` by the capped far rate.  Positivity gives both
`0 ≤ actual jG(u)` and `1 ≤ transitionBlockCap(u)`.  This scalar chain is the
only intended use of T590; no theorem whose conclusion contains `qvAt` enters.

### 6.3 Raw-QV/coordinate bridge

`early_normalized_full` is applied at `u = u_j` with

```text
x     := ratR E s N u_j
Theta := APrimeSmoothWeightActual.threshold delta N
J     := actual jG at u_j
Smax  := APrimeGeneralMovingRawSources.sourceC4 E s zetaSrc N u_j.
```

After the near identity and monotone far replacement, its right side is
`transitionRawCoordRate / (ratR^8 * threshold^2)`.  Nonnegativity and positivity
of `ratR`, `tT`, and `threshold` permit taking square roots and rearranging to
the row in §4.2.

The near identity used here is T590's
`diagNearRate_source_eq`; it inserts T579's exact `sourceEll` without changing
the factor `4 N^zetaSrc eta(u)^(-1) cNear2(W,ell(u))
(ell(u)/ell(s_N))^5`.

The exact bridge from `lkFun` to `coordFun` should copy the established proof
shape in `APrimeFirstCellPrefixGoodRows.quadVar_coordFun_eq_stored`:

1. rewrite `Hflow` as real scalar multiplication of `Xmat`;
2. remove the coordinate's deterministic constant using `quadVar_sub_const`;
3. use `EarlyQVRate.quadVar_lkFun_eq_quadVar_loopObs`;
4. keep the fixed `sigPM` charge and arbitrary coordinate `a`.

Only the endpoint assumptions change; the algebra is not first-cell-specific.

## 7. Power and normalization ledger

The proposed bound is exactly

```text
 exp(1) / threshold(delta,N)
   * max_{0 ≤ j < k} [ sqrt(u_j) * ratR(u_j)^(-4)
       * sqrt(
           4 N^zetaSrc eta(u_j)^(-1)
             cNear2(W,ell(u_j)) (ell(u_j)/ell(s_N))^5
           + 2 W^(-1)
           + 1200 eta(u_j)^(-1) A(u_j)^(-1/3)
               transitionBlockCap(u_j)^3 ) ].
```

Here

```text
threshold(delta,N) = 8 exp(1)^2 N^(2 delta),

transitionBlockCap(u) =
  1 + N^tauG
    (9 exp(sqrt 3)
      ((16 exp(1)^2 + 1) N^(2 delta) ratR(u)^4) + 2).
```

Thus the outer coefficient may be rewritten as
`1 / (8 exp(1)) * N^(-2 delta)`, but the public theorem should retain the
literal threshold.  The leading pure-cap monomial, if expanded only for
asymptotic inspection, behaves as

```text
N^(3 tauG / 2 + delta) * ratR(u_j)^2
  * sqrt(eta(u_j)^(-1) A(u_j)^(-1/3)),
```

times `sqrt(u_j)`.  This heuristic is not a replacement for the additive,
literal cap in the theorem.

The following factors are deliberately absent:

- no endpoint `ratR(v_k)^(-2)`;
- no evolved source factor `ratR(u_j)^(-2)` in place of the raw
  `ratR(u_j)^(-4)`;
- no `6 ellStar(v_k)` indicator;
- no propagated `256 exp(3) W^(-D)` endpoint leakage;
- no buffer `xi` and no widened-support loss.

Those belong to the evolved formula (5.42)/T590–T606 path, not to the raw
stored coordinate-QV needed by T333.  The raw spatial `W^(-D)` leakage is
already absorbed in the coefficient `1200`; the repaired `2 W^(-1)` term
remains explicit.

## 8. Boundary plan

- **`k = 0`.**  The selected theorem is stated only for `1 ≤ k`.  Separately,
  the transition is empty because `prefixSample = 0` and the threshold is
  positive; the cross term also has its established zero branch.  No finite
  supremum is constructed.
- **`k ≥ 1`.**  T333 requires every `j < k`.  This includes `j = 0`.
- **First stored time.**  `u_0 = s_N`.  For an arbitrary moving window,
  `s_N` may be positive, so `sqrt(u_0)` need not vanish.  T579 supplies the
  source event there and T597 supplies the cap there.  The row must be proved,
  not erased with `sqrt(0)=0`.
- **`k = 1`.**  This is generally nonzero when `s_N > 0`; the first-cell
  zero argument applies only when `s_N = 0`.
- **Last active cell.**  The hypotheses allow
  `k = cutNetTop ...`; both T579 and T597 include the closed right endpoint.
- **Cross zero branches.**  The existing `p = 0`, inactive, `k = 0`, and
  `r = 0` branches remain outside the favorable-prefix theorem.
- **Support orientation.**  The proof uses
  `omega ∈ commonEvent ∩ transition` in that direction.  It does not reverse
  support inclusions or substitute an enlarged event.

## 10. Nondegeneracy

The scalar/window/regularity assumptions are jointly satisfiable by the
explicit positive-window witnesses already used for T590/T597.  T597 also
proves an eventual common-event resident and an active cell at an explicit
parameter point.

It deliberately does **not** prove that this resident lies in the strict
smooth transition.  Accordingly, §4.3 is an honest conditional localization
theorem under the same accepted convention as T597, but it is not evidence
that `commonEvent ∩ transition` is inhabited.  If the project requires a
literal resident for every conditional event theorem, the exact smallest
additional input is:

```lean
∃ᶠ/∀ᶠ N, ∃ k omega,
  1 ≤ k ∧ k ≤ cutNetTop ... ∧
  omega ∈ commonEvent ... N ∩ transition ... N k canonicalM.
```

No stronger joint nonvacuity claim is currently justified.

## 11. Paper check

- Formula **(5.24)** is the BDG moment estimate for the stochastic integral
  involving `U ∘ E^(M)`.  It is not a prefix-gradient estimate and does not
  replace the raw stored-coordinate QV row above.
- Formula **(5.42)** is an evolved QV estimate with the propagator
  `U_{u,t}`, endpoint normalization, a near indicator, and the weakened
  `A^(-1/3)` far factor.  It motivates the T590–T606 current-QV branch.
  Setting the propagator heuristically to the identity motivates a raw source
  estimate, but (5.42) itself does not prove the T333 input and must not be
  substituted for it.

The formal split is therefore faithful to the paper: (5.24) belongs to the
moment/BDG layer; (5.42) belongs to the evolved current-QV layer; the prefix
weight derivative needs an earlier same-time raw QV layer.
