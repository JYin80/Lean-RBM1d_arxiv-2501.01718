## Mathematical and Lean checks

- In `PermutationPrefixFiltrationCore.lean`, `prefixSigma W k` is `MeasurableSpace.generateFrom (prefixCylinders W k)`, where every generator has the form `{ρ | ρ i = v}` with `i.val < k`. The `prefixCell W k π` definition filters all permutations by precisely the conjunction `∀ i : Fin W, i.val < k → ρ i = π i`.
- In `PermutationPrefixCellMeasurable.lean`, `measurableSet_prefixCell` identifies the *entire* event `{ρ | ρ ∈ prefixCell W k π}` with `⋂ i : {i : Fin W // i.val < k}, {ρ | ρ i.1 = π i.1}`. That subtype is finite. Each factor is an allowed generator, using `v = π i.1`, and `MeasurableSet.iInter` closes the intersection. Thus the proof uses only coordinates strictly below `k`; it does not infer measurability merely from the ambient discrete measurable space.
- `prefixCell_event_eq_univ_of_zero` proves the `k=0` event is `Set.univ`. `prefixCell_event_eq_singleton_of_width_le` proves the event is `{π}` whenever `W ≤ k`; extensionality of permutations from equality at every coordinate is supplied by the accepted T711 theorem.
- `prefixCell_event_zero_width` uses subsingleton elimination on `PermΩ 0` and identifies the event with the singleton of `Equiv.refl (Fin 0)` for every `k`. The sample type has one permutation, so this singleton is also the whole space; no empty-support conclusion is made.
- `prefixCell_event_two_support_witness` inherits T711's explicit `W=2, k=0` identity/swap witness. Both permutations lie in the same cell and `swap ≠ identity`. This demonstrates genuine two-point support rather than a vacuous existence claim.
- The theorem concerns a cell indexed by an actual `π`. It asserts no realization of an arbitrary prescribed prefix, no conditional law, and no `N`, `W`, or time scaling, first-cell/shared event, or P2 result. In the specified paper PDF, (2.3) and (2.4) are Green-function local laws; this theorem is finite-filtration infrastructure downstream of those statements, not a proof of either local law.
