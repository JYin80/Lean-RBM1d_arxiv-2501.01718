# T837 — two successive images, conditional on the permutation prefix

## Result and scope

`RBM1D/Gauss/PermutationTwoNextImagesCondExp.lean` proves `uniformPerm_two_successiveImages_condExp` for every width `W`, valid adjacent `k,j : Fin W` with `j.val = k.val + 1`, and every `v,w : Fin W`. Under `uniformPerm W`, the real indicator of `ρ k = v ∧ ρ j = w` has conditional expectation given the generated `prefixSigma W k.val` equal almost everywhere to `1 / ((W-k.val)(W-k.val-1))` when `v ≠ w` and both images are unused before `k`, and zero otherwise. It asserts equality only almost everywhere for the conditional-expectation representative.

On each actual prefix cell, the proof equates the two real integrals. For a valid pair, it converts T822's ENNReal quotient to a real identity using the positive finite mass of the actual cell. For equal or previously used images, the ordered event is empty inside that cell. T804 makes the right-hand side constant on cells; T807 gives prefix measurability; T792 identifies the atoms; the finite disjoint-cell decomposition and the set-integral uniqueness theorem used by T813 yield the a.e. statement. No one-image conditional expectations are multiplied, and the target law is not assumed.

## Boundary and nondegeneracy

The module proves that `W=0` has no index and `W=1` has no adjacent pair. Valid adjacency forces `W-k.val ≥ 2` and `W-k.val-1 ≥ 1`, and the two real denominator factors are explicitly proved positive. At `W=2,k=0,j=1`, both ordered distinct pairs have conditional probability `1/2`, while an equal pair has zero. A separate witness proves the `(0,1)` event contains the identity, excludes the transposition, and has positive mass in a positive actual prefix cell. The last eligible pair has the same conditional half-law for either valid ordering. There are no new hypotheses requiring a separate satisfiability witness.
