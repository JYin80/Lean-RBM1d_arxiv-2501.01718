## Formal result

`eventually_integral_positiveTimeCrossBudget_le_early_prefix_allOrders_microscopic`
fixes `p ≥ 1` before the eventual cutoff. Eventually in `N`, it holds for
every `k ≤ cutNetTop ... N` with `k ≤ N^D`, and every `a : LoopArg ...`, with
`v = cutNetPt ... k`:

```text
∫_(s N)^v positiveTimeCrossBudget E D (deltaWeight δ) s t N k p a
  ≤ (15*p/2) * K * N^(13δ/640 - 3D/2 - 8) * ratR(E,s,N,v)^(-2)
```

integrand is the literal full positive-time T1089 cross budget, with the T995

`jointRate_k_zero` result; for `k ≥ 1` it proves the target bound from the
