## Exact compiled propositions

The scratch definitions (in `RBM.Gauss`) are

```lean
private noncomputable def fourierNorm (W : ℕ) : ℂ :=
  ((Real.sqrt (W : ℝ) : ℂ))⁻¹

private noncomputable def fourierMatrix (W : ℕ) : Matrix (Fin W) (Fin W) ℂ :=
  fun j a => fourierNorm W * permutationFourierCharacter W a j
```

For `1 ≤ W`, it proves:

```lean
fourierMatrix_conjTranspose_mul (W : ℕ) (hW : 1 ≤ W) :
  (fourierMatrix W)ᴴ * fourierMatrix W = 1

fourierMatrix_mul_conjTranspose (W : ℕ) (hW : 1 ≤ W) :
  fourierMatrix W * (fourierMatrix W)ᴴ = 1

char_product (W : ℕ) [NeZero W] (a b j : Fin W) :
  permutationFourierCharacter W b j *
    star (permutationFourierCharacter W a j) =
      permutationFourierCharacter W (b - a) j

fourierMatrix_diagonal_entry (W : ℕ) (hW : 1 ≤ W)
    (v : Fin W → ℂ) (a b : Fin W) :
  ((fourierMatrix W)ᴴ * Matrix.diagonal v * fourierMatrix W) a b =
    (W : ℂ)⁻¹ * ∑ j : Fin W,
      permutationFourierCharacter W (b - a) j * v j
```

Here `star` on `ℂ` is complex conjugation. The orientation is exactly
**`b-a`** for row `a`, column `b` of `Fᴴ diag(v) F`; it was not inferred from
Mathlib's negative-phase DFT.

## Proof route and APIs verified

Required imports were `RBM1D.Gauss.PermutationFourierCharacter`,
`Mathlib.Analysis.Fourier.ZMod`, `Mathlib.LinearAlgebra.UnitaryGroup`, and
`RBM1D.Defs.SemicircleQuantileReflection` (the last only for the quantile
witness). The proof first identifies the project's positive-phase character
with `ZMod.stdAddChar ((q.val * j.val : ℕ) : ZMod W)` using
`ZMod.stdAddChar_coe`. Conjugation is handled by
`AddChar.map_neg_eq_inv`, `ZMod.stdAddChar_apply`, `Circle.norm_coe`, and
`Complex.inv_eq_conj`; `Fin.val_sub` and `ZMod` cast simplification give the
modular difference. This avoids an unproved identification with `ZMod.dft`.

The project theorem `permutationFourierCharacter_sum_zero` supplies the
nonzero-mode sum when `2 ≤ W`; if `W=1`, every `q : Fin W` has `q.val=0`.
The zero-mode sum is `W`. The scalar identity
`star (fourierNorm W) * fourierNorm W = (W : ℂ)⁻¹` follows from
`Real.sq_sqrt` and complex conjugation of a real scalar. Entrywise
`Matrix.mul_apply` then gives `FᴴF=1`. The square-matrix theorem
`mul_eq_one_comm` gives `FFᴴ=1` from this left inverse. Thus both sides
are established, with no one-sided inverse assumption.

The scratch instantiates both identities explicitly at `W=1` and `W=2`.
It also uses `semicircleQuantileReflection_witness_two.1` to prove for the
actual midpoint quantiles `λ₀<λ₁` that

```text
(F₂ᴴ diag(λ₀,λ₁) F₂)(0,1) = (λ₀-λ₁)/2 ≠ 0.
```

This witnesses a genuinely nonconstant block. It uses the actual quantile
producer, rather than a synthetic bounded table. Every displayed scratch
