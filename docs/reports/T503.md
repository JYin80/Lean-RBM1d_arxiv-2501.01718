```text

```

sixth of the target power to each term using
`SumZeroDyn.eventually_const_mul_rpow_le`. This preserves the required
quantifier order: `p`, hence `C_p`, is fixed before the eventual
threshold in `N`.

```text

```

```text

```

No product-scale strengthening or extra `N`, `W`, or time factor is
used.
