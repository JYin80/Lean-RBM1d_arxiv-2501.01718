## Proved statement

The public theorem `centeredVariance_wirtProduct_contraction_eq` assumes a finite label set `s`, a Hermitian matrix `H`, and only `∀ i ∈ s, (z i).im ≠ 0`. It proves

```lean
(∑ a, ∑ b, (centeredVarianceEntry d N a b : ℂ) *
  Gauss.wirtSecond d N
    (fun K => ((∏ i ∈ s, (stieltjes K (z i)).im : ℝ) : ℂ)) H a b)
=
(∑ i ∈ s,
  ((∏ j ∈ s.erase i, (stieltjes H (z j)).im : ℝ) : ℂ) *
    ((2 * (paperK1Contraction N H (z i) true true).im : ℝ) : ℂ))
+ ∑ i ∈ s, ∑ j ∈ s.erase i,
  ((∏ k ∈ (s.erase i).erase j, (stieltjes H (z k)).im : ℝ) : ℂ) *
    (-(1 / 4 : ℂ) *
      (paperK2Contraction N H (z i) (z j) true true
       - paperK2Contraction N H (z i) (z j) true false
       - paperK2Contraction N H (z i) (z j) false true
       + paperK2Contraction N H (z i) (z j) false false))
```

This preserves the ordered factor labels in the cross term. Repeated spectral parameters are allowed, and no positivity, `N ≠ 0`, loss exponent, event, or time parameter is assumed. Empty and singleton boundary-case theorems are also included.

## Proof route and mathematical source

The proof reuses the coordinate Hessian expansion `wirtSecond_stieltjesImProduct_expansion` from T1409 and the one-factor and first-derivative contraction identities from T1426. It formalizes the finite-product second-derivative decomposition into a single-factor second derivative and ordered two-factor first derivatives. For off-diagonal matrix coordinates, it proves the `1/4` coordinate normalization and then uses the covariance symmetry under simultaneous index swap to identify the full contraction with the ordered Wirtinger product. Finally it reindexes the finite sums and applies the T1426 contractions, yielding the `-1/4` four-sign `paperK2Contraction` combination.

This formalizes the pointwise deterministic product-Hessian/contraction algebra underlying manuscript formulas (2.22)–(2.24), under the stated nonzero-imaginary-part domain for the resolvents. It does not formalize the further expectation/time step in (2.25), the absolute-value kernel bound, or a Brownian-path claim. The manuscript source is `paper/250520-YinJun-v2.pdf`; the assigned mathematical preflight and same-event witness are recorded in T1425 §§3–6.
