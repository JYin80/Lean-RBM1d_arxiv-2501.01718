## Proof

T438 supplies the actual uncut current quadratic variation at the same
moving endpoint and on the same `sharpCommonEvent`:

```text
qvAt <= 147456 * N^alpha * eta_r^(-1) * R_v^(-4)
          * currentBracket N v r.
```

T461 supplies, with one threshold uniform in `k` and `r`,

```text
currentBracket N v r <= 3.
```

All outside factors are nonnegative.  The proof then takes the real square
root using the exact identities

```text
sqrt(147456) = 384,
(sqrt 3)^2   = 3,
(N^(alpha/2))^2       = N^alpha,
(eta_r^(-1/2))^2      = eta_r^(-1),
(R_v^(-2))^2          = R_v^(-4).
```

Both far rows remain inside `currentBracket` until T461 bounds the complete
three-row sum.
