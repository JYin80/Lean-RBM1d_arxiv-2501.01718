# T842 — deterministic next-image increment bound

## Scope and result

Added `RBM1D/Gauss/PermutationNextImageIncrementBound.lean`. The main theorem
`permutation_nextImage_increment_le` proves the requested pointwise statement
for every width, valid reveal index, actual permutation, real-valued function,
and `C ≥ 0` with `|f v| ≤ C` for all `v`:

```lean
|f (π k) - (∑ v ∈ unusedImages W k π, f v) / ((W - k.val : ℕ) : ℝ)| ≤ 2 * C
```

The proof bounds the finite sum by the number of unused images times `C`,
rewrites that count with T785's `unusedImages_card`, and uses the positive
denominator supplied by T833. The triangle inequality then gives `2*C`. It
uses the actual unused set associated with `π`; no conditional expectation or
T840 centered theorem is imported.

## Boundary checks and nonvacuity

`permutation_nextImage_increment_last_eq_zero` proves that the centered
increment vanishes at the last valid reveal. Its width-one specialization is
`permutation_nextImage_increment_one_eq_zero`. Width zero has no valid reveal
index by the imported T785 theorem `no_next_index_zero`.

`permutation_nextImage_increment_two_witness` takes `f(0)=0`, `f(1)=1` and
exhibits values `-1/2` and `1/2` on the identity and transposition samples at
`W=2,k=0`. Each sample lies in its positive-mass singleton actual-prefix atom
at prefix length one. Thus the pointwise conclusion has a nonconstant,
nonzero instance on both positive atoms.

No assumptions beyond the theorem parameters are introduced. There is no
paper delta: this is a finite deterministic auxiliary bound, not a claim about
paper (2.3)–(2.4), a Gaussian tail estimate, or a chain closure.
