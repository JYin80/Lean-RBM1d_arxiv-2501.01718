## Loss schedule and theorem outputs

For each fixed `p ≥ 1`, the free parameter is `λ > 0` with
`λ ≤ min (1/10000) (c/10000)`. The schedule is

`zetaSrc = zetaCtr = tauG = λ/1000`, `deltaWeight = xi = λ`,
`deltaCap = 2λ`.

`free_loss_rooms` proves the required strict positivity, the equality
`deltaWeight + xi = deltaCap`, the source-to-weight and source-to-cap room
conditions, the `c/20` bounds, and both transition room inequalities. The
pointwise result keeps the literal profile and exact all-order constants:

```text
normGoodCrossBudget(u)
  ≤ (15p/4) crossProfile(u) + (15p/8) N⁻¹ / √u.
```

It is uniform eventually in `N`, over every active target cell `k`, every
output, and positive `u` in the closed cell. The order is `p` first, then
`∀ᶠ N`; `p = 0` is excluded by `1 ≤ p`. The `k = 0` branch is handled
separately using the exact zero-rate identity.

Integration yields `(15p/4)` times the integral of the literal `crossProfile`
plus `(15p/4) N⁻¹ (√v − √(s N))`. The full positive-time cross budget then has
the same profile integral and **two separately retained** terms
`(15p/4) N⁻¹ (√v − √(s N))`: the norm-good complement payment and the distinct
norm-bad integral reduction payment. Integrability at `s N = 0` is proved, and
the endpoint `u = 0` is included in the interval comparison.
