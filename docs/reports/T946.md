# T946 — literal positive-phase finite Fourier matrix

## Result

The new module `RBM1D/Gauss/PermutationFourierUnitaryMatrix.lean` publicly
defines

```lean
permutationFourierMatrix W j a =
  ((Real.sqrt (W : ℝ) : ℂ))⁻¹ * permutationFourierCharacter W a j
```

and proves, for every `1 ≤ W`, both `Fᴴ * F = 1` and `F * Fᴴ = 1`.
The character identity is exactly

```lean
permutationFourierCharacter W b j *
  star (permutationFourierCharacter W a j) =
    permutationFourierCharacter W (b - a) j.
```

Thus the public entry theorem for any `v : Fin W → ℂ` is

```lean
(Fᴴ * Matrix.diagonal v * F) a b =
  (W : ℂ)⁻¹ * ∑ j, permutationFourierCharacter W (b - a) j * v j.
```

The phase and `Fin W` subtraction are literal: there is no invocation of
Mathlib's negative-phase DFT as if it were definitionally equal to the
project character. The proof identifies the character with
`ZMod.stdAddChar`, proves the conjugate and modular subtraction bridges,
then uses the accepted nonzero-character sum. The right inverse follows
from the left inverse by `mul_eq_one_comm` for square matrices.

## Boundary and satisfiability checks

- `permutationFourierMatrix_one_check` verifies both identities at `W=1`.
- `permutationFourierMatrix_quantile_one_check` uses the actual odd-center
  semicircle quantile to verify that the one-cell block is zero.
- `permutationFourierMatrix_two_check` verifies both at `W=2`.
- `permutationFourierMatrix_quantile_two_offdiag` uses the **actual**
  semicircle midpoint quantiles and their strict inequality to show
  `(F₂ᴴ diag(λ₀,λ₁) F₂)(0,1) = (λ₀-λ₁)/2 ≠ 0`.
  This is a nonconstant, nonvacuous matrix witness.

The only width hypothesis in the general matrix results is `1 ≤ W`,
exhibited by both concrete widths. No new stochastic or Gaussian premise
is introduced. There is no literal paper-delta entry because these are
finite deterministic auxiliaries, not restatements of a paper theorem.
