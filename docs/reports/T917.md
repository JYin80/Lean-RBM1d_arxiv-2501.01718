# T917 — normalized Fourier sum flow-time modulus

## Result

**PASS within the stated finite deterministic scope.** The new module
`RBM1D/Gauss/PermutationFourierFlowTimeModulus.lean` proves
`norm_permutationFourierSum_flow_time_modulus`: for `W ≥ 1`, pointwise
`|lam j| ≤ 2`, `‖χ j‖ ≤ 1`, any `π : Equiv.Perm (Fin W)`, and
`u,v ∈ [0,1/2]`,

```text
‖permutationFourierSum W (fun j => semicircleFlowKernel u (lam j)) χ π
 - permutationFourierSum W (fun j => semicircleFlowKernel v (lam j)) χ π‖
≤ 12 √|u-v|.
```

The proof uses the accepted T905 pointwise kernel modulus at `lam (π i)`,
multiplies each difference by `χ i`, applies `norm_sum_le`, then cancels the
actual complex denominator `(W : ℂ)`. The premise `1 ≤ W` gives
`0 < (W : ℝ)`, so this normalization is nonzero and `div_le_iff₀` applies.
The numerator is bounded by `W · (12 √|u-v|)`; `Complex.norm_natCast` makes
the denominator norm exactly `W`, leaving the claimed constant unchanged.

The second public theorem,
`permutationFourierSum_W1_flow_endpoint_witness`, gives a nondegenerate
`W=1` example with `lam=0`, `χ=1`, and the identity permutation. The hypotheses
hold, and the normalized sums are `i` at `u=0` and `2i` at `u=1/2`; the theorem
also states these values differ. Thus the time observable is genuinely
nonconstant. The theorem requires `W ≥ 1`; no `W=0` normalization is used.
