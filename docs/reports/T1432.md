## Proved public statements

In `RBM.Gauss` the source defines `cubeSegment a₀ a₁ t = a₀ + t • (a₁-a₀)` and
`cubeAlternatingDifference f a₀ a₁ = f a₁-f a₀`. It proves:

```lean
cubeFTC_one (f : V → ℝ) (a₀ a₁ : V) (hf : ContDiff ℝ 1 f) :
  cubeAlternatingDifference f a₀ a₁ =
    ∫ t in (0 : ℝ)..1, fderiv ℝ f (cubeSegment a₀ a₁ t) (a₁-a₀)

cubeFTC_zero (f : PUnit → ℝ) : emptyCubeValue f = f PUnit.unit

cubeSegment_derivative (a₀ a₁ : V) (t : ℝ) :
  HasDerivAt (cubeSegment a₀ a₁) (a₁-a₀) t

cubeSegment_derivative_norm_le (a₀ a₁ : V) (B : ℝ)
  (hB : ‖a₁-a₀‖ ≤ B) (_t : ℝ) : ‖a₁-a₀‖ ≤ B
```

The zero-dimensional statement explicitly encodes the singleton empty vertex and an empty
iterated integral as evaluation. In dimension one there is exactly one shifted face for the sole
coordinate, so its difference is the interpolation derivative and its norm bound is immediate.

The source includes a checked nonzero dimension-one witness: `V = ℝ`, vertices `1` and `2`, and
`f x = x`; both the alternating difference and the integral equal `1`. This is the `r=1`
instance of the prescribed product witness. It does not claim that the higher-dimensional product
witness tests higher shifted-face differences; as clarified by the scheduler, those differences
vanish for subset order at least two in that witness.
