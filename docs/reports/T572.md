## Mesh mismatch audit

Three meshes presently coexist and must not be conflated.

1. T571 uses

   ```text
   transitionMesh N = (max 1 N)^248.
   ```

2. The old pinned witness `aprimeHypOn_jSnorm_exampleGrow` uses `D=1`, `t=1/2`,
   `delta0=1`, and

   ```text
   meshK (2 + 2*1) (1/2) = (N+1)^8.
   ```

   It is not a T571 consumer.

3. T483's general-moving package uses

   ```text
   Kmod D = 2D + 7,
   targetMesh D = polynomialMesh (2D+7),
   targetMesh 60 N = N^258 eventually,
   Ccard 60 = 259.
   ```

   It is not the T571 mesh. At `D=60`, the first-cell constructor instead uses
   `Kmod = 2+2D = 122`, `transitionMesh ~ N^248`, and `Ccard=249`.

`WeightedMoment` depends on the mesh through both `cutNetPt` and the prefix weight. There is no
available theorem transporting a moment bound between these different nets. Therefore neither
`meshK` nor T483's `targetMesh 60` may replace `transitionMesh`, even though each has its own valid
mesh arithmetic.

The generic `APrimeAssembly.aprimeSlot_of_widened_family` is also not a consumer of T571. It asks
for a moment family under the larger, order-dependent `widenedW`. T571 supplies a moment bound under
the smaller p-independent `piecewiseW`, and `piecewiseW <= widenedW` has the wrong direction for
recovering the larger-weight integral. The correct route is the direct
`aprimeHypOn_jSnorm_event` constructor.

## Good event and nonvacuity

Use one event throughout the event-restricted interface:

```text
firstCellGood N = {omega : Omega d | norm (Xmat d N omega) <= N}.
```

- It is measurable for every `N`.
- It is `HighProb` by `Gauss.highProb_norm_Xmat_le`.
- It is nonempty for every `N`, not merely eventually: `omega=0` belongs to it by
  `APrimeSlotFields.zero_mem_normX_le`.
- The modulus is asserted on this exact event, not on `univ` and not on an event renamed from a
  different source.
- The first-cell window is eventually strict by `Gauss.first_cell_window_nondegenerate`; T571's
  positive `k=2` package is stronger, giving an active endpoint `v>0` for the same selected
  `tauPrime`.

The T571 moment statement itself is unconditional over the Gaussian measure, so it has no hidden
event that must be identified with `firstCellGood`. Its positive witness lies in
`sharpCommonEvent`; the existing implication used inside T571

```text
sharpCommonEvent membership
  -> commonEvent_to_dynamic_support
  -> APrimeSupportRunning.good_subset

```

shows that this same positive resident is also in `firstCellGood`. Thus a future consumer may export
a same-sample positive-window, weight-one, `Good`-resident certificate without intersecting events or
changing the moment theorem.

At `k=0`, T571 already supplies the exact endpoint and cutoff branch, while
`jSnorm_piecewiseW_fields` supplies prefix domination for every `k`, including zero. No active-index
assumption is introduced by the constructor.

## Paper check: (2.76), (5.43)-(5.47)

The checked source is exactly `paper/250520-YinJun-v2.pdf` (95 pages, Acta version dated
2026-07-24).

- (2.76) is a statement for every `s <= u <= t` and every `D>0`, with the time factor
  `(eta_s/eta_u)^4`, the stretched-exponential spatial tail, and `W^(-D)`.
- (5.43) introduces the stopping time at the common threshold
  `J*_(u,D) >= (eta_s/eta_t)^4`.
- (5.44) integrates the near and cubic-far quadratic-variation terms only up to the same stopped
  time.
- (5.45) is uniform in every intermediate endpoint `s <= t' <= t`.
- (5.46) takes a single fixed `N^(-C)` net and a maximum over its indices.
- (5.47) concludes `J*_(tau,D) prec (eta_s/eta_t)^2`, and only then removes the stopping time by
  showing `P(T <= t)` negligible.

The Lean A-prime route is not a literal formalization of that stopping-time proof: it uses the
unconditional p-independent smooth weight and `WeightedMoment`. The present consumer preserves all
of the data that the Lean replacement actually quantifies over, but it proves only the first-cell,
fixed-`D=60`, fixed-`E=0` interface. It does not prove the paper's all-window/all-`D` conclusion.
