# T930 — strict closed-time interpolation for a finite Fourier sum

## Result

**PASS in the deterministic finite model.** The new module
`RBM1D/Gauss/PermutationFourierClosedTimeInterpolation.lean` proves that for
`W ≥ 1`, `h > 0`, `|lam j| ≤ 2`, `‖χ j‖ ≤ 1`, and one fixed permutation `π`,
strict bounds `< r` at every node of the actual clipped grid imply, for every
`u ∈ [0,1/2]`,

```text
‖permutationFourierSum W (j ↦ semicircleFlowKernel u (lam j)) χ π‖
  < r + 12 * sqrt h.
```

The hypotheses allow arbitrary real `r`. They introduce no probabilistic or
asymptotic assumptions.

## Proof and boundary checks

The proof selects `j` from `permutationFourierClosedTimeGrid_coverage`, which
gives `|u - grid(h,j)| < h`, and uses `permutationFourierClosedTimeGrid_range`
to place that node in `[0,1/2]`. The accepted T917 modulus at `u` and this node
gives the same-permutation difference bound `≤ 12 sqrt(|u-grid(h,j)|)`;
monotonicity of `Real.sqrt` bounds this by `12 sqrt h`. The norm triangle
inequality then combines this weak modulus estimate with the selected node's
strict `< r` estimate. Thus the final strictness comes from the node premise.
All times in the theorem use closed inequalities, so `u=0` and `u=1/2` are
included without division or endpoint limits.

The Fourier sum is used in its actual orientation from
`permutationFourierSum`: `(∑ i, χ i * x (π i)) / (W : ℂ)`. Interpolation applies
to the same fixed `π` throughout. No conjugation, phase reversal, or inverse
permutation is introduced; the generic `χ` interface includes canonical
characters when desired.

The public `permutationFourierClosedTimeInterpolation_W1_witness` supplies a
nonconstant satisfiable example with `W=1`, `lam=0`, `χ=1`, `π=id`, `h=1/2`,
and `r=3`. The actual grid has nodes `0` and `1/2`; the normalized sum norms
there are `1` and `2`, both strictly below `3`. The endpoint values are `i`
and `2i`, hence differ.
