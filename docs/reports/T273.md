## (a) `T267a` —— `μ = 2√Smax` 写进 ζ

**仿射吸收**：`S` 在 `s3Rhs` 里**只**出现在远场项 `cFar2·((2J)²·((Wℓη)·(2√S)))`，即 `s3Rhs = C₁·√S + C₂`（`C₁, C₂ ≥ 0`）。`s3Rhs_sqrt_le`：`√S ≤ M√S₀`、`M ≥ 1` ⟹ `s3Rhs(S) ≤ M·s3Rhs(S₀)`——与 T267 的 `s3Rhs_mul_le`（对 `κn`）**同一套路**，只是把 `C₁`/`C₂` 按 `√S` 重新切分。

## (b) `T268b` —— `hQbd` 的生产者，指数账

`R := η_s/η_t ≥ 1`，`Λ² := R^8`。
1. A1（`Step2MomentStep.integral_nearInt_le`）：`∫_s^t Q^{near} ≤ (Im m)⁻¹·(η_s/η_t)^4 = m⁻¹R^{+4}`；
2. 定义 `qHatNear E s t u := nearInt E s t u / (η_s/η_t)^8`，即**除以 `Λ² = R^8`**（`intervalIntegral.integral_div` 把除法提到积分外）；
3. **`4 − 8 = −4`**：`R^4/R^8 = R^{−4}`，写成不含 `R` 的形式 `(η_s/η_t)^4/(η_s/η_t)^8 = (η_t/η_s)^4`；
4. 结论 `∫_s^t Q̂^{near} ≤ (Im m)⁻¹·(η_t/η_s)^4`，**正是** `integral_inv_sqrt_mul_sqrt_kappa_le` 的 `hQbd` 的**字面形状**（`η_t/η_s ≤ 1`，是负指数那一侧，**没反**）。

⭐ 顺带把 `hQ0`（逐点非负）与 `hQint`（区间可积，经 `η_u` 在 `t < 1` 窗口上的连续性）也证成定理，于是 `integral_inv_sqrt_mul_sqrt_kappa_qHatNear_le` 是 (d) 的**无 `hQbd` 版**；唯一剩下的侧条件是乘积 `u^{−1/2}√(Q̂_u)` 的可积性——**那是 (a) 本身的假设，不属于预算**。
