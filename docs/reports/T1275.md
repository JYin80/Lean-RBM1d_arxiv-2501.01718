# T1275 — early-prefix p=1 N1 consumer

## Result

Added `RBM.APrimeGeneralMovingEarlyPrefix3DP1N1Consumer.eventually_early_prefix_3D_p1_N1_consumer` in
`RBM1D/Gauss/APrimeGeneralMovingEarlyPrefix3DP1N1Consumer.lean`. For fixed
`|E| < 2`, `D ≥ 60`, regular window data, `BoundsCore`, and
`0 < δ ≤ min 1 (c / 100)`, it gives a single eventual cutoff such that every
active `1 ≤ k ≤ cutNetTop` with `k ≤ N^(3D)` and every output label satisfies

```text
2 ∫_[s_N,v_k] (T615 actual smooth-weighted drift norm at p=1
               + full positive-time cross budget at p=1)
  ≤ APrimeOneStep.driftTerm(..., x, R, ...) / R^4,
```

with `x = N^(δ/8)` and `R = ratR(E,s,N,v_k)`. The theorem uses the actual
T615 smooth weight and the full positive-time budget; it does not replace
either integrand by a proxy in its conclusion.

## Mathematical preflight and proof path

The mesh is `N^(4D+18)`. Thus `k ≤ N^(3D)` gives
`v_k - s_N ≤ N^(-D-18)`, and the square-root interval has length at most
`N^(-D/2-9)`. The accepted T611 pointwise envelope `|driftAt| ≤ N^(D+8)`
passes to the p=1 weighted norm because the actual weight lies in `[0,1]`;
integrating gives `∫g ≤ N^(-10)`.

For the cross term, the accepted T1207 reduction, T1247 pointwise p=1 bound,
and T1245 profile estimate give, before the outer factor two,

```text
∫ fullCross ≤ (15/2) K N^(13δ/640 - D/2 - 8) R^(-2)
               + (15/2) N^(-D/2-10),
```

where `K` is the accepted positive cross-profile constant. Since `δ ≤ 1`,
`D ≥ 60`, and `R ≥ 1`, twice this bound is at most
`15 K N^(-1) + 15 N^(-1)`. Combining with the drift gives
`2 ∫(g + fullCross) ≤ (17 + 15K)N^(-1)`. The eventual absorption
`2 Im(mE) (17 + 15K) ≤ N` puts this below `1/(2 Im(mE))`.

For the selected small-slot parameters, `x ≥ 1` and the accepted near-field
slot lower bound gives
`driftTerm(...)/R^4 ≥ x^(5/4)/(2 Im(mE)) ≥ 1/(2 Im(mE))`.
This closes the exact consumer inequality. The cutoff is uniform in active
`k` and output labels for the fixed theorem parameters.

`nondegenerate_early_prefix_witness` extends the accepted T995 scheduled
same-event witness: on that same event the first cell is active, lies in the
`N^(3·60)` prefix, has widened weight equal to one, and has strictly positive
actual smooth weight. The witness retains the noncollapsed window and the
existing regularity and `BoundsCore` hypotheses; no additional assumption is
introduced.
