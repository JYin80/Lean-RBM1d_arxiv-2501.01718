# T458 — deterministic moving first-cell scale floors

## Result

New exclusive module:
`RBM1D/Gauss/APrimeFirstCellScaleFloors.lean`.

The module defines `ScalePackage tau' N k` for the actual moving endpoint

```text
v   = cutNetPt 0 transitionMesh N k,
A_v = endpointScale N v = W ell_v eta_v,
R_v = xRate v = eta_0 / eta_v.
```

`eventually_scalePackage` proves, eventually in `N` and uniformly for every
actual first-cell index `k<=cutNetTop`, that

```text
0 <= v <= 1/2,
0 < A_v,
N^(1/2) <= A_v,
1 <= R_v <= 2,
R_v^30 <= A_v.
```

The polynomial floor and ratio floor are separate fields of the package.
No product `N^(1/2) R_v^30 <= A_v` is asserted.

## Proof ledger

The pointwise theorem `scalePackage_of_bounds` takes the deterministic inputs

```text
N^(5/8) <= W,
2 <= N^(1/8),
2^30 <= N^(1/2).
```

For every moving first-cell endpoint, `ell_v>=1` and `eta_v=1-v>=1/2` give

```text
A_v >= W/2 >= N^(5/8)/2 >= N^(1/2).
```

Also `eta_v<=1`, hence `1<=R_v<=2`.  Therefore

```text
R_v^30 <= 2^30 <= N^(1/2) <= A_v.
```

`Dims.bandwidth_grow` supplies the bandwidth input.  The two remaining
numerical thresholds follow from divergence of positive real powers of `N`.
The proof uses no random event, `Good` assumption, or next-cell `BoundsCore`.

## Boundary geometry

  the endpoint is exactly zero.
* `eventually_positive_two_scalePackage` proves the actual `k=2` endpoint is
  strictly positive and carries the same deterministic package.

The module stops at the scale inputs and performs no far-row absorption or
cross-time estimate.
