## Exact finite model and indexing

Let `Ω W := Equiv.Perm (Fin W)` with the full measurable space `⊤`, and set

```lean
noncomputable def uniformPerm (W : ℕ) : Measure (Ω W) :=
  ProbabilityTheory.uniformOn (Set.univ : Set (Ω W))
```

For every `W`, this is a probability measure: even `W=0` has the identity permutation. `uniformOn_apply_finset` gives `μ(A)=|A|/|Ω W|` for finite `A`. `PMF.uniformOfFintype (Ω W)` is an alternative distribution, but the measure form works directly with the conditional-kernel and Azuma APIs. `Fintype.card_perm` identifies `|Ω W|=W!`; no factorial identity is needed for the conditional-law ratio.

Use a fixed observation type for all `k : ℕ`:

```lean
abbrev Obs (W : ℕ) := Fin W → Option (Fin W)

def prefixObs (W k : ℕ) (π : Ω W) : Obs W :=
  fun i => if i.val < k then some (π i) else none

def cylinders (W k : ℕ) : Set (Set (Ω W)) :=
  {s | ∃ (i v : Fin W), i.val < k ∧ s = {π | π i = v}}

def prefixSigma (W k : ℕ) : MeasurableSpace (Ω W) :=
  MeasurableSpace.generateFrom (cylinders W k)

def prefixFiltration (W : ℕ) : MeasureTheory.Filtration ℕ
    (inferInstance : MeasurableSpace (Ω W)) where
  seq := prefixSigma W
  mono' := prefixSigma_mono W
  le' := fun _ => le_top
```

Here `prefixSigma_mono` is a short compiled proof by `MeasurableSpace.generateFrom_mono`: `i.val<k` implies `i.val<l` when `k≤l`. The displayed filtration fields and definitions compiled in the scratch probe, with `prefixSigma_mono` proved. The only warning is Mathlib's style warning that a definition of class type is semireducible; it is not a type error. An exact bridge still to prove is

```lean
prefixSigma W k = (⊤ : MeasurableSpace (Obs W)).comap (prefixObs W k).
```

Its statement typechecked. It identifies the cylinder-generated σ-algebra with the observation σ-algebra required by `condDistrib`; monotonicity alone does not establish this equality.

For `0≤k≤W`, let `C(k,p)={ρ : Ω W | ∀ i, i.val<k → ρ i=p i}`. For an actual `π`, put `C_k(π)=C(k,π)`. Then `π∈C_k(π)`, so `|C_k(π)|>0` and `μ(C_k(π))>0`. On a supported arbitrary prescribed `p`, require `0<|C(k,p)|` before dividing. An inconsistent `p` can give `|C(k,p)|=0`, for example `W=3`, `k=2`, `p 0=p 1=0`. Its event has probability zero; there is no meaningful pointwise conditional law to demand there.

## Conditional law and the exact missing implication

With `X_k=prefixObs W k`, the prospective pointwise theorem, for all `W k : ℕ`, every `π : Ω W`, and every `s : Set (Ω W)`, is

```lean
ProbabilityTheory.condDistrib id (prefixObs W k) (uniformPerm W)
    (prefixObs W k π) s =
  ProbabilityTheory.uniformOn (C_k(π)) s.
```

This means every completion of the observed prefix has equal conditional weight. More explicitly, if `C(k,p)` has positive cardinality, then for every event `A`,

\[
  \Pr(A\mid C(k,p))=\frac{|A\cap C(k,p)|}{|C(k,p)|}.
\]

For `k<W` and a next value `v`, define `C(k,p,v)=C(k,p)∩{ρ:ρ(k)=v}`. Given a supported prefix, the conditional probability of `v` is `|C(k,p,v)|/|C(k,p)|`; conditioned also on a positive-cardinality `C(k,p,v)`, the remaining permutation is uniform on that fiber. This latter finite fiber is T694's `permutationPrefixFiber W k p v` (up to its subtype/Finset representation). T703's transport and T704's proposed mean range refer to these exact positive fibers. An unused `v` alone does not guarantee positivity when `p` is inconsistent.

The source-backed proof route is pointwise and finite. `condDistrib_apply_of_ne_zero` gives the conditional kernel as the joint mass divided by the mass of the observed singleton. The latter is nonzero because an actual `π` realizes the prefix and the uniform measure gives every permutation positive mass. Rewrite each mass by `uniformOn_apply_finset`; cancel the common denominator `|Ω W|`, leaving `|A∩C_k(π)|/|C_k(π)|`. `Measure.ext_of_singleton` permits equality of the two finite measures after checking singleton events; `integral_fintype` then turns conditional integrals into finite weighted sums. No unverified pointwise conditional-expectation lemma is assumed. The remaining Lean work is the finite observation/fiber equivalence, the positive-mass arithmetic, and the σ-algebra equality above.

## From T704's range to the Doob difference

Let `F(π)=permutationFourierSum W x χ π`, with `W≥2`, `∀j, ‖x j‖≤2`, and `∀j, ‖χ j‖≤1`. For a real coordinate `f=Re F` or `f=Im F`, define the **finite** prefix mean

\[
 M_k(π)=\frac{1}{|C_k(π)|}\sum_{ρ∈C_k(π)} f(ρ),\qquad 0≤k≤W.
\]

The finite definition with `Finset.univ.filter` and division by its cardinality typechecked in the probe. Positivity follows from `π∈C_k(π)`; do not use Lean's formal `0/0=0` as a conditional-law argument. The conditional-law theorem plus the σ-algebra equality should identify `M_k` with `μ[f\mid prefixSigma W k]` (at least almost everywhere); the finite route may instead prove the required tower identity directly by partitioning `C_k(π)` over `v`.

Set `D_{k+1}=M_{k+1}-M_k` for `0≤k<W`. On a supported `C_k(π)`, write `m_v` for the mean of `f` on a positive next-image fiber. The disjoint partition by `v` gives

\[
 M_k(π)=\sum_{v:\,|C(k,p,v)|>0}
       \frac{|C(k,p,v)|}{|C(k,p)|}\,m_v,
 \qquad M_{k+1}(π)=m_{π(k)}.
\]

T704's proposed result says `|m_v-m_w|≤B`, with `B=8/W`, for any two supported candidates. Hence `M_k` is a convex combination of values all within `B` of `m_{π(k)}` and **pointwise** `|D_{k+1}(π)|≤B`. The same partition proves the conditional mean of `D_{k+1}` given the first `k` images is zero. This is the exact Doob step; the range comparison by itself is not an increment theorem. The `π`-realized next fiber is positive, so the argument is nonvacuous even if other candidate fibers are empty.

At `k=0`, `C_0(π)=Ω W`; `M_0` is the global uniform mean, zero for a nonzero character by actual T692. At `k=W`, `C_W(π)={π}`, so `M_W=f(π)`. At `k=W-1`, the unused image is determined by the preceding `W-1` images; thus `M_W=M_{W-1}` and the last difference is zero. For `W=2`, `x=(2,-2)` and `χ=(1,-1)` yield `F(id)=2`, `F(swap)=-2`, so `M_0=0`, `D_1=±2`, `D_2=0`: the process is genuinely random. For `W=1`, there is no nonzero Fourier mode; the P2 specialization is not posed. The zero mode at any `W` lacks T692's character mean-zero hypothesis and must not be fed into the centered tail without separate recentering.

## Exact Azuma parameter and tail constant

Mathlib's endpoint is `ProbabilityTheory.measure_sum_ge_le_of_hasCondSubgaussianMGF`. It uses a `Filtration ℕ`, a `StronglyAdapted` process, an initial `HasSubgaussianMGF`, and conditional `HasCondSubgaussianMGF` for subsequent increments. Embed the finite process as `Y 0=0`, `Y (k+1)=D_{k+1}` for `k<W`, and `Y i=0` thereafter; invoke it with `n=W+1`, `cY 0=0`, and conservatively `cY (k+1)=B²=64/W²` for `k<W`. The theorem's hypotheses run over `i<n-1`, so they request exactly the `W` conditional increments, including the deterministic last reveal. `Y 0` has parameter zero. `StronglyAdapted` follows once each finite prefix mean is measurable at its reveal level.

The conditional MGF is a further proof obligation: on each positive prefix cell, the conditional law is uniform, `D_{k+1}` has conditional mean zero and lies in `[-B,B]`. Apply `hasSubgaussianMGF_of_mem_Icc_of_integral_eq_zero` to that conditional probability measure to get `((2B)/2)²=B²`. Assemble these cellwise estimates into `HasCondSubgaussianMGF (prefixSigma W k) ... D_{k+1} B² μ`. Mathlib has no ready-made lemma in the inspected files that performs this finite-cell assembly automatically; `HasCondSubgaussianMGF` is defined through `condExpKernel`. The above pointwise `condDistrib` identity, together with the σ-algebra equality, is the concrete bridge to that kernel. A direct finite exponential-moment induction over prefix cells is a fallback if this kernel transfer is cumbersome; it needs the same finite partition, centering, and Hoeffding bound, so it does not bypass the mathematics.

The parameter sum is `W(64/W²)=64/W`. For `a≥0`, a one-sided coordinate tail is

\[
 \Pr(f-M_0\ge a)\le
 \exp\!\left(-\frac{a²}{2(64/W)}\right)
 =\exp(-Wa²/128).
\]

Apply the same inequality to `-f` for two sides. If `‖F‖≥r≥0`, then `|Re F|≥r/√2` or `|Im F|≥r/√2`; T692 gives both coordinate means zero for a nonzero character. Substituting `a=r/√2` gives `exp(-Wr²/256)` **per one-sided coordinate event**. Four events yield exactly `4 exp(-Wr²/256)`. The parameter `64/W` is conservative; the deterministic last increment could be assigned zero, but is not needed for this constant. There is no factor-of-two discrepancy. For `r=0`, the bound is trivial (`1≤4`).
