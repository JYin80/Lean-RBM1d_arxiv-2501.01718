- `step345_threshold_one_le`：第 3 槽的门槛 `A_s^{1/2} ≥ 1` 最终成立——接口**不是**在要 `Ξ^{(L−K)}_{u,2} ≪ 1`（那种请求 `hinit`（`≺ 1`）永远支持不了）。

- `flucRowFlow_canonical`、`flucBlkFlow_canonical`：在显式的 `x N u ω i = G_u(ii) − m` 上，`Eq45FlowInputs` 三个字段里有两个对**每个**样本与模型成立 ⟹ 三者不联合矛盾（`eq45FlowInputs_of_ibpFlow_canonical`）。
- `eq45FlowInputs_nonfiat`：**反 fiat** 检查——对**任意** `x`，该束都推出 (4.5) 本身（`|L−K|_1 ≺ L^max_u`），那是关于**模型**的陈述、不是关于 `x` 的。所以没有哪个 `x` 能把三个合取项全清空（最多清空两个）。
- 量词卫生：未引入 `∀ p N`（`CutHypEv.moment` 保持 `δ, ε` 在 `p` 之前、`∀ᶠ N` 最内）；所有时间量词都在 `TimeIcc s t N` / `Set.Icc (s N) (t N)` 内、`0 ≤ s ≤ t < 1`；未引入 `∀ ω` 的 size 不等式。`ω = 0` 与「大常数倍单位阵」两点：两条新假设都是 `StochDom`/矩平均型，逐点不被否证。

## 它主动标出的残余风险（不是它引入的）

`CutHypEv.modulus` 是带固定 `N^{Kmod}` 的 `∀ ω` Hölder 模，对无界高斯项是**唯一有风险的字段**。它与第 2 槽 `MomentHypCut.cut` 的**同一个字段**，所以第 3 槽现在与第 2 槽同风险等级，**没有新风险类进表**。
