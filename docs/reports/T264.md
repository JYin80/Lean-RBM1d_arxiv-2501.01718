## (S1) —— 做出来了，就是 (★) 逐字

`RBM.Gauss.hasDerivAt_integral_weighted`：
```
HasDerivAt (fun s => ∫ ω, w ω • Ψ s (Hflow d N s ω) ∂(P d))
  ( ∫ ω, w ω • timeD1 Ψ u (Hflow d N u ω)
  + ½ • Σ_{p ∈ usedCoord} gvar p • ∫ ω, w ω • coordD2 (Ψ u) (Hflow d N u ω) p
  + (1/(2√u)) • Σ_{p ∈ usedCoord} gvar p • ∫ ω, wD p ω • coordD1 (Ψ u) (Hflow d N u ω) p ) u
```
前提：`hst : MatrixStein d`、`h : TestFunT₁ d N T Ψ`、`hw : WeightC1 d N w wD`、`0 < u`、`T ∈ nhds u`。
证明 = `hasDerivAt_integral_Psi₁` 的控制收敛论证把 `w ω •` 带着走，再对 `ω_q ↦ w·∂_qΨ` 做**一次** `MatrixStein.stein`（它的坐标导数按乘积法则是 `(∂_q w)·∂_qΨ + w·√u·∂_q²Ψ`）。
⭐ **审稿点名的禁路（把 `w(M/√u)` 塞进 `Ψ`）没有用**。
配套自证：`finDep_smul_real`、`finDep_add'`（仓库原先**没有**通用的 `FinDep` 封闭性）。

## `w` 的正则性阶数 —— **只要一阶**

`RBM.Gauss.WeightC1 d N w wD` **恰好六个字段、没有二阶导字段**：`cont`、`contD`、`finDep`/`finDepD`（`MatrixStein.stein` 要的 `FinDep`）、`hasDeriv`（`wD p` **就是** `∂_{crd p} w`，一阶）、`bdd`/`bddD`（`|w| ≤ C`、`|wD p| ≤ C`，对 `p ∈ usedCoord` 一致）。
**所有量词都只跑 `usedCoord d N`，不是全部坐标。**
⭐ **这在操作层面证实了 D19**：`∇²w` 从不出现，所以 `∇²χ` 的 card-free 界确实不在关键路径上。

## (S4) —— 做出来了

`RBM.MomentDuhamel.weightedMinkowski_of_deriv_le`：
```
momNormW P W p (Y v) ≤ momNormW P W p (Y s) + 2·(∫_s^v (A r + B r) dr) + √((2p−1)·∫_s^v g r dr)
```
前提：`0 ≤ W`、`1 ≤ p`、`φ u = ∫ W·|Y_u|^{2p}` 在 `Icc s v` 上连续、在 **`Ioo s v`** 上 `HasDerivAt φ (φ' u) u`，以及
`φ' u ≤ 2p·φ(u)^{(2p−1)/(2p)}·(A u + B u) + p(2p−1)·φ(u)^{(p−1)/p}·g u`。
新增：`momNormW`（`= (∫ W·|Y|^{2p})^{1/(2p)}`）、`momNormW_one`（`W ≡ 1` 时退回 `momNorm P (2p)`）、`momNormW_nonneg`、`sqrt_rpow_inv`。
**证明与 T191 逐字同**：`rpow_inv_le_of_deriv_le_Icc`（本来就对 `φ` 抽象，所以带权矩原样喂得进去）再 `RBM.sqrt_le_of_integral_le`；上确界由 `exists_isLUB_Icc` 经 `IsCompact.exists_bound_of_continuousOn` 命名，**没有额外强加有界性假设**。
⭐ **Grönwall 因子是 1，没有指数。**
⭐ **左端点可以是 `0`**：导数假设只活在 `Ioo s v` 上（D17）。

## 见证

* `sat_weightedMinkowski` —— 全退化实例，`∀ p ≥ 1`，说明假设束在 `s = 0` 处不自相矛盾；
* ⭐ `sat_weightedMinkowski_sharp` —— **非退化**：`p = 1`、`W ≡ 1`、`Y_u ≡ √u`、`A = B = 0`、`g ≡ 1` 于 `[0,1]`。于是 `φ u = u`、`φ' = 1`，**微分假设取等号**（`1 ≤ 1`）**而结论也取到**（`1 ≤ 0 + 0 + √1`）。矩、它的导数、QV 项**全都非零**，界是**锐的**——既不空真也不松。

**`p = 0`**：由假设 `1 ≤ p` 排除（继承自 `rpow_inv_le_of_deriv_le_Icc`）。`p = 0` 处指数 `1/p` 是 `1/0`，陈述会**静默退化**；那一支仍归 T260 的 `integral_weight_pow_zero_le`。**本单不声称覆盖它。**
