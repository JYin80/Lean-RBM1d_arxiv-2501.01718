## Coefficient-one chain

`familyWeightTransferAt_of_bounds` proves

```lean
momNormW (Gauss.P d) targetWeight p familyMax
  <= momNormW (Gauss.P d) canonicalWeight p familyMax
  <= momNormW (Gauss.P d) canonicalWeight P familyMax.
```

The first inequality applies integral monotonicity and real-power
monotonicity to T542's pointwise `targetWeight <= canonicalWeight`.  The
second inequality is T543's same-measure, same-weight Lyapunov theorem.
Both constants are exactly one.

`actualFamilyWeightTransfer` makes this uniform after the eventual size
cutoff for every positive active first-cell mesh index.  The orders remain
fixed before that cutoff.

## Zero branch and positive resident

`kZeroFamilyWeightTransfer` retains together:

- the exact endpoint `endpoint N 0 = 0`;
- target weight equal to one for every sample;
- canonical high-order weight equal to one for every sample;
- the same two-step coefficient-one family norm chain.

`positiveTwoFamilyWeightTransferResident` uses T542's literal same-event
`k = 2` resident.  On the identical sample, the target order-`p` weight and
canonical order-`P` weight both equal one, the endpoint is positive, and the
coefficient-one family norm chain holds.  No numerical value is assigned to
the final canonical order-`P` norm.

The closed theorem chooses one `tauPrime` before every admissible `delta`,
then fixes `p` before the eventual size cutoff.  It retains T542's measurable
high-probability sharp event at `alpha = delta/16`, the exact zero branch,
and the positive same-event resident.  These fields provide a nondegenerate
witness without introducing a new hypothesis.
