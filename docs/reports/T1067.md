## Exact consumer identity

The relevant field of
`APrimeDuhamelModel.momFlowDeriv_le` is

```text
Integrable (fun ω => w ω * |flowY d N Ψ₁ r ω|^(2*p)) (Gauss.P d).
```

At the T615 moving endpoint, `Ψ₁` is
`APrimeDriftTimeFamily.coordAt d E D N σ a s_N v_k`. The definition of
`flowY` makes its value exactly the norm of this same coordinate evaluated at
`Hflow d N r ω`. `normalizedTestFunBridge` supplies the corresponding
`TestFunT₁` bridge on `[s_N,v_k]`.

For `N ≥ 2` and active `k`, T615's actual weight is on its active branch and
equals the literal smooth cutoff to the power `2*p`. T1043's `actualY` is that
same cutoff times the norm of `coordAt`, with the same `N,k,σ,a,r,v_k`. Thus
the pointwise identity used in the Lean proof is

```text
weight_actual(ω) * |flowY(coordAt)(r,ω)|^(2*p)
  = |actualY(ω)|^(2*p).
```

This is an equality with the consumer integrand, not an estimate by a
different cutoff observable. The accepted T1043 finite-size bound obtains a
uniform-in-`ω` bound for the raw coordinate on the closed time cell from
`exists_bdd₀_ukerObsT`, divides by the positive `driftScale`, and uses
`0 ≤ cutoff ≤ 1`; continuity gives measurability. Its bounded power is
integrable under the finite Gaussian probability measure. The new theorem
transfers that exact integrability by the displayed identity. The actual
weight also has the accepted `0 ≤ weight ≤ 1` bounds from T615.

The only premises are `|E| < 2`, `0 ≤ s_N ≤ t_N < 1`, and fixed `p ≥ 1`.
The eventual index can be taken with `N ≥ 2`; no good-event or transition
membership is used. The `k=0` cell is included, and both closed-cell
endpoints are retained.
