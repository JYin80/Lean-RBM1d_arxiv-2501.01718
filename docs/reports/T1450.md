# T1450 — all-order outer smooth-norm derivative bound

## Result and scope

**Worker result: PASS for the assigned deterministic calculus arrow.** The new module proves the all-order estimate (A) from T1424 §3.2 for both `s = 1` and `s = -1`. For even `q` with `max 2 (4*M) ≤ q`, `1 ≤ k ≤ M`, nonzero `x : ι → ℝ`, and arbitrary `v : Fin k → ι → ℝ`,

```text
|D^k (smoothNormPower q s)(x)[v]| ≤ C_k q^(k-1) qNorm(q,x)^(s-k) ∏ j, qNorm(q,v j),
```

where `smoothNormPower q s x = (powerSum q x)^((s:ℝ)/(q:ℝ))` and

```text
C_k = ∑ c : OrderedFinpartition k, (Nat.factorial c.length : ℝ).
```

This is an explicit finite combinatorial constant depending only on `k`. `OrderedFinpartition` represents each set partition in its canonical order by increasing greatest element. The proof uses the scalar outer coefficient bound `|(s/q)_p| ≤ p!/q`, the accepted T1434 inner derivative bound, and the ordered-partition chain rule. The powers combine to `qNorm(q,x)^(s-k)` and `q^(k-1)`. No coordinate cardinality, positivity of individual coordinates, or lower bound on direction norms is assumed.

The module also proves `smoothNormPower_contDiffAt` at every nonzero vector for every differentiability order. Since even `q` makes `powerSum q` positive whenever the full vector is nonzero, this includes points with individual zero coordinates.

The formal `Fin 2` witness is `x = v = (1,0)`: the theorem `fin2_smoothNormPower_first_derivative_witness` records `x 0 = 1`, `x 1 = 0`, and a nonzero first derivative for each `s ∈ {1,-1}`. The derivative equals `s`.
