## Claim and dependency check

For every natural `W` with `2 ≤ W`, every `q : Fin W` with `q ≠ 0`, and every
`j : Fin W`, the definition is literally
`χ_q(j) = exp(2 * π * I * (q.val : ℂ) * (j.val : ℂ) / (W : ℂ))`.
There is no `ZMod` reinterpretation or extra table condition. The theorem
proves `∑ j, χ_q(j) = 0`; for every `x : Fin W → ℂ`, the specialization proves
the counting average over **all** `Equiv.Perm (Fin W)` of the existing
`permutationFourierSum W x χ_q` is zero. The latter definition is exactly
`(∑ i, χ_q(i) * x (π i)) / (W : ℂ)`, retaining T684's `W⁻¹` normalization.

The import path is acyclic:
`PermutationFourierCharacter → PermutationFourierMean → PermutationFourierSwap → Mathlib`,
with a separate Mathlib complex-log import in the character module. The mean
theorem calls T684's `permutationFourierSum_mean_zero` with the newly proved
zero-sum hypothesis. It does not assume character orthogonality through a
different interface.

| Nontrivial root | Passed. `z=1` implies `W ∣ q.val`; since `q.val < W`, this forces `q.val=0`, contradicting `q≠0`. |
| Geometric sum | Passed. The character is `z^j.val`. `geom_sum_mul` yields `(∑_{n<W}z^n)(z−1)=z^W−1=0`; `z≠1` gives the exact zero sum. `Fin.sum_univ_eq_sum_range` transfers it to `Fin W`. |
| `W=2` | Passed. `q=1` gives `χ(0)=1`, `χ(1)=−1`. Taking `x(0)=2`, `x(1)=−2` makes the identity Fourier value `2` and the swapped value `−2`, so the zero mean is genuine cancellation. |
