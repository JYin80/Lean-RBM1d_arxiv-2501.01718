## 3. Independent proof of the stronger first-cell cap: the event

Let `d = Dims.exampleGrow`, `E=0`, `D=60`. For each `N`, identify the matrix Hilbert space with the orthogonal direct sum of `L` blocks `C^W`. Define `B_N` by the conjunction:

1. every matrix block `X_ab` outside `d_L(a,b) ≤ 1` is zero;
2. every off-diagonal nearest-neighbor block has operator norm at most `8`.

This is a finite intersection of measurable conditions. The first condition has probability one. It must be stated explicitly: `Gauss.Model.lean:201–255` defines `Omega = Coord -> R`, makes zero-variance coordinates Dirac under `P`, and then reads those coordinates directly in `Xentry`. Thus `Xmat` is Hermitian at every sample, but it is banded only almost surely. Merely bounding neighboring blocks does not exclude arbitrary nonzero distant blocks at measure-zero samples. Intersecting the finite band-zero event fixes this exactly.

For distinct neighboring blocks `a,b`, each entry has independent centered real and imaginary Gaussian parts of variance `1/(6W)`, since `S_ab=1/(3W)`. Hermitian reversal makes `X_ba=X_ab*`; it does not duplicate coordinates inside one off-diagonal block. This remains true for the wrap-around pair and for `L=3`.

Here is a direct high-probability estimate requiring no matrix-norm theorem as an external input. A `1/4`-net of the complex unit sphere in `C^W`, regarded as a real sphere in dimension `2W`, has cardinality at most `9^(2W)`: take a maximal separated set and compare the volumes of disjoint radius-`1/8` balls with the radius-`9/8` ball. For any matrix `B`, approximating both maximizing unit vectors gives

```text
||B|| ≤ 2 max_(x,y in the two nets) |x* B y|.
```

For fixed unit `x,y`, the real and imaginary parts of `x*X_ab y` each have variance `1/(6W)`. The scalar Gaussian exponential-moment bound and the union of the four one-sided tails give

```text
P(|x* X_ab y| > 4) ≤ 4 exp(-24W).
```

Consequently

```text
P(||X_ab|| > 8) ≤ 4 exp(-(24-4 log 9)W).
```

The coefficient `24-4 log 9` is positive. A union bound over at most `2L` oriented neighboring pairs gives

```text
P(B_N^c) ≤ 8L exp(-(24-4 log 9)W).
```

Since `L≤N` and `W≥N^(5/8)` eventually in `exampleGrow`, this is at most `N^(-M)` eventually for every fixed `M`. Independence between different blocks is not required for this union bound. No diagonal-block norm bound is needed. This proves that `B_N` is measurable and HighProb, before any local law, averaged law, cutoff or A′ statement is used.

## 4. Independent proof of the stronger first-cell cap: conjugation

Fix `omega ∈ B_N`, a block `y`, and put

```text
alpha = log(65/64),
D_y|_(block a) = exp(alpha d_L(a,y)) I_W.
```

```text

```

There are at most two off-diagonal neighbors in each block row and each block column. The block Schur estimate gives `||K||≤1/4`. Explicitly, if `k_ab=||K_ab||`, weighted Cauchy–Schwarz bounds

```text
sum_a ||sum_b K_ab v_b||²
  ≤ (max_a sum_b k_ab)(max_b sum_a k_ab) sum_b ||v_b||².
```

Both maxima are at most `1/4`. This accounts for both orientations; no Hermitian cancellation is being used for `K`, which need not be Hermitian.

```text

  ≤ 1/(eta_u-||K||) ≤ 4.
```

The same estimate holds with the conjugate spectral parameter, so it covers both `Gsig` charges. Undoing the conjugation in block `(x,y)` yields

```text

```


The right side tends to zero, since its logarithm is

```text
log 16 + 2alpha + 60 log W - alpha (log W)^(3/2) -> -infinity.
```

Thus `jG(u)≤2≤N` eventually, simultaneously for all `0≤u≤1/2`. If no far pairs exist the definition already gives `jG=1`. At `u=0`, off-block entries vanish exactly. The proof is deterministic on one event and already uniform in the entire continuum; no time net is needed here.



