## Normalized claim

For all sufficiently large actual `N`, set `W = Dims.exampleGrow.W N` and let
`C_N(π)` be the encoded sample

```lean
omegaOfHermitian Dims.exampleGrow N
  (blockDiagonal Dims.exampleGrow N
    (fun _ => permutationFourierBlock W (Dims.exampleGrow.W_pos N) π))
```

For a fixed permutation `π`, assume for every `u ∈ [0, 1/2]` and every
canonical `q : Fin W` that

```lean
‖permutationFourierSum W (fun k => semicircleFlowKernel u (semicircleLambda ... k))
    (permutationFourierCharacter W q) π
  - (if q = 0 then Complex.I else 0)‖ < flowDelta ... N.
```
Then `C_N(π)` lies in `goodSetFlow` at the same `N`, same `π`, and every time
and pair of physical indices. Consequently, the T979 good-permutation event is
contained in the preimage of the literal physical `goodSetFlow`; if its
probability is at least `1 - 8 N^(-14)`, the same lower bound holds for that
preimage. The probability concerns `uniformPerm W`, not the Gaussian law.

## Inclusion and boundary audit

`PermutationFourierExampleGrowFlowCarrier.quantile_block_event` is the exact
physical producer. Its proof reads back the encoded Hermitian matrix, factors
the resolvent blockwise, and identifies each within-block resolvent entry with
the scalar Fourier sum at mode `b - a`. Given the all-time scalar condition,
instantiate it at `q = b - a`. Under the actual `NeZero W` instance,
`b - a = 0 ↔ a = b`; the scalar target `if q = 0 then I else 0` is therefore
exactly the physical diagonal target `if i = j then I else 0` for a within-block
entry.

For distinct physical blocks the resolvent entry is exactly zero, and the
reference entry is zero. The literal `GoodEvent` uses a weak `≤ δ`, while the
scalar hypothesis is strict `< δ`; passing from strict to weak is valid. The
cross-block case uses `0 ≤ δ`. The eventual margin supplied by T948 is in fact
strictly positive. The closed interval includes both endpoints, and the
quantile-block producer preserves the same `u` and `π` throughout; no
permutation or time is changed in the inclusion.

The scalar all-time event of T979 includes the zero mode. T933 supplies its
uniform weak estimate `≤ 8√2/W`, and T948 places that strictly below the
literal `flowDelta` threshold. For nonzero modes T930 gives a strict bound
`< 76√(log N/W)` from the strict grid-node condition; T937 places that strictly
below `flowDelta`. Thus the strict scalar condition required here is exactly
available after T979's grid-to-all-time step.

The accepted actual-dimension bounds give `W ≥ 2` eventually. This excludes the
single-mode degeneracy and is available in the T977 probability producer and
T973/T979 witnesses. For every `π` when `W ≥ 2`,
`quantileBlock_nonzero` proves the Fourier block is nonzero; block readback then
proves the physical matrix is nonzero. For every `π`,
`blockDiagonal_zeroVar` proves the encoded sample vanishes on every
zero-variance coordinate. The optional `GoodMesh` strengthening is also
all-π: `quantileCarrier_mem_generalMovingGoodMesh` gives operator norm at most
`N` once `N ≥ 2`, using the accepted deterministic norm bound `‖Xmat‖ ≤ 2`.
These factors can be conjoined to the same preimage event without lowering its
probability.

For the probability direction, if `G_N` is the T977 strict grid event, `S_N`
the T979 all-time scalar event, and `A_N` the carrier preimage of literal
`goodSetFlow`, the inclusions are `G_N ⊆ S_N ⊆ A_N`. Monotonicity gives
`μ(A_N) ≥ μ(S_N) ≥ μ(G_N) ≥ 1 - 8N^(-14)`. The same applies to the optional
conjunction since the additional carrier properties hold for every `π` in the
relevant eventual dimension range. All subsets of the finite permutation space
are measurable.
