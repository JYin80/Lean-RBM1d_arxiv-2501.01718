`Dims.exampleGrow` Gaussian sample and law, and rate `C N^(δq/2)`.

The index partition checks each boundary directly. `k=0` uses T1159; `k=1`
uses T1167; `2 ≤ k ≤ N^4` uses T1169, including `k=2` and `k=N^4` whenever
those indices are active; and `N^4 < k` uses T1165 with its unchanged real
power upper bound. The strict inequality leaves no gap or overlap at `N^4`.
The common event is uniform over all these active indices.
