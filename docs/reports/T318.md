`0∈[0,v]`, so the interval is nonempty and compact;

chooses a maximizer, and `QbActual` evaluates the rate there.

so the weight equals one at every sample and the interval has positive
length. This universal weight assertion is nonvacuous because

zero function `ω₀ := fun _ => 0`.
