# Paper (5.43) / Lean flow alignment — read-only review

2026-09-25 UTC. Source: `paper/250520-YinJun-v2.pdf`, (5.21), (5.24), (5.40)–(5.48), especially (5.43). This report records a scheduler reconciliation of an independent Astra XHigh read-only review; it accepts no Lean theorem.

The manuscript uses a Brownian matrix flow and the first hitting time `T = inf {u ≥ s : J*_{u,D} ≥ (η_s/η_t)^4}`, then `τ = T ∧ t`. Its martingale estimate (5.24) is applied to the stopped stochastic integral. The deterministic terminal parameter `t` in the evolution kernel is retained when stopping; replacing it by a random terminal parameter would need a separate proof. The paper's (5.43) argument has no derivative of a cutoff weight.

`Gauss.Model.Hflow` is the radial coupling `H_u = √u X`. `Gauss.APrimeGronwall.hasDerivAt_integral_weighted` instead uses a fixed smooth prefix weight and has the extra term `(2√u)⁻¹ ∑q S_q E[(∂q w)(∂q Ψ)]`; its source comment identifies this as the price of replacing the paper's stopping time. That cross term is required by this *alternative Lean identity*, but is not a missing paper lemma. One-time equality of radial and Brownian Gaussian laws does not identify stopped paths. `Flow.Hypotheses.Sample` and `Flow.Universality.OUFlow` do not specify the required Brownian law. The inspected repository has no instantiated Hermitian Brownian process or stopped Itô/BDG producer. Existing `LoopIto.generator_add_zMotion_gauss` already supplies the moving deterministic drift algebra and must be reused.

Classification: the first paper-faithful gap is **formalization infrastructure for the actual Brownian model and stopped stochastic integral**, followed by identification of the existing drift/QV algebra with that process. A standalone continuous first-hitting-time/cap lemma could be useful, but would be an abstract prerequisite, not an actual-model producer or cutoff closure. A new positive cutoff ticket must specify its exact actual-model consumer, covariance and adaptedness, stopping-time/bracket hypotheses, quantifier/loss order, and a nondegenerate instance of only those assumptions before dispatch. The radial smooth-prefix derivative bound remains a conditional alternative route on HOLD; do not count it as a paper requirement.

The independent review also checked T1381. Paper (4.12) and `Eq45Flow` require stochastic domination for deterministic admissible weights; T1381's normalized all-`p` moment is a different public interface. With the available deterministic polynomial envelope, stochastic domination can imply each fixed normalized moment by splitting good and overwhelming-tail events. Thus T1381's no-source final is a scope-incomplete attempt, not a disproof of the moment bound or paper (4.12). Its future consumer-facing target should quantify deterministic weights outside probability and use the actual random `Lmax` control; the all-time consumer additionally needs the existing net/modulus step.
