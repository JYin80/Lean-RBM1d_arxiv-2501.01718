# T357 — numerical near-only drift remainder absorption

## Result

Implemented `RBM1D/Gauss/APrimeDriftNearAbsorb.lean`. The module builds with
`lake build RBM1D.Gauss.APrimeDriftNearAbsorb` (exit 0). Every new theorem is
checked by `#print axioms`; each reports only `propext`, `Classical.choice`, and
`Quot.sound`. The file contains no `sorry` or new `axiom`.

The deterministic residual is defined with the **full** one-loop multiplier

`R = 2 C N^ζ [r L/(ell_u eta_u)] [eta_u^-1 J T(F)]`,

where `F=ell**−ell*` and the target near rate is
`P(d)=eta_u^-1 r^3 T(d)`. The compiled `residual_ratio_eq` gives the exact
identity

`R/P(d) = 2 C N^ζ [L J/(ell_u eta_u r²)] [T(F)/T(d)]`.

Thus only one of the two residual factors `eta_u^-1` cancels; `r²` remains in
the denominator. `residual_ratio_le` applies the compiled near tail floor
`A^-2 ≤ exp((log W)^(3/4)) T(d)` with `A=W ell_u eta_u`, yielding the factor
`A² exp((log W)^(3/4))` without changing either scale factor.

The later compiled declarations give:

* `gap_tail_le_two_floor`: `T(F)≤2W^-D`, using `A≥1`, `log W≥4`, and
  `(4D)²≤log W`. The proof compares `F=ell**−ell*` with
  `ell**−4ell*` before applying the existing stretched-exponential lemma.
* `cap_coefficient_le` and `residual_ratio_le_N`: under `L,J,A,eta_u^-1≤N`
  and `ell_u,r,N≥1`, the ratio is at most
  `2 C N^(5+ζ) exp((log W)^(3/4)) T(F)`.
* `residual_ratio_le_W`: if `N≤W²`, this is at most
  `4 C W^(11+2ζ−D)`. The exponent includes the honest `N^ζ` loss.
* `residual_ratio_le_invW` and `residual_indicator_le_invW`: for `D=60`,
  `0≤ζ≤1`, and `4C≤W`, the ratio is at most `W^-1`. The latter theorem keeps
  `1_{d≤ell*}` on both sides, so the far branch has zero remainder.
* `eventually_residual_indicator_le_invW`: on a growing band, the bound
  `4C≤W_N` follows eventually for fixed `C` from `Step2.tendsto_W`; all other
  numerical scale and `J` caps remain explicit eventual hypotheses.

`local_loop_indicator_absorb` is the scalar interface for a pointwise
three-loop estimate. `gaussian_local_loop_indicator_absorb` instantiates it
with the **actual Gaussian sample** and T350's compiled
`gaussian_three_near_far_indicator_le`; its hypotheses explicitly include
`J = APrimeJG.jG ... ≤ M` on that sample. This is a local bound for one
near-output/far-internal-label term, not an `eGpm` or `Adr` theorem.

## Nonvacuity

`first_cell_nondegenerate_witness` uses `W=exp(57600)`, `M=W²`,
`eta_u=W^-1`, and `L=ell_u=J=r=C=1`, `ζ=0`. It proves a strict positive
first grid-cell duration, positive `C`, `J`, `T(F)`, and residual, plus the
indicator-preserving `W^-1` absorption at `d=0`. These are deterministic
parameters; this theorem does not assert that a particular Gaussian sample
simultaneously realizes the model cap `J≤M` at a positive running time.
T350 independently supplies a real Gaussian first-cell near/far geometry
witness at a smaller scale, without the present `(4D)²≤log W` threshold.

## Remaining inputs and limits

The route to the paper's (5.35), (5.49)–(5.50) still needs a multiplier-aware
actual `eGpm` near/far branch argument. It must supply the averaged one-loop
(4.5) estimate `c≤C N^ζ r/A`, use T350's local three-loop bound in the near
branch of `Lemma57.eG_near_le`, and propagate the resulting spatial tail
through the kernel. The existing global `rhs535` interface drops the near
indicator too early and cannot be substituted for that branch proof.

Separately, the `J≤N` estimate and the Step-1 source/entry/modulus conditions
must be established on one common positive-probability event. No such
simultaneous event producer is claimed here. This module also does not prove
an actual Gaussian `Adr` bound or the stochastic averaged-loop estimate.
