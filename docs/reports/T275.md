### 1.1 加权 Hölder（新的通用工具，§5）

(G) 的 `hbound` 需要**带权**的两条 Hölder。它们**不需要新的 Hölder 论证**：代入 `Y ↦ W^{1/(2p)}·Y`（`wscale`）、`Q ↦ W^{1/p}·Q`（`wscaleQ`）后，`(W^{1/(2p)})^{2p} = W`，于是 T191 的 `integral_pow_sub_one_mul_le` / `integral_pow_sub_two_mul_le` 原封不动地给出

* `integral_weight_pow_sub_one_mul_le`：`∫ W|Y|^{2p−1}|Z| ≤ (∫W|Y|^{2p})^{(2p−1)/(2p)} · ‖Z‖_{W,2p}`，
* `integral_weight_pow_sub_two_mul_le`：`∫ W|Y|^{2p−2}Q ≤ (∫W|Y|^{2p})^{(p−1)/p} · rateNormW P W p Q`，

## 2. `hbound`：(★) 三项各就各位

`momFlowDeriv_le` 的结论就是 (G) 的 `hbound`：

```
momFlowDeriv ≤ 2p·φ^{(2p−1)/(2p)}·(‖G‖_{W,2p} + Bc) + p(2p−1)·φ^{(p−1)/p}·rateNormW P w p Q
```

* **漂移 + 二阶**：`driftPart_add_qvPart` 先把两项**合成一个加权积分** `∫ w ω·((∂₁Ψ).re + genPt)`（`genPt d N Φ M = 2⁻¹∑_α S_α (∂_α²Φ)(M).re`，`genPt_momentFun` 说明它在 `Φ = |F|^{2p}` 处就是 `Gauss.genMomentPt`），可积性由 `integrable_genIntegrand` 给；然后两条加权 Hölder。逐点被积函数的界 `hle` 是假设——**与未加权路线（`Gauss.integral_le_holder_sum_of_bdd` 的 `hle`）同一条**，由 T214 那条逐点引理供给，不是新东西。
* **交叉项**：`hcross`，由 §3 交割。

⚠ 可满足性加强：`hle` 写成**带权形式** `∀ ω, w ω·LHS ≤ w ω·RHS`（不是 `∀ ω, LHS ≤ RHS`）。这样在 `w ω = 0`（软截断在好事件外恰好为 `0`）处它是 `0 ≤ 0`，于是 `Q` 可以取**带指示函数的** `qvRateEvolvedOn`（好事件外为 `0`）而不产生空真。

## 3. (b) `hBbd`：交叉项 → `crossInt κ̂ Q̂ u`

链条（三步，全是定理）：

1. **`crossPart_le_integral`**：`crossPart ≤ (2√u)⁻¹·∫ ∑_α S_α |∂_α w|·‖∂_αΦ‖`（`Complex.re_le_norm` + `norm_integral_le_integral_norm` + `integral_finsetSum`，可积性由 `integrable_crossSum`）。
2. **`crossPart_le_of_S5`**（核心）：接 T265 的 (S5) `sum_gvar_crossTerm_le`（**逐点、同一矩阵变量**）。结论
   `crossPart ≤ ½·(Cs·Rbd)·φ^{(2p−1)/(2p)}`。
   中间用到新引理 `integral_wscale_pow_sub_one_le`：`∫|W^{1/(2p)}Y|^{2p−1} ≤ φ^{(2p−1)/(2p)}`（就是 `Z ≡ 1` 的 Hölder，概率测度上 `momNorm P (2p) 1 = 1`）。
3. **`crossPart_le_budget`**：把它改写成 `hbound` 吃的形状 `crossPart ≤ 2p·φ^{…}·Bc`，`Bc = Cs·Rbd/(4p)`。

**`hBbd` 本身**：

* `crossBudget_le_crossInt`：`c·(√(u_j/u)·√(Q̂_u)) ≤ crossInt κ̂ Q̂ u`，用 T271 的 `sqrt_div_le_sqrt_inv`（`√(u_j/u) ≤ u^{−1/2}`，`u_j ≤ 1`）——**`u^{−1/2}` 就是从这里来的**，`hfit : c² ≤ κ̂` 把常数吸进 `κ̂`。
* `crossBudget_le_crossInt'`：同一结论的另一读法，用 T271 的 `inv_two_sqrt_le_sqrt_inv`（`(2√u)⁻¹ ≤ u^{−1/2}`）。两条都给，因为 T271 §4 把两条义务并列。
* `crossBudget_le_crossInt_model`：`(Cs₀·√(u_j/u))·√(Q̂_u)/(4p) ≤ crossInt κ̂ Q̂ u` —— **字面就是 `Bcr u ≤ crossInt κ̂ Q̂ u`**，唯一剩下的是 `hfit : (Cs₀/(4p))² ≤ κ̂`，两个显式确定数之间的不等式（可核、无 `ω`、无 `∃C`）。

### 3.1 空真检查（本单最花心思的地方）

`crossPart_le_of_S5` 的每一条可能在好事件外为假的假设都**被限制在事件上**：

* `hwD`（链式法则 `|∂_α w| ≤ √u·‖∂_α W_mat(H_u)‖`）：`∀ ω ∈ Good`；
