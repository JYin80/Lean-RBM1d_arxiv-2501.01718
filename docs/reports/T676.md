## Statements and proof

Define `permutationFourierSum W x χ π = (∑ i, χ i * x (π i)) / W`. The domain-position swap is `(Equiv.swap j k).trans π`, so the exact difference, with its sign fixed, is

```text
F((swap j k).trans π) - F(π)
  = (χ j - χ k) * (x (π k) - x (π j)) / W.
```

The proof isolates `j` and `k` in the finite sum and handles `j = k` separately. If `W ≥ 2`, all `‖x i‖ ≤ 2`, and all `‖χ i‖ ≤ 1`, the two differences have norms at most 4 and 2, giving `‖F(swapped)-F(π)‖ ≤ 8/W`. This bound is sharp for `W=2`, `x=(2,-2)`, `χ=(1,-1)`, `π=id`, `j=0`, `k=1`; the code checks the bounds, nonconstancy of both tables, and equality with `8/2=4`.
