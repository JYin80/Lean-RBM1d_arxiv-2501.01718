# T511 — exact two-charge stochastic-domination transfer

## Result

Added `RBM1D/Gauss/APrimeGeneralMovingChargeTransfer.lean`.

The module defines the real observable

```text
traceNorm(E,N,u,sigma,b,omega)
  = ‖centeredTrace(E,N,u,omega,sigma,b)‖
```

and proves for every size, real time, block, and sample that

```text
traceNorm(E,N,u,false,b,omega)
  = traceNorm(E,N,u,true,b,omega).
```

This is exactly T501's all-sample conjugation identity at the norm level.
It has no event restriction and introduces no factor in `N`, `W`, time, or
the control.

## Transfer interfaces

The module exports exact plus-to-minus transfers at the identical control:

* `selector_stochDom_false_of_true` for a deterministic selector
  `u : Nat -> Real`, uniformly in the block index;
* `unifDomIcc_false_of_true` for the public moving-window `UnifDomIcc`
  interface;
* `stochDom_timeIcc_false_of_true` for the public `StochDom` interface with
  `TimeIcc s t N × ZMod (L N)` inside the index set.

`selector_badSet_false_eq_true` additionally states that the two selector
failure sets are literally equal for every exponent and size.  The transfer
proofs use pointwise equality and `StochDom.of_le_left` or
`UnifDomIcc.of_le_left`; they perform no two-charge union bound and introduce
no event.

## Nondegenerate witness

`positive_length_same_good_charge_transfer_witness` reuses T501's parameter
tuple and the identical `APrimeGeneralMovingGoodMesh.good` event.  It retains:

* eventual positive window length;
* measurability and `HighProb` of the event;
* all-size event nonemptiness;
* the pointwise plus/minus norm identity on that same event and window.

No new hypothesis is introduced.

## Scope

This module is only a charge-transfer bridge.  It takes a plus-charge
`StochDom` or `UnifDomIcc` result as an input and does not claim that the plus
bound or an all-time bound has already been proved.  Those inputs remain the
responsibility of the fixed-selector and time-net chain.
