## Exact candidate

With `open MeasureTheory ProbabilityTheory` and `open scoped MeasureTheory`, the following statements typecheck against the current core, T776, and T785. The singleton statement is the primary target; the finite-set statement is the corresponding full distribution on the finite image space.

```lean
∀ (W : ℕ) (k : Fin W) (v : Fin W),
  (uniformPerm W)[(fun ρ : PermΩ W =>
      if ρ k = v then (1 : ℝ) else 0) | prefixSigma W k.val]
    =ᵐ[uniformPerm W]
  (fun π : PermΩ W =>
    if v ∈ unusedImages W k π
    then (1 : ℝ) / ((W - k.val : ℕ) : ℝ) else 0)

∀ (W : ℕ) (k : Fin W) (A : Finset (Fin W)),
  (uniformPerm W)[(fun ρ : PermΩ W =>
      if ρ k ∈ A then (1 : ℝ) else 0) | prefixSigma W k.val]
    =ᵐ[uniformPerm W]
  (fun π : PermΩ W =>
    ((A.filter (fun v => v ∈ unusedImages W k π)).card : ℝ) /
      ((W - k.val : ℕ) : ℝ))
```

These assert almost-everywhere equality of real-valued conditional expectations, the natural `condExp` conclusion. They do not assert a pointwise equality for a chosen representative. The finite-set statement can follow by finite additivity from the singleton statement, or directly by summing the cell quotients.

## Actual producers and required proof obligations

1. T711 defines `PermΩ W := Equiv.Perm (Fin W)`, the ambient measurable space `⊤`, `uniformPerm W := uniformOn univ`, and `prefixSigma W k := generateFrom (prefixCylinders W k)`, where a cylinder fixes `π i = v` for `i.val < k`. The actual cell `prefixCell W k π` consists of permutations agreeing with `π` at those positions. The cell measurability producer is `measurableSet_prefixCell` (T732). Thus `prefixSigma W k.val ≤ ⊤`.
2. T776 proves the event-on-actual-cell quotient as a finite fiber-cardinality ratio, proves its cell mass positive and finite, and gives zero for a used image. T785 proves `(unusedImages W k π).card = W-k.val`; `k.isLt` makes this denominator strictly positive. These do **not** establish a conditional expectation.
3. **Pending T792:** identify `@measurableAtom (PermΩ W) (prefixSigma W k.val) π` with the actual cell. This supplies the precise atoms over which the `prefixSigma`-measurable sets are unions. Do not replace this with an ambient `⊤` atom (a singleton).
4. **Pending T795:** for every *unused* `v`, obtain the exact ENNReal quotient `P(C_k(π) ∩ {ρ | ρ k=v}) / P(C_k(π)) = 1/(W-k.val)`. For used `v`, use T776's zero theorem. Convert the quotient to a real integral ratio only after proving the finite positive cell mass and positive finite denominator; this avoids a `0/0` or `∞/∞` simplification.
5. Prove that the displayed right-hand function is `prefixSigma`-measurable: the predicate `v ∈ unusedImages W k π` is a finite conjunction of complements of generating coordinate cylinders, hence constant on each actual prefix cell. It is bounded by one, so it is integrable. The input indicator is also bounded and integrable under the probability measure.
6. Partition any `prefixSigma`-measurable set into its finitely many actual atoms, and use the cell quotient on each atom to show equality of set integrals. Then apply Mathlib's `ae_eq_condExp_of_forall_setIntegral_eq` (in the symmetric orientation) to get the `=ᵐ` statement. Its prerequisites include `SigmaFinite ((uniformPerm W).trim (show prefixSigma W k.val ≤ ⊤ from le_top))`, which was inferred in the probe. This uses the characterization of `condExp`, not the target law as a hypothesis.

No arbitrary, inconsistent prefix is quantified: each cell is centered at an actual `π` and has positive mass. On a null atom in a more general sample space, conditional expectation determines values only almost everywhere; one may conventionally set the quotient to zero there, but no pointwise null-atom formula follows from this target. There are no null actual cells here.

## Boundary and nondegeneracy checks

- `W=0`: `Fin 0` has no `k`; the next-image statement has no instance. The sole permutation and its prefix atoms exist, but no next image exists.
- `W=1`, `k=0`: one unused image, denominator one, and its conditional probability is one.
- `W=2`, `k=0`: identity and swap are distinct actual samples in the same unrevealed atom. Both image values have mass `1/2` inside that atom, so the proposed law is genuinely random and not vacuous.
- `W=2`, `k=1`: the remaining image has conditional probability one; the already used image has probability zero. Identity and swap give opposite remaining images.
- Last valid reveal `k.val+1=W`: T785 gives exactly one unused image; its probability is one and every used image has probability zero. `k=W` is excluded by `k : Fin W`.
