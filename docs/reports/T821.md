# T821 — preflight of two successive unused images on an actual prefix cell

## Verdict: PASS for the exact finite quotient

The proposed statement is well typed in `RBM.Gauss` with `open MeasureTheory ProbabilityTheory`:

```lean
theorem uniformPerm_two_successiveImages_given_actualPrefix
    (W : ℕ) (k j : Fin W) (π : PermΩ W) (v w : Fin W)
    (hj : j.val = k.val + 1)
    (hv : v ∈ unusedImages W k π)
    (hw : w ∈ unusedImages W k π) (hne : v ≠ w) :
    uniformPerm W {ρ | ρ ∈ prefixCell W k.val π ∧ ρ k = v ∧ ρ j = w} /
      uniformPerm W {ρ | ρ ∈ prefixCell W k.val π} =
        (1 : ENNReal) /
          (((W - k.val : ℕ) : ENNReal) *
            ((W - k.val - 1 : ℕ) : ENNReal))
```

The notation `W - k.val - 1` is natural-number subtraction, parsed left associatively. Since `j : Fin W` and `j.val = k.val + 1`, we have `k.val + 2 ≤ W`; thus both natural denominators are strictly positive. The exact statement needs all three image assumptions. Values used before `k`, and the case `v = w`, have zero event mass and are deliberately excluded; any later all-pairs law should state those zero cases separately.

## Boundary and satisfiability checks

- `W=0` and `W=1` admit no `k,j : Fin W` with `j.val=k.val+1`.
- `W=2`, `k=0`, `j=1`, `π=id`: `unusedImages 2 0 π={0,1}`. The ordered pairs `(v,w)=(0,1)` and `(1,0)` select the identity and swap permutations, respectively. The actual empty-prefix cell has two members and mass one; each selected event has one member and mass `1/2`, exactly the proposed denominator `2·1`. Both events are positive, so the theorem is nonvacuous.
- At the last eligible `k=W-2`, `j=W-1`; the second factor is `W-k.val-1=1`, never zero. The theorem then reduces to the first unused-image probability `1/2`.
- For general admissible parameters, the chosen `π₁` and a second positive fiber at `j` give a resident of the two-image event. The conditioning cell has positive finite measure, so the displayed quotient is never `0/0`.
