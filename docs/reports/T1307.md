## Proof route and output

`moving_hfamily_of_same_actual_coordinate_input` proves that, for every
`p : ℕ`, there is `C > 0` such that eventually, uniformly over all active
cells `k`, including `k = 0`,

```text
∫ widenedW(λ,p) ·
    |cutTrunc(N^(2λ), jSnorm at the moving endpoint)|^(2p) dP_band
  ≤ C N^(λ p/2).
```

For `p ≥ 1`, the proof applies the endpoint-maximum estimate to the finite
coordinate family, transfers each coordinate moment by the accepted
same-loss cross-order weight comparison, and uses
`card(LoopArg (L_N) 2) ≤ N²`. The choice `q ≥ ceil(16/λ)` absorbs this
`N²` cost, yielding a high moment scale `N^(7λ/32)`. Weighted Lyapunov lowers
the moment from `q` to `p`, and raising back to power `2p` gives exponent
`7λp/16 ≤ λp/2`. The `p = 0` branch is handled separately using
`0 ≤ widenedW ≤ 1` and the band probability measure.

The nondegenerate witness uses the existing `E = 0`, `D = 60` positive-length
window and gives an active first cell with a common-event sample where the
widened weight is one and the actual smooth weight is positive. This witnesses
the model, loss-window, and weight geometry. It **does not** establish or
witness `UniformSameActualCoordinateInput`; that coordinate moment estimate
remains the theorem's explicit external premise. Accordingly, the result must
be consumed conditionally.
