# T752 — uniform first-image law

## Files and scope

Added `RBM1D/Gauss/PermutationFirstImageUniform.lean` and this report only.
The module imports T711's `PermutationPrefixFiltrationCore` and T721's
`PermutationFiberFirstPartition`; T721 transitively uses T703's equal fiber
cardinality result. No shared file or root import was changed.

## Result

For every positive width `W` and every `v : Fin W`,

```lean
uniformPerm W {π | π ⟨0, hW⟩ = v} = (1 : ENNReal) / (W : ENNReal)
```

is proved by `uniformPerm_firstImage`. For `W ≥ 2`, T703 gives equal cardinality
for all the `k=0` fibers (the unused-before-prefix conditions are vacuous), and
T721's first-image equivalence gives their cardinal sum as the full permutation
cardinality. The event is identified with its corresponding fiber, and
Mathlib's `uniformOn_univ` counting formula converts this ratio into the
probability. For `W=1`, T721's singleton-fiber count gives mass one directly.

The theorem has no added assumptions beyond `0 < W` and `v : Fin W`. At `W=0`
there is no `v : Fin 0`, so the statement correctly has no instance. The
`uniformPerm_firstImage_two_witness` records the two distinct width-two
permutations (identity and transposition), their different first images, and
mass `1/2` for each event. These events are therefore nonempty and distinct.

This is only the first-image case `k=0`. It does not assert a conditional law
after an arbitrary prefix, nor any `N`/time scaling, first-cell/shared-event,
Doob, Azuma, P2, or paper local-law result (2.3)–(2.4).
