# T401 — unconditional all-time first-cell control of the actual block `jG`

## Claim and verdict

**Proved as written, in the mathematical sense.** For the actual Gaussian
sample `Gauss.sample d`, with `d = Gauss.Dims.exampleGrow`, there is a measurable
event family `E_N` with `HighProb (Gauss.P d) E` such that, eventually in `N`,

```text
for every omega in E_N and every u in [0, 1/2],
  1 <= APrimeJG.jG (Gauss.sample d) 0 N u omega ell_u eta_u 60 <= 2 <= N.
```

Thus the same bound holds at every real running time in
`[0, firstCellT tau N]`, for the very same `tau > 0` that supplies the Step-1
source events. Intersecting `E_N` with T398's all-time source event preserves
measurability, high probability, and eventual positive probability. There is
no positive-weight or A-prime hypothesis.

The proof is a finite-dimensional weighted resolvent calculation, with a
constant bound on each adjacent off-diagonal Gaussian block proved by an
explicit finite-net argument. Neither a new local-law theorem nor a
bootstrap conclusion is used. The missing result identified by T398 was a
missing proved producer in the inspected route; it is not a false
mathematical assertion or a remaining mathematical obstruction on this first
cell. This report supplies the derivation. It does not claim that the new
producer is already formalized in Lean.

Write `W=d.W N`, `L=d.L N`, and
`dist(a,b)=zdist L (a-b)`, the cycle graph distance. Let `X_ab` denote the

```text
H_u = sqrt(u) X,  z_u = i(1-u),  eta_u = 1-u,
S_ij = 1/(3W) if dist(block(i),block(j)) <= 1, and 0 otherwise.
```

Here `H_u=sqrt(u)X` is the repository's Gaussian moment-route coupling. It is
not an assertion about a Brownian sample path. The assigned claim is exactly
about this coupling.

For `0 <= u <= 1/2`, `L >= 3` makes the length cap inactive, so

```text
ell_u = (1-u)^(-1/2),       1 <= ell_u <= sqrt(2),
1/2 <= eta_u <= 1,         A_u = W sqrt(1-u) in [W/sqrt(2), W].
```

In particular `ell_0=1`. The first cell has left endpoint exactly zero and
right endpoint at most `1/2`; for every fixed positive `tau` it eventually
has right endpoint exactly `1/2`. It is not the tiny test time `N^(-248)`.

With `G^sigma_u=(H_u-z^sigma_u)^(-1)`, the actual definitions are

```text
gmBlk_u(a,b) = max_(sigma,p,q) |G^sigma_u((a,p),(b,q))|,
```

The Lean maximum inserts zero for non-far pairs, so an empty far range gives

`W^(-D)`, not `N^(-D)`. We preserve both. The maximum includes a neighbor of
the first block; its distance cost is exactly one block below.

## 2. A measurable event with an explicit probability estimate

An arbitrary point of the product sample space can have nonzero coordinates
whose Gaussian variance is zero. Therefore matrix band support must be
included in the event; it is not a pointwise property of every `omega`.
Let

```text
S_N = {omega : X_ab(omega)=0 whenever dist(a,b)>1},
B_N = {omega : ||X_ab(omega)||_op <= 8
               whenever a != b and dist(a,b)<=1},
E_N = S_N intersect B_N.
```

All conditions are finite in `N`. Entries depend continuously on finitely
many coordinate evaluations, and finite-dimensional operator norm is
continuous, so these sets are measurable. On every coordinate contributing
to an off-band entry, `gvar=0`; its law is `gaussianReal 0 0`, the point mass
at zero. A finite intersection gives `P(S_N)=1`.

For a fixed pair of distinct adjacent blocks `a,b`, all `W^2` entries of
`X_ab` are independent centered circular complex Gaussians with
`E|X_ab(p,q)|^2=1/(3W)`. This follows directly from the injective upper-pair
coordinate map in `Xentry`; reversing the block order conjugates the
entries and preserves the assertion. In particular, for deterministic unit
vectors `v,w` in `C^W`,

```text
Z = <v,X_ab w>,
Var(Re Z) = Var(Im Z) = 1/(6W).
```

For completeness, the Gaussian moment-generating function is
`E exp(t Re Z)=exp(t^2/(12W))`. Exponential Markov with
`t=6W s` gives `P(Re Z>s)<=exp(-3W s^2)`; applying it also to the negative
tail and to the imaginary part yields

```text
P(|Z|>r) <= 4 exp(-(3/2) W r^2).                         (T401.1)
```

Take a `1/4`-net `V` of the unit sphere of `C^W`, viewed as `R^(2W)`, with
`|V|<=9^(2W)`. This bound follows by packing disjoint radius-`1/8` balls
around a maximal separated set inside the radius-`9/8` Euclidean ball.
For any complex matrix `M`, approximating both unit vectors in a maximizing
bilinear form gives

```text
||M|| <= max_(v,w in V) |<v,Mw>| + (1/2)||M||,
so ||M|| <= 2 max_(v,w in V) |<v,Mw>|.
```

Consequently (T401.1), with `r=4`, and a finite union bound give

```text
P(||X_ab||>8) <= 4 exp(-(24-4 log 9)W).
```

There are at most `2L` oriented off-diagonal neighboring block pairs.
Independence between these pairs is unnecessary. With
`c0=24-4 log 9>15`,

```text
P(E_N^c) <= 8 L exp(-c0 W).                              (T401.2)
```

The dimension hypotheses imply `L<=N` and `W>=N^(1/2+c)` eventually for
some fixed `c>0`. Thus for every fixed requested failure exponent `M>0`,

```text
8 L exp(-c0 W) <= 8 N exp(-c0 N^(1/2+c)) <= N^(-M)
```

eventually. This proves `HighProb E`. The event is independent of `M`, the
time parameter `u`, the first-cell parameter `tau`, the source losses, and
the floor exponent `D`. Only the eventual threshold for the tail bound
depends on `M`. No all-moments-at-fixed-N quantifier is involved.

Only adjacent off-diagonal blocks are bounded here. Diagonal blocks do not
enter the weighted perturbation below and need no norm hypothesis.

## 3. Deterministic exponential decay on the entire interval

Fix `omega in E_N`, `u in [0,1/2]`, and a target block `b`. Set

```text
alpha = log(65/64) > 0,
f(a) = dist(a,b),
D_b = direct_sum_a exp(alpha f(a)) I_W.
```

This is an invertible finite matrix, even when `L` is large. The metric
triangle inequality gives `|f(a)-f(a')|<=1` whenever `a,a'` are adjacent,
including the edge across the cycle boundary. Put

```text
K = D_b H_u D_b^(-1) - H_u.
```

Its diagonal blocks vanish exactly. Its off-band blocks vanish because
`omega in S_N`. Each remaining block satisfies

```text
||K_aa'||
 <= (exp(alpha)-1) sqrt(u) ||X_aa'||
 <= (1/64) * 8 = 1/8.
```

There are at most two such blocks per row and column. To check that this
does not cost a factor `W` or `L`, write a vector as `(v_a)_a` and use

```text
||(Kv)_a|| <= (1/8)(||v_(a-1)||+||v_(a+1)||),
sum_a ||(Kv)_a||^2 <= (1/16) sum_a ||v_a||^2.
```

The last inequality uses `(x+y)^2<=2(x^2+y^2)` and the two permutation
reindexings of the cycle. Therefore `||K||<=1/4`.

For either charge, Hermiticity and `|Im z_u^sigma|=eta_u>=1/2` give
`||G_u^sigma||<=2`. Hence

```text
||K G_u^sigma|| <= 1/2,
||(H_u-z_u^sigma+K)^(-1)||
 <= ||G_u^sigma|| / (1-||K G_u^sigma||) <= 4.
```

This is just the convergent geometric series for `I+K G_u^sigma`; no
external decay theorem is assumed. Similarity gives

```text
D_b G_u^sigma D_b^(-1) = (H_u-z_u^sigma+K)^(-1).
```

Taking its `(a,b)` block, using `f(b)=0`, and bounding a block compression
by the whole operator norm proves

```text
||G_u^sigma[a,b]||_op <= 4 exp(-alpha dist(a,b)),
gmBlk_u(a,b) <= 4 exp(-alpha dist(a,b)).                  (T401.3)
```

This calculation is deterministic for every `u` in the closed interval,
on the single event `E_N` already chosen. There is no time net, uncountable
union bound, differentiability assumption at zero, or loss in the number
of times. Both charges are handled by the same Hermitian matrix and the
same event.

## 4. The exact `jG` cap and the floor ledger

For `SB(a,a') != 0`, `dist(a,a')<=1`; therefore, with `r=dist(a,b)`,
`dist(b,a')>=r-1`. Applying (T401.3) twice gives

```text
gsqBlk_u(a,b) <= 16 exp(-2 alpha (r-1)).                 (T401.4)
```

The bound includes the neighbor `a'=a` and every allowed shift. There is
no diagonal issue in a far pair once `ellStar/2>1`, since then `a'!=b`.
In fact (T401.4) is valid even before making that eventual restriction.

For a far pair and any fixed `D>=0`, use only the positive floor
`T_u,D(r)>=W^(-D)`, and then `ell_u>=1`:

```text
gsqBlk_u(a,b)/T_u,D(r)
 <= 16 exp(2 alpha) W^D exp(-2 alpha r)
 <= 16 exp(2 alpha) exp(D log W-alpha (log W)^(3/2)).     (T401.5)
```

The last expression is uniform in `u,a,b,omega`. For `D=60` a completely
explicit sufficient eventual condition is

```text
log W >= (61/alpha)^2,  and  W >= 16 exp(2 alpha).
```

Indeed `alpha sqrt(log W)>=61`, so (T401.5) is at most
`16 exp(2 alpha)/W<=1`. The maximum over non-far pairs contributes zero,
and hence `1<=J_u,60<=2` for all running times on `E_N`. Since `W->infinity`
and `N>=2` eventually, this proves the requested `J_u,60<=N`.

More generally, for every fixed `D,K>=0`, the same event gives
`sup_(u in [0,1/2]) (J_u,D-1)<=W^(-K)` eventually, by replacing `61` with
`D+K+1`. This is an asymptotic statement with a threshold depending on
`D,K`. It is not a simultaneous assertion for all `D` at a fixed size.

At `u=0`, `H_0=0` and both resolvents are diagonal. For all sufficiently
large `W`, every far pair remains off diagonal after the one-neighbor
shift, giving the exact identity `J_0,D=1`. At `u=1/2`, the resolvent norm
bound is still exactly `2`; the proof includes that endpoint. If the cycle
is too short to contain a far pair, the definition gives `J=1` directly.

## 6. Why the previously inspected route stopped

`GoodEvent` is a max-entry local law. On its own it has no spatial decay;
dividing its off-diagonal bound by `W^(-60)` can lose roughly `W^59`.
The universal resolvent bound alone similarly gives only
`J<=1+4W^60` on this cell. Those bounds do not meet T357's budget.

The exact accepted `EntryBoundFlow'` contains both the diagonal-neighbor
term `W^(-1) 1_(dist<=1)` and the additive floor `2N^(-D)`. The diagonal
term disappears in the far geometry. The resulting theorem
`APrimeJG.highProb_jG_le_of_entryBoundFlow` is

```text
J_u <= 1 + N^epsilon (9 exp(sqrt(3)) jS_u + 2).
```

It leaves the actual `jS_u` present. T388 controls that quantity only on
positive active support. Inferring an unconditional all-time cap from this
chain without another estimate would be unjustified. The first-time
continuity argument also does not extend from `N^(-248)` to `1/2`.

The successful additional ingredient here is the elementary Gaussian
block norm event plus deterministic finite-range resolvent decay. It is
stronger information than the bare fixed-power norm event `||X||<=N`.
It follows from the actual Gaussian model directly and costs only the
explicit exponentially small probability (T401.2).

The zero-variance support restriction is essential for a pointwise event
statement: arbitrary product-space samples can create long-range matrix
entries. Such samples have probability zero. Including `S_N` removes them
without changing the probability estimate.
