## ⭐ `modulus` 的四步（这是本单的数学内容）

论文的 `J*` 与 T257 已有的 `jSfarSm` 差两件事：**远场权重 `χ`** 与 **随时间变的归一化 `R_u^{−4}`**。

1. `abs_jS_sub_le` —— `Finset.sup'` 传递，照搬 `Step2FarMart.abs_jSfarSm_sub_le`。
2. `abs_jS_sub_le_of_lk` —— **对 loop 输入 `(Λ, γ)` 不可知**，同 `abs_jSfarSm_sub_le_of_lk`。
   关键观察：`abs_lkFarSm_ratio_sub_le` 把带权差拆成「权重项 + 无权比值项」，而 `ratio_step_le`
   界的正是二者之和；**权重项非负**，所以同一个常数 `jSfarSmLip + Λ·W^D` 直接可用于无权的 `jS`
   （`le_trans (le_add_of_nonneg_left _) hstep`，不需要重证 `ratio_step_le`）。
3. `abs_jS_sub_le_event` —— 取 `(Λ, γ) = (lkLipEv, 1/2)`，事件 `{‖X‖ ≤ N}`，**允许 `v = w = 0`**（D17）。
4. `abs_jSnorm_sub_le_event` —— 把 `R_u^{−4}` 装回去：
   `jSnorm = jS·ρ_u`，`ρ_u = ((1−u)/(1−s_N))^4`（`jSnorm_eq_mul`）；
   `jSnorm_v − jSnorm_w = (jS_v − jS_w)ρ_v + jS_w(ρ_v − ρ_w)`，
   其中 `ρ_v ≤ 1`（`rhoS_le_one`，用到 `s_N ≤ v`）、`|ρ_v − ρ_w| ≤ 4(1−t₀)⁻¹|v−w|`（`abs_rhoS_sub_le`，
   经新证的 `abs_pow4_sub_le`）、`jS_w ≤ W^D·crudeLk + 1`（`jS_le_crude`，由 `jS_le_of_bdd` + `norm_lk_le_crude`）。
   常数记作 `jTotNormEv = jSfarSmLip + lkLipEv·W^D + 4(1−t₀)⁻¹(W^D·crudeLk + 1)`。

`exists_const_jTotNormEv` 把它压到 `K·N^{1+2D}`（在 `exists_const_jTotEv` 上补一项，用 `crudeLk = W⁻¹(q²+r)`），
于是 `eventually_modulus_jSnorm_event` 得到 **`Kmod = 2+2D`、`γ = 1/2`**，与 `jSfarSm` 的事件路线**完全同指数**。
该定理对**任意** `Good N ⊆ {‖X‖ ≤ N}` 成立 —— 这正是 (b) 需要的自由度。

## 可满足性 / 空真自查

1. **没有任何 `∀ ω` 的确定性 size 界**：`eventually_modulus_jSnorm_event` 的模量只对 `ω ∈ Good N` 断言，
   且 `Good N ⊆ {‖X‖ ≤ N}`。工单点名的陷阱（`APrimeHyp.modulus` 是 `∀ω` 的、对 `jSnorm` 为假，T249）**未触碰**：
   本文件只产 `APrimeHypOn`，从不产 `APrimeHyp`。
2. **`ω = 0` 心算**：`H = 0`、`G = −z⁻¹`，`‖X‖ = 0 ≤ N`，落在 `Good` 里；模量此时两边都有限、不矛盾（`zero_mem_normX_le` 编译）。
   **「大常数倍单位阵」心算**：`‖X‖` 大到超过 `N` 时该点直接落在 `Good` 外，模量不作断言 —— 这正是 T249 反例逃逸的方向。
3. **渐近条件都是 `∀ᶠ N`**（`modulus`/`mesh_fine`/`card_le`/`levpoly`），没有 `∀ p N` 形。
4. **反「更易满足」证书**：`APrimeSlot.toPrime` 编译（旧槽 ⟹ 新槽）；`aprimeSlot_of_aprimeSlot'` 编译（新槽 + (2.69) ⟹ 旧槽），
   两向都在，所以删 `init` 不是偷偷放宽结论。
5. `jS_le_crude` / `jS_le_of_bdd` 都是**每个 `ω`** 的界，但它们是**上界**（`‖lk‖ ≤ W⁻¹(η⁻²+(1−t₀)⁻¹)` 是
   `norm_green_le` 的确定性推论，对所有 `ω` 真），不是 size 假设，不会造成空真。
