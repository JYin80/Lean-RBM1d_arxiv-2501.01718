## What is proved

The module defines the concrete entry event as the union over both matrix indices, with threshold
`W^ρ * (zScale⁻¹)^(1/2)`, and the concrete block event as the union over all `ZMod (L N)` blocks,
with threshold `W^ρ * zScale⁻¹`. Both are measurable for every `d`, `N`, `z : ℂ`, and `ρ`.

The concrete `entryLocalLawXi/Zeta` and `blockLocalLawXi/Zeta` use
`(transfer_gauss d).Hband`; rewriting by `transfer_gauss_Hband` proves exact equalities of both
events with `Band.strictBadSet`. The resulting strict-bad sets are measurable for every `N`,
stronger than the eventual measurability premise of T844.

The block expression is formally checked by `blockLocalLawXi_normalized_sum_sub_center`: it is
`‖W⁻¹ * (∑ₓ Gₓₓ) - msc z‖`, so centering follows the normalized diagonal sum. The distinct entry
and block `zScale` powers are preserved.

`measurable_green_Xmat` applies `measurable_green_apply` at `u = 1` and rewrites
`Hflow d N 1 ω = Xmat d N ω`. This is only an algebraic measurability identity, not a flow local
law at terminal time. The proof uses finite unions and finite sums, without probability bounds.
