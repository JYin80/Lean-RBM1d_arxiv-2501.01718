## Decision

## Exact acceptance manifest

| Public declaration | Exact accepted statement |
|---|---|
| `RBM.CarrierCutoffTime.continuousOn_ell` | For every `B : Band Ω`, `N : ℕ`, real `a,b` and `hb : b < 1`, `ContinuousOn (fun u : ℝ => B.ell N u) (Set.Icc a b)`. |
| `RBM.CarrierCutoffTime.continuousOn_ellStar_half` | Under exactly the same parameters, `ContinuousOn (fun u : ℝ => ellStar (B.W N : ℝ) (B.ell N u) / 2) (Set.Icc a b)`. |

Theorems contain no sample, event, probability estimate, `a ≤ b` premise, or separate endpoint restriction. `Band.ell N u` unfolds to `ellHat (B.L N) (u : ℂ)`, and `ellHat L ξ = min (1 / √‖1-ξ‖) L`. For each `u ∈ Icc a b`, the proof uses `u ≤ b < 1` to show `1-u > 0`, hence the denominator is nonzero. The `ContinuousOn` statement includes `a` and `b` whenever the interval is nonempty. Its validity for an empty interval when `a>b` is harmless; the concrete nonempty witness below rules out using emptiness as the only content.

The paper's (5.27)–(5.29) define the deterministic tail and its ratio and then introduce `ℓ*_u = (log W)^(3/2) ℓ_u` for the far-pair scale. The source definition is exactly `ellStar W ℓu = Real.log W ^ (3 / 2 : ℝ) * ℓu`. The accepted second theorem retains this coefficient and the final `/ 2`; it asserts continuity only. `Band.W_pos N` ensures `0 < (B.W N : ℝ)` for every `N`. Positivity is part of `Band`, although continuity of multiplication by the fixed real coefficient does not require using it in the proof.

The hypotheses are realized with `a=0`, `b=1/2`, and `B=Gauss.band Gauss.Dims.exampleGrow`: `0 < 1/2 < 1`, and the interval has distinct included endpoints. `Dims.exampleGrow` is a constructed `Dims` with positive `W`, `L≥3`, `c=1/8`, and the required eventual dimension/bandwidth laws; `Gauss.band` transfers its fields to `Band`. Thus there is no hidden inconsistent `Band` premise or vacuous interval in this instance.
