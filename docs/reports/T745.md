# T745 — prefix sigma-algebra boundary

## Scope and relation to the paper

Added `RBM1D/Gauss/PermutationPrefixSigmaBoundary.lean`, importing only the accepted T711 core, and this report. The paper's local semicircle laws (2.3)–(2.4) are probabilistic Green-function estimates. This module proves only the finite-information boundary for the permutation prefix filtration underlying that later setup; it claims no conditional distribution, local law, probability estimate, or paper closure. No root import or other source file was changed.

## Statements established

* `prefixSigma_zero_eq_bot`: for every width `W`, `prefixSigma W 0 = ⊥`. The proof shows there are no coordinate cylinders with index `i.val < 0`, so the generated sigma-algebra is bottom.
* `prefixSigma_zero_width_eq_bot`: explicitly records the `W = 0` boundary.
* `firstCoordinateZeroEvent_measurable_one` and `firstCoordinateZeroEvent_not_measurable_zero`: for `W = 2`, the event `{π | π 0 = 0}` is measurable after revealing the first coordinate and is not measurable at time zero.
* `firstCoordinateZeroEvent_two_witness`: the identity belongs to this event and the transposition `swap 0 1` does not.
* `prefixSigma_two_zero_lt_one`: the time-zero sigma-algebra is strictly below the one-coordinate sigma-algebra, by the event distinction above.
