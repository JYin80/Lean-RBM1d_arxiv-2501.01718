# T741 — positive support for an actually realized prefix fiber

## Scope and paper relation

Added `RBM1D/Gauss/PermutationActualPrefixFiberSupport.lean`. The module imports
only `RBM1D.Gauss.PermutationFiberCount` (T703), whose import chain includes
the accepted T694 fiber definition and swap equivalence. No root import or
existing declaration was changed.

Paper formulas (2.3)–(2.4) state probabilistic local semicircle and partial
tracial local laws. This module proves only the finite support fact needed by
later conditional-exposure work; it asserts none of those probability bounds,
and introduces no probability, denominator, or conditional-law statement.

## Results

For every `W`, `k : Fin W`, prefix map `p`, and permutation `π` agreeing with
`p` below `k`, `permutationPrefixFiber_actual_mem` exhibits the subtype element
`⟨π, hπ, rfl⟩` in `permutationPrefixFiber W k p (π k)`. Consequently,
`permutationPrefixFiber_actual_card_pos` proves that fiber's finite cardinality
is strictly positive. The result is explicitly restricted to the value `π k`
of an existing agreeing permutation; it makes no positivity claim for an
arbitrary inconsistent prefix or arbitrary next image.

Boundary witnesses are included: `Fin 0` is empty, so there is no `k` at
`W=0`; at `W=1` the empty-prefix fiber has cardinality one for every prefix
map; at `W=2`, the identity and transposition realize the distinct `0` and
`1` fibers at `k=0`, and both have positive cardinality. The W=2 cardinality
fact reuses T703's explicit identity/swap witness.
