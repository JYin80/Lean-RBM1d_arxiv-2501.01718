# T232 — `CutHyp` 的 `modulus`/`mesh_fine` 改成 `∀ᶠ N`

**文件**：`RBM1D/Gauss/MomentDuhamelCut.lean`、`RBM1D/Gauss/CutHypTheta.lean`
**验收**：`lake build RBM1D` exit=0，公理审计 12333 条，全部 `[propext, Classical.choice, Quot.sound]`，0 `sorry`、0 `axiom`。
**paper-delta**：`T232a`。

## 做法

**没有就地弱化原结构**。`CutHyp`/`CutHyp'`/`CutHypCond` 的字段照原样保留，因为
`RBM1D/Hierarchy/Step2FarMart.lean:1782/1783` 是一条**已经成立的定理**在消费它们，
改字段会让那条定理当场不类型检查（该文件对本单只读）。

改法是**并存**：新增 `CutHypEv`（`MomentDuhamelCut`）、`CutHypEv'`、`CutHypCondEv`
（`CutHypTheta`），把 `modulus` / `mesh_fine` 共六处字段的 `∀ N` 换成 `∀ᶠ N in atTop`，
并给出单向特化 `CutHypEv.of_cutHyp` / `CutHypEv'.of_cutHyp'` / `CutHypCondEv.of_cutHypCond`，
以及全套下游消费者的 `Ev` 版（`stochDom_of_cutHypEv`、`stochDom_of_cutHypEv'`、
`stochDom_of_condMomentEv`、`jS_stochDom_cutEv`、…）。共 67 条新声明。

## 弱化是严格的（编译的否定结果）

`sat_modulus_not_forall`、`sat_no_cutHyp`、`sat_no_cutHyp'`、`sat_no_cutHypCond`：
取论文允许的、**时间上真在变动**的门槛 `J_u = 2u⁺`，则 `∀ N` 形式的 `modulus`
对**任何** `Kmod`、`γ` 都假 —— 在 `N = 0` 处右端是 `(0:ℝ)^Kmod · 1^γ ≤ 1`，左端是 `2`。
于是 `¬ Nonempty (CutHyp …)`。

结论：`∀ N → ∀ᶠ N` **不是换个写法**，而是把一个不可满足的接口换成可满足的；
「小 `N` 的特例」不是「日后可以补回来」，而是**本来就不存在**。

## 可满足性见证

`satCutHypEv` / `satCutHypEv'` / `satCutHypCondEv` 及其 `_timeDep` 版本 +
`sat_stochDom_of_cutHypEv(')` / `sat_stochDom_of_condMomentEv(_timeDep)`：
`mesh_fine` / `card_le` 用原来那组参数即可满足（`mesh_N = (N+1)²`、`Kmod = 1`、
`γ = 1/2`、`Θ ≡ 1`、`Ccard = 3`），`modulus` 在 `∀ᶠ N` 下由同一组参数满足。
