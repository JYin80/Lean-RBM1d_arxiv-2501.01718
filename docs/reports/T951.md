## Exact compiled interface

For any `d : Dims`, `N : ℕ`, and block family
`C : ZMod (d.L N) → Matrix (Fin (d.W N)) (Fin (d.W N)) ℂ`, the scratch defines

```lean
blockDiagonal d N C : Matrix (d.Idx N) (d.Idx N) ℂ :=
  fun i j => if i.1 = j.1 then C i.1 i.2 j.2 else 0
```

It proves the following propositions, with no hidden restriction on `N`:

```lean
(∀ a, (C a).IsHermitian) → (blockDiagonal d N C).IsHermitian
HermitianBandSupported (blockDiagonal d N C)
(∀ a, (C a).IsHermitian) →
  Xmat d N (omegaOfHermitian d N (blockDiagonal d N C)) =
    blockDiagonal d N C
∀ c : Coord d, (gvar d c : ℝ) = 0 →
  omegaOfHermitian d N (blockDiagonal d N C) c = 0
```

Hermiticity is entrywise: in the same block it is the corresponding block's
Hermiticity, and between different blocks both entries vanish. Band support
uses only `0 ∈ sbSupport (d.L N)`; a zero-variance coordinate at size `N`
cannot read a nonzero off-block entry. The last two propositions apply the
actual `Generator.lean` theorems `Xmat_omegaOfHermitian` and
`omegaOfHermitian_eq_zero_of_gvar_eq_zero`. The encoder does not rescale by
variance and writes the full product sample, so readback is exact at every
matrix entry, not almost everywhere.

This is a genuinely off-diagonal witness for the embedding API, not a
quantile-circulant block or a high-probability sample.
