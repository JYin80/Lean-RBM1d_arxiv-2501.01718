## Verdict: mathematical preflight PASS; the exact pointwise theorem is proved

The new theorem exposes the positive-time pointwise estimate used privately
inside the accepted all-fixed-order norm-good cross-budget producer. For each
fixed `p ≥ 1`, it chooses one eventual cutoff in `N`, uniform over every
active T995 target-mesh cell `k`, output `a`, and `u > 0` in the closed cell
`[s N, v_k]`, where `v_k = cutNetPt s (targetMesh D) N k`. At the literal
scheduled weight and event it proves

```text
normGoodCrossBudget E D (deltaWeight δ) s t N k p a u
  ≤ (15p/4) * crossProfile E D s t zetaSrc tauG deltaWeight deltaCap N k a u
      + (15p/8) * N⁻¹ / √u.
```

The assumptions are unchanged from the all-order producer: `|E| < 2`,
`60 ≤ D`, `0 ≤ s N ≤ t N < 1`, `c > 0`, `Cond272Reg`,
`BoundsCore (Gauss.sample Dims.exampleGrow) E s`, and
`0 < δ ≤ min(1,c/100)`. The proof fixes `p` before forming the eventual
quantifier. It adds no hypotheses.
