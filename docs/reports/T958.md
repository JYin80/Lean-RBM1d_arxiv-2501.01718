# T958 — actual growing-model Fourier entry margin

## Result

Added `RBM1D/Gauss/PermutationFourierExampleGrowEntryMargin.lean`. It proves
`permutationFourierExampleGrow_eventually_entry_margin`: for all sufficiently
large `N`, there is one permutation of the actual `Dims.exampleGrow.W N`
midpoint-quantile table, chosen before every `u ∈ [0,1/2]` and every pair
`a,b : Fin W_N`, such that

```lean
‖permutationFourierSum W_N actualKernel
    (permutationFourierCharacter W_N (b - a)) π -
  (if a = b then Complex.I else 0)‖ <
    flowDelta Dims.exampleGrow 0 (fun _ => 1 / 2) N
```

The kernel is the literal `semicircleFlowKernel u (semicircleLambda W_N hW j.val
j.isLt)` table. A second theorem,
`permutationFourierExampleGrow_eventually_entry_margin_nonempty`, packages the
same conclusion on an eventual set where `2 ≤ W_N`. Thus the actual index set
has at least two elements and includes both diagonal and nonzero `b-a` cases.

## Proof

Intersect T939's eventual uniform nonzero-mode bound with T937's strict
off-diagonal numerical margin and T948's strict zero-mode margin. Extract the
single permutation from T939 before introducing `u,a,b`. If `a=b`, then
`b-a=0`; T933 identifies its character with the constant-one weight and gives
the weak `8√2/W_N` quadrature error, which composes with T948's strict margin.
If `a≠b`, then `b-a≠0`; T939's strict `76√(log N/W_N)` bound composes with
T937's strict margin. The weak-to-strict diagonal step and the strict
off-diagonal step retain the literal `< flowDelta` conclusion.

The nonempty companion combines the main theorem with the second component of
T939's `permutationFourierExampleGrow_eventually_exponent_and_premise`, which
gives the eventual `W_N ≥ 2` witness for the actual `Dims.exampleGrow` model.
No new assumptions are introduced.
