## 23. (4.8) 的符号

**论文 p.49，Lemma 4.2 (4.8)**：`G_ij = G_ii Σ_k H_ik G^(i)_kj`（`j ≠ i`）。

**我们证出的**：`G_ij = − G_ii Σ_k H_ik G^(i)_kj`。

按论文全篇的约定 `G = (H − z)^{-1}`，Schur 补给出的 (1,2) 块是 `−s^{-1} b D^{-1}`，
带负号。见 `RBM1D/Green/Minor.lean` 的 `RBM.green_off_diag_eq` / `green_off_diag_paper`
（从 `M * G = 1` 直接算出，不依赖任何外部结果）。

**影响**：无。论文只在 `|G_ij|` 的形式下使用 (4.8)（(4.10)、(A.18)、(A.19)），符号不进入任何结论。
