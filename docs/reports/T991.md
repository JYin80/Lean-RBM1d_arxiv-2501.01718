For one fixed cutoff `χ`, target truncation `θ`, and observable `Y`, put
`Z=χ|Y|`. On the probability space, ordinary Lyapunov gives

```text
∫ χ^(2p)|Y|^(2p) ≤ (∫ χ^(2q)|Y|^(2q))^(p/q),  1 ≤ p ≤ q.
```
Thus a fixed high-order estimate `≤ C N^(δq/2)` gives the low-order estimate
`≤ C^(p/q) N^(δp/2)`. For each fixed `δ,p`, the selected `q` and its constant
are fixed before the eventual-in-`N` bound; the threshold is uniform over the
active prefix indices `k`. This uses the same cutoff and same sample at both
orders. It does not switch between order-dependent measures. In the actual
weight, the target observable remains exactly
`cutTrunc (N^(2δ)) (jSnorm ... (cutNetPt ... k))`.

At `p=0`, both natural zeroth powers are `1`, including on the inactive
piecewise branch, so the probability integral is exactly `1`. This branch is
proved separately and never divides by `p`.
