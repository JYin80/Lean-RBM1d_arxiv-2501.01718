# T543 — variable-delta same-weight Lyapunov wrappers

## Deliverable

Added `RBM1D/Gauss/APrimeFirstCellDeltaSameWeightLyapunov.lean`.

The module leaves the bootstrap exponent `delta` explicit in the canonical
order-`P` weight and proves the coefficient-one comparison

```lean
momNormW (Gauss.P d) (canonicalHighWeight tauPrime delta P N k) p
    (familyMax N k) <=
  momNormW (Gauss.P d) (canonicalHighWeight tauPrime delta P N k) P
    (familyMax N k)
```

for `1 <= p <= P`.  The probability measure and the weight are literally
identical on both sides.

## Quantifiers and boundary

`eventually_sameWeight_momNormW_le` fixes `delta`, `p`, and `P` before the
eventual matrix-size threshold.  That threshold is uniform over every
`k <= cutNetTop`, with no lower bound on `k`, so the active statement includes
`k = 0`.

`eventually_kZero_sameWeight_momNormW_le` separately retains the exact empty
prefix data:

```lean

```

integrability of the actual finite family maximum.  Continuity of the
delta-dependent canonical high weight is proved directly from
`APrimeSmoothWeightActual.continuous_weight`.  High weighted integrability is

`APrimeFirstCellSampleRegularity.actual_generator_sampleRegularity_endpoints`.

`APrimeInit.momNormW_le_momNormW_of_exponent_le`.

The module introduces no model hypothesis or event bundle, so no potentially
vacuous resident assumption is present.  It imports T467 only for the public
