# T477 — audit of the general moving-window full modulus

## Verdict

The T405 exponent

```text
K(D) = 2D + 7
```

is safe under the original `Cond272Reg` hypothesis.  No strengthening to
`Cond272'`, no fixed terminal time, and no product condition is needed.

Expanding the actual public definitions gives the sharper envelope

```text
jTotNormEv exampleGrow N E D (t N) <= C(E,D) N^(2D+4)
```

eventually, for fixed `E`, fixed `D >= 60`, and the moving terminal value
`t N`.  Therefore the unit-coefficient modulus required by `APrimeHypOn`
holds eventually with every fixed real exponent

```text
K > 2D + 4.
```

There is no smallest real exponent produced by this constant-absorption
argument; `2D+4` is its infimum.  The smallest convenient integer-affine
choice is `K=2D+5`.  Thus T405's `2D+7` has two full powers of slack and does
not require correction.  This report does not claim that the moving-window
full modulus has already been compiled.

## Exact public producer

The pointwise theorem is
`APrimeSlotFields.abs_jSnorm_sub_le_event`
(`RBM1D/Gauss/APrimeSlotFields.lean:251`): for `v,w <= t0`, on
`{omega | ||Xmat d N omega|| <= N}`,

```text
|jSnorm(v)-jSnorm(w)|
  <= |v-w|^(1/2) * jTotNormEv d N E D t0.
```

For each `N`, it may be instantiated with the moving value `t0=t N`.
The public constant is defined at
`RBM1D/Gauss/APrimeSlotFields.lean:243` by

```text
jTotNormEv
 = jSfarSmLip
   + lkLipEv * W^D
   + 4 (1-t0)^(-1) (W^D * crudeLk + 1).
```

The fixed-`t0` theorem `exists_const_jTotNormEv` cannot itself be reused with
`t0=t N`: its existential constant depends on `t0`.  The moving-window proof
must expand `jTotNormEv` and bound its displayed factors uniformly using the
endpoint floor.

## Endpoint quantities

Set

```text
r = (1-t_N)^(-1),
q = eta_{t_N}^(-1),
h = (2 sqrt(1-t_N))^(-1).
```

The original hypothesis is exactly

```text
Cond272Reg B E s t c
  = Cond272 B E s t
    and eventually N^c <= B.scale E N (t N),
```

at `RBM1D/Flow/Thm221Bare.lean:126`, with fixed `c>0`.
`APrimeGeneralMovingWindowFloor.eventually_endpoint_floor`, based on
`Gauss.rpow_neg_one_le_one_sub_of_scale_ge`, gives

```text
N^(-1) <= 1-t_N,
```

hence `r <= N`.  Since
`eta_t=(1-t) Im(m(E))` and `E` is fixed with `|E|<2`,

```text
q <= C_E N.
```

Also `0<=t_N<1`, so

```text
h = (1/2) r^(1/2) <= (1/2) N^(1/2).
```

All constants in these estimates may depend on the already fixed energy;
none depends on `N`.  The argument uses only the regime component of the
original `Cond272Reg`, not a gained factor involving
`(eta_s/eta_t)^30`.

## Complete exponent ledger

The definitions audited below are in
`RBM1D/Gauss/LoopLipschitz.lean`:

- `crudeLk`, lines 1476--1477;
- `jSfarSmLip`, lines 1487--1489;
- `tailLip`, lines 1280--1282;
- `lkLipEv`, lines 2128--2131.

Use the public eventual dimension bounds

```text
1 <= W, 1 <= L, W L <= N, W <= N, L <= N,
```

and fixed `D>=60`.  First,

```text
crudeLk = W^(-1) (q^2+r) = O_E(W^(-1) N^2),

tailLip
 = 2h q^2 + 2q^3 + q^2 (L/2)h
 = O_E(N^(5/2) + N^3 + L N^(5/2)).
```

Substitution into every summand of `jTotNormEv` gives:

| Summand | Bound before absorbing fixed constants |
|---|---:|
| `L h crudeLk W^D` in `jSfarSmLip` | `N^(D+3/2)` |
| `crudeLk * (2h q^2) * W^(2D)` | `N^(2D+7/2)` |
| `crudeLk * (2q^3) * W^(2D)` | `N^(2D+4)` |
| `crudeLk * (q^2 L h) * W^(2D)` | `N^(2D+7/2)` |
| first term of `lkLipEv * W^D` | `N^(D+6)` |
| second term of `lkLipEv * W^D` | `N^(D+1)` |
| `4r(W^D crudeLk+1)` | `N^(D+2)+N` |

For example, the largest term is bounded as

```text
W^(-1) N^2 * N^3 * W^(2D)
  = N^5 W^(2D-1)
  <= N^(2D+4).
```

The terms containing `L` retain the cancellation supplied by `WL<=N`;
for instance

```text
L W^(2D-1)
  = (LW) W^(2D-2)
  <= N^(2D-1).
```

For `D>=60`, `2D+4` dominates every exponent in the table, including
`D+6`.  This proves the asserted `C(E,D) N^(2D+4)` envelope.  Taking an
eventual threshold with `C(E,D)<=N` gives the clean choice `K=2D+5`;
the ticket's `K=2D+7` follows a fortiori.

The estimate deliberately uses the dimension inequalities named in the
T475 producer.  Further exploitation of the special asymptotics
`L_N asymp N^(1/4)`, `W_N asymp N^(3/4)` could lower the exponent, but is
unnecessary for this interface and is not needed to validate T405.

## Quantifiers and boundary cases

The valid order is:

```text
fix E, D, c, s, t and Cond272Reg;
then eventually N;
then for every omega in the norm event and every v,w in [s_N,t_N].
```

The exponent `K(D)` is fixed before `N`; it does not depend on `N`, `v`,
`w`, or `omega`.  The eventual threshold may depend on the fixed
`E,D,c,s,t`.  This is exactly the order of the `APrimeHypOn.modulus` field
at `RBM1D/Gauss/Step2Bootstrap.lean:1996`.

The hypotheses `0<=s_N<=t_N<1` imply `|v-w|<=1`, which is the remaining
length premise of `abs_jSnorm_sub_le_event`.  The cases `v=w` and `s_N=t_N`
are valid and give zero differences.  They do not make the construction
vacuous:

- T473's `positive_length_grid_window_witness` supplies one application of
  the paper grid with the same `Cond272Reg` data and `s_N<t_N` eventually;
- `Gauss.traceMomentBound_gauss` together with
  `Gauss.eventually_nonempty_normX_le` makes
  `{omega | ||Xmat exampleGrow N omega||<=N}` eventually nonempty.

No lower bound on the window length is used in the modulus estimate.

real `K>=0`.  Its `aprime_mesh_fields` proves


It therefore accepts either the sharper convenient choice `K=2D+5` or
T405's `K=2D+7`.  The already stated target specialization at `2D+7` has
mesh exponent `4D+18` and cardinality exponent `4D+19`, exactly as required.

```text

              -> expanded LoopLipschitz/APrimeSlotFields constant
              -> event modulus

```

No first-cell modulus is used as a general-window source, and no audited
module imports or requires next-cell `BoundsCore`, `WeightedMoment`,
`hfamily`, or an `APrimeSlot'` conclusion.  There is no next-cell
`BoundsCore` dependency cycle.
