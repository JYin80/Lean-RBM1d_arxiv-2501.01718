## Claim and direct dependencies

`0 ≤ t n`, `|(z n).re| ≤ 3`, and `0 < (z n).im ≤ 1` for every `n`, the source defines

```text

R2(n,ω) = M_n⁻¹ ∑_α |λ_α(ouMatrix d n (t n) (ouCommonProjection d n ω)) − z n|²,
R(n,ω) = sqrt(R2(n,ω)),                    μ = ouCommonMeasure d.
```

The target is every integer moment order, including `p=0`:
`∃ C_p>0, ∀ n, ∫ R2(n,ω)^p dμ ≤ C_p`, with a constant independent of
`n,d,t,z`, followed by `RBM.StochDom μ R 1`. The source's definitions use actual
Hermitian eigenvalues of the fixed-time OU matrix; there is no abstract matrix or
profile parameter in the public target.

The dependency chain is internal:

1. T1420's `ouCommonProjection_map` sends the single measure `ouCommonMeasure d`
   to T1401's `ouProductMeasure d n` for every `n`, including zero.
2. T1401's `ouCoordinate_hasLaw` identifies each interpolated real coordinate as
   a centered Gaussian with `ouCoordinateVar`. Composition with the common
   projection gives the exact law used here. The accepted `ouMatrix` is pointwise
   Hermitian and equals `Xmat` of those interpolated coordinates.
3. The source proves the Hermitian spectral identity
   `∑_α λ_α(H)^2 = frobSq H` from spectral decomposition and the existing
   trace/Frobenius identity. Its centered expansion identifies the statistic with
   the actual Frobenius and trace expression. For `|Re z|≤3` and `0<Im z≤1`,
   `R2 ≤ 4 M_n⁻¹ coordSq + 32` pointwise.
4. The positive envelope `w_ij=Sblk_ij+M_n⁻¹` has row sum `2`. Counting both
   coordinate tags gives total weight `4M_n`. For nonnegative time each actual
   coordinate variance is at most its envelope, including zero-variance entries.
   Centered Gaussian moments give `E|X_c|^(2p)=dfac(p) var(X_c)^p`.
   Weighted Jensen then gives `E(coordSq^p) ≤ dfac(p)(4M_n)^p`.
5. The preceding bounds yield, for `p≥1`, the explicit constant
   `2^(p−1)(dfac(p)·16^p+32^p)`. At `p=0`, the probability measure gives
   the constant `1`. The code proves integrability separately before using
