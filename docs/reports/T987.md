For fixed `N,u<1`, `|E|<2` implies `(zt E u).im ≠ 0`. The existing
`continuous_Gsig_Hflow` makes every Green entry continuous in the sample. The
`gmBlk` maximum ranges over a nonempty finite set of charges and entry labels;

positivity assumption. On the other side, `sample_Lval` and
`continuous_gloop_Hflow` make each actual `Step2.lk` continuous, and the
finite maximum `Step2.jStar` gives continuity of `Step2.jS`.

`u : TimeIcc s t N` obeys `u ≤ t N < 1`; this includes both endpoints when
present. The intersection over all such real times is closed, regardless of
uncountability. If the interval is empty, the intersection is the whole sample
space and the conclusion remains valid. No continuity in `u` is used. The
proof imports the existing event and Gaussian continuity definitions; no
import points back to the new module.

`IsClosed` and `MeasurableSet` for the literal `blockEvent` under only
`|E|<2` and `t N<1`. It also proves the concrete `E=0`, `s=0`, `t=1/2`
closedness statement for every `N,D,τ`.

an actual sample in `blockEvent 0 60 (fun _ => 0) (fun _ => 1/2) τ N` for all
sufficiently large `N`. It uses the existing growing-band first-cell witness
with `s_N=0`, `t_N=1/2` eventually, the existing `highProb_commonEvent`, and
`commonEvent_subset_rawCarrier` to extract the *literal* block component.

hypotheses and event for this parameter choice, but does not claim that the
selected sample has `Xmat ≠ 0`; that stronger property was not established
for this exact block event. The measurability theorem introduces no further
hypothesis requiring a sample witness.
