# T815 — preflight of the global unused-image marginal

## Verdict: PASS (mathematical and API feasibility; no Lean theorem claimed)

The exact target is true and has a finite, noncircular proof route using the existing upstream declarations. T816 can proceed after its separate source/root ownership gate. This is a report-only preflight: no Lean source was edited or compiled here.

```lean
theorem uniformPerm_mem_unusedImages (W : ℕ) (k v : Fin W) :
    uniformPerm W {π : PermΩ W | v ∈ unusedImages W k π} =
      ((W - k.val : ℕ) : ENNReal) / (W : ENNReal)
```

## Source checks and exact route

* `PermutationPrefixFiltrationCore.lean` defines `PermΩ W := Equiv.Perm (Fin W)` and `uniformPerm W := uniformOn (Set.univ : Set (PermΩ W))`. Its measurable space is `⊤`. Thus every finite event below is measurable, and the `uniformOn_univ` / `Measure.count_apply_finset` computation **already used in T752** gives event cardinality divided by `Fintype.card (PermΩ W)`.
* `PermutationUnusedImageCount.lean` defines membership by `∀ i < k, π i ≠ v`. Its proof of `unusedImages_card` contains the precise inverse-position equivalence: `v ∈ unusedImages W k π ↔ k.val ≤ (π.symm v).val`. This equivalence is currently `private` there. T816 should reprove the two-line equivalence locally or expose a new public lemma in its own permitted module; it must not rely on the private name across modules.
* `PermutationFirstImageUniform.lean` proves `uniformPerm_firstImage W hW v`, the exact probability `1/W` of `π 0 = v`. Its proof depends on the T703 equal-cardinality fibers and hence T694 codomain swaps. It is an unconditional first-coordinate law, with no input from the sought marginal or a conditional law. T738 supplies `prefixFree_card W k.val`, namely the cardinality of `{j : Fin W // k.val ≤ j.val}` as `W - k.val`; alternatively use the same `Fintype.card_subtype_compl` calculation as T785. These dependencies are upstream and acyclic.
* Let `zero : Fin W := ⟨0, Nat.zero_lt_of_lt k.isLt⟩`, `J := {j : Fin W // k.val ≤ j.val}`, and `F := {ρ : PermΩ W // ρ zero = v}`. There is an explicit equivalence from the target event subtype to `J × F`: send `π` to `j := π.symm v` together with `ρ := (Equiv.swap zero j).trans π`. Since `π j = v`, one has `ρ zero = v`. Conversely, send `(j,ρ)` to `(Equiv.swap zero j).trans ρ`. The transposition is involutive, and the unique preimage of `v` in the resulting permutation is `j`. The `Equiv.trans` application direction is checked against T694's `permutationCodomainSwap_apply`: `(swap zero j).trans π` acts on the **domain**, giving `π (swap zero j i)`. Thus `Fintype.card_congr` and `Fintype.card_prod` yield

  `card(target event) = (W - k.val) * card(F)`.

* Convert this cardinality by the same `uniformOn_univ` calculation used in T752. Rewrite `card(F) / card(PermΩ W) = 1/W` using `uniformPerm_firstImage` and its event-card formula (the latter is `private` in T752, so repeat its short cardinality calculation locally). Then ENNReal multiplication/division gives `(W-k.val)/W`. No cancellation by the event-cardinality or a conditional probability is needed. The denominator `W` is positive by `k.isLt`, and the natural cast of `W` is finite (`ENNReal.natCast_ne_top`); in particular the expression has its ordinary finite-probability meaning.

The first technical point T816 must implement is the event-subtype equivalence and its orientation, followed by the reusable event-card calculation. No missing mathematical implication remains. Avoid importing T807/T810/T813 or postulating inverse-position uniformity: the equivalence above derives it from T752.

## Boundaries and nondegeneracy

There is no `k : Fin 0` at `W=0` (`no_next_index_zero`). At `W=1,k=0`, the event is all permutations and its mass is `1`. At `W=2,k=0`, it is again the whole space with mass `1`; at `W=2,k=1`, each fixed `v` has mass `1/2`. For `v=1`, the identity permutation belongs to the `W=2,k=1` event and the transposition does not; for `v=0`, their roles reverse. This gives both a member and a nonmember, consistent with T785's `unusedImages_two_distinct_samples` and T752's two-point first-image witness. At the last valid `k` (`k.val+1=W`) the numerator is one, giving `1/W`.

The paper's Theorem 2.3, formulas (2.3)–(2.4), states high-probability Green-function and partial-trace local laws with `N`, `W`, `ℓ(z)`, and `η` scales. The proposed identity is only a global finite uniform-permutation marginal. It contains no analytic scale, time evolution, first-cell/shared event, or local-law closure, and it does not imply (2.3)–(2.4).
