## 1. `hfit` / `hbudget` 是不是真的成了定理？

**是。** 两条都是**定理**，不是 fiat、不是结构字段：

| T271 余项 | 本单交付 | 形状 |
|---|---|---|
| `hbudget`（`qv_bound_model` 的假设） | `eventually_hbudget` | `∀ p, 1 ≤ p → ∀ᶠ N in atTop, (2p−1)·G N ≤ (slotTail (N^{δ/8}) (Rn N))²` |
| `hfit`（`drift_bound_first_cell` 的假设） | `eventually_hfit` | `∀ p, ∀ᶠ N in atTop, fitLhs E N (tc N) (Qb N) (Qm N) εs δ ≤ slotDrift m (N^{δ/8}) (Rn N)` |
| 两条合并 + T263 侧条件 | `eventually_slot_arith` | `∀ p : ℕ, 1 ≤ p → ∀ᶠ N in atTop, SlotSide … ∧ hfit ∧ hbudget` |
| 同上，输入换成 `≺` | `eventually_slot_arith_of_detDom` | 同上，假设只是 `≺ 1`，**指数由本文件选（δ/32），调用者不用挑** |

它们的输入是**包络的 `≺`-界**（T268/T269 交付的形状），不是「假设结论」：

* `hGbd : ∀ᶠ N, 4·(Rn N)⁴·G N ≤ cq·N^η`（`G N` 在模型层就是 T269 的 `(b−a)·Q^{bd}`）；
* `hLbd : ∀ᶠ N, fitLhs … ≤ cp·N^η`（`fitLhs` **逐字**就是 T268 `integral_early_le_budget` 的输出，见 §2）。

`≺` 版把这两条换成 `f ≺ fun _ => 1`，由 `RBM.detDom_iff` 在 `τ = δ/32` 处取出——**调用者一个指数都不用选**。

### 槽的选取

八个槽取 **T263 的因子-2 余量见证** `RBM.StepSideAPrime.sat_StepSide''_half`，命名为
`slotXi = x/2`、`slotA = 2cWt²x³³R¹⁰`、`slotEps = (2cWt²x³³R¹⁰)⁻¹`、`slotQ = R²/2`、
`slotBeta = (2cWt x¹⁶R²)⁻¹`、`slotGamma = (2cWt^{3/2}x²⁴R⁴)⁻¹`、`slotKappa = x/2`、
`slotJv = cWt x¹⁶R⁴/2`，并由 `slotSide : 1 ≤ x → 1 ≤ R → SlotSide x R` **证明**它们满足 `StepSide''`（`x = N^{δ/8}`，`1 ≤ x` 由 `1 ≤ N` 得到）。

于是
`slotDrift m x R = driftTerm m x R (那七个) / R⁴`、`slotTail x R = tailTerm x R (x/2) / R⁴`。

## 2. `p`-依赖常数：走的是**主路线**，不是带撇退路

**没有用 `WeightedMoment'`，没有把 `δ/2·p` 放宽到 `δ·p`。** Cowork 的判定成立：`p` 在 `N` 之前取，所以

```
eventually_const_mul_rpow_le : η < θ → ∀ᶠ N : ℕ in atTop, c * (N:ℝ)^η ≤ (N:ℝ)^θ
```

对**任何**固定常数 `c`（含 `√(2p−1)`、`c_MD`、`‖χ′‖·p`）成立。两个槽自带的余量：

* **tail 槽**：`tailTerm x R (x/2) ≥ x·R²·(x/2)`，除以 `R⁴` 得 `≥ x²/(2R²)`，平方得
  `(slotTail x R)² ≥ x⁴/(4R⁴) = N^{δ/2}/(4R⁴)` —— `sq_tailTerm_slot_ge`。
  **`(2p−1)` 就吸在这个 `N^{δ/2}` 里。**
* **drift 槽**：`driftTerm ≥ Ξ·(x m⁻¹R²·q) = (x/2)(x m⁻¹R²·R²/2) = x²m⁻¹R⁴/4`，除以 `R⁴` 得
  `slotDrift m x R ≥ x²m⁻¹/4 = N^{δ/4}/(4m)` —— `driftTerm_slot_ge`（经通用的 `driftTerm_ge_near`，
  它只用其余各项非负，不对它们提任何额外要求）。

指数账：`hbudget` 容得下任何 `η < δ/2`，`hfit` 容得下任何 `η < δ/4`；**`η < δ/16` 同时覆盖两者**，正是工单 ⭐ 段所指的取法，`c_p·N^η` 落进 `stepRhs''` 里已有的 `x = N^{δ/8}` 因子。

两条辅助等式 `rpow_div_eight_sq`（`(N^{δ/8})² = N^{δ/4}`）、`rpow_div_eight_pow_four`（`(N^{δ/8})⁴ = N^{δ/2}`）把这一步做实。

## 3. 量词次序（T188 纪律）

* 所有渐近条件一律 `∀ p, ∀ᶠ N in atTop, …`；**文件里没有一处 `∀ p N` 形**。
* `eventually_const_mul_rpow_le` 的 docstring 明写：常数 `c` 必须先固定；写成 `∀ c N, …` 会不可满足。
* 包络与常数在总装定理里都按 `p` 索引（`cp cq : ℕ → ℝ`，`tc Qb Qm G : ℕ → ℕ → ℝ`），因为漂移/二次变差包络确实依赖 `p`。
* **没有对 `ω` 的量化**：本文件全是确定性算术；`qv_bound_model_slot` 原样继承 T271 的事件限制假设（`∀ u ∈ Icc a' b', ∀ ω ∈ Good N, …`）。

## 4. 接线检查（§8）：形状**逐字**对上 T271 的消费者

两条无自身内容的定理，编译通过即证明形状一致：

* `drift_bound_first_cell_slot` —— `RBM.APrimeModel.drift_bound_first_cell`，`Dbd := slotDrift m x R`，
  左端 `fitLhs E Nr tc Qb Qm εs δ`。**`fitLhs` 与 `drift_bound_first_cell` 的 `hfit` 左端是同一个项**（定义式相同，`exact` 通过）。
* `qv_bound_model_slot` —— `RBM.APrimeModel.qv_bound_model`，`c := slotTail x R`，
  并把 `hc : 0 ≤ c` 就地交割（`slotTail_nonneg`），生产者不用再论证。

## 5. 可满足性见证（§7、§9）——**在 `R > 1` 上**

`sat_slot_arith`（指数版）与 `sat_slot_arith_detDom`（`≺` 版），显式参数：

| 参数 | 值 |
|---|---|
| `δ` | `1/2`（故 `x = N^{1/16}`） |
| `η` | `1/64`（`< δ/16 = 1/32`）；`≺` 版内部取 `δ/32 = 1/64` |
| `ε_s` | `1 = 2δ`（故第一格的 `N` 幂是 `N⁰`，左端是常数） |
| `m` | `1` |
| `E` | `0` |
| `R = Rn N` | **`2`**（窗口未塌缩，`R > 1`） |
| `t_c` | `1/4` |
| `Q^{bd} = Qb`，`Q_m` | `1`，`1` |
| `G`（二次变差包络） | **`1`（严格正，不是 0）** |
| `c_q` | `64` |
| `c_p` | `satFit = fitLhs 0 1 (1/4) 1 1 1 (1/2)`，**`satFit_pos : 0 < satFit`** |

`sat_slot_arith_nondegenerate` 把非退化性单独陈述并编译：`1 < 2`（窗口比）、`0 < 1`（包络）、
`0 < satFit`（第一格左端）、`∀ᶠ N, 0 < slotTail (N^{1/16}) 2`。
**没有一个槽是靠把某个量塌成 `0` 满足的。**

反向自查（空真）：`eventually_hbudget` / `eventually_hfit` 的全部假设在上表处同时成立且结论非平凡；
`f ≺ 1` 在 `f ≡ 64` 处成立，所以 `≺` 接口也不是空的。
