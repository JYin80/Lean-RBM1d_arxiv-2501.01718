actual spectral-norm good event and uniformly over active far indices. For
each fixed `δ₀`, `0 < δ ≤ δ₀`, and `p ≥ 1`, it must select `q ≥ p` and `C > 0`


## Producer audit and decisive exponent check

- T999's `eventually_actual_widened_family_of_selected_high` is a conditional
  transfer interface. It requires the high-order estimate uniformly for every
  active `k`; it does not produce the Gaussian estimate.
- T1097 proves that estimate only at `k = 0`, where the prefix is empty and the
  weight is identically one. Its stochastic domination input is the initial
  `BoundsCore` law at `s_N`.
- T1103 proves the good-event contribution only at `k = 1`, by comparing that
  endpoint to `s_N`. It uses T475 and the actual target mesh, and absorbs the
  resulting `(19/4) N^-2` cutoff error into the requested rate.
- T475 is the applicable general-moving modulus: on `{‖Xmat_N‖ ≤ N}` it gives
  `|jSnorm(v)-jSnorm(w)| ≤ N^(2D+7)|v-w|^(1/2)`. The target mesh is eventually
  `M_N = N^(4D+18)`, with no fixed terminal time assumption.

For `v_{N,k}=s_N+k/M_N`, the T475 endpoint-to-initial error bound becomes

```text
N^(2D+7) * (k/M_N)^(1/2) = N^-2 * sqrt(k).
```

T1103 uses `k=1`, giving `N^-2`. Uniformly over active indices, however,
`k ≤ cutNetTop ≤ (t_N-s_N)M_N < M_N`, so the available bound can grow to
order `N^(2D+7)`. Applying T1103's cutoff Lipschitz constant `19/4` produces
an error term

```text
(19/4)^(2q) * N^(-4q) * k^q.
```

Absorbing this into `C N^(δq/2)` by this route requires a uniform restriction
of roughly `k ≤ C_q N^(4+δ/2)`. The stated moving-window hypotheses supply no
such restriction; the active range may extend to the target-mesh scale. The
far-index clause `k > N^4` therefore cannot be handled by extrapolating
T1103's first-point calculation. This is a failure of the available estimate,
not a lower bound on the actual endpoint error.

The literal widened weight also does not close the gap. At an active `k`, it
cuts off the soft maximum over indices `j < k` at scale `2e N^(2δ)` and then
raises that cutoff to `2q`; it does not include the endpoint `j = k`. On its
nonzero support, the prefix values can be bounded at scale `O(N^(2δ))`. T475
then controls the last mesh step by `N^-2`, leaving only a pointwise endpoint
scale `O(N^(2δ))` and a `2q`-power bound of order `N^(4δq)`. That is larger
than the requested `N^(δq/2)` by a positive power for every `δ > 0`. Improving
the expectation requires an additional far-index distributional estimate or
a proved stopped-process bridge for this same observable and weight; neither
is supplied by T475, T1097, or T1103.

Thus the prescribed sources establish the `k=0` and `k=1` cases but leave the
smallest missing implication exactly at positive far indices: control of the
selected high-order endpoint moment on the good event, compatible with the
same widened prefix weight. This preflight does not refute that literal
mathematical statement; it establishes that the authorized producer route
does not prove it. Per the ticket gate, I stopped without writing a Lean
replacement, weakening the exponent, fixing a terminal time, or substituting
another sample/window.
