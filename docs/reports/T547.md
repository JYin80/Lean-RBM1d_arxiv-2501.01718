## Imported interfaces and choices

The implementation uses the following accepted interfaces.

1. `APrimeGeneralMovingInitialHinit.eventually_initial_hinit` is the
   delta-parametric general initial-data theorem.  It is instantiated with
   `E = 0`, `D = 60`, `s = 0`, `t = firstCellT tauPrime`, `c = 1/2`, and the
   constant weight one.
2. `APrimeFirstCellInitialMomentBudget.firstCell_cond272Reg` and
   `APrimeFirstCellInitialMomentBudget.firstCell_boundsCore` provide the
   first-cell `Cond272Reg` and `BoundsCore` inputs.  They do not freeze
   `delta`.
3. `APrimeFirstCellInitialMomentBudget.momNormW_le_one_weight` transfers the
   constant-weight estimate to any nonnegative weight bounded by one, with
   coefficient exactly one.
4. The weight used by T547 is
   `APrimeFirstCellDeltaSameWeightLyapunov.canonicalHighWeight`.  Unfolding
   it gives `APrimeSmoothWeightActual.weight` with the same explicit
   `delta`, the actual canonical smoothing order, and the Gaussian measure
   `P d`.  Nonnegativity and the upper bound by one come directly from
   `APrimeSmoothWeightActual.weight_nonneg` and
   `APrimeSmoothWeightActual.weight_le_one`.
5. `APrimeAssembly.initial_slot_scale_eq` gives the exact simplification
   of the raw initial slot to
   `N^(5*delta/32) * R_v^(-2)`.
6. `APrimeFirstCellCanonicalPlateau.exists_sharpCommonEvent_with_canonical_plateau`
   fixes one `tauPrime` before all admissible `delta` and supplies the
   measurable, high-probability literal sharp event and its positive
   same-event `k = 2` resident.

The T542 canonical weight and the T543 canonical high weight unfold to the
same actual canonical smooth weight.  T547 uses T543's name because its
definition exposes the order parameter without introducing any target-weight
or family conclusion.  T542 remains an imported accepted interface for the
later target/canonical comparison; no such comparison is claimed here.

- `endpoint N k` is the literal first-cell `cutNetPt`.
- `initial N k a` is
  `APrimeAssembly.initialEvolvedNormAt (sample d) 0 60 0 N (endpoint N k) a`.

  weight exactly one, and `initialBoundAt` for every output coordinate.

## Public theorems

### `initialBudget_eq`

For every active endpoint and `N >= 1`, the unsimplified slot is exactly

```text
N^(5*delta/32) * R_v^(-2),
R_v = etaT 0 0 / etaT 0 (endpoint N k).
```

The positivity of `R_v` follows from `Step2Moment.ratR_pos`, using the active
mesh-point inclusion and the first-cell upper bound below one.

### `eventually_initialBoundAt`

For fixed `tauPrime > 0`, `delta > 0`, and `p >= 1`, one eventual threshold
works for every active `k` and every `LoopArg` output.  The proof proceeds as
follows.

1. Apply the general initial-hinit theorem once with constant weight one.
2. Turn each active mesh point into a `TimeIcc` endpoint using
   `cutNetPt_mem_netFinset` and `netFinset_subset_Icc`.
3. Obtain the required unweighted moment integrability from
   `APrimeAssembly.integrable_initialEvolvedNormAt_pow_gauss`.
4. Dominate the actual canonical weight by one using
   `momNormW_le_one_weight`.  This introduces no coefficient, change of
   measure, event loss, time-net loss, or power loss.
5. Rewrite the raw slot with `initialBudget_eq`.

The quantifier order is `delta`, then fixed `p`, then eventual `N`; the
eventual statement is uniform in active `k` and output `a`.

### `eventually_initial_k_zero`

At `k = 0`, the theorem records all four facts together:

1. `endpoint N 0 = 0`;
2. `R_0^(-2) = 1` exactly;
3. the actual canonical weight is identically one for every sample;
4. the moment bound is exactly `N^(5*delta/32)`.

Thus the zero branch retains neither a hidden ratio factor nor a cutoff
coefficient.

### `positiveTwoInitialResident_of_canonical`

This theorem combines T467's resident and `eventually_initialBoundAt` at the
same eventual size.  The chosen sample belongs to the literal
`sharpCommonEvent tauPrime delta alpha N`; its `k = 2` endpoint is active and
positive, its actual canonical weight equals one, and the initial estimate
holds for every output coordinate.  No transition inhabitance is asserted.

### `exists_deltaInitialMomentBudget_with_resident`

This is the closed producer.  Its outer order is

```text
exists tauPrime > 0,
  ... and
  forall delta, 0 < delta -> delta <= 1/100 ->
  forall p, 1 <= p ->
  ... eventual N ...
```

It fixes `alpha = delta/16` and returns, for the identical literal event:

- measurability for every `N`;
- `HighProb (P d)`;
- eventual nonemptiness;
- the uniform active-index/output initial bound;
- the exact `k = 0` branch;
- the positive same-event `k = 2` canonical-weight-one resident.

The eventual nonemptiness is obtained directly from the same `HighProb`
statement, so the package is nonvacuous.
