# T410 — First-cell running far-output Green drift

## Scope

This ticket adds the event-local running-time far-output estimate in
`RBM1D/Gauss/APrimeFirstCellEGFarRunning.lean`.  It does not add a near-field
estimate, perform the time integration, or assemble an `APrimeSlot'` witness.

## Shared parameter and event

The event

```lean

  APrimeFirstCellAllTimeNearSources.good τ' ζ₁ ζ₃ N ∩
    APrimeFirstCellSourceSupport.jointEvent τ' ζ₃ N
```

## Exact running checkpoint

The theorem `eventually_running_far_exact` gives the requested checkpoint.  Its
quantifiers cover every:

- positive active prefix (`1 ≤ k` and positive support weight),
- real running time `r ∈ [0,u_k]`,
- far output pair `(a₁,a₂)` satisfying the `ellStar` separation.

On the same sample it proves

```lean
APrimeSupportRunning.jG N r ω ≤ N ^ (1 / 8)
```

and the exact running far inequality.  The auxiliary theorem
`running_mem_firstCell` embeds every such `r` into the first-cell `TimeIcc`, so
the all-time source event and the Green-function event are used at the same
time and sample.

## Inputs to the actual far lemma

`norm_eGpm_far_running_bound` calls `Lemma57.eG_far_le` directly.  The inputs
are supplied as follows.

1. `block_averages_on_good` proves both orientations of (5.57), uniformly in
   the running time, with the exact error
   `firstCellDelta N + (W N : ℝ)⁻¹`.
2. `norm_eGpm_running_bound` feeds the T400 averaged source into the actual
   `EGDef.norm_eGpm_le` bound, producing
   `κ₁ = 2 N^ζ₁ (ell_u / ell_0)`.
3. The two-loop input uses
   `APrimeFirstCellEGFar.two_loop_re_le_gsqBlk` followed by
   `APrimeJG.gsqBlk_le_jG_mul_tailT`.
4. The block maximum input uses
   `APrimeDriftNearTriple.gmBlk_le_sqrt_jG_tail`.
5. The two local comparison inputs use the primed statements
   `Lemma57.gloop_h558a'` and `Lemma57.gloop_h558b'`.
6. The three-loop input is
   `APrimeFirstCellEGFar.norm_gloop_three_le_gmBlk`.

The output order from `Lemma57.eG_far_le` is converted to the required
`(a₂,a₁)` orientation.  The decay parameter is literally `D = 60`; it is not
hidden behind a variable or weakened.

The coefficient inside the tail is retained as three separate rows:

```text

168 · J · sqrt J · A⁻¹
J · sqrt J · L · sqrt(W⁻⁶⁰) / ell
```

No `A⁻¹/³` coarsening is used.

## Nonvacuity

`positiveFarPlateau_of_good` supplies a same-sample witness at `k = 2`:

- every displayed support weight equals one;
- the second grid time is positive and lies inside the first cell;
- the antipodal blocks are distinct and satisfy the far separation;
- the same sample satisfies `jG ≤ N^(1/8)` at that time.

`exists_running_far_with_plateau` packages measurability, high probability,
eventual nonemptiness, and this plateau witness under the single chosen `τ'`.

## Power normalization

No additional `N^ν` theorem is asserted.  The exact compiled checkpoint keeps
all three literal rows.  A power normalization needs an explicit pointwise
dimension comparison such as `W N * L N ≤ N`; the available growth data in
this layer do not expose that comparison pointwise in the required theorem.
Consequently the optional normalization remains with the T402/T405 arithmetic
audit rather than being inserted here with a stronger unstated premise.
