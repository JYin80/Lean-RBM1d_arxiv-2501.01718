# T423 — independent actual-Gaussian block-tail and finite-union audit

## Verdict

The mathematical fixed-vector tail and quarter-net union are correct with the stated
constants.  For `d = Gauss.Dims.exampleGrow`, distinct adjacent blocks `x ≠ y`, deterministic
unit vectors `v,w : Gauss.BlockVec (d.W N)`, and `r ≥ 0`, one has

```text
(Gauss.P d).real {ω | ‖⟪v, xBlock N ω x y · w⟫_ℂ‖ > r}
  ≤ 4 * exp (-(3/2) * d.W N * r^2).
```

For a T416 quarter-net `V`, this implies

```text
(Gauss.P d).real {ω | ‖xBlock N ω x y‖ > 8}
  ≤ 4 * 9^(4 * d.W N) * exp (-24 * d.W N)
  = 4 * exp (-(24 - 4 * log 9) * d.W N).
```

Moreover `24 - 4 log 9 > 15`.  Opposite orientations have equal operator norm, so the full
adjacent-block failure event is a union over at most `L` unoriented cyclic edges, including when
`L = 3`.  Its probability is therefore bounded by

```text
4 * L * exp (-(24 - 4 * log 9) * W)
  ≤ 4 * L * exp (-15 * W),
```

and this is eventually at most `N^(-D)` for every `D > 0` under `exampleGrow`.

No mathematical premise in T420 fails.  The false strengthening to avoid is independence of
the two orientations `(x,y)` and `(y,x)`: they are pointwise adjoints and hence generally
maximally dependent.  The narrower statement used here needs independence only among the
`2 W^2` real product coordinates within one chosen orientation.

At the inspected working-tree snapshot, T420's Lean module already contained the genuine
coordinate-law, independence, coefficient, and projected-variance constructions, but did not
yet contain the final one-sided/four-tail theorem.  A direct `lake env lean` check also stopped
at two local `NNReal` coercion/rewrite goals in the projected-variance lemmas.  Thus the

## 1. Actual coordinate law and independence

Write `W = d.W N` and let `p,q : Fin W`.  The definitions in
`RBM1D/Gauss/Model.lean` are literal:

```text
Gauss.P d = Measure.infinitePi (fun c => gaussianReal 0 (Gauss.gvar d c)),
```

and `Gauss.Xentry` reads the ordered upper-triangular coordinate pair.  If `x.val < y.val`,

```text
X_{(x,p),(y,q)} = R_{pq} + i I_{pq};
```

if `y.val < x.val`, it reads the same unordered pair in reverse and gives

```text
X_{(x,p),(y,q)} = R_{pq} - i I_{pq}.
```

T420's `blockCoord` encodes this ordering and its `blockCoord_injective` proves that the map

```text
(p,q,b) : Fin W × Fin W × Bool ↦ Gauss.Coord d
```

is injective.  Therefore the `2 W^2` real coordinates used by one block are mutually
independent.  This is stronger and more precise than merely saying that the `W^2` complex
entries are independent.

Adjacency gives `x-y ∈ {1,-1}` because `x ≠ y` and `L ≥ 3`.  Hence `Sblk = 1/(3W)` on every
cross-block entry.  The full matrix indices `(x,p)` and `(y,q)` are distinct, so
`Gauss.gvar_offDiag` divides by two and gives

```text
Var R_{pq} = Var I_{pq} = 1/(6W).
```

This is exactly T420's `gvar_blockCoord`; no distributional assumption is added.

The exact Lean entry points are:

- `Gauss.P_map_eval` for the law `gaussianReal 0 (gvar d c)`;
- `ProbabilityTheory.iIndepFun_infinitePi` for the independent coordinate evaluations;
- `iIndepFun.precomp` for an injective coordinate map and `iIndepFun.comp` for deterministic
  scalar multiples;
- `integrable_exp_mul_gaussianReal` and `mgf_gaussianReal` for the one-coordinate Gaussian MGF;
- `HasSubgaussianMGF.const_mul` and `HasSubgaussianMGF.sum_of_iIndepFun` for a finite weighted
  sum.

T420 packages these as `hasSubgaussianMGF_coord`, `iIndepFun_coord`, and
`hasSubgaussianMGF_weighted_coord_sum`.  These are the required genuine model-law lemmas; no
new model-law axiom is needed.

## 2. Complex coefficient variance and the fixed-vector tail

Let

```text
c_{pq} = conj(v_p) * w_q,
Z = ⟪v, xBlock N ω x y · w⟫_ℂ = Σ_{p,q} c_{pq} X_{pq}.
```

Since `‖v‖ = ‖w‖ = 1`,

```text
Σ_{p,q} |c_{pq}|^2
  = (Σ_p |v_p|^2) (Σ_q |w_q|^2) = 1.
```

The orientation sign affects only the sign of each imaginary coordinate.  For every complex
coefficient `c`, the squared real coefficients of `c(R ± iI)` add to `|c|^2`, and the squared
imaginary coefficients do the same.  Consequently

```text
Var(Re Z) = Var(Im Z) = (1/(6W)) Σ_{p,q}|c_{pq}|^2 = 1/(6W).
```

T420 proves the coefficient identities as `sum_blockReCoeff_sq` and
`sum_blockImCoeff_sq`, after the exact expansions `blockScalar_re_eq_coord_sum` and
`blockScalar_im_eq_coord_sum`.  Its intended variance proxy is `blockVarProxy N = 1/(6W)`.

Thus, for all `t : ℝ`, both projected MGFs satisfy

```text
E exp(t Re Z) ≤ exp(t^2/(12W)),
E exp(t Im Z) ≤ exp(t^2/(12W)).
```

In fact equality holds because the sums are Gaussian, but the upper bound represented by
`HasSubgaussianMGF` is sufficient.  The exact tail API is
`HasSubgaussianMGF.measure_ge_le`; applying it to a projection and to `.neg` gives, for `s ≥ 0`,

```text
P(Re Z ≥ s), P(-Re Z ≥ s), P(Im Z ≥ s), P(-Im Z ≥ s)
  ≤ exp(-s^2 / (2/(6W))) = exp(-3W s^2).
```

The target events use strict inequalities, so each is included in the corresponding `≥` event.
With `s = r / sqrt 2`,

```text
|Z| > r  ⇒  |Re Z| > s or |Im Z| > s,
s^2 = r^2/2,
```

and `measureReal_union_le` (twice) yields

```text
P(|Z| > r) ≤ 4 exp(-3W(r^2/2)) = 4 exp(-(3/2)Wr^2).
```

For an ENNReal-valued theorem, convert with `MeasureTheory.ofReal_measureReal`; `Gauss.P d` is a
probability measure, so all relevant measures are finite.

### Endpoints

- At `r = 0`, the derivation remains valid: `s = 0`, each one-sided bound is `1`, and the stated
  right side is `4`.  The sharper trivial probability bound `≤ 1` is unnecessary.
- At `W = 1`, `d.W_pos` keeps `blockVarProxy` strictly positive.  Unit vectors exist, for example
  `EuclideanSpace.single 0 1`; T416 also records this in `exists_quarterSphereNet_one`.
- The argument uses neither a division by `r` nor an assumption `r > 0`.

## 3. Orientation and the cyclic `L = 3` case

`Gauss.Xentry_swap` gives pointwise

```text
xBlock N ω y x = (xBlock N ω x y)ᴴ.
```

This equality follows by matrix extensionality and `Matrix.conjTranspose_apply`.  Then
`Matrix.l2_opNorm_conjTranspose` gives equality of the two block norms.  No probability or
independence argument is involved.

This also supplies a concrete counterexample to orientation independence.  For `W = 1`, if
`Z = X_{xy}`, then the reverse orientation is exactly `conj Z`; its norm event is the same event,
not an independent copy.  Any union proof that multiplies probabilities or invokes independence
between these two orientations is invalid.

For every `L ≥ 3`, a distinct pair with `zdist L (x-y) ≤ 1` satisfies

```text
y = x + 1  or  x = y + 1.
```

Therefore all norm failures are covered by the `L` representatives `(x,x+1)`, indexed by
`x : ZMod L`; the reverse case uses the adjoint equality.  This remains exact for `L = 3`:
the representatives are the three edges of the triangle, while all six ordered adjacent pairs
are their two orientations.  The frequently quoted `2L` ordered-pair bound is valid but loses a
factor two; the T423 bound uses at most `L` norm events.

The current public distance API contains `zdist_one_le`, `zdist_neg_one_le`, and
`zdist_le_one_of_mem_sbSupport`.  The converse classification needed for this reduction is not
available publicly in the inspected dependency set.  T420 has a private
`eq_zero_or_eq_one_or_eq_neg_one_of_zdist_le_one`; a later union module should expose or locally
reprove its nonzero corollary.  This is a missing combinatorial Lean producer, not a mathematical
gap.

## 4. Quarter-net union and exact constants

T416 provides a finite `V : Finset (Gauss.BlockVec W)` with

```text
Gauss.IsQuarterSphereNet V,
V.Nonempty,
V.card ≤ 9^(2W),
‖M‖ ≤ 2 * Gauss.blockBilinearMax M V.
```

The exact packaged declaration is `Gauss.exists_quarterSphereNet_l2_opNorm`; the underlying norm
bound is `Gauss.l2_opNorm_le_two_blockBilinearMax`.

If `‖M‖ > 8`, the last inequality forces `blockBilinearMax M V > 4`.  Since `V ×ˢ V` is nonempty,
`Finset.exists_mem_eq_sup` extracts `v,w ∈ V` with

```text
‖⟪v, Matrix.toEuclideanCLM M w⟫_ℂ‖ > 4.
```

Every net point has norm one by `IsQuarterSphereNet.1`, so the fixed-vector estimate at `r=4`
applies.  `measureReal_biUnion_finset_le` or `measureReal_iUnion_fintype_le` then gives

```text
P(‖xBlock‖ > 8)
  ≤ V.card^2 * 4 * exp(-(3/2)W*4^2)
  ≤ 4 * 9^(4W) * exp(-24W).
```

No independence among net events is used.  The exponent arithmetic is

```text
(9^(2W))^2 = 9^(4W),
(3/2) * 4^2 = 24,
9^(4W) = exp(4W log 9),
```

so the bound equals `4 exp(-(24 - 4 log 9)W)`.

The numerical margin `24 - 4 log 9 > 15` is true.  A robust Lean proof of
`log 9 < 9/4` can use `Real.log_lt_iff_lt_exp` together with the first six nonnegative terms of
the exponential series via `Real.sum_le_exp_of_nonneg`; their rational sum at `9/4` is strictly
larger than `9`.  Linear arithmetic then gives the claimed margin.

## 5. Measurability and eventual polynomial tail

The full event needed downstream is already defined by T407 as
`APrimeFirstCellJGAllTime.adjacentBlockEvent`.  Its measurability is already compiled:

```text

APrimeFirstCellJGAllTime.measurableSet_adjacentBlockEvent
```

The proof uses entrywise measurability, finite products, the matrix norm, and finite
intersections.  Fixed scalar maps are also measurable as continuous finite-dimensional linear
expressions composed with `measurable_xBlock`; alternatively their coordinate-sum expansions
reduce this to `measurable_pi_apply`.  The finite union inequalities themselves do not require
independence.

After the orientation reduction and the union bound over `x : ZMod L`,

```text
P(adjacentBlockEvent N)ᶜ ≤ 4 * L * exp(-15W).
```

For `exampleGrow`, `Dims.bandwidth_grow` gives eventually
`N^(5/8) ≤ W`; the dimension field `d.dim` gives `L ≤ N` eventually because `W ≥ 1`.
Therefore

```text
4 * L * exp(-15W)
  ≤ 4 * N * exp(-15 * N^(5/8)).
```

For every fixed `D > 0`, multiply by `N^D` and use
`RBM.SumZeroDyn.eventually_exp_small` with

```text
C = 4,  k = D+1,  c = 15,  τ₁ = 5/8.
```

Together with the standard positive-`N` `Real.rpow` identities, it yields eventually

```text
4 * N * exp(-15 * N^(5/8)) ≤ N^(-D).
```

This establishes the requested eventual probability estimate.  T423 does not assert or add a
`HighProb` theorem, and it does not claim any `jG` closure.
