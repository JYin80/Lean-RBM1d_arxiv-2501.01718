`λ_j = semicircleLambda W hW j.val j.isLt`. The scratch uses the
positive-phase normalized matrix from T941,


The compiled `blockA_hermitian` gives `A.IsHermitian` for **every** permutation.
No unitary assumption is needed for this part: the actual quantiles are real,
so the diagonal is Hermitian and `Matrix.isHermitian_conjTranspose_mul_mul`
applies. For `0 ≤ u ≤ 1/2`, write

```text
d_j(u) = (sqrt u * λ_(π j) : ℂ) - i * (1-u : ℂ),
g_u(x) = semicircleFlowKernel u x =
         ((sqrt u * x : ℂ) - i * (1-u : ℂ))⁻¹.
```

The scratch proves the exact matrix factorization


and then the entry theorem, for **all** `a b : Fin W`, including `u=0`,

```text

  = permutationFourierSum W
      (j ↦ semicircleFlowKernel u λ_j)

```

Thus the coefficient is precisely `W⁻¹ ∑_j χ_(b-a)(j) g_u(λ_(π j))`,
with the project's **positive** character. The entry `a=b` was separately

For `a≠b`, a separate compiled lemma gives `(b-a : Fin W).val ≠ 0`;
the orientation is `b-a`, not `a-b`. T933's accepted zero-mode bound and
T939's all-time nonzero-mode permutation theorem therefore address exactly

## Inversion and nondegeneracy

The denominator proof takes imaginary parts: `Im d_j(u)=-(1-u)` and
`1-u ≥ 1/2`, so `d_j(u)≠0`, including at `u=0`. A scratch generic lemma
uses both `FᴴF=I` and `FFᴴ=I` and the pointwise nonzero denominators to prove

```text
(Fᴴ diag(d) F)⁻¹ = Fᴴ diag(j ↦ d_j⁻¹) F.
```

It uses `Matrix.inv_eq_left_inv` for `F`, `Fᴴ`, and the diagonal, followed by
`Matrix.mul_inv_rev`; it does not identify the inverse of a potentially
singular diagonal with pointwise inverses. The factorization uses the verified
`Matrix.diagonal_smul`, `Matrix.smul_one_eq_diagonal`,
`Matrix.diagonal_sub`, `Matrix.mul_sub`, `Matrix.sub_mul`,
`Matrix.mul_smul`, and `Matrix.smul_mul` APIs. T941's character bridge and
`fourierMatrix_diagonal_entry` supply the phase and exact `1/W` normalization.

At `W=2`, `π=id`, `u=1/2`, the scratch proves the resolvent entry `(0,1)` is

```text
(g_(1/2)(λ₀) - g_(1/2)(λ₁))/2 ≠ 0.
```

It uses the actual quantile inequality `λ₀<λ₁` from
`semicircleQuantileReflection_witness_two.1`, the positive square root of
`1/2`, and injectivity of complex inversion. This is stronger than merely
showing the block matrix is nonconstant and is a nonvacuous witness for the
resolved off-diagonal claim. `W=1` is covered by the two-sided unitary proof
and the diagonal theorem; `W=0` is excluded by the explicit `1≤W` premise.
