## Paper (5.42)–(5.44) and the smooth-weight replacement

I checked the stated paper PDF, `paper/250520-YinJun-v2.pdf`, directly at
(5.42)–(5.44). Formula (5.42) bounds the evolved tensor quadratic variation.
The proof then defines the stopping time (5.43) as the first time the
normalized profile `J*_{u,D}` reaches `(η_s/η_t)^4`; (5.44) integrates the
quadratic-variation bound only up to `T ∧ t`, using that stopped profile cap.
The following steps use BDG for the stopped martingale and show the stopping
event is negligible.

The project's route replaces this stopped-process argument by a smooth
prefix weight evaluated as a function of the single Gaussian matrix `X`.
Differentiating that weight produces the cross term, whose derivative is
supported precisely on the strict band
`1 < prefixSample/threshold < 2`. Therefore the project's conditional cross
consumers need the common raw source conditions and this transition on one
sample. The paper's stopped `J*` cap does not furnish that event relation, and
the T995 numerical schedule does not supply it either. This is a genuine
extra support obligation of the smooth-weight replacement, not a consequence
of (5.42)–(5.44).
