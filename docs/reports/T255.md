## 甲：做出来了，**但工单的字面陈述是假的，它编译了反驳**

⚠ **未取幂的比值 `ρ = ‖F‖/T` 的 `BddC2C` 是可反驳的**：`z ↦ ‖z‖` 在 `0` 处不可微，而 `0` **取得到**——那就是 `L = K`，**与 T250 用来反驳乘性导数界的是同一个配置**。
```lean
not_bddC2C_norm_div {T : ℝ} (hT : T ≠ 0) (a₀ a₁ a₂ : ℝ) : ¬ BddC2C (fun z : ℂ => ‖z‖ / T) a₀ a₁ a₂
```
所以工单第 1 步（「甲 + `bddC2C_pow_real`」）**按字面走不通**。

**但什么都没损失**：`testFun_softW_mul` 消费的是 `BddC2C (fun M => ∑ i ∈ S, ρ i M ^ (2*r))`，**从来不是** `BddC2C (ρ i)`。偶次幂**是**光滑的（`‖z‖^{2r} = (z.re²+z.im²)^r`），所以甲直接在 `^(2r)` 层交付：`bddC2C_ratio_pow_of_le`（常数显式，见报告顶部的签名）。

模型层的 `a₀/a₁/a₂` 由 `bddC2C_loopObs` + `bddC2C_loopObs_sub` 给：`b₀ = card(d.Idx N)·Bⁿ + Kb`、`b₁ = card·n·Bⁿ`、`b₂ = card·n²·Bⁿ`，`B = 2(1+η_u⁻¹)³`（`(+,−)` 时 `n = 2`），地板 `T₀ = Θ_N·W^(−D)`（`rpow_neg_le_tailT`）。**全部有限、显式、且不依赖被估的量。**

⭐ **额外做的、但很关键的一条**：`∑ᵢρᵢ^{2r}` 的 `BddC2C` 常数带一个**整的 `card S` 因子**——正是软最大值存在的理由所要避免的损失。它证了**不带这个因子的逐点梯度**：
```lean
norm_fderiv_sum_ratio_pow_le … : ‖fderiv ℝ (fun M => ∑ i ∈ S, (‖F i M‖ / T i)^(2*r)) M‖
    ≤ (2r) * (S.card ^ (1/(2r)) * (∑ i ∈ S, (‖F i M‖/T i)^(2*r)) ^ (1 - 1/(2r))) * (b₁/T₀)
```
这正是 `abs_deriv_softMax_le_affine` 在 `Λ = 0` 处的模型侧输入（第 5–6 步），再经 `rpow_card_le_exp_one` 把 `card^{1/2r}` 降到 `e`。

### ⭐⭐ 三条具名阻塞，全部在它的可写文件之外

1. **Ω-桥（硬停，也是乙接不上的真正原因）。** `WeightedMoment P J s t mesh lev Θ δ₀ W` 量化在**抽象**的 `(Ω, MeasurableSpace, P)` 上，`J : ℕ → ℝ → Ω → ℝ` 来自 `RBM.Sample B`（`Flow/Hypotheses.lean:225`）；而 `hasDerivAt_integral_Phi` 活在**具体**的高斯系综上：`∫ ω, Φ (Hflow d N s ω) ∂(P d)`（`Gauss/Generator.lean:803`）。
   **全仓没有任何引理把 `X.H N u ω` 与 `Hflow d N u ω` 认同，也没有把生成元恒等式搬到 `Sample` 上的东西。** 需要的形状：`(hX : X.H N u = Hflow d N u ∘ …) → ∫ ω, Φ (X.H N u ω) ∂P = ∫ ω, Φ (Hflow d N u ω) ∂(P d)`，或者一个 `Sample` 版的 `MatrixStein`。
2. **`J*` 是 max，不是软最大值。** `WeightedMoment` 的被积函数是 `|cutTrunc θ (J N u ω)|^{2p}`，`J = jS = jStar`（`Hierarchy/Step2.lean:642`）是 `Finset.max`；软最大值只经权重 `W` 进来。**在模型的指标集上 `jStar ≤ softMax r S ρ` 的比较，全仓没有做过**；`le_softMax`/`softMax_le` 只有抽象版。
3. **第 7 步就是那个估计本身，且落在未核实的指数上。** 仓库里唯一产出那个形状的是 `CutHypTheta.sat_oneStep`，那是 `J ≡ Θ ≡ 1` 的平凡见证。真的那条就是 (5.39)–(5.47)，即近场 `≲ R^{7/2}/R^8` 与远场 `≲ R·A^{−1/3}R^4` 的拆分。**它没碰那两个指数、不背书**，与 T230 一样无法从论文 §5.3 重建出那两个显示式。→ Cowork。

## 见证与 `p = 0`

`sat_testFun_softW_lkRatio`：取**真正的**两边 `(+,−)` 环 `⟨[true,false],[a₁,a₂]⟩` 作分子（不是常数），`z = i`、`η = 1`、`W = 2`、`D = 1`、`Θ_N = 1` 使分母地板 `1/2 > 0`，`r = 1`、`Ψ ≡ 1`。轮廓本身的非退化在上游（T250 的 `softRootProfile_ne_const`）。没有常数是 `∞`，没有一条依赖被估的量，`BddC2C` 全是关于矩阵函数的确定性陈述（随机不等式上没有 `∀ ω`）。

**`p = 0`：没走到**——交付的每条都不含 `p`（`p` 只在第 7 步经 `weightedMoment_bound_of_*` 进来）。按工单手查过：`p = 0` 时 `WeightedMoment` 的被积函数退化成 `∫ W`，逐点压制消失，**装第 7 步的人必须像 `APrimeHypOn.toAPrimeHyp` 那样单独分支**。
