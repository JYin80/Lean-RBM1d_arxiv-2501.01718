# T472 — independent coefficient and moment-order audit

## Verdict

The first-cell full-cross route is mathematically sound for every fixed
moment order `p >= 1`, but the interpretation attached to T469's extra
`BcrossActual := 2p * Bfull` is reversed.  The literal T457 `Bfull` is already
the exact `Bc` required by `APrimeDuhamelModel.momFlowDeriv_le`.  Consequently
the smallest true and useful T469 target is

```text
integral_0^v Bfull(r) dr
  <= C_p N^(alpha - 2 delta) (xRate v)^(-2),
C_p = (15p/4) (18432 sqrt(2) / exp(1) + 1).
```

The separate integral theorem for `BcrossActual` is algebraically true, but
`BcrossActual` must not be supplied as `Bc`: doing so pays an unnecessary
additional factor `2p`.  No `N`-exponent or moment-uniformity obstruction is
present in the actual downstream quantifier order.

## Exact coefficient and consumer

`APrimeCrossJointSplit.crossPart_active_le_jointEvent` proves, at `r > 0`,

```text
crossPart
 <= (1/(2 sqrt(r))) (2p)^2 (15/8)
      * phi(r)^((2p-1)/(2p))
      * [b sqrt(q(r)) + Eall rho^(1/(2p))].
```

Thus its deterministic coefficient is exactly

```text
(1/(2 sqrt(r))) (2p)^2 (15/8)
  = (15p^2/(4 sqrt(r))).
```

T457 defines

```text
Bfull(r)
  = (15p/(8 sqrt(r)))
      * [b sqrt(q(r)) + Eall rho^(1/(2p))].
```

Therefore the T361 conclusion is exactly

```text
crossPart <= 2p * phi(r)^((2p-1)/(2p)) * Bfull(r).
```

This is verbatim the `hcross` hypothesis of
`APrimeDuhamelModel.momFlowDeriv_le`, with `Bc = Bfull`.  The resulting
derivative bound contains

```text
2p * phi(r)^((2p-1)/(2p)) * (A(r) + Bfull(r)).
```

`MomentDuhamel.weightedMinkowski_of_deriv_le` then yields

```text
momNormW(v)
  <= momNormW(s)
     + 2 integral_s^v (A(r) + Bfull(r)) dr
     + sqrt((2p-1) integral_s^v g(r) dr).
```

Hence the final cross contribution is `2 integral Bfull`, bounded by
`2 C_p N^(alpha-2 delta) (xRate v)^(-2)`.  Supplying
`Bc = BcrossActual = 2p * Bfull` would still give a valid coarse estimate,
but would overpay by `2p` and is not the exact consumer wiring.

This agrees with the paper's (5.37)--(5.42) structure: the widened weight
creates the cross term through differentiation of the `2p`-moment, while
the deterministic rate entering the Minkowski estimate is the quantity
after factoring out the consumer's outer `2p`.  The paper formulas themselves
carry no moment-order variable.

## Quantifier and moment-order audit

The relevant producers choose `p` before the eventual matrix-size threshold:

```text
forall p, 1 <= p -> eventually N, ...
```

This order occurs in T468's `eventually_crossPart_le`, T469's
`eventually_integral_literalBfull_le`,
`APrimeOneStep.weightedMoment_of_stepBoundPos''`, and
`APrimeWeight.weightedMoment_of_stepBound_mono`.  The final
`Step2Bootstrap.WeightedMoment` conclusion is also pointwise in `p`:

```text
forall p, exists C > 0, eventually N, ...
```

Thus `C_p` may depend on `p`.  Its linear growth, and even the optional
quadratic constant obtained by integrating `BcrossActual`, is harmless for
fixed `p`.  A statement with the order `eventually N, forall p` is neither
proved nor needed.  The `p = 0` branch is separate in
`APrimeOneStep.oneStep_pzero`; the cross route assumes `1 <= p`.

## Moment, event, and moving-endpoint checks

- `APrimeFirstCellJointCrossRegularity.Ycut` is exactly
  `cutoff * actualY`.  On an active resident,
  `APrimeSmoothWeightActual.weight = cutoff^(2p)`, so
  `|Ycut|^(2p) = weight * |actualY|^(2p)`.  The exponent
  `(2p-1)/(2p)` in T468 therefore matches `momFlowDeriv_le` exactly.
- T468 uses one literal
  `APrimeFirstCellSharpCommonEvent.sharpCommonEvent tauPrime delta alpha N`
  simultaneously for the favorable prefix bound, current-QV bound, global
  envelope, and complement probability.  No independent-event product is
  introduced.
- The endpoint is the moving resident value
  `v = cutNetPt 0 transitionMesh N k`, uniformly for every resident `k`.
  No fixed endpoint is substituted.
- `positiveTwoJointCrossGeometry_of_prefix` gives, eventually, a sample in
  the same common event with `0 = u_0 < u_1 < u_2 <= firstCellT` and
  `2 <= cutNetTop`, together with all five sample regularity fields.  Hence
  the common event is nonempty on a positive resident.  It deliberately does
  not assert that `Good intersect transition` is inhabited; this is not a
  premise of the event-split estimate and does not invalidate the bound.

## Power and boundary audit

With T464/T461/T463's actual inputs,

```text
b = (16 sqrt(3)/exp(1)) sqrt(v) N^(alpha/2 - 2 delta),
sqrt(q(r))
  <= 384 sqrt(3) N^(alpha/2) eta_r^(-1/2) (xRate v)^(-2).
```

Their product is

```text
b sqrt(q(r))
  <= (18432/exp(1)) sqrt(v) N^(alpha-2 delta)
       eta_r^(-1/2) (xRate v)^(-2).
```

For `0 <= r <= v <= 1/2`, `eta_r^(-1/2) <= sqrt(2)` and
`sqrt(v) <= 1`.  T463 supplies

```text
Eall rho^(1/(2p))
  <= N^(alpha-2 delta) (xRate v)^(-2).
```

Therefore the bracket is bounded by

```text
(18432 sqrt(2)/exp(1) + 1)
  * N^(alpha-2 delta) (xRate v)^(-2).
```

Finally, `integral_0^v r^(-1/2) dr = 2 sqrt(v) <= 2`, which gives exactly
T469's literal constant `C_p`.  There is no extra `W` power: the bandwidth
and `A` losses have already been absorbed in the T461 rate estimates, and
the argument uses separate scale floors rather than the rejected product
condition.

At `r = 0`, `APrimeCrossJointSplit.crossPart_zero_r0` gives the formal zero
cross term and T457's `Bfull_zero` totalizes the rate to zero.  At `k = 0`,
`APrimeFirstCellJointCrossActual.crossPart_zero_k0` and
`APrimeFirstCellFullCrossBudget.integral_literalBfull_k0` handle the empty
interval.  Positive `k = 2` geometry prevents the integral assertions from
being witnessed only by that empty cell.

## Dependency audit and correction

The audited route is leaf-directed:

```text
T361 cross/event split -> T468 actual adapter
T457 integrability + T461/T463/T464 rates -> T469 integral budget
general Duhamel model -> Minkowski -> one-step -> weighted moment
```

None of the audited modules imports or uses next-cell `BoundsCore`, and no
reverse dependency from the general Duhamel, one-step, or weighted-moment
consumer into T468/T469 is present.  There is no dependency cycle.

The needed correction is documentary/interface-level: describe
`literalBfull` as the exact downstream `Bc`; retain `BcrossActual` only as an
optional direct coefficient envelope, not as the rate required by
`momFlowDeriv_le`.  No stronger theorem or extra hypothesis is needed.
