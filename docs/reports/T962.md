## Finite coordinates read at fixed `N`

`Coord d = Σ N, Idx d N × Idx d N × Bool` and `Ω d = Coord d → ℝ`
(`RBM1D/Gauss/Model.lean:196–199`). For a fixed `N`, `Gauss.Xentry` reads the real coordinate
on the diagonal and, for every strict `idxKey` upper-triangle pair `i,j`, both real and imaginary
coordinates `⟨N,i,j,true/false⟩`; the lower-triangle entry reuses that pair by conjugation. Thus
the exact finite used set is `Gauss.usedCoord d N` (`RBM1D/Gauss/Generator.lean:405–413`), mapped
into the full coordinate type by `crd d N`. Its cardinality is `n^2` for `n = Fintype.card
(d.Idx N)`: one real coordinate per diagonal entry and two per strict upper-triangle pair.
`Xmat_eq_sum` (`Generator.lean:415–418`) gives the decomposition over this finite set. The
reverse-triangle coordinates, diagonal imaginary coordinates, and coordinates at other sizes are
not read.

## Variance split and compatible centers

For any coordinate `⟨N,i,j,b⟩`, `gvar` is `Sblk` if `i=j`, and `Sblk/2` otherwise
(`Model.lean:201–219`). `gvar_crd_pos_iff_mem` (`Generator.lean:1313–1331`) identifies strict
positivity exactly with `i.1-j.1 ∈ sbSupport (d.L N)`. On support, the exact variances are
`1/(3W)` on the diagonal and `1/(6W)` off diagonal (`Generator.lean:1262–1304`); off-band
coordinates have variance zero (`:1306–1311`). The same support criterion applies to the two
tags, though only the upper-triangle tags/diagonal-real tag are used by `Xmat`.

The actual producers are `omegaOfHermitian` (`Generator.lean:1161–1166`) and
`Xmat_omegaOfHermitian` (`:1238–1260`): every Hermitian matrix `M` is exactly reconstructed at
`N`. If `M` is also `HermitianBandSupported` (`:1149–1152`), then
`omegaOfHermitian_eq_zero_of_gvar_eq_zero` (`:1344–1358`) proves that its encoded full sample is
zero at **every** zero-variance coordinate, including coordinates not used by `Xmat` and other
size indices. This is the needed compatibility condition: a proposed center with nonzero value
at a zero-variance coordinate cannot be in the support. The condition is non-vacuous;
`exists_nonzero_hermitianBandSupported` gives a rank-one diagonal example at every `d,N`
(`Generator.lean:1360–1379`).

## Probability API and compiled scratch statement

The installed proof route is already packaged in `RBM1D/Gauss/FiniteSupportCore.lean`:

* `effectiveCoords d J` filters a finite `J` by `gvar d c ≠ 0` (`:33–35`).
* `P_map_restrict` says the finite restriction has law
  `Measure.pi (fun c : I => gaussianReal 0 (gvar d c.1))` (`Model.lean:234–238`).
* For each positive-variance factor, Mathlib's
  `gaussianReal_absolutelyContinuous' 0 hvar` (`Mathlib/Probability/Distributions/Gaussian/Real.lean:259–264`)
  gives `volume ≪ gaussianReal`; `AbsolutelyContinuous.isOpenPosMeasure` and the finite `pi`
  open-positive instance (`Mathlib/MeasureTheory/Constructions/Pi.lean:614–622`) yield
  `gaussian_pi_open_pos` (`FiniteSupportCore.lean:37–44`). `effective_open_cylinder_pos`
  transfers any nonempty open subset of the active finite-coordinate space to positive `P` mass
  using `Measure.map_apply` and `P_map_restrict` (`:46–54`).
* `zero_variance_coord_ae_zero` follows from `P_map_eval` and `gaussianReal_zero_var`
  (`:60–66`). Finite intersection gives `zero_variance_coords_ae_zero` (`:68–77`).
  Consequently `support_cylinder_pos` shows that the hybrid cylinder (open on active coordinates,
  exactly fixed to zero on zero-variance coordinates) has positive mass (`:96–116`).

The scratch theorem packages the actual matrix producers with this positive-probability result.
It defines `matrixCoords d N := (usedCoord d N).image (crd d N)` and proves, for every
Hermitian band-supported `M` and every `r>0`, (i) exact reconstruction `Xmat … = M`, (ii) the
encoded values are zero at all zero-variance coordinates in `matrixCoords`, and (iii) the support
cylinder whose active restriction lies in the radius-`r` metric ball around the encoded center
has positive probability. The more general `support_cylinder_pos` proves the result for **any**
nonempty open set around that active center, hence for an open rectangular box as well. This is a
finite-coordinate support statement; it does not establish membership in a resolvent good event.

## Hypotheses / gaps

The generic finite-product lemma requires exactly `gvar d c ≠ 0` on its finite subtype and a
nonempty open set. The hybrid full-space version removes that variance hypothesis by filtering
the active coordinates, but it forces all discarded coordinates in `J` to their Dirac value zero.
For a matrix center supplied by the project, `M.IsHermitian` is required for exact readback and
`HermitianBandSupported M` supplies the zero-coordinate compatibility. No additional assumption
on `P`, variance positivity, or a paper event was inserted into the scratch theorem.
