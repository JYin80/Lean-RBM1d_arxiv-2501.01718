# T411 — moving-endpoint `hfamily` implementation audit after T405

## Verdict

The exact first-cell `hfamily` required by
`APrimeAssembly.aprimeSlot_of_widened_family` is **not currently produced by
the compiled interfaces**.  The obstruction is not the normalized generator:
`APrimeNormalizedGenerator.normalizedGeneratorBridge` already works for an
arbitrary fixed endpoint `v`, every `r ∈ [s,v]`, and the actual
`driftAt`/`qvAt`.  The first unavailable implication is the row-preserving,
active-support passage from the raw T409/T410/T408 inputs to those actual
moving-endpoint rates.

In particular, T408's latest exported theorem
`APrimeFirstCellQVRunningSmall.eventually_running_qv_le` has the literal
endpoint `v = 1/2` on both `qvAt` and `driftScale`.  Its conclusion is the
collapsed estimate `qvAt ... 0 (1/2) r ≤ N^ν`.  It cannot be used with the
required endpoint

```text
v = u_k = cutNetPt 0 transitionMesh N k
```

and cannot be converted to that endpoint by weakening: the endpoint occurs in
the tail `T_v`, in `ell_v`, in the propagator `U_(r,v)`, and in the denominator
`(eta_0/eta_v)^4`.  This audit therefore does not replace `v` by `1/2`, add a
hypothesis, or claim an A-prime slot.

The low-level QV theorem is already moving-endpoint correct:
`APrimeFullQV.qvAt_full_absorbed` accepts arbitrary
`0 ≤ s ≤ r ≤ v < 1`, keeps `D ≥ 60`, and bounds the actual uncut `qvAt` by
the square of `driftScale⁻¹ * rootProfile(...,r,v,...)`.  What is missing is a
new specialization of that theorem at `v=u_k` which preserves the T405 rows.

## 1. Audited interface chain

For the first cell set

```text
s = 0,
v = u_k = cutNetPt 0 transitionMesh N k,
0 ≤ r ≤ v,
D = 60,
x_r = eta_0/eta_r,
R = eta_0/eta_v,
A = W ell_v eta_v.
```

The exact consumer chain is:

```text
APrimeSlot'
  <- aprimeSlot_of_widened_family
  <- hfamily under APrimeWeight.widenedW
  <- weighted moment of jSnorm at v=u_k
  <- endpoint coordinate moments for coordAt ... 0 v v
  <- normalized-generator estimate on every r∈[0,v]
  <- weighted drift, current-QV, and prefix-gradient/current-QV rates
  <- T409 near eGpm + T410 far eGpm + quadGlue + full moving QV.
```

The target `hfamily` has the literal quantifier order

```text
forall delta, 0 < delta -> delta ≤ delta0 -> forall p,
  exists C > 0, eventually forall N, forall k ≤ cutNetTop,
    integral widenedW_p(delta,N,k) *
      |cutTrunc(N^(2 delta), jSnorm_N(u_k))|^(2p)
      ≤ C N^(delta p/2).
```

`weightedMoment_of_widened_family` transfers this estimate to the old,
moment-independent `piecewiseW`, and `aprimeSlot_of_widened_family` packages it
as `APrimeSlot'`.  For the first cell its fixed `t0<1` parameter can be taken as
`1/2`; that restriction is not a first-cell blocker.  It remains a blocker for
using the same constructor unchanged on arbitrary late moving windows.

The following model layers are already present and have the correct endpoint
parameter:

| Obligation | Existing declaration | Audit result |
|---|---|---|
| Fixed endpoint scale | `APrimeDriftTimeFamily.driftScale` | Exact `T_v(a) R^4` denominator |
| Evolved coordinate | `coordAt` and `flowY_coordAt` | Exact `U_(r,v)(L-K)_r / (T_v R^4)` |
| Evolved drift | `driftAt` | Exact `||U_(r,v) driftF_r|| / (T_v R^4)` |
| Current QV | `qvAt`, `qvAt_eq_evolved` | Actual uncut covariance of the same coordinate |
| Generator comparison | `normalizedGeneratorBridge` | Available for every `s≤r≤v<1`, `p≥1` |
| Drift time regularity | `continuousOn_momNormW_driftAt`, `intervalIntegrable_momNormW_driftAt` | Available, but gives no sharp rate |
| QV time regularity | `intervalIntegrable_rateNormW_qvAt` and the prefix-weight specialization | Available, but gives no sharp rate |
| Initial moving endpoint | `eventually_initial_hinit_gauss'` | Uniform in endpoint and coordinate; supplied from `BoundsCore` |

Thus the remaining work is in model producers and their assembly, not in the
abstract Duhamel or `APrimeSlot'` interfaces.

## 2. Exact T405 budgets at the moving endpoint

The pointwise drift target before time integration is

```text
a(r) = C N^ν eta_r^(-1) R^(-2) [
    x_r^(-1/2)
  + N^(4delta) A^(-1) x_r^6
  + N^(2delta+tau) A^(-1/2) x_r^(11/4)
  + N^(3delta+3tau/2) A^(-1) x_r^(9/2)].
```

The current-QV target is

```text
q(r) = C N^ν eta_r^(-1) R^(-4) [
    x_r^(-3/2)
  + N^(4delta+2tau) A^(-1/2) x_r^(19/4)
  + N^(6delta+3tau) A^(-1) x_r^8].
```

For a stored prefix time `u_j<v`, the corresponding normalized
prefix-gradient bracket is

```text
N^(ν-4delta) eta_0^(-1) [
    x_j^(-9/2)
  + N^(4delta+2tau) A^(-1/2) x_j^(7/4)
  + N^(6delta+3tau) A^(-1) x_j^5].
```

With `delta=c/1000`, `tau=delta/16`, and `0<ν≤delta/100`, the seven nonleading
rows map as follows.

## 3. T409 and T410: what can be reused literally

### T409 near drift

`eventually_near_on_active_support` is uniform over every active `k`, every
real `r∈[0,u_k]`, and every output pair.  It proves the raw near-output bound

```text
||eGpm_r(a1,a2)|| 1_near
  ≤ N^ν eta_r^(-1) (ell_r/ell_0)^3
      T_(r,60)(d(a2,a1)) 1_near.
```

It keeps the `D=60` floor through the internal far residual and exports
`eGpm_zero` at `r=0`.  The actual loop orientation is
`[a2,b,a1]`; `driftF_zero_eq_eGpm_add_quadGlue` uses
`eGpm(a 0,a 1)`, so the correct substitution is
`a1=a 0`, `a2=a 1`.  The output tail is then
`zdist(a 1-a 0)`, equal to the required output distance.  No orientation
repair is missing.

What T409 does not provide is `U_(r,v)` transport, division by the moving
`driftScale`, the `quadGlue` summand, or a weighted norm bound for `driftAt`.

### T410 far drift

`norm_eGpm_far_running_bound` is the useful row-preserving theorem.  It keeps

```text
cFar(W,ell_r) * J_r * kappa2,
168 * J_r * sqrt(J_r) * A_r^(-1),
J_r * sqrt(J_r) * L * sqrt(W^(-60)) / ell_r
```

as three separate coefficients multiplying the exact output tail.  The final
checkpoint `eventually_running_far_exact` additionally inserts the coarse
support bound `J_r≤N^(1/8)`.  That final cap is suitable for T412, but it is
not the T405 substitution

```text
J_r ≤ C N^(2delta+tau) x_r^4.
```

For the seven-row implementation, reuse
`norm_eGpm_far_running_bound` and supply the sharper dynamic cap separately.
The third T410 coefficient is an additive `D=60` floor error; it is not one of
the seven principal rows and must remain visible until its polynomial factor
is absorbed.

The exact moving-endpoint drift producer still has to combine the T409 near
branch, the row-preserving T410 far branch, and
`quadGlue_pm_eq_eLL`/`norm_eLL_le`, then apply a deterministic Uker tail
estimate such as the declarations in `Hierarchy/KernelDecay.lean`.  No
current theorem returns the resulting bound on
`APrimeDriftTimeFamily.driftAt ... 0 u_k r`.

## 4. T408 and full QV

The audited T408 working-tree state exports
`eventually_running_qv_le`.  Its complete conclusion is

```text
qvAt d 0 60 N sigPM a 0 (1/2) r omega ≤ N^ν
```

on positive support of `weight (1/100)`.  The preceding definitions
`runningRootProfile`, `rootProfile_le_running`, and
`normalized_running_le` also contain the endpoint `1/2` literally.

This theorem verifies that the fixed-half-cell full-QV chain can be closed,
including the near repair, quadratic and cubic far terms, and the spatial
leakage.  It does not supply either of the two interfaces needed here:

1. `qvAt ... 0 u_k r` for the current moving endpoint;
2. a row-preserving bound with the explicit `eta_r^(-1) R^(-4)`, `A_v`, and
   `x_r` powers needed by rows 4 and 5 and by time integration.

The correct starting point is therefore
`APrimeFullQV.qvAt_full_absorbed`, instantiated directly with `v=u_k`, not
T408's final fixed-endpoint theorem.  Its `rootProfile` already retains:

* the current near rate and repaired `W^(-1)` residual;
* the quadratic and cubic `diagFarRate` terms;
* the endpoint kernel with `((1-r)/(1-v))^2`;
* the propagated `W^(-60)` leakage;
* the actual uncut covariance and the exact `driftScale` denominator.

A new moving-endpoint arithmetic theorem must insert the support cap without
collapsing these pieces and derive rows 4 and 5.  A second theorem must apply
the same source at every stored prefix time `u_j`, preserve the
`sqrt(u_j)≤1` pullback, divide by the prefix threshold `N^(2delta)`, and feed
`sqrt_quadVar_prefixMatrix_le_exp_max`.  Those are rows 6 and 7.  T408 has no
prefix-gradient conclusion.

## 5. Cutoff support, dynamic block cap, and the common event

The favorable estimates in T409, T410, and T408 are stated under positive
support of `APrimeSupportRunning.weight (1/100)`.  The `hfamily` is quantified
over every `0<delta≤delta0` and uses the actual canonical smooth weight at
that `delta`.  There is no compiled theorem currently converting

```text
0 < weight delta ... omega
```

to the fixed-support hypothesis

```text
0 < weight (1/100) ... omega
```

for `delta≤1/100`.  The conversion is deterministic: for `N≥1`, the threshold
`N^(2delta)` is at most `N^(2/100)`, so positivity of the smaller-threshold
cutoff implies positivity of the larger-threshold cutoff.  This small bridge
is missing.

More seriously, the T405 rows require the dynamic block cap.  The repository
already contains
`APrimeSupportRunning.eventually_jG_le_constant_on_support`, which yields

```text
jG_r ≤ supportConstant * N^(2delta+xi)
```

under `APrimeSupportRunning.good tau' xi` and positive `weight delta`.
Taking `xi=tau=delta/16` gives the required power, up to an eventually
absorbed constant.  The T395 joint event instead hardcodes
`APrimeSupportRunning.good tau' (1/100)`, and the final T409/T410/T408
checkpoints hardcode the support level `delta=1/100`.  For arbitrarily small
`delta`, the fixed `1/100` loss cannot be renamed `tau=delta/16`.

No new stochastic estimate is needed.  A new common event must intersect, at
the same literal `tau'`:

* the T409/T410 source events with losses chosen after `delta` and `ν`;
* the length-four/length-six source event used by full QV;
* `APrimeSupportRunning.good tau' (delta/16)` for the dynamic block cap;
* the norm/modulus event used by the actual smooth support.

All component high-probability theorems accept the same `tau'`, so their
finite intersection is available.  What is absent is the packaged event and
the theorem exporting all favorable consequences from one membership proof.
Using separate existentially chosen `tau'` values would be invalid.

## 6. Weighted rates, cross term, and boundaries

Pointwise favorable estimates do not yet fill the norm slots used by the
one-step inequality.

* `driftEnvelope` has exactly the four T405 drift terms, and
  `direct_integral_drift_budget` integrates them, but its hypothesis
  `Adr(r)≤driftEnvelope(r)` is not produced for the actual weighted
  `driftAt`.
* `crossPart_active_le_jointEvent` correctly splits the full product
  `prefixGradient * sqrt(qvAt)`.  It still requires favorable bounds for both
  factors, a global polynomial envelope for the product, a quantitative
  complement probability, and integrability.  There is no theorem supplying
  those fields from the common first-cell event.
* The current QV norm and joint product need the standard favorable-event plus
  complement argument.  Finite-size measurability/integrability declarations
  exist, but the polynomial all-sample envelopes have not been connected to
  this moving-endpoint family.

The boundary pieces exist only separately:

* `normalizedGeneratorBridge` is valid at `r=0`, while the positive-time
  cross consumer assumes `0<r`;
* `crossPart_zero_r0`, `crossPart_zero_k0`, and `weightD_zero_k0` provide the
  corresponding zero branches;
* T409 exports `eGpm_zero`, but this alone is not a theorem about the complete
  `driftF=eGpm+quadGlue`;
* `weight_zero_prefix` gives the empty-prefix weight;
* `eventually_initial_hinit_gauss'` supplies the same left-endpoint datum for
  every moving endpoint;
* interval integrals vanish when `s=v`.

A final assembly theorem must join these facts.  In the first cell `k=0`
means `v=s=0`; it must take the initial branch directly.  For `k>0`, the
positive-time identity must be integrated and extended to `r=0` using the
available continuity/integrability statements.  No current theorem performs
that case split for the actual smooth weight.

## 7. Endpoint moment and old/new weight gap

`widenedW_le_weight_canonical` has the correct direction and the same
`delta,p,k,omega`: an estimate under the actual smooth weight implies the
requested estimate under `widenedW`.  This comparison is ready to use.

Two later connectors are missing.

First, there is no packaged endpoint theorem which rewrites
`coordAt ... 0 v v` using `Uker_self` and proves

```text
jSnorm_N(v) = R^(-4) + max_a |coordAt_a(v,Hflow_v)|
            ≤ 1 + max_a |coordAt_a(v,Hflow_v)|.
```

Second, paying the `L^2` coordinate family requires a higher fixed moment
`P≥p` and Lyapunov under one fixed subprobability measure.  The current
weight and generator APIs tie the smooth-weight exponent to the moment order,
and the only compiled old/new comparison is same-order.  There is no theorem
which keeps the target-order `p` weight fixed while proving a `2P` coordinate
moment, or equivalently proves that the higher-power cutoff equals one on the
target weight's support.  Consequently the current code cannot pay the
coordinate cardinality and recover `N^(delta p/2)` for every small requested
`p`.

This is a genuine final `hfamily` producer gap even after the seven pointwise
rows are supplied.

## 8. Minimal disjoint successor tickets

The following split keeps file ownership disjoint and exposes one usable
interface per ticket.

### T411a — arbitrary-`delta` support and common event

Exclusive new module: `Gauss/APrimeFirstCellMovingSupport.lean`.

Deliver:

1. positivity transfer from actual `weight delta` to the fixed `1/100`
   support used by T409/T410/T408 when `0<delta≤1/100`;
2. the sharper dynamic cap
   `jG_r≤C N^(2delta+delta/16)` on every `r∈[0,u_k]`;
3. one measurable high-probability event at one literal `tau'` exporting the
   T409, T410, length-four/six, dynamic-support, and modulus consequences.

No drift, QV, or moment integration belongs in this file.

### T411b — complete moving-endpoint drift rate

Exclusive new module: `Gauss/APrimeFirstCellDriftMoving.lean`.

Consume T411a, T409, the row-preserving T410 theorem, and the existing
quadGlue leaf.  Prove the complete raw `driftF` profile with the correct
`(a 0,a 1)` output orientation and all `D=60` floors, transport it by
`U_(r,u_k)`, divide by the exact `driftScale`, and export the pointwise and
weighted `Adr≤driftEnvelope` bounds.  Handle `r=0` for the full drift, not only
for `eGpm`.

### T411c — moving current and early QV rows

Exclusive new module: `Gauss/APrimeFirstCellQVMoving.lean`.

Instantiate `qvAt_full_absorbed` at `v=u_k`.  Preserve the near, quadratic,
cubic, repaired `W^(-1)`, and propagated `W^(-60)` terms through normalization.
Export the current rows 4--5 and the stored-prefix rows 6--7 through
`sqrt_quadVar_prefixMatrix_le_exp_max`.  Do not consume T408's
fixed-`1/2` final theorem.

### T411d — weighted generator and joint-event integration

Exclusive new module: `Gauss/APrimeFirstCellWeightedMoving.lean`.

Consume T411b/T411c.  Supply the favorable-event/complement bounds for the
actual drift norm, current QV norm, and the full
`prefixGradient*sqrt(qvAt)` product; feed
`crossPart_active_le_jointEvent`, `direct_integral_drift_budget`, the QV
integral consumer, and `normalizedGeneratorBridge`.  Include the `r=0`,
`k=0`, and `s=v` branches and return a coordinate moment estimate uniform in
`k`, endpoint, and output coordinate.

### T411e — endpoint family moment and slot

Exclusive new module: `Gauss/APrimeFirstCellHFamily.lean`.

Prove the endpoint `jSnorm`/`coordAt` comparison, the same-measure higher
moment cutoff lemma needed to pay `L^2`, the actual-smooth-weight family
moment, and then transfer it through `widenedW_le_weight_canonical`.  Export
the literal `hfamily` accepted by `aprimeSlot_of_widened_family`; only after
that theorem typechecks may a first-cell `APrimeSlot'` be constructed.

These five tickets are ordered by dependency and edit separate new files.
None requires a new probabilistic assumption.  The stopping condition for
T411 is reached now: the current declarations do not prove the moving-endpoint
row suppliers or the same-measure endpoint family moment.
