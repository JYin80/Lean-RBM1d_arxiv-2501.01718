## ⚠ 它自己标出的一条「要盯住」的输入（不是缺陷）

`hdom : ∀ ω, ∣cutTrunc θ (Jf ω)∣ ≤ ∣Y ω∣` **对所有 `ω` 量化、没有好事件限制**。
它**可以接受**，因为**两边都是随机量**（接口泛函 vs Duhamel 自己的截断泛函）——在 `Y = cutTrunc θ ∘ Jf` 处**取等号**，它把这一点编译成了见证（`integral_cutTrunc_le_of_momNormW_le_self`）。
⭐ docstring 里带了显式 ⚠：**确定性变体（`∣cutTrunc θ (J ω)∣ ≤ const` 对所有 `ω`）永远不许写**——那正是 V548 §6 对 (S5)/(S3) 点名的陷阱（`Θ′⁻¹√QV(J̃) ≤ 1` 形的常数**按字面不可满足**，真实大小是 `√κ̂ ≍ N^{−2δ}η_s^{−1/2}`）。
**本文件里没有任何这种形状**：`hdrift`/`hqv` 界的是**随机范数的积分**，从不用 `1` 去界一个随机量。
