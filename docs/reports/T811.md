## Claim and dependencies

For every `W : ℕ`, `k : Fin W`, actual `π : PermΩ W`, and `A : Finset (Fin W)`, `uniformPerm_nextImage_finset_given_actualPrefix` states that the mass of `ρ ∈ prefixCell W k.val π` with `ρ k ∈ A`, divided by the mass of that actual cell, equals

```lean
((A.filter (fun v => v ∈ unusedImages W k π)).card : ENNReal) /
  ((W - k.val : ℕ) : ENNReal)
```

The direct import is `PermutationNextImageUniformCell`, whose source imports the event/card ratio, unused-image count, and finite fiber counting. It has no import of T810 or a conditional-expectation target. The new module uses the existing `prefixCellNextFiber` subtype, not a surrogate sample space. The root file contains one point import of `PermutationNextImageFiniteSetCell` at line 139; the successful root build verifies the import closure is acyclic.

The proof's `prefixCellNextImageFinsetEquiv` identifies the event with the dependent sum of fibers over `v ∈ A`. Thus the event cardinal is their cardinal sum. If `v` was used before `k`, `prefixCellNextFiber_card_zero_of_used` makes its cardinal zero. If `v` is unused, `prefixCellNextFiber_card_eq_of_unused` equates it with the fiber at `π k`. That reference fiber is positive because `π` itself lies in the actual cell and has next value `π k`. `unusedImages_card` gives `W-k.val`, so the cell cardinal is `(W-k.val)` times the same positive fiber cardinal. The total permutation cardinal and then the positive finite common fiber cardinal cancel in `ENNReal`. No target theorem or conditional law is used as a premise.
