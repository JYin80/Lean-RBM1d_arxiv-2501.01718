## §14 — step 0: read-only `Psum(H.F)` audit (2026-09-22)

Set `m=n+2`, `A_u=B.scale E N u=W_N ell_u eta_u`, and let `K≥1` be the loop-decay radius parameter. The requested deterministic reduction is `norm_Qop_apply_le` (`Hierarchy/SumZero.lean:112`):

The coarse real-time consequence of `norm_vartheta_le` (`Hierarchy/SumZero.lean:99`) is `‖vartheta_u‖≤1`. The raw `‖F‖` term is controlled by `xiRhs_stochDom` and `DriftBound.norm_driftF_le` with the permitted weight `rho_u=eta_u⁻¹`; the issue here is the `Psum` term. For an `m`-argument tensor, `Psum` fixes its first label and sums its remaining `m−1` labels, so the untruncated error has `L_N^(m−1)` terms.

**Ward route.** Lemma 3.6 (`Loop/WardGeneral.lean:365`) is an identity for the primitive loop. Its packaged flow use, `SumZeroDyn.WardP` / `norm_Psum_lkT_le` (`Hierarchy/SumZeroDyn.lean:1647,3209`), bounds `Psum(lkT)` for `QGood` charges, not `Psum(H.F)`. No existing Ward identity for the drift `F` was found. Even if one applied the available `lkT` bound to an analogous term, its leading expression for `m` arguments would be

```
(W_N eta_u)⁻¹ · (2e(ell_u K+1))^(m−2) · K phi · A_u^(-(m−1)),
```

plus `(W_N eta_u)⁻¹ L_N^(m−2) delta`. After multiplication by `A_u^m`, the leading coefficient is `ell_u · (2e(ell_u K+1))^(m−2) K`, hence grows like `ell_u^(m−1) K^(m−1)`. Thus this packaged Ward estimate neither applies to `F` nor removes a positive `ell_u` power from `Psum` alone.

**Fast-decay truncation.** `FastDecayFlow.fastDecay_driftF_window` (`Gauss/FastDecayFlow.lean:453`), from the deterministic `DriftDef.fastDecay_driftF` (`Hierarchy/DriftDef.lean:430`), gives `FastDecay` for `F` at radius `4 ell_u K` with tail `delta_F`.
```
‖Psum F(x)‖ ≤ (2e(4 ell_u K+1))^(m−1) M_F + L_N^(m−1) delta_F.
```

With only `‖vartheta_u‖≤1`, the normalized main term retains `(2e(4 ell_u K+1))^(m−1)`, a positive `ell_u^(m−1)` factor. `M_F` already has the main scale `A_u^(-m) eta_u⁻¹` (`DriftBound.norm_driftF_le`, `Hierarchy/DriftBound.lean:245`), so multiplying by `A_u^m` leaves `eta_u⁻¹` times this factor; neither `eta_u` nor `A_u` cancels it. The tail is explicitly `L_N^(m−1) delta_F`, with any additive part of `M_F` also multiplied by the window factor.

**Available deterministic refinement, outside the coarse `vartheta≤1` step.** At real `u∈[0,1)`, `SumZeroDyn.norm_vartheta_real_le` (`Hierarchy/SumZeroDyn.lean:207`) gives `‖vartheta_u‖≤(cTwo52/ell_u)^(m−1)`. Indeed, `SumZeroDyn.norm_Qop_le_of_fastDecay` (`:2538`) already composes `norm_Qop_apply_le`, the window sum, and this sharper `vartheta` bound. With its radius parameter `4K`, it states

```

                  + (2 cTwo52)^(m−1) L_N^(m−1) delta_F.
```
