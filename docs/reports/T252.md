## 甲：转写做出来了，`γ = 1` 而不是 `1/2`

```lean
RBM.norm_lk_sub_le_lip : ∀ (d : Gauss.Dims) (N : ℕ) (ω : Gauss.Ω d) {E t₀ s v w : ℝ},
  |E| < 2 → 0 < s → s ≤ v → s ≤ w → v ≤ t₀ → w ≤ t₀ → t₀ < 1 →
  ∀ (x : LoopArg (d.L N) 2),
    ‖Step2.lk (Gauss.sample d) E N v ω x - Step2.lk (Gauss.sample d) E N w ω x‖
      ≤ |v - w| * RBM.lkLip d N E t₀ s
lkLip d N E t₀ s = L·W·2·(η_{t₀}⁻¹)² · greenLip E t₀ s  +  W⁻¹(1−t₀)⁻²
greenLip E t₀ s  = η_{t₀}⁻¹(1 + 3η_{t₀}⁻¹)/(2s) + η_{t₀}⁻²
```
**对每个 `ω` 成立**——`‖X‖` 从未进来，正因为 `mul_green_smul` 把它消掉了。`0 < s` 是处处显式的假设（**没有**被放宽成 `0 ≤ s`）；右端**始终带 `|v−w|`**，不是裸的绝对界。

链条：`gloopProd` 上的望远镜展开 `A₁B₁−A₂B₂=(A₁−A₂)B₁+A₂(B₁−B₂)`（§1；已有的 `gchain_eq_add_sum_gchainMixed` 只动 `z` 不动 `H`，所以这一条必须新写）→ 迹（§2）→ 流（§3）→ 再加上原始的 `K`，走一条新的预解式恒等式 `Θ_ξ−Θ_ζ=(ξ−ζ)Θ_ξS^{(B)}Θ_ζ` 与一个**逐项**的、不带 `L` 因子的界（§4）。

**`Kmod`**：在 `s_N ≥ N^{−C}` 与 `W_N L_N ≤ N`（`dim` 字段）下，`lkLip ≤ N^{1+C}·c(E,t₀)`，故 `(L−K)` 层面 `Kmod = 1 + C`；除以 `T_{u,D} ≥ W^{−D}`（`rpow_neg_le_tailT`）要付 `W^D ≤ N^D`，所以 `‖lk‖/T` 层面 **`Kmod = 1 + C + D`、`γ = 1`**。
