## 2. Exact coordinate reconstruction

The authoritative definitions are in `Gauss.Model` and `Gauss.Generator`:

```text
Coord d = Sigma N, d.Idx N x d.Idx N x Bool
Omega d = Coord d -> Real
idxKey(a,alpha) = W*a.val + alpha
crd d N p = <N,p>
```

`usedCoord d N` contains

```text
(i,j,true), (i,j,false)  if idxKey i < idxKey j,
(i,i,true)               on the diagonal.
```

The independently reconstructed sample is the finite sum

```text
omegaM = sum_{p in usedCoord d N}
           Pi.single (crd d N p) (if p.tag then Re M[p] else Im M[p]).
```

Injectivity of `crd d N` gives exact evaluation on every used coordinate and zero elsewhere.
The three `Xentry` branches then give:

```text
idxKey i < idxKey j:  Re M_ij + I Im M_ij = M_ij,
i = j:                Re M_ii = M_ii,
idxKey j < idxKey i:  Re M_ji - I Im M_ji
                       = conj(M_ji) = M_ij.
```

The diagonal equality is `Matrix.IsHermitian.coe_re_apply_self`; the lower-triangle equality
is `Matrix.IsHermitian.apply`.  There is no `sqrt(gvar)`, `1/sqrt(gvar)`, or `sqrt 2` factor.

This proves exact matrix equality, rather than equality almost everywhere or only after
restriction to effective coordinates.

## 3. Literal variance table and full-sample zero fixing

For `i=(a,alpha)` and `j=(b,beta)`, the definitions are

```text
Sblk i j = sbKre(a-b)/W,
sbKre(x) = 1/3 if x in {0,1,-1}, and 0 otherwise,
gvar(i,j,tag) = Sblk i j       if i=j,
                Sblk i j / 2   if i!=j.
```

Since `W>0`, the literal table is:

| Coordinate | Support condition | Exact `gvar` |
|---|---|---:|
| diagonal, either Bool tag | automatic (`a-b=0`) | `1/(3W)` |
| off diagonal, either tag | same or adjacent physical blocks | `1/(6W)` |
| off diagonal, either tag | physical-block difference outside `{0,1,-1}` | `0` |

Only the diagonal real tag is in `usedCoord`; the diagonal imaginary row in this table is an
unused coordinate of the infinite product.

For a band-supported `M`, every used current-size coordinate with `gvar=0` reads a zero matrix
entry.  The finite-sum definition also vanishes automatically on:

- all unused current-size coordinates, including reverse pairs and diagonal imaginary tags;
- all coordinates at every size `N' != N`.

Thus the full statement `forall c : Coord d, gvar c=0 -> omegaM c=0` is valid.  This is
strictly stronger than checking the zero coordinates in a current-size subtype.

## 4. Paired-block support, parity, and cyclic endpoints

Use representatives `0,...,L-1`, pair `(0,1),(2,3),...`, and leave `L-1` unpaired when `L`
is odd.  The pairing is performed on representatives before coercion to `ZMod L`; there is no
pair `(L-1,0)`.

For one pair and

```text
U = [[c,s],[-s,c]] tensor I_W,  c=s=1/sqrt(2),
```

direct multiplication gives

```text
U diag(A_b,A_c) U* =
  [[(A_b+A_c)/2, (A_c-A_b)/2],
   [(A_c-A_b)/2, (A_b+A_c)/2]].
```

The equality of the two off-diagonal blocks is compatible with Hermitian symmetry because
`A_c-A_b` is Hermitian.  An unpaired block contributes only `A_b` on its diagonal.  Hence all
nonzero target entries are in the same physical block or one consecutive adjacent block,
including the odd-`L` endpoint case.  Reverse entries have block difference `-1`, also in
`sbSupport`.

One encoded sample `omegaN` is used in every norm, raw, good-flow, centered, block, and prefix
row.  The carrier and prefix index may depend on `N`, but no row substitutes a second sample.

## 5. Carrier-margin audit

### 5.1 Norm

Each pair is a unitary conjugate of `diag(A_b,A_c)` and an unpaired block is `A_b`.  Therefore
`norm M_N <= 2`, so the strict row `norm M_N < N` holds eventually.  This is conditional on
the stated semicircle-block matrices but does not require (4.1)–(4.2).

### 5.2 Literal `rawEvent`, `n=3,4,6`

`APrimeGeneralMovingRawSources.rawEvent` quantifies over every
`p : TimeIcc s t N x LoopData L n` and uses the unindicated loop value.  For a Hermitian
matrix, the repository's resolvent-loop estimate gives

```text
norm Lval_n(u) <= eta_u^(-n) * W^(-(n-1)).
```

At the audited specialization `E=0`, `s=0`, `0<=u<=1/2`, one has `eta_u=1-u`, `ell_0=1`, and

```text
N^zetaSrc * Step1.aprioriRhs
  = N^zetaSrc * (ell_u/ell_0)^(n-1)
      * (W*ell_u*eta_u)^(-(n-1))
  = N^zetaSrc * W^(-(n-1)) * eta_u^(-(n-1)).
```

The quotient of the deterministic envelope by the unweighted right side is exactly
`eta_u^(-1)<=2`.  For fixed `zetaSrc>0`, eventually `2<N^zetaSrc`.  Hence all charge words,
block rows, closed-window times, and `n=3,4,6` satisfy the literal rows with strict margin.
No Fourier estimate or norm-event indicator is used.

### 5.3 `goodSetFlow` and centered rows

These rows are **not proved**.  They require a uniform deterministic construction with

```text
abs(W^(-1) sum_j g_u(lambda_j) - I) <= C/W
```

and simultaneous nonzero Fourier-mode bounds after blockwise permutations,

```text
abs(W^(-1) sum_j g_u(lambda_(pi_b j)) exp(2*pi*I*q*j/W))
  <= C*sqrt(log N/W).
```

The repository has no quantified producer of the quantiles, permutations, uniform time net,
or constants.  T643's bounded-difference/net sentence is a plausible proof plan, not durable
evidence.  The minus centered row follows pointwise by conjugation only after the plus row is
proved on the same sample.

### 5.4 Conditional `blockEvent` and `jG=1`

For the exact pair direct sum, `gmBlk(x,y)` can be nonzero only when `x,y` lie in the same
pair component.  A nonzero term in

```text
gsqBlk(x,y) = max_{x': SB(x,x') != 0} gmBlk(y,x')*gmBlk(x',y)
```

therefore has `zdist(x,x')<=1` and `zdist(x',y)<=1`; cyclic triangle inequality gives
`zdist(x,y)<=2`.  This includes an unpaired component and adjacency across the cyclic
endpoint in the *SB row*: even if `x'` is `0` and `x` is `L-1`, their cyclic distance is one,
so the same bound remains valid.

The literal hard cutoff in `jG` selects a pair only when

```text
ellStar(W,ell_u)/2 <= zdist(x,y).
```

On the closed first-cell window, `ell_u>=1`; for `Dims.exampleGrow`, `W->infinity`, so
eventually `ellStar(W,ell_u)/2>2` uniformly in `u`, including both endpoints.  Every selected
far numerator is consequently zero.  `tailT` is strictly positive, so each selected quotient
is exactly zero; unselected terms are zero by the `if`.  The finite supremum is zero and
`jG=1`.

The cutoff depends on time, so `jG` should not be called jointly continuous across cutoff
crossings.  This does not invalidate a fixed-`N` cylinder argument: the cutoff is independent
of the sample, the center numerator is zero for every selected pair, there are finitely many
pairs, Green entries have a uniform coordinate modulus on the compact time interval, and
`tailT` has a positive fixed-`N` minimum.  The preserving radius may be very small and may
depend on `N`.

### 5.5 Prefix and canonical transition

T643's estimate

```text
c1*(1+uW) <= jSnorm(omegaN,u) <= c2*(1+uW)
```

is not derived from a repository theorem or from the encoder.  The first-hitting argument,
mesh rounding, and canonical smooth-max comparison therefore remain conditional as well.
Joint upper-semicontinuity is not replaced here by a continuity assertion; in particular,
the time-dependent hard cutoff in `jG` is treated separately as above.
