## Mathematical preflight and exact producer match

I checked the public declarations and actual definitions in the accepted
T1145/T1146 and T1115/T1116 sources. T1145's
`eventually_selected_high_extended_good` returns an order `q ≥ p₀` and a
positive constant with its eventual bound on `good N`, uniformly over the
requested extended range. T1115's `eventually_bad_active_for_order` takes
that exact `q` and bounds the same integrand on `(good N)ᶜ` for all active
`k ≥ 2`. For `N ≥ 1`, `N^4 < k` implies `2 ≤ k`, so T1115 covers every
index in this ticket. The T1145 hypothesis `δ ≤ δ₀` is passed unchanged;
T1115 only needs `δ > 0`.

For each input `p`, set `p₀ = max(p, ⌈32/(3δ)⌉₊)`. Then `p ≤ p₀` and
`32 ≤ 3δp₀`; applying T1145 at `p₀` returns `q ≥ p₀`, hence
`q ≥ p` and `32 ≤ 3δq`. No conversion or mismatch occurs in the order.
The T1145 good-event constant is `Cgood`; T1115's bad-event constant at
this exact order is `2^(2q)`. Since both estimates have rate
`N^(δq/2)`, the full constant is `Cgood + 2^(2q) > 0`.

Before splitting the integral, the proof establishes integrability of the
full integrand from the actual weight's measurability and `0 ≤ W ≤ 1`, the
positive eventual cutoff scale, measurability and nonnegativity of the
endpoint `jSnorm`, and `Step2Bootstrap.integrable_weight_mul`. It then uses
the measurable `good N` / complement partition via `integral_add_compl`.
There is no change of event, endpoint, sample, measure, cutoff, weight order,
or exponent, and no union bound or mesh-cardinality loss.
