## Claim and dependency check

For a finite index type `n`, a Hermitian matrix `H`, `k` spectral parameters `E_i+iη_i`, and every `η_i>0`, the theorem states

`∏_i Im stieltjes(H,E_i+iη_i) = (card n)^(-k) ∑_{f : Fin k → n} ∏_i η_i / ((λ_(f i)-E_i)^2+η_i^2)`.

The only analytic input is the previously accepted single-factor formula `stieltjes_im_eq_normalized_specWeight` from `StieltjesEtaMonotone.lean`. The new proof applies it independently at each `i`, separates the product of `card(n)⁻¹` factors, and uses `Fintype.prod_sum` to enumerate every function `Fin k → n` exactly once. Thus the coefficient is precisely `card(n)^(-k)`, including at `k=0`; no factorial enters this identity. When `n` is empty, Lean's inverse convention and the empty sums preserve the stated algebraic identity.

The second proof partitions the same full function type by `Function.Injective f` and its negation using `Finset.sum_filter_add_sum_filter_not`. This is exhaustive and disjoint, including `k>card n`, when the injective part is empty. The combined theorem substitutes this partition into the product formula. No collision bound or cancellation is inferred.

`corrPairing` in `Universality.lean` sums over embeddings `Fin k ↪ n`, hence the same ordered injective tuples, but has a separate prefactor `card(n)^k (card(n)-k)! / (card(n))!` and a test-function summand. T1407 identifies the index set only. It does not assert that the injective spectral sum equals `corrPairing`, and no factorial from that pairing is lost in the spectral identity. `Claim223` compares expectations of exactly the products on the left at two flow times, with spectral parameters in (2.22); applying the pointwise T1407 identity to each Hermitian flow sample is the deterministic first step toward that consumer.
