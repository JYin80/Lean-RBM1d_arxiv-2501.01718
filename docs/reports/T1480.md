It is **not** a claim that the already-absorbed envelope theorem preserves a pointwise random factor `Xi^L(omega)` on its right-hand side: that stronger random-relative statement does not follow merely by reversing `Xi^L <= Lambda_m`. ## 3. Paper-route composition and full loss budget

Use `momNorm_Uker_QQ_event_untrunc_le` with source tensor `F_u`, `psi=Psi`, `kappaA=W_N`, `zeta=0`, and the existing `Xi_N`. Since `eta_u=1-u`, the theorem's `kappaA*((1-u)*ellHat_u)` is **exactly** `A_u`. The global `hGM` row follows from the accepted projected entry bound by division by `A_u^(2*m)`; it is not an additional on-event assertion.

The source's actual loop-decay theorem, inspected from the compiled import, states

`forall m0>=1, forall tau,D>0, eventually N, forall omega in Xi_N,
 forall u in [0,1/2], LoopDecay ... m0 (ell_u*N^tau) N^(-D) ...`.

Take `m0=2*m+2`. `FastDecayFlow.fastDecay_eeFun` then supplies, on the same event,

`FastDecay L (ell_u*K) delta F_u`, with `K=N^tau` and
`delta = m*W_N*L_N*N^(-D) <= m*N^(1-D)`.

A global crude resolvent bound supplies `e <= c_m*N`: from `norm_eeFun_herm_le`, use the spectral imaginary-part lower bound `1/2`, `W>=1` and eventual `L<=N`. Thus `hAe` is satisfied on `Xi_N` without another event.

The exact generic conclusion is

`momNorm_p Z <= cKerSumZero(2*m)*(4*K)^(4*m)*A_v^(-2*m)*momNorm_p Psi`

` + cKerSumZeroErr(2*m)*L^(2*m)*((1-s)/(1-v))^(2*m)*qqErr(L,m-1,ell_u,K,e,delta)`

` + Env*pr^(1/p)`.

There is no main-term `eta_s/eta_v` factor. The ratio in the **error** term is bounded by `2`, uniformly on the first half, and is absorbed in a constant depending only on `m`. The `zeta` term vanishes exactly.

## 4. Cheapest implementation on this bounded window

The preceding paper-route check is sufficient for RELEASE. A worker need not introduce additional reusable QQ-error machinery just to realize the released bounded theorem: another already compiled kernel producer gives a shorter corollary for this precise window.

`RBM.norm_Uker_apply_le` bounds a tensor by `C^(2*m)` times its max norm, assuming

`1 + norm((u-v)*xi_i)/(1-norm(v*xi_i)) <= C`.

At `E=0` every doubled charge has norm one. For `0<=u<=v<=1/2`, take the exact constant `C=(1-u)/(1-v)`. Apply it to `QQ_u F_u` and the accepted entry bound. The scalar cancellation is

`((1-u)/(1-v))^(2*m) * A_u^(-2*m)
 = (ell_v/ell_u)^(2*m) * A_v^(-2*m)
 <= 2^(2*m) * A_v^(-2*m)`.

Thus, for **every** sample,

`Z <= 2^(2*m)*A_v^(-2*m)*Psi`.

Moment monotonicity/homogeneity with the existing integrability then gives the actual transport theorem directly, using the envelope loss `epsilon` with **no new polynomial loss** and no second untruncation. Nonnegativity of `Psi` follows already from `eeFun_norm_le_qvEnvelope` and scale positivity, so a new public version of a private helper is unnecessary. This uses a compiled kernel theorem, not a new transport proof or new mathematical route. The same-event probability work remains exactly the work already discharged by the accepted envelope theorem.

The boundedness of `ell_v/ell_u` is essential to this shortcut. It is not a substitute for the manuscript's sum-zero argument on general moving windows. Do not extrapolate it to (5.92).
