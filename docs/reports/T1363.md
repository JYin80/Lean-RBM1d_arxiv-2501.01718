# T1363 — whole-paper general-Dims prefix-gradient preflight

## Verdict

**FAIL (scope blocker; no mathematical counterexample established).** The
requested arbitrary-`Dims` actual-prefix-gradient theorem cannot be proved by
the accepted free-loss wrapper plus the existing T613 producer. The exact
consumer/event and the direct T613 source chain are specialized to

generic producer. The scheduler correction explicitly rules out that scope
expansion. No Lean source was created or modified, and no theorem was weakened
to `exampleGrow`.

## Independent same-event nondegeneracy check

The inspected accepted witnesses do not provide the requested joint witness:

- T1305's `nondegenerate_free_loss_positive_cell_witness` gives a sample in
  `commonEvent`, an active first cell `k = 1`, and positive actual weight.
  It does not assert transition membership.
- T1051's `eventually_exampleGrow_target_transition` gives a strict-transition
  sample at `k = 2` on a positive first-cell window, but does not assert
  `commonEvent` membership.
- T1101's `eventually_early_prefix_transition_exclusion` proves that, on the
  specified first-cell window and T995 loss schedule, every norm-good sample
  has prefix ratio `< 1` for every active `k ≤ N^10`; hence none belongs to
  the strict transition.

For the particular T1303/T1305 first-cell schedule, the third result is a
direct obstruction to combining the first two witnesses. On that schedule
`commonEvent` is a subset of `rawCarrier`; `rawCarrier` contains
`sourceGood`, and `sourceGood` contains the literal norm event
`‖Xmat‖ ≤ N`. If `lambda` is the T1303 loss, set `delta := 100 * lambda`.
The T1303 constraint `lambda ≤ min (1/10000) (c/10000)` gives
`0 < delta ≤ min 1 (c/100)`, and T995's `deltaWeight delta = delta/100`
equals the actual weight loss `lambda`. Thus T1101 applies to the same
`E = 0`, `D = 60`, `s = 0`, `t = firstCellT tauPrime`, mesh, canonical order,
and actual weight loss. Since `k = 1,2 ≤ N^10` eventually, it proves that
`commonEvent ∩ transition` is empty on those positive first cells eventually.
This does not establish emptiness for later cells `k > N^10` or for every
possible window; neither cited transition producer supplies a joint witness
there. No nonzero actual cross/gradient observable or positive probability
for a same-sample intersection was inferred from separate witnesses.

The requested stronger joint nondegeneracy witness (positive window,
nonzero actual source/observable, and positive probability for the same
`commonEvent ∩ transition`) therefore remains unavailable. For the documented
first-cell `k = 1,2` candidate schedule, the early-prefix theorem rules out
such an intersection eventually. The generic theorem preflight also remains
blocked at the fixed-model producer/event mismatch described above.
