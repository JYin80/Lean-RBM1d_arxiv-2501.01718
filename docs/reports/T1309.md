## Verdict

the literal `APrimeGeneralMovingCrossProfileSlot.crossProfile` integrates on
every active closed target cell to
`(C_T C_A / Im(mE E)) N^(3h) R_v^(-2)`, uniformly in the active cell `k` and

## Claim and preflight

Put `h = lambda / 1000`, use the actual weight loss `lambda`, and set the cap
loss to `2 * lambda`. For each active cell, write

```text
v = cutNetPt s (targetMesh D) N k,
R_v = ratR E s N v.
```

The theorem assumes, on one eventual set of `N`, uniformly in every active
`k`, that

```text
transitionPrefixGradientRate(E,D,s,t,h,h,lambda,N,k)
  ≤ C_T N^h etaT(E,s_N)^(-1/2),
```

and, for every output `a` and every `u ∈ [s_N,v]`, that the **complete** actual
root profile with cap `2 * lambda`, including its residual and far terms,
satisfies

```text
absorbedRootProfile(E,s,h,N,u,v,D,profileCap(E,s,h,2*lambda,N,u),a)
  ≤ C_A N^(2h) etaT(E,s_N)^(-1/2) R_v^(-2).
```

These are premises, not conclusions inferred from the integral estimate. The
local public `profileCap` is definitionally the existing
`generalMovingBlockCap`. The literal cross profile is the product of those
two actual producers and `(2 * sqrt u)^(-1)`. Multiplying the bounds gives

```text
crossProfile(u) ≤ (C_T C_A / 2) N^(3h) etaT(E,s_N)^(-1) R_v^(-2) u^(-1/2).
```

For `0 ≤ s_N ≤ v < 1`, the exact integral of the formal inverse-square-root
function is `2 (sqrt v - sqrt s_N)`, also when `s_N = 0`. Since
`sqrt v ≤ 1`, `s_N ≤ sqrt s_N`, and
`etaT(E,s_N) = (1-s_N) Im(mE E)`,

```text
etaT(E,s_N)^(-1) ∫_[s_N,v] u^(-1/2) du ≤ 2 / Im(mE E).
```

This cancels the profile's factor `1/2` and gives the stated constant. It is a
direct scalar integration; no integral conclusion is assumed.
