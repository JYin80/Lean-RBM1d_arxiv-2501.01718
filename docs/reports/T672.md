## Minimal future theorem shape (specification only)

For a fixed `N E D s t`, a single fixed sample `ω` (used in every center and nearby expression), and an effective-coordinate metric space with center `x₀`, package the following interfaces:

1. `s N ≤ u ≤ t N < 1` throughout the parameter interval, so the full closed time interval lies below the resolvent singular time; do not drop either endpoint.
2. `W := B.W N > 0`, and retain the actual positive tail floor `W ^ (-D) ≤ tailT W ℓu ηu D dist`; use `tailT_pos` for denominator positivity.
3. The literal active cutoff in `jG` is closed jointly in `(u,x)`, from continuity of `u ↦ ellStar W (B.ell N u)` and the fixed block distance.
4. The active quotient `gsqBlk / tailT` is jointly continuous and nonnegative in `(u,x)` on the closed time window. The zero value off the closed active set then gives joint upper semicontinuity by the checked zero-extension construction.
5. The block-pair index is finite and nonempty, as in the existing `Finset.univ.sup'`; its current witness is the explicit pair `(0,0)`. Use the existing `gsqBlk_nonneg` interface for the numerator sign, together with denominator positivity.
6. The resulting joint gap `F(u,x) := jG(...,u,ω,x) - RHS(...,u,ω)` is strictly negative at the same center for every `u ∈ Set.Icc (s N) (t N)`.

The intended conclusion shape is only the uniform local implication

```lean
∃ ε > 0, ∀ u ∈ Set.Icc (s N) (t N), ∀ x,
  dist x x₀ < ε → F u x < 0
```

obtained from the compact closed time interval times the center singleton and the compact-thickening theorem. This records a future interface target; no such block-event neighbourhood or carrier resident is asserted here.
