# T493 — actual general moving-endpoint maximum-to-family bridge

## Scope

The new module `RBM1D/Gauss/APrimeGeneralMovingEndpointFamily.lean` proves the
literal pointwise family bound for the actual Gaussian `jSnorm` at every
active endpoint of a general deterministic moving window.  It imports the
accepted T489 endpoint-coordinate identity and `APrimeInit`; it does not add a
root import or modify any shared module.

## Main statement

`MovingEndpointFamilyBound E D s t mesh` says that, for every `N`, every
`k ≤ cutNetTop s t mesh N`, every cutoff `theta`, every integer `p ≥ 1`, and
every sample `omega`, with `v = cutNetPt s mesh N k`,

```text
|cutTrunc theta (jSnorm v)|^(2*p)
  ≤ 2^(2*p - 1) *
      (1 + ∑ a, ‖coordAt d E D N sigPM a (s N) v v (Hflow d N v omega)‖^(2*p)).
```

`movingEndpointFamilyBound_on_window` supplies this property under exactly the
ticket's window hypotheses: bulk energy `|E| < 2`, `60 ≤ D`,
`0 ≤ s_N ≤ t_N < 1`, and positive mesh.  The conclusion is pointwise in every
sample.  There is no event, probability estimate, `N`/`W` loss, or additional
time assumption.

## Proof chain

1. T489's `APrimeGeneralMovingEndpointCoord.jSnorm_endpoint_le` gives
   `jSnorm v ≤ 1 + max_a ‖coordAt ... (s_N) v v ...‖` for the actual endpoint
   coordinates.
2. `Step2Moment.jSnorm_nonneg` supplies the nonnegativity required by the
   finite-family inequality directly from the literal definition.
3. `APrimeInit.cutTrunc_pow_le_family` is instantiated with the full finite
   coordinate type `LoopArg (d.L N) 2`, `S = Finset.univ`, and
   `Y a = ‖coordAt ... a‖`.
4. `abs_norm` removes the redundant absolute value and the filtered sum over
   `Finset.univ` simplifies to the displayed full coordinate sum.

The local theorem `cutTrunc_jSnorm_pow_le_endpoint_family` records this exact
pointwise implication.  The moving-window wrapper uses
`netFinset_subset_Icc` to place every active endpoint in `[s_N,t_N]` and then
applies the local theorem.

## Boundary and satisfiability checks

`endpointFamily_zero` treats `k = 0` explicitly.  It proves
`cutNetPt s mesh N 0 = s N` and the same literal family inequality at that
endpoint.

`positive_length_admissible_family_witness` reuses T489's same-model witness.
It provides positive `tauPrime` and `c`, a window that is eventually strictly
positive in length, `Cond272Reg`, the T483 deterministic field package, the
T489 moving-endpoint identity, and the new family bound on
`targetMesh 60`.  Thus the hypotheses are jointly satisfiable on the same
positive-length Gaussian window.

## Deliberate limits

This ticket is pointwise only.  It does not assert coordinate integrability,
coordinate moment estimates, a weighted `hfamily`, `APrimeSlot`, or a
next-cell `BoundsCore`.  No such conclusion is used in the proof.
