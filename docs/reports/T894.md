# T894 — closed-flow semicircle equal-mass quadrature

## Result

**Standalone and root builds pass.** `RBM.semicircleQuadrature_closed_flow_explicit` proves, for every natural `W` with `1 ≤ W` and every real `u` with `0 ≤ u ≤ 1/2`, the exact deterministic bound

`‖(1/W) ∑_{j<W} (√u λ_j − i(1−u))⁻¹ − i‖ ≤ 8√2/W`.

Here `λ_j` is the T883 midpoint quantile. The public `semicircleQuadratureLambda` extends that function outside `j<W` only to make a total function for `Finset.range W`; `semicircleQuadratureLambda_eq` proves literal equality with T883's `semicircleLambda` at every summation index. No asymptotic or probabilistic hypothesis is introduced.

The paper source is solely `paper/250520-YinJun-v2.pdf`, printed page 7 immediately before (2.1). I inspected the PDF: it gives `ρ_sc(x)=(2π)⁻¹√(4−x²)_+` and `m_sc(z)=∫ρ_sc(x)/(x−z) dx`. Thus the denominator is `x−z`, fixing the positive `i` sign of the flow-line integral. The quantile estimate is an auxiliary consequence of that density, not a paper local law.

- On each cell, T883 gives `γ_j<λ_j<γ_{j+1}` and exact mass `ENNReal.ofReal(1/W)`. `qcell_real` converts that mass to `Measure.real=1/W`. The integral norm bound is `2√2(γ_{j+1}−γ_j)/W`.

- `semicircleQuadrature_zero` establishes exact value `i` for all `W≥1` at `u=0`, so the error is exactly zero. `semicircleQuadratureLambda_one_zero` identifies the `W=1` midpoint with zero using `F(0)=1/2` and inverse uniqueness. `semicircleQuadrature_one_half_error` establishes the **exact error one** at `W=1,u=1/2`, since the kernel there is `2i`.
