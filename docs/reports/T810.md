## Result

The module proves, for every `W`, `k : Fin W`, actual permutation `π`, and
`A : Finset (Fin W)`,

```lean
uniformPerm W {ρ | ρ ∈ prefixCell W k.val π ∧ ρ k ∈ A} /
  uniformPerm W {ρ | ρ ∈ prefixCell W k.val π} =
    ((A.filter (fun v => v ∈ unusedImages W k π)).card : ENNReal) /
      ((W - k.val : ℕ) : ENNReal)
```

The proof gives an equivalence between the event subtype and the dependent
sum of next-image fibers indexed by values in `A`. Its cardinal is the sum of
fiber cardinalities over `A`. Used values have zero fibers by T776; unused
fibers all have the same positive cardinality by T795. The event count is
therefore the number of unused values in `A` times one common fiber count.
The actual-cell count is `(W-k.val)` times that same positive count. The
uniform-permutation mass factors have the same finite denominator, which is
cancelled in `ENNReal`.

No hypotheses were added. `uniformPerm_nextImage_finset_actualPrefix_nonzero`
records that the actual cell mass and the natural denominator are positive,
and that the cell mass is finite.

## Boundary and nondegeneracy witnesses

- `W=0`: `uniformPerm_nextImage_finset_no_index_zero` proves there is no
  `k : Fin 0`.
- `W=1, k=0`: `uniformPerm_nextImage_finset_one` proves the full set of images
  has quotient one.
- `W=2, k=0`: each singleton image set has quotient `1/2`. The theorem also
  embeds `prefixCellNextFiber_two_witness`: identity and swap are distinct
  realized samples in the two respective nonempty fibers, and both fiber
  cardinalities are positive.
- Final valid reveal `k.val + 1 = W`:
  `uniformPerm_nextImage_finset_last` gives quotient one when `π k ∈ A`, and
  zero otherwise. The unused set is proved to be exactly `{π k}`.
- For every valid `W,k,π`, the actual permutation `π` witnesses membership in
  its prefix cell; the nonzero theorem additionally exhibits the required
  positive event-cell mass and positive denominator.
