## Scope and source check

The consumer is the coefficient check in formula (A) of `docs/reports/T1424.md` §3.2. Its
inner polynomial estimate is the derivative of `P_q(x) = ∑ i, x i ^ q` on an arbitrary finite
coordinate type, for even `q ≥ 2`, `1 ≤ j ≤ q`, all `x` including vectors with zero
coordinates, and arbitrary `j` directions. The required estimate uses the finite q-norm
`F_q(x) = (∑ i, |x i|^q)^(1/q)` without a dimension factor. The accepted
`RBM1D/Gauss/CutoffBounds.lean` has first- and second-order smooth-maximum estimates, but not
this polynomial all-order statement. The T1430 partial source is unaccepted and was not
imported. The targeted project/Mathlib search recorded in
`docs/reports/V6-power-sum-higher-derivative-preflight.md` found no duplicate source theorem.

The prescribed paper's formula (4.12) uses the random, unsmoothed loop-maximum scale. This
module is a deterministic polynomial lemma; it introduces no event, sample, time window,
active-cell, `N`, or loss-exponent quantifier and does not construct `Pr`, `Yr`, or an actual
Gaussian producer. Its witness below is a single deterministic argument tuple satisfying both
the zero-coordinate and nonzero-derivative requirements. A later stochastic composition still
has to supply its actual same-sample/event inputs.

## Proved public statements

In `RBM.Gauss.PowerSumHigherDerivatives`, the source defines
`powerSum q x = ∑ i, x i ^ q` and
`qNorm q x = (∑ i, |x i| ^ q)^((q : ℝ)⁻¹)`. It proves:

```lean
iteratedFDeriv_powerSum_apply (q j : ℕ) (hj : j ≤ q)
    (x : ι → ℝ) (v : Fin j → ι → ℝ) :
  (iteratedFDeriv ℝ j (powerSum q) x) v =
    (q.descFactorial j : ℝ) * ∑ i, x i ^ (q - j) * ∏ m : Fin j, v m i

abs_iteratedFDeriv_powerSum_le_factorial (q j : ℕ) (hq : 0 < q) (hj : j ≤ q)
    (x : ι → ℝ) (v : Fin j → ι → ℝ) :
  |(iteratedFDeriv ℝ j (powerSum q) x) v| ≤
    (q.descFactorial j : ℝ) * qNorm q x ^ (q - j) * ∏ m : Fin j, qNorm q (v m)

abs_iteratedFDeriv_powerSum_le (q j : ℕ) (hqeven : Even q) (hq : 2 ≤ q)
    (hjpos : 1 ≤ j) (hj : j ≤ q) (x : ι → ℝ) (v : Fin j → ι → ℝ) :
  |(iteratedFDeriv ℝ j (powerSum q) x) v| ≤
      (q.descFactorial j : ℝ) * qNorm q x ^ (q - j) * ∏ m : Fin j, qNorm q (v m)
  ∧ |(iteratedFDeriv ℝ j (powerSum q) x) v| ≤
      (q : ℝ) ^ j * qNorm q x ^ (q - j) * ∏ m : Fin j, qNorm q (v m)
```

The first formula is exact and has no positivity hypothesis on any coordinate. The Hölder
argument is proved in the module: it normalizes each nonzero direction in the q-norm, treats a
zero direction separately, and uses a weighted finite AM–GM estimate. When `j = q`, the
`x`-factor has exponent zero and the proof handles that endpoint without requiring `x ≠ 0`.
The coefficient comparison `q.descFactorial j ≤ q^j` gives the second bound. There is no
coordinate-cardinality factor.

The required nondegenerate zero-coordinate witness is:

```lean
nonzero_zero_coordinate_witness (q j : ℕ) (hqeven : Even q)
    (hq : 2 ≤ q) (hjpos : 1 ≤ j) (hj : j ≤ q) :
  (iteratedFDeriv ℝ j (powerSum q : (Fin 2 → ℝ) → ℝ)
    (fun i => if i = 0 then 1 else 0))
    (fun _ i => if i = 0 then 1 else 0) ≠ 0
```

It uses `x = (1,0)` and all directions equal to `(1,0)`. Thus the same point has a vanishing
coordinate and a nonzero derivative for every permitted order.
