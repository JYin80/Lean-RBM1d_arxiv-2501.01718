## Exact remaining interface

T334's actual `qvAt` profile is conditional on pointwise Step-1 length-four
and length-six source bounds and the running `jG` support cap. Those must
hold on one common Gaussian event; this module neither constructs that event
nor changes T334's pointwise hypotheses. The missing analytic bridge is the
uniform weighted-rate comparison
`g(u)≤qvEnvelope(m,s,v,N,δ,τ,A,u)` for the *evolved* QV rate supplied to
`APrimeOneStep.qv_bound_of_envelope`, together with its interval
integrability. In particular, any `qvRate` used for the endpoint must be the
evolved version with the endpoint normalization, rather than the unevolved
diagonal rate. The deterministic integral and time-premise lemmas can be
applied only after that bridge and the numerical threshold are established.
