## 1. 先做审计，再写第一行 Lean

最有价值的一天不是写证明，是把论文从头到尾读一遍、标出**每一处用到路径性质的地方**。
结果决定整个项目的形状，而且可能是「这条路走不通」——那也要第一天知道。

本篇的审计结果，真正用到路径性质的只有三处 + 一处：

| 用到路径性质的 | 用在哪 |
|---|---|
| Lemma 5.3 的随机积分 | Duhamel 展开的那一半 |
| Lemma 5.5 的 BDG 鞅矩估计 | (5.24) 的证明 |
| (5.43) 的那一个停时 | Step 2 的自改进 |
| Def 2.1(i) 在不可数参数集上取并 | `≺` 的一致性 |

**决定性的是「没有」那一栏**：全文没有用到域流与适应性、Markov 性、两时刻联合律、Doob 不等式。
只要这四样一样都没用到，「过程」就只是一个记号——真正被用到的只有每个时刻的边缘律以及它随时间怎么变，
这两件事都可以不经过 Itô 得到。

## 2. 四件替换

### 2.1 枢纽：生成元的二阶项 = BDG 右端的二次变差

生成元恒等式：

```
∂_u E[Φ(H_u)] = ½ Σ_ij S_ij E[∂_ij ∂_ji Φ(H_u)]
```

用在 `|F|^{2p}` 上，二阶项长成 `|F|^{2p−2} · Σ_α S_α |∂_α F|²`，
这**逐字等于**论文 (5.25) 已经算出来的二次变差，也就是 BDG 不等式右端。

所以**不用重做任何分析**：论文那一大段估计原封不动留着，只是它现在由生成元产出，不再由 BDG 产出。

**先去你们的论文里找这个对应。找得到，路就通；找不到，别开工。**

## 3. 唯一承重的一块：高斯分部积分（Stein）

生成元恒等式的证明 = 在积分号下求导（链式法则给出 `(2√u)⁻¹ Σ_α ω_α ∂_α Φ`）
+ 每个坐标用一次 Stein（把 `ω_α` 换成 `方差_α · ∂_α`，产生的 `√u` 正好消掉 `(2√u)⁻¹`）。

**这一块完全与维数无关，可以整包拿走。** 三层：

| 层 | 内容 | 规模 |
|---|---|---|
| 一维实值 | `p′ = −(x/v)·p`（整条路线唯一的概率内容），然后 ℝ 上分部积分 | 约 160 行 |
| 一维复值 | 实虚部拆分，各用一次上面那条 | 约 80 行 |
| 矩阵版 | 见下 | 约 190 行 |

### 3.1 矩阵版别走 Fubini，走「重采样」

直觉路线（约化到 `Measure.pi` + 对一个坐标做有限 Fubini）的坑：要把被积函数沿有限指标集
分解成 `(I → ℝ) → ℂ`，需要一个「在 `I` 外任取默认值」的扩张，记号很脏。

便宜得多的是一条**测度不变式**：

```
upd c (ω, t) := 把 ω 的第 c 个坐标换成 t
((P) ⊗ γ_c).map (upd c) = P
```

「用同分布的独立样本重采样一个坐标，不改测度」。在可测长方体上验证即可
（`Measure.eq_infinitePi`，`c ∈ s` / `c ∉ s` 两种情形各一行乘积重排）。
然后 Stein 两边都沿这个映射推过去，乘积上 Fubini 分离出那个坐标，内层正是一维版本。

**独立性只在这一处用到。** 两个额外好处：

* 原以为必需的「只读有限个坐标」假设**根本用不到**（重采样恒等式对整个无穷乘积直接成立）；
* 方差为 0 的退化情形自动覆盖（`gaussianReal 0 0 = dirac 0`，两边都是 0），不必加非退化假设。

## 4. 先证确定性包络，它是免费的

排在最前面，因为它解锁后面全部：`Im z = η > 0` 就有

```
‖G‖_op ≤ η⁻¹        各阶导数 ≤ k! · η^{−(k+1)}
```

关键是**在全空间成立**，不是「在好事件上成立」。后果：

* Stein 要求的「全局有界」天然满足，**不需要磨光截断**；
* 它给出「`≺` ⟹ 矩」的反向桥（正向那座是 Markov）。有了双向桥，`≺` 与矩可以自由来回。

## 5. `≺` 不要动

容易犯的规模错误：既然要用矩，就把全文 `≺` 都改写成矩。**别这么干。**
实测：§5 有 141 处 `≺`、仓库里 157 条 `≺` 定理、98 个结构字段，
但真正需要矩形式的只有 **2 个鞅接口 + 4 处二次变差输入**。

**硬性约定**：对外一律保持 `≺`，矩只在证明内部出现。进证明前用反向桥升成矩，
跑完 Grönwall 用 Markov 降回 `≺`。这样论文的陈述一个字都不用改。

顺带一个对论文很重要的检查：本篇能做到**零处陈述改动、零处重新编号**，
是因为 Lemma 5.5 的陈述 (5.24) *本来就是矩不等式*——两边都是期望，BDG 只出现在证明里。
**先看你们那条关键引理的陈述是不是逐路径的**：如果是，改动预算完全不同，要提前跟作者谈。

## 6. 永远不要写 `axiom`

做不了的东西写成 `structure` 字段或定理参数。区别不是风格：

* 字段可以**原地换成定理，签名一个字不改**。我们先后卸掉了 BDG、停时、矩阵 Stein，
  十来张依赖它们的工单**一张都没返工**。
* `axiom` 会污染公理审计（对整个命名空间跑 `#print axioms`，只允许
  `propext / Classical.choice / Quot.sound`），而且没人知道哪天该把它拿掉。

配套：**卸载完成时不要顺手改进签名。** 卸 `MatrixStein` 时发现它的两条「有限依赖」假设
在新路线上用不到，仍然照收不误、直接忽略，就为了下游不动。

## 7. 已经替你们试过、都不通的捷径

| 捷径 | 为什么不通 |
|---|---|
| 用 n = 1 的层级绕开涨落平均 | 自耦合系数 `η_u⁻¹` 的积分是**对数**的，Grönwall 因子是多项式量级，`≺` 吸不掉；且演化核 `‖U‖ ≺ (η_u/η_t)^n ≥ 1` 是放大不是压缩 |
| 方差 / 正交性代替高阶矩展开 | `E_k[Z_k]=0` 加 minor 替换只到 `Ψ^{3/2}`，差 `Ψ^{1/2}`。方差只看二阶，看不到「每个指标至少出现两次」 |
| 高斯 Poincaré / Efron–Stein | `∂G_kk = −G_kj G_mk ≺ Ψ²` 给出 `Var ≲ N·Ψ⁴`，差 `N` 倍；完全没用上 `(1 − E_k)` 的结构 |

## 8. 哪些**不能**照抄

§2–§6 全部与维数无关。下面三条是 d = 1 的便宜账：

**闭式传播子是 d = 1 的偶然。** 最近邻 `S^(B) = ⅓(1 + T + T⁻¹)` 让 `(1 − ξS)K = δ` 变成三项递推，
特征方程 `ρ² − (3/ξ − 1)ρ + 1 = 0` 恰有一根在单位圆内，于是 `Θ_xy = c(ξ)(ρ^d + ρ^{L−d})`。
指数衰减、差分估计、`ℓ¹/ℓ∞` 界全部白送，我们因此**整个绕开了附录 B 的围道平移 + Poisson 求和**。
d ≥ 2 没有这个闭式，要老实走 Fourier 路线，单独排预算。

**组合层的几何会变。** 多边形典范划分 ↔ 无交叉配对是平面几何。树表示的*形状*可能还在，几何论证不会在。

**涨落平均的计数不因高斯而简化。** 高斯让前两步变干净（条件期望是精确 Fubini、
minor 与该行严格独立，不必走一般分布的矩方法），但计数那一步一点都没省。
**这里有个坑，务必先说**：小行替换只迭代一阶给出的是 `Ψ^{2p+1}`，目标是 `Ψ^{4p}`
（`p=1` 时是 `Ψ³` 对 `Ψ⁴`），标准证法要迭代到 `2p` 阶。
而且**任何 `≺` 或指示函数记账都补不回来**：消失引理依赖 `E_k[(1 − E_k)X] = 0`，
乘上好事件的示性函数就破坏它，且示性函数不是「只读非本行坐标」的，提不出 `E_k`。
**一开始就按 `2p` 阶设计归纳，别先做一阶版本再想补。**

## 9. 建议的顺序

1. **随机层审计**。逐处标出路径性质，特别确认 Doob / Markov / 两时刻联合律一处都没有。产出是文档，不是代码。
2. **确定性包络**：`‖G‖ ≤ η⁻¹` 与各阶导数界。免费，解锁后面全部。
3. **Stein 三层**：一维实值 → 一维复值 → 矩阵版（重采样路线）。
4. **生成元恒等式**。到这一步 Itô 已经不在关键路径上。
5. **对矩的 Grönwall + 两座 `≺` 桥 + 连续归纳**。
6. 然后才是模型自己的组合层。

1–5 是通用件。做完之后「随机层」在仓库里应该只剩几条分布相等的假设——
本仓库现在全文 133 个节点里还挂着假设的只有 4 个，其中两个是分布相等，
一个是随机积分的逐路径形状（矩路线只要它的期望版，那一版已经证了）。
