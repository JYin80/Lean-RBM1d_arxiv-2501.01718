# T616 — post-T608 arbitrary-charge `E \otimes E` QV preflight

## Verdict

### Independent-audit disposition

The exponent ledger and the conditional pointwise theorem design below are correct, but
`XiLKTwoCutQV.lean` is **not yet dispatchable**.  The proposed statement assumes both
`hapriori` and the genuine time-indexed `hEE`; this report does not provide a compiled
same-window producer or a simultaneous nondegenerate witness for those hypotheses.  T621 has
verified the conditional chain from `highProb_xiLowEvent` and the floored
`highProb_eeDecay_of_inputs'` (including `hOmega`, `LDEFlowDom'`, and literal (2.76)) through
`EEBridge.stochDom_norm_eeField`, together with a compatible `Step1.Hyp → Step1.apriori`
interface, but found no compiled simultaneous same-window witness.  Thus §8 remains only a
conditional API sketch and must not be implemented or described as closing the
arbitrary-charge QV row.

There is a second independent block at the Lean module level.  The proposed imports are not
pre-Step-3 clean: `APrimeQVEndpoint` reaches `Flow.FirstCell`, Step45 and
`Step6HierarchyGauss`; `XiLKTwoCutInitial` reaches Step45/Step6; and even the current
`Step2PP`/`LKDecayQuant` module closures reach Step45.  A successor must use the clean
`MomentDuhamelRhs` kernel/moment lemmas and first extract the needed stochastic producers into
genuinely upstream modules.  T626 owns that dependency audit.  The theorem-level mathematical
argument remains pre-(2.77), but that fact does not waive the repository's module-level
acyclicity rule.

The desired arbitrary-charge quadratic-variation row has a noncircular pre-Step-3 route, but it
is **not** obtained by composing the currently advertised wrappers verbatim.  Two losses would
make that composition dishonest:

1. `RBM.Gauss.hEEmom_of_stochDom` replaces its time-dependent control `gE N u` by a
   time-independent majorant `PhiE N`.  Applied as stated, it erases the required literal factor
   `A_u^{-4} eta_u^{-1}`.
2. `RBM.APrimeQVEndpoint.norm_Uker_eeFun_le_ratio` bounds the evolved tensor by the unweighted
   sum of all `L_N^4` tensor entries.  Taking moments after that estimate incurs an inner
   `L_N^4` family cost, which is not present in the target row.

The smallest honest next theorem is therefore a **pointwise evolved `E \otimes E` moment
profile**, conditional on the genuine `hEE` stochastic-domination input.  It should convert that
input with `momNormDom_of_stochDom` while the time `u` remains in the index, descend from moment
order `2P` to `P`, and then use `momNorm_Uker_apply_le`.  This preserves exactly

```text
R_{u,v}^4 * A_u^(-4) * eta_u^(-1) * Psi_E(N),
```

with no inner label-cardinality loss.  The time integral, square root, and the outer
`4 * L_N^2` all-charge family are later corollaries, not part of the first producer.

No part of this route uses (2.77), a Step-3 conclusion, or any of the excluded cutoff/A-prime
assembly interfaces.

## 1. Exact Step-1 source of `xiL_6`

The exact repository theorem is

```text
RBM.Step2PP.flow_xiL_apriori_le'
```

in `RBM1D/Hierarchy/Step2PP.lean`.  Its relevant specialization is `m = 6`:

```text
flow_xiL_apriori_le' X hE hs0 hst ht1 hapriori (m := 6) (by norm_num)
```

and it gives

```text
StochDom B.P (Step3.flowXiL X E s t 6)
  (fun N (_ : TimeIcc s t N) (_ : Ω) => Step3.flowR B s t N ^ 5).
```

Thus the deterministic factor is exactly

```text
Psi_E(N) = Step3.flowR B s t N ^ 5 = (ell_t / ell_s)^5.
```

The occurrence of the namespace `Step3` here is only definitional: `flowXiL` and `flowR` are
names for the uniform loop maximum and the ratio `ell_t/ell_s`.  The proof of
`flow_xiL_apriori_le'` invokes the Step-1 field `AprioriFlow`, scale positivity, and monotonicity
of `ell`; it invokes no Step-3 estimate.  The actual producer of `AprioriFlow` is
`RBM.Step1.apriori` in `RBM1D/Hierarchy/Step1.lean`, from `BoundsCore`, `Cond272`, the regular
lower-scale input, and `Step1.Hyp`.  Hence the source of `xiL_6` is precisely (2.73), with all
charges already covered by the maximum in `AprioriFlow`.

## 2. Source tensor and its real hypotheses

At `n = 0`, `RBM.Gauss.stochDom_norm_eeFun_det` combines

```text
hEE   : ||eeField|| \prec A_u^(-4) * eta_u^(-1) * xiL_6
hxiL  : xiL_6 \prec Psi_E(N)
```

to obtain

```text
||eeFun|| \prec A_u^(-4) * eta_u^(-1) * Psi_E(N).
```

Here `A_u = (band d).scale E N u = W_N ell_u eta_u`.  The arithmetic is literal:
`2 * (n + 2) = 4` and `2 * (n + 2) + 2 = 6`.

The `hEE` premise is not a free field and must not be described as a Step-1-only fact.  Its
current honest producer is

```text
RBM.EEBridge.stochDom_norm_eeField
```

with the following two event inputs:

- `RBM.Gauss.highProb_xiLowEvent`, the uniform polynomial lower event for `xiL_6`;
- `RBM.LKDecayQuant.highProb_eeDecay_of_inputs'`, the **floored** decay-event producer.

The latter requires the same-sample good-flow event, `LDEFlowDom'`, and the pre-Step-3 decay
input (2.76).  This is an admissible dependency for the present ticket, but it is a genuine
dependency and must appear in any self-contained adapter.  The unprimed route through
`LDEFlowDom` should not be used: the repository audit already identified that interface as the
unavailable one.  None of these inputs is (2.77).

## 3. Exact QV scaling ledger

For `q : LoopData (d.L N) 2`, `s_N <= u <= v < 1`, set

```text
R_{u,v} = (1 - u) / (1 - v),
A_u     = (band d).scale E N u,
Psi_E   = Step3.flowR (band d) s t N ^ 5.
```

The `E \otimes E` summand in `twoCoordDuhamelRhs` is exactly

```text
[cMDval' P 0 * integral_(s_N)^v
  momNorm P_gauss P
    (||Uker^(xi2(q.charge))_(u,v)
        (eeFun_u(q.charge))(append q.label q.label)||) du]^(1/2).
```

For `P >= 1`,

```text
cMDval' P 0 = 2 * (2 * P - 1).
```

The pointwise target is

```text
momNorm P_gauss P
  (||Uker^(xi2(q.charge))_(u,v)
      (eeFun_u(q.charge))(append q.label q.label)||)

<= C * N^(epsilon/2)
     * [R_{u,v}^4 * A_u^(-4) * eta_u^(-1) * Psi_E(N)].
```

Consequently its square-root contribution to the normalized row is

```text
A_v^2
  * [cMDval' P 0 * integral_(s_N)^v
      R_{u,v}^4 * A_u^(-4) * eta_u^(-1) * Psi_E(N) du]^(1/2)
```

times `C^(1/2) * N^(epsilon/4)`.  There is no additional `W_N`, `L_N`, or `eta` power:
all such dependence is already contained in `A_u^{-4} eta_u^{-1}` and `Psi_E`.

The fourth power is forced by the four coordinates of
`SumZeroDyn.xi2 E q.1`.  `RBM.APrimeQVEndpoint.norm_Uker_eeFun_le_ratio` verifies the same
pathwise expansion factor in the endpoint geometry of (5.42), but it is too coarse for the
moment proof because of its subsequent sum over all tensor labels.

## 4. Moment order and family costs

The source-to-moment bridge naturally proves even moments:

```text
momNorm P_gauss (2 * P) ||eeFun_b||
  <= C * N^(epsilon/2)
       * A_u^(-4) * eta_u^(-1) * Psi_E(N).
```

Lyapunov's inequality then gives the required order `P` for the QV integrand.  The evolution
must be performed with `RBM.Gauss.momNorm_Uker_apply_le`, which takes the kernel row mass
outside the moment norm by weighted Minkowski.  With four coordinates, its cost is exactly
`R_{u,v}^4`; it does **not** sum moments over `LoopArg (L_N) 4` and therefore pays no `L_N^4`.

This inner label issue is separate from the outer all-charge family in T596.  That family has
the exact cardinality

```text
# LoopData (L_N) 2 = 4 * L_N^2.
```

When the eventual all-charge cutoff theorem is assembled, its quantifier order must remain

```text
delta0, delta, epsilon, target p,
choose P >= p and P >= 4/epsilon,
choose C,
eventually N,
all v in the target mesh.
```

After applying the order-`P` estimate and descending to order `p`, the outer cost is exactly
`(4 * L_N^2)^(p/P)`.  It is not `4 * L_N^2`, and it must not be confused with the forbidden
inner `L_N^4` loss.  The proposed pointwise theorem itself quantifies `epsilon`, then `P`, then
`C`, `eventually N`, every mesh endpoint `v`, every `u` in the interval, and every `q`.

## 5. Why `hEEmom_of_stochDom` cannot be the final wrapper

`RBM.Gauss.hEEmom_of_stochDom` accepts a time-dependent `gE N u`, but its conclusion uses a
time-independent `PhiE N` after the premise

```text
gE N u <= PhiE N.
```

Taking `PhiE` to be a supremum over the interval would destroy the requested literal integrand
`A_u^{-4} eta_u^{-1} Psi_E(N)`.  The repair is local and already supported by the library:

1. index `momNormDom_of_stochDom` by `(u,q,b)`, with
   `Phi(N,u,q,b) = A_u^{-4} eta_u^{-1} Psi_E(N)`;
2. keep this `Phi` unchanged instead of applying `MomNormDom.control_mono` to a constant;
3. use the existing Lyapunov lemma to descend from `2P` to `P`;
4. apply `momNorm_Uker_apply_le` at order `P`.

The reverse bridge's side conditions are available without a new probabilistic idea:

- positivity follows from positivity of `scale`, `etaT`, and `flowR`;
- an eventual polynomial lower bound follows, for example, from
  `A_u <= N`, `eta_u <= 1`, and `flowR >= 1`, giving the harmless lower control
  `N^{-4} <= A_u^{-4} eta_u^{-1} flowR^5`;
- `RBM.Gauss.norm_eeFun_herm_le` gives a deterministic polynomial envelope, using the terminal
  `eta_t` for a uniform bound and the standing dimension/eta estimates;
- measurability and integrability come from the existing Gaussian continuity and envelope
  lemmas, including `continuousOn_eeFun_path` and `continuous_uker_eeFun_omega`.

These are proof obligations for the new wrapper, not extra stochastic hypotheses.

## 6. Endpoint and sample/event audit

For a positive mesh interval `s_N < v`, the pointwise profile above applies for every
`u in [s_N,v]`.  At the left endpoint `v = s_N`, the QV integral is exactly zero and must be
proved by the zero-length interval identity.  It should not invoke T596's positive-time cutoff
theorem.  Although the pointwise ratio itself is well-defined there and equals one at `u=v`,
the clean endpoint branch is simply the vanishing integral.

All random variables are evaluated under the single Gaussian probability measure
`(band d).P` and on the same sample `sample d`.  The high-probability events used to produce
`hEE` are converted to stochastic domination before the moment bridge; no event parameter
survives in the proposed conclusion.  In particular, there is no reuse of a `(+,-)` event to
assert a `(+,+)` coordinate, and no independent-copy or sample-switching step.

## 9. Nondegeneracy and current limit of the witness

The geometric and indexing assumptions are nonvacuous without using a first-cell producer:
`XiLKTwoCutInitial.positive_grid_boundsCore_witness` gives the general positive first grid step
for `Dims.exampleGrow`, `E = 0`, `s_N = 0`, together with `Cond272Reg`, `BoundsCore`, and a
genuine `(+,+)` two-loop coordinate.  Independently,
`APrimeQVEndpoint.ratio_witness` exhibits the positive interval `u = 0`, `v = 1/2`, where the
four-coordinate expansion factor is exactly `16` (and the displayed QV prefactor is `32`).

The conditional signature in §8 assumes `hEE`, so an eventual implementation must also
exhibit the named same-window `hEE` producer chain.  That chain is noncircular, but it remains
theorem-level only and conditional on the pre-Step-3 (2.76)/floored-LDE inputs described in
§2; the current module closure is not acyclic.  This report therefore
does not claim a compiled simultaneous Gaussian witness beyond those inputs.  Claiming one
from a first-cell package, an A-prime event, or (2.77) would violate the ticket boundary.
