# T488 — General moving-window initial `hinit`

## Result

Added `RBM1D/Gauss/APrimeGeneralMovingInitialHinit.lean`.  The module removes the
fixed terminal-time premise from the Gaussian initial-coordinate estimate under
the original moving-window hypotheses and `Cond272Reg`, while retaining the
exact `initialEvolvedNormAt`, `initTerm`, and `slotXi'` conclusion.

The main theorem is
`RBM.APrimeGeneralMovingInitialHinit.eventually_initial_hinit`.  Its quantifiers
fix `δ > 0`, `p ≥ 1`, and the measurable weights `0 ≤ W ≤ 1` before the eventual
quantifier in `N`; after that quantifier the conclusion is uniform over every
`v ∈ [s_N,t_N]`, output pair, and hence also includes the boundary value
`v = s_N`.

No flow-coordinate moment assumption, `hfamily`, `APrimeSlot'`, next-cell
`BoundsCore`, or fixed terminal endpoint is used.

## Polynomial scales

The endpoint floor from T473 gives

```text
N⁻¹ ≤ 1 - t_N ≤ 1 - v.
```

After absorbing the fixed positive factor `(mE E).im` by the eventual estimate
`(mE E).im⁻¹ ≤ N`, this yields the uniform spectral lower bound

```text
N⁻² ≤ etaT E v.
```

In the residual initial scale the Stieltjes factor cancels exactly:

```text
(etaT E (s_N) / etaT E v)⁻²
  = ((1-v)/(1-s_N))² ≥ N⁻².
```

Thus the moment bridge uses `Bexp = 2`.  Applying the all-sample `jS` envelope
with `cη = 2` gives exponent `D + 4`; `xiK ≤ N` gives `D + 5`, and absorption
of the fixed multiplicative constant gives the convenient envelope exponent
`K = D + 6`.  These inputs feed
`APrimeAssembly.momentDom_of_stochDom_of_eventual_envelope` together with
`initialEvolvedNorm_stochDom_sharp'`.  The final conclusion keeps the exact
small initial scale `N^(5δ/32) R_v⁻²`, expressed through `initTerm` and
`slotXi'`; no extra exponent loss is introduced there.

## Nondegenerate witness

`positive_length_hinit_witness` constructs the first grid cell at `E = 0` with
`s_N = 0` and `t_N = gridT ... 1`.  It provides the original moving-window
conditions, `Cond272Reg`, `BoundsCore_zero`, and eventual strict positivity
`s_N < t_N`.  Together with the main theorem it supplies the requested genuine
positive-length instance (for example with constant weight `W = 1`).
