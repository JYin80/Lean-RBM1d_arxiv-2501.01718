# T633 — later-prefix same-sample support audit

## Verdict

**Split verdict: PASS for a strict literal scalar transition with `0 < x_N < N`,
but FAIL for the same scalar sample in the literal raw carrier.**  Moving the
prefix past `k = 2` removes the norm obstruction found in T628.  The first new
strict-margin obstruction is instead the next component of `rawCarrier`, namely
`goodSetFlow`: at the closed endpoint `t_N = 1/2`, every scalar sample has
diagonal Green-function error exactly `1`, whereas `flowDelta N < 1` eventually.

Thus T628's fixed-`k = 2` calculation remains correct, but its inference that a
non-scalar direction is forced *by the norm row* is false.  A non-scalar direction
is nevertheless forced if one wants to enter `rawCarrier`, for the stronger
endpoint reason proved below.  This audit does not establish or rule out a
non-scalar common-support witness.

This is a feasibility audit, not a newly compiled theorem.  No Lean source, root
import, task/status file, paper-delta file, git index, commit, branch, or remote
state was changed.

## 2. Boundary prefixes

- `k = 0`: `prefixSample = 0`, so the strict lower transition inequality is
  impossible.  This follows directly from the empty prefix; the compiled theorem
  `APrimeGeneralMovingJointMeasurable.transition_k_zero_eq_empty` lives in the
  rejected/downstream T618 surface and is not admitted as an upstream dependency.
- `k = 1`: only `j = 0`, hence only `u_0 = s_N = 0`, is stored.  Since
  `Hflow d N 0 omega = 0`, this prefix is sample-independent.  Canonical
  calibration and the zero-field estimate give eventually
  `prefixSample <= exp(1) * (1 + N^(-10)) < threshold`, so no transition occurs.

Thus the first sample-dependent prefix is `k = 2`, but there is no reason to keep
`k` fixed while `N` grows.

## 3. A later scalar crossing below the norm cutoff

After `N`, set

```text
j_N = ceil(5 * M_N / N^2),
u_N = j_N / M_N,
k_N = j_N + 1.
```

Eventually

```text
5/N^2 <= u_N <= 6/N^2,
h_N < u_N,             3 <= k_N <= cutNetTop s t mesh N.
```

At the zero scalar sample, use `APrimeSmoothTransition.lk_scalarSample` and split
by the cyclic distance `r = zdist a b`.

- For `r = 0`, `norm_Theta_sub_identity` and the elementary resolvent denominator
  estimate give `|lk(a,a)| <= C u_N/W_N`.
- For `r >= 1`, `norm_Theta_apply_le_pow` gives
  `|lk(a,b)| <= W_N^{-1} u_N^r/(1-u_N)`.
  On this early window, the literal main part of `tailT` is at least
  `W_N^{-2} exp(-sqrt r)`.  Since `u_N < exp(-1/2)` eventually, the maximum of
  `u_N^r exp(sqrt r)` over integers `r >= 1` is attained at `r = 1`.

Consequently the exact ratio defining `jS`, uniformly at every stored time
`v <= u_N`, is at most `1 + C u_N W_N`.  Since eventually `W_N <= N` and
`u_N <= 6/N^2`,

```text
jSnorm(v, scalarSample 0) <= 2
```

for all stored `v`.  The public bound
`APrimeSmoothWeightActual.prefixSample_le_of_jSnorm_bound` and
`canonicalM_calibration` therefore yield

```text
prefixSample(scalarSample 0)
  <= exp(1) * (2 + N^(-10))
  < threshold deltaWeight N.
```

Now put

```text
x_end = 2/sqrt(u_N).
```

The last stored flow matrix is exactly `2 I`.  The scalar lower estimate
`APrimeSmoothTransition.jSnorm_transition_lower`, transferred to the literal
prefix by `jSnorm_net_le_prefixSample`, gives

```text
prefixSample(scalarSample x_end) >= W_N/64
                                  > 2 * threshold deltaWeight N
```

eventually, using `W_N >= N^(5/8)` and `deltaWeight < 1/4`.  Moreover

```text
0 < x_end <= 2N/sqrt(5) < N.
```

The scalar ray is continuous by
`APrimeSmoothWeightActual.contDiff_prefixMatrix` and the linear identity
`Xmat_scalarSample`.  The intermediate value theorem therefore provides
`0 < x_N < x_end < N` for which the normalized prefix is, for example, exactly
`3/2`.  This is the required strict literal transition.

The baseline estimate above is the essential correction to T628: replacing the
literal `tailT` by the crude floor `W_N^{-60}` loses too much at
`u_N asymp N^{-2}`.  Keeping the distance-dependent exponential and the exact
`Theta` power restores the uniform `O(u_N W_N)=O(N^{-1})` estimate.

## 4. Same-sample raw-carrier test, in literal order

For `omega_N = scalarSample d x_N`:

| literal row | result | strict margin |
|---|---:|---|
| `normEvent` | PASS | `norm (Xmat omega_N) = x_N < N` |
| `rawEvent n=3` | PASS | factor `eta_u^{-1} <= 2 < N^zetaSrc` |
| `rawEvent n=4` | PASS | same strict factor |
| `rawEvent n=6` | PASS | same strict factor |
| `goodSetFlow`, all times/endpoints | **FAIL** | endpoint error `1 > flowDelta N` |

The raw rows use the exact powers, not a schematic estimate.  On
`u in [0,1/2]`, `eta_u = 1-u >= 1/2`, and
`Gauss.norm_sample_Lval_le` gives

```text
norm(Lval_n) <= eta_u^(-n) * W_N^(-(n-1)).
```

With `s_N=0`, `Gauss.aprioriRhs_eq` identifies

```text
Step1.aprioriRhs_n = (W_N * eta_u)^(-(n-1)).
```

The quotient is exactly bounded by `eta_u^{-1} <= 2`, hence eventually strictly
below `N^zetaSrc`.  Thus the three literal right sides are respectively

```text
N^zetaSrc * (W_N eta_u)^(-2),
N^zetaSrc * (W_N eta_u)^(-3),
N^zetaSrc * (W_N eta_u)^(-5).
```

This argument actually holds for every sample, so it is not a scalar-ray artifact.

The next row fails for every scalar amplitude.  At the included endpoint
`t_N=1/2`, write `a = sqrt(1/2) x`.  For a scalar sample,

```text
Hflow = a I,   zt 0 (1/2) = i/2,   mE 0 = i,
green(Hflow,zt) = (a-i/2)^(-1) I.
```

Every diagonal entry therefore has the exact error

```text
abs((a-i/2)^(-1) - i)
  = abs(1/2 - i*a) / abs(a-i/2)
  = 1.
```

On the other hand `Gauss.flowDelta_le_rpow_neg`, with the fixed `c>0`, gives
eventually

```text
flowDelta d 0 t N <= N^(-c/6) < 1.
```

Hence `omega_N` is strictly outside `goodSetFlow`, including its endpoint, and so
outside `rawCarrier`.  Per the ticket's stopping rule, no strict-margin claim is
made for the later `centeredEvent` (either charge) or `blockEvent` (`jG`) rows.

## 5. Continuity, effective projection, and the measurable core

At fixed `N`, the scalar matrix uses only finitely many diagonal coordinates.
`Sblk_diag_pos` shows that these coordinates have positive variance; zero-variance
coordinates are discarded in the effective projection `I_N^+`.  The strict
transition, norm, and three raw-event margins, together with continuity, would
therefore produce a nonempty open cylinder in `I_N^+`.  The finite-coordinate
Gaussian law (`Gauss.P_map_restrict` plus mutual absolute continuity of the
nondegenerate one-dimensional factors) would give that cylinder positive mass.

This does not help here: the strict endpoint failure persists on a neighborhood
of the scalar point, so no such cylinder is contained in `rawCarrier`.

The T628 measurable-core gap also remains.  From

```text
commonEvent = measCore (Gauss.P d) rawCarrier,
commonEvent subset rawCarrier,
P(rawCarrier^c) = P(commonEvent^c),
```

one cannot infer `P(rawCarrier \ commonEvent)=0` without measurability/null
measurability of `rawCarrier` or an exact null-difference theorem.  This is
secondary to the scalar endpoint obstruction, which occurs before the core is
used.
