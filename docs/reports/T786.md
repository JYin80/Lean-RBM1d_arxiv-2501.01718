**PASS.** For every `W : ℕ`, `k : Fin W`, and actual permutation `π : PermΩ W = Equiv.Perm (Fin W)`, T785 defines

```lean
unusedImages W k π = Finset.univ.filter (fun v => ∀ i : Fin W, i < k → π i ≠ v)
```

## Dependency and proof audit

`PermutationUnusedImageCount` imports only `PermutationPrefixFiltrationCore`, whose project-free imports are Mathlib's uniform-measure and filtration modules. T711 defines `PermΩ W` as the full permutation group on `Fin W`; thus every `π` is bijective and its prefix is realized. The root now imports T785 at `RBM1D.lean:134`, after the separate T776 import. There is no path back to the root or to a conditional-law module.

The key private lemma establishes

```lean
(∀ i : Fin W, i < k → π i ≠ v) ↔ k.val ≤ (π.symm v).val.
```

In the forward direction, an earlier inverse image would contradict the unused predicate, since `π (π.symm v) = v`. In the reverse direction, `π i = v` forces `i = π.symm v`, contradicting `i < k`. `Finset.card_bij` then maps each unused value `v` to `π.symm v`, injectively by the inverse permutation, and reaches every index `j ≥ k` via `v = π j`. The remaining cardinal computation counts the complement of `{j : Fin W | j.val < k.val}` as `W-k.val`. Each implication is present in Lean; no cardinality or surjectivity premise is merely asserted.

The witness is nondegenerate: at width two both identity and swap are valid samples, while their remaining singleton images differ. The `Fin W` type rules out `k=W` and larger positions.
