# T528 — First-cell endpoint moment under the widened target weight

## Result

Added `RBM1D/Gauss/APrimeFirstCellEndpointWidenedMoment.lean`, importing
accepted T524 and T522.  For every fixed pair

```text
1 <= p <= P,
8000 <= P,
```

the closed theorem `exists_endpointWidenedMoment_with_resident` supplies one
`tauPrime > 0` such that, eventually in `N` and uniformly over every active
positive first-cell index `k`,

```text
momNormW (P d) (targetWeight tauPrime p N k) p
  (jSnorm ... N (endpoint N k))
    <= 1 / ratR ... N (endpoint N k)^4
       + N^(delta/2) *
           (etaT 0 0 / etaT 0 (endpoint N k))^(-2).
```

The weight is literally T520's `targetWeight tauPrime p N k` throughout.
The family contribution has exponent `delta / 2`, exactly as in T524.

## Fixed-size proof and integrability

T522's exact pointwise identity rewrites the endpoint observable as

```text
jSnorm(endpoint N k) = R_v^(-4) + familyMax N k.
```

The new lemma `integrable_targetWeight_familyMax_pow` proves the precise
integrability premise required by T522.  It uses the measurable widened
weight, `0 <= targetWeight <= 1`, and T521's unweighted integrability of
`|familyMax|^(2*p)`.  It stays on `Gauss.P d` and uses the same power
`2*p` as the target moment.

Theorem `endpointWidenedMomentAt_of_family` then applies T522's
coefficient-one `momNormW_const_add_le` and composes it with T524's
`familyWidenedMomentAt`.  No extra multiplicative coefficient or exponent
loss is introduced.

## Boundary branch and resident

`kZeroEndpointWidenedMoment` is separate.  It retains `endpoint N 0 = 0`,
the general endpoint estimate, and the exact ratio-one consequence

```text
momNormW (P d) (targetWeight tauPrime p N 0) p (jSnorm ... N 0)
  <= 1 + N^(delta/2).
```

The positive resident reuses T524's same sample in the same literal
`sharpCommonEvent`.  It retains event measurability, high probability,
eventual nonemptiness, active `k = 2`, positive endpoint, and both plateau
equalities

```text
targetWeight tauPrime p N 2 omega = 1,
weight tauPrime P N 2 omega = 1.
```

It also carries `endpointWidenedMomentAt tauPrime p N 2`.  Hence the result
is nonvacuous, including the boundary values `p = 1` and `P = 8000`.
