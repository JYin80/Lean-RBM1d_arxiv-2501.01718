# T1035 — General-moving integrability of the literal joint rate

## Verdict: mathematical preflight PASS; conditional proof complete

### Mathematical preflight

The paper source checked was only `paper/250520-YinJun-v2.pdf`, formulas
(5.42)–(5.44). Formula (5.42) gives the evolved QV profile, (5.43) defines
the stopping time from the threshold for `J*`, and (5.44) bounds the
quadratic variation of the stopped martingale by integrating that profile.
This ticket supplies only the `hZi` integrability input for the Lean cross
estimate. It does not identify the literal Lean transition/joint-rate with
the paper's stopping time, nor prove the paper's profile or stopping bounds.

The exact Lean observable is

```text
jointRate = transition.indicator
  (prefixGradient * sqrt (qvAt ...))
```

The T617 producer
`APrimeGeneralMovingJointGlobalPoly.eventually_prefixGradient_mul_sqrt_qvAt_le_poly`
bounds that product for every sample, every active target-mesh prefix (also
`k = 0`), every charge word and output, and every time in the closed cell.
For nonnegative `deltaWeight`, both factors are nonnegative; the indicator
therefore leaves this upper bound in place on the strict transition and
returns zero off it. Taking absolute values and the `2*p` power gives the
finite constant bound `jointEnvelope D N ^ (2*p)` for each fixed `N,p`.

T618's
`measurable_prefixGradient_and_jointRate` supplies measurability at precisely
the same `targetMesh D`, `canonicalM`, `k`, `sigma`, `a`, endpoint, `u`, and
sample. Its time hypothesis is exactly `u ∈ Icc (s N) (endpoint k)` and it
includes `k = 0`. Bounded measurability under the Gaussian probability measure
then proves integrability. No membership of the sample in a favorable event,
or in an intersection with the transition, enters this argument.

### Delivered theorem

Added `eventually_integrable_jointRate_pow` in
`RBM1D/Gauss/APrimeGeneralMovingJointRateIntegrable.lean`. Its quantifiers are
`p` fixed first, then eventually `N`, uniformly over all active `k`, all
`sigma`, `a`, and `u` in the same closed running-time cell. The integrand is
the exact `|jointRate ...|^(2*p)` required by
`crossPart_active_le_jointEvent`, with the actual transition indicator and
canonical smoothing order retained. The existing assumptions are exactly
those needed by T617/T618: `|E| < 2`, `60 ≤ D`, the ordered nonnegative moving
window below one, positive `c`, `Cond272Reg`, and `0 ≤ deltaWeight`.

The file also re-exports T995's
`scheduled_positive_cell_witness` as `t995_positive_cell_witness` for the
nondegenerate scheduled common-event / positive-weight window context. This
witness does not assert that its sample is in the strict transition set, and
it is not used to claim such an intersection.
