## Inputs still required for the concrete `jSnorm` application

1. A concrete differentiable power weight and derivative, with `Gauss.WeightC1`, and a bridge from T265's matrix derivative to the `wD` argument of `crossAbsSum`.
2. A **global pointwise** S5 estimate in the `crossPart_le_of_S5_event.hS5` shape. T265 provides the core matrix inequality, but its `hK` (the rescaled weight gradient rate at the same matrix) still needs a concrete bound and normalization for the chosen prefix weight.
3. The sharp evolved (5.42) `EvolvedQVBound` on `E`. T275 defines this interface; T277 has not yet proved the desired `QBd` envelope.
4. Global, polynomial in `N` envelopes for drift, evolved QV, and the cross absolute sum. `WeightC1` and `TestFunT₁` contain global derivative bounds, but this file does not assemble the exact paper-scale polynomial constants.
5. Integrability/measurability for the chosen drift and evolved observable. The sharp cross theorem explicitly lists `hYm`, `hQm`, `hYi`, `hQi`, and `hProdInt`. The last follows from bounded concrete test functions but is not yet wired here.
6. For each fixed `δ,p`, a measurable auxiliary event `E_{δ,p,N}` with `P(Eᶜ)` sufficiently small. With polynomial `Env_N` of degree `a`, choosing the `HighProb` exponent greater than `2p(a+1)` makes `Env_N·P(Eᶜ)^(1/(2p)) ≤ N⁻¹` eventually. This arithmetic and the actual joint S3/Step 1 event supplier are still to be instantiated; no uniform event across all `δ` is requested by these lemmas.

`crossPart_le_of_S5_event` gives a conditional route to the `hcross` inequality, not a completed model proof. It has the needed moment exponent but still requires the concrete S5 normalization, polynomial complement budget, and sharp evolved (5.42). The same qualifications apply to `hdrift`/`hqv`; T280c supplies event splitting, not all model estimates.
