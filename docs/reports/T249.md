## 甲：**反例成立**——`CutHypEv.modulus` 在 `s ≡ 0` 上 `¬Nonempty`

Cowork 的论证是对的，而且**比他写的更强、更便宜**：**不需要 `G_h` 跨块 `O(1)` 对 `W^{D−2}` 的量级估计，也不需要 `K` 的任何界**。关键是两件已编译的事：

1. **`u = 0` 处整个泛函恒为 1**（`jSfarSm_zero`）：`H_0 = 0` ⟹ `L_{0,σ,a} = K_{0,σ,a}`（(2.67)，即仓库现成的 `gloop_zero_zt_zero_eq_Kgen`）⟹ `(L−K)_0 ≡ 0` ⟹ `J*^{sm}_{0,D} = 1`，**对所有 `ω`**。
   所以 `s ≡ 0` 时取 `w = 0`，`modulus` **根本不是连续模而是绝对界** `J*^{sm}_{v,D}(ω) ≤ 1 + N^{Kmod} v^γ`（`jSfarSm_le_of_modulusEv_zero_start`），右端 `v → 0` 时趋于 1。
2. **同一个 `z_v` 下远场 loop 确实在动，幅度与 `v` 无关**：取 `A` = 块对换对合置换阵（`blockSwap`，`A² = 1`，故 `(A−z)⁻¹ = (1−z²)⁻¹(A+z)`，`green_involMat`），则 `L_{(+,−),(a₁,a₂)}(A) = W⁻¹(1−z²)⁻¹(1−z̄²)⁻¹` 而 `L_{(+,−),(a₁,a₂)}(0) = 0`。流 `H_v = √v·ω·A` 在 `ω = v^{−1/2}` 处给 `H_v = A`、在 `ω = 0` 处给 `H_v = 0`，**`K_v` 两边直接抵消**，故两点中必有一点 `‖(L−K)_v‖ ≥ W⁻¹‖1−z_v²‖⁻²/2`（`exists_jSfarSm_ge_swapSample`）。

**编译出来的否定结论**：
* `not_cutHypEv_swapSample_of_far : ¬ Nonempty (MomentDuhamelCut.CutHypEv B.P (fun N u ω => jSfarSm (swapSample B b) E D N u ω) (fun _ => 0) t Θ)`
* `not_entryModulusEv_swapSample_of_far : ¬ EntryModulusEv (swapSample B b) E (fun _ => 0) t D`

前提全部非退化、无自由常数：`|E| < 2`、`2 ≤ D`、`t₀ < 1`、`∀ᶠ N, 0 < t N`、`∀ᶠ N, t N ≤ t₀`，以及唯一的几何前提 `hsep`（两块相距够远使 `farChi = 1`，即 `12ℓ*_v ≤ ‖a₁−a₂‖`，转换引理 `farChi_eq_one_of_sep`；`ℓ*_v = (log W)^{3/2}ℓ̂(v) = W^{o(1)}` 而 `‖a₁−a₂‖` 可取 `≍ L`，(2.2) 下对大 `N` 成立）。显式常数 `c = 1/(200((η_{t₀})⁻² + 1))`（`gap_lower`）。

⭐ **病根不是 `∀ᶠ N`，是 `∀ ω`**：`ω` 自由 ⟹ 在任何 `v > 0`，`H_v = √v X(ω)` 跑遍全部 Hermitian 阵，**与 `v` 多小无关**。

**这同时回答了 T245 的追加问**：`EntryModulusEv` 做不出非退化见证，**因为在 `s ≡ 0` 的非退化窗口上它是假的**——与甲同一机制、同一套构造。

通用版（不依赖具体样本，供别处复用）也编译了：`not_modulusEv_zero_start` / `not_entryModulusEv_zero_start` / `not_cutHypEv_jSfarSm_zero_start`——只要「存在 `c > 0`，使每个 `v ∈ (0, t_N]` 都有某个 `ω` 令 `J ≥ 1 + c`」。

**对 T230 / T243 的直接后果**：任何 `s N = 0` 的网格格点上都不能假设 `modulus`；窗口左端**必须** `s_N > 0`。

## 乙：`‖X‖`-free 的 Lipschitz

`mul_green_smul`：`Y·G_v = v^{−1/2}(1 + z_v G_v)`（把 `X` 从第二预解式恒等式里消掉）。

`norm_green_sqrt_sub_le`（`0 < v`，`u,v < 1`，**对所有 `ω`，不用 `‖Y‖` 的任何界**）：
`‖G_u − G_v‖ ≤ |√v−√u|/√v · (η_u⁻¹(1 + ‖z_v‖η_v⁻¹)) + |u−v|·η_u⁻¹η_v⁻¹`

`norm_green_sqrt_sub_le_lip`（`0 < s ≤ u, v`，`u,v < 1`）：
`‖G_u − G_v‖ ≤ |u−v| · ( η_u⁻¹(1 + ‖z_v‖η_v⁻¹)/(2s) + η_u⁻¹η_v⁻¹ )`
关键步 `|√v−√u|/√v ≤ |u−v|/(2s)`。**确切窗口条件：`s ≤ u,v` 且 `s > 0`，`u,v < 1`**，此外什么都不要。

代入 `s_N ≥ N^{−C}`、`t_N ≤ t₀ < 1`、`‖z_v‖ ≤ 3`、`η ≥ η_{t₀}`：常数 `≤ N^C · C(E,t₀)`，即 **`Kmod = C`、`γ = 1`（Lipschitz，不是 Hölder 1/2）**。
