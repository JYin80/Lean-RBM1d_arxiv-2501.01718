# T530 — Strict-margin first-cell endpoint arithmetic

## Result

Added `RBM1D/Gauss/APrimeFirstCellEndpointSharpArithmetic.lean`, importing
accepted T529 and T526 only.

At the literal value `delta = 1/2000`, the module proves for `N ≥ 81` and
fixed `P ≥ 80000` that

```text
card (LoopArg (L_N) 2) ^ (1 / (2P)) ≤ N ^ (delta / 40).
```

The proof uses the accepted two-coordinate cardinality estimate
`card (LoopArg (L_N) 2) ≤ N²`, rewrites the family cost exactly as
`N^(1/P)`, and checks `1/P ≤ delta/40` at `P = 80000`.

The module verifies

```text
delta/40 + delta/5 = 9*delta/40 < delta/4
```

and proves the corresponding exact product identity.  The strict gap
`delta/40` then absorbs both the endpoint baseline and the coefficient-one
main term, giving eventually in `N`, uniformly for every real `1 ≤ R ≤ 2`,

```text
R^(-4) + N^(9*delta/40) * R^(-2) ≤ N^(delta/4) * R^(-2).
```

The proof uses `R^(-4) ≤ R^(-2)` and two applications of the existing
constant-times-power asymptotic lemma.
