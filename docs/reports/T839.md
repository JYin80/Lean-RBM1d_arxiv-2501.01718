## Exact existing interface

`Band.prob_le_of_stochDom` (`Flow/Consequences.lean:426`) takes nonnegative control `ζ`, `StochDom B.P ξ ζ`, and positive `ρ,D`, and concludes eventually

```text
B.P {ω | ∃ u, W_N^ρ ζ_N(u,ω) < ξ_N(u,ω)} ≤ ENNReal.ofReal (N^(−D)).
```

Its proof converts `N^(ρ/2)` to `W_N^ρ` using the eventual bandwidth assumption. `localLaw_prob_of_boundsCore` (:857) instantiates it with `u : B.Idx N × B.Idx N`, `ζ=(B.zScale N z_N)⁻¹ᐟ²`, and the entrywise Green error. `partialTrace_prob_of_boundsCore` (:878) instantiates it with `u : ZMod (B.L N)`, `ζ=(B.zScale N z_N)⁻¹`, and the centered, `W⁻¹` normalized diagonal block sum. In both cases `B.zScale N z_N = W_N ellZ(L_N,z_N) Im(z_N)` has exactly the extra `+1` in `ellZ`. The input `hB : BoundsCore X E (fun N => lemT (z N))` is **assumed**; the block theorem additionally assumes `T1 : TransferLoop1 T`. `BoundsCore.localLaw` supplies the half-power; `BoundsCore.LmK 1` supplies the full power. Averaging the entry estimate alone does not supply the latter.

The moving-energy counterparts are the first two conjuncts of `localSemicircleLaw_of_boundsCoreN` (`Flow/EnergyUniform.lean:660`), with `hz : SpecSeqN κ θ E z` and `hB : BoundsCoreN X E (fun N => lemT (z N))`. The `_of_z` version (:722) takes `E_N=lemE(z_N)` through `SpecSeqN.of_z`. `localSemicircleLaw_of_Thm221N'_of_z` (:771) instead assumes `hT : Thm221N' X κ`; it does not prove that premise. All return **separate eventual bad-event bounds**, and all place the whole finite spatial-index union inside each probability. The spectral sequence `z : ℕ → ℂ` is chosen before `∀ᶠ N`; no theorem here states a probability for one event quantified over all spectral values or all flow times.

## Minimal strictness bridge

Let `Bad_N = {ω | ∃ u, W_N^ρ ζ_N(u,ω) < ξ_N(u,ω)}` and `Good_N = Bad_Nᶜ = {ω | ∀ u, ξ_N(u,ω) ≤ W_N^ρ ζ_N(u,ω)}`. A generic theorem can keep precisely the inputs of `Band.prob_le_of_stochDom` and conclude, without measurability,

```lean
∀ᶠ N : ℕ in atTop,
  B.P (Bad N) < ENNReal.ofReal ((N : ℝ) ^ (-D))
```

by invoking that theorem at **producer exponent `D+1`**, then intersecting with `N≥2`. For `D>0` and `N>1`, `N^(-(D+1)) < N^(-D)`. The target `W^ρ` factor, control `ζ`, and entire index type `U N` remain unchanged; only the tail exponent changes. The order is `∀ρ>0, ∀D>0, ∀ᶠN` after a fixed `StochDom`, so this is not a claim uniform in all `D` with one `N₀`.

To state the paper's **good-event probability**, the bridge also needs `MeasurableSet (Bad N)` eventually (or an adequate null-measurability hypothesis), which the generic `StochDom` and `Band.prob_le_of_stochDom` signatures do not provide. The precise conditional target, using ENNReal for the probability, is

```lean
theorem Band.prob_good_gt_of_stochDom
    (B : Band Ω) {U : ℕ → Type*} {ξ ζ : ∀ N, U N → Ω → ℝ} {ρ D : ℝ}
    (hζ : ∀ N u ω, 0 ≤ ζ N u ω) (h : StochDom B.P ξ ζ)
    (hBadMeas : ∀ᶠ N : ℕ in atTop,
      MeasurableSet {ω | ∃ u, (B.W N : ℝ)^ρ * ζ N u ω < ξ N u ω})
    (hρ : 0 < ρ) (hD : 0 < D) :
    ∀ᶠ N : ℕ in atTop,
      ENNReal.ofReal (1 - (N : ℝ)^(-D)) <
        B.P {ω | ∀ u, ξ N u ω ≤ (B.W N : ℝ)^ρ * ζ N u ω}
```

Here `B.isProbabilityMeasure` gives `B.P univ=1`; measurability gives the complement identity, and eventually `0<N⁻ᴰ<1`. One may prove the target via `measure_add_measure_compl` or `measure_compl` and ENNReal subtraction. **This exact declaration was not typechecked.** Its mathematical premises and binder order are the preflighted interface. It is not safe to omit `hBadMeas`: a small outer measure for a nonmeasurable bad set does not by itself give the required complement identity. In particular, `Transfer` has `Hband` and transfer fields but no `Measurable Hband` field (`Flow/Hypotheses.lean:512`), so measurability is not automatic in the generic consequence theorem. For the concrete Gaussian transfer `Hband=Xmat`, `Gauss.measurable_Xmat` (`Gauss/OpNorm.lean:228`) and the measurable matrix inverse machinery give a noncircular route to both finite-union event-measurability proofs; the exact two final event lemmas were not found in the inspected interfaces.

Conditional concrete specializations must retain the original `T`, `hκ`, spectral data, and `hB`, adding the relevant eventual event-measurability proof. The fixed-energy route has `hz : SpecSeq κ θ E z`; the moving-energy route has `hz : SpecSeqN κ θ E z` (or `SpecSeqN.of_z` and a corresponding `BoundsCoreN` for each `z`). Set output `ρ=τ` only when matching the paper's threshold, and retain `θ` as the separate lower-imaginary-part exponent until then. Each specialization yields an eventual strict good probability **for its one chosen sequence `z`**. It does not turn `BoundsCoreN` or `Thm221N'` from assumptions into proved Gaussian bounds.

## One shared event and quantifiers

For **one fixed admissible `z_N` on the same probability space**, a common good event for (2.3) and (2.4) is logically available after both conditional estimates exist: define `GoodJoint_N = EntryBad_Nᶜ ∩ BlockBad_Nᶜ`. Apply each existing bad-event bound at `D+1`, intersect their two eventual filters, and use the finite union bound. Eventually `N≥3`, so `2N^(-(D+1)) < N^(-D)`; with both bad sets measurable, `B.P GoodJoint_N > 1−N^(-D)`. The same `ω` is used in both events; no probabilistic independence is assumed. This does **not** give one event simultaneous in every continuum-valued `z`, or through the first and later time cells. The accepted abstract T831 diagonal lemma can move an eventual-index quantifier across admissible deterministic `z` only once a producer applies to every sequence; it does not exchange `∀z` with a probability or provide a simultaneous-in-`z` random event.

## Nonvacuity and first missing work

The spectral/width domain is nonempty: `Gauss.Dims.exampleGrow` has `c=1/8` and growing `W_N,L_N`; take `κ=1`, `θ=ρ=1/4`, and `z_N=i/2`. Then `0<Im z_N≤1`, `|Re z_N|≤2−κ`, and eventually `N^(−3/4)≤1/2`. Its `zScale` is positive, so both distinct thresholds are genuine. This witnesses the **domain and strictness arithmetic**, not the analytic `BoundsCoreN` or `Thm221N'` hypotheses. The Gaussian `transfer_gauss` and `transferLoop1_gauss` are already defined in `Gauss/DistEq.lean:209–251`; `TransferLoop1` is only an unproved extra premise for an arbitrary `T`.

Thus the next bounded *formal* task is the conditional generic bridge plus two Gaussian event-measurability lemmas, if a literal `P(good)>...` theorem is wanted. The first missing *analytic* ingredient for unconditional paper (2.3) is a noncircular moving-energy sharp `BoundsCoreN.localLaw` at `lemT(z_N)` for the Gaussian sample; (2.4) additionally needs `BoundsCoreN.LmK 1` at that same time and energy. The current positive first-cell `E=0` result does not cover later cells or the universal spectral/energy sequence. A complete paper claim would also have to address the existing indexing difference `W_N L_N≤N≤2W_N L_N` versus the paper's `N=W L`. No build or axiom check was run for this report-only preflight.
