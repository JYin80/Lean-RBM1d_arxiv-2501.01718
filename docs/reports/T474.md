## Result

For every fixed real `K >= 0`, the module defines

```text
polynomialMesh K 0 = 1,
polynomialMesh K N = N^(2*K+4)  for N > 0.
```

Thus the mesh is positive for every natural `N` and agrees eventually with
the desired unshifted polynomial mesh.  On every deterministic moving
window satisfying

```text
0 <= s_N <= t_N < 1,
```

the module proves, eventually in `N`,

```text
N^K * (1 / polynomialMesh K N)^(1/2)
  = N^(-2) <= 1,

(t_N - s_N) * polynomialMesh K N + 2
  <= N^(2*K+5).
```

The first equality is exposed separately as `mesh_fine_eq_inv_sq`.  The
theorems `eventually_aprime_mesh_fine` and `eventually_card_le` have exactly
the deterministic `mesh_fine` and `card_le` shapes used by
`Step2Bootstrap.APrimeHypOn`, with `gamma = 1/2`, `Theta = 1`, and
`Ccard = 2*K+5`.  `aprime_mesh_fields` packages these together with
`mesh_pos` for direct insertion into an `APrimeHypOn` constructor.

## Proof arithmetic

For positive `N`, real-power identities give

```text
1 / N^(2*K+4) = N^(-(2*K+4)),
N^K * (N^(-(2*K+4)))^(1/2) = N^(-2).
```

For the cardinality bound, `0 <= t_N-s_N <= 1` reduces the left side to
`N^(2*K+4)+2`.  For `N >= 3` and `K >= 0`, the mesh is at least one, so

```text
N^(2*K+4)+2 <= N * N^(2*K+4) = N^(2*K+5).
```
