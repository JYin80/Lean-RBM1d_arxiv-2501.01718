1. T792 proves `@measurableAtom ... (prefixSigma W k.val) π = {ρ | ρ ∈ prefixCell W k.val π}`. Thus a prefix-measurable set either includes or excludes an entire cell, and distinct actual cells can be summed once each.
2. T776 gives the event-on-cell measure/cardinality quotient, positive finite mass of every actual cell, and zero quotient for any already used image. T795 proves the quotient `1 / (W-k.val : ENNReal)` for each unused image without assuming a conditional expectation. T785 proves the unused count `W-k.val`; `k.isLt` yields `0 < W-k.val`. For every `π`, `π k` is unused by injectivity, providing a witness. All cells are centered at actual permutations, avoiding inconsistent prescribed prefixes and null conditioning cells.
3. Let `f ρ = if ρ k=v then (1:ℝ) else 0` and `g π = if v∈unusedImages W k π then (1:ℝ)/(W-k.val:ℝ) else 0`. T807 proves the event in `g` is `MeasurableSet[prefixSigma W k.val]`; the two-valued real function is therefore measurable in that sub-sigma algebra and `AEStronglyMeasurable` there. 4. On an actual cell `C = {ρ | ρ ∈ prefixCell W k.val π}`, `g` is constant: T804 directly proves `unusedImages W k ρ = unusedImages W k π` for `ρ∈C`; T807 plus T792 also gives this event-level constancy. Consequently `∫ ρ in C, g ρ ∂uniformPerm W = g π * (uniformPerm W C).toReal`. Also `∫ ρ in C, f ρ ∂uniformPerm W = (uniformPerm W (C ∩ {ρ | ρ k=v})).toReal`. T795's stronger cardinal identity `prefixCell_card_eq_unused_mul_fiber` is an alternative that avoids division in `ENNReal` during the conversion.
5. For any `s` measurable in `prefixSigma W k.val`, partition `s` by the finite collection of *distinct* actual cells. Since each cell is wholly inside or outside `s`, finite additivity of set integrals gives `∫ ρ in s, g ρ ∂uniformPerm W = ∫ ρ in s, f ρ ∂uniformPerm W`. Indexing by all `π` without removing duplicate cells would overcount, so this distinct-cell step is essential. ## Boundary and nondegeneracy audit

- `W=0`: `Fin 0` has no `k`, so no next-image instance exists.
- `W=1,k=0`: the single permutation sends `0` to `0`; the unused count and denominator are one, so both sides are one almost everywhere.
- `W=2,k=0`: identity and swap are distinct samples in the same unrevealed atom; for either `v=0` or `v=1`, the target value is `1/2`, and T795 exhibits two positive half-mass fibers. This is the nondegenerate witness.
- `W=2,k=1`: each prefix cell is a singleton. Its remaining image has value one; its already used image has value zero. Identity and swap give opposite remaining images.
- Last valid reveal `k.val+1=W`: T785 gives `W-k.val=1`; the remaining image has value one and every used image zero. The type of `k` excludes `k=W`.
