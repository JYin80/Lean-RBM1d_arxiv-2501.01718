# T816 — global unused-image marginal

## Result

Implemented the unconditional finite-permutation identity in
`RBM1D/Gauss/PermutationUnusedImageMarginal.lean`:

```lean
theorem uniformPerm_unusedImages_marginal (W : ℕ) (k v : Fin W) :
    uniformPerm W {π : PermΩ W | v ∈ unusedImages W k π} =
      ((W - k.val : ℕ) : ENNReal) / (W : ENNReal)
```

The proof locally identifies `v ∈ unusedImages W k π` with
`k.val ≤ (π.symm v).val`. It then constructs an explicit equivalence from the
event subtype to the product of (i) remaining positions and (ii) permutations
whose first image is `v`, using the transposition of position zero with the
inverse image of `v`. This gives the event cardinality
`(W-k.val) * card(first-image fiber)`. The uniform event mass is cardinality
over total cardinality; T752's first-image law supplies the fiber mass `1/W`.
No conditional-law statement is used.

The file also proves positivity of the event mass, positivity and finiteness of
the denominator, the absence of a valid index at `W=0`, the `W=1` case, both
`W=2` cases (`k=0` gives one and `k=1` gives one half), and the last-reveal
case. At `W=2, k=1, v=1`, identity belongs to the event and the transposition
does not; the event has mass one half, so the witness is nonempty and proper.
