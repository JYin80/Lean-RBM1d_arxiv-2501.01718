## 三字段的结论

### `meas` —— **无条件关掉，没有任何假设**

`aestronglyMeasurable_jSfarSm X E : ∀ D, 0 < D → ∀ N u, AEStronglyMeasurable (fun ω => jSfarSm X E D N u ω) B.P`，对**每个** `Sample B` 成立。
链条从唯一的字段 `Sample.measurable`（`ω ↦ (H_u)_{ij}`）走到 `green` → `Gsig` → 矩阵乘 → `gloopProd`（对折叠的电荷/标签表做归纳）→ `trace` → `Lval` → `lk` → `lkFarSm` → `Finset.sup'`。唯一不连续的一步是矩阵逆，用已有的 `RBM.Gauss.measurable_matrix_inv_apply`（`Defs/MatrixMeasurable.lean`）——**没造新轮子**。

⭐ **附带收益**：`measurable_Lval` / `measurable_lk` 是本仓**第一批一般 `Sample` 上的可测性结果**；形状完全相同的 `Step2Moment.MomentHyp.meas`（`Step2Moment.lean:380`）与 `MomentDuhamelCut.CutHyp`/`CutHypEv`/`CutHypTheta` 对 `Step2.jS` 的 `meas` 字段，现在都只差一步 `Finset.sup'`。

### `near` —— **接线关掉**

`near_of_sharp = Step2Near47.hnear_sharp`，即 T207 的锐版 (5.47)：`J*_{u,D} ≺ (η_s/η_u)²`。该字段不再独立，成为 `Step2Near47.MomentHypCutSharp`（锐版矩接口，`CutHypTheta.momentHypCutSharp_of_cut2` 已能导出）。

### `modulus` —— **按字面证明为假**（本仓第 11 例空真缺陷），并给出修复

**否定结论**：`not_entryModulus_of_jSfarSm_ne`、`not_entryModulus_of_ratio_ne`。
机制：`N = 0` 处右端是 `(0:ℝ)^(1:ℝ)·|v−w|^{1/2} = 0`（`modulus_rhs_eq_zero_at_zero`，对任意 `Kmod ≠ 0`、`γ` 都陈述），所以那个请求**不是模而是等式约束**：`modulus_ratio_const_at_zero` 逼出 `v ↦ ‖(L−K)_v‖/T_{v,D}` 在整个 `[s₀,t₀]` 上对**每个** `ω`、每个标签对恒定；`modulus_jSfarSm_const_at_zero` 逼出 `J*^{sm}_{·,D}` 在那里恒定。**这就是 T232 的 `∀N` vs `∀ᶠN` 缺陷，现在证明它也到达了逐项字段。**

**第二个独立缺陷**：`entryModulus_uniform_in_omega` —— 即使 `N ≥ 1`，该字段仍是**对所有 `ω` 量化的确定性不等式**，而它所乘的因子只有 `≺ 1`（走 `T ≥ W^{−D}` 的确定性界是 `W^D`，下游 `D ≥ 60`）。这是禁止模式第 1 条，需要事件限制。

**修复（已交付并编译）**：`EntryModulusEv`（同一字段，`∀ᶠ N in atTop`）→ `cutHypEv_jSfarSm_of_entries` → `stochDom_jSfarSm_of_entriesEv` → `flowEq548W_of_sharp_entriesEv`。(5.48) 改走 T232 的 `MomentDuhamelCut.CutHypEv` 而不是 `CutHyp`；`window`/`Θ_pos`/`J_nonneg`/`mesh_pos`/`mesh_fine`/`card_le` 仍然证出（复用 `Step2FarMart.mesh_fine_one_at_sq`、`card_le_one_at_sq`），`meas` 由 §1 交割、`near` 由 §2 交割。**这条路上只剩 `hmoment` 与 `hinit` 是输入。**
