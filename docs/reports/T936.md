```lean
∀ᶠ N : ℕ in Filter.atTop,
  ∃ π_N : PermΩ W_N,
    ∀ u : ℝ, 0 ≤ u → u ≤ 1/2 →
      ∀ q : Fin W_N, q ≠ (⟨0, _⟩ : Fin W_N) →

It may depend on `N`; no fixed permutation across all `N` is asserted. The right side is exactly `76 sqrt(h_N)`, since `64+12=76`. The final inequality is strict because the node inequality is strict; interpolation supplies a weak `12 sqrt(h_N)` increment.
