# T692 — finite nonzero Fourier character and permutation mean

- No source producer, root import, task/status table, or Git state was edited or committed by this ticket.

For every `W ≥ 2` and `q : Fin W` distinct from its canonical zero element, the new
`permutationFourierCharacter W q j` is exactly
`Complex.exp (2 * Real.pi * Complex.I * (q.val : ℂ) * (j.val : ℂ) / (W : ℂ))`.
The theorem `permutationFourierCharacter_sum_zero` proves that its sum over all
`j : Fin W` is zero. The proof writes the character as powers of
`z = exp (2πi q/W)`, proves `z^W = 1` and `z ≠ 1` using Mathlib's exact
roots-of-unity criterion, then applies the finite geometric-sum identity.

`permutationFourierCharacter_mean_zero` applies **the existing T684 theorem**
`permutationFourierSum_mean_zero` to this character, for every complex table
`x : Fin W → ℂ`. The conclusion retains T684's counting average over every
permutation and the producer's exact `W⁻¹` Fourier normalization. There is no
added table bound or hypothesis substituting for character orthogonality.

## Boundaries and nondegeneracy

`permutationFourierCharacter_two` proves `χ₁(0)=1` and `χ₁(1)=-1` for `W=2`.
This is a nonconstant, nonvacuous instance. The zero-mode theorem proves
`∑χ₀ = W ≠ 0` whenever `W≥2`, so excluding `q=0` is necessary.
`permutationFourierCharacter_no_nonzero_mode_one` proves that `Fin 1` has no
nonzero mode. No assumption with a hidden satisfiability burden was introduced.
