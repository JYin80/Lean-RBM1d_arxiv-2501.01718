# T687 — Finite nonzero Fourier-character sum API inventory

## Scope and result

Read-only inventory/probe only. No repository Lean source, `STATUS.md`, or `TASKS.md` was changed; this report is the sole owned file. The probe proves the finite character identity stated below. It does not prove a probabilistic tail, a permutation tail, a Gaussian carrier, a first-cell statement, or an A-prime closure.

The paper's (2.3) is the local semicircle law for the Green function entries and (2.4) is the partial tracial local law over blocks `I_a`. They are later probabilistic entry/trace estimates, not the finite character orthogonality statement proved in this probe.

## Minimal import and checked API

The scratch file compiled with the single direct import:

```lean
import Mathlib.Analysis.SpecialFunctions.Complex.Log
```

The import provides all declarations used below through its dependency closure; an additional direct `Mathlib.Algebra.Ring.GeomSum` import was tested and is unnecessary. In particular, the exact checked signatures were:

```lean
Complex.exp_two_pi_mul_I_mul_div_eq_one_iff {k N : ℕ} (hN : N ≠ 0) :
  Complex.exp (2 * ↑Real.pi * Complex.I * ↑k / ↑N) = 1 ↔ N ∣ k

Complex.exp_nat_mul (x : ℂ) (n : ℕ) :
  Complex.exp (↑n * x) = Complex.exp x ^ n

geom_sum_mul {R : Type u} [Ring R] (x : R) (n : ℕ) :
  (∑ i ∈ Finset.range n, x ^ i) * (x - 1) = x ^ n - 1

Fin.sum_univ_eq_sum_range {α : Type u} [AddCommMonoid α]
    (f : ℕ → α) (n : ℕ) :
  ∑ i, f ↑i = ∑ i ∈ Finset.range n, f i
```

Thus `Complex.exp_two_pi_mul_I_mul_div_eq_one_iff` is the key roots-of-unity API: it converts the nontrivial-root check to `¬ N ∣ k`. `geom_sum_mul` supplies the finite geometric-series identity. Here `Complex.exp_nat_mul` and the `Fin`-to-`range` sum lemma connect the character to that series.

## Exact probe statement

The tested character was

```lean
noncomputable def chi (W : ℕ) (q : Fin W) (j : Fin W) : ℂ :=
  Complex.exp (2 * Real.pi * Complex.I * (q.val : ℂ) * (j.val : ℂ) / (W : ℂ))
```

and Lean accepted the following theorem, without axioms or added assumptions beyond the displayed ones:

```lean
theorem chi_sum_zero (W : ℕ) (hW : 2 ≤ W) (q : Fin W)
    (hq : q ≠ (⟨0, by omega⟩ : Fin W)) :
    (∑ j : Fin W, chi W q j) = 0
```

Proof route: put `z = exp (2π i q/W)`. The root theorem gives `z^W=1` using `W ∣ q.val * W`. If `z=1`, the same theorem gives `W ∣ q.val`, contradicting `q.isLt` and nonzero `q`. Then `chi W q j = z^(j.val)`, and the geometric-series equation gives a product equal to zero. Since `z-1 ≠ 0`, the sum is zero.

This is a proved bounded finite-sum identity, not merely API availability. The work did not add it to a repository module.

## Boundary/nondegeneracy checks

The scratch theorem `char_two_example` compiles with

```lean
chi 2 ⟨1, by decide⟩ ⟨0, by decide⟩ = 1 ∧
chi 2 ⟨1, by decide⟩ ⟨1, by decide⟩ = -1
```

so `W=2, q=1` gives the nonconstant table `(1,-1)` and the zero-sum theorem is nonvacuous. At `W=1`, Lean also accepts

```lean
¬ ∃ q : Fin 1, q ≠ 0
```

because `Fin 1` has only its zero element: there is no nonzero mode. Thus the `W ≥ 2` lower bound excludes precisely this empty-mode boundary.

## Encoding note and relationship to existing producer

The probe represents cyclic indices by canonical values in `Fin W`; the character phase uses the product of their natural-number values, cast to `ℂ`, divided by `(W : ℂ)`. This agrees with the usual exponential character on residues modulo `W`, since changing an integer representative by a multiple of `W` changes the phase by an integral multiple of `2πi`. The Mathlib root criterion naturally expresses the needed condition as `W ∣ q.val`, and the `Fin` proof discharges it using `q.isLt`.

This is not syntactically a `ZMod W`-valued character API: `q : Fin W` and `j : Fin W` are used, with `.val` explicitly exposed. If a future theorem is stated on `ZMod W`, it will need a transport/rewrite between the residue encoding and this canonical-`Fin` formula; no such bridge was proved here. The actual existing `permutationFourierSum` remains `W⁻¹ ∑ χ_i x_(π i)` over `Fin W`, and T684 assumes only `∑ χ = 0`; this probe can instantiate that assumption for the displayed nonzero Fourier characters but does not alter or extend T684.
