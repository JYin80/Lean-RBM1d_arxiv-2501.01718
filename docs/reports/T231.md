## 两条桥真正给出的因子（各读一遍，未假设相同）

* **plain**：`EEUker.quadVarPairs_Uker_le_norm_eeFun`（`EEUker.lean:629`）结论带 `((n : ℝ) + 2)`；`_xi2`(655)、`_xi2'`(694) 同因子。底层 `quadVarPairs_Uker_le_norm_eeArg` 给的是 `(n : ℝ)` 处的**环长**，band 形用 `hcast : ((n+2:ℕ):ℝ) = (n:ℝ)+2` 转换。
* **`Q`**：`MomentDuhamelQInt.quadVar_qUkerObsT_le_norm_QQ_eeFun`（`:658`）同样带 `((n : ℝ) + 2)`；底层给 `(k:ℝ)+1` 于环长 `k+1`，band 形用 `hcast : ((n+1:ℕ):ℝ)+1 = (n:ℝ)+2`。

**结论：两条都恰好是 `(n:ℝ)+2`（= 环长），一致。** ⚠ `MomentDuhamelQInt.lean` 当时不在构建里，T231 只读了它的陈述，**没有让任何入库文件依赖它**。

## 判别性检查（四组，全部编译）

1. **槽的蕴含真的不成立（本单存在的理由）**：`hbound_slot_n_add_two_holds`——在 `p=1, A=1, G=0, Q=1` 处 `φ' = 2` **对一切 `n`** 满足带撇槽（RHS `= n+2 ≥ 2`）；`hbound_slot_one_fails`——**同一数据不满足旧槽**（RHS `= 1 < 2`）。即 `(n+2)` 形的界**推不出** `1` 形的界，**旧 `hbound` 按字面永远卸不掉**。
2. **新常数无余量（没有为了对上而放大）**：`deriv_le_hyp_sharp_one'`（带撇假设取**等号**）+ `rpow_inv_le_of_deriv_le_sharp_one'` + `deriv_le_conclusion_sharp_one'`（结论也是**等号**）。
3. **接口层旧常数确实不够**：`cMDval'_enough` 成立 vs `cMDval_not_enough`（在 `1 ≤ n`、`0 < v` 时**为假**）。
4. **量词/边界**：`cMDval' p n = ((n:ℝ)+2)·max 0 (2p−1)`，故 `cMDval'_zero`、`cMDval'_nonneg` 对**所有** `p` 成立，`Hyp.cMD_nonneg` 仍满足，`p = 0/1` 无负常数。`n` 是固定环长不是渐近参数，不涉 `∀ᶠ N`。
