## Exact target

With `open MeasureTheory ProbabilityTheory` and `open scoped MeasureTheory`, the intended statement is

```lean
theorem uniformPerm_nextImage_finset_condExp
    (W : ℕ) (k : Fin W) (A : Finset (Fin W)) :
    (uniformPerm W)[(fun ρ : PermΩ W =>
      if ρ k ∈ A then (1 : ℝ) else 0) | prefixSigma W k.val]
      =ᵐ[uniformPerm W]
    (fun π : PermΩ W =>
      ((A.filter (fun v => v ∈ unusedImages W k π)).card : ℝ) /
        ((W - k.val : ℕ) : ℝ))
```

The conclusion is almost-everywhere equality under `uniformPerm W`. It does not identify Mathlib's selected conditional-expectation representative pointwise. There are no additional assumptions or arbitrary, potentially empty prefix events.

## Noncircular proof route

1. T711 defines the finite uniform permutation space and the generated prefix sigma algebra. T785 defines `unusedImages` and proves its cardinality is `W-k.val`, positive because `k.isLt`. T807 proves each unused-value membership event is `prefixSigma`-measurable. The exact T813 singleton theorem gives the conditional expectation of `1_{ρ k=v}` almost everywhere, with right side `if v ∈ unusedImages W k π then 1/(W-k.val) else 0`.
2. For every `ρ`, prove the pointwise finite partition identity
   `((if ρ k ∈ A then (1:ℝ) else 0)) = ∑ v ∈ A, (if ρ k=v then (1:ℝ) else 0)`.
   Exactly one summand can equal one, since `ρ k` has a unique value. This is a finite indicator identity, not a conditional law.
3. Apply Mathlib's actual `MeasureTheory.condExp_finsetSum` (in `ConditionalExpectation/Basic.lean`), whose hypothesis is `∀ v ∈ A, Integrable (fun ρ => if ρ k=v then (1:ℝ) else 0) (uniformPerm W)`. `Integrable.of_finite` discharges it for this finite probability space. The theorem yields an almost-everywhere sum of singleton conditional expectations.
4. Combine the finitely many T813 almost-everywhere equalities using finite-sum congruence. Pointwise simplify the resulting sum:
   `∑ v ∈ A, (if v ∈ unusedImages W k π then (1:ℝ)/n else 0) = ((A.filter (fun v => v ∈ unusedImages W k π)).card:ℝ)/n`, where `n=(W-k.val:ℕ)`. This is `Finset.sum_filter`/constant-sum arithmetic; `n>0` also excludes any denominator ambiguity. Finite intersections of full-measure sets preserve the almost-everywhere conclusion.

This route uses only T813's singleton conditional-expectation theorem as a conditional-law premise. It does not use the finite-set target, T810's finite-set actual-cell quotient, a pointwise conditional-expectation representative, or an ambient-top atom. T810 offers an independent direct cell route but is not required for this implementation. T813 itself uses actual positive prefix cells, T792's exact `prefixSigma` atom identity, T807 measurability, and earlier singleton fiber/cardinality results; its final acceptance remains T814's responsibility. An implementation should import the accepted T813 module and use `condExp_finsetSum`, rather than reprove the delicate cell-integral characterization.

## Boundary and nondegeneracy checks

- `W=0`: there is no `k : Fin 0`, hence no next-image instance.
- `W=1, k=0`: `unusedImages` has one value and the denominator is one. The right side is zero for `A=∅` and one for `A=univ`.
- `W=2, k=0`: both values are unused. For either singleton `A`, the ratio is `1/2`; for `A=univ`, it is one. Identity and swap are distinct samples in the same unrevealed prefix atom, each realizing one singleton event, so the half law is nondegenerate.
- `W=2, k=1`: each actual sample has one remaining image. A singleton `A` gives one if it contains that image and zero otherwise; identity and swap select opposite remaining images. `A=univ` gives one.
- Last valid reveal, `k.val+1=W`: `W-k.val=1`, so the formula is the zero-or-one membership indicator of the sole unused image. There is no `k=W` case.
