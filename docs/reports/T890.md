# T890 — specialized semicircle Stieltjes bridge

## Proof stage

**Standalone module PASS; root integration is still gated.** The new module
`RBM1D/Defs/SemicircleStieltjesBridge.lean` proves the requested identity for
`0 < u ≤ 1/2`. It uses T873's independently accepted density integral as the
analytic input and a separate quadratic-root argument to identify `msc`.
This does not claim the identity for every `y>0`, or any equal-mass
quadrature/Q0 result.

The prescribed source, `paper/250520-YinJun-v2.pdf`, page 7 immediately before
(2.1), defines
`m_sc(z) = ∫_ℝ ρ_sc(x)/(x-z) dx`. The module uses exactly this
`(x-z)⁻¹` sign and the accepted `semicircleMeasure` density.

## Declarations and proof route

The module exposes:

- `eq_msc_of_mul_im_pos`: uniqueness of the quadratic root with positive
  imaginary part in the upper half-plane, derived by factoring the difference
  of the two quadratic equations and ruling out the second factor by its
  positive imaginary part.
- `msc_flow_value`: `msc (i(1-u)/√u) = i√u` for `0<u≤1/2`.
- `semicircleMeasure_stieltjes_flow_kernel_scale`: the pointwise scaling
  `(x-z_u)⁻¹ = √u (√u x-i(1-u))⁻¹`.
- `semicircleMeasure_stieltjes_flow_integrable`: integrability of the ordinary
  Stieltjes kernel, transported from T873 through the constant scaling.
- `semicircleMeasure_stieltjes_flow`: the requested density integral equals
  `msc z_u`, using `integral_const_mul` and
  `semicircleFlowResolvent_integral`.
- `semicircleStieltjesFlow_half_nonconstant`: T873's `u=1/2` nonconstant
  witness is also available from this module.

The theorem domain requires `0<u`; consequently `z_u` is never formed at
`u=0`, where the displayed spectral parameter is undefined. T873's separate
constant-integrand endpoint theorem remains the correct `u=0` statement.
There are no new hypotheses beyond the domain bounds and no paper-delta.
