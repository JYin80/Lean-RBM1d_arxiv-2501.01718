# T825 — finite-set next-image conditional expectation

## Result

`RBM1D/Gauss/PermutationNextImageFinsetCondExp.lean` proves
`RBM.Gauss.uniformPerm_nextImage_finset_condExp` for every `W : ℕ`,
`k : Fin W`, and `A : Finset (Fin W)`. The real-valued conditional expectation
of the indicator of `ρ k ∈ A`, conditioned on `prefixSigma W k.val`, is
almost everywhere

```lean
fun π =>
  ((A.filter (fun v => v ∈ unusedImages W k π)).card : ℝ) /
    ((W - k.val : ℕ) : ℝ)
```

The conclusion is the exact almost-everywhere conditional-expectation formula;
it does not identify Mathlib's chosen representative pointwise. The proof
reduces the event indicator to the finite sum of singleton indicators, uses
Mathlib's `condExp_finsetSum`, applies T813's accepted singleton theorem to
each summand, then collects the finite a.e. equalities and simplifies the sum
to the filtered cardinality.

## Boundary and nondegeneracy

- `W=0`: there is no `k : Fin 0`.
- `W=1,k=0`: the finite-set event is deterministic, according as the sole
  value belongs to `A`.
- `W=2,k=0`: the singleton `{0}` has conditional expectation `1/2`.
- At width two the singleton event `{π | π 0 ∈ {0}}` contains the identity and
  excludes the transposition, so it is nonempty and proper.
- At the last valid reveal, the denominator is one; the theorem records the
  corresponding formula for every finite `A`.

There are no added assumptions. The width-two singleton check is a nontrivial
finite witness, not an empty-event claim.
