
1. `hasSubgaussianMGF_coord` proves directly from `P_map_eval`, `mgf_gaussianReal`, and Gaussian
   exponential integrability that every coordinate of the actual infinite-product sample has
   sub-Gaussian variance proxy `gvar`.
2. `iIndepFun_coord` specializes `iIndepFun_infinitePi` to the actual law `Gauss.P d`.
   `hasSubgaussianMGF_weighted_coord_sum` then proves the weighted finite-sum MGF from this model
   independence and an injective coordinate map.  Independence is therefore a conclusion about
   the model, not a theorem hypothesis.
3. `blockCoord` chooses the canonical unordered cross-block coordinate according to `idxKey`.
   `blockCoord_injective` proves that the `2W²` real/imaginary coordinates used by one ordered block
   are distinct.  `gvar_blockCoord` uses distinctness, cyclic adjacency, `gvar_offDiag`, and the
   literal block profile to obtain variance `1/(6W)` for each coordinate.
4. `blockScalar_re_eq_coord_sum` and `blockScalar_im_eq_coord_sum` expand the actual
   `APrimeFirstCellJGAllTime.xBlock`.  The sign in `Xentry` is handled separately according to the
   order of `x.val` and `y.val`; reversing the ordered block reuses the same unordered coordinates
   with the conjugate sign.  No independence between opposite orientations is asserted or used.
5. `sum_blockReCoeff_sq` and `sum_blockImCoeff_sq` prove that the coefficient squares in each real
   projection sum to one from `‖v‖=‖w‖=1`.  Consequently
   `hasSubgaussianMGF_blockScalar_re` and `hasSubgaussianMGF_blockScalar_im` have exact variance
   proxy `1/(6W)`, equivalently MGF bound `exp(t²/(12W))`.
6. `projected_upper_tail` and `projected_lower_tail` apply the sub-Gaussian Chernoff bound to get
   `exp(-3Ws²)` for each of the four signed real/imaginary tails.  In
   `blockScalar_norm_tail`, the deterministic implication
   `|z|>r ⇒ |Re z|>r/√2 ∨ |Im z|>r/√2` and a four-set union bound give the exact constant
   `4 exp(-(3/2)Wr²)`.
