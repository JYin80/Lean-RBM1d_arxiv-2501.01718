# 覆盖范围与边界

本文件回答一个问题：**这个仓库到底证明了论文的哪些部分，没有证明哪些，为什么。**
逐条节点的状态见蓝图（`blueprint/src/content.tex`，以及由它生成的依赖图）；
这里给的是范围、边界和读法。

论文：Horng-Tzer Yau & Jun Yin, *Delocalization of One-Dimensional Random Band Matrices*,
arXiv:2501.01718（仓库里的 `paper/250520-YinJun-v2.pdf`）。
**项目约束：只依据这一篇论文，不参考其他文献。**

## 一句话

论文的**确定性内核**已经形式化完毕：传播子 `Θ_ξ` 的全部性质（Lemma 2.14 六条，
整个圆盘 `‖ξ‖<1`）、第 3 节的 `K` 理论（树表示、Ward 恒等式、sum-zero），
以及由 local law 推退局域化的那一步。**随机层不在范围内**，原因见下。

## 为什么随机层不在范围内

论文 §2.4 起的主线建立在**矩阵布朗运动的 Itô 演算**上：(2.34) 的 SDE、
loop hierarchy (2.45)、Theorem 2.21 的六步、§5–7 的全部分析。

Mathlib 目前**没有** Itô 公式、没有矩阵值 SDE、没有 Dyson Brownian motion。
把这些补上是一个独立的、规模远超本项目的工程。因此：

* **在范围内**：一切不依赖随机性的陈述——线性代数、组合、常微分方程、复分析。
* **不在范围内**：期望、高概率陈述、`≺` 的概率版本（Def 2.1 (i)(iii)(iv)）、
  §2.4、§2.6–2.7、§4、§5–7、附录 A 的估计部分（Lemma A.2 起）。

边界画在**定义与代数**这一侧：例如 Definition 2.9 的 G-loop、附录 A 的 G-chain，
它们的定义和代数性质（共轭、循环不变、Ward 恒等式、chain↔loop）都是确定性的，
已经形式化；而它们的**概率估计**不是。

## 我们与论文不同的地方

`docs/paper-deltas.md` 里逐条记着（目前 22 条），按性质分三类：

**一、论文的笔误（我们改了并记录）**

* Figure 6 之后 n=4 的显式式，边界因子下标差一（应为 `Θ_{t m_i m_{i+1}}`）。
  有两个独立佐证：论文 (3.42) 自己用的是正确下标；有限差分数值核对相差 `1e−2` vs `1e−11`。
* 另有若干处注记不精确（如 Def 2.10 后关于 `a_1` 的说法），定义本身无歧义。

**二、我们补上的假设（论文默认或略过）**

* `L ≥ 3`。`S^(B)_{ab} = ⅓·1(dist ≤ 1)` 在 `L ≤ 2` 时行和不等于 1。
* Lemma 3.4 需要「长度为 2 的 loop 一致有界」。这是 n=2 的 Riccati 型方程做
  Grönwall 唯一性所必需的；论文一句「K 是唯一解」略过。
* Lemma 3.4 在 **n = 2 要特判**：二角形的树是单条边而非星图；
  `not_hasDerivAt_starK_two` 用一条否定性定理钉死了星图值在 n=2 **不**满足 (2.55)。

**三、我们的建模选择（不是偏离，是取舍）**

* **Lemma 3.2 被引用而非证明**：论文证明了「典范划分 ↔ 无交叉配对」，我们**把右边当作
  `T_SP` 的定义**。代价：Definition 3.1 的平面几何不在范围内。收益：第 3 节其余组合全部可
  `decide`（`|T_SP(4)| = 3`、`11`、`45` 都验过）。
* **(2.51) 只能逐项（ℂ 值）陈述**：Mathlib 里矩阵的 Pi 拓扑与 ℓ^∞ 范数拓扑 defeq 但不语法相等，
  矩阵值的 `HasDerivAt` 改写不过去。
* **附录 B 的两条路**：论文走「无穷体积核 + 围道平移 + Poisson 求和 + dyadic 分解」。
  我们对 d=1 另外发现了闭式解 `Θ_{xy} = A(ξ)(ρ^d + ρ^{L−d})`，(2.52)(2.53)(2.54) 都能由它
  直接得到；同时也把论文的 Fourier 路线独立做了一遍（`Propagator/{Symbol,SymbolBound,Contour,Poisson,DecayComplex}.lean`）。
  两条路的结论互为交叉验证。**dyadic 分解因此没有必要做**。

`axiom`，编译直接失败**。这道关卡是硬的，不靠人读日志。（它已经实际拦下过一次未完成的证明。）
