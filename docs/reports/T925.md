# T925 — eventual `exampleGrow` Fourier-grid count

## Scope and statement

Added `RBM1D/Gauss/PermutationFourierExampleGrowGridCount.lean` and one point import
in `RBM1D.lean`. The module imports the T919/T920-accepted clipped grid and the
actual `Dims.exampleGrow` producer. It defines exactly

```text
h_N = log N / W_N,
T_N = permutationFourierClosedTimeGridCount h_N,
K_N = L_N (W_N - 1) T_N.
```

The theorem `permutationFourierExampleGrow_eventually_bounds` proves one eventual
conjunction

```text
0 < h_N ∧ h_N ≤ 1/2 ∧ T_N ≤ 2 W_N ∧ K_N ≤ 2 N².
```

The theorem `permutationFourierExampleGrow_eventually_nondegenerate` proves
eventually `3 ≤ L_N ∧ 2 ≤ W_N ∧ 0 < T_N ∧ 0 < K_N`. Thus the conservative count
contains actual nonzero modes and time nodes; neither factor is silently zero.

## Proof dependencies and arithmetic

Mathlib's `isLittleO_log_rpow_atTop`, transferred along the natural-number cast,
and `Dims.bandwidth_grow` give eventually `log N ≤ W_N/2`. Independently,
`log N > 0` and `log N ≥ 1` eventually. The pointwise `W_pos` field justifies
division, so `0 < h_N ≤ 1/2`. The accepted generic grid theorem gives
`T_N ≤ 2W_N` from `W_N ≥ 1` and `log N ≥ 1`.

The `Dims.exampleGrow.dim` field gives eventually `W_N L_N ≤ N`; `L_N ≥ 3`
implies `W_N ≤ N`. In natural-number arithmetic,

```text
L_N (W_N - 1) T_N ≤ (L_N W_N)(2W_N) ≤ N(2N) = 2N².
```

This uses `W_N - 1 ≤ W_N` without converting natural subtraction into real
subtraction. `Dims.tendsto_growW` gives eventually `W_N ≥ 2`, and the grid count
is a natural ceiling plus one, hence positive. These facts and `L_N ≥ 3`
make `K_N > 0`.
