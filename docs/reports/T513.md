
## Pointwise lower bound and quantifiers

T495's scalar lower-bound argument uses public pointwise producers:

```text
Step1.inv_W_le_inv_scale:
  W_N^(-1) <= scale_E,N(u)^(-1),

Step1.one_le_ell_div:
  1 <= ell_N(u)/ell_N(s_N).
```

The new `W_inv_le_q` applies these directly at an arbitrary real window
time. It proves, for every N and such u,

```text
W_N^(-1) <= q_N(u).
```

Thus no selector/eventual quantifier interchange is needed.

`Gauss.W_le_self d` gives `W_N <= N` after one threshold depending only
on the model. Positivity of W permits inversion, so
`eventually_inv_le_q` establishes uniformly over all window times

```text
N^(-1) <= W_N^(-1) <= q_N(u).
```

T504 gives `qExt=q>0` on the window. Therefore `q_N(u) <= 2q_N(u)`,
which yields the required control floor. This part uses only bulk energy
and the original window bounds, without `Cond272Reg`.

## Slow variation

T504 gives, after one threshold, the symmetric factor-two comparison at
distance at most `N^(-16)`. Its reverse-order inequality yields

```text
qExt(v) <= 2 qExt(u),
control(v) <= 2 control(u).
```

For each fixed epsilon > 0, `N^epsilon` tends to infinity, hence
`2 <= N^epsilon` eventually. Global nonnegativity of the control allows
multiplication by this inequality. Intersecting the two eventual conditions
proves `control_slow`.

The quantifier order is exactly epsilon first, then eventual N, then all
samples, blocks and pairs of real times. No time grid or probability union
appears in this proof.
