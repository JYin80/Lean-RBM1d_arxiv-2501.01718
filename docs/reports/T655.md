# T655 - clean literal carrier-cylinder boundary audit

## Verdict

**Incomplete, with the smallest missing implication being a clean literal
relative-interior producer.**  T643 supplies a mathematically viable deterministic
coupled-block centre with uniform strict margins, and T648 supplies the correct finite
effective-coordinate support and local `measCore` retention mechanism.  Those two inputs do
fit together, but the repository does not yet contain a theorem saying that one open
effective-coordinate cylinder around that centre is contained in the **literal**

```text
rawCarrier E D s t zetaSrc zetaCtr tauG N
  inter
transition d E D deltaWeight s (targetMesh D) N k canonicalM.
```

There are two distinct reasons.

1. **Mathematical formalization is still missing.**  T643 is an audit, not a Lean producer.
   The semicircle-quantile/permutation centre, its realization as one Gaussian sample, and
   the common uniform slack over every closed-time row have not been compiled.  Pointwise
   strictness alone would not suffice: the time-indexed rows need one positive uniform slack
   before compactness/continuity yields a cylinder.
2. **The exact predicates cannot currently be imported upstream.**  Their definitions are
   spread over modules whose closures reach `Step3FlowSharp`, Step 45, Step 6, `FirstCell`,
   `Step345Producer`, `Thm221NoEL`, and the `APrimeSlot'`/T230 assembly surfaces.  This is
   module pollution for the small definitions themselves, but it prevents a clean theorem
   from even stating the literal target.

The first file-disjoint action should therefore be one bounded signature-preserving
extraction of the exact carrier/transition predicate closure.  It is specified in Section 8
as T656.  It deliberately proves no cylinder and no resident.  After that extraction, the
honest mathematical next theorem is the relative-interior statement; the deterministic
coupled-block centre must still be formalized or supplied as an explicit strict-margin
input.

T644 and T647 are used only as accepted audits.  The working-tree implementations T652 and
T653 are **not accepted inputs** here.  Every statement below involving their proposed cores

## 3. Effective-coordinate semantics and finite dependence

The correct finite set is

```text
J N  = (Gauss.usedCoord d N).image (Gauss.crd d N),
I+ N = J N filtered by (fun c => Gauss.gvar d c != 0).
```

This choice is exact for three reasons.

1. `Gauss.Xmat_eq_sum` expresses `Xmat d N omega` using only `usedCoord d N` and the
   corresponding `crd` coordinates.
2. `Gauss.crd_injective` prevents collisions in that coordinate encoding.
3. `Gauss.Hflow_congr_of_agree` proves that agreement on `J N` gives identical `Hflow` at
   every time, hence identical resolvents and loop observables.

The prefix also depends only on `Xmat`; all raw rows, `goodSetFlow`, both centered rows, and
`blockEvent` are built from `Hflow = sqrt(u) * Xmat` plus deterministic quantities.  Therefore
**every literal row has the same finite coordinate dependence**.  Coordinates outside `J N`
may vary arbitrarily and cannot change any row.

The restriction to `I+ N` must not be weakened.  Coordinates in `J N \ I+ N` have Dirac law
at zero.  T643's deterministic target is compatible with this: its matrix is supported only
on same or adjacent physical blocks, where the band variance is positive, and its coordinates
with zero variance are zero.  A formal centre theorem must state and prove precisely

```text
forall c in J N, Gauss.gvar d c = 0 -> omega0 N c = 0.
```

Then `zeroFix d (J N)` forces every sample in the hybrid cylinder to agree with the centre on
all zero-variance used coordinates.  The open effective part controls the remaining used
coordinates.  Together with `Xmat_eq_sum`, this is enough to control the actual matrix; no
full-support assertion on all used coordinates is valid.

The repository already has the finite-dependence ingredients.  What it does not have is the
compiled realization of T643's coupled-block matrix as such an `omega0 N`, or a packaged
relative-interior theorem for all literal rows.

## 4. Strict margins and the open-cylinder obligation

For a fixed sufficiently large `N`, the required strict centre data are:

```text
norm (Xmat omega0) < N;

forall n in {3,4,6}, forall p,
  norm (Lval ... omega0 ...) < N^zetaSrc * Step1.aprioriRhs ...;

forall u in Icc(s N,t N), forall x y,
  norm (G_u(x,y)-m*1(x=y)) < flowDelta ...;

forall sigma,u,b,
  norm (centeredTrace ... omega0 sigma b) < N^zetaCtr * (2*qExt ...);

forall u,
  jG ... omega0 ... <
    1 + N^tauG * (9*exp(sqrt 3)*Step2.jS ... omega0 + 2);

1 < prefixSample ... omega0 / threshold ... < 2.
```

T643's estimates give these margins uniformly eventually:

- norm at most `2`, versus `N`;
- each raw-row quotient at most `eta_u^(-1) <= 2`, versus `N^zetaSrc`;
- `C*sqrt(log N/W) = o(W^(-1/6))` uniformly over the whole closed time window;
- both centered charges are `O(1/W)`, versus the larger
  `2*N^zetaCtr/(W*eta_u)` allowance;
- the exact centre has `jG = 1`, while the literal right side is strictly larger than `1`;
- the target/canonical prefix ratio is `3/2+o(1)`.

These are the correct margins, but a Lean cylinder theorem must not replace them by a list of
pointwise `<` hypotheses over an uncountable time interval.  It must either take explicit
uniform slack constants, or prove them from the T643 quantitative estimates.  Once uniform
slack is present, the topology is sound:

- `Icc (s N) (t N)` is compact and includes both endpoints;
- all loop, Green, centred-trace and block index types are finite outside time;
- `t N < 1` keeps the resolvent spectral parameter uniformly off the real axis;
- `tailT` is strictly positive because of its `W^(-D)` floor;
- `threshold` is positive for eventual `N > 0`;
- finite maxima, norms, products and quotients by these positive denominators are continuous;
- `u = 0` is harmless: `sqrt` is continuous there even though its derivative is singular;
- T647's `contDiff_prefixMatrix` supplies more than the continuity needed for the finite
  prefix.

Compactness therefore gives one effective-coordinate neighbourhood preserving every
closed-time row simultaneously.  Intersecting the finitely many resulting neighbourhoods and
the strict transition neighbourhood gives one open effective set `Ueff`.  The hybrid
`supportCylinder d (J N) Ueff` then uses the identical sample in all rows.

The endpoint cases do not create an extra branch: the carrier time interval is closed, while
the prefix is finite and uses exactly `j < k`.  The only special prefix cases are the already
recorded empty `k=0` and sample-independent `k=1` cases; T643's chosen crossing is later.

## 6. Exact local `measCore` transfer

Let

```text

C = commonEvent ... N = Gauss.measCore (Gauss.P d) R,

```

The current generic identities give

```text

```

`U subset R`

```text

```

Since the same cylinder also satisfies `U subset transition`,

```text

```

Consequently the literal common-event/transition intersection is nonempty (indeed it has
positive outer measure) without any measurability assumption on `rawCarrier` and without a
global raw-minus-core null theorem.  This is the correct repair of the older T623/T628
prerequisite claim.
