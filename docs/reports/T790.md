# T790 — preflight of the finite prefix-sigma atom

## Verdict and exact target

**Feasible, with a short missing generator argument.** The proposed statement is mathematically true for every `W k : ℕ` and actual `π : PermΩ W`. Its exact Lean type elaborates under the installed Mathlib:

```lean
theorem measurableAtom_prefixSigma_eq_prefixCell
    (W k : ℕ) (π : PermΩ W) :
    @measurableAtom (PermΩ W) (prefixSigma W k) π =
      {ρ | ρ ∈ prefixCell W k π}
```

The explicit measurable-space argument is essential. T711's ambient instance on `PermΩ W` is `⊤`; an unqualified atom in that instance is `{π}` for every `k`, which is false for the prefix atom at `W = 2, k = 0`. The expression above was type-checked in `/tmp/T790Probe.lean` with `lake env lean` (exit 0); no theorem proof was attempted. Mathlib's actual definition is `measurableAtom π = ⋂ (s) (_ : π ∈ s) (_ : MeasurableSet s), s` under the chosen instance.

## Smallest noncircular proof route

T711 defines `prefixSigma W k` as `MeasurableSpace.generateFrom (prefixCylinders W k)`, where each generator is `{σ | σ i = v}` with `i.val < k`. It defines `prefixCell W k π` by agreement at every such coordinate. T732 proves the actual-cell event measurable in precisely `prefixSigma W k`; T711 proves `π ∈ prefixCell W k π`. Thus `measurableAtom_subset` gives the atom-to-cell inclusion.

For the reverse inclusion, suppose `ρ ∈ prefixCell W k π`. On every generator `{σ | σ i = v}`, `π` and `ρ` have equivalent membership, since `ρ i = π i` when `i.val < k`. The installed theorem `MeasurableSpace.forall_generateFrom_mem_iff_mem_iff` upgrades this generator equivalence to **every** set measurable in `generateFrom (prefixCylinders W k)`. In particular, `ρ` belongs to every prefix-measurable set containing `π`, hence to the defining intersection of `@measurableAtom (PermΩ W) (prefixSigma W k) π`. This directly proves the other inclusion. The exact checked API has the form

```lean
(∀ s, MeasurableSet[MeasurableSpace.generateFrom S] s →
    (x ∈ s ↔ y ∈ s)) ↔
  ∀ s ∈ S, x ∈ s ↔ y ∈ s
```

The remaining local work is an elementary membership bridge from `Finset.mem_filter` to prefix-coordinate agreement, plus applying the generator equivalence and unfolding the atom. No finite-partition theorem, `condExp`, conditional-distribution identity, positive-mass division, or probability argument is needed. T733's equal-or-disjoint partition is useful for boundary checks, but not a logical dependency of this proof. The observation-map/comap route from T783 is valid but longer: set `obs π := fun i : {i : Fin W // i.val < k} => π i.1`, show `prefixSigma W k = MeasurableSpace.comap obs` of the finite discrete observation space, and identify the fiber `obs ⁻¹' {obs π}` with the actual cell. The nontrivial missing part is the **reverse** measurable-space inclusion: every observation-measurable set must pull back to a union of finitely many fibers, and each fiber is a finite intersection of coordinate cylinders. Mathlib's checked `comap_generateFrom` alone does not establish this equality or the atom identity. The direct generator-equivalence theorem avoids that extra work.

## Boundary and satisfiability checks

* `W = 0, k = 0`: no coordinate is revealed, so both the cell and prefix atom are `Set.univ`; `PermΩ 0` has one element, hence this is also a singleton. The same holds for every `k` at width zero.
* `k = 0` for any `W`: there are no generators, so the prefix sigma algebra is trivial and every atom and actual cell is `Set.univ`. For `W = 2`, identity and swap are distinct members of that same atom. This rules out accidental use of the ambient `⊤` atom.
* `W ≤ k`: every coordinate is revealed. T711's cell is `{π}`; coordinate cylinders distinguish any two permutations, so the prefix atom is `{π}` too. This includes `W = 1` and `W = 0`.
* `W = 2, k = 1`: identity and swap have different values at coordinate `0`, so their atoms are distinct (indeed singleton cells). T733 supplies the corresponding unequal-cell witness. At `k = 0` T733 supplies equal cells.

There are no added hypotheses to render the theorem vacuous. `PermΩ W` is inhabited for every `W` (identity permutation), and `W = 2, k = 0` gives a genuinely nonsingleton atom. These checks establish nondegenerate satisfiability rather than an empty-premise result.
