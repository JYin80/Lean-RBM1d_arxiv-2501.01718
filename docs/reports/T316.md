# T316 — finite-size model-pinned first-cell drift envelope

## Result

Added `RBM1D/Gauss/APrimeDriftEnvelope.lean`. The weight `prefixWeight` is the
actual `APrimeWeight.prefixSoftW` driven by
`Step2Moment.jSnorm (Gauss.sample d)`, with its measurability and bounds
`0 ≤ w ≤ 1` proved from the existing declarations. The rate `driftRate` is
exactly

```text
momNormW (Gauss.P d) w p
  (APrimeDriftTimeFamily.driftAt d E D N Step2.sigPM a 0 v u).
```

In particular, its drift is the Gaussian flow's `Uker ∘ DriftDef.driftF`
divided by the fixed endpoint `T_{v,D}(a)(η_0/η_v)^4`; there is no caller
supplied `Qb` or drift field.

`continuousOn_driftRate` applies T292's weighted norm continuity on `[0,v]`.
Since the interval is compact and contains zero when `0 ≤ v`, the extreme
value theorem yields `exists_max_driftRate`. `maxTime` chooses such a time and
`QbActual` evaluates the actual rate there. The checked declarations prove

```text
0 ≤ QbActual,
∀u∈[0,v], driftRate(u) ≤ QbActual,
∃u*∈[0,v], driftRate(u*) = QbActual.
```

They hold at each fixed finite `d,N,E,D,a,p` and actual prefix weight. The
Lean statement allows every `0 ≤ v < 1`, so in particular every first cell
`0 < v ≤ 1/2`; it also allows `p=0`, although the A′ moment application uses
`p≥1`. No stochastic or asymptotic size bound on `QbActual` is claimed.

`first_cell_witness` specializes to `E=D=0`, `v=1/2`, `p=1`, `r=1`, and
empty prefix `k=0`. It proves positive time length, `w(ω)=1` for every
Gaussian sample, nonnegative envelope, and attainment on the interval. This
establishes that the compactness input is nonempty and that the weight is
nonzero in this instance. It does not claim that the drift itself is strictly
positive or that a Good/soft-support intersection has been constructed.

## Scope and next quantitative gap

This removes the free finite-size drift envelope in the `hAbd` slot of
`APrimeModel.drift_bound_first_cell`: it may be instantiated by `QbActual`.
It does not prove `QbActual ≺ 1`, `tc·QbActual ≺ 1`, `fitLhs ≺ 1`, or the
first-pass A′ conclusion. The remaining theorem is a same-family,
same-event bound uniform in the interval and in large `N`; T313 records
the needed spatially normalized `Uker ∘ driftF` estimate and the
weighted-moment/event quantifiers. Compactness alone gives no asymptotic
control.
