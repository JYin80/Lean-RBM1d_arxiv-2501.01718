## Statements and argument

For `W ≥ 2`, `x χ : Fin W → ℂ`, and `∑ i, χ i = 0`, the module proves

```text
∑ π : Equiv.Perm (Fin W), permutationFourierSum W x χ π = 0
(∑ π : Equiv.Perm (Fin W), permutationFourierSum W x χ π)
  / (Fintype.card (Equiv.Perm (Fin W)) : ℂ) = 0.
```

The summand is the existing `(∑ i, χ i * x (π i)) / (W : ℂ)` with its exact normalization. There is no norm or boundedness hypothesis on `x`.

Uniformity is proved, not postulated. For any positions `i,k`, the bijection `π ↦ π * Equiv.swap i k` of the full permutation type changes `π i` to `π k`; hence the sums of `x (π i)` and `x (π k)` over all `π` agree. Summing those equal values over all `W` positions and using the bijection `j ↦ π j` gives

```text
∑ π, x (π i) = (Fintype.card (Equiv.Perm (Fin W)) / W) * ∑ j, x j.
```

Finite-sum interchange and `∑χ=0` then give the first identity. The permutation count is nonzero (`Fintype.card_ne_zero`), so the second expression is the ordinary uniform counting average.

## Nondegenerate witness

At `W=2`, take `x=(2,-2)` and `χ=(1,-1)`. Both tables are nonconstant, `∑χ=0`, and the Fourier sum at the identity is `2 ≠ 0`. Its average over both permutations is nevertheless zero, so the theorem records cancellation rather than a pointwise zero.
