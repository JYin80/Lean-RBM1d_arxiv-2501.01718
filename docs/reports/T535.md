# T535 — Literal fixed-delta first-cell endpoint hfamily integral

## Result

Added `RBM1D/Gauss/APrimeFirstCellFixedDeltaHFamily.lean`.  The closed
theorem `exists_fixedDeltaHFamily_with_resident` supplies one
`tauPrime > 0`, one literal sharp event, and for every fixed `p : Nat` a
constant `C_p > 0` such that, eventually in `N` and uniformly over every
active positive first-cell index `k`,

```text
∫ omega,
    targetWeight tauPrime p N k omega *
      |cutTrunc (N^(2*delta))
        (jSnorm ... N (endpoint N k) omega)|^(2*p) ∂(P d)
  <= C_p * N^((delta/2) * p),

delta = 1/2000.
```

The theorem separately supplies the same integral at `k = 0`, including
`endpoint N 0 = 0`.  For `p >= 1` it takes `C_p = 2^(2p)`; for `p = 0`
it takes `C_0 = 1`.

## Endpoint norm and exponent calculation

For each fixed `p >= 1`, the proof chooses the fixed high order

```text
P = max p 40000.
```

Thus `p <= P` and `P >= 40000` hold before the eventual size threshold.
T533 supplies under the literal target weight

```text
momNormW (P d) targetWeight_p p familyMax
  <= N^(delta/4) * R_v^(-2).
```

The module proves directly that every active first-cell endpoint satisfies
`1 <= R_v <= 2`.  T522's exact identity and coefficient-one weighted
Minkowski give

```text
jSnorm(v) = R_v^(-4) + familyMax,
momNormW targetWeight_p p (jSnorm(v))
  <= 1 + N^(delta/4)
  <= 2 * N^(delta/4)
```

for `N >= 1`.  Raising this last bound to `2p` gives the exact identity

```text
(2 * N^(delta/4))^(2p)
  = 2^(2p) * N^((delta/2) * p).
```

There is no extra `N`, `W`, time, family-cardinality, measure, or event
loss.  T533 already paid the finite-family cost once.

## Honest endpoint integrability

`integrable_targetWeight_endpoint_pow` proves integrability of the
untruncated endpoint weighted power before integral monotonicity is used.
It combines:

- T528's integrability of `targetWeight_p * |familyMax|^(2p)`;
- measurable `targetWeight_p` with `0 <= targetWeight_p <= 1`;
- measurability of the actual endpoint `jSnorm`;
- the exact identity `jSnorm(v) = R_v^(-4) + familyMax`; and
- the standard finite-power inequality for the sum of two nonnegative
  terms.

Therefore the integral proof does not use the convention that a
nonintegrable total integral is zero.

The truncation is pointwise dominated by the nonnegative endpoint
observable.  `APrimeOneStep.integral_cutTrunc_le_of_momNormW_le` then
converts the endpoint norm estimate into the displayed integral.

## The `p = 0` branch

At `p = 0`, the integrand reduces to `targetWeight_0`.  The proof uses
measurability and `0 <= targetWeight_0 <= 1` on the probability measure to
obtain the bound by one directly.  It does not invoke `momNormW`, whose
root exponent degenerates at zero.

## Same-event nonvacuity

The closed theorem takes its one parameter and event from accepted T533.
It preserves event measurability, `HighProb`, and eventual nonemptiness.
For every `p`, `positiveTwoFixedDeltaHFamilyResident` reuses one sample in

The plateau holds also for `p = 0`, so the zero-order clause is not an
