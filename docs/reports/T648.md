# T648 - finite Gaussian support and local `measCore` retention audit

## Verdict

**Correct after the necessary effective-coordinate restriction, and locally stronger than T623/T628 recorded.**

For a finite set `I` of Gaussian coordinates with

~~~text
forall c : I, Gauss.gvar d c.1 != 0,
~~~

the law of `I.restrict` is positive on every nonempty open set in the finite product. In particular, every nonempty open box around the deterministic effective-coordinate vector has strictly positive `Gauss.P d` mass. This is false if restated as full support on all used coordinates: zero-variance coordinates are Dirac at zero. The correct full sample-space event is the effective open cylinder intersected with the finite event fixing every zero-variance used coordinate at zero. That hybrid cylinder is measurable and has the same positive mass as its effective part.

The local measurable-core retention statement is valid without measurability of the raw carrier. If `C subset R`, `P(C^c)=P(R^c)`, `P` is finite, `U` is measurable, and `U subset R`, then

~~~text
P(U inter C) = P(U).
~~~

Thus a positive-mass strict cylinder `U subset rawCarrier inter transition` retains all its mass after intersection with `commonEvent = measCore P rawCarrier`. The stronger global assertion `P(rawCarrier \ commonEvent)=0` still does not follow when `rawCarrier` is nonmeasurable. T628 correctly rejected the global null-difference claim but incorrectly treated it as a prerequisite for the local cylinder transfer. The local transfer follows directly from `Measure.measure_toMeasurable_inter`, or equivalently from the stored inclusion and complement-measure equality via `Measure.measure_inter_eq_of_measure_eq`.

## 1. Normalized claim cards

### 1.1 Finite effective support

Fix `d : Gauss.Dims`, `N : Nat`, and

~~~text
I_N  = (Gauss.usedCoord d N).image (Gauss.crd d N),
I_N+ = I_N.filter (fun c => Gauss.gvar d c != 0).
~~~

The exact finite-product target is stronger and cleaner when stated for an arbitrary finite `I`:

~~~lean
theorem effective_open_cylinder_pos
    (d : Gauss.Dims) (I : Finset (Gauss.Coord d))
    (hvar : forall c : I, Gauss.gvar d c.1 != 0)
    {U : Set (forall c : I, Real)}
    (hU : IsOpen U) (hne : U.Nonempty) :
    0 < Gauss.P d (I.restrict ⁻¹' U)
~~~

For a deterministic vector `x : forall c : I_N+, Real` and radii `r : forall c : I_N+, Real` with `0 < r c`, take

~~~text
U = {y | forall c, abs (y c - x c) < r c}.
~~~

This is open and contains `x`, so the theorem applies. The quantifier is over the subtype `c : I_N+`, and the coordinate map is exactly `I_N+.restrict`; no unmentioned coordinate is silently included.

For the full used-coordinate set define

~~~text
zeroFix d I_N =
  {omega | forall c in I_N, Gauss.gvar d c = 0 -> omega c = 0}.
~~~

Then the correct cylinder in `Gauss.Omega d` is

~~~text
Cyl(U) = (I_N+.restrict ⁻¹' U) inter zeroFix d I_N.
~~~

The zero-variance condition on the deterministic T643 vector is essential. T643's ansatz has nonzero matrix coordinates only at physical-block distance at most one, where its audit records strictly positive band variance; all zero-variance used coordinates have target value zero.

### 1.2 Local retention

Let `P` be any finite measure and let `R,C,U` be arbitrary sets. The exact abstract theorem is

~~~lean
theorem local_core_retention
    (P : Measure Omega) [IsFiniteMeasure P]
    (hCsub : C subset R) (hcompl : P Cᶜ = P Rᶜ)
    (hU : MeasurableSet U) (hUR : U subset R) :
    P (U inter C) = P U
~~~

No measurability of `R` is assumed. No measurability of `C` is needed for this equality either, although the actual `measCore` is measurable. For `P = Gauss.P d`, probability gives the required finiteness automatically.

## 2. Finite Gaussian support proof

`Gauss.P_map_restrict` gives the exact law

~~~text
(Gauss.P d).map I.restrict
  = Measure.pi (fun c : I => gaussianReal 0 (Gauss.gvar d c.1)).
~~~

For every `c : I` with nonzero variance, Mathlib supplies both directions

~~~text
gaussianReal 0 v << volume,
volume << gaussianReal 0 v.
~~~

The second direction, `gaussianReal_absolutelyContinuous'`, transports the `IsOpenPosMeasure` property of Lebesgue measure to the Gaussian. The first direction records the converse null-set implication, so each factor is mutually absolutely continuous with Lebesgue measure. The finite-product instance `Measure.pi.isOpenPosMeasure` then proves that the product Gaussian assigns nonzero, hence strictly positive, mass to every nonempty open `U`. Finally `Measure.map_apply`, using `Finset.measurable_restrict I` and the Borel measurability of open `U`, pulls the result back to `Gauss.P d`.

Finiteness and nonemptiness are exact:

- `I` is a `Finset`, so its subtype is a finite product index.
- `U.Nonempty` is explicit; for a box around `x`, the witness is `x`.
- Every factor is a probability measure, hence sigma-finite.
- No lower bound uniform in `N` is asserted or needed.
- The sample and center may depend on `N`, while T643's deterministic parameters retain their original quantifier order.

This proves positivity for every nonempty open set, not only rectangular boxes.

## 3. Zero-variance coordinates

For `Gauss.gvar d c = 0`, `Gauss.P_map_eval` and `gaussianReal_zero_var` give

~~~text
forall-ae omega under Gauss.P d, omega c = 0.
~~~

Because `I_N` is finite, `Filter.eventually_all_finset` combines these statements over every zero-variance used coordinate. The event `zeroFix d I_N` is measurable: it is a finite intersection of coordinate-equality sets, and each coordinate evaluation is measurable. Therefore `Measure.measure_inter_eq_of_ae` gives

~~~text
P(Cyl(U)) = P(I_N+.restrict ⁻¹' U) > 0.
~~~

This is the necessary correction to a full-support statement. The hybrid cylinder is generally not open in the full product topology because of its Dirac coordinates, but it is measurable and has positive probability. Artificially opening a zero-variance coordinate around a nonzero target would be false; omitting its constraint would also be unusable for a deterministic inclusion in `rawCarrier`, because arbitrary sample points could then change `Xmat` through that coordinate even though such points have probability zero.

## 4. Local `measCore` retention

Put `R = rawCarrier` and `C = measCore P R = (toMeasurable P Rᶜ)ᶜ`. There are two compiled proofs.

### Direct `toMeasurable` proof

Since `U` is measurable and `P(Rᶜ) != infinity`, Mathlib gives

~~~text
P(toMeasurable P Rᶜ inter U) = P(Rᶜ inter U).
~~~

The right side is zero because `U subset R`. Since `Cᶜ = toMeasurable P Rᶜ`, the complement piece `U inter Cᶜ` is null. `measure_sdiff_null'` then gives `P(U inter C)=P(U)`.

### Proof using only the stored identities

From `C subset R`, complements reverse: `Rᶜ subset Cᶜ`. Together with `P(Cᶜ)=P(Rᶜ)` and `P(Rᶜ) != infinity`, `Measure.measure_inter_eq_of_measure_eq` gives, for measurable `U`,

~~~text
P(Rᶜ inter U) = P(Cᶜ inter U).
~~~

The left side is zero, and the same final `measure_sdiff_null'` step proves retention. This uses exactly the public facts `measCore_subset` and `measure_compl_measCore`; it does not need a measurable or null-measurable raw carrier.

Consequently, if strict continuity margins produce a measurable cylinder with

~~~text
0 < P(U),
U subset R,
U subset transition,
~~~

then `0 < P(U inter C)=P(U)`. By monotonicity, `C inter transition` has positive outer measure and is nonempty. Measurability of `transition` is not needed for this positivity implication, although downstream integral interfaces may still require the active clean transition-measurability producer.

## 5. Why the global null-difference remains unavailable

The local theorem cannot be specialized with `U=R` unless `R` is measurable. Thus it does not prove `P(R \ C)=0`.

This is a real logical distinction. For example, take a two-point set with the trivial measurable space and the finite probability measure whose outer measure is one on every nonempty set. For a proper nonempty `R`, its nonempty complement has measurable hull equal to the whole space, hence `C=(toMeasurable P Rᶜ)ᶜ` is empty. Then

~~~text
C subset R,
P(Cᶜ) = 1 = P(Rᶜ),
P(R \ C) = P(R) = 1.
~~~

Nevertheless every measurable `U subset R` is empty in this coarse measurable space, so local retention remains true. This countermodel shows that complement-measure equality, inclusion, and finiteness do not imply the global outer-null difference for a nonmeasurable carrier.

The strongest safe statements are:

1. local retention for every measurable `U subset R`: proved;
2. global `P(R \ C)=0`: conditional on `MeasurableSet R`, `NullMeasurableSet R P`, or a direct null-difference theorem.
