# T475 — general moving-window normalized-loop modulus

## Result

Added `RBM1D/Gauss/APrimeGeneralMovingLoopModulus.lean`.

The main theorem
`RBM.APrimeGeneralMovingLoopModulus.eventually_jSnorm_modulus` proves, for
`d = Gauss.Dims.exampleGrow`, fixed `|E| < 2`, `D ≥ 60`, and every admissible
moving window satisfying the original `Cond272Reg`, that eventually in `N`,
on the fixed norm event `‖Xmat d N ω‖ ≤ N`, uniformly for all
`v,w ∈ [s_N,t_N]`,

```text
|jSnorm(v,ω) - jSnorm(w,ω)|
  ≤ N^(2D+7) |v-w|^(1/2).
```

All `ω`, `v`, and `w` quantifiers occur after the eventual `N`.  The theorem
has no fixed terminal time and introduces no additional random hypothesis.

## Coefficient ledger

Write

```text
r  = (1-t_N)^-1,
m  = (Im m_E)^-1,
q  = η_{t_N}^-1 = r m,
Cp = (2 sqrt(1-t_N))^-1.
```

T473 gives `r ≤ N`.  Since `0 ≤ t_N < 1`, also `Cp ≤ r ≤ N`.  The fixed
bulk factor `m` is kept inside a constant depending only on `E`.

Using `W L ≤ N`, `W ≤ N`, and `L ≤ N`, the explicit public definitions give:

```text
crudeLk ≤ (m^2+1) N^2,
tailLip ≤ (2m^2+2m^3+m^2/2) N^4,
jTotNormEv ≤ K(E) N^(2D+6).
```

The four contributions are bounded respectively by fixed multiples of
`N^(D+4)`, `N^(2D+6)`, `N^(D+6) + N^(D+2)`, and
`N^(D+3) + N`.  They all fit under `N^(2D+6)` for `D ≥ 1`.
Eventually `K(E) ≤ N`; this supplies the final exponent `2D+7`.
The public pointwise theorem `APrimeSlotFields.abs_jSnorm_sub_le_event` is
then instantiated at the moving endpoint `t₀ = t_N`.
