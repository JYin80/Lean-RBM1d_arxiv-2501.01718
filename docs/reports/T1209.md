# T1209 — all-active norm-good transition exclusion

## Verdict: mathematical preflight FAIL; the proposed exclusion is false

For the literal T995 schedule, the norm-good strict-transition set is
nonempty at an active index beyond `N^10` for infinitely many sizes. The
counterexample uses the same first-cell window, target mesh, canonical order,
and `deltaWeight` as T1101. Thus the requested all-active exclusion cannot be
proved, and I added no Lean theorem or weaker replacement.

The parameters can be fixed explicitly as `τ' = 1`, `c = 1`, `δ = 1/200`.
They satisfy T995's `0 < δ ≤ min(1,c/100)`, and
`deltaWeight δ = 1/20000`. Eventually the first-cell schedule is `s_N=0`,
`t_N=1/2`; writing `M_N = targetMesh 60 N` and
`\widehat M_N=N^258 ∈ ℕ`, we have `M_N=(\widehat M_N : ℝ)` and
`cutNetTop = \widehat M_N/2` whenever `N` is even and sufficiently large. The
canonical order is `m_N = cutNetTop · q_N + 1`, where
`q_N = card (LoopArg (L_N) 2) ≥ 1`.

## Same-sample counterexample

Take infinitely many even `N` and the scalar sample
`ω_N = scalarSample Dims.exampleGrow (4√2)`. The existing scalar-matrix
identity gives `Xmat ω_N = 4√2 · I`, hence `‖Xmat ω_N‖ = 4√2 ≤ N` for
large `N`: this sample lies in T1201's literal norm-good event. Put
`j_H=\widehat M_N/8` and `k_H=j_H+1`. These are integers on the even subsequence,
`cutNetPt 0 M_N N j_H=1/8`, and `k_H` is active. T1051's scalar lower-bound
producer `jSnorm_transition_lower`, at `h=1/8`, gives

```text
jSnorm(1/8, ω_N) ≥ W_N/64.
```

The literal prefix dominates each stored `jSnorm`, so
`prefixSample(k_H,ω_N) ≥ W_N/64`. Since `W_N ≥ N^(5/8)` eventually and
`threshold = 8 exp(1)^2 N^(1/10000)` for this fixed `δ`, this prefix is
eventually strictly larger than twice the threshold.

At the other endpoint, set `k_0=N^10`. It is active eventually, and the
accepted T1101 theorem applies to the *same* `ω_N` because it is norm-good:

```text
prefixSample(k_0,ω_N) / threshold < 1.
```

The dense target mesh prevents the prefix from jumping over the transition
band between these two indices. Here is the exact local argument. Let `f_j`
be the smooth-JS value at node `j`, let `P_k` be the literal `2m_N` soft
maximum of `f_0,…,f_{k-1}`, and let `J_j=jSnorm(j/M_N,ω_N)`. The accepted
all-pairs norm-event modulus used in T1101 gives, for every adjacent pair of
nodes in `[0,1/2]`,

```text
|J_(j+1) - J_j| ≤ N^122 · (1/M_N)^(1/2) = N^-7.
```

The separately inspected T475 general-moving modulus has the weaker
coefficient `N^127`, which still gives the valid adjacent-node bound `N^-2`.
Either producer controls every adjacent pair in the cell. This use is local;
it does not extend T1101's early-time estimate `J_j ≤ 1+N^-2` to later `j`.
The existing pointwise smooth-JS bounds
are `J_j ≤ f_j` and

```text
f_j ≤ A_N (J_j + N^-10),   A_N = q_N^(1/(2m_N)).
```

Because `m_N ≥ cutNetTop·q_N`, `log A_N ≤ 1/(2·cutNetTop)`, so `A_N→1`,
and `m_N→∞`. Let `k_*` be the first index after `k_0` for which `P_(k_*)`
exceeds the threshold. It exists by the high endpoint. Its predecessor is at
most the threshold, and it dominates `f_(k_*-2) ≥ J_(k_*-2)`. The adjacent
modulus then gives `J_(k_*-1) ≤ threshold + N^-7`, hence
`f_(k_*-1) ≤ A_N(threshold + N^-7 + N^-10)`. The soft-maximum identity

```text
P_(k_*) ≤ 2^(1/(2m_N)) · max(P_(k_*-1), f_(k_*-1))
```

shows `P_(k_*) < 2·threshold` for all sufficiently large even `N`, since
`2^(1/(2m_N)) A_N → 1` and the threshold is bounded below by `8 exp(1)^2`.
By the definition of `k_*`, it is also strictly above the threshold. Thus
`ω_N` belongs to the literal `transition` set at this active `k_*`, with
`N^10 < k_* ≤ cutNetTop`.

This is a same-sample counterexample to the requested all-active exclusion,
not merely a gap in the available early-prefix estimate. It uses a valid
pairwise modulus only to control adjacent mesh nodes across the full cell.

## Joint-rate scope and paper check

T1201's `jointRate` is the strict-transition indicator times the prefix
gradient and the square root of the evolved drift QV. The counterexample
shows that the norm-good transition indicator is not identically zero, so
the proposed transition-exclusion argument cannot establish exact vanishing
of the norm-good `jointRate`. I did not establish nonvanishing of either
multiplicative factor at this sample, so this report does not claim that the
product itself is nonzero.

I inspected the authorized PDF `paper/250520-YinJun-v2.pdf` directly.
Equation (5.21) is the stopped integrated 2-G-loop hierarchy; (5.24) is its
stopped martingale moment/QV estimate; (5.43) defines the paper's first
crossing stopping time for `J*`; and (5.44)–(5.46) give the stopped QV bound,
intermediate-terminal-time bound, and finite time-net bound. The discrete
smooth-prefix transition used here is an internal replacement construction,
not the paper's stopping-time event. This counterexample does not contradict
the paper's stopped-process argument.
