## Public interface proved

```lean
permutationFourierClosedTimeGridCount (h : ℝ) : ℕ :=
  Nat.ceil ((1 / 2 : ℝ) / h) + 1

permutationFourierClosedTimeGrid (h : ℝ)
    (j : Fin (permutationFourierClosedTimeGridCount h)) : ℝ :=
  min ((j.val : ℝ) * h) (1 / 2 : ℝ)

permutationFourierClosedTimeGrid_zero (h : ℝ) :
    permutationFourierClosedTimeGrid h ⟨0, Nat.zero_lt_succ _⟩ = 0

permutationFourierClosedTimeGrid_range (h : ℝ) (hh : 0 < h)
    (j : Fin (permutationFourierClosedTimeGridCount h)) :
    0 ≤ permutationFourierClosedTimeGrid h j ∧
      permutationFourierClosedTimeGrid h j ≤ 1 / 2

permutationFourierClosedTimeGrid_last (h : ℝ) (hh : 0 < h) :
    permutationFourierClosedTimeGrid h
      ⟨Nat.ceil ((1 / 2 : ℝ) / h), Nat.lt_succ_self _⟩ = 1 / 2

permutationFourierClosedTimeGrid_coverage (h u : ℝ) (hh : 0 < h)
    (hu0 : 0 ≤ u) (hu1 : u ≤ 1 / 2) :
    ∃ j : Fin (permutationFourierClosedTimeGridCount h),
      |u - permutationFourierClosedTimeGrid h j| < h

permutationFourierClosedTimeGrid_coverage_le (h u : ℝ) (hh : 0 < h)
    (hu0 : 0 ≤ u) (hu1 : u ≤ 1 / 2) :
    ∃ j : Fin (permutationFourierClosedTimeGridCount h),
      |u - permutationFourierClosedTimeGrid h j| ≤ h

permutationFourierClosedTimeGrid_mesh_boundary (h : ℝ) (n : ℕ)
    (hh : 0 < h) (hnh : (n : ℝ) * h ≤ 1 / 2) :
    ∃ j : Fin (permutationFourierClosedTimeGridCount h),
      permutationFourierClosedTimeGrid h j = (n : ℝ) * h

permutationFourierClosedTimeGrid_card (h : ℝ) :
    (Finset.univ : Finset (Fin (permutationFourierClosedTimeGridCount h))).card =
      permutationFourierClosedTimeGridCount h

permutationFourierClosedTimeGridCount_div_le_two_width
    (W : ℕ) (a : ℝ) (hW : 1 ≤ W) (ha : 1 ≤ a) :
    permutationFourierClosedTimeGridCount (a / (W : ℝ)) ≤ 2 * W
```

The coverage proof selects `k = floor (u/h)`. Since `k*h ≤ u ≤ 1/2`,
clipping is inactive at the selected node. The floor inequalities give
`0 ≤ u - k*h < h`, including exact equality `u = k*h` at integer mesh
boundaries. The final index is legal because the number of indices is
`ceil ((1/2)/h)+1`; the ceiling inequality puts its unclipped coordinate at
or above `1/2`. The generic width proof uses `a ≥ 1` to bound
`(1/2)/(a/W) ≤ W`, hence `ceil((1/2)/(a/W))+1 ≤ W+1 ≤ 2W`.

## Boundary and witness checks

The module proves executable arithmetic checks for:

* `h = 1/2`: count `2`, with nodes `0` and `1/2`.
* `h = 1/3`: count `3`, with index `2` clipped from `2/3` to `1/2`.
* Every positive `h`: both endpoints are covered by the general coverage
  theorem; zero and the last index are also given as exact nodes.
* Every in-range integer mesh point `n*h ≤ 1/2` occurs exactly, by
  `permutationFourierClosedTimeGrid_mesh_boundary`.

There are no new probabilistic assumptions, and thus no satisfiability witness
is needed. The mesh theorem assumes only `h > 0` and the stated in-interval
condition. The width bound assumes only `W ≥ 1` and `a ≥ 1`.
