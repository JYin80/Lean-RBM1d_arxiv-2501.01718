# T833 — weighted next-image conditional expectation

## Result

`RBM1D/Gauss/PermutationNextImageWeightedCondExp.lean` proves
`uniformPerm_nextImage_weighted_condExp`: for every `W`, `k : Fin W`, and
deterministic `f : Fin W → ℝ`, the conditional expectation of `f (ρ k)` given
`prefixSigma W k.val` agrees almost everywhere under `uniformPerm W` with
`(∑ v ∈ unusedImages W k π, f v) / ((W - k.val : ℕ) : ℝ)`.

The proof writes the function as a finite sum of singleton indicators, applies
the finite-sum conditional-expectation rule, and uses the accepted singleton
conditional-expectation theorem. It adds no assumptions and does not assume
the target conditional law. The denominator is proved positive from
`k.isLt`.

Boundary and satisfiability checks are included: width zero has no valid
index; at width one the formula reduces to the sole value of `f`; the
width-two witness uses `k = 0` and `f(0) = 0`, `f(1) = 1`, so the function is
nonconstant and the denominator is positive; and the last-index theorem
reduces the average to a sum over the single remaining image with denominator
one. The theorem and witness axioms were printed; they use only
`propext`, `Classical.choice`, and `Quot.sound`. There is no `sorry` or new
axiom.

This is a finite-permutation auxiliary statement. It does not assert either
Gaussian high-probability estimate in paper formulas (2.3)–(2.4), nor any
shared event, analytic scale, or paper-chain closure. No paper delta is needed.
