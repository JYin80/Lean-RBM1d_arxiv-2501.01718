# T490 — general moving high-order coordinate producer audit

## Verdict

After T484, and without assuming either T488 or T489, the earliest remaining
producer that is both mathematically closed and bounded in scope is the
**general moving all-time raw Step-1 source bundle**:

```text
raw loops of lengths 3, 4, and 6
  + the fixed T483 Good event
  -> one measurable high-probability event on every moving window
  -> APrimeFullQV.SourceEvent at every running time
  -> the raw three-loop source at every running time.
```

This bundle is sufficient to unlock the source side of the uncut evolved-QV
route.  It is not the complete coordinate-moment producer: the general moving
all-time centered one-loop estimate used by the drift is still absent from a
public theorem with only the original Step-1 hypotheses.  The first-cell
`DetAvgIBPTimeNet` theorem cannot be substituted for it.

The next ticket should therefore implement only the raw common source event
specified below.  It should not claim a drift bound, a cross bound, a
coordinate moment, `hfamily`, `APrimeSlot'`, or a next-cell `BoundsCore`.

## Literal paper quantities

For a fixed endpoint `v` and running time `u <= v`, the coordinate is

```text
Y_u(a) = [U_(u,v)(L-K)_u]_a / [T_(v,D)(a) R_v^4],
R_v = eta_s / eta_v.
```

The paper's first-pass inputs are:

```text
(5.39)  U_(s,v)(L-K)_s / T_v,
(5.40)  U_(u,v) E^((L-K)x(L-K))_u / T_v,
(5.41)  U_(u,v) E^(G)_u / T_v,
(5.42)  (U_(u,v) x U_(u,v)) E^(ExE)_u / T_v^2.
```

The Lean coordinate, drift, and QV are the literal objects in
`APrimeDriftTimeFamily`:

```text
coordAt  d E D N sigPM a (s N) v u
driftAt  d E D N sigPM a (s N) v u omega
qvAt     d E D N sigPM a (s N) v u omega.
```

The denominator in `coordAt` and `driftAt` is the fixed endpoint scale
`T_(v,D)(a) R_v^4`; `qvAt` is the full uncut Gaussian quadratic variation of
that same coordinate.

## Exact raw source scales

Put

```text
d       = Dims.exampleGrow,
B       = band d,
A_u     = B.scale E N u = W_N ell_u eta_u,
r_u     = ell_u / ell_(s_N),
q_N     = N^zeta,
ellSrc  = ell_(s_N) * (2 q_N)^(-1/5).
```

`Step1.apriori` gives, on one event and simultaneously in time and labels,

```text
length 3:  |L_3(u)| <= q_N r_u^2 A_u^(-2),
length 4:  |L_4(u)| <= q_N r_u^3 A_u^(-3),
length 6:  |L_6(u)| <= q_N r_u^5 A_u^(-5).
```

Define

```text
C3(zeta,N,u) = q_N r_u^2 A_u^(-2),
C4(zeta,N,u) = q_N r_u^3 A_u^(-3),
C6(zeta,N,u) = q_N r_u^5 A_u^(-5).
```

The six-loop premise of `sourceEvent_of_step1` is exact:

```text
2 C6
  = (ell_u / ellSrc)^5 * ((A_u^2)^(-1))^2 * A_u^(-1).
```

Thus the general moving source conversion loses exactly `N^zeta` and no
extra power of `W`, `r_u`, `eta_u`, or the mesh cardinality.  The four-loop
level supplied to `SourceEvent` is exactly `C4`.

## Exact proposed Lean interface

The next module should be
`RBM1D/Gauss/APrimeGeneralMovingRawSources.lean`.  The intended definitions
and theorem signature are:

```lean
namespace RBM.APrimeGeneralMovingRawSources

private noncomputable abbrev d : Gauss.Dims := Gauss.Dims.exampleGrow
private noncomputable abbrev B : Band (Gauss.Ω d) := Gauss.band d

noncomputable def sourceEll (s : ℕ → ℝ) (ζ : ℝ) (N : ℕ) : ℝ :=
  B.ell N (s N) * (2 * (N : ℝ) ^ ζ) ^ (-(1 / 5 : ℝ))

noncomputable def sourceC3 (E : ℝ) (s : ℕ → ℝ)
    (ζ : ℝ) (N : ℕ) (u : ℝ) : ℝ :=
  (N : ℝ) ^ ζ * (B.ell N u / B.ell N (s N)) ^ (2 : ℕ) *
    (B.scale E N u)⁻¹ ^ (2 : ℕ)

noncomputable def sourceC4 (E : ℝ) (s : ℕ → ℝ)
    (ζ : ℝ) (N : ℕ) (u : ℝ) : ℝ :=
  (N : ℝ) ^ ζ * (B.ell N u / B.ell N (s N)) ^ (3 : ℕ) *
    (B.scale E N u)⁻¹ ^ (3 : ℕ)

def rawEvent (E : ℝ) (s t : ℕ → ℝ) (ζ : ℝ)
    (n N : ℕ) : Set (Gauss.Ω d) :=
  {ω | ∀ p : TimeIcc s t N × LoopData (d.L N) n,
    ‖(Gauss.sample d).Lval E N p.1 ω p.2.idx‖ ≤
      (N : ℝ) ^ ζ * Step1.aprioriRhs B E s t n N p ω}

def sourceGood (E : ℝ) (s t : ℕ → ℝ) (ζ : ℝ)
    (N : ℕ) : Set (Gauss.Ω d) :=
  APrimeGeneralMovingGoodMesh.good N ∩
    rawEvent E s t ζ 3 N ∩
    rawEvent E s t ζ 4 N ∩
    rawEvent E s t ζ 6 N

theorem general_moving_raw_sources
    {E c : ℝ} {s t : ℕ → ℝ}
    (hE : |E| < 2) (hs0 : ∀ N, 0 ≤ s N)
    (hst : ∀ N, s N ≤ t N) (ht1 : ∀ N, t N < 1)
    (hc : 0 < c) (hreg : Cond272Reg B E s t c)
    (hB : BoundsCore (Gauss.sample d) E s)
    (hStep : Step1.Hyp (Gauss.sample d) E s t) :
    ∀ ζ : ℝ, 0 < ζ →
      HighProb (Gauss.P d) (sourceGood E s t ζ) ∧
      (∀ N, MeasurableSet (sourceGood E s t ζ N)) ∧
      (∀ N, sourceGood E s t ζ N ⊆
        APrimeGeneralMovingGoodMesh.good N) ∧
      ∀ᶠ N : ℕ in atTop,
        ∀ ω ∈ sourceGood E s t ζ N,
        ∀ u : TimeIcc s t N,
          APrimeFullQV.SourceEvent (Gauss.sample d) E N (u : ℝ) ω
            (sourceEll s ζ N) (sourceC4 E s ζ N u) ∧
          (∀ p : LoopData (d.L N) 3,
            ‖(Gauss.sample d).Lval E N (u : ℝ) ω p.idx‖ ≤
              sourceC3 E s ζ N u)
```

The proof chooses `kappa = (2 - |E|)/2`, applies `Step1.apriori` at
`n = 3,4,6`, takes the three `HighProb.highProb` events at loss `zeta`, and
intersects them with `APrimeGeneralMovingGoodMesh.highProb_good`.
Measurability follows as in `APrimeFirstCellCommon.rawLoopEvent_isClosed`:
each pointwise inequality is closed in `omega`, and arbitrary intersections
of closed sets are closed.  The source identity above discharges the factor
two in `sourceEvent_of_step1`.

## Common-event and boundary audit

The structural slot event remains exactly

```text
Good_N = {omega | ||Xmat_N(omega)|| <= N}.
```

`sourceGood` is an auxiliary event and satisfies `sourceGood_N subset Good_N`.
Consequently T484 applies on the same sample whenever an active widened
weight is positive.  The later moment proof must estimate on

```text
sourceGood_N intersect {V_P > 0}
```

and pay its complement inside the unconditional weighted integral.  It must
not replace the `APrimeHypOn.Good` field by `sourceGood`.

For fixed requested `p >= 1`, choose the high order `P` before the eventual
`N`, with

```text
P >= p,  32 <= 3 delta P,  1/P <= delta/8.
```

Only after this choice select `zeta` and the failure exponent needed to pay
the `2P`-moment complement.  The theorem above quantifies over every positive
`zeta`, so this order is preserved.  Its event is already uniform in all
running times and all loop labels; there is no additional union over active
`k` or output coordinates.

Boundary handling is as follows.

- `k = 0`: `u_0 = s_N`; the source event is available there, but the
  coordinate argument uses the initial estimate and zero time integrals.
- `k >= 1`: for every `r in [s_N,u_k]`, `r` is a member of `TimeIcc s t N`,
  so the same source sample and T484 support cap apply.
- `p = 0`: the final family moment is one and does not use this source ticket.
- All output indices are covered by the `LoopData` quantifiers before the
  eventual `N` statement is specialized.

The nondegenerate witness should use the admissible positive first-cell
window as a special instance of the general theorem.  The common event is
eventually nonempty by `HighProb.nonempty`.  At active `k = 1`, the prefix
contains only `u_0=s_N=0`; `APrimeFirstCellCommon.J_zero` makes the widened
weight equal to one for every sample in `Good`.  Hence one sample from
`sourceGood` simultaneously carries:

```text
s_N < u_1 <= t_N,
omega in sourceGood_N subset Good_N,
widenedW(...,P,N,1,omega) = 1,
SourceEvent at every r in [s_N,u_1].
```

This is a positive-length same-sample source/support witness.  It does not
assert that target support is a high-probability event.

## Exponent preflight after the raw source ticket

On positive support, T484 gives the loop cap

```text
J_loop(u) <= C N^(2 delta) x_u^4,
x_u = eta_s / eta_u.
```

After the entry-event adapter, the block cap has the required form

```text
J_block(u) <= C N^(2 delta + tau) x_u^4.
```

With the raw source losses absorbed into a reserved `N^nu`, the rows required
by the coordinate argument are unchanged from the T485 audit:

```text
drift:
  N^(4 delta)             A_u^(-1)   x_u^6,
  N^(2 delta + tau)       A_u^(-1/2) x_u^(11/4),
  N^(3 delta + 3 tau/2)   A_u^(-1)   x_u^(9/2);

current QV:
  N^(4 delta + 2 tau)     A_u^(-1/2) x_u^(19/4),
  N^(6 delta + 3 tau)     A_u^(-1)   x_u^8;

stored-prefix gradient:
  N^(4 delta + 2 tau)     A_u^(-1/2) x_u^(7/4),
  N^(6 delta + 3 tau)     A_u^(-1)   x_u^5.
```

For `delta0=c/1000`, `tau=delta/16`, and `nu=delta/100`, every row satisfies

```text
(N-exponent + nu)/c + (x-exponent)/30 < A-exponent.
```

This uses the separate consequences `N^c <= A_t` and `x_t^30 <= A_t`; it
does not use the false product strengthening.  The raw source ticket adds no
new power to this table beyond the explicitly reserved `nu`.

## Precise remaining obstruction after the next ticket

The full drift source also needs the centered one-loop estimate at every
running time, in the paper scale

```text
|| trace((G_sigma(u)-m_sigma) E_b) ||
  <= N^zeta1 * r_u * A_u^(-1)
```

for both charges and all blocks on one event.  The public interfaces do not
yet derive this exact all-time general-window statement from only
`BoundsCore`, `Cond272Reg`, and `Step1.Hyp`:

- `DetFlucAvgComplete.fixedTimeFAStatement_proved` is fixed-time;
- `Eq45FlowInputs.unifDomIcc_flucAvg_iter'` is all-time but assumes
  `FlucGainUpTo` for every moment grade and every running time;
- the first-cell construction `DetAvgIBPTimeNet` supplies the missing time-net
  event only for `E=0`, `s=0`, and the first-cell mesh;
- `Eq45FlowBudget.eq45Flow_of_goodSetFlow_budget` still exposes the tower,
  time-modulus, and conditional-gain hypotheses and is not a theorem from the
  original T483/T405 inputs alone.

Therefore the first-cell theorem
`APrimeFirstCellAllTimeNearSources.exists_highProb_good` cannot be renamed or
specialized into the arbitrary moving result.  The ticket after the raw
source bundle must close this exact fluctuation-averaging producer, or report
which one of its public gain/time-net hypotheses remains unprovable from
`Step1.Hyp`.

Only after that obstruction is removed should the implementation assemble:

```text
general source + T484 support
  -> general full drift and diagonal QV
  -> T277 evolved uncut QV
  -> prefix-gradient/current-QV joint product
  -> high-P coordinate moment under one V_P
  -> family sum, same-V_P Lyapunov, widenedW transfer.
```

No result in this audit supplies a conditional `APrimeSlot'` closure or any
next-cell `BoundsCore`.
