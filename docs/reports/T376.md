## Weakest useful stronger cap and a true producer

If a stronger bound `J≤N^β` holds, the four relevant exponents become `ζ`, `2β-3/8+ζ/2`, `3β-3/4`, and `3β-44`, each with an `o(1)` logarithmic loss. To obtain a desired bound `qvAt(h,a)≤N^ν` uniformly in `a` from this profile, a sufficient strict margin is

```
ζ < ν,
β < min(3/16 + ν/2 - ζ/4, 1/4 + ν/3),
```

with a little room left for the `o(1)` factors. In the usual small-`ν`, small-`ζ` regime, the quadratic threshold is binding. In exponent-only terms, `J≤N^(3/16)` is the weakest fixed polynomial cap that works for every prescribed `ν>0` after choosing sufficiently small `ζ>0`; a strict smaller exponent makes the margin immediate. The simpler **true** cap `J≤2` follows on the same event from T366's private `jG_firstTime_le`; it yields far quadratic `N^(-3/8+ζ/2+o(1))`, far cubic `N^(-3/4+o(1))`, and far leakage `N^(-44+o(1))`. The near term `N^(ζ+o(1))` then governs. T366 currently exports only `eventually_jG_le_N_of_norm`. The smallest positive Lean ticket is to assign sole ownership of the T366 file and add a public `eventually_jG_le_two_of_norm` wrapper around its private bound, followed by a disjoint pointwise-rate theorem consuming that exported cap. A wholly new file cannot invoke the private lemma without recreating its proof from public off-block bounds.

No improvement to `ellSource` or `Smax` alone repairs the `J³ A_h^-1` obstruction under `J≤N`, because that term does not contain either source parameter. T348/T366 already quantify over every fixed `ζ>0`, so choosing `ζ<ν` is legitimate for the first-cell pointwise rate. For a fixed `ζ≥ν`, this particular near envelope cannot yield `N^ν`; one would need a stronger length-six source with `(ell_h/ellSource)^5≤N^(ν-o(1))`, or choose a smaller available `ζ`. This is a statement about the displayed envelope, not an impossibility claim about the actual QV.

Finally, T373's witness has one nonzero `h` and one `ω` carrying the norm event, source event, active `k=2` plateau, and QV bound for every label. Its `∃ω` at each `N` is not itself a high-probability event theorem. Even after exporting `J≤2`, a single-time estimate cannot be integrated over `[0,1/2]`, inserted as a weighted QV moment, or extended to every prefix. The next mathematical producer for the smooth-weight consumer must establish the corresponding common event and cap at running times, together with the actual weighted split/integration.
