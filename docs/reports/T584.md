## Exact profile and powers

The proof specializes `APrimeFullQV.qvAt_full_absorbed`; therefore the near
repair is literally `(W_N : Real)^(-1)` and occurs as
`diagNearRate + 2*W^-1` under the near square root.  No residual is erased.
With T491's exact
`sourceEll = ell_s*(2*N^zetaSrc)^(-1/5)`, the full near coefficient is

```text
4 * N^zetaSrc * eta_u^(-1) * cNear2 * r_u^5 + 2*W^(-1).
```

The literal `diagFarRate` in `rootProfile`, after inserting T491's

```text
sourceC4 = N^zetaSrc * r_u^3 * A_u^(-3),
```

retains the three exact pre-square-root rows:

```text
16 * eta_u^(-1) * cFar2 * Jbar^2
   * N^(zetaSrc/2) * r_u^(3/2) * A_u^(-1/2),
1152 * eta_u^(-1) * Jbar^3 * A_u^(-1),
32 * W * L * W^(-D) * Jbar^3.
```

Thus both the quadratic source row and the spatial leakage row remain in the
theorem; neither is replaced by a paper-level monomial.  The near endpoint
leakage `256*exp(3)*W^(-D)` also remains literal.

Both endpoint ratios are retained exactly.  Each kernel term in
`rootProfile` contains `((1-u)/(1-v))^2`, while
`driftScale = T_{v,D}(a) * ratR(E,s,N,v)^4`.  Since

```text
(1-u)/(1-v) = ratR(E,s,N,v) / ratR(E,s,N,u),
```

the normalized root factor is exactly
`ratR(E,s,N,u)^(-2) * ratR(E,s,N,v)^(-2)`.  The implementation deliberately
keeps the literal `rootProfile` representation instead of replacing these
two ratios by a coarser terminal power.

## Boundary handling and dependencies

The active-cell assumptions are `1 <= k` and `k <= cutNetTop`.  The endpoint
`v_k` is proved to lie in `[s_N,t_N]`; hence every `u` in the closed prefix
also lies in the full moving window.  Both `u=s_N` and `u=v_k` are allowed.
No pointwise claim is made at `k=0`: an instantaneous QV rate does not vanish
merely because a later integration interval has zero length.

The monotonicity from the actual `jG` to `Jbar` is proved privately from
`APrimeJGWidened.diagFarRate_mono` and nonnegativity of the endpoint kernel.
The module imports only `APrimeGeneralMovingCommonSources` and the neutral
`APrimeJGWidened` helper module.  It does not import any
`APrimeFirstCellQV*` module, moment conclusion, `hfamily`, `APrimeSlot'`,
six-step assembly, or paper-closure module, so the dependency direction is
acyclic with respect to those consumers.
