## 2. 问题 2：现方案逐环核查

### 2a. 矩 Duhamel 代替 (5.20)+(5.24)；「停止后的二次变差」在矩版本里对应什么

**成立。** 设 `F_u(X) := |Ψ_u(√u X, u)|^{2p}`（`Ψ_u` 通过 `H_u = √u X` 依赖 `X`，通过 `z_u`、`U_{u,t}` 显式依赖 `u`）。对固定 `X` 求导再对 `X_α` 做一次 Stein（`E[X_α g] = σ_α² E[∂_{X_α} g]`，`∂_{X_α}[f(√uX)] = √u ∂_{H_α}f`）得
`d/du E[F_u] = E[(∂_u + 𝓛)F_u]`, `𝓛 = ½Σ_α σ_α² ∂_{H_α}²`，
与 Itô 取期望后完全一致（一时刻边缘律相同）。再由 `𝓛|Ψ|^{2p} ≤ 2p|Ψ|^{2p-1}|𝓛Ψ| + p(2p−1)|Ψ|^{2p-2}Q_u`（`genMomentPt_le`），`Q_u := Σ_α σ_α²|∂_{H_α}Ψ_u|² = (U⊗U∘E⊗E)_{u,a,a}/T^2`（Lemma 5.5 的 (5.25)，`U` 是确定性线性算子所以可以穿过 `∂_α`），Hölder 后除以 `pψ^{p-1}`（`ψ = Φ^{1/p}`，T191 的 `diffIneq_of_deriv_le`）得 `MomentDuhamel.Hyp.momentDuhamel` 的 Minkowski 形式
`‖Ψ_v‖_{2p} ≤ ‖U_{s,v}Ψ_s‖_{2p} + 2∫_s^v‖U_{u,v}F_u‖_{2p}du + (c_{MD}∫_s^v‖Q_u‖_p du)^{1/2}`。
这正是 (5.20)+(5.24)：BDG 的 `E(∫QV)^p` 被 `(∫‖Q_u‖_p)^p` 代替（Minkowski，方向对），既然 (5.44) 本来就是把 `Q_u` 逐点用 `J*` 界住再积分，没有损失。

**停止后的二次变差 ↔ 权重支撑上的二次变差。** 论文 (5.44) 用 `J*_{u,D} < R^4, u<τ`；矩版本里 `E[w·|Ψ|^{2p-2}Q_u] ≤ (E[w|Ψ|^{2p}])^{1-1/p}(E[w Q_u^p])^{1/p}`，而 `E[wQ_u^p]^{1/p} ≤ sup_{supp w ∩ Good_N} Q_u + (坏事件)`。在 `supp w`（早网点 `J*_{u_j} ≤ 2eN^{2δ}R_j^4`）∩ `Good_N`（时间模 + Step 1 的 `≺` 事件）上，由时间模 `J*_u ≤ J*_{u_{j}} + 1·R^4`（`mesh_fine`）得**所有** `u ∈ [s,u_k]` 的先验界，于是 (5.42) 可用。坏事件由 `J*`、`Q_u` 的确定性多项式包络（`jS_le_rpow`、`‖G‖ ≤ η^{-1}`）付账：`E[Q_u^p 1_{bad}] ≤ N^{Kp}N^{-D′}`，`D′ = D′(p)` 任取——量词顺序是 `p` 先定，再取 `D′`，与 `≺` 的定义一致。**所以「停止」在矩版本里就是「乘以支撑在先验事件附近的权重」。**

#### 2c.1 导数与交叉项（一次 Stein）

`F_u(X) := |Ψ_u(√uX,u)|^{2p}`。对固定 `X`：`d/du[w(X)F_u(X)] = w·∂_u^{显}F_u + w·(2√u)^{-1}Σ_α X_α (∂_{H_α}F_u)(√uX)`。对第二项用 Stein，`g := w·(∂_{H_α}F_u)(√u·)`，`∂_{X_α}g = ∂_{X_α}w·∂_{H_α}F_u + w·√u·∂²_{H_α}F_u`：

`Φ′(u) = E[w·(∂_u + 𝓛)|Ψ_u|^{2p}] + C_u`, `C_u := (2√u)^{-1} Σ_α σ_α² E[ ∂_{X_α}w · ∂_{H_α}|Ψ_u|^{2p} ]`. (★)

第一项就是无权重的矩 Duhamel（§2a），`C_u` 是论文里没有的交叉项。（若改用 `hasDerivAt_integral_Psi₁` 的联合形式 `Ψ(u,M) = w(M/√u)F_u(M)`，`∂_1Ψ` 里的 `−(2u^{3/2})^{-1}⟨M,∇w⟩F` 与 `𝓛` 里的 `(2u)^{-1}Σσ²∂²w·F` 经 Stein 恰好合并成同一个 `C_u`；但 `⟨M,∇w⟩` 对 `M` 不一致有界，`bddT` 不成立，所以应直接证 (★)。）

#### 2c.2 Cauchy–Schwarz 拆分的合法性

`∂_{X_α}w = 2p·χ^{2p−1}·χ′(J̃/Θ″)·Θ″^{-1}·∂_{X_α}J̃`，`|∂_{H_α}|Ψ|^{2p}| ≤ 2p|Ψ|^{2p−1}|∂_{H_α}Ψ|`。对同一个 `ω`，在坐标指标 `α` 上用带权 `σ_α²` 的 Cauchy–Schwarz（就是 `sum_gvar_mul_le_sqrt_quadVar`）：
`|Σ_α σ_α² ∂_{X_α}J̃·∂_{H_α}|Ψ|^{2p}| ≤ √QV_X(J̃)·2p|Ψ|^{2p−1}√Q_u`，`QV_X(J̃) := Σ_α σ_α²|∂_{X_α}J̃|²`。
**合法**：两个梯度都是对同一个高斯变量 `X` 的坐标梯度（早时刻的 `∂_{X_α}` 与当前时刻的 `∂_{H_α}` 只差因子 `√u`：`∂_{X_α}[f(√uX)] = √u∂_{H_α}f`），`σ_α²` 是同一组权。「混时刻」没有带来任何额外困难——这与真布朗流里 `⟨M^{(u_j)}, M^{(u)}⟩` 的混协变差不同：在 `√uX` 模型里所有时刻共用一个 `X`，所以出现的是**同一 ω 上两个梯度的内积**，而不是两个鞅的协变差。

#### 2c.3 软最大值梯度的**向量**界（现有砖的问题所在）

`J̃ = Y^{1/q}`，`Y = Σ_i (f_i f̄_i)^r/c_i^{2r}`（`i = (j,b)`，`f_i = lk_{u_j,b}(√u_jX)`，`c_i = T_{u_j,D}(b)R_j^4`）。逐坐标：
`|∂_αJ̃| = |(1/q)Y^{1/q−1}∂_αY| ≤ J̃^{1−q}Σ_i ρ_i^{q−1}|∂_αf_i|/c_i`。
**先在 ℓ²_σ(α) 里用 Minkowski，再对 i 用 Hölder**：
`√QV_X(J̃) ≤ J̃^{1−q}Σ_i ρ_i^{q−1}·√QV_X(f_i)/c_i ≤ J̃^{1−q}(Σ_iρ_i^{q−1})·max_i √QV_X(f_i)/c_i ≤ card^{1/q}·max_i √QV_X(f_i)/c_i`, (V)
其中 `Σ_iρ_i^{q−1} ≤ card^{1/q}(Σρ_i^q)^{1−1/q}` 就是 `sum_abs_pow_pred_le`。而 `QV_X(f_i) = u_j·Σ_ασ_α²|∂_{H_α}L_{u_j,b}|² = u_j·(E⊗E)_{u_j,b,b}`（Definition 5.4，`∂K = 0`）。于是
`Θ″^{-1}√QV_X(J̃) ≤ (2eN^{2δ})^{-1}·e·max_{j,b}√(u_j(E⊗E)_{u_j,b,b})/(T_{u_j,b}R_j^4) ≤ ½√κ̂_max`. (V′)

**现有砖为什么不够。** `abs_deriv_softMax_le_affine` 是**标量**陈述：对每个固定 `α`，从 `|∂_αρ_i| ≤ Λ|ρ_i| + K` 推 `|∂_αJ̃| ≤ ΛJ̃ + card^{1/q}K`。要得到 ℓ²_σ(α) 界必须对 α 求和，而 `K` 有两种取法，都不行：
* 取 `K = K_α := max_i|∂_αρ_i|`（逐 α）：`QV_X(J̃) ≤ e²Σ_ασ_α²max_i|∂_αρ_i|²`，而 `Σ_α max_i ≤ Σ_i Σ_α`，回到 `Σ_i QV(ρ_i) ≤ card·max_i QV(ρ_i)`——**基数损失** `card = N^{Ccard}L²` 原样回来；`max` 与 `Σ_α` 不交换是本质的。
* 取 `K = a₁‖B_α‖`（T250 的 `abs_coordD1_le_affine`，`a₁` 是 `ρ_i` 在**全体** Hermitian `M` 上的一阶导一致上界）：`√QV_X(J̃) ≤ e·a₁·(Σ_ασ_α²‖B_α‖²)^{1/2} ≍ e·a₁√N`。而 `a₁ ≥ sup_M‖∇ρ_i‖`，对远对 `b`（`T_b = W^{-D}`）`a₁ ≳ Wη^{-3}/(W^{-D}R^4) = W^{D+1}η^{-3}R^{-4}`，比 `supp w` 上的真实 `√κ̂ ≲ η^{-1/2}N^{-2δ}` 大 `W^{D+1}η^{-5/2}N^{2δ}` 倍。交叉项因此至少是 `N^{1/2}W^{D+1}η^{-5/2}` 量级，**任何 `≺`/`N^δ` 余量都吸收不了**（附录 B 有量级核算）。
所以回答工单的问题「仿射版下交叉项还能否闭合（`K = a₁‖B_α‖`）」：**不能**。正确的 `K` 不是确定性常数而是随机量 `√QV_X(f_i)/c_i`，并且必须以 (V) 的向量形式使用；(V) 的证明只比标量版多一步 Minkowski，是容易的，但**必须新写**。

#### 2c.5 Grönwall 收口（Minkowski 形式）与为何权重要取 `χ^{2p}`

把 2c.2–2c.3 代入 (★)：
`|C_u| ≤ (2√u)^{-1}·2p‖χ′‖_∞·½√κ̂_max·2p·E[χ^{2p−1}1_{S′}|Ψ_u|^{2p−1}√Q_u]`，`S′ := {Θ″ ≤ J̃ ≤ 2Θ″} ⊇ supp χ′(J̃/Θ″)`。
关键一步：`χ^{2p−1}|Ψ|^{2p−1} = (χ^{2p}|Ψ|^{2p})^{1−1/(2p)} = (w|Ψ|^{2p})^{1−1/(2p)}`，Hölder（指数 `2p/(2p−1)` 与 `2p`）：
`|C_u| ≤ 2p·Φ(u)^{1−1/(2p)}·‖D̃_u‖_{2p}`，`‖D̃_u‖_{2p} := (p‖χ′‖_∞/(2√u))·‖1_{S′}√(Q_u κ̂_max)‖_{L^{2p}(P)}`。
它与漂移项 `2pE[w|Ψ|^{2p−1}|U_{u,t}F_u/T|] ≤ 2pΦ^{1−1/(2p)}‖UF_u/T‖_{w,2p}` **同形**。于是 `momentIneq_of_diffIneq` 的推导（除以 `pψ^{p−1}`、`ψ = Φ^{1/p}`）逐字可用，得到**带权 Minkowski 形式**
`‖Ψ_t‖_{w,2p} ≤ ‖U_{s,t}Ψ_s‖_{w,2p} + 2∫_s^t(‖U_{u,t}F_u/T‖_{w,2p} + ‖D̃_u‖_{2p})du + (c_{MD}∫_s^t‖Q_u‖_{w,p}du)^{1/2}`. (G)
Grönwall 因子是 `1`（Minkowski 形式无指数因子），所有 `p` 依赖都进入常数 `C(δ,p)`。

**为何必须是 `χ^{2p}`（或等价地 `|∂w| ≲ w^{1−1/(2p)}`）。** 若权重取 `w = χ(J̃/Θ′)`（`WeightedMoment` 里 `W` 不依赖 `p`），交叉项里是 `|χ′|·|Ψ|^{2p−1}`，没有任何 `χ` 的幂可供 Hölder 回到 `Φ`。紧支撑光滑函数不可能有 `|χ′| ≤ Cχ`（否则 `χ ≥ χ(x₀)e^{-C|x−x₀|} > 0`）；要 `|χ′| ≤ Cχ^{1−1/(2p)}`，quintic Hermite 在右端 `χ ≍ (2−x)^3`、`|χ′| ≍ (2−x)^2 ≍ χ^{2/3}`，只对 `p ≤ 3/2` 成立。试图用更宽的权重 `χ(J̃/(2Θ′))` 控制 `E[|χ′||Ψ|^{2p}]` 会无穷回归。**所以：对每个 `p` 用 `W_p := χ(J̃/(2Θ′))^{2p}`（仍是 `C²`：`bddC2C_pow_real`），它 `≥ χ(J̃/Θ′)`（`J̃ ≤ 2Θ′` 时 `χ(J̃/(2Θ′)) = 1`），证完 `E[W_p·(…)^{2p}] ≤ CN^{δp/2}` 后由 `weightedMoment_mono`（逐 `p` 用）回到接口权重。接口 `WeightedMoment` 本身不用改。**（也可改 `cutChi` 为平坦型 `exp(−1/(2−x))`，则 `|χ′| ≤ C_pχ^{1−1/(2p)}` 对一切 `p` 成立、权重可与 `p` 无关；但 T175 的 Hermite 轮廓已被多处使用，不建议。）

Cowork 04:05 的「Young 后给 Grönwall 多一项 `Θ^{-2}·sup_v QV-rate_v`」在 `w = χ^{2p}` 之下也是对的：`√(Q_uκ̂) ≤ ½(Q_u + κ̂)` 后，`κ̂` 部分变成加性项 `p‖χ′‖·κ̂_max·∫_s^t u^{-1/2}du ≈ (t−s)κ̂_max`（在 `ψ` 层面，无指数因子），`Q_u` 部分并入现有 QV 项。要避免的是对 `|Ψ|^{2p−1}·(率)` 做逐点 Young 得到 `∫(率)^p du`：`∫(Q_u^{near})^p du ≍ R^{4p}η_s^{1−p}` 比 `(∫Q_u^{near})^p ≍ R^{4p}` 大 `η_s^{1−p}`，不可接受；`MomentGronwall.momentIntegral_le_gronwallBound` 那种「`Φ′ ≤ KΦ + ε`、常数 `ε`」的形式**不能**用于本项，要用 (G)。


#### 2c.6 指数核算：近场、远场，与 Cowork 的两个粗估

在 `Good_N`（Step 1 的 `≺` 事件 ∩ 时间模事件；坏事件由包络 `N^{K}` 与 `P(bad) ≤ N^{-D′}`、`D′ = D′(p)` 付账）上，`κ̂_max ≤ κ̂^{bd}`、`Q_u ≤ Q_u^{bd}`（确定性函数）。交叉项总量

两式都对，但要加三条注记：(i) 它们隐含权重是 `χ^{2p}`（否则 Young 后的 `|Ψ|^{2p}` 项配的是 `χ^{2p−1}|χ′|` 而不是 `w`）；(ii) 它们隐含 `sup_v QV-rate_v` 用的是 (5.36) 在早时刻的**逐路径**界，这要求 Step 1 的 `≺` 事件对全部网点一致（并集界 `N^{Ccard}L²`，标准）；(iii) 在 Lean 的时间相关归一化 `Λ_u = N^{2δ}R_u^4` 下，近场变成更好的 `(t−s)·sup_j κ̂_j^{near} ≤ N^{-4δ}(Im m)^{-1}`，而远场多出自举余量：`c₀³N^{2δ}R^5A_t^{-1/3}`（`A^{-1/3}` 版）或 `c₀³N^{2δ}R^5A_t^{-1/2}`。**这与现有 `StepSide.A_ge : x^{17}R^{10} ≤ A` 的关系**：`N^{2δ}R^5A^{-1/3} ≤ 1` 需要 `A ≥ N^{6δ}R^{15} = x^{48}R^{15}`，`x^{17}R^{10}` **不够**；`A^{-1/2}` 版需要 `A ≥ x^{32}R^{10}`，也不够（`x^{16−17/2}R^{5−5} = x^{15/2}`）。所以要么把 `A_ge` 提到 `x^{48}R^{15}`（(2.72) 的 `R^{30}` 在 `R ≥ N^{2δ/5}` 时蕴含它），要么——**推荐**——早时刻 QV 的远场用锐形式 (5.71)/(5.72)，则 `(t−s)κ̂^{far} ≤ W^{-1}[R^{7/4}A_t^{-1/2} + N^{2δ}R^5A_t^{-1}] ≤ W^{-1}` 在现有约束下已成立。

#### 2c.7 `Θ ≍ (η_s/η_t)^4` 是否合适

合适。门槛要满足 (a) 高于结论且有余量：结论（归一化后）`‖Ψ_t‖_{w,2p} ≺ R^{-2}·1(near) + R^{-4}`，即未归一化 `R^2·1 + 1`，门槛 `N^{2δ}R^4`（或论文的 `R^4`）在 `R ≥ N^{τ}` 时有余量；(b) 低到使漂移/QV 的远场在 `J* ≤ Θ` 下 `≺ 1`：按 2c.6 与 §3，用锐远场在 (2.72) 下成立。任何 `R^{2+ε} ≤ Θ ≤ R^4` 都行，`R^4` 是 (2.76) 的自然选择；Lean 的时间相关 `Λ_u = N^{2δ}(η_s/η_u)^4` 更锐、且与 `jSnorm`、`thr` 一致。

#### 2c.8 一步的完整核算（归一化单位，`‖·‖ = ‖·‖_{w,2p}`，`Good` 上、带 `N^{ε}`）

`‖Ψ_t‖ ≤ ‖U_{s,t}Ψ_s‖ + 2∫‖UF_u/T‖ + X + (c_{MD}∫‖Q_u‖_p)^{1/2}`
* 初值 (5.39)：`≺ r_t²·1(near ℓ*_t) + 1` → `/R^4`：`R^{-3}·1 + R^{-4}`；
* 漂移 (5.40)：`∫η_u^{-1}(η_u/η_t)²A_u^{-1}(c₀Λ_u)²du ≤ c₀²N^{4δ}R^{8}A_t^{-1}·R²/2` → `/R^4`：`≤ N^{4δ}R^{-24}`；
* 漂移 (5.41) 近：`∫η_u^{-1}(η_u/η_t)²r_u²du ≤ R²/Im m` → `R^{-2}·1(near 3ℓ*_t)`；远：**必须用锐形式**（项目的 `eG_le_reduced`：`β J* + γ (J*)^{3/2}`，`β = r^{3/2}A^{-1/2}`、`γ = rA^{-1}`），则 `≪ 1`；论文所写形式 `η_u^{-1}(η_u/η_t)^2A_u^{-1/3}(J*)^3` 积分后为 `c₀³N^{6δ}R^{12}·A_t^{-1/3}R^{11/6}/Im m ≤ c₀³N^{6δ}R^{23/6}`（用 (2.72)），归一化后 `N^{6δ}R^{-1/6}`，**装不进预算 `N^{δ/4}`**——见 §3；
* QV (5.42)：`(∫Q̂)^{1/2} ≺ R^{-2}·1(near 6ℓ*_t) + [远]^{1/2}`；
* 交叉项：`X ≺ N^{-2δ}R^{-2}(log N)^{1/2} + [远]`。
合计 `‖Ψ^{(a)}_t‖_{w,2p} ≤ N^{ε}·(C R^{-2}·1(|a_1−a_2| ≤ 6ℓ*_t) + C R^{-4})`，即未归一化的 (5.48)：`R^2·1(near) + 1`。再取 `max_a`（`L²` 并集，`L^{1/p} ≤ N^{ε}`）与 `+1`：`‖jSnorm(u_k)‖_{w,2p} ≤ C N^{2ε} ≤ x² = N^{δ/4}`（`ε ≤ δ/16`，`p ≥ 8/δ`），即 `E[w·cutTrunc(N^{2δ},jSnorm(u_k))^{2p}] ≤ N^{δp/2}`——`WeightedMoment` 的逐 `p` 子句，常数 `C = 1`；小 `p` 用 Lyapunov（§2e）。改进倍数 `N^{2δ} → N^{δ/4}`，与 `netGood_highProb_of_condMoment` 的 Markov 步（`p ≥ 2(D+Ccard+2)/δ`）匹配。
