## Deterministic proof

T458 supplies, uniformly over all resident moving endpoints,

```text
N^(1/2) <= A_v,
1 <= x_v <= 2.
```

For every `q in [0,v]`, antitonicity of `etaT` gives
`1 <= x_q <= x_v <= 2`.  Thus the two negative near powers are at most one.

For the half-scale rows,

```text
A_v^(-1/2) <= N^(-1/4),
```

and for the full-scale rows,

```text
A_v^(-1) <= N^(-1/2).
```

The four far rows are therefore bounded by

```text
2^(7/4)  N^(4 delta + 2 tau - 1/4),
2^5      N^(6 delta + 3 tau - 1/2),
2^(19/4) N^(4 delta + 2 tau - 1/4),
2^8      N^(6 delta + 3 tau - 1/2).
```

The proof uses the two largest constants and one common eventual filter
intersection.  The gaps

```text
quadGap  = 1/4 - (4 delta + 2 tau) > 0,
cubicGap = 1/2 - (6 delta + 3 tau) > 0
```

make both resulting negative powers tend to zero.  The threshold depends on
neither `k` nor `u` nor `r`.
