# T1133 — integral bound for the actual general-moving cross budget

## Verdict: mathematical preflight PASS; exact actual-budget cap proved

The new theorem
`RBM.APrimeGeneralMovingCrossBudgetIntegralBound.eventually_integral_positive_time_cross_budget_le`
proves, for each fixed `p ≥ 1`, eventually in `N` and uniformly for every
active target-mesh index `k` and output `a`,

```text
∫_[s_N, cutNetPt(...,N,k)] Bc(E,D,deltaWeight,s,t,N,k,p,a,r) dr
  ≤ 2 · envelopeConstant(p,N,D)
      · (√cutNetPt(...,N,k) − √s_N),

envelopeConstant(p,N,D) = crossMomentCoeff(p)/(4p) · N^(2D+17).
```

Here `Bc` is the existing `positiveTimeCrossBudget`, whose definition retains
the actual canonical smooth weight through `jointRate` and the fixed actual
`Step2.sigPM` charge. The theorem is exactly for the same `E,D,c,s,t,
deltaWeight,p,N,k,a` inputs and active-cell range as T1107, T1113, and T1123.
No alternate sample, charge, coefficient, or weakened cap is introduced.

## Mathematical preflight

I checked only `paper/250520-YinJun-v2.pdf`. Formula (5.21) is the stopped
integrated loop hierarchy and includes the terminal stochastic-integral
term. Formula (5.24) is the BDG bound for that stochastic integral in terms
of its integrated transported `E⊗E` quadratic variation. This theorem does
not prove either paper formula or bound the martingale term; it integrates
the already-defined T1089 actual `Bc` using the accepted T1107 pointwise cap.

The actual accepted producer signatures match exactly:

- T1107 `eventually_positive_time_cross_budget_le_polynomial` supplies
  `0 ≤ Bc ≤ crossMomentCoeff(p)/(4p√r) · N^(2D+17)` for positive `r`,
  eventually and uniformly on every active closed cell/output.
- T1113 `eventually_active_target_cross_envelope_integral` supplies
  integrability and the exact integral of that same deterministic envelope,
  plus the same positive-time pointwise cap.
- T1123 `eventually_intervalIntegrable_positive_time_cross_budget` supplies
  interval integrability of the actual `Bc` on those same cells, eventually
  in `N`, with no additional assumption.

The new proof intersects the three eventual statements, extends the
pointwise comparison to `r=0` (both formal expressions equal zero), and
applies `intervalIntegral.integral_mono_on`. T1113 evaluates the upper
integral as `2 · envelopeConstant · (√v − √s)`, including `s=0` and `s=v`.

Boundary and identity checks:

- `r=0`: the source `Bc` and `crossEnvelope` both evaluate to zero under the
  formal division-by-zero and negative-rpow conventions; this is proved in
  the all-points comparison, so the closed endpoint is included.
- `k=0`: the theorem quantifies over all active indices, including `k=0`.
  There the target endpoint equals `s_N`; both sides are zero by the
  degenerate interval and square-root difference.
- `p=1`: allowed by the literal `hp : 1 ≤ p`; the coefficient agrees with
  the accepted `crossMomentCoeff_one = 15/2`, so the envelope constant is
  `(15/8)·N^(2D+17)`.
- Same sample/charge/coefficient: the actual budget definition uses the
  existing `jointRate` and `Step2.sigPM`; the pointwise and integrability
  producers have those same exact definitions. No samplewise replacement is
  made in the integration step.
- T995: the theorem re-exports the accepted
  `t995_positive_cell_witness`, which supplies the nondegenerate `E=0`,
  `D=60`, `p=1` positive-cell/same-sample positive-actual-weight witness.
  Its scope remains a common-event witness, not transition-event membership.
