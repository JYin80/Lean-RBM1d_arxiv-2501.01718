# T638 — non-scalar same-sample support feasibility audit

## Verdict

**Split verdict: a genuinely non-scalar, positive-variance, block-circulant path can be
made to pass the strict transition, norm, all three raw-event rows, and the whole closed
`goodSetFlow` interval, but the identical transition sample fails the next literal row,
`centeredEvent`.**  The failure is not a loose estimate.  For every block-diagonal
identical-block matrix, the Ward identity gives an exact relation between the diagonal
two-loop error that drives the transition and the imaginary part of the centered block
trace.  The transition requires size `N^(2*deltaWeight)/W`, while `centeredEvent` permits
only `N^zetaCtr/W`; here

```text
2*deltaWeight = deltaCap,       zetaCtr = deltaCap/64.
```

Hence the two strict margins are incompatible eventually.  This rules out the natural
same-block/circulant construction, but it does **not** refute every band-supported
non-scalar matrix: a construction with genuine coupling between neighbouring physical
blocks could redistribute the two-loop mass while keeping its Ward row sum small.  No
such deterministic construction or impossibility theorem is currently available.

The audit stops at `centeredEvent`.  It makes no assertion about `blockEvent`/`jG`, finite
Gaussian support, the measurable core, or a positive-mass cylinder.  It selects no Lean
implementation ticket.

Only this report was written.  No Lean source, root import, scheduler/status file,
paper-delta file, git index, commit, branch, or remote state was changed.

## 2. A deterministic non-scalar path on positive-variance coordinates

Write `W = d.W N`, `L = d.L N`, and identify the matrix space as `L` physical blocks of
size `W`.  Let `rho_sc` be the semicircle law.  Choose one point `lambda_j in [-2,2]`
from each of the `W` equal-mass quantile intervals of `rho_sc`.  For

```text
0 <= r <= 1/sqrt(2),
f_r(lambda) = (r*lambda - i*(1-r^2))^(-1),
```

the semicircle equation gives

```text
integral f_r d rho_sc = i.
```

Choose a permutation `pi_N` of the quantile points such that every non-zero discrete
Fourier coefficient is uniformly small:

```text
sup_{0 <= r <= 1/sqrt(2)} max_{q != 0}
  abs(W^(-1) * sum_j f_r(lambda_(pi_N j)) * exp(2*pi*i*q*j/W))
    <= C * sqrt(log W / W).                                      (2.1)
```

This is a deterministic finite choice.  Existence follows by applying bounded-difference
concentration to a uniformly random permutation on an `r`-net of spacing `W^(-3)`, taking
a union bound over at most `O(W^4)` pairs `(q,r_net)`, and extending off the net.  On the
whole interval, `abs(f_r) <= 2` and `abs(partial_r f_r) <= 16`, so the extension error is
`O(W^(-3))`.  The auxiliary permutation probability is used only to prove the existence
of one finite deterministic permutation; it is not the Gaussian model law, not a
high-probability replacement for carrier membership, and does not change the sample
between rows.  One may take the lexicographically first permutation satisfying (2.1).

Let `F_W` be the Fourier matrix and set

```text
A_0 = F_W^* diag(lambda_(pi_N j)) F_W.
```

Repeat `A_0` on every physical block and put zero between distinct physical blocks.  This
matrix is Hermitian and genuinely non-scalar.  Every possibly non-zero entry lies inside
one physical block.  For such two indices `i,j`,

```text
Sblk L W i j = 1/(3W) > 0,
```

so both off-diagonal real/imaginary coordinates and the used diagonal real coordinate
have positive Gaussian variance.  Thus the construction uses no zero-variance direction.

Now use the later target-mesh point from T633:

```text
j_N = ceil(5 * mesh N / N^2),
u_N = j_N / mesh N,
k_N = j_N + 1,
5/N^2 <= u_N <= 6/N^2.
```

Choose

```text
R_N = ceil(C_0 * exp(1)^2 * N^deltaCap),
```

where `C_0` is a fixed sufficiently large numerical constant.  Since
`W >= N^(5/8)` eventually and `deltaCap <= 1/100`, `R_N/W -> 0`.  Replace any `R_N`
Fourier eigenvalues in every copy of `A_0` continuously by the common value

```text
a_N = 2/sqrt(u_N).
```

Call the resulting identical-block matrix path `M_N(theta)`, `0 <= theta <= 1`, with
`M_N(0)` the unspiked matrix and `M_N(1)` the fully moved eigenvalues.  It is realized by
one sample `omega_N(theta)` through the real/imaginary coordinates read by `Xmat`.

The endpoint satisfies

```text
a_N <= 2*N/sqrt(5) < N,
norm(M_N(theta)) <= max(2,a_N) < N.                              (2.2)
```

## 3. Strict transition on the literal prefix

At every stored `v <= u_N`, the unspiked diagonal two-loop is the equal-mass quantile
approximation of its semicircle integral.  The quantile `W_1` error is `O(W^(-1))` because
the support has length `4` and the resolvent and squared-resolvent functions are uniformly
Lipschitz on `v <= 1/2`.  Consequently its diagonal `L-K` error is

```text
O(W^(-2) + v/W).
```

For distinct physical blocks, `L=0`, while the exact propagator estimate gives

```text
abs(K_ab) <= W^(-1) * v^dist(a,b)/(1-v).
```

Using the main, distance-dependent part of `tailT` rather than the `W^(-60)` floor,
the worst non-zero distance is `1`; uniformly for `v <= u_N`, all normalized errors are
`O(1 + vW) = O(1)`.  Canonical calibration therefore gives

```text
prefixSample(M_N(0)) = O(1) < T_N.                              (3.1)
```

At `v=u_N`, each moved eigenvalue changes its squared resolvent from at least `2/3`
eventually to

```text
abs(2 - i*(1-u_N))^(-2) <= 1/4.
```

Thus the diagonal two-loop changes by at least a fixed multiple of `R_N/W^2`.  Since

```text
tailT(W,ell_u,eta_u,60,0) * ratR(0,s,N,u)^4 <= 16/W^2
```

on this early interval, the last stored `jSnorm` is at least `c_0 R_N`.  The choice of
`C_0` makes

```text
prefixSample(M_N(1)) > 2*T_N.                                  (3.2)
```

All resolvents stay a positive distance from the real axis, so the finite matrix path and
the literal smoothed prefix are continuous in `theta`.  From (3.1)-(3.2), the intermediate
value theorem supplies `theta_N in (0,1)` with, for example,

```text
prefixSample(M_N(theta_N)) / T_N = 3/2.
```

This is a genuine non-scalar strict transition at the literal `targetMesh`, the literal
`canonicalM`, and a prefix `k_N` chosen only after `N`.

## 4. Literal raw-carrier audit

Let `omega_N = omega_N(theta_N)`.

| literal row | result | strict margin |
|---|---:|---|
| `normEvent` | PASS | `norm(Xmat omega_N) < N` by (2.2) |
| `rawEvent n=3` | PASS | exact factor `eta_u^(-1) <= 2 < N^zetaSrc` |
| `rawEvent n=4` | PASS | same exact factor |
| `rawEvent n=6` | PASS | same exact factor |
| `goodSetFlow`, every entry and `u in [0,1/2]` | PASS | error `C sqrt(log W/W) + 4R_N/W < flowDelta_N` |
| `centeredEvent`, plus charge | **FAIL** | forced size `gtrsim N^deltaCap/W`, allowed size `O(N^(deltaCap/64)/W)` |

### 4.1 Exact raw-event powers

For `n=3,4,6`, the deterministic resolvent envelope is

```text
norm(Lval_n) <= eta_u^(-n) * W^(-(n-1)).
```

Since `s_N=0`, `ell_s=1`, and `Gauss.aprioriRhs_eq` gives

```text
Step1.aprioriRhs_n = (W*eta_u)^(-(n-1)),
```

the quotient is exactly `eta_u^(-1) <= 2`.  The three right sides remain, literally,

```text
N^zetaSrc * (W*eta_u)^(-2),
N^zetaSrc * (W*eta_u)^(-3),
N^zetaSrc * (W*eta_u)^(-5).
```

No sample replacement or high-probability statement is used.

### 4.2 Closed-endpoint `goodSetFlow`

For the unspiked block, the diagonal resolvent entries differ from `i` by `O(W^(-1))`,
and (2.1) bounds every off-diagonal entry by

```text
C*sqrt(log W/W).
```

Entries between physical blocks vanish.  Replacing `R_N` eigenvalues changes any
resolvent entry, uniformly for `0 <= u <= 1/2`, by at most

```text
(R_N/W) * (2/(1-u)) <= 4R_N/W.
```

At the included endpoint `t_N=1/2`, because `L>=3`,

```text
ell_(1/2) = sqrt(2),  eta_(1/2)=1/2,
flowDelta_N = (W/sqrt(2))^(-1/6) = 2^(1/12)*W^(-1/6).
```

Both `sqrt(log W/W)` and `R_N/W` are `o(W^(-1/6))`; the same endpoint threshold is used
on the entire interval.  Hence every entry and both closed endpoints pass strictly.

### 4.3 First obstruction: exact Ward/centered incompatibility

For any identical-block block-diagonal Hermitian matrix, write

```text
G_a(u) = (sqrt(u)*A - i*(1-u))^(-1),
c_a(u) = W^(-1)*Tr(G_a(u)) - i.
```

Here `c_a` is exactly the plus-charge `centeredTrace`.  The block Ward identity and the
definition of the two-loop give

```text
L_(+,-),(a,a) = W^(-2) * normFrob(G_a)^2
              = (1 + Im c_a)/(W*(1-u)).
```

The deterministic kernel is `K_(a,a)=W^(-1)*Theta_u(a,a)`.  Therefore

```text
lk(a,a)
  = Im(c_a)/(W*(1-u))
      + W^(-1) * ((1-u)^(-1) - Theta_u(a,a)).                  (4.1)
```

For real `0 <= u < 1`, the Neumann series for `Theta_u` is entrywise non-negative,
`Theta_u(a,a) >= 1`, and `sum_b Theta_u(a,b)=(1-u)^(-1)`.  Hence the second term of
(4.1) lies in

```text
[0, u/(W*(1-u))].                                               (4.2)
```

Now use only the lower strict transition inequality.  The public smooth-prefix upper
bound implies contrapositively that some stored time `v <= u_N` has

```text
jSnorm(v) >= T_N/exp(1) - N^(-10) >= c*N^deltaCap.              (4.3)
```

For the block-diagonal matrix all off-block loops vanish.  The exact `Theta` power bound
and the distance-dependent `tailT` show that every `a != b` normalized error is `O(vW)=o(1)`.
Thus (4.3) is attained on a diagonal pair.  Since the diagonal tail is at least `W^(-2)`,

```text
abs(lk(a,a)) >= c*N^deltaCap/W^2.                               (4.4)
```

Equations (4.1)-(4.2), `v <= 6/N^2`, and `W <= N` then give

```text
abs(c_a(v)) >= W*(1-v)*abs(lk(a,a)) - v
            >= c'*N^deltaCap/W.                                (4.5)
```

But inside the window

```text
qExt(0,s,t,N,v) = 1/(W*(1-v)),
```

so the literal centered row requires

```text
abs(c_a(v)) <= 2*N^zetaCtr/(W*(1-v)) <= 4*N^(deltaCap/64)/W.    (4.6)
```

The strict lower bound (4.5) exceeds (4.6) eventually.  Therefore the same transition
sample is outside `centeredEvent` already for the plus charge.  Per the ticket's stopping
rule, this report makes no claim about the minus charge beyond the definition and makes no
claim about the later `blockEvent`/`jG` row.

## 5. Exact remaining deterministic gap

The failed construction isolates a more precise target than “find a non-scalar matrix.”
Any next candidate must use genuine nearest-neighbour physical-block coupling and must
simultaneously provide, on the identical sample,

```text
max normalized abs(L-K)  ~ N^deltaCap,
all centered Ward row sums = O(N^(deltaCap/64)/W),
all Green entries within flowDelta_N = 2^(1/12) W^(-1/6),
norm(Xmat) < N,
```

through every closed-window time.  Equivalently, it must create a large **spatial
redistribution** of the non-negative two-loop mass while keeping its row sum almost
unchanged.  The smallest honest missing statement is either

1. a deterministic nearest-neighbour block-coupled approximation realizing this
   redistribution with the displayed strict margins; or
2. an impossibility estimate deriving `prefixSample < threshold` from `goodSetFlow` plus
   `centeredEvent` at these exponents.

Neither statement is present in the repository or follows from the block-diagonal Ward
calculation.  No finite-support or measurable-core work is useful before one of them is
settled.
