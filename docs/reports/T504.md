## Proof

The positivity of the block lengths and `etaT` permits exact cancellation
of `ell_N(u)` against `scale_E,N(u) = W_N ell_N(u) etaT(E,u)`.

T473 supplies `N^(-1) <= 1-t_N`. Consequently, on the window,
`(1-u)^(-1) <= N`. Multiplication by the mesh bound gives the exact relative
estimate `N^(-16) N = N^(-15)`.

The factor-two proof uses the sufficient consequence
`|u-v| <= N^(-16) <= N^(-1) <= 1-t_N` for `N >= 1`. Hence

```text
1-v <= 2(1-u),
etaT(E,v) <= 2 etaT(E,u),
q_N(u) <= 2 q_N(v).
```

Here `etaT(E,u) = (1-u) (mE E).im` and `(mE E).im > 0`.
Interchanging the two times proves the reverse inequality on the same
deterministic window.
