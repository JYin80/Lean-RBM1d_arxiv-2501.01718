## ⭐⭐ 第 0 步的答案：衰减率**不是过粗**——是 T205/T227 **读错了**

**`cor35Rate δ = cZero · √δ / 4`**（`Loop/Cor35.lean:366`）——**根号**在间隙上，**不是线性**。

* `exists_loopDecay_Kval`（`Gauss/Step6DriftEG.lean:390`）把 `δ` 取成 `cKdecay 3 (1−v)·exp(−cor35Rate(1−v)·ℓ)`，间隙用 `1−v`。
* 所以衰减**长度**是 `(1−v)^{−1/2}`，**正是 `ellHat` 的第一支** `ℓ̂_v = min((1−v)^{−1/2}, L)`——与第一阶段 (2.52) **同一个锐化长度**。
* 于是 `cor35Rate(1−v)·(ℓ_v·N^τ) = (c₀/4)·N^τ`，**已编译成 `cor35Rate_mul_ell_mul`**（用 `LKDecayQuant.ellHat_mul_sqrt_eq_one`：截断不活跃时 `ℓ̂_v√(1−v) = 1`，**间隙精确抵消**）。指数是 `e^{−c₀N^τ/4}`，**没有 `D log N` 门槛要过**。
* 互补区制 `L√(1−v) < 1` 下 `ℓ_v = L`，半径 `ℓ_vN^τ > L/2` 超过环直径，陈述平凡。

**交替电荷那一支**：`hgap` 只用 `‖m(σ)m(σ′)‖ = 1`，对**所有**电荷组合给同一个 `1−v`，所以 `cor35Rate` **已经是最坏（交替）那支的率**，非交替支不需要更好的界。T229 的 `n = 2` 闭式思路**不必用上**。
