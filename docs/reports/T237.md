## 三件各自的结论

1. **`lkGood` 可测性 —— 做成了，但走的是「不需要可测性」那条。**
   没有去证 `MeasurableSet (lkGood …)`（它对不可数的 `TimeIcc` 取交，仍未证），
   而是按 T222 的做法取**可测核** `measCore P Ξ := (toMeasurable P Ξᶜ)ᶜ`：
   它是 `Ξ` 的**可测子集**（一切 `∀ ω ∈ Ξ` 假设自动继承）、**补集测度相同**
   （`HighProb` 逐字继承）。「时间连续性 + 可数稠密子集」那条路**没用上、不需要**。
   `toMeasurable` 一次即过：对**补集**取 hull 再取补，`measure_toMeasurable` 给等测度、
   `subset_toMeasurable` 给子集方向，正好是需要的两个方向。仓库里同一惯用法已有三处
   （`Gauss/Envelope.lean:290`、`Gauss/CutHypTheta.lean:1762`、`Gauss/Step6DriftSplit.lean:203`），按后者写，没造新轮子。

2. **`hDec*` 事件限制版 —— 做到「单条 `momNorm`」一层。**
   `momNorm_Uker_{Qop,commS,dot,QQ}_event_untrunc_le`：结论是**未截断**的张量，
   假设里**没有任何 `∀ ω` 量化的衰减**（只要 `∀ ω ∈ Ξ`，且 `Ξ` **不带可测性**），
   代价是三条新假设（确定性包络 `Env`、可积性、`(P Ξᶜ).toReal ≤ pr`）。

3. **`hEnv*` 的 `Qop` 半边 —— 做成。**
   `hGM_Qop_of_event` 用 `SumZeroDyn.norm_Qop_le_of_fastDecay` 把「事件上的 size `M` + 衰减 `δ`」

   `ζ = (2c)^{n+1}L^{n+1}δ`），事件外靠 `Qop 0 = 0` 免费。
