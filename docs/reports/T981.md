## Cylinder and actual Gaussian mass

At fixed `N`, the flow constraints have finitely many entry indices and
continuous test functions in `(ω,u)`: `continuous_Xmat` gives joint continuity
of `Hflow = √u • Xmat`, the spectral parameter stays in the upper half-plane
on the compact half-time interval, and matrix inversion and entry norms are
continuous there. The centered constraints have finitely many `(charge, block)`
indices. Their trace integrands are continuous by the same resolvent argument,
and their threshold is continuous in time: on `[0,1/2]`, the clamped extension
`qExt` is `1/[W_N(1-u)]`, whose denominator is bounded below by `W_N/2`.
Finally, continuity of `Xmat` and of the finite-dimensional operator norm
makes `ω ↦ ‖Xmat Dims.exampleGrow N ω‖` continuous.

Each strict inequality at `ω_N` consequently holds on an open neighborhood in
`Ω`; compactness of `[0,1/2]` upgrades the time-indexed flow and centered
neighborhoods to finite-coordinate cylinders via the same generalized-tube /
product-neighborhood argument used in T963/T968. Intersect the three
cylinders by taking the union of their finite coordinate sets and intersecting
the corresponding open coordinate neighborhoods. The resulting cylinder is
still centered at `ω_N` and lies in the literal triple intersection for every
coordinate sample in it.

Restrict this finite cylinder to `effectiveCoords` and take the finite product
of its coordinate neighborhoods. This is open and nonempty, witnessed by the
restriction of `ω_N`. For every cylinder coordinate with zero variance,
compatibility gives `ω_N c = 0`; since the coordinate neighborhood contains
`ω_N c`, it contains the Dirac support value `0`. Therefore the support
cylinder (active coordinates in the open set and zero-variance coordinates
fixed to zero) lies in the triple event. T962's `support_cylinder_pos` gives
this support cylinder strictly positive `P Dims.exampleGrow` mass. By measure
monotonicity, the literal triple intersection has positive mass; no measurability
of that intersection is needed for this lower bound.

The carrier is nondegenerate: eventually `W_N ≥ 2`, `L_N ≥ 3`, and the matrix
is nonzero. The interval has distinct endpoints. The same center satisfies all
these checks; no second witness or incompatible zero-variance assignment is
introduced.

```lean
(N : ℕ) (zeta δ : ℝ) (ω₀ : Ω Dims.exampleGrow)
(hthreshold : ∀ u ∈ Set.Icc (0 : ℝ) (1 / 2 : ℝ),
  δ ≤ (N : ℝ)^zeta *

      (if i = j then mE 0 else 0)‖ <
        flowDelta Dims.exampleGrow 0 (fun _ => 1 / 2) N)
(hctr : ∀ u ∈ Set.Icc (0 : ℝ) (1 / 2 : ℝ),
  ∀ b : ZMod (Dims.exampleGrow.L N),
    ‖APrimeGeneralMovingTwoChargeModulus.centeredTrace 0 N u ω₀ true b‖ < δ)
(hnorm : ‖Xmat Dims.exampleGrow N ω₀‖ < (N : ℝ))

  (gvar Dims.exampleGrow c : ℝ) = 0 → ω₀ c = 0) :
```
