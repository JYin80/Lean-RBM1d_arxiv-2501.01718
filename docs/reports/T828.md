## Exact logical conversion

For fixed `κ,τ`, define the **single-index** domain

```text
A_N(z) :≡ 0 < Im z ∧ Im z ≤ 1 ∧ |Re z| ≤ 2−κ
           ∧ (N:ℝ)^(−1+τ) ≤ Im z.
```

Assume `0<κ≤2` and `0<τ<1`, as in the nonempty small-parameter regime. There is a filler `z⁰_N=i/2`: it satisfies the first three conditions for every `N`, and the fourth eventually because `N^(−1+τ)→0`. Equally, `i` works as a filler even at `τ=1`. The precise abstract requirement is only an all-`N` base sequence satisfying the first three conditions and the fourth eventually; the explicit inequalities on `κ,τ` are a convenient sufficient condition.

Let `P_N(z)` be either stated failure-probability bound. From

```text
∀ z : ℕ→ℂ, [first three conditions for every N]
  → [fourth condition eventually]
  → ∀ᶠ N, P_N(z N),
```

one **can prove** `∀ᶠ N, ∀ z, A_N(z) → P_N(z)`. If the latter failed, choose an unbounded set of indices `N_j` and at each one an admissible `z_j` for which `P_{N_j}(z_j)` fails. Define a single sequence equal to `z_j` at those indices and to `i/2` elsewhere. It satisfies the first three conditions at every index and the fourth eventually, yet its eventual `P_N` assertion fails at infinitely many `N_j`. This is a classical choice/diagonal argument. A version using one chosen counterexample at every bad index avoids enumerating the subsequence. Any initially given spectral sequence whose positivity, upper bound, or bulk condition fails on a finite prefix can first be replaced there by the filler; eventual statements are invariant under that change. The selected large bad indices must be left untouched.

For a precise Lean target, let `EntryBad B T N z τ` and `BlockBad B T N z τ` abbreviate **exactly** the two set comprehensions in `localSemicircleLaw_of_Thm221N'_of_z`, with `z N` replaced by `z` and `τ'` by `τ`. The conditional candidate is:

```lean
theorem uniform_localSemicircleLaw_of_Thm221N'_of_z
    (T : Transfer X) (T1 : TransferLoop1 T)
    (hκ : 0 < κ) (hκ2 : κ ≤ 2)
    (hτ : 0 < τ) (hτ1 : τ < 1)
    (hT : Thm221N' X κ) {D : ℝ} (hD : 0 < D) :
    ∀ᶠ N : ℕ in atTop, ∀ z : ℂ,
      0 < z.im → z.im ≤ 1 → |z.re| ≤ 2 - κ →
      (N : ℝ) ^ (-1 + τ) ≤ z.im →
      B.P (EntryBad B T N z τ) ≤ ENNReal.ofReal ((N : ℝ) ^ (-D)) ∧
      B.P (BlockBad B T N z τ) ≤ ENNReal.ofReal ((N : ℝ) ^ (-D))
```

Here the abbreviations must be expanded or actually defined before typechecking. The result is uniform in the **eventual index** `N₀`, and its quantifier order is `∃N₀ ∀N≥N₀ ∀z∈A_N`. Apply the existing moving-energy theorem to the diagonal sequence with `τ'=τ`; use its two eventual bounds together to handle the conjunction. Alternatively first prove an abstract lemma for `P_N` and specialize it twice. The latter keeps this quantifier argument separate from resolvent algebra. `hT` must stay outside the `z` quantifier. For the bounds-core route, the required premise would instead be `∀` admissible sequences `z`, a corresponding `BoundsCoreN ...`; the current theorem taking just one `hB` does not supply it.

The logical lemma makes no claim about `P(∀ admissible z, both inequalities hold)` at a given `N`. Pointwise probability bounds, even with an `N₀` uniform in `z`, do not imply a bound on the probability of the union over uncountably many `z`: on `[0,1]` with Lebesgue measure, each singleton `{z}` has mass zero while their union has mass one. A simultaneous-in-`z` event needs an additional analytic discretization/continuity argument and measurability. The paper's displayed (2.3) and (2.4) each fix `z` and already union over their finite spatial index sets. If a later result needs the entry and block bounds on one event for that fixed `z`, apply the two estimates with `D+1` and a union bound at sufficiently large `N` (`2N^(−D−1)≤N^(−D)` eventually). This is separate from the spectral quantifier conversion.

## Probability wording, scale, and satisfiability

The current Lean results bound each failure probability by `N^(−D)`, hence yield success probability **at least** `1−N^(−D)` once the failure set is shown measurable, matching the printed `≥` in (2.3)–(2.4). If a strict `>` convention is requested, use `D+1` in the failure estimate and `N^(−D−1)<N^(−D)` for large `N`; no stronger analytic input is needed. Formal conversion to a success-event measure should establish the finite union failure set's measurability from the measurable resolvent entries; the probability-bound statements alone do not encode that step.

The diagonal conversion preserves `W_N`, `L_N`, `η`, `ellZ`, and the exact powers in both bounds. It creates no first-cell or time-uniform good event and no one-loop estimate. `Gauss.Dims.exampleGrow` (`Gauss/DimsExample.lean:222–236, 238–260`) has `c=1/8` and both `W_N,L_N→∞`. For example `κ=1`, `τ=1/4`, and `z_N=i/2` satisfy the spectral conditions eventually, including `N^(−3/4)≤1/2`. This is a nondegenerate **domain** witness only; it does not instantiate `Thm221N'`, `BoundsCoreN.localLaw`, or `BoundsCoreN.LmK`. The Lean dimension index has eventual `W_N L_N≤N≤2W_N L_N`, whereas the paper's matrix size is exactly `N=W L`; uniformization does not remove this existing model difference.
