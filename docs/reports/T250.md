## 甲：`TestFun` 实例——**造出来了**

```lean
theorem testFun_softW_mul {ι : Type*} {S : Finset ι}
    {ρ : ι → Matrix (d.Idx N) (d.Idx N) ℂ → ℝ} {Ψ : Matrix (d.Idx N) (d.Idx N) ℂ → ℂ}
    {r : ℕ} {Θ : ℝ} {a₀ a₁ a₂ b₀ b₁ b₂ : ℝ} (hr : 1 ≤ r) (hΘ : 0 < Θ)
    (hsum : BddC2C (fun M => ∑ i ∈ S, ρ i M ^ (2 * r)) a₀ a₁ a₂)
    (hΨ : BddC2C Ψ b₀ b₁ b₂) :
    TestFun d N (fun M => ((softW r S (fun i => ρ i M) Θ : ℝ) : ℂ) * Ψ M)
```
这就是 T230 的 `Φ` 形状（`softW` 嵌进 ℂ，乘矩因子）。

**`ContDiff ℝ 2` 被用满，没有降阶余地**：grep 确认 `TestFun.contDiff_fderiv` / `differentiable_fderiv` / `continuous_fderiv2` 都吃二阶，且 `hasDerivAt_coordD1_update`（→ `hasDerivAt_integral_Phi`，生成元恒等式）要 `fderiv (fderiv Φ)` 可微。**按纪律先查了「阶数是不是多了」，结论是没多，于是把二阶证了而不是弱化。**

**核心技术**：`contDiff_softRootProfile` —— `y ↦ χ((max y 0)^{1/2r}/Θ)` 在**整条 ℝ 上** `C²`。用局部性证：在 `Iio (Θ^{2r})` 上它是常数 `1`（把 `cutChiD_softW_eq_zero` 从「`χ′` 为零」升级成「函数局部为常数」，这才是 `ContDiff` 要的）；在 `Ioi 0` 上 rpow 光滑（`Real.contDiffAt_rpow_const_of_ne`）。两个开集覆盖 ℝ，因为 `Θ^{2r} > 0`。

**链式法则是显式的**：
```lean
bddC2C_comp_real : BddC2C F a₀ a₁ a₂ → ContDiff ℝ 2 g →
  (∀ M, |g (F M)| ≤ c₀) → (∀ M, |deriv g (F M)| ≤ c₁) → (∀ M, |deriv (deriv g) (F M)| ≤ c₂) →
  BddC2C (fun M => g (F M)) c₀ (c₁ * a₁) (c₂ * (a₁ * a₁) + c₁ * a₂)
```
`g` 的界**局部化在 `F` 取到的点上**，所以 `g = (·)^m` 这种在 ℝ 上无界的也能用。权重的 `bdd₀ = 1`、`bdd₁ = c₁a₁`、`bdd₂ = c₂a₁² + c₁a₂`，其中 `(a₀,a₁,a₂)` 是**多项式** `∑ᵢρᵢ^{2r}` 的常数，`(c₁,c₂)` 来自 `exists_deriv_bounds_softRootProfile`（存在性，非显式：`g′`、`g″` 连续且在 `[Θ^{2r},(2Θ)^{2r}]` 外为零，紧性给界）。`TestFun.bdd₁/bdd₂` 本身就是 `∃ C`，**没有损失**——而且这样**刻意避开了对 `2r` 次根求导**，否则会平白引入依赖 `r` 的常数。

## 乙：⚠⚠ **T230 §12 的目标签名是假的，它编译了反例**

```lean
theorem not_coordD1_le_mul_norm {F} {M} {q} (h0 : F M = 0) (h1 : coordD1 d N F M q ≠ 0) (Λ : ℝ) :
    ¬ ‖coordD1 d N F M q‖ ≤ Λ * ‖F M‖
theorem not_logDerivBound_of_zero {S} {ρ ρ'} {i} (hi : i ∈ S) (hρ : ρ i = 0) (hρ' : ρ' i ≠ 0)
    (Λ : ℝ) : ¬ LogDerivBound S ρ ρ' Λ
```
理由：在 `L = K` 的 Hermitian `M` 处右端是 `0`，而 `∂_α L ≠ 0`。**`∂K = 0` 让情况更糟不是更好**（`∂_α lk = ∂_α L`，它没有理由在 `L = K` 处也为零）。`L = K` 在定义域里——就是 `ω = 0` 那类配置。
所以**没有任何 `Λ(d,N,u)`（多项式与否）能满足纯乘性的形状**；`LogDerivBound`（加性项取 0）是**可反驳的**，不是「尚未证明」。

**修复（编译）**：
```lean
theorem abs_deriv_softMax_le_affine {r} (hr : 1 ≤ r) {S} {ρ ρ'} {Λ K} (hK : 0 ≤ K)
    (h : ∀ i ∈ S, |ρ' i| ≤ Λ * |ρ i| + K) (hY : 0 < ∑ i ∈ S, ρ i ^ (2*r)) :
    |…| ≤ Λ * softMax r S ρ + (S.card : ℝ) ^ ((1:ℝ)/(2*r)) * K
theorem abs_coordD1_le_affine (hF : BddC2C F a₀ a₁ a₂) (M) (q) :
    ‖coordD1 d N F M q‖ ≤ (0:ℝ) * ‖F M‖ + a₁ * ‖Bmat d N q.1 q.2.1 q.2.2‖
```

⭐ **它同时指出我们都误判了「对数型」的价值所在**：那个 `≺`-内容**从来不是因子 `Λ`，而是「没有 `card`」**。朴素路线给 `∑ᵢ 2r|ρᵢ|^{2r-1}K → card·K`；新的 Hölder 步
`sum_abs_pow_pred_le : ∑ᵢ|ρᵢ|^{2r-1} ≤ card^{1/2r}·(∑ᵢρᵢ^{2r})^{1−1/2r}`
把它变成 `card^{1/2r}·K ≤ e·K`（经 T230 的 `rpow_card_le_exp_one`）。**这就是软最大值相对乘积权重的全部收益，而且它在 `Λ = 0` 时照样成立。** `Λ_N` 是自由实数，不许取 `+∞`、也不依赖 `‖lk‖`——所以不是绝对界的伪装。
