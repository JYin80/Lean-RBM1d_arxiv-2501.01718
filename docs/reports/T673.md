# T673 — finite probability API probe

## Scope and result

Read-only Mathlib API/import probe for the missing finite-permutation concentration step in
T668. No probability theorem was proved, and no Lean/project source was changed. Both scratch
files were under `/private/tmp`; `lake env lean /private/tmp/T673Minimal.lean` exited 0.

The smallest missing project interface is a finite-permutation exposure bridge: construct the
prefix-reveal filtration for a uniformly random `Equiv.Perm (Fin W)` and prove the conditional
Hoeffding hypotheses from the transposition-completion coupling. Mathlib has the generic
conditional-sub-Gaussian Azuma theorem and Hoeffding lemma, but no ready-made finite-permutation
bounded-difference theorem or permutation exposure filtration was found. The remaining zero-mean
Fourier identity and finite union/existence step are ordinary finite counting arguments.

## Verified APIs

The following all compiled with this minimal import set:

```lean
import Mathlib.Probability.Distributions.Uniform
import Mathlib.Probability.UniformOn
import Mathlib.Probability.Moments.SubGaussian
import Mathlib.Basic.Complex.Basic
```

* `Equiv.Perm (Fin W)` is finite (`Equiv.instFintype`); the exact cardinality API is
  `Fintype.card_perm : Fintype.card (Equiv.Perm α) = (Fintype.card α).factorial`.
* `PMF.uniformOfFintype (Equiv.Perm (Fin W))` is the uniform permutation law;
  `PMF.uniformOfFintype_apply` returns the reciprocal cardinality. For an event expressed as a
  set, `ProbabilityTheory.uniformOn (Set.univ : Set (Equiv.Perm (Fin W)))` has the probability
  instance `ProbabilityTheory.instIsProbabilityMeasure_uniformOn_univ`.
  `ProbabilityTheory.uniformOn_apply_finset` gives normalized finite counting when the event is
  represented by a finite set.
* `ProbabilityTheory.hasSubgaussianMGF_of_mem_Icc_of_integral_eq_zero` is Hoeffding's lemma for a
  centered bounded real variable. The general martingale tail API is
  `ProbabilityTheory.measure_sum_ge_le_of_hasCondSubgaussianMGF`; it assumes a `Filtration`,
  `StronglyAdapted`, an initial sub-Gaussian bound, and one `HasCondSubgaussianMGF` bound per
  increment, and concludes
  `μ.real {ω | ε ≤ ∑ i ∈ Finset.range n, Y i ω} ≤ exp (-ε^2/(2 * ∑ i ∈ Finset.range n, cY i))`.
  This is a usable endpoint after the project proves the exposure/conditional-MGF bridge.
* Complex projections are `Complex.re` and `Complex.im`; the verified norm bounds are
  `Complex.abs_re_le_norm` and `Complex.abs_im_le_norm`.
* The finite union estimate is `MeasureTheory.measure_biUnion_finset_le`; the countable versions
  are `MeasureTheory.measure_biUnion_le` and `MeasureTheory.measure_iUnion_le`.

`Mathlib.Data.Complex.Basic` compiled but emitted a deprecation warning; the current import is
`Mathlib.Basic.Complex.Basic`. The scratch probe also confirmed that `Finset.measure_biUnion_le`
and `Finset.measure_iUnion_le` are not names; the measure bounds live in `MeasureTheory`.

## Exact limitation of the available concentration API

The Azuma theorem above is not itself the desired permutation statement. It does not construct the
filtration generated by revealing `π(0), …, π(W-1)`, identify conditional completions, or turn the
transposition sensitivity `8/W` into conditional centered increment ranges. Those remain the
project-local proof obligation. Once established, Hoeffding's lemma with each real/imaginary
increment in `[-8/W,8/W]` gives sub-Gaussian parameter `(8/W)^2`; summing `W` parameters and using
the `r/√2` coordinate threshold yields `2 exp(-W r²/256)` per coordinate, hence the requested
`4 exp(-W r²/256)` after the two-coordinate union.

No API was found for a uniform permutation exposure process or a direct bounded-differences
inequality. The imports above provide generic building blocks, not a finite-probability proof.

## Honest prospective interface

One reusable target is the following mathematical signature. Let `χ : Fin W → ℂ` be a unit-modulus,
zero-mean character, and let `x : Fin W → ℂ` satisfy `‖x j‖ ≤ 2`. Define

```text
fourierCoeff(x, χ, π) = (W : ℂ)⁻¹ * ∑ j : Fin W, x (π j) * χ j.
```

Then for `2 ≤ W` and `0 < r`, prove under normalized counting on
`Equiv.Perm (Fin W)`:

```text
Pr_π [r ≤ ‖fourierCoeff(x, χ, π)‖] ≤ 4 * exp (-(W : ℝ) * r^2 / 256).
```

The exact project application takes `x j = g_u(λ_j)` and
`χ j = exp(2π i qj/W)` for `q : ZMod W`, `q ≠ 0`. This signature bounds a single W-point, single
time, nonzero mode. It deliberately says nothing about zero mode, `u=0` or `u=1/2` endpoint
analysis, time interpolation, finite unions over `L(W−1)T_N ≤ 2N²`, cyclic shifts, or a shared
sample/event.

  `centeredTrace_false_norm_eq_true` is also present.

The finite tail statement supplies no carrier event, common-event inclusion, nondegenerate
