# T432 — independent joint-event audit for the sharp first-cell block cap

## Verdict

**Passed.**  T428's literal event can be intersected with T418's literal common event while
retaining one actual sample with all of the following properties simultaneously:

- the `k=2` prefix is active and the actual exponent-`delta` weight equals one for every moment
  order;
- the actual length-four/six `SourceEvent` holds at the positive endpoint `u_2`;
- the sharp block observable satisfies `APrimeJG.jG<=2` for every real running time in
  `[0,1/2]`, hence in `[0,u_2]`.

This conclusion must be obtained by choosing the sample from the **intersection** HighProb event
and then applying the universal active-weight theorem to that sample.  Intersecting two unrelated
existence witnesses would be invalid.  The required universal theorem and event projections are
already compiled, so the joint resident needs no new probabilistic estimate.

The sharper cap directly improves the block-`jG` input in T415's moving QV profile.  It does not
bound the loop observable `Step2.jS` in T422's quadratic drift profile; T430's loop bound remains
necessary.

## 1. Literal events and their intersection

```text

Gcommon_N = APrimeFirstCellEGAllOutputRunning.good tau delta nu N
          = APrimeFirstCellMovingSupport.commonEvent
              tau (sourceLoss nu) (sourceLoss nu) (delta/16) N.
```

T428 proves `HighProb (P d) Gsharp` with no parameter or premise.  T418's
`exists_good_with_all_output` chooses one `tau>0` and then, for every
`0<delta<=1/100` and every `nu>0`, supplies measurability and
`HighProb (P d) Gcommon`.  Therefore

```text
Gjoint_N := Gsharp_N ∩ Gcommon_N
```

is measurable and HighProb by the existing intersection lemmas.  Since `P d` is a probability
measure, `HighProb.nonempty` supplies, eventually in `N`, one `omega∈Gjoint_N`.  All subsequent
sample-dependent facts below are proved for this `omega`.

For an arbitrary positive loss `lambda`, T413's stronger
`exists_commonEvent_with_plateau` has the order

```text
exists tau>0, forall delta∈(0,1/100], forall zeta1,zeta3>0, ...
```

so one may set `zeta1=zeta3=lambda`.  T418 specializes this to
`lambda=sourceLoss nu`, retaining the order

```text
exists tau>0, forall delta∈(0,1/100], forall nu>0, ... .
```

T428 adds no `tau`, `delta`, or loss choice, so intersection does not change this order.  In
particular, neither `tau` nor the event is reselected after a moment order or sample is known.

The sharp event keeps T428's failure estimate

```text
4 * L_N * exp (-15 * W_N) <= N^(-D),
```

using only `W_N >= N^(5/8)` and `W_N * L_N <= N`.  Applying `HighProb.inter` merely asks each
factor for a stronger polynomial failure exponent before taking the union bound; it introduces no
new relation between `W`, `delta`, or the source loss.  Thus the `N`/`W` exponents and the
all-real-time interval are compatible on the literal intersection.

## 4. Effect on current consumers

### T415 moving QV: genuine improvement

T415's `movingProfileAt` passes `APrimeSupportRunning.jG N r omega` into
`APrimeFullQV.rootProfile`, including its quadratic and cubic far rows.  The local adapter
`qvAt_on_joint_moving_of_scales` currently asks for `jG<=N^(1/8)` and weakens this to the underlying
`jG<=N` premise.  On `Gjoint`, T428 instead gives `jG<=2` at every real `r<=u_k`.

The existing T415 adapter is tied in its signature to T395's
`APrimeFirstCellSourceSupport.jointEvent`, although its proof consumes only the running
`SourceEvent` and the block cap.  T418's common event supplies the same `SourceEvent`.  A primed
adapter can therefore call `APrimeFullQV.qvAt_full_absorbed` directly with the T418 source and the
T428 bound.  Downstream estimates may substitute `J<=2` in the `J^2` and `J^3` rows, removing the
small polynomial block-cap losses.  The moving endpoint, near residual, `W^-1` repair, and
`W^-60` leakages remain unchanged.

### T422 raw drift: no loop improvement

T422's `quadProfile` contains

```text
Step2.jS (sample d) 0 60 N r omega
```

rather than `APrimeJG.jG`.  T413's `comparisonEvent` only bounds block `jG` **above** by an
expression involving loop `jS`; it cannot be inverted to bound `jS` from T428's block cap.  Hence
the sharper result does not absorb or improve T422's quadratic drift row.  T430's same-event
running loop-`J` cap is still required.  T422's linear `eGpm` part remains available on the joint
event by projection to `Gcommon`.
