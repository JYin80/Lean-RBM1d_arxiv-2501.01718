## `δ' N` 的显式形式

```
δ' N = errBudget (L N) n (v N) (Kd N) (Msz N) (δ N) (Pb N) (esz N)
     = qopErr1 … + commErrBd … + dotErrBd … + qqErrBd …
commErrBd L n v K Pb = (n+2)(1−v)⁻¹·Pb·C^(n+1)·(2+L·C)·exp(−c₀K/2)
dotErrBd  n v K Pb   = Pb·(3(n+1)·C^(n+1)·(1−v)⁻¹·exp(c₀/2))·exp(−c₀K/2)
```
量级（`k = n+2`）：
```
δ' N  ≍  poly(L N, n)·(Msz N + Pb N + esz N)·e^{−c₀·Kd N/2}   +   (L N·C)^{2n+4}·δ N
```
**它真的依赖 `N`**（T246 点名的陷阱）：`commErrBd` 带显式因子 `L N`，`qqErrBd` 带 `(L N)^k` 与 `(2e(L N·Kd N+1))^k`——**没有常数能压住**。

## ⚠ 它订正了 T246 的一句话

T246 报告里「四个预算都是多项式乘 `O(e^{−cN^τ})`，`δ' N` 超多项式小」**不完全对**：
* 指数部分 `poly(N)·e^{−c₀N^τ/2}` —— 超多项式小，随便够；
* **非指数部分 `(L N·C)^{2n+4}·δ N` 不是超多项式小**，它是 `N^{O(n)}·N^{τ₁−D}`。

而且这一项**不是 T253 放宽出来的，是 `qBlockErr` 定义自带的**（`+ L^k·δ·(C/ℓr)^k` 那一项没有任何指数因子），所以**任何** `δ'` 都至少有这个量级；T253 的界在这一项上只比下确界多一个 `ℓr^k ≤ L^k` 的因子。
**不影响 `hnum` 能否卸掉**（`D` 自由，`n`、`τ₁` 在 `D` 之前固定，对任意目标 `D'` 取 `D` 足够大即可），**但影响谁来写 `hnum` 时的记账方式**。
