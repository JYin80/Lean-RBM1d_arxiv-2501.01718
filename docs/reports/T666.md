## 2. Public surface and exact types

The support predicate is

```lean
def RBM.Gauss.HermitianBandSupported {d : Dims} {N : ℕ}
    (M : Matrix (d.Idx N) (d.Idx N) ℂ) : Prop :=
  ∀ i j, i.1 - j.1 ∉ sbSupport (d.L N) → M i j = 0
```

The coordinate value and full sample are

```lean
noncomputable def RBM.Gauss.hermitianCoordValue {d : Dims} {N : ℕ}
    (M : Matrix (d.Idx N) (d.Idx N) ℂ)
    (p : d.Idx N × d.Idx N × Bool) : ℝ

noncomputable def RBM.Gauss.omegaOfHermitian (d : Dims) (N : ℕ)
    (M : Matrix (d.Idx N) (d.Idx N) ℂ) : Ω d
```

`hermitianCoordValue M p` is `(M p.1 p.2.1).re` when `p.2.2=true` and the imaginary part
when `p.2.2=false`.  `omegaOfHermitian` is the finite sum

```text
sum p in usedCoord d N,
  Pi.single (crd d N p) (hermitianCoordValue M p).
```

The evaluation surface is:

```lean
omegaOfHermitian_crd_of_mem
omegaOfHermitian_crd_eq_zero_of_not_mem
omegaOfHermitian_eq_zero_of_size_ne
omegaOfHermitian_crd_true_of_lt
omegaOfHermitian_crd_false_of_lt
omegaOfHermitian_crd_diag
```

The last three corollaries say exactly, for `idxKey d N i < idxKey d N j`,

```text
omegaOfHermitian d N M (crd d N (i,j,true))  = (M i j).re
omegaOfHermitian d N M (crd d N (i,j,false)) = (M i j).im
omegaOfHermitian d N M (crd d N (i,i,true))  = (M i i).re.
```

The two zero lemmas state separately that every unused coordinate at size `N` and every
coordinate at a different size `N' != N` is zero.  Thus the definition is a full-product
sample, not a function only on an effective finite subtype.

Exact readback is

```lean
theorem RBM.Gauss.Xmat_omegaOfHermitian {d : Dims} {N : ℕ}
    (M : Matrix (d.Idx N) (d.Idx N) ℂ) (hM : M.IsHermitian) :
    Xmat d N (omegaOfHermitian d N M) = M
```

The proof splits into the three literal `Xentry` branches.  The upper triangle uses
`Complex.re_add_im`, the diagonal uses `Matrix.IsHermitian.coe_re_apply_self`, and the lower
triangle uses `Matrix.IsHermitian.apply`.  There is no `sqrt(gvar)`, `sqrt 2`, inverse
variance, probability statement, or almost-everywhere weakening.

## 3. Exact support and variance conventions

The new `Sblk` facts are

```text
Sblk_eq_of_mem:
  block difference in sbSupport -> Sblk L W i j = 1 / (3 * W)

Sblk_eq_zero_of_not_mem:
  block difference notin sbSupport -> Sblk L W i j = 0

Sblk_pos_iff_mem:
  0 < Sblk L W i j <-> block difference in sbSupport.
```

They assume `[NeZero W]`, exactly what is needed for positivity and division.  Applied to a
`Dims`, `d.W_pos N` supplies this condition.

The coordinate facts are

```text
gvar_crd_diag_exact:
  gvar (i,i,b) = 1 / (3 * d.W N)                 for either Bool tag b

gvar_crd_offDiag_exact:
  i != j and block difference in sbSupport
    -> gvar (i,j,b) = 1 / (6 * d.W N)            for either Bool tag b

gvar_crd_eq_zero_of_not_mem:
  block difference notin sbSupport -> gvar (i,j,b) = 0

gvar_crd_pos_iff_mem:
  0 < gvar p <-> block difference in sbSupport.
```

Consequently the used diagonal real variance is `1/(3W)` and each used off-diagonal real or
imaginary variance on the same/adjacent blocks is `1/(6W)`.  The statements deliberately
apply more broadly than `usedCoord`: an unused diagonal-imaginary coordinate also has
variance `1/(3W)`, and an unused reverse off-diagonal coordinate can have variance `1/(6W)`.
The encoder sets such coordinates to zero by its chosen finite-singleton support, not by
claiming their variance is zero.

## 4. Full-product zero-variance compatibility

The exact theorem is

```lean
theorem RBM.Gauss.omegaOfHermitian_eq_zero_of_gvar_eq_zero
    {d : Dims} {N : ℕ} {M : Matrix (d.Idx N) (d.Idx N) ℂ}
    (hband : HermitianBandSupported M) (c : Coord d)
    (hg : (gvar d c : ℝ) = 0) :
    omegaOfHermitian d N M c = 0
```

For a used current-size coordinate, positivity/support equivalence turns `hg` into an
off-band matrix entry, which is zero by `hband`; its real and imaginary parts are therefore
zero.  For unused current-size coordinates and every coordinate at another size, each
singleton in the defining sum evaluates to zero.  The quantifier is over the full
`Coord d`, so none of these cases is omitted.

## 5. Nondegenerate satisfiability witness

The theorem

```lean
theorem RBM.Gauss.exists_nonzero_hermitianBandSupported (d : Dims) (N : ℕ) :
  ∃ M : Matrix (d.Idx N) (d.Idx N) ℂ,
    M.IsHermitian ∧ HermitianBandSupported M ∧ M ≠ 0
```

constructs the explicit diagonal matrix with value `1` at

```text
i0 = (0 : ZMod (d.L N), 0 : Fin (d.W N))
```

and zero elsewhere.  The index is valid because `d.W_pos N`; `d.three_le_L N` is already
part of `Dims`.  The matrix is Hermitian, nonzero at `(i0,i0)`, and band supported because a
nonzero entry has physical-block difference `0 in sbSupport`.  This is a nonzero witness at
every `d,N`, stronger than a single concrete specialization; the zero matrix is not used as
the satisfiability witness.
