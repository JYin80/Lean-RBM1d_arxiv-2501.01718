## Proof split

The adapter uses the actual declaration

```lean
APrimeSmoothWeightActual.weight_nonneg
```

through the abbreviation `APrimeSupportRunning.weight`.

* If `w = 0`, both weighted products reduce to zero.  This branch makes no
  claim that the unweighted `qvAt` vanishes.
* If `w != 0`, nonnegativity gives `0 < w`.  T438's
  `currentRowsBound` then supplies the unweighted estimate on the same
  sample, event, moving endpoint, real running time, and output.  Multiplying
  by the nonnegative `w` proves the result.

The exact T438 current rows remain unchanged:

```text
x_r^(-3/2),
N^(4 delta + 2 tau) A_v^(-1/2) x_r^(19/4),
N^(6 delta + 3 tau) A_v^(-1)   x_r^8,
tau = delta/16.
```

Consequently the `W^(-1)`, `W L W^(-60)`, and propagated
`256 exp(3) W^(-60)` terms are paid exactly where T438 pays them.  This
adapter performs no further weakening or absorption.

## Positive same-event witness

`positiveWeightedCurrentRowsPlateau` reuses T438's same positive `k = 2`
resident.  On that one sample it retains:

* membership in the same `sharpCommonEvent`;
* positive moving endpoint `v <= firstCellT <= 1/2`;
* the same source event and fixed block bounds;
* `weight delta ... 2 p N 2 N omega = 1` for every moment label `p`;
* the weighted estimate for every real `r in [0,v]` and every output `a`;
* explicit weighted estimates at both `r = 0` and `r = v`.

This is a nondegenerate witness: the actual weight is one, rather than zero.
The main definition assumes `k >= 1`; it makes no statement for `k = 0` and
does not claim `qvAt = 0` there.

## Assumptions and scope

No new mathematical assumption was added.  The only input to the adapter is
T438's proved `currentRowsBound`; the closed theorem obtains it from T438's
closed same-event producer.

This module proves only the favorable-event pointwise weighted inequality.
It does not integrate in time, estimate the Good-event complement, form a
global moment norm, construct `hG` or `hfamily`, or claim A-prime.
